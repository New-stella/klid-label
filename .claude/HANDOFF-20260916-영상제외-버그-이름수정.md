## 6. 이 라운드에서 실제로 밟은 함정 (전달 필수)

구현·QA 에이전트 프롬프트에 **매번 실어라.** 안 그러면 다음 담당이 그대로 밟는다.

| 함정 | 요지 |
|---|---|
| ★**엔티티 기본값** | `NOT NULL` 컬럼 기본값을 **빌더/생성자에만** 두면 `new Entity()` + 필드 대입 경로가 비어 **INSERT 전멸**(실측 113건 / 130 FAILED). **필드 선언**에 둘 것 |
| ★**인가 시험** | **JWT `role` 클레임은 인가에 안 쓰인다 — `LS_USER_ROLE` 이 진실원.** 역할을 안 심으면 403 이 「그 역할이라서」가 아니라 「무권한이라서」 나고 **시험이 이름만 남는다** |
| ★**변이 방식** | **삭제가 아니라 「결과만 뒤집는 최소 변형」**(`AND 1 = 0` · `x.or(x.not())`). 절을 지우면 미바인딩으로 컨텍스트가 죽어 무관한 시험까지 죽는다. **각 변이마다 실행 건수를 기준선과 대조** |
| ★**범위 단언** | 「범위 안에서 센다」류는 **픽스처가 자족**해야 한다. 공유 컨테이너 잔여가 대조군을 대신하면 스위트를 좁게 돌리는 순간 **아무것도 증명하지 않는다** |
| ★**공용 표 침범** | 시험 픽스처가 공용 원장에 남의 식별자 공간을 쓰면 **시퀀스가 자라 공용 시드 행을 지운다**(시한폭탄). 운반체는 **자기가 만든 행의 자식**으로 |
| **컨텍스트 상한** | `@TestPropertySource` 신설 시 **상한 75** 가드에 걸린다. 올리지 말고 **같은 설정을 가진 기존 클래스**에 넣어라 |
| **Flyway 스쿼시 가드** | 신규 마이그레이션마다 `FlywaySquashBaselineIT` **세 곳** 수동 갱신. ★그중 **javadoc 목록은 어떤 시험도 강제하지 않아** V37·V38 이 이미 비어 있었다 |
| **동시 편집** | **검증 에이전트가 도는 동안 그 파일을 건드리지 마라** — 변이 원복이 통째 덮어쓰기면 남의 편집이 사라진다(실제로 겪음) |
| **빌드 동시성** | **빌드 에이전트 동시 2개 금지**(`build/test-results` 충돌 → 위양성). fan-out 은 **순차** |
| **QA stall** | 전체 회귀 + 변이마다 회귀를 연달아 돌리면 600초 무진행으로 죽는다. **회귀는 백그라운드+폴링, 변이는 타깃 스위트** |
