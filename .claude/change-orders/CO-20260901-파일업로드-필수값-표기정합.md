## 1. 왜 하는가

파일 업로드 화면에서 **화면이 요구하는 필수값과 실제로 시작을 막는 조건, 그리고 서버가 요구하는 값 셋이 서로 어긋나 있다.** 세 건 다 기본값이 미리 채워져 있어 평소에는 드러나지 않고, 사용자가 값을 지우거나 문서를 읽을 때만 드러난다.

가장 눈에 띄는 것은 한 화면 영역 안에 모순이 나란히 놓여 있다는 점이다 — 화면이 `출처유형 *` 으로 필수 표기를 달아 두고, **바로 그 아래 줄에서 「이 값은 전송되지 않습니다」 안내를 함께 띄운다**(`TusUploadPanel.tsx:254-255`).

## 2. 무엇을 바꾸는가

세 건이며 서로 독립이다.

### ① 촬영일시의 필수 표기가 실제 조건과 어긋난다

화면은 촬영일시에 별표를 달지 않는데(`TusMetaFieldsets.tsx:193` `label="촬영일시"`), 시작 조건은 파이프라인 즉시 실행 경로에서 그 값을 요구한다(`unifiedUploadForm.ts:228` `if (!form.shtDtLocal) return false;`). 값을 지우면 **별표 없는 항목 때문에 시작 버튼이 잠기고, 화면 어디에도 이유가 없다.**

→ 즉시 실행 경로일 때 촬영일시에 필수 표기가 뜨게 한다. **조건을 바꾸는 것이 아니라 표기를 조건에 맞춘다.**

⚠ 이벤트유형도 같은 성질이지만 그 입력칸은 이 묶음이 아니라 폼 상단 공통 영역이 소유한다(`UploadRouteFields.tsx:122 EventTypeField`, 라벨 `이벤트유형` 에 별표 없음). 같은 판정으로 함께 맞춘다.

⚠ 두 컴포넌트 모두 지금은 경로를 모른다 — `FieldsetProps`(`TusMetaFieldsets.tsx:30`)에 `route` 가 없고 `EventTypeField` 의 인자에도 없다. 다만 **같은 패널의 `PrivacyTypeField` 가 이미 `route` 를 받고 있어**(`TusUploadPanel.tsx:275`) 그 관례를 따르면 된다.

### ② 문서 문구가 실제 동작보다 낡았다

`DevAutolabelTestController` 의 작업 설명과 400 응답 설명이 *"cctvId 미등록 시 400"* 이라 적었으나, `DevAutolabelTestService.validateMeta` 는 *"cctvId 등록 여부는 검증하지 않는다(대조할 마스터가 없다)"* 를 스스로 명시하고 실제로 검사하지 않는다.

→ 실제 동작(형식 검증만)에 맞게 문구를 고친다. **검증 로직은 건드리지 않는다.** 설계(API-152)는 이미 형식 검증만으로 올바르게 적혀 있어 고칠 것이 없다.

### ③ 출처유형 화면 강제를 푼다 (사용자 확정)

어느 경로에서도 서버가 요구하지 않는 값인데 화면만 막고 있다.

- 파이프라인 즉시 실행 — **전송조차 되지 않는다.** 같은 파일이 스스로 `UNSENT_GROUPS[IMMEDIATE]` 에 `'출처유형'` 을 넣어 두었고(`unifiedUploadForm.ts:91`), 파일 머리 주석도 `출처유형 → ✗ 계약에 없음`(`:28`)이라 적었다.
- 관제 인입 재현 — 전송은 되지만 비우면 서버가 `USER_ULD` 기본값을 붙인다.

그런데 시작 조건은 경로를 가리지 않고 이 값을 요구한다(`unifiedUploadForm.ts:224`).

→ 시작 조건에서 이 검사를 빼고 화면의 별표도 뗀다. **입력칸 자체와 인입 재현 경로에서의 전송은 그대로 둔다** — 강제만 걷는다.

**무르게 한 것이 아니라 축을 갈랐다** — 입력칸 지문(`formFieldSignature`)에서 후행 ` *` 를 정규화해 떼고, 떼어낸 표기 축을 `requiredLabels()` 로 **따로 세워** 관계 단언으로 고정했다: *"갈리는 둘만 빠지고 나머지는 그대로"*(`beforeRequired − afterRequired === ['이벤트유형 *','촬영일시 *']` + `afterRequired ⊆ beforeRequired`). 정규화만 했으면 「필수 표기가 통째로 사라져도 초록」이 되는데 그 사각을 스스로 막았다. 변이 C·D 가 이 케이스를 죽이는 것으로 증명됐다.

**후속 (이번 범위 밖)**
- 필수 표기를 이 폼의 기존 관례인 인라인 ` *` 로 통일했다. 저장소에 더 나은 접근성 수단(`<FieldLabel required>` — 별표 `aria-hidden` + sr-only `(필수)`)이 있고 9곳이 쓰지만, **이 폼은 6곳 전부 인라인**이라 한 칸만 바꾸면 같은 fieldset 안에서 접근 이름 형식이 갈린다(낭독기가 「별표」와 「필수」를 섞어 읽는다). 폼 전체를 옮기는 것은 별도 라운드이며 그때 `getByLabelText('… *')` 셀렉터 다수가 함께 바뀐다.
- 런타임 E2E 미수행 — 표기와 시작 버튼 활성 조건만 바뀌고 전송 payload 를 건드리지 않아 BE 배포와 무관하다.
