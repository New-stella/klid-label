# CO-20260902 — 포털 본문 상단 이동 탭 신설

- 상태: 착수
- 근거 결정: `SHELL-002` v8 · `NAV-002` v17 · `SCREEN-028` v34 (설계 **선반영 완료** — 이 CO 는 ITEM 을 고치지 않는다)
- 범위: 프론트 전용

## 1. 왜

포털 채널의 저작도구 화면은 Host 화면 안에서 실행된다. **Host 가 머리 영역과 좌측 주 메뉴를
모두 소유**하고 저작도구는 그 아래 **본문만** 그린다(2026-09-02 사용자 확정, 구속).

그래서 저작도구는 자기 좌측 레일을 두지 않는다 — 두면 왼쪽 레일이 둘이 되어 Host 화면과 부딪힌다.
대신 **목적지 셋을 본문 상단 이동 탭**으로 오간다.

⚠ **Host 메뉴에 우리 하위 목적지를 등재하지 않는다** — 등재하면 이동 수단이 둘이 되고, 목적지가
늘 때마다 **상대 배포가 필요**해진다. 본문 상단 탭은 Host 자신도 쓰는 확립된 패턴이다.

## 2. 설계 확정값 (재발명 금지)

**탭 영역** — 키 `portal-content-tabs` · 자리 `inline_tabs` · 표시 `tabs` · 가로 · 전 기기 ·
출처 `NAV-002` · 단계 1→1.

**탭에 뜨는 목적지 셋**

| 라벨 | 경로 | 화면 |
|---|---|---|
| 내 작업 | `/portal` | `SCREEN-028` |
| 내 업로드 | `/portal/uploads` | `SCREEN-033` |
| 증강 | `/portal/augment` | `SCREEN-044` |

**탭을 노출하지 않는 화면** — 아래 둘은 목적지가 아니라 **목록에서 행을 눌러 들어가는 자리**이고,
몰입 편집 화면이라 이동 탭을 두지 않는다.

| 화면 | 경로 | 왜 |
|---|---|---|
| 포털 라벨링 | `/portal/label/:id` | 목록 행에서 진입. 편집 중 이탈을 부른다 |
| 업로드 영상 마킹 | `/portal/uploads/:uldSn/marking` | 특정 자산에 매인 화면. 영상 재생이 세로를 차지한다 |

⚠ `/portal/uploads/:uldSn/label`(업로드 자산 라벨링)은 **폐기된 목적지**다 — 포털 라벨링 화면으로
합쳐진다. 이번 CO 의 범위가 **아니다**(별도 단계). 여기서는 **탭에 넣지 않는 것**까지만 지킨다.

## 3. 무엇을 한다

1. **포털 채널 셸에 본문 상단 이동 탭을 신설**한다. 목적지 셋을 가로 탭으로 그리고 현재 위치를 표시한다.
2. **좌측 주 메뉴·머리 영역·푸터를 두지 않는다** — 지금 형상이 이미 그러하다면 **바꾸지 않는다**
   (설계가 구현 쪽으로 되돌아온 것이라 제거할 코드가 없을 수 있다. 실측하고 보고하라).
3. **위 두 화면에서는 탭을 노출하지 않는다.**
4. **관제 채널은 손대지 않는다.**

## 4. 하지 말 것

- **로고·사용자 신원·역할 배지를 두지 마라** — Host 머리 영역이 이미 보여 준다.
- **좌측 레일을 만들지 마라.** 이 축은 **두 번 뒤집혔고** 지금이 세 번째 확정이다.
- **목적지 목록을 화면 쪽에 다시 나열하지 마라** — 두 곳에 적으면 한쪽만 갱신돼 어긋난다.
  탭 항목의 진실원은 한 곳이어야 한다.
- 라벨링 화면 통합·마킹 화면 신설은 **다른 단계다.** 여기서 하지 마라.

## 5. 수용 기준

1. 포털 채널 목적지 셋이 본문 상단 탭으로 오간다. 현재 위치가 표시된다.
2. 라벨링·마킹 두 화면에서 탭이 **뜨지 않는다.**
3. 저작도구가 그리는 좌측 레일·머리 영역·푸터가 포털 채널에 **없다.**
4. **관제 채널 화면이 무변경**이다(소스 동치 또는 되돌림 실증으로 보인다).
5. 프론트 전건 통과 · lint 0 errors · 빌드 성공.
