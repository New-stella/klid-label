## §2 변경 요지 (사용자 확정 2026-09-14)

1. 영상 분석 설명(왼쪽 5 — 저장 축은 시계열 메타) + 이벤트 어노테이션(오른쪽 7)을 담은 **하나의 비모달 창**을 두 화면에 둔다 — 제목 표시줄 드래그 이동 · 모서리 크기조절 · 기본 1440×810(뷰포트 약 75%) · 최소 560×640 · 폭 880 미만이면 두 칸이 위아래로 쌓임 · 뒤 화면(캔버스·타임라인·우측 탭) 조작 가능 · 창은 동시에 하나(열려 있으면 버튼이 「창 앞으로 가져오기」). 필드·섹션별 팝업은 두지 않는다.
2. 우측 메타 탭의 두 패널 자리는 **요약 카드 + 버튼 하나**로 바꾼다.
3. 라벨링: 입력 + **저장 버튼 하나**(창 아래 「닫기」·「저장」 — 바뀐 칸만 저장, 둘 다 바뀌면 둘 다, 한쪽 실패 시 그 칸 머리에 표시 · 미저장 표시는 제목 표시줄 + 칸 머리 · 미저장으로 닫으면 확인) · 캡션 문장은 여러 줄 입력.
4. 라벨링: 근거 후보 **「화면에서 지정」 모드** — 창을 숨기고 위쪽 띠에서 현행 두 동작(현재 프레임 추가 · 선택 객체 추가)으로 담은 뒤 「완료」로 창 복원·반영, 「취소」는 이번에 담은 것만 폐기. 제목 표시줄 「잠시 접기」(띠의 「펼치기」로 복원).
5. 검수: 읽기 전용(입력·저장·후보 추가/삭제·지정 컨트롤 렌더 안 함) · **영상 분석 설명에 검토 상태 배지 없음**(요약 카드에도 검토 상태 행 없음) · **근거 프레임 번호를 누르면 뒤 화면이 그 프레임(SRC_SN)으로 이동**하고 창은 접힘 + 띠 「펼치기」 · 이 영상에 없는 번호는 이동 없이 안내.
6. 표기: **이 창과 요약 카드에서는 「영상 분석 설명」** 이라고 쓴다(「시계열」「시계열 메타」「시계열 서술」 금지 — 사용자 확정 「시계열이란 말도 어려워」 · 범위는 이 창과 요약 카드만, 다른 화면의 「시계열」 표기는 그대로) · 창 안에서 내부 키(`vlm.description` · `manual-timeseries` 등)를 라벨로 노출하지 않는다 · 「이벤트 어노테이션」은 이름 유지(한 줄 설명으로 풀이) · 이벤트 분류는 **이름 + 코드**(「교통사고 car_accident」, 코드 흐리게, 모르는 코드는 코드만) · 후보는 **「캡션 1」「근거 1」 + 흐린 저장 키 `c1`**(번호는 저장 키의 숫자 — 목록 순번으로 다시 매기지 않는다) · 추가 버튼 「+ 캡션 추가」「+ 근거 추가」.
7. **도움말은 라벨 아래 회색 글씨로 항상 표시 + 「도움말 숨기기」 버튼**(숨김 여부는 브라우저에 기억).
8. 창 위치·크기는 **브라우저에 기억**(서버 저장 없음 · 복원 위치가 화면 밖이거나 저장소를 못 읽으면 기본 위치).
9. 캡션 문장의 마크다운 기호 표시 방식은 **사업자 회신 대기** — 당분간 원문 텍스트 그대로 표시.
10. 「잠시 접기」 띠: 안내 한 줄 「영상 분석 설명 · 이벤트 어노테이션 창을 잠시 접었습니다. 다시 보려면 펼치세요.」 + 「펼치기」 · 저장 안 된 변경이 있으면 「저장 안 된 변경 있음」 병기.
11. 근거 지정 띠 「취소」: 이번에 담은 값만 버리고 **창을 원래 크기·위치로 바로 되돌린다**(「완료」와 복원 동작 동일, 값 반영만 다름).
12. 미저장 닫기 확인: 제목 「저장하지 않은 변경이 있습니다」 · 본문 「닫으면 고친 내용이 사라집니다. 바뀐 칸: {칸 이름}」 · 버튼 「저장하고 닫기」「저장하지 않고 닫기」「계속 작성」.
13. **이전 방식 구간 키 값(「0-8」 등)에는 대응하지 않는다** — 사용자 확정(2026-09-14 「이전 데이터는 목업이 준 잘못된 데이터잖아 그냥 삭제하고 대응도 하지 마」). 창·요약 카드에 그 표시·접기·대체 규칙을 두지 않는다. ⚠ 프로젝트 지침의 「이미 적재된 구간 키는 작업 결과라 보존(삭제·숨김 금지)」 서술을 뒤집는 결정이며, 사용자가 그 근거를 「목업이 준 잘못된 데이터」로 판정했다.
    - **246 삭제 완료(2026-09-14)**: 구간 키 행은 0건이었고, 실제 대상은 목서버가 만든 시계열 결과였다 — `vlm.description`·`vlm.accuracy` 메타 31건 · 그 검토 행 19건(승인 4 포함) · 시스템 자동 작성 이벤트 어노테이션 5건. 남은 메타 292건(영상 기술정보·이관 원문·포털)은 불변. 백업 CSV 3종은 세션 스크래치패드 `246-mock-vlm-backup-20260914/`.
    - ⚠ 승인 4건(영상 1·2·26·43)의 이미 만든 산출 폴더·승인 동결 메타는 지우지 않았다 — 개발 서버에서 화면과 옛 산출물이 어긋날 수 있다(인지·수용).
    - ⚠ 현장(온프렘) DB 에도 같은 목서버 데이터가 있는지는 확인하지 못했다(접근 불가) — 별도 확인 필요.

## §4 영향·리스크

- **하위호환**: 영상 상세 응답은 필드 추가만. 시계열·이벤트 어노테이션 API·저장 데이터 무변경 → 관제·산출물 영향 없음.
- **되돌리기**: 프론트 revert · 백엔드 새 필드 제거.
- **리스크**: 두 저장 창구를 한 버튼으로 묶을 때 부분 실패 표시 누락 · 비모달 창과 캔버스 단축키 충돌 · 근거 지정 모드 중 프레임 전환·저장 상태 꼬임 · 프레임 전환 재조회가 편집 중 시계열 값을 덮음.

  - 근거는 **게시된 고충실 시안**(오늘 재게시판): `SD-002` main·`evntanno-window`·`evidence-strip` / `SD-005` main·`evntanno-window`. ⚠ 로컬 키트의 `design.html`(원본)은 게시본보다 **뒤처져 있다** — 그것을 근거로 삼지 말 것.

  - **판정 방법(사용자 확정): 화면을 직접 열어 시안과 나란히 비교**한다. 코드 대조만으로는 간격·순서·비율 차이가 안 잡힌다.

  - 결과물은 **항목별 대조표**(시안 / 구현 / 일치)이며 **대조하지 않은 항목도 명시**한다. 「맞췄다」는 주장만으로는 통과가 아니다.
