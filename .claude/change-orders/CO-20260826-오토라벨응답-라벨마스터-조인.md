# CO-20260826 오토라벨 응답이 라벨 마스터를 조인하지 않는다

## 1. 무엇이 문제인가

영상 상세 → **오토라벨 결과** 탭의 「라벨별 분포」가 **라벨명을 영어로만** 보여준다.
라벨 마스터 화면에는 한글 등록명이 나오는데 여기만 다르다. 색상도 전부 같은 파랑이다.

사용자 신고: *"상세화면에 라벨별 분포는 왜 다 영어로만 나오지? 라벨마스터랑은 다르게 나오네"*

## 2. 원인

두 화면이 **서로 다른 경로**를 타고, 그중 하나만 라벨 마스터를 조인한다.

| 경로 | 표시명 | 색상 |
|---|---|---|
| 라벨링 화면·라벨 마스터 | `LS_DATA_LBL` + **`LS_LABEL` 조인**(`labelId`) → 마스터 등록명 | 마스터 `COLR_VL` |
| **영상 상세 오토라벨 탭** | `LS_DATA_LBL.LABEL_NM` **원문** | `#3B82F6` **하드코딩** |

`VideoQueryService` 의 응답 조립이 한 값을 두 필드에 복사한다 — `labelCode` 와 `labelName` 이
같은 `getLabelNm()` 이고, 색은 상수다. AI 가 쓴 `LABEL_NM` 은 COCO 클래스명(영문)이라 영어로 보인다.

**이건 드리프트가 아니라 낡은 채로 남은 것이다.** DTO 주석이 이유를 스스로 적어 뒀다 —
*"라벨 색상/표시명 코드 테이블은 **V1 시점 미존재** — labelCode 를 labelName 으로 fallback,
color 는 기본값 사용. 추후 연계 시 확장."* 라벨 마스터가 생기기 전에 만들어진 응답이다.

⚠ **프론트를 고쳐서 될 일이 아니다.** 화면에 `resolveLabelDisplayName` 을 끼워도 그 함수는
2026-08-03 에 *"COCO 한글 사전은 마스터와 어긋나는 두 번째 진실원"* 이라는 이유로 치환 로직이
전부 제거된 **통과 함수**다. 서버가 마스터를 조인해 내려줘야 한다.

## 3. 도메인별 변경 상세

### DOMAIN-003 (영상·프레임 수집) — `video/service/VideoQueryService.java`

오토라벨 결과 응답 조립에서 라벨 마스터를 조인한다.

- **`labelName`** — 마스터에 연결된 라벨은 **마스터 등록명**. 미연결 라벨은 **저장된 라벨명 원문
  그대로**(지어내지 않는다). **절대 null 로 내리지 않는다** — 화면이 이 값을 그대로 그려 빈칸이 된다.
- **`color`** — 마스터 등록 색상. 미연결이면 **null**. **서버가 임의 기본색을 만들지 않는다.**
  화면은 이미 `?? '#4ECDC4'` 로 자기 폴백을 갖고 있다.
- **`labelCode`** — **무변경.** 화면이 이 값으로 분포를 묶으므로 의미를 바꾸면 그룹핑이 흔들린다.
- 조인은 **N+1 을 만들지 않는다** — 목록 경로가 이미 쓰는 batch 조회 방식을 따른다.

**불변**: 응답 필드 구성·순서·타입(색만 nullable 로 넓힘) · 인가(REVIEWER/WORKER) ·
`confidence`·`createdBy` 산출 · 프론트 코드(변경 0건이어야 한다).

## 4. 영향 없음을 확인한 것

- **프론트 변경 0건** — 화면이 이미 null 색상을 폴백 처리한다.
- **다른 워크트리와 무충돌** — gui 는 backend 변경 0건, portal 의 backend 변경 33건은
  전부 `dataset/export/*` 축이라 `video/` 를 건드리지 않는다(실측).

## 5. 수용 기준

1. 마스터에 연결된 라벨은 분포 바에 **마스터 등록명**이 나온다.
2. 마스터 색상이 있으면 그 색으로 막대가 그려지고, 라벨마다 색이 갈린다.
3. 마스터 미연결 라벨은 **저장된 원문**이 그대로 나오고 화면 폴백색을 쓴다(빈칸·오류 없음).
4. 라벨 N종을 담은 영상에서 쿼리 수가 **N 에 비례해 늘지 않는다**.
5. 프론트 소스 변경 0건.

## 6. 관련 설계 ITEM

- **`API-044`** (GET /v1/videos/{rawSn}/labels/auto, v5) — **선반영 대상.**
  현재 본문이 결함을 사양으로 박아 뒀다: `color` = *"표시 색상 (기본값 #3B82F6)"*,
  `labelName` = *"라벨 표시명 (코드 테이블 미존재 시 labelCode fallback)"*.
  「코드 테이블 미존재」 전제가 무효다.
- `SCREEN-009` section[5] 는 분포 바의 **존재**만 규정하고 표시명·색 출처를 말하지 않는다 —
  응답 필드 계약이라 `API-044` 가 소관이다. 화면 사양은 건드리지 않는다.
