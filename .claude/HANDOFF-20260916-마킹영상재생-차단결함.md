## ⚠⚠ 사용자 결정 대기 — 압축 뒤 가장 먼저 AskUserQuestion 으로 물을 것

**포털 채널 재생 인증을 어떻게 할지 미정.** `ADR-071` 이 "포털 업로드 영상 재생도 같은 쿠키 축"이라 적었는데:
- 내부 쿠키 `klid_stream_nonce` 의 **Path 가 내부 영상 스트림 경로로 한정** → 포털 스트림 경로(`/v1/portal/uploads/...`)에 **안 실린다**(코드 실측).
- 현재 포털 스트림 구현은 **서명 질의만으로 통과**, 쿠키 판정 없음(코드 실측).
- `API-239` v1 본문은 *"이 채널의 실행 환경 확인이 안 돼 클라이언트를 한 번 더 묶는 값은 정하지 않는다 · 유효 시간을 짧게 두고 재생 도중 만료가 정상 동선"* 으로 **의도적으로 미정**이었다. 포털은 호스트가 저작도구 화면을 자기 화면에서 실행하는 환경이라, 크로스 사이트면 SameSite=Lax 쿠키가 `<video>` 요청에 안 실릴 수 있다.
- ⚠ **그런데 `API-238` v2 · `API-239` v2 가 이미 쿠키 단독으로 쓰였다**(보류 지시가 늦게 도달). `API-239` 는 위 "의도적 미정" 서술을 **교체**했다. 기준선은 `scratchpad/api239/API-239.json`(v1 원본)에 있다.
- ⇒ **ADR-071 의 포털 포함은 초안의 과잉일 가능성이 크다.** 현장 이슈는 **관제 채널**이다.

**✅ 결정(2026-09-16 사용자): A — 포털 제외.** `ADR-071` 범위를 내부 채널로 한정 · `API-238` 인증 서술 v1 복원 · `API-239` 인증 서술 v1 복원(접두 규약 추가분 유지) · `SEQ-019`·`SCREEN-045` 는 이번 범위 밖 · D013 구현은 건 1(경로)만.

선택지(정석안 먼저):
- **A (권장)**: 포털은 이번 범위에서 제외 — `ADR-071` 범위를 내부 채널로 한정 정정, `API-238`·`API-239` 의 포털 인증 서술을 v1 로 되돌림(접두 규약 추가분은 유지 가능 — 건 1 서버 수정이 포털에도 걸리므로). 포털 쿠키는 임베딩 환경 확인 후 별건.
