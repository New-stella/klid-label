# 외부 시계열 분석 사업자 실응답 원문 (2026-09-14)

사업자 실서버가 돌려준 **콜백 본문 원문**이다. 사업자 응답 형식이 바뀌면 이 원문을 쓰는 시험이
먼저 깨지도록 두는 것이 목적이다.

## ⚠ 이 폴더의 JSON 을 고치지 말 것

손으로 다듬거나 다시 타이핑하면 원문이 아니게 되어 시험이 지키려는 것이 사라진다.
형식이 바뀌어 새 원문이 필요하면 **새 날짜 폴더를 따로 만든다.**
