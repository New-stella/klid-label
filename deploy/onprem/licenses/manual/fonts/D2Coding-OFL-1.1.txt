[이 파일의 출처 — 반드시 함께 읽을 것]

  npm 패키지 `d2coding@1.3.2` 에는 라이선스 전문 파일이 <들어 있지 않다>(실측:
  패키지 전체에 LICENSE/COPYING/OFL 이름의 파일 0건, package.json 의 "license"
  필드에 "OFL" 문자열만 있음). 그래서 이 파일은 두 출처를 <합쳐서> 사람이 만든 것이다.

  1) 저작권·상표·라이선스 선언  ← 폰트 바이너리 자신의 name 테이블에서 읽었다.
     대상: node_modules/d2coding/src/d2coding.ttf
       nameID  0 (Copyright)  : Copyright (c) 2015-2016 NHN Corporation. All rights
                                reserved. Font designed by FONTRIX Inc.
       nameID  7 (Trademark)  : D2Coding is a registered trademark of NHN Corporation.
       nameID 13 (License)    : This Font Software is licensed under the SIL Open Font
                                License, Version 1.1.
       nameID 14 (License URL): http://dev.naver.com/wiki/nanumfont/index.php/OpenFontLicense
     (nameID 14 의 주소는 현재 서비스되지 않는다 — 그래서 2) 가 필요하다.)

  2) SIL OFL 1.1 전문  ← SIL 정본에서 그대로 받았다.
     내려받은 곳 : https://openfontlicense.org/documents/OFL.txt
     받은 날짜   : 2026-08-30
     받은 파일 SHA256 : 1d361a8f8e8ce6e68457dcd93fb56e162e6baa3bbb7e7573a290d44399f6b57e
     교차검증   : 같은 매체에 실리는 Pretendard 의 LICENSE.txt 안에 들어 있는 OFL 1.1
                  본문과 <줄끝 공백 정규화 후 완전 일치>함을 확인했다. 즉 아래 본문은
                  지어낸 것이 아니라 두 독립 출처가 같다고 말하는 텍스트다.

  아래 「저작권 고지」는 1) 에서, 「SIL OPEN FONT LICENSE Version 1.1」 이하 본문은
  2) 에서 왔다. 본문은 한 글자도 고치지 않았다.

  ⚠ 이 파일은 자동 수집물이 아니라 <사람이 채운 것>이다. d2coding 패키지가 장래에
    라이선스 파일을 포함하게 되면 그쪽을 정본으로 바꾸고 이 파일을 폐기하라.
