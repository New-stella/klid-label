[이 파일의 출처 — 반드시 함께 읽을 것]

  npm 패키지 `victory-vendor@37.3.6` 에는 라이선스 전문 파일이 <들어 있지 않다>
  (실측: 패키지 루트에 LICENSE/COPYING 이름의 파일 0건. package.json 의
  "license" 필드에 "MIT AND ISC" 문자열만 있다).
  그래서 이 파일은 두 축을 <합쳐서> 사람이 만든 것이다 — 요약이 아니라 전문 그대로다.

  1) MIT  ← victory-vendor 를 배포하는 Victory 저장소의 라이선스 전문.
     내려받은 곳 : https://raw.githubusercontent.com/FormidableLabs/victory/main/LICENSE.txt
     받은 날짜   : 2026-08-30
     경위        : 패키지 루트 `LICENSE`/`LICENSE.md` 는 404 다. GitHub license API
                   (repos/FormidableLabs/victory/license)가 가리키는 실제 경로가
                   `LICENSE.txt` 였다.

  2) ISC  ← 이 패키지가 <소스째 벤더링해 담고 있는> d3 계열 패키지들의 라이선스 전문.
     "AND ISC" 가 가리키는 대상이 이것이다. 각 전문은 <반입 대상 패키지 자신>
     (lib-vendor/<이름>/LICENSE)에서 그대로 꺼냈다 — 외부에서 받지 않았다.
     ⚠ 사본이 여럿이지만 저작권 연도·표기가 조금씩 달라 <중복 제거하지 않고 전부> 싣는다.
       한 벌만 남기면 다른 패키지의 저작권 고지를 누락하게 된다.
