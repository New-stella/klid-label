# GPU 델타 — 제3자 라이선스 고지

이 디렉터리는 **GPU 델타로 새로 반입되는 패키지 22개**의 라이선스 고지다.
CPU 판 매체(`licenses/`)에 이미 담긴 것은 여기 중복하지 않는다.

## ★ 이 델타가 라이선스 표면을 바꾼다

CPU 판 매체는 **전부 오픈소스**였다. 이 델타는 거기에 **NVIDIA 독점 EULA 계통**을 들인다 —
`nvidia-*` CUDA 런타임 라이브러리 16개와 `cuda-bindings` 가 그것이다. 심의에서 이 축이
새로 생긴다는 점을 반드시 함께 보고할 것.

| 계통 | 패키지 | 성격 |
|---|---|---|
| NVIDIA 독점 | `nvidia-*` 16개 · `cuda-bindings` | 재배포는 허용되나 **EULA 동의가 전제**다. 전문 동봉 |
| BSD-3-Clause | `torch` · `torchvision` | 오픈소스 |
| Apache-2.0 | `cuda-pathfinder` · `nvidia-nvtx` | 오픈소스 |
| MIT | `onnxruntime-gpu` | 오픈소스 |
| (미상) | `triton` | 전문 2건 동봉 — METADATA 에 이름 필드가 없다 |

## 전문이 휠에 없는 3건 (동봉 못 한 것 — 숨기지 않는다)

| 패키지 | 사유 | 어디서 확인하나 |
|---|---|---|
| `cuda-toolkit` | 4KB **메타 패키지**로 코드가 없다(다른 `nvidia-*` 를 끌어오기만 한다). 실물이 없으니 고지 대상도 아니다 | — |
| `nvidia-cusparselt-cu12` | 휠에 전문이 들어 있지 않다. `nvidia-*` 계통과 **같은 EULA** 다 | 같은 계통 다른 패키지의 동봉 전문 |
| `onnxruntime-gpu` | METADATA 에 `MIT License` 로 선언돼 있으나 전문 파일이 휠에 없다 | MIT 표준 전문 |

⚠ **"전문이 없다"를 "의무가 없다"로 읽지 말 것.** 이름이 확인된 이상 의무는 그대로다.
반입 심의에 이 표를 그대로 제출하고, 필요하면 공급자에게 전문을 요청한다.
