# LogiCraft 화면정의서 소급 재점검 (배치 A~E 대상 15건)

배치 A~E 지시에 "기능은 합집합" 규칙이 누락되어, 화면 구조·명칭을 납품 FE 기준으로 다시 쓰는 과정에서 테스트베드 전용 기능이 서술에서 희석·누락됐을 가능성을 소급 점검했다. 배열 원소 삭제(컴포넌트 총 개수 감소)는 이번에도 발생하지 않았다 — 전 화면 순증 또는 순변동 0.

## 3. 테스트베드 전용 기능 발견 목록 (신규 반영)

### SCREEN-005 라벨링 캔버스 (최다 발견)
- 검수 제출 취소 버튼(검수 대기 상태 한정) / 재검수 제출 버튼 문구 분기 + 제출 차단 안내
- 재비식별 대기 잠금 시 상시 배너
- 밝기·대비·라벨/작업 투명도 실시간 조절 슬라이더 + 초기화(기존 서술은 "보기 전용"으로 축소돼 있었음)
- 진행 중 작업(저장/불러오기/AI 탐지·분할·추적) 캔버스 오버레이 + 즉시 취소
- 프레임 이미지 로드 실패 원인 힌트 안내
- 저장 충돌(다른 사용자 선저장) 안내 다이얼로그, 프레임 이동 시 미저장 변경 확인 다이얼로그
- 버전 이력 패널의 "변경 이력" 탭 전체(저장 이벤트 단위 추가/수정/삭제 배지 + 항목별 되돌리기) — 기존엔 "버전" 탭만 있고 이 탭 통째로 누락
- 하단 프레임 썸네일 상태색 구분(현재/미해결 문의/저장됨)
- 키포인트 배치 중 우측 패널 상시 진행 가이드(인체 다이어그램 + 진행률)
- 확대/축소·표시숨김 토글·AI 추적 보조 단축키 3건
- AI 탐지 다이얼로그 "트랙으로 실행" 흐름
- "캔버스 상단 옵션바" 섹션 신설(저장·실행취소·다시실행·프레임이동·화면맞춤·확대축소·표시숨김을 실제 컴포넌트로 반영 — 기존엔 서술만 있고 컴포넌트가 없었음)

### SCREEN-006 마킹
- 버퍼링/탐색 중 로딩 스피너 표시 분기
- 비식별 누락 신고 성공 시 작업목록으로 복귀하는 동선

### SCREEN-008 영상 처리 현황
- 마킹 설정 행 액션의 실제 노출 조건(배치단계 MARKING_READY + 비식별 미차단, 기존 서술은 "미배정"만으로 단순화돼 있었음)
- 처리 단계 배지가 통상 단계보다 비식별 상태(진행중/실패)를 우선 표시하는 미문서 분기

### SCREEN-009 영상 상세
- 재비식별 확인 다이얼로그가 요청 진행 중 ESC/배경클릭 닫기를 차단하는 중복 제출 방지 동작

### SCREEN-010 라벨 이력

## 4. 이번 배치 수정으로 빠졌다가 되살린 서술

- **SCREEN-026 프리셋 관리**: `before_raw`에 명시돼 있던 복제 기능·헤더 부제 동적 표시·빈 상태 생성 버튼 3건이 재작성 과정에서 서술·컴포넌트 양쪽에서 빠졌다가 이번에 복원됨.
- 그 외 화면(005/006/008/009/010/012/018/019/022/023/024/025/032/035)은 담당 에이전트가 before_raw와 대조한 결과, 배치 A~E 재작성이 기존 기능을 실제로 삭제한 사례는 발견하지 못했다고 보고함. 이번에 추가된 항목들은 대부분 "재작성 이전부터 이미 문서화가 부족했던 테스트베드 전용 기능"이지, "재작성이 새로 떨어뜨린 것"은 아니다.

## 5. 작업 중 발견된 관찰 사항 (투명성 기록)

- **SCREEN-018/019/022/023**: 담당 에이전트 작업 도중 각 ITEM이 **다른 세션/프로세스에 의해 동시에 재작성**된 상태를 발견함(버전 번호가 예상보다 앞서 있었음). 각 에이전트는 최신 상태를 재조회한 뒤 그 위에서 작업을 재구성했고, SCREEN-023에서는 그 동시 수정이 실제 라이브 기능(진행률/재시도 배너, 생성률 통계)을 잘못 `[폐기]` 표기하고 route를 오기재한 것을 발견해 정정했다.
- **SCREEN-024/025/032**: 담당 에이전트가 `get_item` 선조회 없이 before_raw 기준으로 1차 패치를 작성했다가, 이미 배치 A~E가 그 이상으로 정확하게 재작성해둔 상태와 충돌(중복 컬럼 생성, 정확했던 서술을 낡은 서술로 되돌림)한 것을 스스로 발견해 `remove`/`set` 정정 패치로 원복함. 최종 상태는 재조회로 검증됨.
- **SCREEN-018 / SCREEN-006~010**: 작업 중 유니코드 이스케이프 사용으로 인한 한글 오타가 발생(예: "컬럼→컴럼", "썸네일→썰네일", "바뀐→바뀜")했고, 담당 에이전트가 재조회 과정에서 스스로 발견해 재확인 방식(생성+왕복검증)으로 전환 후 전량 정정함. SCREEN-008/009에는 **이번 작업 이전부터 존재하던 동일 패턴의 손상**도 함께 발견되어 같이 정정했다. 모든 화면 최종 재조회 결과 한글 손상 없음을 확인.

## 6. 판단 보류 항목

- **SCREEN-005**: 좌측 도구바의 "좌/우 90° 회전", "그리드 표시 토글", "영역 확대"가 실제 도구 하위 파일에서 확인되지 않아(시간 제약) 미변경. YOLO 트랙(API-123) 실제 호출 지점 미확인. 이슈/이벤트 어노테이션/개인정보·촬영환경 메타 패널 내부 컴포넌트는 미상세 대조. 납품 FE 대조는 시간 제약으로 미수행.
- **SCREEN-012**: "이미 배정된 행은 체크박스 비활성화" 서술이 실제 코드와 다른 것으로 보이나(사양에 있는데 코드에 없는 방향), 이번 작업 범위(합집합 보강) 밖이라 미수정. 작업자 select "(비활성)"/"(현재)" 접미사는 세부사항으로 판단해 별도 컴포넌트화하지 않음.
- **SCREEN-018/019**: 메타 탭 "시계열 서술 편집 가능" 서술이 테스트베드(읽기 전용)와 다른데, 납품 FE 실제 동작까지 검증하지 못해 기존 서술 유지. "라벨 수" 컬럼 정렬 방향 차이(좌/우)는 구조 축으로 보고 미변경. 이슈 탭에 잘못 연결된 것으로 보이는 API-011은 삭제 없이 정답 API들만 병기.
- **SCREEN-022**: `/augments/{id}/cancel`·`/progress`·`/restore` 엔드포인트에 대응하는 API ITEM이 프로젝트에 없어 신규 ID를 임의로 만들지 않고 컴포넌트 note에 경로 텍스트로만 기재.
- **SCREEN-024**: "미배정"(null-role) 상태와 계정 활성/비활성 읽기전용 여부는 이미 사양에 반영돼 있음을 확인만 함.
- **SCREEN-025**: 자체 실수로 덮어쓴 "실시간 모니터링" 섹션 원문 일부를 버전 히스토리 도구 부재로 완전히 복구했다고 확신할 수 없음(대체 서술은 다른 서술과 모순되지 않음) — 인지 사항으로 기록.
- **SCREEN-006/008/009/010**: `RollbackConfirmModal`의 확인 문구("현재 변경사항은 새 커밋으로 보존됩니다")가 확정된 롤백 시맨틱(재활성·비적층)과 모순되는 **테스트베드 UI 문구 자체의 오류**로 판단해 사양에 반영하지 않음(코드 수정은 범위 밖). SCREEN-009 재비식별 404 처리·"환경 설정 조건부 제공" 서술은 납품 FE 검증 불가로 보류.
