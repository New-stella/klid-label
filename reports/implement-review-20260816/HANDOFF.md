## 6. 이번 세션이 실측으로 배운 것 (같은 실수 반복 방지)

### ★키트 SYNC 는 «한 번 하고 끝나는 일» 이 아니라 **꼬리 작업**이다
화면 축 ITEM 을 고치는 **모든 라운드**가 키트를 낡게 만든다. 이 세션에서 SYNC 를 완료·커밋한 뒤
두 번 더 벌어졌고(이벤트 표기 정렬 2건 · `SCREEN-005` 편집 1건), **사용자가 물어보지 않았으면
낡은 채로 남았을 것**이다. ⇒ 라운드 끝에 붙인다.

### ★★인계 목록을 그대로 믿지 마라 — 실측하면 상당수가 이미 해소돼 있다
잔여 7건을 라이브로 재확인하니 **다섯이 이미 해소됐거나 애초에 결함이 아니었다.**
믿고 고쳤으면 **명시된 설계 결정을 뒤집을 뻔했다**(`ERD-015` 가 *"정의는 `ERD-023` 이 소유한다,
갱신 대상 아님"* 이라고 **스스로 적어놨다**). 착수 전 라이브 재확인은 선택이 아니다.

### ★★검사기가 좁아지는 다섯 형태 — 한 세션에 전부 밟았다
memory `hangul-breaks-word-boundary-regex` 에 표로 적립했다. 요지:
①타입 범위를 좁게 열거(`erd` 통째 누락) ②정규식 접미사 누락(`Ledger`) ③**부정문을 못 가름**
(«읽지 않는다» 를 결함으로 8건 올릴 뻔) ④지목 목록 의존(전수 스윕에서만 IP 2건 추가 발견)
⑤**필드당 첫 매치만 출력**(뒤가 가려져 3 ITEM 을 «정당» 으로 오분류).
- 한글은 `\b` 가 무력하다 → `코드\s*기준` 이 «대표**코드 기준**» 에 걸린다. `(?<![가-힣])` 필요.
- `finditer` 로 **전 출현**을 돌리고, 판정 전에 **문맥을 출력**하라. 히트 수를 결함 수로 보고하지 마라.
- 수치를 낼 때마다 **그 검사가 무엇을 못 보는지** 함께 적어라.

### ★렌더 판정 규칙 — 구 규칙이 인계문에 남아 있어 다음 사람을 오도했다
*"`replace` opcode 0 으로 판정"* 은 **폐기된 규칙**이다. 서버가 `&#x27;`→`'` 엔티티 되돌림 등으로
치환을 대량 만들어(이번 335회) **정상 게시가 전건 FAIL** 로 잡힌다.
정본은 memory `render-mirror-regeneration-procedure` + `logicraft-render-sanitizer-strips-attributes`.

### ★키트 안에 SYNC 가 손대지 않는 낡은 사본이 있었다
`_shared/{uc,ac}-orphan/` 50 파일이 전건 `screens/` 사본과 중복인데 내용이 달랐다. **버전표 대조로는
안 잡힌다**(뒤처짐 0 인데 낡은 사본 존재). 삭제 완료 + 플랫폼 보고 완료
(system issue `5fc4fe78-c487-4490-b588-f55ff92b270f`). 재동기화에서 **다시 생기지 않음**을 확인했다.

### MCP 도구 함정 (재확인)
- 쓰기는 `data_mode:"patch"` + `op:"set"`. **`replace` 전체 교체는 절단 사고의 원인**이다.
- 배열 **추가**는 `op:"add"` + 인덱스 **없는** path. 교체는 `op:"set"` + 인덱스.
- `update_item` 은 `stale` 을 **자동 해제**한다 → 쓰기 **전에** `stale`/`stale_reason` 을 읽어 기록할 것.
- `get_item`·`list_items` 는 `domain_id` 를 echo 하지 않는다. `kit-export` 는 한다.
- 전수 판정은 `kit-export?include_retired=true` — 기본 호출은 **활성만** 준다.

### 한글 손상 — 이 채널에서는 «안 쓰는 것» 이 불가능하다
MCP 인자가 JSON 직렬화되며 한글을 `\uXXXX` 로 인코딩한다. **기대본 바이트 대조가 유일한 방어선**이다.
절차: baseline 을 파일로 확보 → 파이썬 `str.replace` 로 결정적 변환(앵커마다 `assert count==1`)
→ patch 쓰기 → 서버 재조회 후 **문자 단위 완전 일치** 대조. 이 세션 약 60 ITEM 전건 통과.

## 7. 참고 — 이 세션의 도구

스크래치(`/tmp/render-round/`, 재부팅 시 소멸)에 있었다. 로직은 위 memory 들에 서술돼 있으니
필요하면 다시 만들면 된다.

| 파일 | 용도 |
|---|---|
| `mcp.py` | MCP over HTTP 헬퍼(`call`) + `kit-export` 래퍼. **전사 없이** 서버 원문을 파일로 받는 경로 |
| `kitdrift.py` | 키트 버전표 ↔ 서버 대조. 미조회를 `assert` 로 실패시킨다 |
| `cmp.py` | 렌더 게시본 ↔ 로컬 생성본 바이트 대조(정규화 분류 + 미설명 잔차 0 판정) |
| `textdiff.py` | 렌더 가시 텍스트만 뽑아 diff |

접속값은 `~/.claude.json` 의 `mcpServers.logicraft` 에서 읽는다(문서에 적지 않는다).
