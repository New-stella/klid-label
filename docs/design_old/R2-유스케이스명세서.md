## 1. 서브시스템 목록

| 서브시스템 ID | 서브시스템명 | 서브시스템 설명 |
|---|---|---|
| KLID-AT-SS-001 | 사용자/권한 | 관제서버·포털서버가 발급한 JWT를 검증하고 채널·역할 기반 접근 제어를 수행하는 서브시스템 (저작도구는 자체 로그인 없음) |
| KLID-AT-SS-002 | 마킹 | 영상에서 이벤트 발생 시점을 자동(프레임 간격) 또는 수동(키보드 단축키)으로 마킹하는 서브시스템. 마킹 결과는 VLM 시계열 분석 위탁의 입력으로 사용 |
| KLID-AT-SS-003 | 배치 파이프라인 | 1분 간격 Quartz 스케줄러로 처리 대기 영상 1건을 마킹→VLM→비식별→프레임추출→YOLO(원본)→SAM2 순서로 자동 처리하는 서브시스템 |
| KLID-AT-SS-004 | 비식별화 | 외부 비식별 솔루션에 비동기 처리를 위탁하고 원본·비식별본을 각각 저장하며, 비식별 누락 신고를 수집하여 재처리를 트리거하는 서브시스템 |
| KLID-AT-SS-005 | 시계열 메타 | 외부 VLM 서비스에 시계열 분석을 위탁하고 결과 메타를 검수담당자가 검토·승인하는 서브시스템 |
| KLID-AT-SS-006 | 라벨링 | 배정된 프레임에 BBox·폴리곤·마스크 등 라벨을 작성·수정·삭제하고 이벤트 타입별 라벨 프리셋을 관리하는 서브시스템 |
| KLID-AT-SS-007 | 검수 | 검수담당자가 작업을 배정·재배정하고 라벨 품질을 검수·승인하며, 검수 완료/수정 이벤트를 관제서버에 통지하는 서브시스템 |
| KLID-AT-SS-008 | 버전관리 | 라벨 저장 시 Gitea에 자동 커밋하여 버전 이력을 생성하고 커밋 단위 이력 조회·롤백을 제공하는 서브시스템 |
| KLID-AT-SS-009 | 데이터 증강 | 검수 완료 영상에 외부 생성형 AI 증강을 비동기 요청하고 결과를 새 영상(RAW_SN)으로 적재하는 서브시스템 |
| KLID-AT-SS-010 | 포털 | 포털서버 발급 JWT 사용자에게 본인 데이터 기반 간편 라벨링을 제공하는 서브시스템 (검수·버전관리 미제공) |

### KLID-AT-UC-016. 영상 마킹

<table>
<tr><td>유스케이스 ID</td><td>KLID-AT-UC-016</td><td>유스케이스명</td><td>영상 마킹</td></tr>
<tr><td colspan="4">
<b>1. 주요 액터</b><br>
&emsp;- 라벨링작업자, 검수담당자<br><br>
<b>2. 이해관계자와 관심사항</b><br>
&emsp;- 라벨링작업자는 영상 재생 중 이벤트 시점을 빠르고 정확하게 마킹하길 원한다.<br>
&emsp;- 검수담당자는 영상별 마킹 모드(자동/수동)를 설정하고, 마킹 결과를 관리하길 원한다.<br>
&emsp;- 운영팀은 마킹 결과가 VLM 시계열 분석 위탁 시 정확하게 전달되길 원한다.<br><br>
<b>3. 전제조건</b><br>
&emsp;- 영상이 시스템에 적재되어 있다.<br>
&emsp;- 영상별 마킹 모드(자동/수동)가 설정되어 있다.<br><br>
<b>4. 종료조건</b><br>
&emsp;- 마킹 결과(이벤트명 + 영상경로 + marks 배열)가 저장된다.<br>
&emsp;- 마킹 결과가 VLM 시계열 분석 위탁(UC-004)에 사용 가능한 상태가 된다.<br><br>
<b>5. 기본 시나리오</b><br>
&emsp;<b>[ 자동 마킹 모드 ]</b><br>
&emsp;&emsp;1. 배치시스템이 영상의 마킹 모드가 '자동'임을 확인한다.<br>
&emsp;&emsp;2. 설정된 프레임 간격 기준으로 자동으로 마킹 포인트를 생성한다.<br>
&emsp;&emsp;3. 마킹 결과(이벤트명 + 영상경로 + marks 배열)를 저장한다.<br>
&emsp;&emsp;4. 마킹 완료 후 VLM 시계열 분석 위탁을 트리거한다.<br>
&emsp;&emsp;5. 본 유스케이스는 종료한다.<br>
&emsp;<b>[ 수동 마킹 모드 ]</b><br>
&emsp;&emsp;6. 라벨링작업자 또는 검수담당자가 마킹 화면에 진입한다.<br>
&emsp;&emsp;7. 영상을 재생하면서 이벤트 발생 시점에 키보드 단축키로 마킹한다.<br>
&emsp;&emsp;8. 마킹된 시점의 프레임 번호·타임스탬프·이벤트명이 목록에 추가된다.<br>
&emsp;&emsp;9. 마킹 완료 후 저장하면 마킹 결과가 DB에 기록된다.<br>
&emsp;&emsp;10. VLM 시계열 분석 위탁을 트리거한다.<br>
&emsp;&emsp;11. 본 유스케이스는 종료한다.<br><br>
<b>6. 대안 시나리오</b><br>
&emsp;<b>가. 마킹 포인트 수정</b><br>
&emsp;&emsp;1. 작업자가 기존 마킹 포인트를 선택하여 시점·이벤트명을 수정하거나 삭제한다.<br><br>
&emsp;<b>나. 마킹 모드 변경</b><br>
&emsp;&emsp;1. 검수담당자가 영상의 마킹 모드를 자동↔수동으로 변경한다.<br>
&emsp;&emsp;2. 기존 마킹 결과 유지 여부를 확인한 후 모드를 전환한다.<br><br>
<b>7. 구현 시 고려 사항</b><br>
&emsp;- 자동 마킹은 파이프라인 내에서 배치시스템이 실행하며, 수동 마킹은 작업자가 UI에서 직접 수행한다.<br>
&emsp;- 마킹 결과 포맷: 이벤트명 + 영상경로 + marks 배열(각 mark: 프레임 번호, 타임스탬프).<br>
&emsp;- 수동 마킹 시 키보드 단축키(Space 등)를 지원하여 빠른 마킹이 가능하다.<br>
&emsp;- 마킹 완료 시 VLM 콜백 비동기 위탁이 자동 트리거된다.<br><br>
<b>8. 발생 빈도</b><br>
&emsp;- 파이프라인 내 영상 1건 처리 시마다 1회(자동) 또는 작업자 수동 마킹 시 수시 발생
