# 감리 지적 대응표 — DB 설계서(저작도구/AT)

- **대상 산출물**: KLID_AT_데이터베이스 설계서(D9) — 학습데이터 저작도구
- **지적 출처**: 설계단계 감리수행결과보고서 §3 데이터베이스 / (라) 데이터 설계
- **작성일**: 2026-07-16 / 작성: 박찬기
- **범위 주의**: 본 지적은 4~5종 DB 설계서(CV·PF=관제, AT=저작도구, GA=생성형, FD=침수탐지) 공통 지적이며, **본 대응표는 저작도구(AT) 담당분에 한정**한다. CV·PF·GA·FD는 각 담당 팀 소관.

## 1. 지적 요지

- **(제목) 이벤트 관련 용어의 명칭·데이터 타입/길이가 설계서마다 다름**
  - CV `evnt_cd` VARCHAR(10) / AT `event_type_cd` VARCHAR(32) / PF `event_type_cd` VARCHAR(20) / GA `event_type` VARCHAR(30)
- **(라) DBMS 종류 누락·테이블/컬럼 한글명 누락 등 DB 설계서 오류**
  1. 연차 사업(2단계 진행 중) — 배경
  2. 1차 구축 DB를 활용하며 테이블/컬럼이 추가·변경되는데 **5종 DB 설계서 모두 신규/변경 여부가 관리되지 않음**
  3. **생성형(GA)·침수탐지(FD)**: 적용 DBMS 종류·버전 누락
  4. **저작도구(AT)·생성형(GA)**: 논리 모델의 물리 모델 반영 관련
  5. **침수탐지(FD)·생성형(GA)**: 테이블·컬럼 한글명 누락

## 2. 저작도구(AT) 항목별 대응

| # | 지적 | AT 해당 | 대응 결과 | 근거 |
|:--:|------|:------:|-----------|------|
| 라-2 | 신규/변경 여부 미관리 | ✅ 해당 | **반영 완료** — D9 §1에 "LS_* 전 테이블·전 컬럼 = 2차 신규 구축(구분=신규)" 명시. 관제 공유 `MNG_*`/`QRTZ_*`는 물리 설계 비대상(READ)으로 구분 대상 제외 | 저작도구 물리 테이블은 전량 신규 `CREATE TABLE`(Flyway `V36__create_new_ls_tables` 등). 1차 물리 테이블을 이관·변경한 대상 없음 |
| 라-3 | DBMS 종류·버전 누락 | △ 부분 | DBMS **종류는 이미 명시**(PostgreSQL, UTF-8). 필요 시 세부 버전 숫자만 보강 가능 | D9 §1 데이터베이스 목록·§2 정의 |
| 라-4 | 논리↔물리 모델 반영 | ❌ 비해당 | **AT 조치 불필요** — AT는 논리명(한글)+물리명(영문) 병기로 반영 완료. 해당 지적은 GA 대상으로 확인 | D9 §3 테이블 명세 전 컬럼 논리명 기재 |
| 라-5 | 테이블·컬럼 한글명 누락 | ❌ 비해당 | **AT 조치 불필요** — 전 테이블·전 컬럼 한글 논리명 완비 | 예: `EVNT_TYPE_CD`=이벤트유형코드, `RAW_SN`=원시영상일련번호 |
| 제목 | event 용어·타입/길이 불일치 | △ 협의 | AT는 프로그램·행정 **표준용어 조합 `EVNT_TYPE_CD`(이벤트유형코드) VARCHAR(32)** 사용 — 표준 준거. **4종 명칭·길이 통일은 타 시스템(CV/PF/GA)과의 협의 사항**으로, 저작도구 단독 변경은 표준 위배 위험 | 표준용어 정합(program/gov glossary) |

## 4. 미결·협의 필요

- **제목 지적(event 용어 4종 통일)**: 명칭/길이를 어느 기준으로 통일할지 관제(CV/PF)·생성형(GA) 팀 합동 협의 필요. 저작도구는 표준용어 근거를 제시하되 결정에 따름.
- **라-3 DBMS 버전 숫자**: 감리가 세부 버전(예: PostgreSQL 15.x) 표기를 요구할 경우 §1에 버전 명기 추가.
