# D2 사용자 인터페이스 설계서

> **ID 표기 규칙(공통)**: 본 산출물의 모든 ID(KLID-AT-UC/CO/DC/DCD/SD/SC/AC/EN/ERD/TB/II/IC/IF/UCD/ACT 등)는 **전체 형식 `KLID-AT-XX-NNN`** 으로 표기한다. 끝부분만(예: `UC-001`) 약식 표기 금지. 범위는 시작 ID만 전체형으로(예: `KLID-AT-UC-001~013`). ※ 요구사항(RQ-SFR-NN-NN)·시스템시험(KLID-ST-NNN) 등 타 체계 ID는 각 체계 원형 유지.

## 작성 목적
> 시스템이 제공하는 사용자 인터페이스의 전체 구조와 메뉴 형식, 화면 목록과 화면의 상세 설계 내역을 기술한다.

## 작성 방법
> 전체 시스템에 대한 사용자 인터페이스의 구조를 사용자에게 제공하는 메뉴 형식으로 기술하고, 화면 및 출력으로 구분하여 목록을 작성하며, 화면의 상세 설계의 내용을 화면별로 기술한다.

### 1. 사용자 인터페이스 구조도

> **▣ 전체 시스템에 대하여 1개 작성한다(반복 아님).** 최상위레벨에서 Top-down으로 작성하며, 저작도구 내부 채널(관제서버 동일 도메인 SSO 진입) 기준 LNB 메뉴 트리로 표현한다. 본 산출물은 R1 기능 요구사항을 실현하는 유스케이스에 매핑된 화면만 다루므로, 구조도에는 해당 화면이 속한 메뉴 경로만 기재한다.

> **채널 분리**: 저작도구 내부 채널(INTERNAL)은 LNB/GNB를 갖춘 `AppLayout`으로, 포털 채널(PORTAL)은 LNB 없는 모바일 친화 `PortalLayout`으로 분기한다(역할·채널 가드). 포털 홈·포털 라벨링은 포털 회원(PORTAL_USER) 전용으로, 내부 메뉴와 상호 진입하지 않는다.

- 화면 진입 (KLID-AT-SD-021)
. 본인에게 배정된 프레임인지 확인한 뒤 현재 프레임 이미지와 라벨 목록을 조회해 캔버스에 표시한다. 본인 배정이 아닌 프레임 접근은 거부한다.
- 라벨 편집·저장 (KLID-AT-SD-021)
. 도구바에서 선택·바운딩박스·폴리곤·세그멘테이션 도구로 객체를 생성·수정·삭제하고, 우측 패널에서 라벨·좌표·속성을 편집한다. 저장 시 현재 작업본을 영속(임시저장)하며, 비식별본은 원본과 동일 좌표를 공유한다. 되돌리기·다시실행은 화면 세션에서 처리한다.
- 객체 자동 추적 (KLID-AT-SD-004)
. 시작 프레임에서 박스로 지정한 객체를 AI 추론에 의뢰해 후속 프레임으로 위치·경계를 전파하고, 비어 있는 프레임은 보간으로 채운다. 결과 좌표는 이미지 실측 범위로 검증한다. 호출 실패 시 추적 실패를 안내하고 기존 라벨을 유지한다.
- 객체 외곽 경계 밀착 (KLID-AT-SD-005)
. 클릭 또는 박스로 객체를 한 번 지정하면 AI 추론이 외곽 경계 폴리곤과 신뢰도를 산출하고, 폴리곤을 단순화해 캔버스에 적용한다. 외곽 인식 실패 시 수동 폴리곤으로 전환한다.
- 라벨 속성값 입력 (KLID-AT-SD-021)
. 선택한 객체에 대해 해당 라벨 마스터에 정의된 속성 스펙(입력 타입·선택 항목·기본값·수정 가능 여부)을 우측 속성 패널에 표시하고, 객체별 속성값을 입력·일괄 저장한다. 정의되지 않은 속성 입력은 거부하고, 선택형 속성은 정의된 항목 중에서만 고를 수 있다.
- 시계열 메타 검토·저장 (KLID-AT-SD-022)
. 우측 패널에서 외부 시계열 분석 결과(메타 텍스트)를 조회해 검토하고, 수정 후 저장한다.
- 이슈 문의·열람 (KLID-AT-SD-016)
. 우측 이슈 스레드 패널에서 영상 단위 문의(INQUIRY)를 작성하고, 검수자의 답변 코멘트를 열람한다. 문의가 해소(RESOLVED)되면 해당 스레드의 코멘트 입력이 잠긴다. 작성자 역할(작업자)을 서버에서 검증한다.
- 버전 이력 비교·롤백 (KLID-AT-SD-008)
. 히스토리 패널에서 라벨 버전 목록을 조회하고, 단건 선택 시 직전 버전과의 변경 내용을, 두 건 선택 시 두 버전 간 변경 내용을 표시한다. 최신이 아닌 버전을 선택하면 롤백할 수 있으며, 롤백 시 새 이력 1건이 생성된다.
- 비식별 누락 신고 (KLID-AT-SD-016)
. 개인정보 노출을 발견하면 신고 사유를 입력해 신고한다. 신고 시 해당 영상이 잠기고 라벨이 안전 삭제된다. 이미 잠긴 영상의 중복 신고와 본인 배정이 아닌 영상의 신고는 거부한다.

. 자동 모드에서는 지정한 프레임 간격으로 마킹을 생성하고, 수동 모드에서는 단축키(마킹/삭제/완료)로 이벤트 시점을 마킹한다. 마킹은 타임라인 막대와 현재 마킹 칩으로 표시하며 선택·삭제할 수 있다. 이벤트명은 관제 클립 메타에서 자동 소싱한다.
- 마킹 완료 (KLID-AT-SD-019)
. 마킹이 1건 이상일 때 마킹 완료를 실행하면 마킹 결과가 저장되고, 이를 기점으로 잔여 배치(시계열 분석 → 프레임 추출 → 오토라벨링)가 시작된다. 마킹 중 비식별 누락을 발견하면 영상 단위로 비식별 신고를 할 수 있다.

- **처리 내용**: 화면이 처리하는 업무 내용을 기술하며, 관련 시퀀스도 ID를 함께 기재한다.
- **기술적 고려사항**: 화면 구현에 필요한 기술적 요소를 기술한다.

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID` / 서브시스템 ID(저작도구): `AT`
> - 산출물 파일명: `KLID_AT_사용자인터페이스설계서_Rev {버전}`
> - 화면 ID: `KLID-AT-SC-NNN` / 관련 유스케이스 ID: `KLID-AT-UC-NNN`(R2 참조) / 관련 시퀀스도 ID: `KLID-AT-SD-NNN`(D1 참조) / 출력물 ID: `KLID-AT-OUT-NNN`
> - 속성 표기: Input(I)·Output(O)·ReadOnly(RO)·Editable(E)·Hidden(H), 복합 속성은 슬래시로 구분(예: I/E)

## 부록 — 범위 제외 화면 및 빈 셀 사유

### 본문 승격 화면 (전체 개발범위 통합, 2026-06-25)

본 산출물은 전체 개발범위를 대상으로, 종전 부록에 "활성/R1 매핑 없음"으로만 정리했던 운영·관리·통계·게시판·포털 화면군을 본문 정식 화면 명세로 승격해 통합하였다. 승격 화면: 세션 인계 진입(KLID-AT-SC-001)·역할 클레임(KLID-AT-SC-002)·대시보드(KLID-AT-SC-011)·작업 목록(KLID-AT-SC-012)·작업자 통계(KLID-AT-SC-020)·전체 통계(KLID-AT-SC-021)·사용자 관리(KLID-AT-SC-024)·프리셋 관리(KLID-AT-SC-026)·포털 홈(KLID-AT-SC-028)·포털 라벨링(KLID-AT-SC-029)·게시판 목록(KLID-AT-SC-030)·게시판 상세(KLID-AT-SC-031)·게시판 작성/수정(KLID-AT-SC-032)·비식별 신고 관리(KLID-AT-SC-033). 라벨링 캔버스(KLID-AT-SC-005)에는 라벨 속성 패널·이슈 문의 스레드 요소를, 검수 상세(KLID-AT-SC-019)에는 이슈 문의 답변·해소 요소를 보강하였다.

> 개발자 전용 화면(`/dev/login` 개발용 로그인, `/dev/autolabel-test` 오토라벨 테스트)은 빌드 플래그 게이팅(기본 OFF)으로 운영 산출물에 포함되지 않으므로 본 산출물에서 다루지 않는다.

### 비활성·폐기 화면

| 화면 | 상태 | 제외 사유 |
|------|------|----------|
| 접근 거부(/forbidden) | 활성(보조) | 권한 불일치 시 표시되는 시스템 안내 화면으로 업무 기능 명세 대상 아님 |
| 비식별 목록 / 비식별 상세 | 비활성(폐기) | 1차 캔버스 블러 방식 폐기, 2차 외부 비식별 솔루션으로 대체 |
| 영상 처리 현황(전용) / 작업 배정(전용) / 오토라벨 요약 / VLM 메타 검토 | 비활성(폐기) | 진입점 없는 화면으로 영상 목록·작업 목록·영상 상세·라벨링 캔버스(시계열 패널) 등으로 기능 흡수 |
| TUS 대용량 업로드 | 비활성(폐기 예정) | 영상 1차 적재가 관제 학습용 설정 기반 주기 배치로 대체되어 1차 적재 경로로 사용하지 않음 |

> VLM 시계열 메타 검토(KLID-AT-UC-022)는 전용 화면이 폐기되고 라벨링 캔버스 화면(KLID-AT-SC-005)의 시계열 메타 패널로 이관되었다. 비식별 옵션 설정(KLID-AT-UC-013)은 전용 활성 화면 없이 외부 비식별 솔루션이 제공하는 옵션을 관리 화면에서 설정하는 운영 동선으로 처리한다.

### 빈 셀(`-`) 사유

- 본 산출물의 화면 목록·화면 상세에는 데이터 미상으로 인한 빈 셀이 없다. 모든 화면에 관련 유스케이스·시퀀스도가 매핑되었으며, 표의 `-` 표기는 해당 항목이 성격상 부재(읽기 전용 항목의 Validation 등)임을 의미한다.
- 컴포넌트 명세·메뉴구조 보조 자료(`ui_component`·`navigation_tree`)는 화면 상세에 포함된 정보로 충분히 표현되어 별도 섹션을 두지 않았다.
