# 작업 목록 조회·필터링·배정

## goal

WORKER는 본인 배정 작업을, REVIEWER는 배치 완료(COMPLETED) 전체 작업을 시간축 단일 정렬 + 이벤트유형(표시명 그룹) 필터 + 워크플로 상태별 KPI 카드로 조회하고, 배정·재배정·일괄배정과 라벨링·마킹 화면 진입을 수행한다.

## main_flow

### [1]

- **step**: 1
- **actor**: 검수자(REVIEWER)/라벨링 작업자(WORKER)
- **action**: 작업 목록 화면(/task)에 진입한다 — WORKER는 본인 배정 작업을(GET /v1/assignments = API-072), REVIEWER는 배치 완료 영상 전체와 배정 정보를 함께 조회한다(GET /v1/tasks/board = API-073)

### [2]

- **step**: 2
- **actor**: 검수자(REVIEWER)
- **action**: 검색어(영상명/작업자명)·이벤트유형·워크플로 상태·작업자 필터를 입력한 뒤 '조회' 버튼(또는 Enter)으로 일괄 확정한다 — 입력 즉시 재조회되지 않으며 확정 시에만 서버 재조회된다

### [3]

- **step**: 3
- **actor**: 시스템
- **action**: REVIEWER 조회는 서버가 전체 데이터 기준으로 필터링·시간축 정렬한 결과를 페이징 반환하고(상태 우선순위 정렬은 사용하지 않는다), WORKER 조회도 서버가 본인 배정 범위로 필터링한 결과를 페이징 반환한다(클라이언트 재필터 없음)

### [4]

- **step**: 4
- **actor**: 검수자(REVIEWER)
- **action**: KPI 카드(전체/미배정/작업중/검수요청/반려, GET /v1/tasks/board/summary = API-136 서버 집계) 클릭으로 워크플로 상태 필터를 즉시 토글한다(같은 카드 재클릭 시 해제) — 대기 상태를 거치지 않는 유일한 입력이다

### [5]

- **step**: 5
- **actor**: 검수자(REVIEWER)
- **action**: 미배정 행의 '배정' 또는 기존 배정 행(완료 제외)의 '재배정' 버튼으로 작업 배정 모달을 연다 — 저장 시 신규는 POST /v1/assignments(API-070), 재배정은 PATCH /v1/assignments/{assignmentId}(API-071)를 호출한다

### [6]

- **step**: 6
- **actor**: 라벨링 작업자(WORKER)
- **action**: 행의 '작업'(라벨링 대상 프레임 존재) 또는 '마킹'(프레임 미존재) 버튼으로 라벨링 화면(/labeling/{srcSn}) 또는 마킹 화면(/marking/{videoId})으로 이동한다

### [7]

- **step**: 7
- **actor**: 검수자(REVIEWER)
- **action**: 테이블에서 미배정 행 1건 이상을 선택하면 노출되는 일괄 배정 액션바로 배정 모달을 bulk 모드로 열어, 선택된 영상 번호를 rawDataIds 배열에 담아 POST /v1/assignments(API-070)를 1회 호출한다 — 서버가 한 트랜잭션에서 전 건을 배정하며 1건이라도 배정 불가 대상이면 어떤 영상도 배정되지 않는다(이미 배정된 행은 선택 체크박스가 비활성화된다)

## description

작업 목록 화면(/task)은 WORKER와 REVIEWER가 공유하되 조회 범위·필터·정렬이 역할별로 다르다. WORKER도 본인 배정 작업을 서버 필터로 조회하고, REVIEWER는 배치 완료(COMPLETED) 영상 전체를 서버가 전체 데이터 기준으로 필터링·시간축 정렬한 결과로 조회한다(상태 우선순위 ORDER BY CASE 정렬은 폐지 — 목록 화면 정렬·필터 정책). '지금 처리할 것'은 정렬이 아니라 KPI 카드(전체/미배정/작업중/검수요청/반려)와 이벤트유형 필터(표시명이 같은 유형코드를 1옵션으로 접는 그룹 필터)로 표현한다. REVIEWER는 이 화면에서 미배정 영상에 작업자를 배정하거나(단건/일괄) 기존 배정을 재배정하며, WORKER는 라벨링 대상 프레임 유무에 따라 라벨링 또는 마킹 화면으로 진입한다. 검색어·이벤트유형·상태·작업자 4개 입력은 '조회' 버튼(또는 Enter)으로 일괄 확정되며 KPI 카드 클릭만 이 대기 상태를 건너뛰고 즉시 적용된다.
