## description

REVIEWER 작업 목록. 영상(LS_DATA_RAW)을 페이징해 LABELER/REVIEWER 배정 정보와 함께 반환한다(미배정 영상 포함, task 측 필드 null).

[정렬 — 시간축 단일] 기본 등록일(regDt) 최신순이며 상태 우선순위 정렬(구 ORDER BY CASE: 반려>검수대기>배정>미배정>완료)은 폐기됐다. '지금 처리할 것'은 정렬이 아니라 workStatus 필터·KPI 카드로 표현한다(CVAT·Label Studio 관행). 배정 화면에 검수 축 우선순위가 섞여 미배정 건이 진행중 건보다 아래로 밀리던 문제를 해소한 변경이다.

[정렬 키 allowlist — strict] regDt/capturedAt/shtDt/rawSn/videoId 만 허용하고 밖의 키는 400 이다(변경 전 이 엔드포인트는 Pageable 을 그대로 받아 잘못된 키가 500 이었으므로 400 이 개선). 항목 개수 상한 3(고유 컬럼 수 파생), 같은 컬럼 중복은 첫 지정만 적용. ★ 검수목록(GET /v1/reviews)은 반대로 lenient(200 폴백)이며 일관성을 이유로 통일하지 말 것.

[두 상태 축] status(배치 상태)와 workStatus(워크플로 상태)는 독립 축이며 AND 결합된다. 신규 파라미터는 모두 optional 이고 BE 기본값이 불변이라 기존 호출은 파라미터 변경 없이 동일 결과를 반환한다(회귀 가드 ListApiBackwardCompatibilityIT).

[필터·집계 서버 이관] q 는 DB WHERE 단계에서 적용되어 totalElements 가 필터 결과 기준으로 정확하다. KPI 집계는 GET /v1/tasks/board/summary 로 분리.
