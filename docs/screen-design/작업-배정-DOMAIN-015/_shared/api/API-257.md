## description

포털 라벨링 화면([[SCREEN-029]])의 AI 분할. 포털 회원이 캔버스에서 클릭(포인트) 또는 드래그(박스)로 객체를 지목하면 AI 추론 서버의 분할 경로로 보내 폴리곤과 신뢰도를 받는다. 요청 본문·성공 응답·취소 규약은 내부 창구 [[API-093]] 과 같은 계약이다(Sam2SegmentRequest / Sam2SegmentResponse). 결과는 저장하지 않는다 — 화면이 작업본에 올린 뒤 기존 포털 저장으로 확정한다. 목업 응답은 화면이 자동 적용하지 않는다.

[입력 검증] points 와 box 는 정확히 하나만 제공해야 하며 둘 다 보내거나 둘 다 없으면 400 이다. 요청 본문의 srcSn 은 경로의 srcSn 과 같아야 하며 다르면 400 이다. 응답 폴리곤은 이미지 실측 해상도 상한까지 좌표를 검증한 뒤 단순화한다. 입력 이미지가 크기 상한 20MB 를 넘으면 413 이다.

[인가 — 포털 작업 대상] 대상 프레임이 포털 작업 가능 영상(검수 완료 영상 또는 포털 데이터셋에서 등록한 영상)의 프레임이거나 요청자 본인이 올린 업로드 자산의 프레임일 때만 통과한다. 프레임이 없으면 404 다. 남의 업로드 자산이거나 포털 작업 가능 영상이 아닌 영상이면 403 이며, 두 경우를 같은 문구로 응답해 대상이 실재하는지 드러내지 않는다. 포털 회원 역할과 포털 채널을 함께 요구한다 — 내부 채널 토큰은 이 창구를 쓰지 못하고, 포털 토큰은 내부 창구 [[API-093]] 을 계속 쓰지 못한다.

[입력 이미지] 추론 입력은 포털 화면이 그 프레임에 보여 주는 이미지와 같은 파일이다. 파일을 고르는 판정은 출처별 포털 프레임 이미지 서빙(데이터마트 영상 [[API-111]] · 본인 업로드 영상 [[API-149]])과 같은 경로 판정을 쓴다. 사용자에게 이미 보이는 이미지 밖의 픽셀은 추론 서버로 나가지 않는다. 내부 창구의 「분할은 원본 프레임에만 실행하고 비식별본은 좌표를 공유한다」는 원칙은 내부 채널 추론 전송에 대한 것이며 이 창구로 옮겨 오지 않는다([[ADR-026]]).

[비식별 판정을 두지 않는다] 포털에는 비식별 파이프라인이 없으므로 비식별 누락 신고에 따른 거부(412)를 이 창구에 두지 않는다. 내부 창구가 가진 그 응답을 이 창구로 옮겨 오지 않는다.

[요청량] 외부 채널이므로 사용자별 요청량 한도를 두며 넘으면 429 로 즉시 거부한다. 이 한도는 포털 AI 실행 창구(AI 탐지 · AI 분할 · AI 자동 추적)가 사용자 단위로 함께 쓰며, AI 자동 추적이 시간 예산 절단에 따라 이어 보내는 연속 호출을 끊지 않는 값이어야 한다. 한도 값은 운영 설정이 정한다.

[대기·취소] 사람이 화면 앞에서 기다리는 동기 호출이다. 화면의 최대 대기 상한은 서버가 내려 주는 AI 대기 예산을 따르며 화면이 자체 상수로 정하지 않는다. 취소는 내부와 같은 규약이다 — 실행마다 새로 만든 취소 식별자를 헤더에 싣고 같은 식별자로 포털 취소 창구([[API-258]])를 부른다. 내부 취소 창구 [[API-204]] 와 같은 계약이지만 그 창구는 내부 채널 전용이라 포털 토큰으로는 닿지 않는다. 식별자가 없거나 형식을 벗어나면 취소만 불가능해지고 추론은 평소대로 수행한다. 취소로 끝난 호출은 422(AI_REQUEST_CANCELLED)로 응답하고 연동 실패로 집계하지 않는다.

[추론 서버] 포털 채널 배포본도 관제 채널 배포본이 쓰는 기존 AI 추론 서버를 호출한다([[ADR-012]]). 포털에 AI 보조를 제공하는 결정의 근거는 [[ADR-013]] 이다.
