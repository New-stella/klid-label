## description

이벤트유형 셀렉트 옵션용 코드 목록을 중복 없이 오름차순으로 반환한다. 이벤트유형·카테고리 마스터가 실재하며, 스캔한 실사용 코드를 마스터 기반 표시명 그룹의 대표코드(그룹 내 최소 코드) 하나로 접어 반환한다 — 반환되는 코드값 자체가 표시명은 아니며, 화면은 별도 조회로 한글 표시명을 구한다.

[★ 파라미터 시그니처가 계약이다] 적용 필터는 status(배치 상태 축) 하나뿐이며 q/eventTypeCd/workerId/workStatus 는 반영하지 않는다 — 필터를 건 뒤 옵션이 사라지면 사용자가 되돌아갈 수 없다. 여기에 파라미터를 추가할 때는 그 값이 옵션 목록을 좁혀도 되는지 먼저 판단해야 한다.

[페이징 없음 — 예외] 목록 조회지만 코드값 select-option 성격이라 화면이 전량을 한 번에 받아야 하고, 무제한 조회는 상한(500)으로 방어한다(페이징 없는 전체조회 금지 규칙의 예외, OWASP API4).

[★ 응답이 배열이 아니라 객체인 이유] 상한 초과 시 잘라서 반환하는데, 벌거벗은 배열로 내려주면 절단이 응답에 드러나지 않아 소비자는 '그 이벤트유형 영상이 없다'고 오인한다 — 목록 필터(eventTypeCd)는 잘린 코드로도 정상 동작하므로 '데이터는 있는데 UI 로 도달할 수 없는' 조용한 손실이 된다. truncated=true 면 화면은 '일부만 표시' 안내나 검색형 입력으로 대체해야 한다.

[값 정규화] EVNT_TYPE_CD 가 null/공백인 영상은 제외되고 반환값은 앞뒤 공백이 제거된다. 목록 필터 eventTypeCd 도 trim 후 비교하므로 받은 옵션을 그대로 다시 보내면 매칭된다.
