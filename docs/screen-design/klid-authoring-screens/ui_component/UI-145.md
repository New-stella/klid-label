# overlay: PathPicker

## name

PathPicker

## category

overlay

## variants

### folder

- **description**: 폴더를 고르는 모드. 목록에 폴더만 담기고 바닥에 '이 폴더 선택' 확인 버튼을 둔다

### file

- **description**: 영상 파일을 고르는 모드. 폴더와 영상 파일이 함께 담기며 확인 버튼을 두지 않는다 — 목록에서 누르면 곧바로 골라진다

## description

서버가 읽을 수 있는 저장소를 한 단계씩 훑어 폴더 또는 영상 파일을 고르는 창구. 브라우저로 파일을 붙이는 것이 아니라 서버 내부 경로를 받는 화면에서, 사람이 경로를 직접 적는 길과 나란히 두는 보조 수단이다. 고르는 길이 적는 길을 대신하지 않으며 허용 범위 판정은 어느 쪽으로 넣든 서버가 소유한다. 허용 저장소 루트에서 시작해 현재 위치를 빵부스러기로 보이고, 하위 목록은 이름 오름차순으로 담는다. 폴더는 눌러 들어가고 영상 파일은 눌러 고른다. 이어받을 자리가 남았을 때만 더 보기가 보이며, 눌렀는데 새로 담긴 것이 없으면 그 사실만 알리고 목록과 더 보기는 그대로 두고 자동으로 다시 이어받지 않는다. 조회가 거부되면 서버가 보낸 메시지를 그 자리에 보여주고 창은 닫지 않는다 — 닫으면 어디까지 내려왔는지 처음부터 다시 찾아야 하기 때문이다.

## props_schema

### mode

- **type**: 'folder' | 'file'
- **required**: true
- **description**: 무엇을 고르는 자리인지. 폴더를 고를 때만 확인 버튼을 두고, 영상 파일은 목록에서 누르면 곧바로 골라진다. 빈 결과 안내 문구도 이 값에 따라 갈린다 — 영상 파일을 고르는 자리에서는 하위 폴더로 더 내려갈 수도 있어 폴더와 영상 파일을 함께 말한다

### open

- **type**: boolean
- **required**: true
- **description**: 창이 열려 있는지. 시안은 스크립트 없이 :target 으로 표현했다

### cwd

- **type**: string[]
- **required**: true
- **description**: 허용 저장소 루트에서 현재 위치까지의 경로 조각. 빵부스러기가 이 값을 그린다

### entries

- **type**: { name: string; kind: 'folder' | 'file' }[]
- **required**: true
- **description**: 현재 자리의 하위 목록. 이름 오름차순

### hasMore

- **type**: boolean
- **description**: 이어받을 자리가 남았는지. 참일 때만 더 보기가 보인다

### emptyAfterMore

- **type**: boolean
- **description**: 더 보기를 눌렀는데 새로 담긴 것이 없었는지. 참일 때만 그 사실을 알린다

### errorMessage

- **type**: string
- **description**: 조회가 거부됐을 때 서버가 보낸 메시지. 화면이 문구를 지어내지 않고 그대로 보여준다

## usage_example

SCREEN-039 산출물 가져오기 — 산출물 폴더 경로와 원본 영상 경로 두 입력칸 옆의 찾아보기 버튼이 각각 folder·file 모드로 이 창구를 연다. 고른 자리는 그대로 입력칸에 들어가며 직접 적어 넣는 길도 그대로 쓸 수 있다.

## accessibility_notes

창은 role=dialog · aria-modal=true 이고 제목 요소를 aria-labelledby 로 가리킨다. 목록 항목은 링크·버튼 등 조작 요소로 두어 키보드 초점을 받으며 한 줄의 조작 영역 높이를 44px 이상으로 확보한다. 폴더와 영상 파일은 아이콘만으로 가르지 않고 종류를 글자로도 적어 색·모양에만 기대지 않는다. 빈 결과와 조회 거부는 각각 role=status·role=alert 로 알리고 창을 닫지 않는다. 빵부스러기는 nav 로 감싸고 구분 기호는 aria-hidden 으로 낭독에서 뺀다.
