## description

전역 상단 네비게이션 바(h-14 fixed). 좌측 로고+제목(학습데이터 저작도구, /dashboard 링크), 우측 역할 배지(관리자/검수자/작업자/포털, 역할별 색상 구분) + 사용자 아바타(이름 첫 글자 원형 이니셜) + 이름. SSO 채널이라 역할 변경 불가 — read-only 표시. 표시하는 사용자 이름의 진실원은 세션 진입 시 조회하는 「내 정보」 응답이며, 인계 토큰의 이름 클레임은 보조 조달원이다. 토큰에 이름이 실려 오지 않아도 「내 정보」가 알려 준 이름을 표시한다. 아바타 이니셜은 그 이름의 첫 글자이므로 같은 조달원을 따른다. 두 조달원 모두에서 이름을 얻지 못했을 때만 대체 표기 '사용자'로 내려간다 — 이 대체 표기 자체는 유지하되, 서버가 이름을 아는 상태에서 이 표기가 나타나면 결함이다.
