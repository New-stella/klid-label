## description

영상 단위(RAW_SN) 이벤트 어노테이션(VQA/CoT/caption)을 조회한다. 어노테이션은 영상 1건당 1건(LS_EVNT_ANNO, RAW_SN UK)이며 payload 는 event_class/question/caption(후보 키 c1..cn 맵)/answer/evidence(후보 키 c1..cn 맵) 구조다. 필드별 조달 출처는 2026-08-25 확정 축을 따르며 상세는 각 필드 설명에 적는다 — 자동으로 채우는 것은 question(저작도구가 보관하는 검증 이벤트 유형별 질문 문구 목록)과 caption 후보 c1 의 caption_text(추가 질문 응답 서술), 같은 후보 cot 의 1단계(묘사 전문의 「상황」 라벨 줄)이고, answer 와 evidence 및 cot 의 2단계 이후는 자동으로 채우지 않는 사람 확정 공란이다. 이 축은 2026-08-24 에 "추가 질문 결과를 answer 초안으로 넣는다"로 확정했던 것을 2026-08-25 회신이 되돌린 것이다 — 같은 축이 이틀 만에 두 번 뒤집혔으므로 세 번째 반전을 막기 위해 경위를 남긴다. 검토 상태(LS_EVNT_ANNO_REVIEW.RVW_STTS_CD: PENDING/AUTO_GENERATED/APPROVED/REJECTED)를 함께 반환한다. 검수 승인 시 export 폴더 JSON 최상위 event 키로 반영(ADR-020). 인증된 사용자(REVIEWER/WORKER).
