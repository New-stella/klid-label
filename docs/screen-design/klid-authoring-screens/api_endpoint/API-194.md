## description

관리 기능에 진입하기 위한 단기 세션을 발급한다. 관리자 공유 패스워드를 검증하고, 성공하면 서버가 단기 토큰을 발급한다.

발급된 토큰은 운영·관리 성격의 쓰기 전반에 효력을 갖는다. 사용자 역할 부여·변경, 연동 서버 주소 변경, 영상 업로드 시작, 관리자 패스워드 변경이 그런 행위다. 이 열거는 전수 목록이 아니라 예시이며, 판정 기준은 운영·관리 성격의 쓰기인가 하나다. 조회에는 요구되지 않는다 — 관리 화면의 목록·상세뿐 아니라 다른 업무 화면이 작업자 목록 같은 사용자 정보를 읽는 경로도 검수자 권한만으로 된다. 포털 채널 이용자가 자신의 자산을 올리는 업로드도 대상이 아니다.

이 토큰은 역할을 승격시키지 않는다. 인가는 대체되지 않고 가산된다 — 관리자 역할은 그대로 필요하다. 토큰은 발급받은 사람에게 묶여 있어 다른 사람이 그 토큰을 쓸 수 없다.

유효기간은 기본 10분이고 설정으로 조정할 수 있으나 상한 30분이 강제되어 30분을 넘길 수 없다. 유효 여부 판정은 서버가 소유한다 — 클라이언트가 아직 유효하다고 스스로 정하지 못한다.

제출된 패스워드는 자격 전용 저장 위치의 해시와 대조한다. 저장 위치에 값이 아직 없으면 배포 설정값으로 되돌아가 판정하며, 둘 다 없으면 어떤 패스워드도 통과하지 않는다. 관리자 패스워드가 바뀌면 그 전에 발급된 토큰은 모두 무효가 된다 — 별도의 무효화 장부를 두지 않고, 토큰 서명이 현재 패스워드에 의존하게 만들어 자연히 검증에 실패하도록 한다.

속도 제한은 역할 자가부여 진입점과 공유한다. 버킷을 나누면 두 진입점을 번갈아 써서 실효 한도가 두 배가 되기 때문이며, 의도된 설계다. 판정 순서는 인가 → 속도 제한 → 패스워드 비교다.

패스워드와 토큰은 어떤 응답에도, 어떤 로그에도 남기지 않는다. 관리자 역할 보유자만 호출한다.
