## statement

검수자가 승인하려는 영상의 비식별화완료여부가 N이면 승인이 거부된다. 이 거부는 상태 전이보다 먼저 판정되므로 검수 상태 전이도 버전 스냅샷도 export 새 버전 재생성도 통지도 전혀 생기지 않는다. 비식별화완료여부가 Y로 바뀐 뒤의 승인 시도는 주 흐름 그대로 진행된다. 이 값이 막는 것은 검수 승인뿐이며 라벨 조회·프레임 이미지·영상 스트리밍·산출물 생성은 닫지 않는다(그 통로를 닫는 것은 비식별 누락 신고 상태로 별개 축). 기본값은 Y이며 외부 이관 원본으로 지정돼 들어온 영상만 N으로 시작한다.
