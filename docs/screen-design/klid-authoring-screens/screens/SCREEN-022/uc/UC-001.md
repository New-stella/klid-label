## description

REVIEWER 가 원본 영상을 선택해 외부 생성형 AI 서비스에 증강 영상 생성을 위임한다. 생성 본체는 외부 책임이며 저작도구는 요청·수신·검수만 담당한다.

[중복 요청은 차단하지 않는다 (ADR-044)] 같은 (영상 × 증강 종류) 요청을 서버가 사전 조회로 막지 않는다 — 생성 결과가 매번 달라 원하는 이미지가 안 나오면 동일 조건으로 다시 요청하는 것이 정당한 운영 동선이다. 연타(오조작) 방어는 FE 단독 책임이며 속도 제한도 두지 않는다(사용자가 인지·수용한 잔여 위험). ⚠ 해상도 파생의 UK_LS_DATA_AUG_RESL 은 별개 계약이라 유지된다.

[귀결] 같은 (영상 × 종류) 파생이 여러 건 공존한다. 결과물 구분의 유일한 축은 PROMPT_CN(요청 시 생성조건 원문, V147)이므로 조회 경로에서 반드시 노출한다. 파생 식별자(VMS_CLIP_ID)도 시각이 아니라 증강 행 PK(DATA_AUG_SN)로 유일화한다 — 시각 기반이면 동시 콜백이 같은 밀리초에 충돌해 결과물이 유실된다.

[생성 조건(prompt) 5필드 — 전부 필수] time/season/weather/terrain/severity 를 REVIEWER 가 입력하면 명세서 §4.1 prompt 로 가공 없이 전송되고 PROMPT_CN 에 원문(JSON)으로 보관된다. 명세가 enum 을 정의하지 않으므로 서버가 값을 좁히지 않는다(검증은 필수·공백금지·상한·보이지 않는 문자 제거뿐). ⚠ AUG_TYPE_CD 는 prompt 에서 파생하지 않는다 — 자유 문자열이 유형 판정에 흘러가면 경로 순회(CWE-22)·RESL_ 네임스페이스 침범이 열린다.

[거부 조건] ①파생본(ORGNL_RAW_SN non-null)은 증강 요청 대상이 될 수 없다 — **400**(파생 깊이 1 고정, ADR-023). 영구 조건이라 재시도 여지가 없으며 원본으로 유도하지 않는다(파생 배정 WORKER 는 원본 접근 권한이 없다). ②비식별 누락 신고 구간은 외부 위탁이 막혀 **412** — 이쪽은 해소되면 재요청이 가능한 일시 조건이다. (R2 UC-001, RQ-SFR-07-01)
