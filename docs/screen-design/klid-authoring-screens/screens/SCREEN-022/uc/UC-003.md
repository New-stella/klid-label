# 해상도 변경 수행

## description

★설계 반전(ADR-018/ADR-023, 2026-07-22~29) — 해상도 변경은 표준 해상도 3종 고정 프리셋(1080P/720P/480P)마다 새 파생영상(RAW_SN, ORGNL_RAW_SN으로 원본 참조)을 생성하는 증강형 파생영상으로 전환되었다(구 '전용 저장모델·영상 재생성 없는 이미지셋 제공' 정책 폐기). 비디오 파일은 원본(비식별) 복사(재인코딩 없음), 프레임 이미지셋만 목표 해상도로 리스케일(축소/확대)한다. **업스케일(원본보다 높은 해상도)도 허용**한다(구 targetH>=srcH 400 거부 가드 제거) — 원본과 동일 해상도인 프리셋만 스킵하고 나머지는 3종 모두 생성한다. 라벨/이미지 좌표는 해상도 배율(scaleX=targetW/srcW, scaleY=targetH/srcH)로 재계산해 **적재한다**(BBOX/POLYGON/세그먼테이션/키포인트 전 종류 — 구 '좌표 미제공' 정책 폐기). 저장모델은 증강과 완전 통합되었다 — 전용 테이블(LS_RESOLUTION_EXPORT/LS_RESOLUTION_LBL_MAP) 없이 LS_DATA_AUG(AUG_TYPE_CD=RESL_1080P/720P/480P)+LS_DATA_AUG_LBL_MAP(COORD_RECALC_YN/SCALE_X/SCALE_Y 재사용)에 적재한다. 해상도 파생은 증강 이력(GET /v1/augments)에 노출·집계에 포함되나 accept/reject(검수 승인·반려)는 차단된다(UC-010 참조). (R2 UC-003, RQ-SFR-06-03)

### 대상 프리셋 전부 스킵

- **trigger**: 모든 프리셋이 원본과 동일 해상도

### 일부 프리셋 생성 실패

**steps**:

- 1건 이상 성공 시 201, 전부 실패 시 500

- **trigger**: ffmpeg 리스케일 또는 좌표 재계산 실패

### 파생본 대상 요청

**steps**:

- 해상도 변경 요청을 400으로 거부한다 — 파생 깊이 1 고정(ADR-023)에 따른 영구 조건이라 재시도 여지가 없다

- **trigger**: 대상 영상이 이미 파생영상(ORGNL_RAW_SN non-null)인 경우

### 비식별 누락 신고 구간

**steps**:

- 해상도 파생 생성은 차단하지 않는다 — 외부 위탁이 없는 내부 ffmpeg 리스케일이라 유출 경로가 열리지 않는다
- 부모 게이트는 DE_IDNTF_YN='N'(비식별 미수행)만 차단하고 'F'(신고)는 통과시킨다

- **trigger**: 대상 영상이 비식별 재처리 대기(DE_IDNTF_YN='F') 상태인 경우
