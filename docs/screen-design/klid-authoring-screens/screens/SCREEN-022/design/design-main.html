증강 요청

검수 완료된 영상 1건에 처리 종류 하나를 골라 요청합니다. 결과는 원본과 다른 새 영상으로 만들어지며 검수를 다시 받습니다.

처리 요청은 검수 완료(승인)된 영상만 가능합니다. 아직 승인되지 않은 영상은 아래 목록에 나타나지 않습니다. 이미 만들어진 파생영상도 다시 처리 대상이 될 수 없습니다.
