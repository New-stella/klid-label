# UC-003 해상도 변경 예외 — 전부 스킵 400·일부 실패 201/전부 500·파생본 400·비식별 신고 통과 (negative)

## scenario

### then

- 대상 프리셋 전부 스킵은 400, 1건 이상 성공은 201, 전부 실패는 500
- 파생본 대상은 400으로 영구 거부
- 비식별 신고('F') 구간도 내부 리스케일이라 차단하지 않고 통과('N'만 차단)

### when

### given

## statement

대상 프리셋 모두에서 산출 크기가 원본과 같아지면 400으로 거부한다. 일부 프리셋 생성 실패 시 1건 이상 성공이면 201, 전부 실패면 500. 대상 영상이 이미 파생영상(ORGNL_RAW_SN non-null)이면 400으로 거부한다(파생 깊이 1 고정 ADR-023, 영구 조건). 비식별 재처리 대기(DE_IDNTF_YN='F') 구간이어도 해상도 파생 생성은 차단하지 않는다 — 외부 위탁 없는 내부 ffmpeg 리스케일이라 유출 경로가 없고, 부모 게이트는 'N'만 차단하고 'F'는 통과시킨다.
