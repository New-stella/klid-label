## description

마킹 화면: 비식별 영상 스트리밍(GET /v1/videos/{rawSn}/stream, HTTP Range) + 배속(0.25x~4x) + 단축키(Space 마킹, Del 삭제, Enter 완료). 자동 마킹은 프레임 간격(intervalFrames, 기본값 30→300 변경) 기반. ★마킹 완료 시 이벤트 마킹 결과에서 frame_policy(마킹 본문에서 프레임 인덱스를 얻으면 frame_selected 모드로 그것을 싣고, 하나도 얻지 못하면 frame_interval 모드로 내린다(빈 목록은 규격 위반이라 거부된다) — 마킹 모드는 그 인덱스를 누가 골랐는지만 가른다(수동이면 작업자가 지정한 프레임, 자동이면 간격으로 자동 선택된 프레임). 정렬·중복제거하며 음수는 허용하지 않고 상한 600 초과분은 절단한다)와 event_type(관제 인입값 LS_DATA_INGEST.VRFC_EVNT_TYPE_CD 를 그대로 — 검증·차단 없이 위탁하며 수용 여부는 벤더 응답이 정한다)이 도출되어, VLM 시계열 위탁(UC-022 — CoT 서술 POST /v1/videovlm-klid/describe 와 VQA POST /v1/videovlm-klid/describe-sub 로 각각 별도 request_id 를 부여하는 이중 위탁)의 논블로킹 제출 입력이 된다. 프레임 추출 간격·장수는 연동 시스템이 지정하지 않고 외부 분석 서버가 관리하므로 frame_policy 에 framerate 필드를 두지 않는다 — 구 서술 'framerate(몇 프레임당 1장)를 mode 무관 필수로 함께 싣는다'는 폐기되었다. ⚠ 구 서술 '마킹 결과(이벤트명+영상경로+marks 배열)는 VLM 콜백으로 전달'도 폐기되었다 — 위탁 요청 규격에 그 필드들이 없고, '콜백'이라는 표현도 방향이 반대다(마킹→VLM 은 위탁/제출이고, VLM→저작도구 방향만 콜백 POST /v1/vlm/callback 이다). 마킹 완료 시 마킹 완료 이벤트가 트랜잭션 커밋 후(AFTER_COMMIT) 잔여 배치를 비동기로 시작한다. 마킹 중 비식별 누락 발견 시 rawSn 기준 비식별 신고 가능(POST /v1/videos/{rawSn}/deident-report = API-091). durationSec 미상 시 ffprobe 등 3단 폴백(쓰기 트랜잭션 밖에서 실행). 영상 목록 화면(SCREEN-007, 이후 폐기됨)의 미배정 행 액션이 '배정' 버튼에서 '마킹' 버튼(자동=즉시 실행, 수동=기존 배정 팝업 재사용)으로 통합됐다. ★비식별 선두 파이프라인(전체 영상 적재 직후 자동 비식별 → 비식별 영상 대상 마킹)이 확정되었다 — 구 'divergence(마킹이 전체 배치를 트리거하던 구 순서)' 서술은 폐기되었다(ADR-022).

## alternate_flows

### 마킹 중 비식별 누락 발견

**steps**:

- rawSn 기준 비식별 신고(POST /v1/videos/{rawSn}/deident-report = API-091)를 접수하고 신고 단계를 DCLR_STP_CD='MARKING' 으로 기록한다
- 신고가 접수되면 해당 영상의 마킹이 중단되고(작업락 + DE_IDNTF_YN='F'), 해소 후 배치 단계를 MARKING_READY 로 되감아 마킹부터 다시 수행한다(활성 마킹은 SKIPPED 로 종결해 재마킹 409 를 푼다)
- 그 상태는 선두 비식별 성공 직후·마킹 이전이라 프레임 행도 라벨도 아직 없어 재마킹이 파괴할 작업 결과가 없다

- **trigger**: 비식별 영상에서 개인정보 노출 발견

### 마킹 단계 신고의 접수 조건 불충족

**steps**:

- 412 PRECONDITION_FAILED — PROCESSING/COMPLETED/FAILED/PENDING 을 구분해 알리지 않는 단일 문구로 안내한다(응답이 영상 처리 단계 오라클이 되지 않게 — CWE-209)
- FE 는 MARKING_READY 가 아니면 신고 버튼을 비활성화해 사유를 다 적고 제출한 뒤에야 거부되는 동선을 없앤다

- **trigger**: 배치 단계가 MARKING_READY 가 아닌 상태에서 마킹 단계 신고

### 비식별 미완료 영상 접근

**steps**:

- 비식별본이 없으면 영상을 제공하지 않아(404) 원본 노출을 차단한다 — 스트리밍은 항상 비식별 영상만 서빙한다

- **trigger**: 비식별이 유효하지 않은 영상의 스트리밍 요청
