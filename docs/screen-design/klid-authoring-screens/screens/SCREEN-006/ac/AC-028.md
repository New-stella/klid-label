# 마킹에서 도출된 VLM 위탁 입력(frame_policy·event_type)

## notes

근거: CLAUDE.md(★VLM·KPST 위탁은 논블로킹 제출이다 / frame_policy 는 마킹에서 도출한다 / event_type 은 위탁을 막지 않는다 절). 판정 지점: VlmTimeseriesStep.resolveEventType · VlmTimeseriesStep(frame_policy 조립) · 마킹 단계 신고 접수 조건 가드.

## priority

high

## scenario

### then

- frame_policy.mode='frame_selected' 이고 selected_frames 는 정렬·중복제거 후 벤더 상한 8건으로 절단된다
- event_type 은 관제 인입값(LS_DATA_INGEST.VRFC_EVNT_TYPE_CD)을 그대로 실어 위탁하며 화이트리스트 검증으로 사전 차단하지 않는다
- framerate 는 LS_MARKING.FRME_INTV_NOCS(마킹 프레임 간격)이며 값이 없거나 0 이하면 설정 기본값(25)으로 폴백한다

### when

- 마킹이 완료되어 VlmTimeseriesStep 이 위탁 요청을 조립한다

### given

- 수동 마킹으로 10개 프레임이 선택되었다

### and_examples

#### [1]

- **case**: 자동 마킹 또는 마킹 결과 부재
- **result**: frame_policy.mode='frame_interval' 로 도출된다

#### [2]

- **case**: 배치 단계가 MARKING_READY 가 아닌 상태에서 마킹 단계 비식별 신고(POST /v1/videos/{rawSn}/deident-report) 시도
- **result**: 412 PRECONDITION_FAILED 로 거부되고 처리 단계(PROCESSING/COMPLETED/FAILED/PENDING)를 구분해 알리지 않는 단일 문구로 응답한다

## statement

마킹 완료 시 frame_policy(수동 마킹=frame_selected+selected_frames 정렬·중복제거·벤더 상한 8건 초과분 절단, 자동 마킹/마킹 부재=frame_interval)와 event_type(관제 인입값 그대로, 검증·차단 없음)이 도출되어 framerate 와 함께 VLM 시계열 위탁(POST /v1/videovlm/verify)의 논블로킹 제출 입력이 되며, 배치 단계가 MARKING_READY 가 아닌 상태에서의 마킹 단계 비식별 신고는 412 로 거부된다.
