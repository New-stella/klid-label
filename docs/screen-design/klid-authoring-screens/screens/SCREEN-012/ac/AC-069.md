# 검색과 필터는 확정할 때만 서버에 다시 묻는다

## notes

입력할 때마다 서버를 부르면 조건을 여러 개 바꾸는 동안 쓸모없는 조회가 반복된다. 상태 카드를 예외로 두는 것은 그것이 한 번 누르면 값이 확정되는 입력이기 때문이다.

## priority

medium

## scenario

### then

- 서버에 다시 묻지 않는다
- 확정하면 그때 한 번 물어 첫 쪽부터 보여준다
- 상태 카드를 누르면 확정을 기다리지 않고 반영되며 같은 카드를 다시 누르면 해제된다

### when

- 검색어와 필터를 입력하기만 하고 확정하지 않는다

### given

- 작업 목록을 조회한 상태다

## statement
