# 상태로 거르는 조건과 화면에 표시하는 상태는 어긋나지 않는다

## notes

거르는 조건과 표시 값을 각자 만들면 작업중으로 걸렀는데 화면에는 대기로 표시되는 행이 생긴다. 이 기준의 축은 두 방향이 한 판정에서 나온다는 것이다.

## priority

high

## scenario

### then

- 돌아온 모든 행의 표시 상태가 작업중이다
- 다른 상태로 표시되는 행이 섞이지 않는다

### when

- 작업중 상태로 목록을 거른다

### given

- 여러 상태의 작업이 섞인 배정 목록이 있다

## statement

작업 상태로 목록을 거를 때 걸러 나온 모든 행은 그 상태로 표시되며, 거르는 조건과 표시하는 값은 같은 판정에서 나온다.
