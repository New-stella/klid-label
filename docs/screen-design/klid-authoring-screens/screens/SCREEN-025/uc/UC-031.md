# 시스템 운영 설정 관리

## goal

REVIEWER가 배치 처리·AI 탐지 추론·라벨링 정밀도 파라미터를 조회·수정하고, 외부 연동(DB·디스크·관제서버·포털서버·AI 서버·비식별 서버) 헬스를 실시간 모니터링하며, 되돌릴 수 없는 위험 액션을 확인 절차를 거쳐 수행한다.

## main_flow

### [1]

- **step**: 1
- **actor**: 검수자(REVIEWER)
- **action**: 시스템 설정 화면(/manage/settings)에서 설정 키-값 목록을 조회한다(GET = API-068)

### [2]

- **step**: 2
- **actor**: 검수자(REVIEWER)
- **action**: 배치 처리(처리 주기·동시 처리 수)/AI 탐지 추론(Confidence Threshold·이미지 크기·IoU 임계값)/라벨링 정밀도(인식 민감도·경계 세밀함) 3종 카드 중 값을 수정한다 — 카드별 독립 폼이며 값이 실제로 바뀐 카드만 저장 버튼이 활성화된다

### [3]

- **step**: 3
- **actor**: 시스템
- **action**: 저장 시 카드 안에서 실제로 바뀐 키에 한해서만 개별 PUT 요청(API-069)을 보낸다(일괄 저장 API 없음)

### [4]

- **step**: 4
- **actor**: 시스템
- **action**: 서버가 타입·범위를 검증하며 범위를 벗어나면 저장을 거부한다(필드별로 구분되지 않는 공통 실패 토스트로 안내)

### [5]

- **step**: 5
- **actor**: 검수자(REVIEWER)
- **action**: 우측 패널에서 5초 주기 폴링으로 외부 연동(DB/디스크/관제서버/포털서버/AI 서버/비식별 서버) 상태·응답시간(latencyMs)을 읽기 전용으로 확인한다(GET = API-090)

### [6]

- **step**: 6
- **actor**: 검수자(REVIEWER)
- **action**: 위험 액션(시스템 초기화(개발 전용)/배치 큐 초기화/캐시 삭제) 버튼을 클릭하면 확인 다이얼로그가 열리고, 확인을 눌러야만 실행된다

## description

REVIEWER가 배치 처리(처리 주기·동시 처리 수)/AI 탐지 추론(Confidence Threshold·이미지 크기·IoU 임계값)/라벨링 정밀도(인식 민감도·경계 세밀함) 3종 설정 카드를 조회·수정하고, 외부 연동(DB·디스크·관제서버·포털서버·AI 서버·비식별 서버) 헬스를 5초 주기 폴링으로 읽기 전용 모니터링하며, 되돌릴 수 없는 위험 액션(시스템 초기화·배치 큐 초기화·캐시 삭제)을 확인 절차를 거쳐서만 실행한다. 저장은 카드별 독립 폼이며 일괄 저장 API 가 없어 실제로 바뀐 키에 한해서만 개별 PUT 요청을 보낸다. 화면 슬라이더 표시 범위와 서버 허용 범위가 완전히 일치하지 않는 필드가 있다(예: IoU 임계값 — 화면 25~80 vs 서버 30~80, 25~29 구간은 화면에서 입력할 수 있으나 서버가 거부한다) — SCREEN-025 화면 사양의 알려진 불일치이며 서버 값이 최종 판정이다. UC-006(라벨링 정밀도 조절의 1회성 AI Tool 모달 override 메커니즘)·UC-013(비식별 옵션 항목 자체)과 서로 다른 관점에서 같은 화면을 다루며 서로를 대체하지 않는다.
