# 설정 저장은 실제로 바뀐 키만 개별로 보낸다

## notes

바꾸지 않은 키까지 함께 보내면 그 키의 수정자와 수정 시각이 손대지 않았는데도 갱신되어 감사 기록이 사실과 달라진다.

## priority

medium

## scenario

### then

- 바뀐 키에 대해서만 요청이 나간다
- 바꾸지 않은 키는 요청에 담기지 않는다
- 값을 바꾸지 않은 카드는 저장할 수 없다

### when

- 그 카드를 저장한다

### given

- 설정 화면의 한 카드에 여러 키가 있고 그중 하나만 값을 바꿨다

## statement

설정은 카드별 독립 폼으로 저장하며 값이 실제로 바뀐 키에 한해 키마다 개별 요청을 보낸다. 여러 키를 한 번에 저장하는 요청은 없다.
