# 되돌릴 수 없는 위험 액션은 확인을 거쳐야만 실행된다

## notes

확인 절차는 구현 진척과 무관한 설계 요구다. 이 단계가 화면 구성에서 사라지면 되돌릴 수 없는 액션이 한 번의 클릭으로 실행되는 사양이 된다.

## priority

critical

## scenario

### then

- 확인을 묻는 단계가 먼저 열린다
- 확인하지 않고 벗어나면 아무것도 실행되지 않는다
- 확인한 뒤에만 실행된다

### when

- 그 액션의 버튼을 누른다

### given

- 관리자 페이지에 되돌릴 수 없는 운영 액션이 있다

## statement

되돌릴 수 없는 운영 액션은 버튼을 누르는 것만으로 실행되지 않고 확인 절차를 거친 뒤에만 수행된다.
