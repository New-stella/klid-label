# 이벤트유형 관리 화면

## route

/manage/event-types

## title

이벤트유형 관리 화면

## device

desktop

## status

draft

## purpose

검수자 전용(/manage/event-types). 관제 인입으로 자동 등록된 이벤트유형의 표시명과 수집여부를 정정한다. ★생성·삭제 기능을 두지 않는다 — 등록의 유일한 출처가 관제 인입이며, 화면에 없는 유형은 관제가 보낸 적이 없는 유형이다. 지우면 그 유형의 영상이 라벨을 잃는다. ★표시명은 서버가 4단(운영자 지정명 → 관제 수신명 → 카테고리명 → 유형코드)으로 해석해 내려주며 화면은 그 값을 그대로 표시한다 — 화면에서 폴백을 다시 계산하면 판정이 갈라져 학습데이터 산출물의 이벤트명과 조용히 어긋난다. ★표시명 칸에는 그 값이 어느 단계에서 온 것인지를 함께 표기한다 — 같은 이름이 여러 줄에 보이는 까닭이 값만으로는 드러나지 않기 때문이며, 표기 값은 서버 응답에 실려 온 것을 그대로 쓴다. ★표시명 지정은 필터 그룹을 가르는 조작이다 — 목록 필터의 이벤트유형 옵션은 표시명이 같은 유형코드들을 한 건으로 접어 보여주므로, 여기서 이름을 지정하면 그동안 한 건으로 보이던 그룹이 자동으로 쪼개진다. 접기는 영구 병합이 아니라 표시명이 같은 동안만 유지되는 상태다. 표시명을 비워 저장하면 지정이 해제되어 관제 수신명으로 되돌아간다. 접근: 검수자 — 화면 진입 시점과 서버 요청 시점 양쪽에서 역할을 이중으로 검사한다. ★이 화면은 검증 이벤트 유형과 그 유형별 질문 문구도 함께 관리한다 — 관제 이벤트유형과 검증 이벤트 유형은 서로 다른 코드 체계이므로 한 목록으로 합치지 않고 나란히 보여준다. 검증 이벤트 유형은 정렬순서 오름차순으로 보여주고, 유형마다 질문을 여러 개 둘 수 있으며 순서가 곧 의미다 — 정렬순서 첫 번째가 그 유형의 기본 질문으로 쓰인다. 질문의 추가·수정·삭제·순서 변경은 그 유형의 질문 목록 전체를 한 번에 교체하는 저장 하나로 처리한다 — 항목 단위 조작 통로를 따로 두면 여러 요청 사이의 중간 상태에서 「첫 번째」가 흔들려 그 사이에 조달되는 질문이 운영자가 의도하지 않은 문구가 된다. ★관제 이벤트유형 코드와 검증 이벤트 유형의 짝은 인입 원장에 실려 온 값을 읽어 보여줄 뿐이며 별도 매핑표를 만들지 않는다 — 사본을 두면 원장과 어긋나는 두 번째 진실원이 된다. 한 검증 유형에 관제 코드가 여러 개 붙을 수 있고 하나도 없을 수도 있다. 검증 이벤트 유형 자체의 등록·수정·삭제 수단은 이 화면에 두지 않는다. 질문 문구는 외부 사업자 요청 본문과 로그에 그대로 실리는 값이라 개행·제어문자가 거부되고 길이 상한이 있으며, 화면은 그 거부를 그대로 안내한다. ★이 문구는 추가 질문 축의 위탁 요청 본문에 직접 실려 나가므로 편집의 결과가 외부로 나가는 값을 바꾼다 — 다만 이미 나간 위탁은 그 시점에 보관해 둔 문구를 쓰므로 편집이 소급되지 않는다. 목록 조회는 API-219, 질문 목록 교체는 API-220 이다. ★목록에는 이벤트유형마다 프리셋 연결 상태를 함께 보여준다 — 표기는 연결됨·연결됨(무효)·연결됨(제외)·미연결이며 이 문구가 확정 표기다. 연결됨(제외)는 프리셋에 라벨을 하나도 담지 않아 그 유형을 오토라벨 대상에서 뺀 상태로, 사람이 그렇게 선언한 것이라 보류가 아니며 보류 거르기에도 걸리지 않는다. 값은 서버가 판정해 내려준 것을 그대로 쓰고 화면이 프리셋 유무를 다시 판정하지 않는다. 프리셋이 없거나 무효인 이벤트유형의 영상은 오토라벨링이 보류되므로, 운영자가 그 사실을 알아차리는 자리가 이 화면이다. ★오토라벨 보류만 보기 조작을 두며 이 조작은 미연결과 연결됨(무효)을 함께 거른다 — 보류를 유발하는 상태가 둘이라 미연결만 거르면 조치가 필요한 유형의 일부가 목록에서 빠진다. 무엇이 보류를 유발하는지의 정의는 서버가 소유하며 화면이 상태 값을 조합해 그 집합을 다시 만들지 않는다. 거르기는 서버가 전체를 대상으로 수행한다 — 화면이 현재 페이지만 걸러내면 다른 페이지의 보류 유형이 조용히 빠진다. 표시명이 같아 한 건으로 접힌 그룹의 비대표 코드 행도 대표코드에 걸린 프리셋을 반영한 값이 실려 온다.
