## § 3. 디자인 결정

### 본문 시나리오를 「검수 완료 이력이 있는 영상」으로 잡았다

이 화면의 v62 변경이 **둘 다 비활성 조건**이라, 활성 상태만 그리면 그 사양이 시안에서 사라진다.
그래서 본문은 그 시나리오 하나를 그리고(신고 비활성 · 폐기/복원 비활성 · 검수제출 → 「재검수 제출」),
**반대편 상태는 「상태 변형」 참고 패널**에 나란히 뒀다. 참고 패널은 SCREEN-008·009 가 대체 상태
(로딩/에러/빈 상태)에 쓴 것과 같은 관례이며 `aria-hidden="true"` 로 중복 낭독을 막았다.

### 비활성은 색이 아니라 문장으로 알린다

DS `dont_rule` 이 *"색만으로 상태를 구분하지 않는다"* 를 못박고 있고, 비활성 버튼은 특히 **왜 못 누르는지**가
없으면 고장으로 읽힌다. 그래서 비활성 버튼마다 **① `title` 툴팁(전체 사유) ② 옆 캡션(`hint-note`, 짧은 사유)
③ `aria-describedby` 연결** 3중으로 붙였다. 사유 문구는 골격 원문을 그대로 쓴다 —
"검수가 완료된 영상은 비식별 누락을 신고할 수 없습니다." · "한번이라도 검수가 완료된 영상은 프레임을 새로
폐기하거나 복원할 수 없습니다."

### 「과거 회차 확정은 막지 않는다」를 안내 박스로 남겼다

골격이 명시한 예외인데 **버튼 상태로는 표현할 수 없다**(같은 버튼이 상황에 따라 열린다). 폐기/복원 상태
카드 안에 `alert-info` 로 그 예외를 문장으로 뒀다. 이걸 빼면 다음 사람이 "폐기는 승인 후 무조건 잠긴다"로
읽고 회차 확정 경로까지 막는다.

### 키포인트 진행 가이드는 탭 **바깥**에 뒀다

골격이 *"어느 탭을 보고 있어도 항상 보이는 영역"* 이라고 규정한다. 그래서 `panel-tabs` 위, 우측 패널 최상단에
독립 블록으로 배치했다(`p-0` 표면 + `p-2` 하단선으로 탭 영역과 분리). 탭 안에 넣으면 메타·이슈 탭에서 사라져
규정과 어긋난다.

### 매트(캔버스)만 다크, 나머지는 전부 라이트

DS 가 *"앱에 다크 표면은 없다. 유일한 예외는 영상 프레임을 얹는 미디어 매트와 그 위 오버레이"* 라고 규정한다.
헤더·도구바·패널·필름스트립은 전부 라이트 톤이고, 매트(`n-10`)와 프레임 자리(`n-9→n-8→n-7` 그라디언트),
그 위 캡션 스크림만 어둡다. 썸네일도 같은 이유로 미디어 표면이다.

### 실제 인물처럼 보이는 이미지를 그리지 않았다

비식별 프레임을 다루는 화면이라 매트 안은 **중립 자리 표시(사진 아이콘 + "비식별 프레임 이미지")** +
라벨 도형(BBOX 2·폴리곤 1) + 그리드로만 구성했다. 사람 형태·얼굴·번호판 비슷한 것을 넣지 않았다.

### 그 밖

- **저장은 옵션바 한 곳** — 골격이 *"이 화면에서 라벨을 저장하는 유일한 진입점"* 이라고 못박아, 헤더에
  저장 버튼을 두지 않고 미저장 건수를 `btn-count` 로 버튼에 붙였다(저장 ③).
- **primary(채움)는 진행 액션에만** — 저장 · 재검수 제출 · 설명 저장 · 시계열 메타 저장 · 어노테이션 저장 ·
  승인 · 해결 처리 · 문의 등록. 되돌리기·보기 조작은 ghost, 대안 액션은 secondary, 파괴적 액션은 danger.
- **좌표 입력은 mono 14px** — ladder 의 mono step 용도 정의가 *"식별자, 좌표, 로그"* 라 X/Y/W/H 가 정확히
  거기에 해당한다. `tabular-nums` 로 자릿수를 정렬했다.
- **밀집 패널의 44px 하한**은 `btn-sm::after { inset:-4px 0 }` · `icon-btn::after { inset:-6px }` 로
  보이지 않는 히트영역만 넓혀 지켰다(행 높이를 키우지 않는다). SCREEN-008 관례 그대로다.
- **탭 전환은 CSS-only** radio+label. `<script>` 0건이라 렌더러가 스크립트를 제거해도 무해하다.

### 그 밖의 접근성 처리

- 도구 활성 = `aria-pressed`, 탭 = `role=tablist/tab/tabpanel`, 라디오 칩 = `role=radiogroup/radio` +
  `aria-checked`, 스위치 = `role=switch` + `aria-checked`, 저장 상태·키포인트 진행 = `role=status`.
- 폼은 전부 `label[for]` 연결(시각 라벨이 없는 곳은 `visually-hidden` 라벨) + 도움말 `aria-describedby`.
- 썸네일은 `button` 이며 상태를 `visually-hidden` 텍스트로 낭독(「현재 프레임」·「폐기된 프레임」 등).
- 클릭 대상은 전부 `button`/`a`(div 클릭 0건), 최소 44×44 히트영역.
- 참고 패널 2종은 `aria-hidden="true"`(본문과 중복 낭독 방지) — SCREEN-008·009 와 같은 처리.
- focus-visible 3px + offset 2px 전역 적용(DS do_rule).

## 게시본 안전 마크업 전환 (재업로드 회차)

LogiCraft 게시 sanitizer 가 일부 태그·속성을 떨어뜨려 게시 프리뷰가 로컬과 달라지던 것을 바로잡았다.
**서버가 저장한 CSS 는 바이트 단위로 그대로 통과하는 것을 실측**했으므로, 잘리는 표현은 모두 CSS 로 옮겼다.
로컬 렌더가 달라지지 않았는지는 전환 전후 **전체 화면 픽셀 대조**로 확인했다.

- `<kbd>` 27개 → `<span class="kbd">` / `<span class="tool-key">`. sanitizer 가 `<kbd>` 를 벗겨내면서
  **인접한 두 키의 글자가 붙어버리던 문제**가 함께 사라진다. CSS 는 `.shortcut-row kbd` → `.shortcut-row .kbd` 로만 바꿨다.
- SVG `stroke-width`·`stroke-linecap`·`stroke-linejoin` 속성(115건) → CSS. 이 화면만 아이콘마다 값이 제각각이라
  일괄 규칙으로는 재현되지 않아 `.stroke-round`·`.cap-round`·`.join-round` 토큰으로 원본과 1:1 로 맞췄다.
- 픽셀 대조 결과 **차이 0**.

### 지어낸 화면 문구 제거

사양의 `note`·`description` 은 "왜 그렇게 하는가"를 적는 자리인데, 그 설명문이 화면 문구로 올라와 있던 것을 뺐다.

- `완료본을 다시 건드립니다` (상단 바) — 사양이 정한 알림 수단은 **버튼 라벨 '재검수 제출'** 하나다.
  옆 캡션은 사양에 없고 말투도 내부 표현이다. 버튼은 그대로 두었고, 죽은 `.header-note` 규칙도 함께 지웠다.
- `라벨 선택(1~9)은 … 이 표에 싣지 않는다.` (단축키 안내) — 사양의 *지시문*이 그대로 노출됐다.
  사양은 모달 각 행의 숫자 배지가 직접 안내하게 한다.
- `좌표 (이미지 경계로 clamp)` → **`X/Y/W/H 좌표`** — 사양 label 로 되돌렸다. `clamp` 는 note 이자 개발 용어다.
- `PII 축 아님` 뱃지 (촬영환경) — 신고 게이트 제외 *근거*이지 화면에 붙일 표시가 아니다.
- `프레임 축과 입도가 다른 별개 축이라 두 값이 달라도 모순이 아닙니다` — 설계 근거절만 덜어내고
  `영상 단위 판정입니다.` 만 남겼다(프레임 축 패널의 대응 문장과 짝이 맞는다).
- `편집 가능한 항목(items 목록)만 …` / `검수큐에 노출되지 않고 …` / `일치도·기술정보를 저장 요청에 포함하면 거부됩니다.`
  — `items`·`검수큐`·`저장 요청` 은 API·파이프라인 어휘이고, 화면이 애초에 그 값을 보내지 않아 사용자가 위반할 수 없다.
