# 버전 비교·복구

## goal

버전 스냅샷을 현재 작업본 또는 다른 버전 스냅샷과 비교(diff)하여 차이를 표시하고, 선택 버전으로 복구(rollback)한다.

## actor

검수자(REVIEWER)

## title

버전 비교·복구

## status

draft

## priority

must

## main_flow

### [1]

- **step**: 1
- **action**: GET /v1/frames/{srcSn}/versions로 버전 이력을 조회한다

### [2]

- **step**: 2
- **action**: 버전 1건을 선택하면 GET /v1/versions/{version}/diff-with-working로 현재 작업본과의 차이를 요청한다

### [3]

- **step**: 3
- **action**: 버전 2건을 선택하면 GET /v1/versions/{version}/diff?compareWith={fromHash}로 두 스냅샷의 차이를 요청한다

### [4]

- **step**: 4
- **action**: 기준 스냅샷(LABEL_PAYLOAD)과 비교 대상을 앱에서 비교해 추가·수정·삭제 차이를 산출·표시한다

### [5]

- **step**: 5
- **actor**: 검수자(REVIEWER)
- **action**: POST /v1/versions/{version}/rollback(body srcSn)으로 복구한다

### [6]

- **step**: 6
- **action**: 대상 스냅샷 행을 재활성하고 라벨 본문을 작업본으로 복원하며 LS_DATA_LBL_HSTRY에 롤백 행위를 기록한다(새 버전 적층 아님, 멱등 시 no-op)

## description

★단일 선택 = 현재 작업본과 비교 (2026-08-05 사용자 확정). 버전 목록에서 커밋 1건만 선택하면 그 스냅샷과 현재 작업본(LS_DATA_LBL)의 차이를 산출한다 — 승인 버전이 1건뿐인 프레임은 두 버전 비교로는 대상이 없어 변경 내역을 아예 볼 수 없었다. 구 동작(1건 선택 = 목록상 직전 버전과 비교)은 폐기. 2건 선택 시 두 스냅샷 비교는 그대로 유지하며 기존 요청 계약(URL/파라미터/응답/상태코드)은 무변경이다. 작업본 payload 는 승인 스냅샷과 동일한 방식으로 구성해야 한다(같은 구성 인자, 라벨 식별자 오름차순, 같은 직렬화 경로) — 어긋나면 수정이 없는데 차이가 나오는 오탐이 생긴다. 읽기 전용이라 새 버전 행을 적층하지 않는다.

★비교축(R7) = 라벨 식별자, 라벨 형태, 라벨명, 라벨 마스터 식별자, 좌표, 트랙 식별자. 구 비교축(형태/라벨명/좌표 3개)에서는 트랙 병합처럼 시스템 자신이 수정 통지를 발행하고 학습데이터 산출물을 새 버전으로 재생성한 변경이 차이 비교에서는 변경 없음으로 보였다. 판정 축은 학습데이터 산출물 재생성 여부를 정하는 라벨 내용 해시의 입력과 합동으로 맞춘다(프레임 식별자만 제외). AI 보조 메타(자동 라벨 여부/신뢰도/출처)와 표시용 라벨명/색상은 의도적으로 제외한다 — 사람이 그 값만 바꾸는 편집 경로가 없고 신뢰도 부동소수는 잡음 차이를 만든다.

★롤백 시맨틱(ADR-009, 2026-07-30) — 대상 스냅샷 행을 재활성한다(새 버전 행을 적층하지 않음). 롤백 행위는 라벨 변경이력에 기록한다(누가·언제·어느 버전으로). 라벨 본문을 작업본으로 실제 복원하며 라벨 식별자·AI 보조 메타·트랙 식별자까지 보존 복원한다(점유된 식별자만 신규 발급 폴백). 멱등 롤백은 no-op — 현재 활성본이 이미 대상 스냅샷이면 라벨을 재작성하지 않고 이력·통지도 발행하지 않는다. (R2 UC-008, RQ-SFR-08-05)

### 손상된 버전 스냅샷

**steps**:

- 400으로 거부한다 — 빈 결과로 표시하면 화면에서 변경 없음으로 보여 거짓말이 되기 때문
- 두 버전 비교 경로의 장애격리(파싱 실패 시 빈 목록)는 기존 계약이므로 유지한다

- **trigger**: 작업본 비교 요청인데 스냅샷 payload의 라벨 목록이 배열이 아니다

### 비식별 누락 신고 구간

- **trigger**: 대상 영상이 비식별 재처리 대기 상태
