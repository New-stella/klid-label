# 라벨 버전 저장·이력 추적

검수 승인(APPROVED) 시점에 영상 단위 라벨 전체 스냅샷(JSON)을 해시 식별자와 함께 DB에 적재하고 변경이력을 기록한다.

## description

검수 승인(APPROVED) 시점에 영상 단위 라벨 전체 스냅샷(JSON)을 LS_LABEL_VERSION.LABEL_PAYLOAD에 적재하고 VERSION_HASH(payload SHA-256)로 식별한다(SAVE_REASON_CD='APPROVED'). 라벨 저장 시점에는 버전을 생성하지 않으며 — 학습데이터로 확정된 단위(검수완료)만 버전 대상이다. 외부 VCS(Gitea) 미사용 DB 스냅샷 방식. ★변경이력 모델 재정의(ADR-033, 2026-07-30) — 이와 별개로 '라벨 1건=1행' 부분 upsert 이력에서 '저장 이벤트 1회=1이벤트+diff(ADD/MDFCN/DEL_CNT, CHG_DTL_CN JSON)'로 전환됐다(V114, LS_DATA_LBL_HSTRY). 라벨 저장 시점에는 버전을 생성하지 않고 검수 승인 시점에만 학습데이터 버전(LS_LABEL_VERSION)이 생성된다는 2계층 구분은 그대로 유지된다 — 변경된 것은 '저장 이벤트' 자체의 이력 기록 방식이다(UC-021의 되돌리기 기능이 이 이력을 사용한다). ★검수 승인은 영상 1건을 한 트랜잭션으로 확정하되 스냅샷 행은 라벨을 가진 프레임마다 1건씩 쌓인다 — 한 영상이 한 행이 아니라 라벨 보유 프레임 수만큼이며, 같은 스냅샷인지는 프레임과 페이로드 해시의 짝으로 식별한다.
