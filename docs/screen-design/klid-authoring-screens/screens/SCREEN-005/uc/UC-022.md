## description

저작도구의 VLM 연동은 외부 VLM 서비스 호출로 시계열 정보를 획득하는 연동만 보유한다(VLM 본체는 외부 책임). VLM 서버가 콜백(POST /v1/vlm/callback)으로 결과 전송 → 결과를 LS_DATA_META 에 적재 + 검수큐(LS_DATA_META_REVIEW) 진입 → REVIEWER 가 라벨링 캔버스(SCREEN-005) 우측 시계열 메타 패널에서 검토·수정한다. ⚠ 구 전용 화면 'SCR-AUTO-002'(SCREEN-015, /auto/:videoId/meta)는 진입점 없는 orphan 이라 폐기(deprecated)되었고 SCREEN-005 로 완전 대체되었다. 승인(RVW_STTS_CD='APPROVED')된 메타만 V_COMPLETED_META 로 데이터마트에 노출된다.

[★위탁 규격 — UC-019(마킹) 쪽 제출 입력과 대칭] 위탁 엔드포인트는 서술(CoT) POST /v1/videovlm-klid/describe 와 질의응답(VQA) POST /v1/videovlm-klid/describe-sub 둘이다. 각각 별도 request_id 로 위탁하며, 콜백 바디에 어느 API 의 응답인지 식별하는 필드가 없으므로 request_id 로 위탁 원장을 역조회해 구분한다. 콜백 results 는 배열이 아니라 객체이며 {description} 단일이다 — 일치도(accuracy)와 검출여부(detected)는 검증(verify) 전용 응답 필드라 이 연동으로는 오지 않는다. 프레임 지정은 마킹 본문에서 프레임 인덱스를 얻으면 frame_selected 모드로 그것을 싣고, 하나도 얻지 못하면 frame_interval 모드로 내린다(빈 목록은 규격 위반이라 거부된다) — 마킹 모드는 그 인덱스를 누가 골랐는지만 가른다(수동이면 작업자가 지정한 프레임, 자동이면 간격으로 자동 선택된 프레임)(정렬·중복제거하며 상한 600, 음수 불가). 그리고 추출 간격이나 장수를 지정하는 필드는 두지 않는다 — 간격·장수는 외부 서비스가 관리한다. event_type(관제 인입값)은 미수신·미허용이어도 위탁을 막지 않고 그대로 실어 보내며 수용 여부는 벤더 응답이 정한다(거부되면 SKIP_REASON_SUBMIT_FAILED 로 기록하고 마킹을 VLM_REQUESTED→VLM_FAILED 로 전이시킨다). metaKey 규격은 서술 전문 키 vlm.description(≤2000, 검수큐 진입+편집 가능)을 두고, 레거시 구간 키(구 구간별 응답이 남긴 것)는 삭제하지 않고 읽기 전용으로 병기한다. 일치도 키(vlm.accuracy)는 두지 않는다 — 그 값이 수신되지 않으므로 화면 전용·검수큐 미진입·데이터마트 export 비대상이라는 규정도 규율할 대상이 없다.

[★결과 활용 — event_annotation 초안 자동채움] 서술(CoT) 결과와 질의응답(VQA) 결과는 event_annotation(VQA/CoT) 축의 초기 초안을 채우고 REVIEWER 가 검토·수정·승인한다. 자동채움은 신규 적재에만 적용하며 사람이 이미 수정한 값·승인 동결본·재검수 시맨틱은 건드리지 않는다.

[★위탁은 논블로킹 제출] 시계열 위탁 단계는 .block(45s) 로 파이프라인 스레드를 붙잡지 않고 subscribe() 로 제출만 개시한다(구 방식은 외부가 느려지면 core 2 짜리 배치 풀이 통째로 마른다). 수락(ACK) 여부는 완료 핸들러가 비동기로 원장·LS_BATCH_PROC_LOG 에 기록한다.

[미결 회수 — 임계가 두 개] ACK 창(stale-timeout, 기본 30분 — 수락 응답조차 못 본 건)과 콜백 창(callback-timeout, 기본 360분 — 벤더 분석은 영상 길이에 따라 수십 분 걸린다)을 구분한다. 하나로 덮으면 정상 위탁을 빼앗는다.

[신고 구간 보류·재위탁] 외부로 나가는 media.path 가 비식별본인데 신고는 바로 그 비식별본의 마스킹 실패를 뜻하므로, 신고 구간에는 위탁을 실패가 아니라 보류(SKIPPED + 사유 적재)한다. 보류는 스스로 재개되지 않으므로 해소 시 DeidentGateReopenedEvent(EVT-007) 를 신호로 그 SKIPPED 기록을 근거 삼아 재위탁한다(멱등 조건: 시계열 메타 0건). 이 배선이 없으면 시계열 메타가 영구 결손된다.
