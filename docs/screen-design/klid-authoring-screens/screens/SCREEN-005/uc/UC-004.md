# 객체 자동 추적

## goal

사용자가 지정한 객체를 이어지는 프레임에서 AI(SAM2)가 자동 추적하여 위치·경계를 갱신한다.

## main_flow

### [1]

- **step**: 1
- **actor**: 라벨링 작업자(WORKER)
- **action**: 시작 프레임에서 추적할 객체를 박스(bbox/시드)로 지정한다 (선행 전제)

### [2]

- **step**: 2
- **action**: POST /v1/frames/{srcSn}/sam2-track 으로 Sam2TrackRequest 를 송신한다 (path/body srcSn 불일치 시 400, 본인 미배정 프레임 IDOR 차단)

### [3]

- **step**: 3

### [4]

- **step**: 4
- **action**: ai-server SAM2 가 후속 프레임에 위치(BBox)·경계(폴리곤)를 전파·반환한다

### [5]

- **step**: 5
- **action**: 자동 라벨로 저장한다(AUTO_LBL_YN='Y', 좌표 실측 상한 검증 CWE-20)

### [6]

- **step**: 6
- **action**: 트랙 보간 알고리즘으로 빈 프레임을 채운다

### [7]

- **step**: 7
- **action**: 사용자가 키프레임을 확인·보정하고 저장한다

## description

라벨링 캔버스에서 작업자가 시작 프레임의 객체를 박스로 지정하면 SAM2 기반 비디오 객체 추적·분할(VOS)로 후속 프레임의 위치(BBox)·경계(폴리곤)를 추론·갱신하고(AUTO_LBL_YN='Y') 트랙 보간으로 빈 프레임을 채운다. 제약: 가림·장면전환·빠른 이동 시 정확도가 저하되며 사용자 키프레임 보정을 전제로 한다. 본인 미배정 프레임 접근은 IDOR 차단(LabelAccessGuard). 오토라벨링은 원본에만 실행하고 비식별본은 좌표를 공유한다. REQ-006(RQ-SFR-08-01)을 실현한다. ★추적 출력 형태 확정(ADR-040, 2026-07-30) — 추적 결과 형태는 선택 객체의 형태로 고정된다(박스로 지정→박스 추적, 폴리곤으로 지정→폴리곤 추적). 구 R12 '모달에서 독립적으로 형태를 선택해 추적' 설계는 폐기됐다 — 툴바·단축키(모달 미경유) 경로에서 trackShape가 undefined면 형태 지정이 생략돼 BE가 기본값(POLYGON)으로 강제 변환하던 결함이 이 고정 정책으로 해소됐다(FE: ObjectAttributePanel shape=shapeToDetectType(target.shape)??track.shape). 온디맨드 YOLO 트랙(POST /v1/frames/{srcSn}/yolo-track = API-123)도 동일 원칙을 따른다.
