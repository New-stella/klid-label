## goal

AI가 객체 외곽선을 인식해 바운딩박스/폴리곤을 경계에 자동 밀착(Snap)시킨다.

## main_flow

- **action**: 캔버스에서 SAM_SEGMENT 도구(단축키 G)로 객체를 클릭(포인트) 또는 드래그(박스)로 지목한다

- **action**: 응답 폴리곤을 이미지 실측 해상도 상한까지 좌표 검증(CWE-20) 후 Douglas-Peucker(POLYGON_SIMPLIFY_TOLERANCE)로 단순화한다

### [5]

- **step**: 5
- **action**: 밀착 결과를 캔버스에 적용한다 (mock 응답은 자동 적용 차단)

## description

대략 친 시드(클릭/박스)를 ai-server(SAM2 segment)에 프록시해 외곽선 기반 폴리곤+신뢰도를 산출하고 경계에 밀착시킨다. 구현: POST /v1/frames/{srcSn}/sam2-segment(Sam2SegmentService) — points/box 정확히 1개(@AssertTrue 배타, 400), SAM2는 원본 프레임 이미지에만 실행(비식별본 좌표 공유), 응답 폴리곤 좌표 실측 상한 검증(CWE-20) + Douglas-Peucker 단순화, mock 응답 FE 자동적용 차단, 이미지 상한 20MB(413). FE는 SAM_SEGMENT 캔버스 도구(단축키 G). MASK↔RLE↔Polygon 변환(CVAT 포팅)을 사용한다. (R2 UC-005, RQ-SFR-08-02)
