# 객체 외곽 경계 자동 밀착

## goal

AI가 객체 외곽선을 인식해 바운딩박스/폴리곤을 경계에 자동 밀착(Snap)시킨다.

## actor

라벨링 작업자(WORKER)

## title

객체 외곽 경계 자동 밀착

## status

draft

## priority

must

## frequency

상시 — 라벨링 중 객체를 한 번 지정할 때마다 실행하는 보조 기능이다.

## main_flow

### [1]

- **step**: 1
- **actor**: 라벨링 작업자(WORKER)
- **action**: 캔버스에서 SAM_SEGMENT 도구(단축키 G)로 객체를 클릭(포인트) 또는 드래그(박스)로 지목한다

### [2]

- **step**: 2
- **action**: POST /v1/frames/{srcSn}/sam2-segment 로 points 또는 box(정확히 1개)를 송신한다 (ai-server 로 프록시)

### [3]

- **step**: 3
- **action**: ai-server(SAM2)가 외곽선 기반 폴리곤+신뢰도를 산출·반환한다

### [4]

- **step**: 4
- **action**: 응답 폴리곤을 이미지 실측 해상도 상한까지 좌표 검증(CWE-20) 후 Douglas-Peucker(POLYGON_SIMPLIFY_TOLERANCE)로 단순화한다

### [5]

- **step**: 5
- **action**: 밀착 결과를 캔버스에 적용한다 (mock 응답은 자동 적용 차단)

## description

대략 친 시드(클릭/박스)를 ai-server(SAM2 segment)에 프록시해 외곽선 기반 폴리곤+신뢰도를 산출하고 경계에 밀착시킨다. 구현: POST /v1/frames/{srcSn}/sam2-segment — points/box 정확히 1개(배타 검증, 400), SAM2는 원본 프레임 이미지에만 실행(비식별본 좌표 공유), 응답 폴리곤 좌표 실측 상한 검증(CWE-20) + Douglas-Peucker 단순화, mock 응답 FE 자동적용 차단, 이미지 상한 20MB(413). FE는 SAM_SEGMENT 캔버스 도구(단축키 G). MASK↔RLE↔Polygon 변환(CVAT 포팅)을 사용한다. (R2 UC-005, RQ-SFR-08-02)
