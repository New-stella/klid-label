# 객체 외곽 경계 자동 밀착

## priority

high

## scenario

### then

- ai-server(SAM2)가 분할 폴리곤 + 신뢰도(score)를 반환한다
- 폴리곤 좌표는 이미지 실측 width/height 범위 상한까지 검증(CWE-20) 후 라벨로 적용한다
- mock 응답은 자동 적용을 차단한다(응답의 mock 플래그로 FE 가 구분)

### when

- 사용자가 캔버스에서 클릭(포인트) 또는 박스로 객체를 지목해 POST /v1/frames/{srcSn}/sam2-segment (API-093)로 요청한다

### given

- 인증되어 있고 본인 배정 대상 프레임(SRC_SN)이 존재한다

### and_examples

#### [1]

- **case**: 본인 배정이 아닌 프레임(IDOR)
- **result**: 403

#### [2]

- **case**: points/box 가 정확히 1개가 아님(둘 다 지정/둘 다 누락)
- **result**: 400(INVALID_INPUT, 배타 검증)

#### [3]

- **case**: 추론 호출 실패
- **result**: EXTERNAL_API_ERROR · 기존 시드 유지

사용자가 캔버스에서 클릭/박스로 객체를 지목하면 sam2-segment(API-093)가 SAM2 분할 폴리곤과 신뢰도를 반환하고 좌표 검증 후 라벨에 적용한다
