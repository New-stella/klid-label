# 영상 학습데이터 가공(라벨링·메타·VLM 시계열 메타 검수)

## priority

high

## scenario

### then

- 라벨·메타·승인된 시계열 메타(RVW_STTS_CD='APPROVED')가 부여되고 검수 승인 시 학습데이터로 확정된다
- 검수큐에 진입해 검토 대상이 되는 시계열 메타는 서술 전문 단일 항목이며, 일치도 항목은 존재하지 않는다
- event_annotation 초안 자동채움은 신규 적재에만 적용되어 사람이 이미 수정한 값과 승인 동결본을 덮어쓰지 않으며, REVIEWER 가 검토·수정·승인한 값만 학습데이터에 실린다

### when

- 작업자가 라벨·메타를 부여하고 외부 VLM 시계열 메타를 REVIEWER가 검토·수정·승인하고 검수한다
- 신규 적재된 외부 VLM 시계열 분석 결과로 시스템이 event_annotation(VQA/CoT) 축의 초기 초안을 자동채움한다

### given
