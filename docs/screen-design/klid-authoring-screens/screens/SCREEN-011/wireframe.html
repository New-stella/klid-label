① 헤더 (제목·새로고침)

설명

좌측 '대시보드' 제목(부제 '시스템 요약 정보를 확인할 수 있습니다.'), 우측에 '새로고침' 버튼(마지막 새로고침 시각을 정적 텍스트로 병기, 클릭 시 요약·영상·작업 쿼리 재조회).

Components

  • Heading(대시보드)
  • Button(새로고침)
×

② KPI 카드 그리드 (역할별)

설명

역할별 카드 수 분기 — WORKER 4카드(처리 대기/처리 완료/내 작업/반려 건수), REVIEWER 3카드(내 작업 제외). 로딩 시 Skeleton. 값은 /stats/summary 응답(pendingCount/completedCount/myTaskCount/rejectedCount).

Components

  • Stat(처리 대기) · → API-055
  • Stat(처리 완료) · → API-055
  • Stat(내 작업) · → API-055
  • Stat(반려 건수) · → API-055
  • Skeleton(로딩 ×3|4)

API

  • API-055
×

③ 데이터 개수 카드 (이미지·영상, 이벤트 분포)

설명

2열 카드. '이미지 데이터 개수'(주 수치 approvedImageCount 장, 보조 '검수완료 기준 · 전체 N장(완료율 X%)') + '영상 데이터 개수'(주 수치 approvedVideoCount 건, 동일 보조 패턴). 각 카드 하단에 검수완료 기준 이벤트 분포(approvedImageDistribution/approvedEventDistribution)를 개수 무관하게 그대로 순회 렌더. 모두 /stats/summary 응답.

Components

  • Card(이미지 데이터 개수) · → API-055
  • Card(영상 데이터 개수) · → API-055
  • List(이벤트 유형 분포 (개수 가변))

API

  • API-055
×

④ 최근 완료 영상 테이블

설명

정렬=reviewCompletedAt desc + 필수 필터 reviewStatusCd=APPROVED 조합으로 상위 5건 영상 목록(useVideos size=5, /videos). 컬럼: CCTV명/이벤트(EventTypeBadge)/길이(formatDuration)/완료일(MM-DD HH:mm). 빈 상태 '영상이 없습니다.', 로딩 Skeleton.

Components

  • Table(CCTV명/이벤트/길이/완료일) · → API-042
  • Badge(EventTypeBadge 이벤트 배지)
  • Skeleton(로딩)

API

  • API-042
×

⑤ 내 작업 현황 테이블 (WORKER 한정)

설명

WORKER 역할에서만 렌더. 본인 배정 작업 상위 5건(useTasks workerId=본인 size=5, /assignments). 컬럼: 영상/상태(StatusBadge)/진행률(ProgressBar — COMPLETED 100·IN_PROGRESS 50·그 외 0). 빈 상태 '작업이 없습니다.', 로딩 Skeleton.

Components

  • Table(영상/상태/진행률) · → API-072
  • Badge(StatusBadge 작업 상태)
  • Progress(ProgressBar 진행률)
  • Skeleton(로딩)

API

  • API-072
