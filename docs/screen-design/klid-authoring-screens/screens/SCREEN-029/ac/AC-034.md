# 비식별 영상 부재 시 다운로드는 라벨·이미지만 담는다

## notes

비식별 영상 경로 조달은 영상 재생 경로와 같은 축(비식별 처리 로그 LS_DEIDENT_PROC_LOG 의 최신 성공 이력에 적재된 DE_IDNTF_FILE_PATH_NM)이어야 하며, 원본 폴백 금지는 포털 채널의 구속 정책과 동일하다. 이 금지는 압축 산출물에 담기는 파일뿐 아니라 어노테이션 문서가 가리키는 경로에도 함께 적용된다 — 파일을 담지 않아도 경로가 실리면 원본의 위치가 외부로 나가기 때문이다.
