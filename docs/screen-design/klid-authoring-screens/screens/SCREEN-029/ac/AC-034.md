# 비식별 영상 부재 시 다운로드는 라벨·이미지만 담는다

## notes

비식별 영상 경로 조달은 VideoStreamService.resolveDeidPath 와 동일 축(LS_DEIDENT_PROC_LOG.DE_IDNTF_FILE_PATH_NM 최신 SUCCESS)이어야 하며, 원본 폴백 금지는 이 프로젝트의 구속 정책과 동일하다.

## priority

critical

## scenario

### then

- 200 과 함께 ZIP 이 반환된다
- ZIP 안에 video.* 파일이 없고 labels.json 과 frames/* 만 존재한다

### when

- 다운로드를 요청한다

### given

- 데이터마트 노출 영상에 본인 저장 라벨이 있다
- 이 영상은 비식별 처리 로그(LS_DEIDENT_PROC_LOG)에 최신 성공 이력이 없다

### and_examples

#### [1]

- **case**: 원본(비식별 이전) 영상으로 대체하려는 시도
- **result**: 어떤 경우에도 원본 폴백이 일어나지 않아야 한다(비식별 정책 구속력 대상)

## statement

다운로드 대상 영상에 비식별 영상 파일이 없으면 ZIP 에 영상 파일 없이 라벨과 이미지만 담기며, 원본 영상으로 대체되지 않는다
