## description

포털은 데이터마트 영상 선택 전용 채널(ADR-013 — 오토라벨링(YOLO/SAM2)·VLM·버전관리·검수 미제공). 관제서버→데이터마트→포털 DB 적재(관제 책임), 저작도구는 포털 DB 에서 Load 한다. 저장 시 원본·데이터마트를 수정하지 않고 사용자별 작업 데이터로 LS_PORTAL_USER_LABEL 에 별도 적재한다(단방향, 마트 반영 안됨). 다운로드는 사용자 작업 데이터 기준·본인 데이터 기간 내. 반응형 웹(PC/태블릿/모바일), WCAG 2.1 AA. JWT 는 포털 서버 발급이며 동일 검증 로직(channel 클레임 분기)을 쓴다.

[★SAM2 는 포털에 제공하지 않는다 — 구 서술 폐기] 구 본문은 「SAM2 분할·추적(POST /v1/portal/frames/{srcSn}/sam2-segment|sam2-track = API-130/131)은 2026-07-20부터 예외적으로 노출된다」고 적었으나 폐기됐다. 코드 실측상 sam2-segment/sam2-track 매핑은 LabelController 의 /v1/frames/{srcSn}/... 2건뿐이고 포털 전용 경로는 서버에서 제거됐다(PortalLabelService 는 프레임 이미지 서빙만 보유). FE 도 채널 분기를 두지 않는다. ADR-013 의 예외는 포털 자산 업로드(UC-027) 한 건이며 SAM2 예외는 없다. ✔ 후속 정리 완료(2026-08-06) — api_endpoint ITEM API-130·API-131 은 status=deprecated 로 전이됐고, DFEAT-044 의 implements 링크에서도 제거됐다(DFEAT-018 은 채널 오연결이라 내부 API-093 으로 재연결).

★1. 2026-07-30 재활성 — 화면(SCREEN-029, /portal/label/:id)이 계속 active 로 서빙 중이었음에도 본 UC 만 잘못 deprecated 처리되어 있었다(구 change_summary '신 R2(R1 항목 한정) 동기화 — R1 전용 요구사항 없는 운영 워크플로우 UC 분리'는 오판정으로 확인됨). ⚠ 단 본 UC 는 R1 기능 요구사항 대응이 없어 R2 유스케이스명세서 문서 범위에서는 제외된다(ITEM 자체는 유효).
