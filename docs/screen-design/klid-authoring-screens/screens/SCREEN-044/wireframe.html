① 증강 요청 현황

설명

본인이 낸 증강 요청을 최근 것부터 목록으로 보여 준다. 각 행에는 요청 일시, 대상 영상, 요청할 때 지정한 생성 조건, 요청 상태, 결과 확인 진입이 놓인다. [셋을 가르는 근거] 행이 함께 나르는 결과 도착 여부와 실패 사유로 판정하며 차례가 있다. 도착 여부가 참이면 결과 도착, 거짓이면서 실패 사유가 비어 있으면 결과 대기 중, 거짓이면서 실패 사유가 차 있으면 실패다. 어느 것에도 해당하지 않으면 결과 대기 중으로 둔다 — 모르는 상태를 도착으로 읽지 않는다. 서버가 내려주는 요청 상태 값 자체로는 가르지 않는다. 그 값역이 열려 있어 화면이 모르는 값이 오면 판정이 무너지기 때문이다. [목록 하나로 판정한다] 실패를 가려내려고 행마다 결과 확인 창구를 부르지 않는다. 세 구분에 필요한 것이 모두 행에 실려 있으므로 목록 조회 한 번으로 판정이 선다. [재조회] 결과 도착을 다시 확인하는 대상은 결과 대기 중인 요청뿐이다. 도착한 요청과 실패한 요청은 재조회 대상에서 빠지며, 대기 중인 요청이 하나도 없으면 재조회를 멈춘다. [실패한 행] 실패한 요청에는 후속 작업 진입과 내려받기를 노출하지 않는다. 목록에 나오는 요청은 본인이 낸 것뿐이며 대상은 본인이 올린 영상에 한정된다 — 데이터마트에서 불러온 영상은 대상이 아니다. 요청을 거는 자리는 이 화면에 두지 않으며, 새로 증강을 걸려면 포털 업로드 화면(SCREEN-033)의 자산별 액션을 쓴다.

② 증강 결과 확인

설명

요청 현황 목록에서 고른 요청의 결과물을 확인한다. 결과가 도착한 요청만 내용을 보이며, 아직 결과 대기 중인 요청을 고르면 대기 중임을 알리고 결과 영역을 비워 둔다. 실패한 요청은 실패했다는 사실과 사유를 함께 보인다 — 목록에서 이미 셋이 갈린 뒤 들어오므로 이 구역이 실패를 처음 알리는 자리가 아니며, 여기서 보이는 사유는 목록에서 줄여 보인 것과 같은 값을 줄이지 않고 전문으로 보인 것이다. 생성 조건도 목록과 같은 규칙으로 보이되 줄이지 않는다 — 조건에 담겨 온 항목을 빠짐없이 보이고 화면이 모르는 항목도 이름과 값을 받은 그대로 이어 보인다. 결과물은 요청한 본인에게만 제공되며, 확인하는 것만으로 데이터마트와 원본이 바뀌지 않는다. 이 경로에는 검수가 없으므로 결과물을 채택·반려로 가르는 결정 단계를 두지 않는다 — 확인한 결과물은 그대로 후속 작업과 내려받기로 이어진다.

Components

  • KeyValue(요청 정보 (대상 영상 · 생성 조건 · 요청 일시 · 결과 도착 일시))

    생성 조건은 목록과 같은 규칙으로 보이되 줄이지 않고 전문을 보인다 — 아는 다섯 항목(시간대 · 계절 · 날씨 · 지형 · 심각도)을 그 차례로 놓고, 그 밖의 항목은 뒤에 이름과 값을 받은 그대로 이어 붙인다.

  • Image(증강 결과물 미리보기)
  • Text(결과가 아직 도착하지 않았습니다)

    결과를 기다리는 중인 요청을 골랐을 때만 보인다.

③ 결과물 후속 작업 진입

설명

확인한 증강 결과물에 라벨링 등 후속 작업을 이어서 하러 가는 자리. 라벨링 자체는 포털 라벨링 화면(SCREEN-029)이 수행하고 이 화면은 그리로 가는 진입만 갖는다 — 같은 작업을 두 화면에서 하지 않는다. 결과가 도착한 요청에만 진입을 노출하고, 결과 대기 중이거나 실패한 요청에는 노출하지 않는다. 목록 행에서도 마찬가지로 결과가 도착한 행에만 이 진입을 낸다 — 목록이 실패를 스스로 가릴 수 있게 되어 행 단위로도 같은 규정이 선다. 후속 작업에서 쓸 수 있는 라벨 도형은 바운딩 박스와 폴리곤 수동 라벨링뿐이며, 오토라벨링·SAM2 인터랙티브 분할·자동추적·키포인트·검수·버전관리는 이 경로에 없다.

Components

  • Text(후속 작업 범위 안내 (바운딩 박스·폴리곤 수동 라벨링만 제공))

④ 결과물 내려받기

설명

⑤ 요청이 없을 때

설명

증강 요청이 하나도 없을 때 목록 자리에 대신 놓이는 안내. 아직 요청한 증강이 없다는 사실과 증강을 걸려면 어디로 가야 하는지를 함께 보인다 — 요청 진입이 이 화면에 없으므로 빈 화면만 남으면 다음에 무엇을 할지 찾지 못한다. 유도 대상은 포털 업로드 화면(SCREEN-033)이며, 그 화면에서 준비가 끝난 본인 영상을 골라 증강을 요청한다.

  • Link(증강할 영상 고르러 가기)
