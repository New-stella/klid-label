라벨 이력 화면

히스토리(라벨 변경 이력·버전 비교/복구) 기능은 라벨링 캔버스 화면(SCREEN-005)의 헤더 진입 버튼이 여는 패널로 제공하며, 별도의 독립 페이지·라우트를 두지 않는다. 패널은 '저장 이력'과 '버전' 2개 탭으로 구성한다(기본 탭=저장 이력). 패널 상단에는 패널 제목과 패널을 접는 닫기(×)를 둔다. 저장 이력 탭은 저장(PUT) 1회 단위 변경(LS_DATA_LBL_HSTRY)을 보여주고 각 저장 시점으로 되돌리기를 제공하며, 버전 탭은 검수 승인 시점 스냅샷(LS_LABEL_VERSION) 비교와 복구(롤백)를 제공한다(DB 스냅샷 기반 버전관리). 패널은 진입 시점의 프레임 식별자를 화면 간 전달로 직접 받으므로 URL 파라미터 검증이 필요하지 않다. 접근: REVIEWER/WORKER.

① 버전 탭 — 커밋 목록

설명

이 섹션은 히스토리 패널의 '버전' 탭 내용을 다룬다(조회 전용 다른 탭은 '저장 이력 탭' 섹션 참조). 프레임(srcSn)의 라벨 버전 스냅샷 목록(최신순). 각 행: 체크박스 + shortHash(mono) + '최신' 배지(idx 0, 시간순 최신 커밋)와 '현재' 배지(isCurrent, 활성 스냅샷)를 각각 독립적으로 표시 — 롤백 이후에는 두 배지가 서로 다른 행에 붙을 수 있다(활성본이 시간상 최신이 아닌 과거 커밋으로 이동) + 커밋 메시지 + 작성자·committedAt. ★선택 규칙 — 커밋 1건 클릭 = 현재 작업본과 비교(GET /v1/versions/{version}/diff-with-working), 체크박스 2건 = 두 버전 비교(GET /v1/versions/{to}/diff?compareWith={from}). 두 모드는 상호 배타적이다. 승인 버전이 1건뿐인 프레임도 현재 작업본과의 비교로 변경 내역을 볼 수 있다. 버전 스냅샷은 검수 승인 시점에만 생성되고 라벨 저장은 스냅샷을 만들지 않으므로 이 목록에는 승인 이력만 담긴다. 프레임 전환 직후 stale 조회는 '현재 목록에 실재하는 해시만 조회'로 막고 단건·두건 두 축에 대칭 적용한다. 빈 목록 시 '아직 커밋된 버전이 없습니다'. 로딩=Spinner, 에러=ErrorState('버전 이력 조회 실패').

② 버전 탭 — 변경 내용 (Diff)

설명

이 섹션은 '버전' 탭에서 두 스냅샷(또는 스냅샷과 현재 작업본)을 비교할 때의 표시 방식을 다룬다. 선택한 버전과 비교 대상(현재 작업본 또는 다른 버전) 간 라벨 diff. type별 색상 분리: ADDED(추가/green)·MODIFIED(수정/yellow)·REMOVED(삭제/red). 각 행: [종류] + 프레임ID + objectId(mono) + 이전/이후 shape(BBOX 좌표·POLYGON 점수·KEYPOINT 관절 수·MASK 크기). ★비교축 = 라벨 식별자 · 라벨 형태 · 라벨명 · 라벨 마스터 식별자 · 좌표 · 트랙 식별자. AI 보조 메타·표시용 라벨명/색상은 의도적 제외. 변경 0건은 빈 목록이 아니라 '변경 없음' 안내를 띄우며, 렌더 분기가 미선택 → 로딩 → 에러 → 결과 순이라 조회 실패(비식별 신고 구간 412 등)가 '변경 없음'으로 잘못 표시되지 않는다. 작업본 비교 경로에서 스냅샷이 손상된 경우는 빈 결과가 아니라 400 이다.

③ 버전 탭 — 롤백

설명

이 섹션은 '버전' 탭의 롤백을 다룬다 — '저장 이력' 탭의 되돌리기와는 다른 축이다('저장 이력 탭' 섹션 참조). 단일 선택한 버전이 최신이 아닐 때만 '롤백' 버튼을 노출한다. 권한: REVIEWER 또는 WORKER(본인 배정만). 클릭 시 확인 다이얼로그. ★롤백 시맨틱 — 대상 스냅샷 행을 재활성한다(새 버전 행을 적층하지 않는다). 라벨 본문을 작업본으로 실제 복원하며 라벨 식별자·AI 보조 메타·트랙 식별자까지 보존 복원하고(점유된 식별자만 신규 발급 폴백), 롤백 행위(누가·언제·어느 버전으로)를 라벨 변경이력에 기록한다. 현재 활성본이 이미 대상 스냅샷이면 진짜 no-op 이다(라벨 재작성·이력·통지 모두 없음). 권한/hex 검증은 BE 가 수행한다. 승인 후 롤백은 학습데이터 산출물을 새 버전으로 전량 재생성하고 성공 이후 관제에 수정 통지를 보낸다. 다른 저장·AI 작업이 진행 중이면 롤백 버튼이 비활성화되고 툴팁으로 안내하며, 확인 다이얼로그 승인 시점에도 다시 검사해 그 사이 시작된 작업과 교차 실행되지 않도록 막는다(이중 방어 — 롤백은 서버측 라벨 재작성이라 저장 PUT 과 동시 실행되면 최종본이 결정되지 않는다).

④ 저장 이력 탭

설명

히스토리 패널의 '저장 이력' 탭(기본 탭) — 저장(PUT) 1회 단위 변경(LS_DATA_LBL_HSTRY)을 프레임 단위로 보여주는 화면이다. 좌측에 저장 이벤트 목록(최신순, 페이지네이션), 우측에 선택한 이벤트의 라벨별 변경 상세를 나란히 둔다. 각 저장 이벤트 행에는 '이 저장으로 되돌리기' 버튼을 둔다 — 그 저장 시점의 변경 내용을 현재 작업본에 되돌리며, 되돌린 내용은 다시 저장해야 확정된다(즉시 서버에 반영되지 않는다). 다른 작업이 진행 중이면 비활성화한다. 이것은 '버전' 탭의 롤백과 서로 다른 축이다 — 되돌리기는 작업본을 그 저장 시점 내용으로 되돌리는 편집이고, 롤백은 검수 승인 스냅샷을 되살리는 복구다. 목록이 비어 있으면 안내 문구를 보여준다.
