③ 게시글 본문

설명

상세 조회(API-096) 결과를 카드로 렌더. 헤더: 고정 배지(pinned), 발행상태 배지(REVIEWER 한정 — PUBLISHED→'발행', DRAFT→'작성중'), 제목 heading, 메타(작성자 writerName→regId 폴백/등록 regDt/수정 mdfcnDt — 조건부). 본문은 줄바꿈·긴 단어를 보존해 표시. 로딩 시 Skeleton, 오류/미존재 시 ErrorState.

Components

  • Badge(고정)

    notice.pinned 일 때만 노출. Pin 아이콘. amber. 텍스트 '고정'.

  • Badge(발행 / 작성중)

    REVIEWER 한정. pubStatus PUBLISHED→'발행'(green), DRAFT→'작성중'(gray)

  • Heading(공지 제목) · binds notice.title

    h1

  • KeyValue(게시 메타)

    조건부 표시: 작성자(writerName, 없으면 regId 폴백)·등록=regDt·수정=mdfcnDt(있을 때). 날짜·시각 형식으로 표시. — 발행일시(pubDt)는 API 응답에는 있으나 화면에 렌더되지 않는다.

  • Text(본문) · binds notice.content

    줄바꿈과 긴 단어를 그대로 보존해 표시

  • Skeleton(로딩 placeholder) · loading

    isLoading 시 제목+본문 스켈레톤

  • Alert(공지를 불러올 수 없습니다) · error

    ErrorState — error || !notice 시 표시 + 목록으로 버튼

⑤ 삭제 확인 모달 (REVIEWER)

설명

삭제 확인 다이얼로그 — 제목은 '공지 삭제', 본문은 '{제목} 공지를 삭제합니다. 이 작업은 되돌릴 수 없습니다.'. 확인하면 삭제(API-099)를 호출하고 그 공지의 첨부도 함께 정리되며, 완료 후 공지 목록으로 이동한다. 삭제가 진행되는 동안에는 진행 중 상태를 표시해 재지시를 막는다.

Components

  • Dialog(공지 삭제)

    AlertDialog 트리거='삭제' 버튼. 제목 '공지 삭제', 본문 '{공지제목} 공지를 삭제합니다. 이 작업은 되돌릴 수 없습니다.'

  • Button(삭제) · → API-099

    삭제 API 호출 → 성공 시 목록 화면으로 이동. 처리 중에는 버튼 비활성화

  • Button(취소)

    다이얼로그 닫기
