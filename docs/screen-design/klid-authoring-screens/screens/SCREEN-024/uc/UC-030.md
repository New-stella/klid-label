# 사용자 계정·역할 관리

## goal

REVIEWER가 사용자 목록을 검색·역할로 필터링해 조회하고 사용자의 역할(검수자/작업자/포털)을 변경한다.

## actor

검수자(REVIEWER)

## title

사용자 계정·역할 관리

## status

draft

## priority

should

## main_flow

### [1]

- **step**: 1
- **actor**: 검수자(REVIEWER)
- **action**: 사용자 관리 화면(/manage/users)에서 사용자 목록을 조회한다(GET /v1/users = API-001, 서버 페이징 20건/페이지, 정렬은 등록 순서 고정)

### [2]

- **step**: 2
- **actor**: 검수자(REVIEWER)
- **action**: 검색어(이름/이메일 부분일치)와 역할 필터(전체/검수자/작업자/포털)를 입력한 뒤 Enter 또는 검색 버튼으로 확정한다 — 확정 시에만 서버 재조회되고 1페이지로 리셋된다

### [3]

- **step**: 3
- **actor**: 시스템
- **action**: 각 행의 계정 활성 상태(활성/비활성) 배지를 표시한다 — 이 값은 외부 시스템(관제서버) 소유이며 이 화면에서 변경 대상이 아니다(읽기 전용)

### [4]

- **step**: 4
- **actor**: 검수자(REVIEWER)
- **action**: 행의 '수정' 버튼으로 사용자 정보 수정 모달을 연다(테이블 행 데이터 기반, 별도 단건 조회 없음)

### [5]

- **step**: 5
- **actor**: 검수자(REVIEWER)
- **action**: 역할(검수자/작업자/포털)을 선택하고 저장한다 — 역할 값만 PATCH /v1/users/{userNo}(API-004)로 전송한다(원래 값과 같거나 미선택이면 저장 버튼이 비활성화된다)

### [6]

- **step**: 6
- **actor**: 시스템
- **action**: 서버가 허용 역할(REVIEWER/WORKER/PORTAL_USER) 화이트리스트로 재검증하고 그 외 값은 400으로 거부한다

### [7]

- **step**: 7
- **actor**: 시스템
- **action**: 성공 시 안내 토스트를 표시하고 목록을 최신화한다

## description

REVIEWER가 사용자 목록을 검색(이름/이메일 부분일치)·역할(검수자/작업자/포털) 필터로 서버 조회하고, 행의 '수정' 모달에서 역할만 변경한다. 계정 활성/비활성 상태는 외부 시스템(관제서버) 소유값이라 이 화면에서는 읽기 전용 배지로만 노출되며 변경 대상이 아니다 — 과거 활성/비활성 토글 기능은 쓰기 권한이 외부 시스템으로 이관되며 폐기되었다(SCREEN-024 화면 사양의 [폐기] 표기 참조). 역할 변경은 서버가 허용 역할 화이트리스트로 재검증하며 그 외 값은 400으로 거부한다.
