# 이미 가진 역할을 다시 저장하면 아무것도 바뀌지 않는다

## notes

역할 기록이 아직 없는 사용자에게 처음 역할을 부여하는 것은 같은 값을 다시 적용하는 것이 아니므로 이 기준의 대상이 아니며 그때는 저장이 일어난다.
