# 사용자 관리는 검수자만 수행한다

## notes

이 기준이 다루는 것은 누가 수행할 수 있는가 하나다. 자기 자신의 정보를 조회하는 것은 역할과 무관하게 열려 있으므로 이 기준의 대상이 아니다.

## priority

critical

## scenario

### then

- 요청이 거부된다
- 다른 사용자의 정보가 응답에 담기지 않는다
- 역할 변경이 저장되지 않는다

### when

- 사용자 목록 조회나 다른 사용자의 역할 변경을 요청한다

### given

- 검수자가 아닌 역할로 인증을 마친 사용자가 있다

## statement

사용자 목록 조회와 단건 조회, 역할 변경은 검수자만 수행할 수 있다.
