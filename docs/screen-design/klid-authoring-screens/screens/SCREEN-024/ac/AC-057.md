# 허용 목록 밖의 역할 값은 저장에 이르지 못한다

## notes

걸러내는 자리를 요청 검증에 두는 것은 저장 계층이 외부에서 들어온 문자열을 그대로 받지 않게 하기 위해서다. 화면이 고를 수 있는 값을 제한하는 것과 별개로 서버가 다시 판정하며, 판정을 화면에만 두면 화면을 거치지 않은 요청이 그대로 통과한다.

## priority

critical

## scenario

### then

- 그 사용자의 역할은 요청 이전 값 그대로 남는다

### when

- 허용된 역할이 아닌 값을 담아 요청한다

### given

- 검수자가 관리자 패스워드로 연 유효창이 아직 유효하다
