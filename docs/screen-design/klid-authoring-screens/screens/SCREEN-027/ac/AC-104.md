# 서버가 다시 떠도 처리 도중이던 항목이 방치되지 않는다

## priority

critical

## scenario

### then

- 처리 도중이던 항목이 다시 집을 수 있는 상태로 되돌아가 남은 항목과 함께 이어 처리된다.
- 정해진 횟수를 넘게 다시 집힌 항목은 실패로 마감되어 영원히 맴돌지 않는다.
- 작업과 항목이 행으로 남아 있어 다시 뜬 뒤에도 조회 결과가 이어진다.
- 두 노드가 같은 항목을 동시에 집지 않는다.

### when

- 서버가 멈췄다 다시 시작한다.

### given

- 일괄 적재가 진행되는 도중이며 일부 항목이 처리 도중 상태다.

## statement

일괄 적재가 진행되는 도중 서버가 멈췄다 다시 시작해도 처리 도중이던 항목이 다시 집혀 이어지고, 정해진 횟수를 넘게 다시 집힌 항목은 실패로 마감된다.
