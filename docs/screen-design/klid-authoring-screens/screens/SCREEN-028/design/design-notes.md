# SCREEN-028 포털 내 작업 화면 — 디자인 노트

| 항목 | 값 |
|---|---|
| 대상 | SCREEN-028 포털 내 작업 화면 (`/portal`) |
| 골격 기준 | `screen_spec` SCREEN-028 **v32** |
| 디자인 시스템 | DS-001 KRDS Public (`_shared/design-system.md`) |
| 성격 | **전면 재작성**. 종전 시안은 사양이 여러 차례 바뀌기 전 판이라 네 섹션 중 셋이 현재 사양과 달랐다 |
| 기술 제약 | 무 JS · CSS-only, 셸 제외 |
| surface | `main` (page) |
| 셸 위치 | **포털 채널 셸(SHELL-002) 안** — 머리 영역·좌측 주 메뉴·푸터를 저작도구가 그리지 않는다 |
| 소비 API | `API-225`(내 저장 작업 목록) · `API-203`(작업 데이터 내려받기) |
| 접근 역할 | ROLE-003 PORTAL_USER |

## § 이번 재작성에서 바뀐 것

### 걷어낸 것

| 종전 섹션 | 걷어낸 이유 |
|---|---|
| ① Hero 제목 밴드 (서비스 제목 + 부제) | 서비스 제목은 외부 채널(Host)의 머리 영역이 이미 보여 주고, 화면 이름은 본문 상단 이동 탭의 활성 항목이 이미 말한다. **같은 말을 두 번 하게 된다** |
| ② 요약 KPI (영상 수 · 라벨링 완료) | 현재 사양에 없다 |
| ③ 이용 방법 카드 (라벨링 시작하기) | 현재 사양에 없다 |
| ④ 데이터마트 영상 목록 | **데이터마트에서 영상을 고르는 목록은 외부 채널이 자기 화면에서 제공한다.** 이 화면의 자리가 아니다 |

### 넣은 것

- **본문 상단 이동 탭** — 저작도구 목적지 셋(내 작업 · 내 업로드 · 증강)을 오간다.
- **내 저장 작업 표** — 대상 영상 / 저장 시각 / 만료 예정일 / 작업 네 열.

### 살린 것

상태 참고 패널의 **내려받기·만료·취소·실패 사유**는 종전 시안이 이미 잘 다루고 있어 그대로 가져왔다.
목록의 성격만 「데이터마트 영상」에서 「내 저장 작업」으로 바꿨다.

---

## § 셸 경계 (2026-09-02 확정, 구속)

**Host 가 머리 영역과 좌측 주 메뉴를 모두 소유하고, 저작도구는 그 아래 본문만 그린다.**
따라서 이 시안에는 머리 영역·좌측 레일·푸터가 **없다. 없는 것이 결손이 아니라 그 확정의 결과다**
— 정합 점검에서 누락으로 보고하지 말 것.

> ⚠ **이 축은 두 번 뒤집혔다.** 최초에는 Host 소유였고, 2026-09-01 에 「저작도구가 좌측 메뉴를
> 그린다」로 뒤집혔다가, 2026-09-02 에 다시 Host 소유로 확정됐다. 지금은 상대 설계와 같은 쪽으로
> 수렴한 상태다. **세 번째로 뒤집지 말 것.**

사용자 신원·로고·역할 배지도 두지 않는다 — Host 머리 영역이 이미 보여 준다.

## § 골격 대조 — 섹션 1개 · 컴포넌트 5개 전수

| 골격 | 컴포넌트 | 시안에서 그린 자리 |
|---|---|---|
| 내 저장 작업 목록 · role=main · layout=list | `Table`(대상 영상·저장 시각·만료 예정일·작업) | `.work-table` — 4열, 행 3개 |
| | `Button`(이어서 작업) · primary · → `/portal/label/{srcSn}` | `.work-actions` 좌측 primary |
| | `Button`(내려받기) · outline · `API-203` | `.work-actions` 우측 secondary |
| | `Button`(다운로드 취소) | 참고 패널 ③ — 내려받는 중일 때만 그 자리에 나타난다 |
| | `Text`(저장한 작업이 없습니다.) | 참고 패널 ② `.empty-box` |

시안 본문은 **정상 상태**를 그리고, 로딩·0건·내려받는 중·실패는 참고 패널에 모았다.
한 화면에 전부 그리면 어느 것이 기본 상태인지 읽히지 않기 때문이다.

## § 판단 — 이동 탭을 `tablist` 로 짜지 않았다

셸 사양은 이 영역을 `inline_tabs` / `style: tabs` 로 규정하고, 부품 카탈로그의 Tabs 는
`role=tablist/tab/tabpanel` 을 갖는다. **그러나 이 시안은 `nav` + 링크 + `aria-current="page"` 로 짰다.**

- 목적지 셋은 **서로 다른 경로**(`/portal` · `/portal/uploads` · `/portal/augment`)다.
- `tablist` 는 **같은 화면 안에서 패널을 바꿀 때** 쓰는 역할이라, 경로가 갈리는 이동에 쓰면
  화면낭독기 사용자에게 "패널이 바뀐다"고 알리고 실제로는 페이지가 통째로 바뀐다.
- 시각 표현(탭 모양)과 의미 구조(내비게이션)는 다른 축이며, 여기서 갈라야 하는 것은 의미 쪽이다.

> ⚠ **이건 사양과 시안이 어긋난 지점이다** — 부품 축(카탈로그 Tabs 재사용)과 접근성 축 중
> 어느 쪽을 따를지 판정이 필요하다. 시안은 접근성 쪽을 골랐고 그 근거를 여기 남긴다.

활성 항목은 **밑줄 2px 로만** 가른다. 채움 필을 쓰면 Host 의 좌측 레일 현재 항목 표시와
모양이 겹쳐 두 내비가 서로를 흉내 내는 것으로 읽힌다.

## § 만료 예정일 — 값이 없으면 자리를 비운다

- 표기는 `만료: YYYY-MM-DD` 로 **날짜까지만**. 시각은 표기하지 않는다.
- 값이 없는 행은 **빈 칸으로 둔다.** `없음`·`-` 를 지어내면 만료가 정해졌는데 표기만 빠진 것으로 읽힌다.
- 표는 열 너비가 고정이라 비어도 아래위 행의 정렬이 흔들리지 않는다 — 시안 2행이 그 경우다.
- **만료가 가까운 작업을 색·아이콘으로 강조하지 않는다**(사양이 명시 거부). 좁은 폭에서도
  열을 접지 않는 이유가 이것이다 — 열을 접으면 빈 칸이 사라져 「값 없음」이 「열 없음」으로 읽힌다.

---

## § 내려받기 — 한 번에 하나

- 받는 동안 **다른 행의 내려받기도 함께 잠긴다**(참고 ③).
- 취소는 **내려받는 중일 때만** 내려받기 버튼 자리에 나타난다.
- **사용자가 누른 취소는 오류가 아니라 정상 종료다** — 실패 안내를 띄우지 않으며 「전송 끊김」과
  한 갈래로 묶지 않는다. 묶으면 스스로 멈춘 사용자에게 연결을 확인하고 다시 시도하라고 권하게 된다.
- 인증이 필요해 직링크를 쓸 수 없다. 버튼이 응답을 받아 브라우저 내려받기를 일으킨다.

## § 접근성

- 표는 `th scope=col` / `th scope=row` 로 짜 각 칸의 소속이 읽히게 했고, `caption` 을 `sr-only` 로 뒀다.
- 이동 탭 항목은 최소 높이 48px(터치 타깃 44px 상회).
- 로딩·빈 상태는 `role=status`, 실패는 `role=alert`.
- 잠긴 버튼은 `disabled` 대신 상태에 따라 가르되, 사양이 잠금을 규정한 자리에서는 이유를 읽을 수 있게 둔다.

> ⚠ **게시본으로 접근성을 판정하지 말 것** — 게시 sanitizer 가 `scope` 와 `stroke-width` 를 지운다.
> 로컬 원본에는 있으므로 판정은 원본으로 한다. `stroke-width` 는 CSS 에도 같은 값을 선언해 두어
> 게시본에서도 아이콘 굵기가 유지된다.

## § 알려진 한계

- 표 본문은 **최소 720px** 이라 그 아래 폭에서는 가로로 굴린다(열을 접지 않는 이유는 위 만료 절).
- 페이저를 두지 않았다 — 현재 사양에 목록 페이징 규정이 없다. 서버가 페이지로 내려주기 시작하면
  옮길 수단을 함께 그려야 한다.
- `.alert-desc` 는 스타일 없는 후크 클래스다(종전 시안에서 그대로 이어받았다).
