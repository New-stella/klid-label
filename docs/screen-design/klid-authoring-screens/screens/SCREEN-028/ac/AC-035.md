# 데이터마트 다운로드는 본인 저장 라벨만 담는다

## notes

데이터마트 축은 rawSn 단위로 공유되는 자산이라 IDOR 방어 축이 '접근 가능 여부'가 아니라 '내용 격리'임을 명시한다 — loadFrameLabels/listMyLabels 와 같은 병합 정책 축.

## priority

critical

## scenario

### then

- ZIP 안 labels.json 에는 A 의 라벨만 담기고 B 의 저장 라벨은 포함되지 않는다

### when

- A 가 그 영상을 다운로드한다

### given

- 사용자 A, B 가 같은 데이터마트 영상의 같은 프레임에 각자 본인 작업 라벨을 저장했다

### and_examples

#### [1]

- **case**: A 가 저장하지 않은 다른 프레임
- **result**: 데이터마트 원본 라벨로 대체되며 B 의 저장분이 아니다

#### [2]

- **case**: 다른 사용자의 rawSn 을 직접 지정해 다운로드를 시도
- **result**: 데이터마트 노출 여부만 판단하며(소유권 개념 없음) 그 영상이 APPROVED 면 누구든 다운로드 자체는 가능하다 — 다만 내용은 호출자 본인의 저장분으로만 구성된다(다른 사용자의 작업 내용이 새지 않는다)

## statement

포털 사용자의 다운로드 결과에는 본인이 저장한 라벨만 포함되며, 다른 사용자의 저장 라벨은 노출되지 않는다
