## description

포털 사용자가 본인 이미지(jpg/jpeg/png, 20MB/장, 50장/요청, all-or-nothing)·영상(mp4/mov/avi, 5GB, TUS 1.0 재개 가능 업로드)을 직접 업로드해 수동 라벨링(BBOX/POLYGON만)한 뒤 본인 데이터(JSON export/원본)를 다운로드한다(ADR-013 예외, 2026-07-17). 업로드 자산은 신규 LS_PORTAL_* 테이블(LS_PORTAL_ULD·LS_PORTAL_ULD_FRME·LS_PORTAL_ULD_LBL·LS_PORTAL_TUS_ULD, V107/V108)로 내부 파이프라인(비식별→마킹→배치→검수)·데이터마트 View와 완전히 분리된다. 영상은 비식별 미적용(본인 데이터)이며 고정 간격 프레임 추출(portal.upload.frame-interval-sec 기본 5초, 상한 maxFrames 2000). 상태: UPLOADED→PROCESSING→READY|FAILED. 오토라벨링(YOLO/SAM2)·VLM·검수·버전관리는 미적용. 화면: 포털 업로드(/portal/uploads, SCREEN-033)·포털 업로드 라벨링(/portal/uploads/:uldSn/label, SCREEN-034) — 둘 다 LogiCraft screen_spec 에 등록되어 있고 realizes_use_cases 로 본 UC 와 연결돼 있다(2026-07-30 확인).
