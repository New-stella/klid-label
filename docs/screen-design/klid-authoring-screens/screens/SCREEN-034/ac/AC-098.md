# 포털 업로드 자산에는 자동 라벨링도 검수도 버전관리도 없다

## notes

이 부재는 빠뜨린 것이 아니라 정한 것이다. 포털 자산은 본인 데이터일 뿐 학습데이터로 확정되는 대상이 아니라서, 확정 절차인 검수와 버전관리를 두지 않는다. 이 기준은 그 부재를 기대 결과로 못박아 누락으로 읽고 채우는 것을 막는다.

## priority

medium

## scenario

### then

- 직접 그리는 경계상자와 폴리곤만 있다
- 자동 라벨링과 검수와 버전관리를 여는 수단이 없다
- 그 자산과 라벨은 내부 학습데이터 산출물에 포함되지 않는다

### when

- 그 화면에서 할 수 있는 일을 살펴본다

### given

- 포털 사용자가 자산을 올려 라벨링하고 있다

## statement

포털 사용자가 올린 자산은 사람이 직접 그리는 경계상자와 폴리곤만 다루며, 자동 라벨링과 분할 보조와 시계열 분석과 검수와 버전관리는 제공되지 않고 내부 학습데이터 경로로 흘러가지도 않는다.
