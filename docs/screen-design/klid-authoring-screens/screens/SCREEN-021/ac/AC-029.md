# 검수완료 기준 수치와 전체 수치 병기 정합

## priority

high

## scenario

### then

- 검수완료 기준 영상 누적 건수는 M 과 같고 처리 현황의 승인 건수와 동일 값이다
- 전체 누적 영상 건수는 검수 여부와 무관하게 N 과 같다
- 검수완료 기준 수치는 항상 대응하는 전체 수치 이하다
- 검수 상태 행이 없는(배정 전) 영상의 프레임은 검수완료 기준 이미지 집계에서 제외된다
- 검수완료 기준 이미지 건수와 프레임 단위 이벤트 분포는 폐기된 프레임을 세지 않으며, 전체 누적 이미지 건수는 폐기 여부로 걸러내지 않는다

### when

- 전체 구축 현황을 조회한다

### given

- 영상 N건 중 M건(M ≤ N)이 검수 승인(APPROVED) 상태다
- REVIEWER 로 인증되어 있다

### and_examples

#### [1]

- **case**: 승인 영상이 0건인 경우
- **result**: 검수완료 기준 영상·이미지 건수가 0이고, 검수완료 기준 이벤트 분포는 전 카테고리가 0건으로 표시된다(카테고리 자체는 계속 노출)

#### [2]

- **case**: 검수 상태 행이 아직 생성되지 않은(배정 전) 영상
- **result**: 검수완료 기준 집계에서는 자연 제외되지만 전체 누적 집계에는 포함된다

#### [3]

- **case**: 승인 영상 안에 폐기된 프레임이 있는 경우
- **result**: 그 프레임은 검수완료 기준 이미지 건수와 프레임 단위 이벤트 분포에서 빠지고 전체 누적 이미지 건수에는 남는다

## statement

검수완료(APPROVED) 영상만 집계한 확정 기준 수치는 검수 여부와 무관한 전체 수치 이하이고, 배정 전(검수 상태 행 없음) 영상은 확정 기준 집계에서 자연 제외되며, 승인 영상 안의 폐기된 프레임은 확정 기준 이미지·프레임 분포 집계에서 제외된다
