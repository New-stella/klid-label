# 이벤트 유형 표시명 그룹 축 집계

## priority

high

## scenario

### then

- 표시명이 같은 상세코드들의 영상 수는 대표코드(그룹 내 최소 유형코드) 한 칸으로 합산된다
- 그룹의 비대표코드는 응답에 별도 칸으로 노출되지 않는다
- 비수집 코드나 제외 대분류 코드의 영상은 어떤 칸에도 합산되지 않는다
- 데이터가 없는 카테고리도 0건으로 포함되어 노출된다

### when

- 이벤트 유형 분포를 조회한다

### given

- 표시명이 같은 상세 이벤트 유형코드가 2개 이상 존재하고, 그중 일부 영상에 각 코드가 매겨져 있다
- REVIEWER 또는 WORKER 로 인증되어 있다

### and_examples

#### [1]

- **case**: 검수완료 기준 이벤트 분포
- **result**: 전체 기준 분포와 카테고리 구성·순서가 동일하고, 검수완료(APPROVED) 영상만 집계한다

## statement

표시명이 같은 상세 이벤트 유형코드들의 영상 수는 대표코드 한 칸으로 합산되어 조회되며, 비수집·제외 대분류 코드는 어떤 칸에도 합산되지 않는다
