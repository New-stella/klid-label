② 누적 학습데이터 2카드

설명

누적 이미지/누적 영상 2개 카드 — 주 수치는 검수완료(approvedImageCount/approvedVideoCount), 보조로 전체(cumulativeImageCount/cumulativeVideoCount)와 완료율 텍스트를 병기한다(예: '검수완료 기준 · 전체 1,000장 (완료율 42%)'). 시각적 진행바 요소(role=progressbar, <progress>)는 렌더하지 않는다 — 완료율은 텍스트로만 표기.

Components

  • Stat(누적 이미지) · binds overall.approvedImageCount

    주 수치=approvedImageCount(검수완료 기준, 장). 보조 텍스트 '검수완료 기준 · 전체 {cumulativeImageCount}장(완료율 N%)'.

  • Stat(누적 영상) · binds overall.approvedVideoCount

    주 수치=approvedVideoCount(검수완료 기준, 건). 보조 텍스트 '검수완료 기준 · 전체 {cumulativeVideoCount}건(완료율 N%)'.

③ 처리 현황 카드

설명

카드 1개로 구성 — 헤더에 '처리현황' 제목과 우측 '전체 N건' 텍스트, 본문에 가로 스택형 진행바(완료/처리중/대기/실패 4구간, 폭=비율) + 하단 4항목 범례 리스트(각 항목 색상점+라벨+건수+비율%). 개별 카드 5개·grid-cols-5 레이아웃이 아니다.

Components

  • Stat(전체)

    카드가 아니라 섹션 헤더 우측 텍스트로 표시('전체 N건') — 완료+처리중+대기+실패 4구간 합계.

  • Stat(완료)

    스택형 진행바 1구간(성공색) + 하단 범례 항목(건수+비율%). 값=processing.approved.

  • Stat(처리중)

    스택형 진행바 1구간(정보색) + 범례. 값=processing.inProgress+processing.reviewPending 합산.

  • Stat(실패)

    스택형 진행바 1구간(위험색) + 범례. 값=processing.rejected.

  • Stat(대기)

    스택형 진행바 1구간(중립색) + 범례. 값=processing.pending.

  • Progress(처리현황 스택 바)

    가로 스택형 진행바 — 완료/처리중/대기/실패 4구간을 각 값/전체 비율(%)만큼 폭으로 표시. 4구간 합이 0이면 바를 렌더하지 않는다.

API

  • API-057
