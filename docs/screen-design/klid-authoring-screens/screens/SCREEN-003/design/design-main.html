접근 거부 화면

역할 또는 채널 기준의 접근 제어를 통과하지 못했을 때 표시되는 안내 화면입니다. 서버를 호출하지 않고 화면에 저장된 역할 값만 읽어 표시합니다.

1기본 화면 — 검수자 역할로 접근이 막힌 경우

이 화면에 접근할 수 없습니다

현재 역할로는 이 페이지에 접근 권한이 없습니다.

현재 역할 검수자

참고 '현재 역할' 자리에 들어가는 배지입니다 — 화면에 저장된 역할 값에 따라 이 중 하나가 표시되며, 역할 값이 없으면 미배정으로, 아는 값이 아니면 받은 값을 그대로 보여줍니다.

① 관리자

관리자 사용자 관리와 연동 설정을 담당하며, 검수자 권한을 계층으로 물려받습니다.

② 검수자

검수자 작업 배정과 검수 승인·반려, 시스템 설정을 담당합니다.

③ 작업자

작업자 영상에 라벨을 만들고 수정해 검수를 요청하는 역할입니다.

④ 포털

포털 포털 전용 화면은 역할과 채널 두 제어를 함께 통과해야 합니다.

⑤ 미배정

미배정 역할 값이 없을 때입니다 — 넷 중 하나로 임의로 채우지 않습니다. 조치가 필요한 상태라 경고 아이콘을 병기합니다.

⑥ 아는 역할이 아닌 경우

받은 값 그대로 이름이 정해지지 않은 역할 값은 지어내지 않고 받은 값을 그대로 노출합니다. '역할 없음' 과는 다른 사실이라 미배정과 같은 표시로 합치지 않습니다.
참고 이 화면으로 오게 되는 경로입니다. 화면에 보이는 요소는 아닙니다.
  • 역할 기준 접근 제어를 통과하지 못한 경우 — 그 화면이 요구하는 역할을 갖고 있지 않습니다.
  • 채널 기준 접근 제어를 통과하지 못한 경우 — 내부 사용자가 포털 전용 화면에 들어가려 한 경우가 여기에 해당합니다.
