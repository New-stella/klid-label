# 라벨 마스터를 고치면 그 라벨을 쓰는 프리셋에 즉시 반영된다

## notes

복사해 두면 마스터와 프리셋이 서로 다른 값을 갖게 되고, 어느 쪽이 맞는지 판정할 근거가 사라진다. 형태를 프리셋마다 따로 켜고 끄게 하면 같은 라벨이 프리셋에 따라 다른 도형으로 그려져 학습데이터가 섞인다.

## priority

critical

## scenario

### then

- 기존 프리셋들이 바뀐 이름과 형태로 보인다
- 프리셋을 다시 저장하지 않아도 반영된다
- 형태는 마스터가 정한 값이며 프리셋에서 따로 바꿀 수 없다

### when

- 그 라벨의 이름과 형태를 마스터에서 바꾼다

### given

- 어떤 라벨이 프리셋 여러 곳에 담겨 있다

## statement

프리셋은 라벨의 이름과 형태를 자기 안에 복사해 두지 않고 마스터를 그때그때 참조하므로, 마스터에서 이름이나 형태나 색을 바꾸면 새로 만드는 프리셋과 이미 있던 프리셋 모두에 곧바로 반영된다.
