# 라벨 클래스·속성 정의 관리

## goal

라벨 마스터(LS_LABEL)와 속성 정의(LS_LABEL_ATTR)를 CRUD하여 프리셋·오토라벨·라벨링 화면 전체가 참조하는 단일 진실원을 유지한다

## actor

검수자(REVIEWER)

## title

라벨 클래스·속성 정의 관리

## status

approved

## priority

should

## main_flow

### [1]

- **step**: 1
- **actor**: 검수자(REVIEWER)
- **action**: 관리 화면(/manage/labels, SCREEN-035)에서 라벨 마스터 목록을 조회한다(GET /v1/manage/labels = API-024)

### [2]

- **step**: 2
- **actor**: 검수자(REVIEWER)
- **action**: 라벨을 신규 등록한다(라벨명·형태 LBL_TYPE_CD·COCO 검출클래스 매핑 DTCT_TYPE_CD, POST /v1/manage/labels = API-025)

### [3]

- **step**: 3
- **actor**: 검수자(REVIEWER)
- **action**: 기존 라벨을 수정한다(PUT /v1/manage/labels/{id} = API-026) — 형태·매핑 변경은 프리셋에 즉시 반영(LBL_ID FK join)

### [4]

- **step**: 4
- **actor**: 검수자(REVIEWER)
- **action**: 속성 정의를 CRUD한다(GET/POST/PUT/DELETE /v1/manage/labels/{labelId}/attrs = API-028~031)

### [5]

- **step**: 5
- **actor**: 검수자(REVIEWER)
- **action**: 라벨을 삭제한다(DELETE /v1/manage/labels/{id} = API-027) — 미연결 프리셋은 오류 없이 '미연결' 표시

## description

REVIEWER가 라벨 마스터(LS_LABEL: 라벨명·형태 LBL_TYPE_CD·COCO 검출클래스 매핑 DTCT_TYPE_CD)와 속성 정의(LS_LABEL_ATTR)를 CRUD한다. 라벨 프리셋(LS_LABEL_PRESET_CODE)은 라벨명·형태를 스냅샷 저장하지 않고 LBL_ID FK로 마스터를 실시간 join하므로(ADR-034) 여기서 라벨명·형태를 바꾸면 신규·기존 프리셋에 즉시 반영된다. 형태는 마스터 LBL_TYPE_CD가 소유하며 프리셋에서 개별 토글할 수 없다. AI 탐지 후보는 이 마스터 목록 기준으로 노출하되 DTCT_TYPE_CD가 매핑된 라벨만 실제 검출 가능(미매핑은 표시만, 선택 불가). 마스터에 매칭 안 되는 기존 코드(labelId null/비활성)는 오류 없이 '미연결'로 표시한다(자동 생성/삭제 없음). 1차 관리자매뉴얼 §4.1.3/§4.1.4 갭을 해소하는 관리 화면(SCREEN-035, /manage/labels, REVIEWER 전용)이다.
