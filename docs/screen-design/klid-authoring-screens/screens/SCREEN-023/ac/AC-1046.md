## statement

외부 서비스가 POST /v1/genai/callback로 증강 결과를 보내면(중복 방지 식별자 포함) 시스템이 회신을 검증하고 원본 참조를 확인한 뒤(부모 게이트는 DE_IDNTF_YN='N'만 막고 'F'는 통과) 새 영상(RAW_SN)을 생성해 ORGNL_RAW_SN에 원본을 연결하고, 부모의 비식별 영상 파일을 파생 전용 경로로 실제 복사해 그 경로를 파생 RAW_FILE_PATH_NM으로 기록한다(복사 원본은 LS_DEIDENT_PROC_LOG.DE_IDNTF_FILE_PATH_NM 값을 읽어 정하고 부모 원본 경로로 대체하지 않음). 원본 라벨/메타 JSON을 복사해 좌표·속성을 보존하고, 증강 축(AUGMENT 및 구 WINTER/NIGHT/RAIN)은 해상도 동일이라 좌표 미변환이며(ADR-059), 촬영환경·개인정보 판정 메타를 생성 시점에 부모 값으로 1회 계승한 뒤(이후 부모 정정 미재전파 스냅샷) 새 영상을 미검수(PENDING)로 적재한다.
