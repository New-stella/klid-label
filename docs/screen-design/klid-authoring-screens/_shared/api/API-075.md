[통지는 검수 완료가 기준이다] 완료 통지는 검수 승인 시점에, 수정 통지는 그 뒤의 수정에만 발행되므로 이 경로가 향하는 대상은 검수 완료된 영상이다.

라벨 본문은 개인정보의 위치를 특정하므로 비식별 누락 신고 구간에는 412 로 차단된다. 반면 산출 폴더 경로와 데이터마트 적재용 뷰는 별도 채널이라 그 차단의 대상이 아니다.
