## description

주어진 폴더와 그 아래를 재귀로 훑어 마킹 문서와 영상의 짝을 찾고, 무엇이 몇 건 들어오는지와 건별 검사 결과를 돌려준다. 이 단계에서는 아무것도 저장하지 않는다. 같은 요청을 여러 번 보내도 결과가 같다.

짝짓기 기준은 폴더 구조가 아니라 마킹 문서가 스스로 적어 둔 영상 파일 이름이다. 문서와 영상이 서로 다른 자리에 놓여 있어도 같은 이름을 찾으면 짝이 된다. 같은 이름의 영상이 둘 이상이면 어느 쪽인지 정할 수 없으므로 그 항목은 짝을 찾지 못한 것으로 다룬다.

훑는 깊이와 항목 수에는 상한이 있다. 상한에 걸리면 조용히 자르지 않고 일부만 훑었다는 사실을 함께 알린다. 폴더 안의 바로가기는 따라가지 않고 건너뛴다. 따라가면 허용된 저장소 범위 밖을 읽게 되기 때문이다.

이 기능은 사람이 영상을 직접 적재하는 경로가 켜져 있을 때만 노출된다. 꺼져 있으면 이 계약 자체가 없다.
