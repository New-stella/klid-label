## description

본인 업로드 자산의 원본 파일을 다운로드한다. DB 확정 MIME + nosniff + Content-Disposition: attachment. 원본 파일명은 제어문자 제거 후 RFC 5987 filename* + ASCII fallback 병기로 CRLF 헤더 인젝션(CWE-113)을 차단한다. 저장 경로 미확정(추출 미완료/이상 자산) 또는 파일 부재 시 404.

자산이 영상이면 원본 파일이 매우 커질 수 있다. 요청 제한시간은 그 크기를 끝까지 받아낼 수 있는 값이어야 한다 — 일반 조회용 기본 제한시간을 그대로 쓰면 큰 자산은 받을 방법이 없다. 이 값은 설정으로 조정하며, 요청이 지나는 경로 중 가장 작은 상한이 실제 상한이 되므로 경로 전체에서 함께 맞춘다. 산출물 구성이 달라 작업 데이터 묶음 다운로드와 하나의 값으로 묶지 않고 경로마다 따로 둔다. 내려받는 도중 사용자가 중단해 클라이언트가 연결을 끊으면 서버는 남은 전송을 이어가지 않고 그 시점에 멈춘다. 중단은 실패가 아니므로 서버 오류로 다루지 않는다.
