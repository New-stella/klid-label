## description

배치 파이프라인이 실패로 고착된 영상을 검수자가 수동으로 재기동한다. 실패 상태가 아닌 영상은 409 로 거부되며, 자동 재시도 큐와 동일한 재실행 경로를 재사용한다. 응답은 201 이 아니라 200 이며 재기동을 접수했다는 사실과 접수 시점의 단계(stage)를 반환한다. ★파이프라인 실행 자체는 응답을 기다리지 않는다 — 실패 상태를 선점하는 것까지만 요청 안에서 처리하고 실제 실행은 비동기로 넘긴다. 파이프라인 한 건은 프레임 추출과 외부 추론을 포함해 수 분 이상 걸리므로, 완료를 기다리면 클라이언트 타임아웃에 먼저 걸려 정상 재기동이 실패로 보이고 요청 스레드도 그동안 묶인다. 진행 상황은 영상 상세 조회의 단계 표시로 확인한다. 재기동은 파이프라인을 처음부터 순회하되 이미 성공한 단계는 산출물이 실재하면 다시 수행하지 않으므로, 실질 작업은 실패한 단계부터 이어진다. 따라서 같은 영상을 여러 번 재기동해도 앞 단계의 프레임·자동 라벨·외부 위탁이 중복되지 않는다.
