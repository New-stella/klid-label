## description

비식별 누락 신고 목록을 상태(status=OPEN|RESOLVED|DISMISSED)로 필터링해 페이징 조회한다. 기본 status=OPEN, 기본 정렬 reportDt DESC, 기본 size=20. REVIEWER 전용(@PreAuthorize hasRole('REVIEWER')). status allowlist(OPEN|RESOLVED|DISMISSED) 밖 입력은 400. 응답은 ApiResponse<Page<DeidentReportListResponse>>(각 행: rprtSn·rawSn·reporterNo·reason·reportDt·status·resolvedDt). REQ-014(RQ-SFR-09-03)·UC-016 연결. 해소 처리는 API-094(POST .../resolve).
