## description

라벨링 프리셋 목록을 조회한다. REVIEWER 전용.

[프리셋이 실효하는지도 함께 내려준다] 프리셋에 담긴 라벨이 전부 AI 검출 클래스에 매핑돼 있지 않으면 그 프리셋은 존재하지만 아무것도 거르지 못하며, 그 이벤트 유형의 오토라벨링은 보류된다(ADR-054). 그 사실이 조회에 드러나지 않으면 운영자는 프리셋을 등록해 놓고도 왜 적용되지 않는지 알 수 없으므로, 프리셋마다 실효 여부를, 라벨마다 검출 클래스 매핑 여부를 함께 싣는다.

[판정은 한 곳에서만 한다] 실효 여부는 오토라벨 보류 판정과 같은 판정을 재사용해 얻으며 이 엔드포인트가 다시 유도하지 않는다. 매핑을 소유하는 것은 프리셋이 아니라 라벨 마스터이므로, 마스터에서 매핑을 지정하면 그 라벨을 담은 기존 프리셋들이 함께 실효해진다.
