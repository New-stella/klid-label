## description

프레임 단위 라벨 전체를 일괄 upsert한다(전체 교체 의미론). 작업본(임시저장)만 수행하며 버전 스냅샷은 생성하지 않는다(버전은 검수 승인 시점에만 — SFR-08). 권한 REVIEWER/WORKER, 본인 배정 프레임만(IDOR 방어). 라벨 형태(lblTypeCd)는 BBOX/POLYGON/SEGMENT/TRACK/SKELETON 중 하나 — SKELETON 은 COCO-17 휴먼 포즈 키포인트로, points 가 17×[x,y,v] 삼중값(v=0 미표기/1 비가시/2 가시)이고 나머지 타입은 [x,y] 2-튜플이다.
