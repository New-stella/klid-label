## description

영상에 이벤트 시점 마킹을 생성한다. 자동 모드는 프레임 간격으로 마킹 지점을 산출하고, 수동 모드는 요청에 담긴 마킹 지점 배열을 그대로 저장한다.

[사전 조건] 대상 영상의 배치 단계가 마킹 대기이고 비식별이 완료돼 있어야 한다. 작업자는 본인에게 배정된 영상만, 검수자는 전체 영상에 접근한다. 같은 영상에 활성 마킹이 이미 있으면 거부한다.

[응답의 배치 트리거 결과] 마킹 저장이 성공하면 마킹 완료 이벤트가 트랜잭션 커밋 이후 잔여 배치(시계열 위탁 → 프레임 추출 → 오토라벨링 → 트랙 보간)를 비동기로 시작한다. 응답의 batchTriggered 는 그 시작이 실제로 개시됐는지를, batchSkipReason 은 개시되지 않았을 때의 사유를 알린다 — 영상을 찾지 못함 · 이미 처리 중이거나 처리가 끝난 영상 · 비식별이 완료되지 않은 영상 · 이미 다른 경로로 큐잉된 영상이 그에 해당한다. 배치가 개시되지 않으면 그 마킹은 종결 처리되며, 배치 개시 여부는 마킹 저장의 성공 여부를 바꾸지 않는다. 두 필드는 선택값이라 판정이 이뤄지지 않은 경로에서는 비어 있다(기존 소비자 하위호환).

[마킹 질문 선택] vrfcEvntQstnSn 은 작업자가 고른 검증 이벤트 질문의 일련번호이며 선택값이다. 값이 없거나 그 영상의 검증 이벤트 유형에 속하지 않는 질문이면 서버가 그 유형의 첫 번째 질문으로 되돌린다 — 화면 입력을 신뢰하지 않으며 400 으로 거부하지 않는다. 질문이 없다고 마킹이 막히지는 않는다. 검증 이벤트 유형이 미수신이면 선택 없이 저장되고 이벤트 어노테이션의 질문 칸이 빌 뿐이며, 외부 시계열 위탁 자체는 그대로 나간다. 마킹을 거치지 않는 경로는 언제나 그 유형의 첫 번째 질문을 쓴다. 고를 질문 목록은 영상 단건 조회 응답에서 조달한다.
