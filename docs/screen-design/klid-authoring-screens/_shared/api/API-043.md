영상 단건 메타를 조회한다. 인증된 사용자. 응답의 stages 는 배치 파이프라인 단계별 상태이며, 배치 이력이 없거나 표시 대상 단계를 특정할 수 없으면 빈 배열이다. 배치가 실패한 영상은 batchFailureReason 에 사용자에게 보여줄 실패 사유가 담긴다. 사유는 서버가 변환한 문구이며 예외 클래스명·SQL·DB 제약명 같은 내부 원문은 응답에 싣지 않는다. 실패한 단계는 stages 의 FAIL 항목이 나타내고, 단계를 특정할 수 없는 실패도 사유만은 전달된다. 지금 건너뛴 상태인 묶음은 skippedStages 로, 건너뛰기가 해제됐고 아직 산출물이 없는 묶음은 clearedStages 로, 지금 실패한 상태인 묶음은 failedStages 로 내려간다. 세 목록 모두 화면 세션과 무관한 영구 상태다. deidentHistory 는 이 영상의 비식별 위탁 이력이며 한 항목이 위탁 1회차다 — 최초 비식별과 검수 완료 후 재비식별이 각각 한 항목이다. 요청 일시 내림차순(최신 먼저)으로 정렬해 최신 20건까지 담고, 이력이 없으면 빈 배열이다. 원본·산출물·리포트의 파일 경로는 담지 않는다.

[검증 이벤트 질문 목록] vrfcEvntTypeCd 는 이 영상의 검증 이벤트 유형이고, vrfcEvntQuestions 는 그 유형에 등록된 질문 목록이다. 정렬순서 오름차순이며 첫 번째가 그 유형의 기본 질문이다. 유형이 없거나 등록된 질문이 없으면 빈 배열이며 오류가 아니다. 마킹 화면이 작업자에게 질문을 보여주고 고른 값을 마킹 등록에 실으려면 이 통로가 필요하다 — 질문을 관리하는 조회 경로는 검수자 전용이라 작업자가 쓸 수 없다. 이 목록은 그 영상에 해당하는 유형 하나의 질문일 뿐 관리용 카탈로그 전체가 아니다. 이 응답의 권한 축은 기존과 같다.
