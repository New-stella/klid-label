#### type

## description

영상 단건 메타를 조회한다. 인증된 사용자. 응답의 stages 는 배치 파이프라인 단계별 상태이며, 배치 이력이 없거나 표시 대상 단계를 특정할 수 없으면 빈 배열이다. 배치가 실패한 영상은 batchFailureReason 에 사용자에게 보여줄 실패 사유가 담긴다. 사유는 서버가 변환한 문구이며 예외 클래스명·SQL·DB 제약명 같은 내부 원문은 응답에 싣지 않는다. 실패한 단계는 stages 의 FAIL 항목이 나타내고, 단계를 특정할 수 없는 실패도 사유만은 전달된다. 수동으로 건너뛴 단계는 skippedStages 로 내려간다.
