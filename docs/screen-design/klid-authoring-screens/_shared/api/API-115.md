[폐기] 이 창구는 두지 않는다. 데이터마트 영상 목록의 소유가 포털(Host)로 넘어갔기 때문이다 — 포털이 자기 데이터셋 원장으로 목록 화면을 그리고, 사용자가 그 목록에서 저작을 시작하면 대상 영상의 메타와 파일 경로를 저작도구로 넘겨 라벨링 화면으로 바로 진입시킨다. 저작도구가 데이터마트 영상 목록을 서버간으로 내려주는 이 창구는 부를 쪽이 남지 않는다.

포털 홈 화면은 데이터마트 영상 목록 대신 본인이 저장한 작업 목록(이어서 작업하기 진입·내려받기·만료 예정일)을 그린다.

보존기간 만료 예정 시각 고지는 없어지지 않고 자리를 옮긴다 — 데이터마트 채널의 만료 예정 시각은 이 창구가 아니라 본인 저장 작업 목록을 내려주는 창구가 실어 보낸다. 고지를 함께 없애면 사용자가 예고 없이 작업물을 잃으므로 그 축은 유지한다.

폐기하는 것은 목록 조회 축 하나다. 데이터마트 자산에서 기존 라벨·메타를 불러오는 Load 축, 본인 작업 라벨 저장 축, 본인 작업 데이터 내려받기 축은 그대로 둔다.
