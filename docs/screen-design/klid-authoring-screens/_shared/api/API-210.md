## description

외부 분류 이름을 저작도구의 라벨 또는 이벤트 유형에 연결해 저장한다. 여러 건을 한 번에 보낼 수 있다.

한 번 저장하면 이후 같은 이름이 들어올 때 자동으로 적용된다. 산출물을 가져올 때마다 다시 묻지 않는다.

대응은 사람이 고른 것만 저장한다. 이름이 비슷하다고 서버가 대신 확정하지 않는다. 짐작으로 연결하면 다른 분류로 저장되고, 저장된 뒤에는 어느 것이 짐작이었는지 구분할 수 없기 때문이다.

대응 종류가 라벨이면 라벨을, 이벤트 유형이면 이벤트 유형을 지정해야 한다. 둘 다 지정하거나 둘 다 비우면 거부한다.

같은 종류·같은 이름에 대한 대응은 하나만 있을 수 있다. 이미 있는 대응을 바꾸려면 바꾸려는 의도를 함께 보내야 한다.

이 창구는 관리자만 호출할 수 있다. 산출물을 들여오는 것은 운영·관리 성격의 쓰기이기 때문이다. 폴더 탐색·검사와 이관 이력 조회는 이 요구의 대상이 아니며 검수자 권한만으로 응답한다 — 조회까지 막으면 화면이 열리자마자 빈 채로 죽는다.
