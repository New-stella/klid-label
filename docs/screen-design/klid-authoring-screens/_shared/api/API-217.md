- 이 창구가 받는 폴더 위치와, 적재 중 항목마다 판정하는 마킹 문서 파일·영상 파일 위치의 범위 판정이 폴더 탐색·검사·적재와 같은 규칙을 쓴다는 것과, 허용 루트의 표기와 실제 자리를 둘 다 시작점으로 인정한다는 것을 본문에 명시. 근거 결정 ADR-065.

- 거부 축(상위 이동 표기·허용 범위 밖 위치·허용 범위 안의 이름이 실제로는 범위 밖을 가리키는 바로가기)은 하나도 완화하지 않았다.
- 이 창구 신설 자체의 근거 결정은 ADR-053 이다. 근거를 적는 자리가 하나뿐이라 최신 결정으로 갱신했을 뿐, 신설 근거가 폐기된 것은 아니다.

## description

검사에서 적재할 수 있다고 나온 짝을 일괄로 적재하는 작업을 등록한다. 요청은 곧바로 반환하고 실제 적재는 뒤에서 항목별로 진행한다. 백 건의 복사와 적재는 한 요청이 기다릴 수 있는 시간을 넘기 때문이다. 진행 상황은 작업 식별번호로 따로 조회한다.

허용 저장소 범위를 판정하는 자리는 둘이다. 요청이 준 폴더 위치를 한 번 판정하고, 그 아래에서 짝지은 마킹 문서 파일과 영상 파일의 위치를 항목마다 다시 판정한다. 그래서 폴더가 통과해도 항목 단계에서 거부될 수 있다. 두 자리 모두 폴더 탐색·검사·적재와 완전히 같은 규칙을 따른다. 이 창구가 자기 허용 목록을 따로 갖지 않는다 — 목록이 두 벌이 되면 한쪽만 넓어져 한 창구에서 막히는 위치가 다른 창구에서 열리고, 산출물을 읽는 축과 쓰는 축이 서로 다른 규칙을 가지면 탐색은 되는데 적재에서 거부되는 상태가 된다. 게다가 이 창구는 요청을 곧바로 반환하고 뒤에서 항목별로 진행하므로, 그 거부는 요청 시점이 아니라 처리 도중 항목마다 드러난다.

허용 저장소 루트 자체가 바로가기여도 이 창구가 성립한다. 범위 판정은 루트의 표기와 루트가 실제로 가리키는 자리를 둘 다 허용 범위의 시작점으로 인정한다. 탐색 창구가 돌려주는 위치는 바로가기를 따라간 뒤의 실제 자리이므로, 그 값을 그대로 이 창구에 보내도 어떤 저장소 형상에서도 통과한다. 둘 중 하나만 인정하면 항목마다 하는 판정이 전부 걸려 일괄 적재가 한 건도 완주하지 못한다. 넓어진 것은 시작점을 읽는 방식뿐이다 — 상위로 거슬러 올라가는 표기는 그대로 거부하고, 허용 범위 밖을 가리키는 위치도 그대로 거부하며, 허용 범위 안의 이름이라도 실제로는 범위 밖을 가리키는 바로가기면 그대로 거부한다. 바로가기가 없는 형상에서는 판정 결과가 종전과 완전히 같다.

적재는 항목마다 따로 이뤄지고 트랜잭션도 항목 단위다. 한 건이 실패해도 나머지가 이어지고 실패한 항목에는 사유가 남는다. 동시에 처리하는 항목 수에는 상한이 있어 뒤에서 도는 처리 대기열이 넘치지 않는다.

짝지은 영상 파일은 저작도구 저장소로 복사한다. 원래 자리를 그대로 가리키면 그 영상에 딸린 산출물이 남의 폴더 옆에 쌓이고 그 폴더가 치워지면 이미 적재한 영상이 깨진다.

적재한 각 영상에는 마킹이 예약 상태로 함께 만들어진다. 그 마킹은 비식별이 끝나 영상이 마킹 가능 상태가 되면 활성 상태로 전이해 이후 처리를 시작한다. 마킹 문서가 준 프레임 이미지는 적재하지 않고 시점 위치 정보로만 쓴다.

영상 식별자는 영상 파일 이름에서 확장자를 뗀 값을 쓴다. 이미 쓰이고 있는 값이면 그 항목만 건너뛰고 나머지는 진행한다.
