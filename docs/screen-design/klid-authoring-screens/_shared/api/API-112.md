## description

REVIEWER가 검수완료(APPROVED) 영상의 비식별 재수행을 요청한다. 서비스가 전제조건(APPROVED·기비식별·락)을 검증하고 작업락을 선점한 뒤 KPST 위탁(REQ_KIND=REDEIDENT)을 시작하며, 실제 완료(프레임 attach + DE_IDNTF_YN='Y')는 폴링 잡이 비동기로 이어받는다. 따라서 본 엔드포인트는 수락 사실만 202 Accepted + status=ACCEPTED로 동기 반환하고 위탁 식별자(procLogSn/kpstPrjId)를 함께 준다. 요청 바디 없이 경로변수 + 인증 principal만 사용한다. kpst.deid.enabled=true 환경에서만 빈이 등록된다.
