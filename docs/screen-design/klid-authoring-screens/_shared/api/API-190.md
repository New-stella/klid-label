## description

반려로 폐기 표식이 찍힌 파생영상을 유예 기간 안에 되돌린다.

[반려 자체를 되돌린다] 폐기 표식만 지우면 검수가 반려로 남아 목록에 계속 보이지 않는 반쪽 복구가 된다. 그래서 표식 해제와 검수 재오픈을 함께 수행해 다시 채택할지 반려할지 고를 수 있게 한다.

[사유가 필수이다] 한번 내린 검수 결정을 다시 여는 행위라 누가 언제 왜 되돌렸는지가 남아야 한다.

[유예가 지나면 되돌릴 수 없다] 이미 실삭제된 항목은 409 로 거부된다 — 파일과 행이 사라졌기 때문이지 권한 문제가 아니다. 화면은 결과 조회 응답의 폐기 축(유예 만료 시각·복구 가능 여부)를 보고 버튼을 그린다.
