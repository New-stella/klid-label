## description

base64 이미지 + clip_id + frame_index를 받아 트래킹된 detections를 반환한다. clip_id별로 트래커 인스턴스를 격리/캐시하며 frame_index=0이면 트래커를 리셋(새 인스턴스)한다. /predict와 동일 응답 구조이며 detections[*].track_id가 트래커 부여 ID다(저신뢰 detection은 null 가능). 탐지는 YOLOX(ONNX Runtime)이고 track_id 부여는 ByteTrack 이며, 설정으로 백엔드를 고르지 않는 단일 백엔드다. mock 조건 시 mock 응답을 반환한다. 저작도구 내부 stateless 추론, 인증 없음.
