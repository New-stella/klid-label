## description

지정 객체를 SAM2로 이어지는 프레임에서 추적·외곽 밀착한다. ai-server 호출. REVIEWER/WORKER.

이 호출은 사용자가 화면 앞에서 기다리는 동기 호출이다. 화면은 작업 종류별 최대 대기 상한까지만 기다리며 그 상한은 이 서버가 정해 내려준다 — 화면이 자체 상수로 정하면 호출당 상한이나 재시도 예산이 바뀔 때 조용히 어긋나고, 짧아진 쪽으로 어긋나면 마지막 시도에서 성공한 추론까지 실패로 보인다. 따라서 상한의 하한은 이 경로가 정당하게 쓸 수 있는 최악 소요 이상이어야 한다.
클라이언트가 요청을 중단하면 서버는 그 추론을 계속 이어가지 않는다. 사용자가 취소했는데 추론이 끝까지 돌면 아무도 쓰지 않을 결과를 위해 추론 자원이 계속 묶이고, 사용자는 취소가 듣지 않는다고 보아 같은 일을 다시 시킨다.

대기 상한은 이 요청이 싣는 프레임 수에 비례한다 — 한 요청 안에서 프레임마다 추론을 되풀이하기 때문이다. 한 요청에 싣는 프레임 수는 계산된 대기가 절대 상한을 넘지 않는 범위로 정하고, 넘길 만큼 많으면 나눠 보낸다. 한 번의 대기가 길어질수록 경로 중간의 더 짧은 상한이 먼저 끊고 그때는 완료분까지 통째로 버려진다.
