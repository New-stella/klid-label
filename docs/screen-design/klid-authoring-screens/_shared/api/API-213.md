여러 영상의 시계열 묶음 스킵을 한 번에 해제한다. 해제는 표식을 지우는 것이 아니라 해제 표식을 덧붙이는 것이라 누가 언제 해제했는지가 함께 남는다 — 단건 해제와 같다. 벤더 연동이 확정된 시점에 쌓인 스킵을 해제하는 것이 이 요청의 용도다. 해제만으로는 시계열이 채워지지 않는다. 건너뛴 묶음을 실제로 다시 수행하는 것은 재수행 요청이 담당한다. ★벤더 연동 시점의 통상 경로는 이 요청이 아니라 일괄 재수행이다. 재수행이 건너뛴 상태를 직접 수락하고 해제 표식까지 함께 남기므로 해제와 재수행을 두 번 돌 필요가 없다. 이 요청은 다시 수행하지는 않으면서 건너뜀 판단만 물리려는 자리에 남겨 둔다. ★대상은 시계열 묶음만 받는다. 한 번에 받는 상한과 중복 식별자를 한 건으로 취급하는 규칙, 요청 순서 보존, 되는 것만 처리하고 거부분은 건별 사유로 돌려주는 부분 성공은 배치 일괄 재처리와 같은 계약을 따른다. 한 건도 처리되지 못해도 200 이며 판정은 결과 목록으로 한다 — 건별 거부 사유를 상태 코드로 올리면 요청이 응답 코드로 영상의 상태를 알려주는 통로가 된다. 대상 목록을 본문으로 받는 삭제 요청이므로, 중간 경로가 본문을 버리는 구성에서는 목록이 전달되지 않는다.
