## description

저작도구 DB의 검수 승인(APPROVED) 자산에서 사용자가 선택한 영상의 라벨/메타를 Load한다 — 포털 DB를 읽지 않는다. ⚠ **[단일 배포 전제 — 재정합 대상]** 「저작도구 DB 의 검수 승인 자산을 Load 한다」는 저작도구가 **한 벌로 배포되던 전제**다. 2026-08-31 확정(ADR-012)으로 저작도구는 **채널별로 별도 배포**되고 각 배포본이 **자기 별도 DB 에만** 연결하므로 **포털 채널 배포본에는 관제 채널 배포본의 승인 자산이 없다.** 대체 조달은 **관제가 비식별 산출물을 포털로 전달 → 포털이 포털 채널 배포본에 알림 → 그 배포본이 배포물을 자기 DB 에 적재해 서빙**하는 방향이다. ✅ **조회 창구가 확정됐다 (2026-09-03 포털 회신)** — 구 표기 「조회 창구가 포털 회신 대기로 미확정이며 확정 전까지 이 서술을 새 설계의 근거로 쓰지 말 것」은 이 회신으로 **해소**됐다. 소재(파일) 조회 창구는 **[포털]API-132** 이며, 그 응답이 알려주는 **NAS 절대경로**로 배포물을 읽는다. 한 건의 소재는 **배포 묶음 파일 한 건과 영상 0건 이상**으로 이루어진다. ⚠ **그 창구의 응답 규격은 포털이 소유하므로 여기에 옮겨 적지 않는다** — 조달처만 가리키고 필드 구성은 [포털]API-132 를 정본으로 본다(복제하면 두 번째 진실원이 되어 한쪽만 낡는다). ⚠ **「포털 DB 를 읽지 않는다」는 그대로 유효**하다 — 우리가 읽는 것은 **NAS 파일**이지 포털 DB 가 아니며, 상호 미접근 확정으로 오히려 강화된다.
