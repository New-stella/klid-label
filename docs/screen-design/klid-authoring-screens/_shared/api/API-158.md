## description

TUS 1.0 재개 가능 업로드 세션을 생성한다. 응답은 201 + Location: /v1/uploads/{uploadId} 헤더(본문 없음). Upload-Metadata 는 TUS 규약(key b64value,key2 b64value2)이며 원문 1KB 상한. ⚠ CLAUDE.md 정책상 1차 적재 경로 아님(관제 학습용 설정 기반 적재 배치로 대체) — 폐지 예정(코드 정리 후속)이나 현재 코드에는 그대로 등록함.
