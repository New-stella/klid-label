## description

관제서버가 통지를 받은 뒤 그 영상의 시계열 메타를 조회하는 경로다.

[통지는 검수 완료가 기준이다] 완료 통지는 검수 승인 시점에, 수정 통지는 그 뒤의 수정에만 발행되므로 이 경로가 향하는 대상은 검수 완료된 영상이다.

[전 행을 그대로 돌려주는 것은 의도다] 이 경로는 그 영상의 시계열 메타 전 행을 반환하므로 이미 적재된 일치도(`vlm.accuracy`)와 영상 기술 메타(`video.*`)도 함께 나간다. 일치도는 신규로는 더 적재되지 않으므로 이 응답에 함께 나가는 것은 과거에 적재된 행이 있는 영상뿐이다 — 연동 대상 시계열 분석 API 가 일치도와 판정을 반환하지 않기 때문이며, 이미 적재된 과거 행은 지우지 않고 그대로 나간다. 검수 승인된 서술만 담는 데이터마트 뷰와는 다른 채널이고 기술 메타는 처음부터 그랬다 — 결함이 아니므로 응답 범위를 좁히지 않는다. 좁히려면 관제와 계약 협의가 선행돼야 한다.
