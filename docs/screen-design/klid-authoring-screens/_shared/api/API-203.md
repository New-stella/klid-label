### rawSn

- **in**: path

**schema**:

#### type

integer

#### format

int64

- **required**: true
- **description**: 다운로드할 데이터마트 영상 식별자

## description

본인이 저장한 작업 라벨을 기준으로, 프레임 이미지 + 라벨 JSON + 비식별 영상(존재 시)을 ZIP 하나로 묶어 반환한다. 라벨 JSON은 프레임마다 본인 저장분이 있으면 그것을, 없으면 데이터마트 원본 라벨을 담는다(GET 프레임 라벨 병합 정책과 동일 축). 비식별 영상 경로가 없으면 영상 파일 없이 라벨·이미지만 담는다(원본 폴백 금지). ZIP 내부 구조: {rawSn}/labels.json(프레임별 병합 라벨) + {rawSn}/frames/{FRM_NO 4자리 zero-pad}.jpg + {rawSn}/video.{ext}(비식별 영상, 있을 경우만). 데이터마트 노출(검수 완료 APPROVED) 영상만 대상이며, 비식별 누락 신고 구간에는 412. 본인 저장 라벨이 한 건도 없는 경우(작업 시작 전, 또는 보존기간 만료로 삭제된 경우)는 410.

내려받는 도중 사용자가 중단해 클라이언트가 연결을 끊으면 서버는 남은 전송을 이어가지 않고 그 시점에 멈춘다. 중단은 실패가 아니므로 서버 오류로 다루지 않으며 받다 만 산출물을 남기지도 않는다. 중단한 뒤 다시 받는 것은 새 요청이라 요청량 제한을 그대로 적용받는다. 요청 제한시간은 산출물을 끝까지 받아낼 수 있는 값이어야 한다 — 영상이 포함되면 산출물이 커지므로 일반 조회용 기본 제한시간을 그대로 쓰면 정상적인 대용량 다운로드가 구조적으로 실패한다. 이 값은 설정으로 조정하며, 요청이 지나는 경로 중 가장 작은 상한이 실제 상한이 되므로 경로 전체에서 함께 맞춘다.
