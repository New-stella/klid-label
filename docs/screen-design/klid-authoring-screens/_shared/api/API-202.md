## description

이 신고의 영상에 대응하는 비식별 산출 디렉터리를 열거해, 해소 시 고를 수 있는 산출물 후보를 돌려준다.

[왜 사람이 고르는가] 외부 비식별 솔루션은 결과를 원본과 다른 이름으로 만들 수 있어 서버가 어느 파일이 재비식별 결과인지 단정할 수 없다. 파일명을 조합하거나 추측하지 않는다는 원칙의 귀결이다.

[★이 목록이 곧 허용목록이다] 해소 요청은 여기서 받은 파일명만 돌려보내며, 서버는 그 값으로 경로를 조립하지 않고 요청 시점에 다시 열거한 결과와 대조해 수락 여부를 정한다. 이 조회가 없으면 해소 요청의 입력값 검증 기준이 사라진다.

[내부 저장 경로를 담지 않는다] 항목 식별은 파일명뿐이고 디렉터리·마운트 구조는 응답에 나가지 않는다 — 이 목록은 작업자도 조회할 수 있어 저장소 구조가 노출되면 안 된다.

[인가] 해소와 동일하다 — 작업자는 본인 배정 영상만, 검수자는 전체.

[빈 목록은 오류가 아니다] 디렉터리가 없거나 비어 있으면 빈 목록과 함께 200 이다.
