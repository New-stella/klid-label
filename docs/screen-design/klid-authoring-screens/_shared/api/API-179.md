## description

원본 영상의 해상도 파생영상 목록과 확정 상태(COMPLETED/IN_PROGRESS/FAILED)를 반환한다.

[왜 필요한가] 해상도 파생 생성 요청(API-092)의 201 응답은 예약 성공만 뜻하고 실제 확정(파일 산출·라벨 복사)은 비동기라, 확정 단계의 실패를 어느 화면에서도 볼 수 없었다. 이 조회가 그 갭을 메운다.

파생영상은 증강 저장모델로 통합 저장되며(증강 종류 코드가 RESL_ 로 시작하는 행), 라이프사이클은 예약 PENDING → 확정 성공 ACCEPTED 다.

응답의 status 는 생성 요청 전용값(CREATED)을 쓰지 않고 확정 진행 상태(IN_PROGRESS/COMPLETED)와 실패(FAILED)만 노출한다.
