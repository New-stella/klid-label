## description

application/offset+octet-stream 본문을 스트리밍으로 청크 append 한다(OOM 방어). Upload-Offset 이 현재 서버 오프셋과 일치해야 하며 불일치 시 409. 청크 크기는 portal.upload.max-chunk-bytes 상한(기본 16MB). 전체 길이에 도달하면 완료 후보로 보고, 락·트랜잭션 밖에서 매직바이트 컨테이너 검증 + ffprobe 비디오 스트림 존재 검증을 수행하며 실패 시 세션을 거부 확정(CANCELLED 영속화)하고 400 을 반환한다. 성공 완료 시 LS_PORTAL_ULD 에 합류되며(PortalVideoUploadedEvent 발행 → 프레임 추출 트리거), 완료 멱등은 DB 조건부 UPDATE 로 보장된다(재전송 안전).
