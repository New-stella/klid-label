## description

★단위는 개별 단계가 아니라 작업 묶음이다 — 시계열(VLM)과 오토라벨(AI 탐지 · AI 분할 · 트랙 보간)이며, 오토라벨은 쪼개서 부분 수행하지 않는다. 뒤 단계가 앞 결과를 입력으로 받고 보간이 그 산출물을 재계산하므로 일부만 수행하면 산출물끼리 어긋나기 때문이다. 보간을 묶음 밖에 두면 어떤 재수행에서도 보간이 무조건 돌아 사람이 손댄 보간 라벨을 지운다 — 묶음이 그 사고를 구조적으로 없앤다.
실패한 배치 단계를 건너뛰고 파이프라인을 진행시킨다. 대상은 시계열과 오토라벨 두 묶음이며, 건너뛰어도 데이터가 영구히 사라지지 않기 때문에 허용한다 — VLM 을 건너뛰면 영상 서술이 사람이 직접 쓴 전문으로 폴백하고, 오토라벨을 건너뛰면 프레임은 남고 작업자가 처음부터 라벨링한다. 사유는 필수이며 배치 이력에 남는다. 산출물 내용이 달라지는 조작이라(시계열 서술 없음 · 자동 라벨 없음) 나중에 그 영상의 시계열이 왜 비어 있는지 되짚을 수 있어야 하기 때문이다. ★ 이때 남기는 사유 값은 비식별 신고가 해소될 때 재개 대상으로 집히는 보류 사유와 반드시 구분되는 별도 값이어야 한다. 같은 값을 쓰면 훗날 재개 절차가 그 기록을 집어 사람이 내린 결정을 뒤집고 외부에 다시 위탁한다. 스킵은 되돌릴 수 있으며 되돌리기는 같은 하위 리소스의 DELETE 가 담당한다.
