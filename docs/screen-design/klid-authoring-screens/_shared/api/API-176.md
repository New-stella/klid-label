## description

프레임(SRC_SN) 단위 라벨 변경 이력을 저장 이벤트 단위로 최신순 페이징 조회한다(라벨 1건=1행이 아님, V114/ADR-033 재구조화). 각 이벤트 행은 요약 카운트(addCnt/mdfcnCnt/delCnt)와 변경 상세 배열 changes[](항목별 changeKind=ADDED/UPDATED/DELETED + before/after 스냅샷 diff)를 담는다. 실제 변경이 없는 무변경 재저장은 이벤트를 생성하지 않으므로 이력에 나타나지 않는다(R7). 롤백 이벤트는 rollbackToVersionHash에 대상 버전 해시가 채워진다(일반 저장 이벤트는 null). GET /v1/frames/{srcSn}/versions(API-034, 스냅샷 버전 목록)와는 별개 개념 — 이쪽은 작업본 저장 시점마다의 변경 diff, 그쪽은 검수 승인 시점 전체 스냅샷이다. WORKER는 본인 배정 프레임만 접근 가능(CWE-639 방어). 기본 size=20 sort=regDt DESC, 최대 100(초과 시 100 클램프). 손상/구포맷 diff는 레코드 단위로 격리 — 파싱 실패 시 빈 changes로 폴백하고 단일 손상 레코드가 페이지 전체를 500으로 만들지 않는다.
