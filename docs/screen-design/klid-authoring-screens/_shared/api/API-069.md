REVIEWER 전용. 연동 서버 주소 키(비식별 서버 · AI 추론 서버 · 외부 시계열 분석 벤더 · 관제 통지 수신처)를 수정할 때는 검수자 권한에 더해 관리자 설정 세션이 발급한 단기 토큰을 함께 요구한다. 토큰이 없거나 만료됐으면 403 이다. 데이터베이스 접속정보는 이 대상이 아니다. 주소 값 규칙: 스킴은 http 또는 https 만 허용한다. IP·포트뿐 아니라 도메인도 입력할 수 있으며, 주소 대역에 따른 차단은 하지 않는다. 형식이 올바르지 않으면 400 이며, 거부 사유에 해석 결과를 실어 보내지 않는다. 값의 우선순위: 설정에 값이 있으면 설정을 쓰고, 없을 때만 배포 환경의 기본값을 쓴다. 설정 변경은 재기동 없이 즉시 다음 호출부터 반영된다.
