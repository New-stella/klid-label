## description

영상 단위(RAW_SN) 이벤트 어노테이션(VQA/CoT/caption)을 조회한다. 어노테이션은 영상 1건당 1건(LS_EVNT_ANNO, RAW_SN UK)이며 caption 만 VLM 생성 + 작업자 수동입력이고 vqa/cot/vd_description 등 나머지는 VLM 생성이다. 검토 상태(LS_EVNT_ANNO_REVIEW.RVW_STTS_CD: PENDING/AUTO_GENERATED/APPROVED/REJECTED)를 함께 반환한다. 검수 승인 시 export 폴더 JSON 최상위 event 키로 반영(ADR-020). 인증된 사용자(REVIEWER/WORKER).
