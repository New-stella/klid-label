증강 결과를 반려한다. 검수 결정을 검수 축에 기록할 뿐 생성 결과 상태는 바꾸지 않는다. 검수자 전용이다.

[사유가 필수다] 사유 없이 반려하면 400 이다(최대 500자). 반려는 파생 영상을 작업 대상에서 빼는 결정이라 누가 왜 뺐는지가 남아야 한다.

[반려는 폐기 표식까지 세운다] 반려된 파생은 등재 게이트에서 즉시 빠지고, 유예 기간이 지나면 배치가 행과 생성 파일까지 삭제한다. 유예 안에서는 복구로 반려 자체를 되돌릴 수 있다.

[해상도 파생은 대상이 아니다] 저작도구 내부 생성물이라 검수 대상이 아니며 400 으로 거부된다.
