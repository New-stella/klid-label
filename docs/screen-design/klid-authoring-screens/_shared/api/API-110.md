## description

포털 사용자가 데이터마트 영상의 프레임 단위 라벨을 Load 한다 — datamart 원본 + 본인 user-label 병합(본인 작업분 우선). 내부 LabelsResponse 와 동일 shape 로 FE LabelingPage(portalMode) 가 소비. PORTAL_USER 전용. 응답의 라벨 원소는 라벨 마스터 참조(labelId)와 트랙 식별자(trackId)를 함께 싣는다. 데이터마트 원본이 갖고 있던 분류 연결과 트랙 연결이 이 응답에서 버려지면, 사용자가 그 프레임을 수정해 저장하는 순간 그 연결이 끊기기 때문이다. 화면은 두 값을 표시하지 않고 저장 요청에 그대로 되돌려 보낸다 — 포털 사용자에게 트랙 번호 변경·병합 수단을 주려는 것이 아니며, 그 편집 수단은 포털에 두지 않는다.
