## description

base64 이미지를 받아 객체 감지 결과(detections)를 반환한다. 탐지 백엔드는 YOLOX(ONNX Runtime) 단일 백엔드이며 설정으로 백엔드를 고르지 않는다. AI_MOCK_MODE=true 또는 가중치 부재/로드실패 시 mock 응답을 반환하며 mock/source/mock_reason 으로 표시한다. 추론 서버는 저작도구 내부 추론 서브시스템으로 stateless 추론 전용이며 인증·DB 가 없다. 저작도구는 타임아웃·재시도·서킷 브레이커 정책을 적용해 호출한다.
