## parameters

### X-Workload

- **in**: header

**schema**:

#### enum

- batch

#### type

string

- **example**: batch
- **required**: false
- **description**: 요청을 처리할 실행 슬롯을 고른다. 값이 정확히 batch 일 때만 배치 전용 슬롯으로 가고, 미지정·빈값·오타·대소문자 불일치를 포함한 그 밖의 모든 경우는 화면 전용 슬롯으로 간다. 배치 파이프라인만 이 값을 실으며 저작도구 화면 경로는 싣지 않는다.

## description

base64 이미지를 받아 객체 감지 결과(detections)를 반환한다. 탐지 백엔드는 YOLOX(ONNX Runtime) 단일 백엔드이며 설정으로 백엔드를 고르지 않는다. AI_MOCK_MODE=true 또는 가중치 부재/로드실패 시 mock 응답을 반환하며 mock/source/mock_reason 으로 표시한다. 추론 서버는 저작도구 내부 추론 서브시스템으로 stateless 추론 전용이며 인증·DB 가 없다. 저작도구는 타임아웃·재시도·서킷 브레이커 정책을 적용해 호출한다. 배치와 저작도구 화면 요청은 서로 다른 실행 슬롯에서 처리되며, 어느 슬롯으로 갈지는 선택 요청 헤더 X-Workload 가 정한다. 헤더가 없으면 저작도구 화면 요청으로 처리한다.
