## description

업로드 세션을 취소하고 임시파일을 삭제한다. ⚠ 1차 영상 적재 경로가 아니다 — 1차 적재는 관제가 인입 원장(LS_DATA_INGEST)에 직접 등록한 행을 저작도구 주기 배치가 폴링해 수행한다. 이 업로드 통로는 내부 관리 화면의 대용량 영상 적재에 쓴다.

관리자 단기 유효창은 이 창구에서 요구하지 않는다. 쓰기이지만 업로드 시작 창구에서 이미 확인을 거친 전송을 되돌리는 것이라 같은 확인을 다시 요구하지 않는다. 권한이 새지 않는 근거는 이 창구가 그 전송의 소유자만 취소하도록 이미 판정한다는 것이며, 그 소유자는 유효창을 연 바로 그 사람이다.
