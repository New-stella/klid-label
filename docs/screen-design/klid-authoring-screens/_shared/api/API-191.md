## description

종결된 인입 행 1건을 미처리로 되돌려 다음 스캔이 다시 집게 한다.

[왜 필요한가] 종결 사유가 설정·환경 오류(공유 저장소 마운트 루트 불일치, 파일 미도착 대기 상한 초과)일 수 있다. 그런데 인입 행은 중복 수신 제약 때문에 관제가 다시 보낼 수 없고 삭제도 금지라, 이 통로가 없으면 그 클립은 수동 개입 없이 영원히 적재되지 않는다.

[대기 예산도 함께 리셋된다] 최초 미도착 관측 시각과 재시도 예정 시각을 함께 초기화하지 않으면 되살린 행이 다음 스캔에서 즉시 재종결된다.

[자동 재큐 배치는 두지 않는다] 원인이 고쳐지지 않은 채 종결과 미처리를 무한 왕복하게 되기 때문이다. 사람이 원인을 고친 뒤 부르는 것이 전제다.

[화면 동선을 두지 않는다] 이 엔드포인트는 운영자가 직접 호출하는 경로다. 되살릴 대상은 아직 영상으로 적재되기 전 단계의 인입 행이라 영상 목록 화면에 나타나지 않는다 — 목록에서 골라 누를 대상이 없으므로 이 호출을 걸 화면이 없다.

종결 상태가 아닌 행은 409 로 거부된다 — 이미 처리된 행을 되살리면 중복 적재가 된다.
