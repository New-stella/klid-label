## description

REVIEWER 전용. DRAFT 게시글을 PUBLISHED 로 전이해 WORKER 에게 노출. 이미 PUBLISHED 면 no-op(멱등, 200). 발행 일시(PBLCN_DT)는 DRAFT 에서 PUBLISHED 로 전이한 시점을 가리킨다 — 이미 PUBLISHED 면 no-op 이라 값이 바뀌지 않지만, 발행을 취소하면 비워지므로 취소 후 다시 발행하면 그 재발행 시점으로 새로 기록된다. 최초 발행 이력은 이 필드가 보존하지 않는다. 응답 ApiResponse<NoticeResponse>.
