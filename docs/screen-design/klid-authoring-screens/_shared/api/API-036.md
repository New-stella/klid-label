## description

대상 스냅샷을 다시 활성 상태로 되돌린다. 새 버전 행을 쌓지 않는다 — 되돌린 결과의 내용이 대상 스냅샷 그 자체라 다시 계산한 해시가 대상 행과 같아지고, 프레임과 해시 조합이 유일해야 하므로 같은 행을 또 넣을 수 없기 때문이다. 누가 언제 어느 버전으로 되돌렸는지는 라벨 변경 이력에 남긴다. REVIEWER/WORKER. 이력 패널에서 되돌릴 버전을 고르고 확인 단계를 거치면 호출된다. 과거 산출 회차를 불러와 저장으로 확정하는 흐름과 공존하며, 그 흐름은 버전 축을 바꾸지 않는다.
