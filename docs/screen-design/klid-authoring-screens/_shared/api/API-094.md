## description

외부 솔루션으로 수동 비식별화를 완료한 뒤 호출해 비식별 누락 신고를 해소한다. 상태 전이와 작업락 해제를 같은 트랜잭션에서 원자적으로 처리한다.

권한은 검수자와 작업자이며 작업자는 본인 배정 영상만 해소할 수 있다(CWE-639). 미해소 상태가 아니면(이미 해소되었거나 기각됨) 409 로 재해소를 차단한다. 미인증은 401, 신고가 없으면 404 다.

자동 재비식별 큐는 폐기됐으며, 이 경로가 외부 수동 비식별화 완료 신호를 받는 유일한 통로다. 해소되면 그 영상에 걸려 있던 조회·저장 차단이 자동으로 풀리고 보존된 기존 라벨을 그대로 다시 쓴다.

해소하려면 어느 비식별 산출물로 해소하는지를 요청 본문 fileName 으로 반드시 지정해야 한다. 외부 비식별 솔루션은 같은 이름으로 덮어쓰지 않고 다른 이름으로 산출할 수 있어, 원장에 기록된 파일 하나만 보고 교체 여부를 판정하면 그런 산출물은 영영 해소되지 않는다. 서버는 기본값을 고르지 않으며 미지정이거나 공백이면 400 이다.

수락 조건은 목록 대조다. 서버는 요청 시점에 그 영상의 비식별 산출 디렉터리를 다시 열거해 후보 목록을 만들고, fileName 이 그 목록에 있을 때만 수락한다(목록 밖이면 400). 경로를 요청 값으로 조립하지 않으며 그 목록 자체가 허용 목록이다. 제출할 fileName 은 비식별 산출물 후보 조회가 돌려준 목록에서 고른 값이며, 그 조회도 같은 열거 규칙을 따른다.

선택한 파일도 기존 검증을 모두 통과해야 하고 하나라도 실패하면 409 다 — 저장 서브트리 실경로 검증, 산출물 무결성(정규파일·크기 하한·컨테이너 시그니처), 파일 수정시각이 신고 시각보다 이후일 것(같은 시각은 거부). 마지막 조건은 신고를 유발한 옛 산출물을 다시 고르는 것을 막는다.

해소에 성공하면 선택한 파일 경로를 비식별 처리 이력에 새 성공 행으로 적재한다. 기존 행을 덮어쓰지 않으므로 어느 산출물이 이전 것이었는지가 이력에 보존되고 최신 성공 이력 조회가 자연히 새 행을 가리킨다. 해소 이후의 프레임 재추출과 영상 스트리밍이 이력에 적재된 경로를 읽으므로, 갱신하지 않으면 다른 이름의 새 산출물을 골라도 이후 처리가 옛 파일을 계속 쓴다.

인가 규칙과 신고 없음 404·이미 처리된 신고 409·검수 승인 영상에 대한 처리·성공 응답 형태는 종전과 같다.
