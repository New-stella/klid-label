## description

이벤트유형 필터 드롭다운 옵션을 제공한다. 수집 대상이고 제외 대분류가 아닌 유형만 대상이다.

[그룹핑 축은 표시명이다] 표시명이 같은 유형코드들을 옵션 1건으로 접는다. categoryKey 에는 그룹의 대표코드(그룹 내 최소 유형코드)가, memberCodes 에는 그룹 전체 코드가 담긴다. 대표를 정렬 기준으로 고정하는 이유는 실행마다 흔들리면 저장된 프리셋 매칭이 흔들리기 때문이다.

[영구 병합이 아니다] 관제가 유형별 이름을 보내기 시작하거나 운영자가 관리 화면에서 표시명을 지정하면 표시명이 갈라져 그룹이 자동으로 쪼개진다. 지금 같은 이름으로 접혀 보이는 것은 이벤트명이 비어 있어 표시명 폴백이 카테고리명까지 내려가기 때문이다.

[필터 파라미터는 이벤트 코드를 유지한다] 표시명은 운영자가 바꿀 수 있어 북마크·저장된 프리셋이 깨진다. 대표코드로 들어오든 비대표 코드로 들어오든 그룹 전체가 매칭된다.

미등록·비규격 코드도 버리지 않고 자기 혼자 그룹이 된다 — 옵션에서 빼면 그 영상이 필터로 도달할 수 없게 된다.

코드→한글명 해석용 맵(API-117)과는 별개다 — 이쪽은 필터 드롭다운 옵션이다. 내부 채널의 검수자·작업자가 공통으로 쓰며 포털 채널은 차단된다. 입력 파라미터가 없는 조회라 입력 검증 표면이 없다.
