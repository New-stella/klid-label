## description

검수 완료된 영상에 대해 외부 증강 시스템에 증강을 요청한다. 검수자 전용이다.

[검수 완료 영상만 대상이다] 미검수 영상이 섞여 있으면 400 으로 거부하며 어느 영상이 막혔는지 응답에 함께 담는다.

[생성 조건 5필드는 전부 필수이며 자유 문자열이다] 시간·계절·날씨·지형·심각도를 입력하면 가공 없이 외부 규격의 생성 조건으로 전달되고 요청 원문이 보관된다. 서버는 값 자체를 좁히지 않는다 — 필수·공백금지·길이 상한과 보이지 않는 문자 제거만 검증한다. 증강 종류는 이 자유 문자열에서 파생하지 않고 별도 목록으로 받는다. 자유 문자열이 종류 판정에 흘러가면 산출물 경로가 조작될 수 있기 때문이다.

[같은 조건으로 몇 번이든 다시 요청할 수 있다] 생성 결과가 매번 다르므로 원하는 결과가 나오지 않으면 동일 조건 재요청이 정당한 동선이다. 서버는 중복을 막지 않으며 연타 방지는 화면이 책임진다. 그 결과 같은 영상·같은 종류의 파생이 여러 건 공존할 수 있어, 결과를 구분하는 축은 요청 시 보관된 생성 조건 원문이다.

[파생본에서는 요청할 수 없다] 파생 깊이는 1 로 고정돼 있어 이미 파생인 영상은 400 으로 거부된다.
