## description

현재 업로드 진행률(offset)을 조회해 재개 지점을 판단한다. 세션 소유자(USER_NO 기준) 검증 후 offset 을 반환한다. ⚠ 1차 영상 적재 경로가 아니다 — 1차 적재는 관제가 인입 원장(LS_DATA_INGEST)에 직접 등록한 행을 저작도구 주기 배치가 폴링해 수행한다. 이 업로드 통로는 내부 관리 화면의 대용량 영상 적재에 쓴다.

관리자 단기 유효창은 이 창구에서 요구하지 않는다. 진행 위치를 읽는 조회이며 유효창은 운영과 관리 성격의 쓰기에만 요구된다. 이 창구도 그 전송의 소유자만 조회하도록 이미 판정한다.
