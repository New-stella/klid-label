## description

청크를 기존 업로드에 append 한다. 본문은 byte[] 로 전체 메모리 적재하지 않고 InputStream 으로 서비스에 스트리밍 위임해 고정 64KB 버퍼로 FileChannel 에 기록한다(OOM 방어). 청크당 상한 초과 시 413 + truncate 롤백. ⚠ CLAUDE.md 정책상 1차 적재 경로 아님 — 폐지 예정(코드 정리 후속)이나 현재 코드에는 그대로 등록함.
