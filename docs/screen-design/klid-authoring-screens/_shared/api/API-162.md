## description

청크를 기존 업로드에 append 한다. 본문은 전체를 메모리에 적재하지 않고 스트리밍으로 위임해 고정 64KB 버퍼로 파일에 기록한다(OOM 방어). 청크당 상한 초과 시 413 + truncate 롤백. ⚠ 1차 영상 적재 경로가 아니다 — 1차 적재는 관제가 인입 원장(LS_DATA_INGEST)에 직접 등록한 행을 저작도구 주기 배치가 폴링해 수행한다. 이 업로드 통로는 내부 관리 화면의 대용량 영상 적재에 쓴다.
