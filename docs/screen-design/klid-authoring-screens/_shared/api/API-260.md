## description

영상 하나를 저작도구 화면 목록 세 곳(영상 처리 현황 · 작업 목록 · 검수 목록)에서 뺀다. 행을 지우지 않고 영상 원장의 제외 표시만 세우므로 언제든 되돌릴 수 있다.

인가 — 검수자 이상이 수행하며 역할 계층으로 관리자도 그대로 수행한다. 라벨링 작업자는 수행할 수 없다. 관리자 전용으로 좁히지 않는다 — 목록을 정리하는 사람이 검수자이고, 좁히면 그 사람이 자기 작업 화면을 정리하지 못한다.

사유 — 필수다. 「왜 뺐는가」가 이 창구의 확정 요구이며, 비어 있거나 공백만이면 수락하지 않는다. 받은 문구는 개행과 제어문자를 제거한 뒤 작업 이벤트 원장의 사유 칸 폭 안으로 길이를 제한해 저장한다. 사유에 개인정보를 적지 않는다 — 원장에 그대로 남고 이력 화면에 그대로 보인다. 화면이 입력 칸에서 그 점을 안내한다.

멱등 — 이미 제외된 영상에 같은 요청을 다시 보내면 아무것도 바꾸지 않고 이력도 남기지 않으며 성공으로 응답한다. 오류가 아니다. 응답의 변경 여부 필드로 이번 요청이 실제로 값을 바꿨는지 구분한다.

배정 충돌 — 배정이 있는 영상은 거부한다. 배정은 풀 수 있으므로 일시 조건이지 영구 거부가 아니며, 안내는 먼저 배정을 해제하라는 문구로 배정 해제 창구를 가리킨다. 그 귀결로 검수 단계에 들어간 영상(검수 대기·검수 중·승인)은 제외할 수 없으며 이는 의도다 — 그 배정을 풀 수 없기 때문이다. 제외의 대상은 잘못 들어온 것과 시험 데이터이지 검수로 넘어간 자산이 아니다. 반려된 영상은 배정을 해제한 뒤 제외할 수 있다.

★배정 존재 조건은 사전 조회만으로 판정하지 않고 값을 바꾸는 갱신 문장 자체에 함께 건다 — 판정과 반영 사이에 배정이 새로 생기는 창을 닫기 위해서다. 갱신이 한 행도 바꾸지 못하면 그 시점의 상태를 다시 읽어, 이미 제외돼 있으면 위의 멱등 성공으로, 그렇지 않으면 배정 충돌 거부로 가른다.

이력 — 값이 실제로 바뀐 경우에만 작업 이벤트 원장에 영상 제외 이벤트를 남긴다. 누가(행위자와 그 시점 역할) · 언제(발생일시) · 왜(사유)를 담으며 새 칸을 만들지 않는다.

★경계 — 제외는 저작도구 화면 시야만이다. 다음은 전부 무변경이며 제외된 영상도 종전과 똑같이 흐른다: 배치 파이프라인(단계 진행과 회수 스윕 포함) · 관제 통지 · 데이터마트 조회 뷰 · 학습데이터 산출물 · 관제 조회 창구 · 통계 대시보드 · 포털 채널. 일관성을 이유로 이 목록 어디에도 제외 조건을 붙이지 말 것 — 붙이는 순간 검수 완료·통지 건에 대한 관제 접근을 무조건 보장한다는 구속 결정을 정면으로 깨고, 총량 축인 통계가 사람의 화면 정리에 따라 흔들린다.

⚠ 산출물 콘텐츠 해시의 입력이 아니다. 넣으면 제외를 켰다 끄는 것만으로 산출물이 다시 만들어지고 수정 통지가 나간다 — 내용은 하나도 바뀌지 않았는데.

⚠ 라벨링 화면 진입도 막지 않는다. 그 결과 검수자가 주소를 직접 넣으면 제외된 영상의 상세가 열린다. 알고 받아들인 비대칭이며 결함으로 다시 보고하지 말 것.

되돌리기 — 복원은 같은 하위 자원을 지우는 별개 창구가 담당한다. 같은 주소에 파라미터를 붙여 행위를 가르지 않는다.
