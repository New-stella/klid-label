## description

프레임 원본 이미지를 ai-server YOLO 로 추론해 검출 좌표만 반환한다(DB 미저장 — SAM2 분할과 동일한 stateless 프록시). 클라이언트가 결과를 캔버스 작업본에 반영한 뒤 기존 라벨 저장 API(PUT /labels)로 확정해야 실제로 저장된다. 재실행해도 서버 측에 아무것도 교체되지 않는다(호출마다 새 추론 결과만 반환). 선택적 body {classes:[...]} 로 검출 대상 클래스(COCO 영문명)를 제한할 수 있으며, 미지정 시 전체 검출(하위호환). shape=POLYGON 이면 검출 박스마다 SAM 분할 폴리곤을 함께 반환한다. ai-server 내부 mock(모델 미로드) 응답이면 detectedCount=0 + 빈 labels + 안내 message 로 반환한다. 권한 REVIEWER/WORKER, 본인 배정 프레임 IDOR 검증. 포털 채널은 역할+채널 격리로 물리 차단(ADR-013).
