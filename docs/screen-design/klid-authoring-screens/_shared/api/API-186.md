## description

자동등록된 이벤트유형의 표시명과 수집여부를 정정한다. null 로 보낸 필드는 미변경이다.

[생성·삭제 API 를 두지 않는다] 등록의 유일한 출처가 관제 인입이기 때문이다. 화면에 없는 유형은 관제가 보낸 적이 없는 유형이며, 지우면 그 유형의 영상이 라벨을 잃는다.

[표시명 변경은 필터 그룹을 가른다] 필터 옵션은 표시명이 같은 유형코드들을 한 건으로 접어 보여준다. 따라서 여기서 표시명을 지정하면 그동안 한 건으로 보이던 그룹이 자동으로 쪼개진다 — 이 접기는 영구 병합이 아니다. 그래서 표시명을 바꾸면 관련 캐시를 무효화해야 한다.

[입력 제한] 경로변수는 코드 컬럼 규격에 맞춰 1~20자·영문·숫자·밑줄·하이픈만 허용한다. 요청 본문은 전용 형식으로 강제되며 PK·분류코드·등록일시는 요청으로 받지 않는다. 수정은 이 한 가지이며 쿼리 파라미터로 행위를 분기하지 않는다.
