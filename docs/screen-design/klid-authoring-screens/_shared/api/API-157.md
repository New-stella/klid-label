## description

본인 업로드 자산의 메타+프레임+프레임별 라벨을 자기완결 JSON 으로 Content-Disposition: attachment 다운로드한다. 서버 생성 고정 파일명(portal-upload-{uldSn}-labels.json, 사용자 입력 미포함—인젝션 여지 없음). 라벨은 업로드 단위 일괄 조회 후 프레임별로 그룹핑해 N+1 을 회피한다. AC6 데이터마트 무접촉 — 포털 3종 테이블(ULD/FRME/LBL)만으로 구성된다(타 도메인 미참조).
