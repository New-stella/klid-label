## parameters

### X-Admin-Session

- **in**: header

**schema**:

#### type

string

- **required**: true
- **description**: 관리자 진입에서 발급받은 단기 토큰. 영상 업로드 시작은 운영·관리 성격의 쓰기라 이 창구에서는 항상 요구한다. 없거나 만료됐으면 403 이며, 권한 부족과 구분해 알리지 않는다.

## description

authoring.dev.upload.enabled=true(env DEV_UPLOAD_ENABLED) 일 때만 빈이 등록되어 endpoint 가 노출된다(기본 false, fail-closed, ADR-039). 미설정/false 면 prd·dev 무관하게 빈 부재(404). 추가로 REVIEWER 권한 가드. multipart/form-data 로 영상 파일과 JSON 메타데이터를 함께 업로드한다. 응답은 즉시(200) 반환되고 프레임 추출 + YOLO + SAM2 는 백그라운드로 실행된다. 허용 확장자: mp4/webm/mov/avi, 기본 최대 500MB.

검수자 권한과 위 운영 토글에 더해, 유효한 관리자 단기 유효창을 함께 요구한다. 셋은 서로를 대체하지 않고 가산된다 — 토글이 켜져 있어야 창구가 열리고, 검수자 권한이 있어야 하며, 그 위에 유효창이 하나 더 필요하다. 유효창은 관리자 진입에서 발급받은 단기 토큰을 X-Admin-Session 헤더로 실어 제시한다. 영상 업로드의 시작은 운영·관리 성격의 쓰기이므로 이 요구의 대상이며, 이 창구는 한 번의 요청으로 업로드가 끝나므로 그 확인도 이 호출 하나에서 이뤄진다. 유효창이 없거나 만료됐으면 403 이고, 거부 사유는 권한 부족과 구분해 알리지 않는다 — 응답이 관리자 유효창의 보유 여부를 알려주는 수단이 되지 않게 한다.

이 창구는 관리 기능의 공통 진입 경로에 속한다. 유효창은 역할을 승격시키지 않으며, 발급받은 사람에게 묶여 있어 요청은 여전히 본인 자격으로 인증된다 — 공유 패스워드로 여는 유효창이지만 업로드 기록에는 실제 행위자가 개인 단위로 남는다.
