### diff_summary

dev 전용 영상 업로드 + 오토라벨 파이프라인 트리거 — 2차 신설. authoring.dev.upload.enabled 토글 기본 false

## deprecated

false

## parameters

_(empty)_

## description

authoring.dev.upload.enabled=true(env DEV_UPLOAD_ENABLED) 일 때만 빈이 등록되어 endpoint 가 노출된다(기본 false, fail-closed, ADR-039). 미설정/false 면 prd·dev 무관하게 빈 부재(404). 추가로 REVIEWER 권한 가드. multipart/form-data 로 영상 파일과 JSON 메타데이터를 함께 업로드한다. 응답은 즉시(200) 반환되고 프레임 추출 + YOLO + SAM2 는 백그라운드로 실행된다. 허용 확장자: mp4/webm/mov/avi, 기본 최대 500MB.
