## description

dev 프로파일 전용(@Profile("!prd")) — 운영(stg/prd) 미노출. DATA_STTS_CD='PENDING' 인 영상의 rawSn 목록을 반환한다 — POST /v1/dev/batch/trigger/next 의 다음 실행 대상 확인용. 목록은 page·size 로 페이징하며 기본값은 page=0·size=20 이고 size 상한은 100 이다. 정렬은 등록 일시 오름차순이며 같은 시각은 식별자 오름차순으로 깨는다 — 정렬을 고정하지 않으면 페이지 경계에서 같은 항목이 중복되거나 빠질 수 있다. 이 순서는 다음 실행 대상을 고르는 경로와 동일하다. 요청자가 정렬 기준을 지정할 수 없다.
