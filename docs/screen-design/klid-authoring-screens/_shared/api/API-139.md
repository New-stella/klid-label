## description

[폐기] 포털 사용자가 본인 이미지를 직접 올리는 접수 창구를 두지 않는다. 이 경로로 들어오는 신규 이미지 접수는 받지 않는다(ADR-013 개정 — 포털 이미지 업로드 축 폐기).

이미 접수된 이미지 자산은 그대로 살아 있다 — 닫히는 것은 신규 접수뿐이며, 기존 자산의 목록·상세 조회와 프레임 이미지 서빙, 다운로드, 삭제는 종전대로 제공한다.

영상 축은 유지된다 — 포털 영상의 재개 가능 업로드, 프레임 추출, 프레임 이미지 서빙은 이 폐기의 대상이 아니다.

아래 요청·응답 규격은 폐기 이전 계약의 기록으로 남긴다 — 새 설계의 근거로 쓰지 않는다.
