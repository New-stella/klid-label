## description

PORTAL_USER 본인 이미지를 multipart/form-data 로 다중 업로드한다(ADR-013 예외, 2026-07-17 — 포털 자산 업로드 신설). 요청당 최대 50장(portal.upload.max-images-per-request), 장당 최대 20MB(portal.upload.max-image-size-bytes, jpg/jpeg/png 만). 디스크에 쓰기 전에 전 파일을 사전검증(확장자 allowlist → 크기 → 매직바이트 시그니처 → 확장자-시그니처 일치 → JPEG는 EOI 마커까지)하여 하나라도 실패하면 파일별 사유와 함께 400을 반환하고 아무것도 저장하지 않는 all-or-nothing 방식이다. 저장 파일명은 UUID 로 강제되고 원본 파일명은 표시용(orgnlFileNm)으로만 보관된다(경로조작 CWE-22 방지). 사용자별 RateLimiter(portalUpload config)로 요청량을 제한한다(CWE-770). 저장된 각 이미지는 대표 프레임(FRME_NO=0)이 즉시 READY 상태로 함께 생성된다.
