## description

검수자만 호출할 수 있다.

목록은 쪽 단위로 돌려준다. 쪽 번호와 한 쪽에 담을 건수를 지정할 수 있고, 지정하지 않으면 서버가 정한 기본값을 쓴다. 응답에는 항목과 함께 현재 쪽 번호, 한 쪽의 크기, 전체 건수, 전체 쪽 수를 나란히 실어 받는 쪽이 다음 쪽이 있는지 스스로 판단할 수 있게 한다.
