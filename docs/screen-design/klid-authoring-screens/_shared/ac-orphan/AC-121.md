# 관리자 패스워드 교체는 현재 패스워드를 다시 확인한 뒤에만 이뤄진다

## notes

유효창만으로 바꿀 수 있게 하면 잠깐 열린 창을 가로챈 사람이 자격 자체를 갈아 치워 정당한 운영자를 잠글 수 있다. 현재 패스워드를 다시 받는 것이 그 한 수를 막는다.

교체 뒤 자기 세션까지 끊기는 것은 결함이 아니라 이 기준이 요구하는 동작이다. 무효화를 별도의 장부나 세대 값으로 하지 않고 유효창 서명이 현재 자격에 의존하게 만들어 이루므로, 예외를 두어 자기 것만 살려 두는 갈래가 없다.

새 값이 현재 값과 같을 때 거부하는 이유는 바뀌지도 않았는데 열려 있던 유효창만 전부 끊기는 일을 막기 위해서다.

## priority

high

## scenario

### then

- 현재 패스워드가 틀리면 바뀌지 않고, 어느 쪽이 틀렸는지 이상은 알려주지 않는다
- 현재 패스워드가 맞으면 바뀐다
- 바뀐 뒤에는 그 전에 열려 있던 유효창으로 어떤 관리 성격의 쓰기도 되지 않는다
- 방금 그 교체에 쓴 유효창도 함께 무효가 되어, 이어서 관리 기능을 쓰려면 새 패스워드로 다시 열어야 한다
- 새 패스워드가 현재 값과 같으면 바뀌지 않는다
- 입력한 값은 응답에도 기록에도 다시 나타나지 않는다

### when

- 현재 패스워드를 틀리게 적고 새 패스워드로 바꾸려 한다
- 현재 패스워드를 맞게 적고 새 패스워드로 바꾼다

### given

- 검수자로 인증한 사용자가 관리자 유효창을 열어 둔 상태다

## statement

관리자 패스워드는 검수자 권한과 유효한 관리자 유효창에 더해 현재 패스워드를 다시 맞혀야만 바꿀 수 있고, 바뀌는 순간 그 전에 발급된 유효창은 방금 쓰던 것까지 모두 무효가 된다.
