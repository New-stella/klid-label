# 관리자 자격은 설정을 조회하는 것만으로 드러나지 않는다

## notes

이 기준이 자격을 일반 설정 저장소에 두지 않는 이유다. 그 저장소는 편집 가능한 키를 목록으로 돌려주므로, 자격을 거기 넣으면 설정을 볼 수 있는 사람 모두가 해시를 얻어 시간을 들여 원래 값을 되찾을 수 있다.

값을 남기지 않는 것과 행위를 남기지 않는 것은 다르다. 공유 자격이라 값만으로는 누가 썼는지 알 수 없으므로, 누가 언제 바꿨는지는 오히려 반드시 남아야 한다.

## priority

high

## scenario

### then

- 설정 조회 결과 어디에도 관리자 패스워드의 해시가 담기지 않는다
- 교체 응답에 바뀐 값이나 그 해시가 담기지 않는다
- 성공이든 실패든 기록에 값이나 해시가 남지 않는다
- 누가 언제 바꿨는지는 남는다

### when

- 운영 설정을 목록으로 조회한다
- 관리자 패스워드를 교체한다

### given

- 검수자로 인증한 사용자가 있다

## statement

관리자 패스워드의 해시는 설정 목록·상세 조회로 드러나지 않으며, 어떤 응답에도 어떤 기록에도 값이나 그 해시가 실리지 않는다.
