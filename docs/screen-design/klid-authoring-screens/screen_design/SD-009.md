## description

관리자가 사용자 목록을 조회·검색·필터링하고 역할을 지정하는 관리 화면의 고충실도 디자인. 디자인 시스템 DS-001(KRDS Public) 토큰만 사용했으며, 와이어프레임 골격(페이지 헤더·검색/역할 필터·사용자 목록 테이블·사용자 정보 수정 모달)을 보존한 채 상태별 비주얼(역할/상태 배지, 로딩 스켈레톤, 빈 결과, 조회 실패), 데이터 밀도(아바타 이니셜, 긴 이메일 ellipsis, loginId 대체 표시), 시각 위계와 컴포넌트 디테일(hover/focus/disabled, 인라인 검증 문구)을 추가했다. 수정 모달에는 역할 변경에 필요한 관리자 단기 유효창의 남은 유효 시간 표시, 만료로 저장이 거부됐을 때의 만료 안내, 관리자 패스워드 재확인 다이얼로그를 함께 담았다. 재확인 입력값은 화면에 다시 표시하지 않는다. 조회에 관리자 단기 유효창까지는 요구하지 않는다. 그 비대칭이 화면에서도 드러나도록 남은 유효 시간 표시를 수정 모달 안에만 두었다.
