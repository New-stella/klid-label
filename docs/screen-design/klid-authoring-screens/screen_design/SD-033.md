## description

KRDS Public(DS-001) 토큰 기반 고충실 디자인. 영상을 한 건씩 골라 올리는 화면이며 업로드 입력 폼과 실행 결과·파이프라인 상태 두 단으로 이뤄진다. 적재 경로를 고르는 라디오가 폼 맨 위에 있고 두 경로가 같은 입력 폼을 쓰므로, 고른 값에 따라 달라지는 것은 보내는 곳과 그 뒤 흐름뿐임을 안내 문구로 밝힌다. 반드시 채우는 식별 정보 묶음만 펼쳐 두고 위치·CCTV 제원·이벤트와 관제일지·기술메타는 접어 두어 처음 보는 사람이 무엇을 채워야 하는지 한눈에 알게 했다. 오른쪽 보조 열은 올린 뒤의 상태를 되풀이해 확인하며 마킹 대기에 닿거나 실패하면 멈춘다. 서버가 읽을 수 있는 폴더를 통째로 들여오는 축은 이 화면에 없다 — 산출물 가져오기(SCREEN-039)가 맡는다.
