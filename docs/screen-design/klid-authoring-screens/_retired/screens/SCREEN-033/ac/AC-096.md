# 올린 이미지는 곧바로 라벨링할 수 있고 영상만 추출을 거친다

## notes

이미지에 프레임을 만들지 않으면 라벨을 어디에 붙일지가 없어 라벨링 화면이 열리지 않는다. 이미지와 영상이 같은 경로를 타야 한다고 통일하면 이미지에 불필요한 추출 단계가 생긴다.

## priority

medium

## scenario

### then

- 이미지는 곧바로 라벨링할 수 있는 상태다
- 이미지에는 자기 자신을 가리키는 프레임이 하나 있다
- 영상은 추출 단계를 거친 뒤에 라벨링할 수 있는 상태가 된다

### when

- 업로드 직후 각각의 상태를 확인한다

### given

- 포털 사용자가 이미지 한 장과 영상 하나를 올린다

## statement

이미지는 별도의 추출 없이 올린 즉시 라벨링할 수 있는 상태가 되고 그 이미지 자신을 가리키는 프레임이 함께 만들어지며, 영상만 고정 간격 추출 단계를 거친 뒤 라벨링할 수 있다.
