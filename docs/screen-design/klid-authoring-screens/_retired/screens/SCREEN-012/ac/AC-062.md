# 배정 목록이 돌려주는 완료는 검수 승인을 가리킨다

## notes

완료라는 낱말은 이 저작도구에서 서로 다른 세 자리에 쓰이며 셋 다 정상이다. 배정 목록이 쓰는 것은 화면 표시 축이고, 이 값을 승인으로 바꾸면 그 값을 읽어 진행률을 계산하는 화면이 검수 완료된 작업마다 진행률을 영으로 표시한다. 실제로 이 표시를 결함으로 잘못 분류한 적이 있어, 그것이 정상 계약임을 이 기준이 못박는다.

## priority

critical

## scenario

### then

- 그 작업의 상태는 완료로 돌아온다
- 응답에 승인이라는 상태 값은 나타나지 않는다

### when

- 작업자의 배정 목록을 조회한다

### given

- 어떤 작업의 검수가 승인되어 있다

## statement

배정 목록이 돌려주는 작업 상태 값에 승인이라는 값은 없으며, 검수가 승인된 작업은 완료로 표시된다.
