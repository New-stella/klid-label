① 헤더·작업자 선택

설명

역할별 헤더 — REVIEWER: 제목 '작업자 통계' + 우측 작업자 선택 select(useUsers role=WORKER size=100). WORKER: 제목 '나의 통계', select 미노출(claims.sub 고정). 대상 workerId 결정: REVIEWER=선택값(초기값 없음, 자동 폴백 없음), WORKER=claims.sub.

Components

  • Heading(작업자 통계)
  • Custom(조회 대상 작업자명) · binds workerStat.workerName
  • Select(작업자 선택)

API

  • API-056
  • API-001
×

② 미선택 안내 (EmptyState)

설명

REVIEWER 가 작업자를 고르기 전 상태 — 아래 KPI/보조지표/일별 차트/월별 표 섹션 전체 대신 이 안내만 렌더된다. (구 정책 '자동 폴백으로 첫 번째 작업자 선택' 은 폐기 — 이 안내 상태로 대체됐다.)

Components

  • Custom(작업자를 선택하세요)
×

③ KPI 4종

설명

완료/진행중/반려/총 라벨 수 4개 KpiCard. 로딩 중 Skeleton ×4. data null 시 0 fallback. 데이터 출처는 /stats/worker 응답(completed/inProgress/rejected/labelCount).

Components

  • Stat(완료) · binds workerStat.completed
  • Stat(진행중) · binds workerStat.inProgress
  • Stat(반려) · binds workerStat.rejected
  • Stat(총 라벨 수) · binds workerStat.labelCount

API

  • API-056
×

④ 보조 지표 (오토라벨 비율·반려율)

설명

data 존재 시에만 렌더. 오토라벨 비율(autoLabelRate*100, 1자리)·반려율(rejectRate*100, 1자리). 값이 유한하지 않으면 '—' 표시. 반려율 10% 초과 시 빨간색 강조.

Components

  • Stat(오토라벨 비율) · binds workerStat.autoLabelRate
  • Stat(반려율) · binds workerStat.rejectRate

API

  • API-056
