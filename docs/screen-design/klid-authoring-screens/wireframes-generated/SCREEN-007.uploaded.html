② 검색·필터 (VideoFilters)

설명

한 줄 그리드 폼. CCTV명/영상ID 키워드(maxLength 100), 상태 select, 이벤트 유형 select, 시작일·종료일 date. 조회 시 page=0 으로 URL searchParams 갱신, 초기화 시 전체 리셋. 입력은 controlled state. ★상태 옵션은 6종이다(전체/완료/처리중/마킹 대기/대기/실패) — BE LsDataRaw.DATA_STTS_* 와 1:1 이어야 하며 MARKING_READY(마킹 대기)가 빠지면 적재~마킹 구간 영상을 상태로 좁힐 수 없다(그 상태 영상이 목록에 실제로 존재한다). ★이벤트 유형 옵션은 <서버 조회 동적>이다(useEventTypes, GET /v1/event-types) — 하드코딩 6종 목록은 폐기됐다. value=categoryKey(그룹 대표코드 = 그룹 내 최소 유형코드), 표시=label 이며 로딩 중에는 disabled+aria-busy. 표시명이 같은 유형코드들은 옵션 1건으로 접히며(관제가 이벤트 코드만 송신해 같은 카테고리의 상세 유형들이 같은 이름으로 보였다), 필터 파라미터는 <이벤트 코드>를 유지한다 — 표시명은 운영자가 바꿀 수 있어 북마크·저장 프리셋이 깨진다. 대표/비대표 어느 코드로 들어와도 그룹 전체로 확장해 IN 매칭하고, 미등록·비규격 코드도 자기 혼자 그룹으로 옵션에 남긴다(제거하면 그 영상이 필터로 도달 불가능해진다).

④ 영상 목록 테이블 + 페이지네이션

설명

GET /v1/videos 페이징 목록. 전체선택/행 체크박스(선택 N건 시 일괄 배정 바). 컬럼: 체크박스/CCTV명/이벤트(EventTypeBadge)/녹화일(capturedAt)/길이(durationSec 포맷)/처리단계(StageBadge: COMPLETED·FAILED, 그 외 StatusBadge)/배정자(workerName, 없으면 '미배정' italic)/액션. ★'개인정보' 컬럼은 표시하지 않는다 — 관제서버가 개인정보 유무를 실제로 보내지 않으며(인입 원장 3필드 dev 실측 전부 NULL) 화면이 보던 privacyTypeCd 는 적재 시 고정되는 레거시 컬럼이었다. PrivacyBadge 컴포넌트는 참조 0건이 되어 삭제됐다(응답 필드는 하위호환 존치). 액션은 세 갈래 — ①기존 배정(workerId 있음) && 검수 승인 완료 아님: '재배정' 버튼(PATCH /v1/assignments/{assignmentId}) ②미배정 && 마킹 진입 가능: '마킹' 버튼(MarkingModal) ③그 외: 액션 없음. 행 클릭은 상세(/video/{id}) 이동. 빈 목록·에러·로딩 스켈레톤 분기.

⑤ 작업자 재배정/일괄 배정 모달 (AssignModal, REVIEWER 전용)

설명

REVIEWER 전용 작업자 배정 모달(AssignModal, TaskListPage 재사용). 이 화면에서는 2가지 모드만 직접 진입한다 — reassign(기존 배정 영상 재배정, PATCH /v1/assignments/{assignmentId}), bulk(선택 N건 일괄 배정, 각 videoId POST /v1/assignments). 단건 신규 배정(assign 모드)은 더 이상 이 화면에서 직접 열리지 않고 '마킹' 버튼 → MarkingModal → '수동' 선택 경로로만 진입한다. 성공 시 모달 닫고 선택 해제 + videos 캐시(VIDEO_KEYS, mutation hook 자동) 및 assignments 캐시(queryClient.invalidateQueries(['assignments'])) 무효화로 행 배정자명 즉시 반영.

⑥ 마킹 진입 팝업 (MarkingModal, REVIEWER 전용)

설명

영상 목록의 '마킹' 버튼 클릭 시 열리는 팝업(MarkingModal). 1단계 '선택'에서 자동/수동을 고른다 — 자동은 프레임 간격(1 이상 정수, 상한 미검증·BE 백스톱) 입력 후 '자동 마킹 시작'으로 POST /v1/videos/{rawSn}/markings(API-047, mode=AUTO) 트리거, 성공 시 마킹이 즉시 생성되고 목록·작업 캐시가 무효화된다. 수동은 별도 UI 없이 기존 AssignModal(mode='assign', videoId=rawSn)을 그대로 렌더해 작업자 배정 흐름으로 넘긴다(POST /v1/assignments). 모달이 닫히면 단계·입력이 초기화된다.
