# 경고 — 낡은 사양에서 생성된 파생 산출물이다

이 디렉터리의 와이어프레임 HTML 은 `screen_spec` 의 `sections` 를 입력으로 **결정론적으로 생성**된
파생물이다. 입력이 낡았으면 출력도 낡는다.

- 파일 최종 기록 시각: **2026-08-07 10:57** · 파일 31건
- 2026-08-08 측정 결과, 같은 시기의 `.staging*` screen_spec 스냅샷은 서버 대비 **전량 또는 대부분 낡아 있었다.**
  따라서 이 HTML 도 현재 화면 구성이 아니다.

**화면 구성(섹션·컴포넌트)을 확인할 때 이 HTML 을 근거로 삼지 마라.** 정본은 서버다:

```
mcp__logicraft__get_item(project_id="4ece2c3f-8e99-46f5-9580-71108a76e578", id="SCREEN-0NN", fields=["sections"])
```

재생성 절차는 `bin/README.md` 를 따르되, **먼저 스냅샷을 갱신해야 한다**
(갱신이 왜 막혀 있는지는 각 `.staging*/STALE.md` 참조).

## 이 표식이 못 보는 것

- HTML 본문과 서버 sections 를 **직접 대조하지 않았다.** 스냅샷 버전 대조에서 추론한 것이다.
- 일부 파일은 우연히 최신과 같을 수 있으나, 어느 것이 그런지는 **판정하지 않았다.**
