## description

오토라벨 신뢰도 분포 막대 차트. 신뢰도 구간 3단계(90% 이상/70~90%/70% 미만)별 라벨 건수를 막대로 보여주며 각 구간은 서로 다른 의미색(고=success/중=warning/저=danger 계열)으로 구분한다. 영상 상세 화면의 오토라벨 결과 탭에서 '신뢰도 분포' 제목 카드 안에 배치되어 처리 정보 요약·라벨별 분포와 함께 노출된다.
