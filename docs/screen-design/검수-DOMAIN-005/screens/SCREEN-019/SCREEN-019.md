# 검수 상세 화면

## route

/review/:id

## title

검수 상세 화면

## device

desktop

## status

draft

## purpose

REVIEWER가 영상 검수 상세를 확인하고 승인 또는 반려를 결정하는 화면. 상단에 영상 메타 정보와 상태를 보여주는 헤더, 그 아래 프레임 이동 컨트롤이 있는 상단바, 캔버스 위의 프레임 썸네일 스트립, 중앙의 읽기 전용 라벨 캔버스, 우측에 객체/메타/이슈 3개 탭으로 구성된 패널이 배치된다. 승인·반려 액션은 검수 헤더가 단독으로 담당한다. 우측 패널의 '객체' 탭은 프레임 라벨 목록·선택 객체 속성·반려 사유 초안이 되는 검수 메모를 다루고, '메타' 탭은 촬영환경·개인정보 판정·프레임 설명을 읽기 전용으로 검토하고 시계열 메타·이벤트 어노테이션은 요약 카드에서 큰 창을 열어 읽기 전용으로 확인하며, '이슈' 탭은 서버에 등록된 이슈(반려 이력·문의)의 열람·댓글·해결 처리를 단독으로 담당한다. 영상에 라벨이 하나도 없는 상태에서 승인을 시도하면 확인 절차를 한 번 더 거친다. 승인은 작업 완료를 의미한다. 접근: REVIEWER. 이미 완료(승인)된 영상 중 검수 승인 이후 라벨·메타가 수정되어 다시 승인이 필요한 영상은 재검토 필요로 표시되며, 이 상태에서는 완료 상태여도 승인 버튼이 다시 활성화되어 재승인할 수 있다. 영상의 비식별이 아직 완료되지 않은 영상은 승인이 거부되므로 승인 버튼을 비활성으로 두고 사유를 미리 안내한다 — 이 조건은 승인만 막고 반려·라벨 확인·프레임 이미지 열람·검수 착수는 막지 않는다. 지금 누가 이 영상을 보고 있는지 화면에 알린다 — 내가 잡은 것인지 남이 잡은 것인지 구분해 보이고, 남이 잡고 있으면 검수 시작이 거절된다는 사실과 그 사람의 이름을 함께 안내한다. 내가 잡은 영상이면 다시 들어와도 그대로 이어서 볼 수 있다. 마지막으로 누가 언제 어떤 역할로 승인했는지도 함께 보인다. ★수정 뒤 재검수를 기다리는 영상은 이 화면에 들어오는 것만으로는 잡히지 않고 검수 시작을 눌러야 잡히며, 눌러도 상태 배지는 바뀌지 않는다 — 완료 배지와 재검토 필요 배지가 그대로 남는다.
