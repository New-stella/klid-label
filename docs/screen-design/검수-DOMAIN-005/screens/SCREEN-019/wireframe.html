검수 상세 화면

REVIEWER가 영상 검수 상세를 확인하고 승인 또는 반려를 결정하는 화면. 상단에 영상 메타 정보와 상태를 보여주는 헤더, 그 아래 프레임 이동 컨트롤이 있는 상단바, 캔버스 위의 프레임 썸네일 스트립, 중앙의 읽기 전용 라벨 캔버스, 우측에 객체/메타/이슈 3개 탭으로 구성된 패널이 배치된다. 승인·반려 액션은 검수 헤더가 단독으로 담당한다. 우측 패널의 '객체' 탭은 프레임 라벨 목록·선택 객체 속성·반려 사유 초안이 되는 검수 메모를 다루고, '메타' 탭은 촬영환경·개인정보 판정·프레임 설명을 읽기 전용으로 검토하고 시계열 메타·이벤트 어노테이션은 요약 카드에서 큰 창을 열어 읽기 전용으로 확인하며, '이슈' 탭은 서버에 등록된 이슈(반려 이력·문의)의 열람·댓글·해결 처리를 단독으로 담당한다. 영… · route /review/:id

③ 프레임 썸네일 스트립

설명

캔버스 바로 위에 위치하며 접고 펼칠 수 있는 가로 스크롤 썸네일 스트립. 썸네일 클릭 시 현재 프레임이 바뀌고, 현재 프레임 위치로 자동 스크롤한다. 좌우 방향키로도 프레임을 이동할 수 있다. 프레임 이미지는 인증된 요청으로 개별 발급받는다. 프레임이 0건이면 안내 문구를 표시한다. 각 썸네일 테두리 색은 프레임 상태를 우선순위로 나타낸다: 현재 프레임(강조) > 미해결 문의가 있는 프레임(경고색) > 라벨이 저장된 프레임(완료색) > 기본. 현재 프레임 강조 표시는 썸네일 경계보다 바깥에 그려지므로, 스트립은 목록의 첫 항목과 마지막 항목에서도 그 표시가 잘리지 않을 만큼의 여백을 갖는다. 썸네일 이미지를 불러오지 못한 자리는 빈 칸으로 두지 않고 불러오지 못했음을 알 수 있는 자리표시를 보여준다.

⑧ 검수 우측 패널 — 메타 탭

설명

우측 패널 '메타' 탭. 촬영환경(날씨·시간대·계절, 영상 단위) → 개인정보 판정(익명·가명·개인정보 포함여부, 영상 단위) → 프레임 설명(프레임 단위) → 개인정보 판정(익명·가명·개인정보 포함여부, 프레임 단위) → 영상 분석 설명 · 이벤트 어노테이션 요약 카드(영상 단위)를 이 순서로 세로로 나열하고, 그 뒤에 참고 정보로 이관 원문 정보(이관으로 들어온 영상에서만 표시)와 영상 기술 정보(해상도·코덱 등)를 둔다. 각 섹션은 접어서 감출 수 있다. ★이 순서는 라벨링 화면(SCREEN-005)의 메타 탭과 같다 — 두 화면을 오가는 검수자가 같은 자리에서 같은 것을 보아야 하며, 순서가 갈리면 무엇을 보고 있는지 대응시키지 못한다. ★이 탭의 모든 항목은 이 화면에서 값을 고치지 않고 읽기 전용으로 확인한다 — 값의 수정은 라벨링 화면의 메타 패널이 담당하며, 검수 승인 시점에 그 값이 동결된다. 편집 지점을 두 화면에 두면 확정 경로가 갈라진다. ★영상 분석 설명과 이벤트 어노테이션은 좁은 탭에서 읽기 어려워 이 자리에는 요약 카드만 두고, 전문은 「크게 보기」로 여는 읽기 전용 창에서 확인한다. 표시할 정보가 전혀 없으면 빈 상태 안내를 노출한다.

Components

  • Custom(메타 섹션 접기/펼치기)

    메타 탭의 각 섹션을 접어서 감출 수 있다. 검수자가 지금 보려는 축만 남기고 나머지를 접어 세로 길이를 줄인다.

  • Custom(촬영환경 검토)

    작업자가 라벨링 화면에서 입력한 영상 단위 촬영환경(날씨·시간대·계절)을 읽기 전용으로 확인한다. 학습데이터 산출물의 촬영환경 조달원이므로 검수자가 승인 전에 값을 확인한다.

  • Custom(개인정보 판정 검토 (영상 축))

    영상 단위 개인정보 판정(익명·가명·개인정보 포함여부)을 읽기 전용으로 확인한다. 학습데이터 산출물의 video 블록으로 나가는 값이라 검수 없이 확정되면 안 된다. 프레임 축 판정과 입도가 달라 두 값이 서로 달라도 모순이 아니다.

  • Custom(프레임 설명 검토)

    현재 프레임의 설명을 읽기 전용으로 확인한다. 학습데이터 산출물의 이미지 설명 조달원이다.

  • Custom(개인정보 판정 검토 (프레임 축))

    현재 프레임의 개인정보 판정(익명·가명·개인정보 포함여부)을 읽기 전용으로 확인한다. 학습데이터 산출물의 image 블록으로 나가는 값이며, 영상 축 판정과 입도가 다른 별개 축이다.

  • Custom(영상 분석 설명 · 이벤트 어노테이션 요약)

    영상 분석 설명의 첫 줄과 이벤트 어노테이션의 이벤트 분류(이름 + 코드)·아직 채우지 않은 항목을 간추려 보여 주고, 버튼 「크게 보기」로 읽기 전용 창을 연다. 설명 아래에는 보조 설명 한 줄 「좁은 탭에서 읽기 어려워 여기에는 간추린 값만 둡니다. 전문은 「크게 보기」로 여는 읽기 전용 창에서 확인합니다.」를 둔다. 검수 화면이라 검토 상태 행을 두지 않는다. 창이 열려 있으면 버튼이 「창 앞으로 가져오기」와 상태 표시 「창 열림」으로, 접혀 있으면 「창 펼치기」와 「창 접힘」으로 바뀐다. 이벤트 분류 이름은 영상 상세 응답의 전체 검증 이벤트 유형 목록에서 코드로 찾고, 목록에 없는 코드는 코드만 보인다.

  • Custom(이관 원문 정보 검토)

    외부 산출물 이관이 저작도구 스키마에 착지할 컬럼이 없어 원문 그대로 보관한 값을 참고용으로 표시한다 — 좌표·위치·카메라 설치 높이·설치 방위·카메라 관리번호·데이터 출처·이벤트 기록·이벤트 상위 계층 이름·외부 영상 식별자·원천 축 개인정보 판정. 사람이 읽는 이름으로 표시하며 원문 열쇠 문자열을 라벨에 그대로 쓰지 않는다. 이름을 정하지 못한 열쇠는 버리지 않고 원문 열쇠로 표시한다. 이관으로 들어오지 않은 영상에서는 이 영역을 표시하지 않는다.

  • Custom(영상 기술 정보 (읽기 전용))

    영상의 기술 정보를 사람이 읽는 값으로 네 항목만 보인다 — 해상도(가로×세로) · 코덱 · 프레임률(소수 둘째 자리까지, 단위 fps) · 길이(분·초). 내부 저장 키를 라벨로 쓰지 않고 받은 값을 날것 그대로 늘어놓지도 않는다 — 프레임률은 반올림해 보이고 길이는 밀리초가 아니라 분·초로 환산해 보인다. 보기 — 해상도 「640×480」 · 프레임률 「30.00 fps」 · 길이 「2분 24.6초」. 고칠 수 없는 참고 표시다.

  • Custom(표시할 메타 정보가 없습니다)

⑨ 검수 우측 패널 — 이슈 탭

설명

우측 패널 '이슈' 탭. 검수 중 발견한 문제를 등록·댓글·해결 처리하는 서버 연동 문의 스레드. '객체' 탭 안의 메모(이 화면 전용)와는 서로 다른 별개 기능이다. 서버에 등록된 이슈의 열람·댓글·해결 처리는 이 탭이 단독으로 담당한다. 상단에 아직 해결되지 않은 문의 건수를 표시하고, 각 스레드는 유형(반려/문의)과 진행 상태(미해결/답변완료/해결)를 배지로 구분해 보여준다. 반려 이력은 해결 처리 이후에도 댓글을 남길 수 있지만, 해결된 문의는 댓글 입력이 잠긴다. 다른 사용자가 같은 문의를 먼저 처리한 경우 동시 처리 충돌 안내를 표시한다. 각 스레드와 각 댓글에는 작성자를 '이름 (역할)' 형태로 표시한다 — 역할은 코드값이 아니라 한글 호칭(작업자·검수자)으로 바꿔 보여주고, 목록에 없는 값은 받은 값을 그대로 쓴다. 이름을 해석하지 못하면 사번으로 대신하고, 역할을 해석하지 못하면 빈 괄호를 남기지 않고 이름만 표시한다. 문의는 작업자와 검수자가 모두 등록할 수 있어 이 표기가 누가 낸 문의인지 가르는 축이 된다. ★스레드 작성자의 역할과 댓글 작성자의 역할은 기준 시점이 다르다 — 댓글은 작성 당시의 역할을 그대로 보존해 보여주고, 스레드는 조회하는 시점의 현재 역할을 보여준다. 따라서 문의를 낸 뒤 역할이 바뀐 사용자는 스레드에서는 바뀐 역할로, 그 사람이 그때 남긴 댓글에서는 당시 역할로 보인다.

⑩ 검수 액션 (승인·반려 — 검수 헤더)

설명

승인·반려는 검수 헤더가 단독으로 담당한다. 반려/승인 버튼은 검수대기·검수중 상태에서만 활성화되고, 완료·반려 상태에서는 모두 비활성화되며 이미 처리된 검수임을 안내한다. 두 액션은 동시에 진행되지 않으며 한쪽이 진행 중이면 다른 쪽도 비활성이다. 승인 클릭 시 승인 확정 확인창을 거쳐 승인 처리하고 목록으로 돌아간다. ★해당 영상에 라벨이 하나도 없으면 승인이 곧바로 처리되지 않고 '라벨 없음 확인' 창이 먼저 뜬다 — 객체가 실제로 없는 정상 영상이면 검수자가 명시적으로 확인해야 승인이 완료되며, 그 확인 사실은 작업 이력에 남는다. 반려 클릭 시 반려 사유(1~1000자) 입력창을 거쳐 반려 처리하고 목록으로 돌아간다. 반려 사유에는 검수 의견과 메모 목록 내용이 함께 담긴다. ★재검토 필요(needsRecheck=true) 영상은 예외다 — 상태가 완료이어도 승인 버튼이 활성화되어 다시 승인할 수 있다(재승인). 재승인도 승인 확정 확인창을 거치며, 승인 상태 자체는 이미 완료이므로 전이 없이 재검토 필요 표시만 해제된다. 반려 버튼의 활성화 여부는 이 예외와 무관하게 기존 규칙(완료 상태 비활성)을 따른다. ★영상의 비식별이 아직 완료되지 않은 영상은 승인이 거부되므로, 승인 버튼을 비활성으로 두고 그 옆에 비식별 완료 전에는 승인할 수 없다는 사유를 미리 안내한다 — 사유를 다 적고 승인을 누른 뒤에야 거부되는 동선을 만들지 않는다. ★막는 범위는 승인 하나뿐이다 — 반려·라벨 확인·프레임 이미지 열람·검수 착수는 그대로 열려 있으므로, 화면 전체가 잠긴 것처럼 보이게 하지 않는다. 이 안내는 프레임 이미지 로드 실패 힌트에 나오는 비식별 재처리 대기(비식별 누락 신고)와는 별개 축이므로 두 안내를 하나로 합치지 않는다.

⑪ 영상 분석 설명 · 이벤트 어노테이션 창 (읽기 전용)

설명

우측 메타 탭의 요약 카드에서 「크게 보기」로 여는 비모달 창. 제목 「영상 분석 설명 · 이벤트 어노테이션」, 부제 「외부 분석 설명과 사건 판단 정보를 크게 보는 창 · 영상 전체에 해당하므로 프레임을 넘겨도 같습니다」. 제목 표시줄을 끌어 옮기고 모서리로 크기를 바꾸며, 창이 떠 있어도 뒤 화면의 캔버스·프레임 이동·우측 탭을 그대로 조작한다. 기본 1440×810 · 최소 560×640이고 폭이 880 미만이면 두 칸이 위아래로 쌓인다. 창은 동시에 하나만 열리고, 위치·크기는 브라우저에 기억하되 복원할 위치가 화면 밖이면 기본 위치로 연다. 왼쪽 칸은 영상 분석 설명, 오른쪽 칸은 이벤트 어노테이션이다. ★이 화면에서는 두 칸 모두 읽기 전용이다 — 입력 칸·글자 수·저장·후보 추가와 삭제·「화면에서 지정」을 그리지 않고 값만 보이며, 빈 값은 「아직 채우지 않았습니다」로 표시한다. 영상 분석 설명에는 검토 상태 배지를 두지 않고, 검토(승인·반려) 표면도 이 창에 두지 않는다 — 검토 상태 확정은 영상 검수 승인 시 자동 처리된다. 값의 수정은 라벨링 화면이 담당한다. 이 창과 요약 카드에서는 「영상 분석 설명」이라고 쓰고 저장 키 이름을 라벨로 노출하지 않는다.

Components

  • Custom(영상 분석 설명 · 이벤트 어노테이션 창)

    제목 표시줄에 제목·부제와 「잠시 접기」·「크게」/「원래 크기」·닫기를 둔다. 검수 화면에는 저장이 없으므로 하단 저장 바를 두지 않는다. Esc 는 창 안에 포커스가 있을 때만 닫는다.

  • Custom(영상 분석 설명 (읽기 전용))

    창 왼쪽 칸. 칸 머리에 제목 「영상 분석 설명」·범위 표시 「영상 전체」와 설명 「외부 분석이 영상을 보고 장소·날씨·상황 등을 적은 설명입니다.」를 둔다. 값만 보이며 입력 칸·글자 수·검토 상태 배지를 두지 않는다.

  • Custom(이벤트 어노테이션 (읽기 전용))

    창 오른쪽 칸. 칸 머리에 제목 「이벤트 어노테이션」·범위 표시 「영상 전체」와 설명 「학습데이터에 함께 저장되는 사건 판단 정보입니다.」를 둔다. 이벤트 분류·질의·답변·캡션 후보(캡션 문장과 사고 단계)·근거 후보(근거 문장과 프레임·객체)를 값만 보인다. 같은 저장 키의 캡션과 근거는 짝을 이루고, 후보는 「캡션 1」「근거 1」 옆에 저장 키를 흐리게 병기한다. 캡션 문장은 받은 원문 텍스트 그대로 보이며 그 아래에 「외부 분석 답을 받은 그대로 보여 줍니다 — 굵게·목록 기호(**, ###)를 어떻게 보일지는 사업자 회신 후 정합니다.」를 적는다. 근거가 없으면 「근거가 없습니다.」를 보인다.

  • IconButton(도움말)

    도움말을 각 라벨 아래 회색 글씨로 항상 표시하고, 칸 머리의 물음표 아이콘 버튼으로 끄고 켠다. 기본은 도움말이 보이는 상태이고 그 선택은 브라우저에 기억한다. 글자 없이 아이콘만 두므로 보조기기가 읽을 이름을 반드시 주며, 도움말이 보이는 동안에는 「도움말 숨기기」, 숨긴 동안에는 「도움말 보기」다.

  • Link({번호} ↗)

    근거의 프레임은 「프레임」을 앞에 한 번만 두고 그 뒤에 번호마다 칩을 하나씩 나란히 보인다 — 「프레임」 「3 ↗」 「104 ↗」처럼 보이며 접두를 칩마다 되풀이하지 않는다. 칩 하나가 프레임 하나를 가리키고 칩마다 이동할 수 있음을 나타내는 표식(↗)을 함께 보인다. 여러 번호를 한 덩어리로 묶지 않는다 — 묶으면 눌렀을 때 어느 프레임으로 가는지 알 수 없다. 칩을 누르면 뒤 화면이 그 칩의 번호로 이동하고 창은 접힌다. 이 영상에 없는 번호는 칩에 「{번호} · 이 영상에 없음」으로 보인다 — 이동 표식(↗)을 두지 않고 흐리게 보여 누를 수 있는 칩과 구분하며, 눌러도 이동하지 않는다. 도움말은 「근거가 보이는 프레임 번호입니다. 누르면 그 프레임으로 이동하고 창은 잠시 접힙니다.」다.

  • Custom(창 접힘 띠)

    창이 접혀 있는 동안 화면 위쪽에 떠서 창 자리를 대신한다. 근거 프레임으로 이동해 접힌 경우에는 「근거 {n} · 프레임 {i}」와 「근거로 적힌 프레임으로 이동했습니다. 확인이 끝나면 창을 펼치세요.」를, 「잠시 접기」로 접은 경우에는 「영상 분석 설명 · 이벤트 어노테이션 창을 잠시 접었습니다. 다시 보려면 펼치세요.」를 보이며 두 경우 모두 「펼치기」로 창을 되돌린다.

  • Toast(이 영상에 없는 프레임 번호 안내)

    이 영상에 없는 프레임 번호를 누르면 이동하지 않고 「{번호} — 이 영상에 없는 프레임 번호라 이동하지 않았습니다.」를 알린다.
