# 시크릿·토큰 미설정 시 x-access-token 미부착 fail-safe

## notes

근거: ADR-063 v4 결정 ⑥, CO-20260905 §3. fail-safe — 발급 불가가 통지 파이프라인을 죽이지 않고 폴백 큐가 회수. QA fail-safe 실단언.

## priority

high

## scenario

### then

- x-access-token 헤더를 붙이지 않는다
- 통지 발송 자체는 예외로 죽지 않는다(폴백 큐가 회수)
- 발급 불가에 대해 WARN 로그를 남긴다
- 토큰·시크릿 값은 로그·예외 어디에도 노출되지 않는다(CWE-532)

### when

- 저작도구가 관제 통지를 발송한다

### given

- 정적 토큰 override 가 설정돼 있지 않다
- 서명 시크릿(JWT_SECRET)도 설정돼 있지 않다
- 관제 통지가 활성화되어 있다

## statement

정적 토큰도 없고 서명 시크릿도 없으면 x-access-token 헤더를 붙이지 않고 통지 자체는 예외로 죽지 않는다(폴백 큐가 회수). enabled 인데 발급 불가면 WARN 을 남기고, 토큰·시크릿 값은 로그·예외에 미노출한다(CWE-532).
