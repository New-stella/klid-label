## description

[폐기] 검수 하단에 별도 액션 바는 두지 않는다. 승인·반려 액션은 검수 헤더(ReviewHeader)가 단독으로 담당한다 — 같은 액션을 두 곳에 두면 상태별 활성 조건과 진행 표시 판정이 갈리기 때문이다. 활성 조건(검수대기·검수중일 때만 활성, 완료·반려 시 비활성+안내, 두 액션 동시 진행 불가)은 헤더 쪽 사양을 따른다.
