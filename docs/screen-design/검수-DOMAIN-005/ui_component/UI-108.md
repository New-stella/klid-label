## description

영상 축(video)/프레임 축(frame) 개인정보 3필드(익명·가명·PII 포함여부)를 편집하는 패널 — 각 필드는 라디오 칩 3지(Y/N/미입력)로 표현하고, 사용자가 직접 고르지 않은 값은 *Source(MANUAL/DERIVED) 태그로 병기한다.
