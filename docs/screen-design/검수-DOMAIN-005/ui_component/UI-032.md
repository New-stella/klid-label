# feedback: Spinner

## name

Spinner

## tags

- common
- feedback
- loading

## category

feedback

## description

로딩 스피너. size(sm/md/lg), aria-label + sr-only 텍스트. role=status. 진행률을 알 수 없는 짧은 대기(버튼 로딩, 페이지 전환 폴백, LoadingOverlay 내부)에 사용 — 진행률(%)을 아는 작업은 ProgressBar, 콘텐츠 구조를 아는 최초 로딩은 Skeleton을 사용한다.
