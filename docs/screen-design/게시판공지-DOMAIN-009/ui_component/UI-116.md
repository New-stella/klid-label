## description

접근이 막혔음을 알리는 원형 잠금 배지. 연한 error tint 배경 위에 진한 잠금 아이콘을 얹고 얇은 테두리를 둔다. 붉은색을 큰 면적으로 채우지 않기 위해 면적이 아니라 대비로 신호를 만든다 — 이 배지는 오류가 아니라 권한 상태를 뜻한다.
