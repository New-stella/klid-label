- **description**: neutral-10 배경 + neutral-80 글자(9.85:1). 포털을 통해 들어온 외부 사용자.

## description

사용자가 들어오는 채널(내부 관제 / 외부 포털)을 표시하는 칩. 고르는 값이 아니라 역할에 연동돼 따라오는 값이라 입력이 아닌 표시 요소다. 내부 채널은 secondary, 포털은 중립색을 써서 두 축이 다름을 색으로도 드러낸다.
