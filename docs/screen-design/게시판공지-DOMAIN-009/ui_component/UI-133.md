## description

해상도 변경 파생을 만들 때 목표 해상도 프리셋을 고르는 다중 선택 목록이다. 한 행에 체크박스 + 프리셋명(1080p) + 최대 크기 치수(최대 1920 × 1080)를 묶어 놓고, 처음에는 세 프리셋이 모두 선택된 상태로 시작한다. 행에 적힌 두 수치는 산출 프레임의 고정 크기가 아니라 상한이라 앞에 '최대' 를 붙여 상한으로 읽히게 적고, 실제 산출 크기는 원본 종횡비에 따라 달라진다는 안내를 목록에 함께 둔다 — 원본이 4:3 이면 720p 프리셋의 산출은 960 × 720 이다. UI-024 Checkbox 는 낱개 컨트롤일 뿐 이 조립(프리셋명 + 상한 치수 + 기본 전체 선택)을 담지 못한다.

## props_schema

### legend

- **type**: string
- **required**: true
- **description**: fieldset legend 문구. 시안: '만들 해상도 (여러 개 고를 수 있고 처음에는 모두 선택돼 있습니다)' 적힌 크기가 상한이며 실제 산출 크기는 원본 비율에 따라 달라진다는 안내를 이 legend 또는 목록에 이어 붙는 보조 문구로 함께 전달한다.

### options

- **type**: Array<{ name: string; width: number; height: number }>
- **required**: true
- **description**: 프리셋 목록. 시안은 1080p(1920×1080) / 720p(1280×720) / 480p(854×480) 3종. width·height 는 산출 프레임의 고정 크기가 아니라 최대 크기(상한)이며, 실제 산출 크기는 원본 종횡비에 따라 달라진다

### value

- **type**: string[]
- **required**: true
- **description**: 선택된 프리셋명 배열. 기본값은 전체 선택

## accessibility_notes

<fieldset> + <legend> 로 묶고 각 행이 <label> 로 네이티브 checkbox 를 감싼다. 행 min-height 44px 로 hit area 를 확보했고, 경계가 유일한 식별 수단인 컨트롤이라 --n-5(흰 면 대비 4.51:1)를 썼다. 치수 표기는 --font-mono + tabular-nums.
