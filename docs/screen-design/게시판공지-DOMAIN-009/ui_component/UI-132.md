### video

- **description**: '영상' + 비디오 아이콘

## description

업로드 자산의 종류를 표 안에서 알리는 분류 표시 사각칩이다. 접수하는 자산이 영상뿐이라 값은 '영상' 하나이며, 이미지 접수를 폐기하면서 값역에서 이미지를 뺐다. 아이콘 + 한글 표기를 한 묶음으로 담고, 상태를 나타내는 pill 배지와 형태(사각 --radius-sm, 경계 --n-3)로 갈라 놓아 같은 행에서 분류와 상태가 혼동되지 않게 한다.

## props_schema

### type

- **type**: 'video'
- **required**: true
- **description**: 자산 유형. 표기는 '영상'

### icon

- **type**: ReactNode
- **required**: false

## accessibility_notes

아이콘 SVG 는 aria-hidden 이고 의미는 한글 텍스트가 전달한다(글자 대비 12.10:1). 경계 --n-3 대 흰 면은 2.01:1 이지만 경계는 묶음 표시일 뿐이라 그대로 뒀다. 높이 24px 이며 조작 요소가 아니다.
