## description

공지·가이드라인 게시글을 작성하는 단일 폼 화면의 고충실도 디자인. 페이지 헤더(브레드크럼 + 뒤로가기 + 제목 + 요약 설명)와 작성 폼 카드(제목 · 내용 · 중요 공지 체크박스 · 취소/작성 액션) 두 영역으로 구성된다. 제목 입력에는 200자 제한을 체감할 수 있는 문자 수 카운터를 추가했고, 내용 입력은 필수 항목 누락 시 보더 색상 변화 + 배경 tint + 아이콘 + 텍스트로 구성된 유효성 오류 상태를 함께 보여준다(색상 단독 사용 금지 원칙 준수). 모든 인터랙티브 요소는 3px 포커스 링 + 2px 오프셋과 44px 이상의 히트 영역을 실제로 구현했다. 제출 처리 중 상태(버튼 스피너 + 비활성화)는 별도 참고 영역으로 시각화했다. 색상·타이포·간격·radius·shadow는 KRDS 공식 토큰(DS-001)만 사용했으며, 전 조합 WCAG 2.1 AA 이상 대비를 통과한다.
