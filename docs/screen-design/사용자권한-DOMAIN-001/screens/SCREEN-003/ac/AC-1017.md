## scenario

### then

- 역할 미해석 시 보호 창구는 거부되나 자기 정보 조회·관리자 등록 창구에는 도달한다(내부 조회는 거부)
- 채널 어긋남은 양쪽 모두 권한 없음으로 거부되고 역할 계층으로도 열리지 않는다
- 토큰 없음/만료는 인증 실패로 거부되고 자원 존재 여부가 드러나지 않는다

### when

### given

- 내부 채널에 역할이 없거나 목록 밖 값이거나, 채널이 어긋나거나, 토큰이 없거나 만료됐다

## statement

내부 채널인데 보관된 역할이 없거나 허용 목록 밖 값이면 보호된 창구에서 거부하되 자기 정보 조회와 관리자 등록 창구에는 도달을 허용한다(라벨 마스터 읽기 같은 내부 조회는 거부). 포털 토큰이 내부 창구를, 내부 토큰이 포털 창구를 부르면 양쪽 모두 권한 없음으로 거부하고 역할 계층으로도 열리지 않는다. 토큰이 없거나 만료되면 인증 실패로 거부하며 자원의 존재 여부가 드러나지 않는다.
