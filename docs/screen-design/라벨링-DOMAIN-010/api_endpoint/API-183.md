## description

영상 단위 개인정보 판정(익명·가명·개인정보 포함여부)을 조회한다. 수동 저장값이 있으면 그 값을, 없으면 비식별 산출물 기본상수(익명 Y / 가명 N / 개인정보포함 N)를 프리필해 반환한다.

[프레임 단위와는 입도가 다른 별개 축이다] 학습데이터 산출물 JSON 의 video 블록은 이 영상 단위 값을, image 블록은 프레임 단위 값을 읽는다. 두 블록의 값이 달라도 모순이 아니다 — '영상 어딘가엔 있지만 이 프레임엔 없다'는 서로 다른 입도의 사실이기 때문이다.

[출처 필드가 계약의 핵심이다] anonymitySource·pseudonymitySource·privacyIncludedSource 는 그 값이 사람이 저장한 판정(MANUAL)인지 시스템 기본상수(DERIVED)인지를 구분한다. 화면은 DERIVED 로 받은 필드를 사용자가 직접 고르지 않았다면 저장 요청에서 null 로 보내야 한다 — 그대로 되돌려 보내면 기본상수가 사람의 판정으로 승격되며, 서버는 출처를 알 수 없어 이를 막지 못한다.

작업자는 본인에게 배정된 영상만 조회할 수 있다. 조회는 비식별 누락 신고 구간에도 차단하지 않는다 — 값 자체가 개인정보가 아니고 막으면 화면이 뜨지 않는다. 저장은 그 구간에 차단된다.
