## description

프레임 단위로 익명·가명·개인정보 포함여부(각 Y/N)를 저장한다.

[전체 교체 계약] 생략(null)한 필드는 수동값이 삭제되어 조회 시 기본상수로 폴백한다. 허용값은 Y 또는 N 뿐이며 그 밖은 400 이다. 경로의 프레임 식별자와 본문의 식별자가 다르면 400 으로 거부한다.

[저장값은 산출물을 결정한다] 학습데이터 산출물 JSON 의 image 블록 개인정보 3필드가 이 값을 읽는다. 영상 단위 값을 읽는 video 블록과는 입도가 다른 별개 축이라 두 블록의 값이 달라도 모순이 아니다.

[사용자가 고르지 않은 필드는 null 로 보낸다] 조회 응답의 출처가 파생값인 필드를 그대로 되돌려 보내면 기본상수가 사람의 판정으로 승격된다.

[산출·통지의 트리거는 재검수 승인이다] 검수 완료된 영상의 이 값을 고치면 그 영상은 다시 검수 대상이 되고, 검수자가 그 수정을 다시 승인한 시점에 산출 폴더가 새 버전으로 재생성된 뒤 관제 수정 통지가 발행된다. 저장 자체는 트리거가 아니다.

작업자는 본인 배정 프레임만 저장할 수 있다.
