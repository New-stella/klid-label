# 라벨 버전 스냅샷 저장·해시 식별

## priority

critical

## scenario

### then

- 영상 단위 라벨 전체 JSON 스냅샷이 LS_LABEL_VERSION.LABEL_PAYLOAD에 SAVE_REASON_CD='APPROVED'로 적재된다
- payload SHA-256(VERSION_HASH)로 버전이 식별되며 동일 payload 재승인은 새 버전을 생성하지 않는다(멱등)
- 라벨 임시저장(작업본 저장) 시점에는 스냅샷을 생성하지 않는다

### when

- REVIEWER가 검수를 승인(APPROVED)한다

### given

- 대상 영상의 라벨이 존재하고 REVIEWER로 인증되어 있다

## statement

REVIEWER가 검수를 승인(APPROVED)하면 영상 단위 라벨 전체 스냅샷(JSON)을 LS_LABEL_VERSION에 적재하고 payload SHA-256(VERSION_HASH)으로 버전을 식별한다(동일 payload 멱등)
