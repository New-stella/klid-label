## description

지금까지 고른 것을 한 줄로 되짚어 주는 요약 표기다. '선택' 라벨 뒤에 종류 배지와 대상 영상을 '×' 로 이어 붙이는데, 이 '×' 는 곱연산이 아니라 두 축을 단순 병렬로 읽히게 하는 구분자다. 아직 아무것도 고르지 않았을 때는 같은 자리에 '아직 고른 항목이 없습니다' 를 둔다. UI-104 CountChip 은 수량 칩이라 성격이 다르다.
