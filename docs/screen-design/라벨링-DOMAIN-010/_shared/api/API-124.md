## description

프레임 원본 이미지를 ai-server YOLO 로 추론하여 BBOX 자동 라벨을 LS_DATA_LBL 에 저장한다(출처 MANUAL_TRIGGER). 재실행 시 기존 자동 라벨만 교체하고 수동 라벨은 보존한다. 선택적 body {classes:[...]} 로 검출 대상 클래스(COCO 영문명)를 제한할 수 있으며, 미지정 시 전체 검출(하위호환). ai-server 내부 mock(모델 미로드) 응답이면 저장하지 않고 savedCount=0 + 안내 message 로 반환한다. 권한 REVIEWER/WORKER, 본인 배정 프레임 IDOR 검증. 포털 채널은 역할+채널 격리로 물리 차단(ADR-013).
