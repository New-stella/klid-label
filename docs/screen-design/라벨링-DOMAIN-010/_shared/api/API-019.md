ErrorCode=CONFLICT. 첨부한 낙관적 동시성 토큰(labelVersion)이 현재 값과 달라 화면이 낡은 경우, 비식별 누락 신고와 무관한 일시적 작업락(트랙 병합·재비식별 진행 중)이 걸린 경우, 사용 중지된 라벨 마스터를 신규로 부여하려는 경우에 거부한다. 전체 교체 의미론이라 낡은 세트를 그대로 저장하면 그사이 다른 세션이 추가한 라벨이 조용히 삭제되므로, 토큰이 어긋나면 저장을 거절한다. 토큰을 첨부하지 않으면 서버가 동시성을 검사하지 않으므로 그 사유로는 충돌하지 않는다. 사용 중지 라벨 제약은 신규 부여에만 적용되며, 기존 라벨이 기존 labelId 를 그대로 유지하는 것은 통과한다.
