## description

프레임 설명(자연어, 최대 1000자)을 저장하거나 수정한다. 이 값은 학습데이터 산출물 JSON 의 이미지 설명 조달원이다. 빈값이나 null 로 저장하면 설명이 삭제된다.

[산출·통지의 트리거는 재검수 승인이다] 검수 완료된 영상의 설명을 고치면 그 영상은 다시 검수 대상이 되고, 검수자가 그 수정을 다시 승인한 시점에 산출 폴더가 새 버전으로 재생성된 뒤 관제 수정 통지가 발행된다. 저장만으로는 산출도 통지도 일어나지 않으며, 아직 한 번도 검수되지 않은 영상도 마찬가지다.

경로의 프레임 식별자와 본문의 식별자가 다르면 400 이다(CWE-345). 권한은 검수자는 통과, 작업자는 본인 배정 프레임만 이다(CWE-639 IDOR 방어).
