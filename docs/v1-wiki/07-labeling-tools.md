## 7.4 라벨링 유형별 상세

### 바운딩 박스 (Bounding Box)
- 용도: 객체 탐지, 기본 위치 표시
- 방법: 시작점 클릭 → 이동 → 대각선 끝점 클릭 (2회 클릭 완성) → 우측 객체 탭에서 속성 선택

### 폴리곤 (Polygon)
- 용도: 정밀한 객체 영역 분할
- 방법: 시작점 클릭 → 테두리 따라 다점 클릭 → 시작점 재클릭으로 닫힘
- 편집: Shift+클릭(점 수정), Ctrl+클릭(점 삭제), F(점 추가), Q(자동 완성)

### 스켈레톤 (Skeleton)
- 용도: 사람 관절 포즈 탐지
- 방법: 시작점 클릭 → 대각선 끝점 클릭 → 스켈레톤 자동 생성 → 각 포인트 위치 조정
- 포인트명은 프로젝트 생성 시 정의([05](05-project-management.md#step-3--라벨-생성))
- 모양 크기 및 개별 점 위치 사용자 직접 수정 가능

### 블러 / 비식별화
- 용도: 얼굴, 번호판, 전화번호 등 개인정보 보호
- 방법: 비식별화 아이콘 → 브러쉬/지우개 + 크기 설정 → 대상 영역 드래그 (지우개로 실수 영역 삭제)
- ⚠️ **반드시 다른 라벨링 전에 먼저 수행** / Ctrl+Z(실행취소) 대상에서 제외

### 그리드 (Grid)
- 용도: 정확한 좌표 선택 보조선. 아이콘 클릭 시 격자 노출.

## 7.5 객체 탭 (우측 패널)

화면: `02-02-09 ~ 11`

| 기능 | 설명 |
|------|------|
| 라벨 변경 | 셀렉트박스에서 동일 종류 내 다른 라벨로 변경 (변경 시 해당 라벨 위치로 항목 이동) |
| 속성 선택 | 라디오 버튼으로 라벨 속성 선택 |
| 잠금 | 수정·이동 불가 (상위 잠금 시 하위 자동 잠금) |
| 뷰어 | 라벨 숨김 (상위 숨김 시 하위 자동 숨김) |
| 삭제 | 라벨 삭제 |
| 복사 | 복사 후 이미지 내 클릭하면 동일 형태 라벨 생성 (오프셋 +10px, 새 라벨 ID) |
| 번호 입력 | 개별 항목 번호 수정 |

상단 영역: 자물쇠(라벨링 영역 잠금/해제), 라벨명 + 객체 수, V(리스트 열림/닫힘).

## 7.6 메타 탭

화면: `02-02-12`
- 텍스트 또는 라디오 버튼으로 프레임별 메타데이터 입력
- 변경 불가능 메타(프로젝트 생성 시 관리자 지정) vs 변경 가능 메타(사용자 입력)
- **"다음 프레임에 적용"** 클릭 시 이후 모든 프레임에 동일 메타 일괄 적용

화면: `02-02-13`

- 관리자 확인 요청·반려 사유가 노출되는 소통 창구 ([09](09-review-workflow.md#관리자-확인-요청))
- DB: `LS_DATA_ISSUE`(계층형 `UP_DATA_ISSUE_SN`) → [15](15-database.md)

## 7.8 객체 추적 및 복사 (UI설계서 §2.3)

- 객체의 프레임 간 이동 경로를 자동 계산하여 추적 → Track 모드([08](08-ai-assisted-labeling.md#track-모드-선형보간))
- 복사: 기존 객체의 라벨·속성·위치(x,y,w,h 또는 polygon points)를 그대로 복사, 동일 위치 중복 방지 위해 +10px offset, 새 라벨 ID로 저장

## 7.9 라벨 데이터 (DB)

`LS_DATA_LBL_HSTRY`(라벨링 이력·최대 용량 9,660MB/년, `TRCK_USE_YN`/`TRCK_ID`/`ATRB` JSON), `LS_PJT_LBL`(라벨 설정·계층 `UP_LBL_SN`·스켈레톤 기본 좌표). 상세 → [15](15-database.md).

> **v2 참고**: v2 캔버스는 **konva.js**(CVAT canvas-drawing 포팅), 라벨 저장은 **전체 스냅샷 JSON을 `LS_LABEL_VERSION`에 저장(SHA-256 해시 버전)**. v1의 라벨 이력 누적 방식과 다르다. 트랙 보간/마스크 변환은 CVAT portable-modules 포팅.
