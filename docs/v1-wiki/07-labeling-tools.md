> ⚠ **다른 두 원문(화면정의서 계열)은 이와 다른 별도 단축키 세트를 적는다 — 병기가 아니라 진짜 불일치다.** `01-UIUX설계서.txt`(화면ID `SKKLID-UI-02-02-05`, "도움말" 버튼 설명 옆 "현재 단축키" 주석)와 `03-UI설계서V1.1.txt`(SC-004 객체 추적 및 복사 기능, "(1) 도움말" 처리 내용)는 **문구가 서로 일치**하는 다음 세트를 적는다: 그리기 도구 = Shift+W · 저장 = Shift+D · 제출 = Shift+F · Ctrl+C(복사)/V(붙여넣기)/Z(이전)/Y(앞으로)/S(저장). 이는 위 관리자매뉴얼 표(저장=Ctrl+S, 프레임이동=W/A/S/D)와 키 배정이 겹치고 충돌한다(예: W 가 한쪽에선 "첫 프레임 이동", 다른 쪽 주석 문맥에선 그리기 도구 배정 키 Shift+W 와는 별개 문자이나 혼동 소지). 두 계열 중 어느 것이 최종 확정본인지는 세 원문만으로는 판정할 수 없다(확인 불가로 남김) — 관리자매뉴얼 쪽이 더 상세하고 화면별 단축키를 체계적으로 정리한 표라 이 위키는 그것을 기본으로 채택했을 뿐, 화면정의서 세트를 오류로 단정하는 것은 아니다.
> 이 외에 여러 (라벨링과 무관한) 화면의 와이어프레임 목업에도 "Crtl+z 실행취소 / Crtl+y 실행취소를 취소 / F12 전체화면으로 보기 / ESC 전체화면 보기 취소" 라는 짧은 팝업 박스가 반복해서 등장한다(예: `01-UIUX설계서.txt` 의 프로젝트 생성 화면 `SKKLID-UI-03-02-05`). 라벨링 화면과 무관한 화면에도 동일 문구가 그대로 붙어 있어 **재사용되는 목업 플레이스홀더로 보이며, 라벨링 전용 확정 단축키로 보기 어렵다** — 표에 반영하지 않았다.

## 7.4 라벨링 유형별 상세

> 바운딩 박스/폴리곤/스켈레톤은 화면 `SKKLID-UI-02-02-09`에서 함께 설명된다 — [7.0](#70-화면-id-순번-확정-skklid-ui-02-02-04--15) 참고(2026-08-19 원문 재확인).

### 바운딩 박스 (Bounding Box)
- 용도: 객체 탐지, 기본 위치 표시
- 방법: 시작점 클릭 → 이동 → 대각선 끝점 클릭 (2회 클릭 완성) → 우측 객체 탭에서 속성 선택

### 폴리곤 (Polygon)
- 용도: 정밀한 객체 영역 분할
- 방법: 시작점 클릭 → 테두리 따라 다점 클릭 → 시작점 재클릭으로 닫힘
- 편집: Shift+클릭(점 수정), Ctrl+클릭(점 삭제), F(점 추가), Q(자동 완성)

### 스켈레톤 (Skeleton)
- 용도: 사람 관절 포즈 탐지
- 방법: 시작점 클릭 → 대각선 끝점 클릭 → 스켈레톤 자동 생성 → 각 포인트 위치 조정
- 포인트명은 프로젝트 생성 시 정의([05](05-project-management.md#step-3--라벨-생성))
- 모양 크기 및 개별 점 위치 사용자 직접 수정 가능
- ⚠ 일반/트랙 모드 적용 여부는 두 원문이 다르다 → [08 §8.3](08-ai-assisted-labeling.md#83-일반--트랙-버튼-모드) 참고

### 블러 / 비식별화
- 용도: 얼굴, 번호판, 전화번호 등 개인정보 보호
- 방법: 비식별화 아이콘 → 브러쉬/지우개 + 크기 설정 → 대상 영역 드래그 (지우개로 실수 영역 삭제)
- ⚠️ **반드시 다른 라벨링 전에 먼저 수행** / Ctrl+Z(실행취소) 대상에서 제외

### 그리드 (Grid)
- 용도: 정확한 좌표 선택 보조선. 아이콘 클릭 시 격자 노출.

## 7.8 객체 추적 및 복사 (`03-UI설계서V1.1.txt` SC-004 객체 추적 및 복사 기능)
