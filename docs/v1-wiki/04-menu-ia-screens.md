# 04. 메뉴 IA · 화면 목록

> 출처: 화면정의서(전체), 통합설계서 §3
> 관련: [03 역할·권한](03-roles-permissions.md) · 각 기능 페이지

## 4.1 라벨러/작업자 메뉴

```
학습 저작도구 (메인 화면 = 로그인 시 첫 화면)
├── 대시보드 — 월별/일별 작업통계
├── 프로젝트
│   ├── 프로젝트 목록 (배정 / 작업중 / 반려 / 관리자확인요청)
│   └── 프로젝트별 작업 리스트 → 라벨링 작업 화면
├── 게시판 — 게시글 목록 / 상세
├── 연습장 — 가공 작업 체험 (임시 저장만)
└── 업로드/생성 [권한자만 노출]
    ├── 파일 업로드
    └── AI 이미지/동영상 생성
```

## 4.2 관리자/프로젝트 담당자 메뉴

```
학습 저작도구
├── 대시보드
│   ├── 담당 프로젝트 (프로젝트담당자만) — 전체 리스트/통계
│   └── 작업 프로젝트 — 내 작업 리스트/통계
├── 프로젝트 관리
│   ├── 담당 프로젝트 목록
│   ├── 프로젝트 생성 (기본정보 → 메타 → 라벨 → 단계 설정 → 권한 부여)
│   └── 프로젝트 상세 (기본정보 수정 / 권한 재배정 / 데이터 현황 / 통계)
├── 사용자 관리 — 사용자 등록 및 관리
├── 영상/이미지 관리 — 목록·상세 / 프로젝트 배정
├── 업로드/생성 데이터 관리 — 업로더 데이터 검토·등록
├── 게시판 — 공지 작성/관리
└── 업로드/생성 — AI 동영상/이미지 생성
```

## 4.3 화면 ID 명명 규칙

```
SKKLID-UI-XX-XX-XX
            │   │   └ 세부 화면 순번
            │   └──── 메뉴 하위 페이지 구분
            └──────── 메뉴 구분

1번째 XX (메뉴 구분):
  01: UI Guide
  02: 라벨러/작업자 화면
  03: 관리자/프로젝트담당자 화면

2번째 XX (하위 페이지):
  01: 대시보드   02: 프로젝트/작업   03: 게시판(라벨러) / 영상·이미지 관리(관리자)
  04: 연습장(라벨러) / 데이터 관리(관리자)   05: 업로드/생성
```

## 4.5 화면 공통 사항 (특이)

- **연습장 이미지는 하드코딩**(변경 시 코드 수정 필요)
- 라벨 설정 화면(`03-02-05/06`)은 Google Form 참고로 명시
- 단축키 상세 정리는 후속 보완 항목으로 명시

> UI 공통 가이드(페이징·리스트·날짜·모달 등)는 [10 대시보드·통계](10-dashboard-statistics.md#ui-공통-가이드) 또는 [17 원본](17-source-documents.md)에 정리. 화면정의서 원본은 [`docs/v1/KLID_IM_UI-UX설계서_학습저작도구시스템_분석.md`](../v1/KLID_IM_UI-UX설계서_학습저작도구시스템_분석.md).
