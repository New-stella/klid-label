## 10.1 작업자/검수자 대시보드

월별/일별 작업 통계, 내 프로젝트별 진행률.

| 옵션 | 설명 |
|------|------|
| 프로젝트 | 조회 프로젝트 선택 (Default: 가장 최근 생성 프로젝트) |
| 월별/일별 | "월"/"일" 버튼 (Default: 월별) |
| 기간 | 날짜 선택 (Default: 전체 기간) |
| 다운로드 | 엑셀 파일로 통계 다운로드 |

**통계 업데이트**: 1시간마다 (우측에 업데이트 시기 표시).
**통계 표시**: 같은 프로젝트에서도 권한별 표시. "완료"/"반려"는 클립 수, 괄호 안은 프레임 수. 날짜는 설정 기간 오름차순. 단계-권한은 1단계 작업자 → 2단계 2차 검수자 순.

## 10.2 관리자/프로젝트담당자 대시보드

| 구분 | 내용 |
|------|------|
| **담당 프로젝트** | 내가 담당자인 프로젝트 리스트/통계 (작업자 작업량·완성도 파악) |
| **작업 프로젝트** | 내가 작업자/검수자인 프로젝트 리스트/통계 |
| **전체 통계** | 담당 프로젝트 전체 집계 |

**"전체 작업내역"**: 데이터 수량이 배정대기 → 배정 → 가공완료 → 1차 검수완료 순으로 이동. 특정 열에 수가 많으면 해당 단계 병목.
**"작업자별 작업내역"**: 권한별 표시, 완료/반려(클립 수, 괄호=프레임). 최종 라벨러는 반려가 "-"로 표시.

역할: 저조한 작업자 개별 관리, 단계별 작업량으로 병목 방지.

## UI 공통 가이드

> 출처: 화면정의서 §8, 통합설계서 §17. 모든 목록/입력 화면에 공통 적용되는 규칙.

### 페이징
| 항목 | 규칙 |
|------|------|
| 페이징 번호 단위 | 10개씩 (리스트 존재 페이지까지만 노출) |
| 리스트 노출 건수 | **15개씩** |
| 정렬 기준 | 최신 날짜·시간 내림차순 |
| `<` / `>` | 이전/다음 10개 페이지 (첫 페이지 표시) |
| `<<` / `>>` | 첫 / 마지막 페이지 |

### 리스트
- 표시 15개씩, 최신 내림차순
- 작업자 리스트: 데이터 상태 우선(반려 → 작업중 → 배정 → 관리자 확인 요청 → 보류) → 날짜 → 명칭 내림차순
- 순번: 최근이 제일 높은 번호

### 날짜 선택
- 형식 `YYYY-MM-DD`, **직접 입력 불가**(date picker만), 시작일 > 종료일이면 자동 변경

### 선택박스 / 입력박스
- 선택박스: 디폴트 항목명 또는 '선택' 표시
- 입력박스: 클릭 시 안내문구 사라지고 커서 노출

### 체크박스 / 모달
- 최상단 체크 시 하위 리스트 일괄 선택
- 모달: 배경 dimmed 비활성화, 팝업명·X·Contents·Action Button 구성

### 공통 원칙
- 권한 없는 메뉴는 **메뉴 자체 미노출**
- 페이지 재진입: 연습장=저장 화면, 대시보드=default 프로젝트 자동 이동

> **v2 참고**: v2는 React + TanStack Query + Tailwind, 페이징은 `ApiResponse<Page>` 표준(기본 size=20, 최대 100). v1의 "15개씩" 규칙과 다르다. 포털은 반응형(PC/태블릿/모바일) + WCAG 2.1 AA.
