## 10.1 작업자/검수자 대시보드 (`SKKLID-UI-02-01-01`, "라벨러 로그인 > 대시보드")

월별/일별 작업 통계, 내 프로젝트별 진행률.

| 옵션 | 설명 |
|------|------|
| 프로젝트 | 드롭다운으로 본인이 담당한 프로젝트 대시보드 확인 |
| 월별/일별 | "월"/"일" 버튼 (Default: 월별) |
| 기간 | 날짜 선택 (Default: 전체 기간, `YYYY-MM-DD`, date picker만 — 직접 입력 불가, 시작일자>종료일자면 자동 변경) |
| 다운로드 | 엑셀 파일로 대시보드 다운로드 |

> ⚠ **프로젝트 드롭다운의 기본값이 원문 두 곳에서 서로 다르다.** `01-UIUX설계서.txt`(화면ID `SKKLID-UI-02-01-01` 세부 설명)는 *"Default: 가장 최근에 생성된 프로젝트"* 라고 적는 반면, `03-UI설계서V1.1.txt` SC-012(작업자 통계)는 *"Default: 가장 최근에 배정된 프로젝트"* 라고 적는다. 어느 쪽이 최종본인지는 이번 원문만으로 확정 불가 — 병기.

**통계 업데이트**: 매일 매시 정각(1시간마다), 우측에 업데이트 시기 표시.
**하단 표 "권한별 작업내역"**: 날짜 / 단계-권한 / 완료 / 반려. 완료·반려는 **클립 수**이며 괄호 안은 **프레임 수**. 날짜는 설정 기간 기준 오름차순. 권한 표기 순서는 "1단계 작업자 → 2단계 2차 검수자" 순. 근거: `01-UIUX설계서.txt`(화면ID `SKKLID-UI-02-01-01`).

## 10.2 관리자/프로젝트담당자 대시보드 (`SKKLID-UI-03-01-01`)

> ⚠ **구 서술 정정 — "전체 통계"는 별도 화면·행이 아니라 "담당 프로젝트" 대시보드 자체가 보여주는 집계다.** `01-UIUX설계서.txt` IA 개요는 *"담당 프로젝트: 내가 프로젝트 담당자로 있는 프로젝트 리스트 / 통계 노출 (전체 리스트, 전체 통계) · 작업 프로젝트: 내가 작업자/검수자로 있는 프로젝트 리스트 / 통계 노출 (내 작업 리스트, 내 작업 통계)"* 라고 적는다. 즉 메뉴는 **담당 프로젝트 / 작업 프로젝트 2개뿐**이고, "전체 통계"는 담당 프로젝트 메뉴가 보여주는 내용의 설명어이지 3번째 메뉴가 아니다.

| 구분 | 화면 | 내용 |
|------|------|------|
| **담당 프로젝트** | `SKKLID-UI-03-01-01`, `02-관리자매뉴얼.txt 7.1` | 슈퍼 관리자/프로젝트 담당자 권한을 배정받은 프로젝트의 라벨러별/과정별 작업 통계 — 전체 리스트 + 전체 통계 |
| **작업 프로젝트** | `02-관리자매뉴얼.txt 8.1`("라벨러와 동일") | 본인이 작업자/검수자로 배정된 프로젝트의 작업 통계 — §10.1 라벨러 대시보드와 화면·항목이 동일 |

**"담당 프로젝트" 화면 구성** (근거: `01-UIUX설계서.txt` 화면ID `SKKLID-UI-03-01-01`, `03-UI설계서V1.1.txt` SC-012):
- 상단 "전체 작업내역": 프로젝트에 **설정된 가공 단계 수만큼**(최초 설정한 프로젝트의 단계까지만 표기 — [09 §9.1](09-review-workflow.md#91-전체-흐름) 참고) 열이 나뉜다. 예: 1단계(배정대기→배정→가공완료→1차검수완료→2차검수완료) / 2단계(배정→가공완료→1차검수완료→최종완료) / 총합. 데이터 수량은 흐름에 따라 오른쪽 열로 이동하며, 특정 열에 수가 많으면 해당 단계에서 병목이 발생하고 있음을 뜻한다(근거: `02-관리자매뉴얼.txt 7.1`).
- "작업자별 작업내역": 날짜 / 단계-권한(ID) / 완료 / 반려. 완료·반려는 **클립 수**(괄호=프레임 수). 라벨러가 같은 프로젝트에서 여러 권한을 가질 수 있어 권한별로 행이 나뉘며, "반려"가 "-"로 표시된 경우는 **최종 라벨러**라 반려받을 수 없다는 뜻.
- 업데이트: 매일 매시 정각(1시간마다). 다운로드: 엑셀.

역할: 저조한 작업자 개별 관리, 단계별 작업량으로 병목 방지(근거: `02-관리자매뉴얼.txt` 7. 대시보드_담당 프로젝트 도입부).

## 10.3 통계 화면 구성

> ⚠ **구 서술 폐기(2026-08-19 원문 실측) — 아래 5행은 전부 사실과 다르다.** 옛 표는 `SKKLID-UI-03-02-16~20` 을 각각 "프로젝트 전체 통계"·"프로젝트 통계 상세"·"권한별 통계"·"데이터 상태별 통계"·"일일 진행률 통계"라고 적었으나, 원문에서 이 다섯 화면은 **"작업 배정"(16·17·18)과 "사용자 확인"(19·20)**이다(화면명 열이 각각 "관리자 로그인 > 프로젝트 관리 > 담당 프로젝트 > 프로젝트 A > 작업 배정" / "… > 사용자 확인"으로 명시됨). 통계와는 무관하다. 이 5개 화면명·용도는 [프로젝트 관리 배정](05-project-management.md) 문서가 다룰 영역이며 이 문서(대시보드·통계) 담당 범위가 아니다.

### 페이징
| 항목 | 규칙 |
|------|------|
| 페이징 번호 단위 | 10개씩 (리스트 존재 페이지까지만 노출) |
| 리스트 노출 건수 | **15개씩** |

### 리스트
- 표시 15개씩, 최신 내림차순
- 작업자 리스트: 데이터 상태 우선(반려 → 작업중 → 배정 → 관리자 확인 요청 → 보류) → 날짜 → 명칭 내림차순
- 순번: 최근이 제일 높은 번호

### 날짜 선택
- 형식 `YYYY-MM-DD`, **직접 입력 불가**(date picker만), 시작일 > 종료일이면 자동 변경

### 선택박스 / 입력박스
- 선택박스: 디폴트 항목명 또는 '선택' 표시
- 입력박스: 클릭 시 안내문구 사라지고 커서 노출

### 체크박스 / 모달
- 최상단 체크 시 하위 리스트 일괄 선택
- 모달: 배경 dimmed 비활성화, 팝업명·X·Contents·Action Button 구성

### 공통 원칙
- 권한 없는 메뉴는 **메뉴 자체 미노출**(근거: `01-UIUX설계서.txt` IA 개요, "해당 메뉴는 권한을 가진 사람만 보이고, 권한이 없는 작업자의 경우 메뉴 자체가 안 보이도록 진행")
- 페이지 재진입: 연습장은 저장된 화면으로 재진입(근거: `01-UIUX설계서.txt`, "저장 시 해당 작업이 저장되며, 연습장 페이지에 재진입 시 저장된 화면 노출"). ⚠ "대시보드=default 프로젝트 자동 이동"은 이번 원문에서 확인하지 못했다(원문 미확인) — 삭제하지 않고 남겨둠
