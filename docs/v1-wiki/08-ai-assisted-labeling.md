# 08. AI 보조 라벨링

> 출처: 통합설계서 §8, 아키텍처설계서 §5.4, 운영자매뉴얼 §3.3.4~3.3.5·3.3.10, 인터페이스규격서(II-003~007)
> 관련: [07 라벨링 도구](07-labeling-tools.md) · [14 인터페이스·API](14-interfaces-api.md)

## 8.1 AI Tool (클릭 세그멘테이션 — SAM 방식)

인터페이스: `KLID-AI-II-003 ~ II-006` (Online, 수시). 화면: `SKKLID-UI-02-02-05`.

라벨러가 객체 일부만 클릭해도 자동으로 객체 경계를 탐지.

**동작**:
1. 좌측 AI Tool 아이콘 클릭
2. 라벨링 형태(바운딩박스 default / 폴리곤) 및 라벨명 선택
3. 객체의 일부분 클릭
4. 객체가 완전히 포함될 때까지 추가 클릭 (여러 클릭 시 첫 클릭을 베이스로 닫힌 폴리곤 생성)
5. 우측 객체 탭에서 "생성" 클릭

> 연결 불가능한 영역 선택 시 객체 탐지 오류 발생 (아키텍처설계서 §5.4).

## 8.2 Auto Labeling (오토 라벨링 — YOLO 방식)

인터페이스: `KLID-AI-II-003 ~ II-006` (AUTO-LABEL, Online). 화면: `SKKLID-UI-02-02-06`.

특정 객체(**사람, 자전거, 자동차, 오토바이, 버스, 트럭** 등)를 자동 탐지하여 라벨 생성.

**동작**:
1. 좌측 Auto Labeling 아이콘 클릭
2. 라벨링 형태, 객체 종류, 라벨명 선택 (저작도구 라벨과 매칭)
3. 연산 중 Loading 표시 → 완료 시 자동 라벨 생성
4. 우측 객체 탭에서 속성 정보만 선택

## 8.3 일반 / 트랙 버튼 모드

AI Tool · Auto Labeling · 바운딩박스 · 폴리곤 공통:

| 모드 | 동작 |
|------|------|
| **일반** | 해당 프레임에만 라벨 생성 (연속되지 않은 객체) |
| **트랙** | 최초 프레임~마지막 프레임 자동 추적 생성. 마지막 프레임에서 위치/크기 수정 시 '트래킹' 버튼 활성화 → 중간 프레임 자동 재계산 (**사용자 직접 수정 프레임은 제외**) |

## 8.4 Track 모드 (선형보간)

인터페이스: `KLID-AI-II-007` (트래킹 Object 정보, Online). 화면: `SKKLID-UI-02-05-08`.

연속 프레임에 등장하는 객체를 효율적으로 라벨링하는 핵심 기능.

```
[최초 프레임] 트랙 라벨 생성
        ↓ 모든 프레임에 동일 위치/크기 라벨 자동 생성
[중간 프레임들] 자동 라벨 (수정 가능)
        ↓
[마지막 프레임] 위치/크기 수정 → '트래킹' 버튼 활성화
        ↓
선형보간(Linear Interpolation)으로 중간 프레임 자동 재계산
```

### 트랙 관리

| 기능 | 설명 |
|------|------|
| 트랙 고유 번호 | 생성 시 자동 배정, 상단 표시 |
| 삭제 아이콘 | 해당 프레임부터 뒤 프레임의 트랙 라벨 삭제 (객체 소멸 시) |
| 변경 버튼 | 트랙 번호 변경으로 가려졌다 재등장한 객체를 하나의 트랙으로 연결 (예: 사람이 차에 가려졌다 재등장) |

### 트랙 데이터 구조 (II-007)

```json
{
  "tracking_list": [
    {
      "tracking_id": "string",
      "frame_no": number,
      "image_path": "string",
      "coordinates": { "x": number, "y": number, "width": number, "height": number },
      "is_track_frame": boolean
    }
  ]
}
```

대응 DB 컬럼: `LS_DATA_LBL_HSTRY`의 `TRCK_USE_YN`, `TRCK_FRM_YN`, `TRCK_ID` ([15](15-database.md)).

## 8.5 베스트 프랙티스 (운영자매뉴얼 §9.4)

- **Auto Labeling**: 사람·자동차 등 자동 가능 객체에 우선 적용
- **AI Tool**: 객체 일부만 클릭 → 자동 테두리 감지
- **트래킹**: 동일 객체 연속 프레임 → 첫·마지막 프레임만 설정 후 자동 계산. 트랙 설정 전에는 가급적 수정 작업 미수행 권장

> **v2 참고**: v2는 추론을 **`ai-server`(YOLO/SAM2)** stateless 서비스로 분리하고 Spring Boot가 `AiServerClient`로 오케스트레이션(Resilience4j 타임아웃/서킷). YOLO/SAM2는 **원본 이미지에만 실행**하고 비식별본과 결과 공유. 트랙 보간은 CVAT 알고리즘 Java 포팅(portable-modules/01).
