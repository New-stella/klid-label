## 13.1 게시판

화면: `SKKLID-UI-02-03-01 ~ 03`. 관리자가 올린 공지/가이드라인 확인 채널.

**목적**: 라벨링 가이드라인·작업 기준 공지, 가이드라인 파일 배포, 프로젝트 공지.

### 조회 (작업자/검수자/업로더 — 열람)
| 항목 | 설명 |
|------|------|
| 검색 | 제목 / 내용 |
| 정렬 | 고정 게시글 → 등록일 → 등록시간 (내림차순) |
| 고정 게시글 | 관리자가 고정한 글 최상단 노출 |
| 게시글 조회 | 제목 클릭 → 상세 |
| 첨부파일 | 클릭 시 다운로드 |

> 새 가이드라인 업로드 시 반드시 확인·다운로드하여 최신 기준 작업.

### 작성·관리 (관리자)
화면: 게시판 → "게시글 작성"

| 항목 | 설명 |
|------|------|
| 게시글 제목 | 필수 |
| 상단 고정 여부 | 체크박스 |
| 게시글 내용 | 필수 |
| 첨부파일 | 선택(가이드라인 등) |

처리 버튼:
- **취소**: 미저장, 목록 이동
- **저장**: 게시글만 저장 (관리자만 확인 가능)
- **등록**: 발행 (라벨러도 확인 가능)
- **발행 취소**: 발행글을 "저장" 단계로 (라벨러 비노출)
- **수정 → 재발행**: 제목/고정/내용/첨부 수정 후 재발행
- **삭제**: 체크박스 선택 → "삭제"

DB: `LS_NTC_BBS`(공지사항), `LS_ATCH_FILE`(첨부파일·`ATCH_FILE_ID`/`ORGNL_FILE_NM`/`FILE_SIZE`/`USE_YN`). → [15](15-database.md).

## 13.2 연습장

화면: `SKKLID-UI-02-04-01`. 라벨링 화면과 동일하게 구현된 연습 환경.

| 항목 | 설명 |
|------|------|
| 목적 | 실제 작업 전 라벨링 기능·도구 연습 (비식별화/바운딩박스/폴리곤/스켈레톤 등) |
| 저장 | **임시 저장만 가능** (제출 불가) |
| 데이터 관리 | 관리자도 연습장 작업 내용 확인 불가 |
| 이미지 | **하드코딩** (이미지 변경 시 코드 수정 필요) |
| 재진입 | 저장된 화면 노출 |

> **v2 참고**: v2 범위(CLAUDE.md)에는 게시판·연습장이 명시되어 있지 않다. v1 고유 보조 기능으로 참고.
