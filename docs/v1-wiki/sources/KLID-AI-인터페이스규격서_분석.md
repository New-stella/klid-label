## 상세 인터페이스 정의

### KLID-AI-II-001: 비디오 추출 요청 (VIDEO-PROC)

**설명**: 원시데이터를 받아 비디오에서 프레임을 추출하는 인터페이스

**송신 시스템**: 데이터송신시스템
**수신 시스템**: 학습저작도구

**데이터 속성**:
- 원시데이터 고유 번호 (가변 길이)
- 비디오 추출 여부 (Boolean)
- 실제 영상 파일 경로
- 추출 시작 시간
- 추출 종료 시간
- 요청 처리 결과 메시지
- 영상 프레임 추출 방식
- 추출 방식에 따른 조건 값

**데이터 속성**:

- 상태 설명 메시지 또는 오류 내용
- 전체 프레임 수
- 현재까지 추출된 프레임 수

## 처리 형태별 분류

### Batch 처리 (1회/분)
- KLID-AI-II-001: 비디오 프레임 추출 요청
- KLID-AI-II-002: 비디오 프레임 추출 상태 응답

### Online 처리 (수시)
- KLID-AI-II-003 ~ KLID-AI-II-007: 오토라벨링 및 트래킹 정보

## 시스템 구성

### 데이터 송수신 시스템

**데이터송신시스템**: 원시 데이터를 제공하고 처리 결과를 수신하는 시스템
**데이터수신시스템**: 처리된 결과 데이터를 수신하는 시스템
**학습저작도구**: 데이터 처리 및 라벨링을 수행하는 중앙 시스템

## 데이터 형식

### 기본 데이터 타입
- **Boolean**: 참/거짓 값
- **String**: 문자열 (가변 길이)
- **Array**: 배열 (여러 항목 포함 가능)
- **Object**: 객체 (구조화된 데이터)

## 요약

본 인터페이스 규격서는 KLID-AI 시스템에서 비디오 처리, 자동 라벨링, 객체 탐지 및 트래킹을 위한 7개의 주요 인터페이스를 정의합니다. 각 인터페이스는 특정 처리 형태(Batch/Online)와 발생 빈도(1회/분 또는 수시)에 따라 설계되었으며, 체계적인 데이터 속성과 구조를 갖추고 있습니다.
