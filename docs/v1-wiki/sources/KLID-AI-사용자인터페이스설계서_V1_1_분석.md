## 2. 주요 화면 및 인터페이스

#### 입출력 파라미터

**요청 파라미터 (REQ)**
| 파라미터명 | 타입 | 필수여부 | 설명 |
|-----------|------|---------|------|
| 적용 프로젝트 | String | 필수 | 적용할 프로젝트 ID |
| 날씨 | String | 필수 | 날씨 속성 (맑음, 흐림, 비, 눈 등) |
| 계절 | String | 필수 | 계절 속성 (봄, 여름, 가을, 겨울) |
| 비식별 여부 | Boolean | 필수 | 비식별 처리 여부 |
| 생성시작일 | Date | 필수 | 데이터 생성 시작 날짜 |

**응답 파라미터 (RES)**
| 파라미터명 | 타입 | 필수여부 | 설명 |
|-----------|------|---------|------|
| 영상/이미지명 | String | 필수 | 영상 또는 이미지 파일명 |
| 이벤트 유형 | String | 필수 | 이벤트 타입 분류 |
| 생성일 | DateTime | 필수 | 데이터 생성 일시 |
| 시간대 | String | 필수 | 시간대 속성 (야간, 주간 등) |
| 개인정보 포함 여부 | Boolean | 필수 | PII 포함 여부 |
| AI 생성 여부 | Boolean | 필수 | AI 생성 데이터 여부 |

### 2.2 라벨링 도구 (Labeling Tool)
#### 개요
- **경로**: [작업자] > 프로젝트 선택 > 라벨링 도구
- **목적**: 학습용 데이터 제작을 위한 주요 어노테이션 도구
- **주요 기능**:
  - 바운딩박스 (Bounding Box)
  - 폴리곤 (Polygon)
  - 스켈레톤 (Skeleton)
  - 블러 (Blur)
  - 그리드 (Grid)

#### 입출력 파라미터
| 파라미터명 | 타입 | 필수여부 | 설명 |
|-----------|------|---------|------|
| 원시데이터 일련번호 | String | 필수 | 원본 데이터 ID |
| 라벨 일련번호 | String | 필수 | 라벨 ID |
| 트랙프레임여부 | Boolean | 필수 | 객체 추적 여부 |
| 좌표 | Array[Number] | 필수 | 바운딩박스/폴리곤 좌표 |
| 순서 | Number | 필수 | 객체 순서 |

#### 라벨링 도구 상세 기능

**1. 바운딩박스/폴리곤**
- 클릭 시 세부 기능 박스 노출
- 라벨: 설정해둔 라벨 노출
- 번호: 신규 번호 자동 부여
- 생성 방식: 일반/트랙 버튼 선택
- 색상: 관리자 설정 색상으로 표기
- 폴리곤: 첫 점과 만나면 작업 종료

**2. 스켈레톤**
- 클릭 시 세부 기능 박스 노출
- 라벨: 설정해둔 라벨 노출
- 번호: 신규 번호 자동 부여
- 생성 방식: 일반/트랙 선택 (트랙 지원)
- 색상: 관리자 설정 색상으로 표기
- 모양: 생성 시 스켈레톤 모양 노출, 프레임에 적용 가능
- 수정: 모양의 크기 및 개별 점 위치 사용자 직접 수정 가능

**3. 블러**
- 마우스를 동그라미 모양으로 변경
- 이미지 클릭 시 해당 영역 블러 처리
- 다시 클릭 시 블러 상태 비활성화

**4. 그리드**
- 클릭 시 이미지에 그리드 노출
- 목적: 정확한 좌표 선택 지원

#### 기술적 고려사항
- 이미지 사이즈나 회전 기능 등의 영향으로 좌표가 달라질 수 있음
- **모든 연산은 반드시 원본 이미지의 해상도와 좌표계를 기준으로 처리**

## 3. 프로젝트 관리 기능

### 3.1 영상/이미지 배정
#### 설명
- 리스트의 체크박스 선택 후 '프로젝트 배정' 버튼 클릭
- 선택 항목이 영상일 경우 프로젝트 배정 팝업 노출

#### 프로젝트 배정 절차
1. 데이터 리스트 선택
2. '프로젝트 배정' 버튼 클릭
3. 프로젝트 선택 팝업 노출
4. 프로젝트 체크박스 선택 (단일 선택)
5. '선택' 클릭 시 데이터 배정 팝업 노출
6. '취소' 클릭 시 팝업창 닫힘

#### 기술적 고려사항
- 영상 처리 시 시스템 자원을 많이 사용
- **1건씩 배치 처리로 진행될 수 있도록 구현이 필요**

## 5. 주요 API/인터페이스 요약

### 5.1 REST API 엔드포인트 패턴
```
GET    /api/v1/projects/{projectId}/videos          - 영상 목록 조회
GET    /api/v1/projects/{projectId}/images           - 이미지 목록 조회
GET    /api/v1/projects/{projectId}/labels           - 라벨 목록 조회
POST   /api/v1/projects/{projectId}/labels           - 라벨 생성
GET    /api/v1/projects/{projectId}/annotations      - 어노테이션 조회
POST   /api/v1/projects/{projectId}/annotations      - 어노테이션 저장
PUT    /api/v1/projects/{projectId}/annotations/{id} - 어노테이션 수정
POST   /api/v1/projects/{projectId}/validate         - 데이터 검수
GET    /api/v1/projects                              - 프로젝트 목록
GET    /api/v1/projects/{projectId}                  - 프로젝트 상세
```

### 5.2 데이터 모델

**Project**
```json
{
  "projectId": "string",
  "projectName": "string",
  "status": "active|inactive|completed",
  "createdDate": "datetime",
  "assignedWorkers": ["workerId"]
}
```

**Annotation**
```json
{
  "annotationId": "string",
  "sourceDataId": "string",
  "labelId": "string",
  "coordinates": [[x1, y1], [x2, y2], ...],
  "objectType": "boundingbox|polygon|skeleton",
  "trackingFrames": boolean,
  "order": number,
  "createdDate": "datetime",
  "status": "pending|completed|rejected"
}
```

## 6. 데이터 흐름 (Data Flow)

```
1. 영상/이미지 수집 (CCTV) → 스토리지 저장
2. 데이터 메타정보 관리 (프로젝트, 속성 등)
3. 작업자에 프로젝트 할당
4. 라벨링 도구를 통한 어노테이션 작업
5. 검수자에 의한 품질 검증
6. 학습데이터 저장 및 내보내기
7. AI 모델 학습
```
