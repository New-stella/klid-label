## 프로그램 카테고리

### 1. WEB 환경 (KLID-AI-PF-001)
**용도**: 사용자 인터페이스 및 대시보드
**특징**: 브라우저 기반의 반응형 웹 애플리케이션
**주요 기능**:
- 프로젝트 관리
- 데이터 업로드
- 라벨링 작업 관리
- 통계 및 보고서

### 2. API 서버 (KLID-AI-PF-002)
**용도**: REST API 기반 데이터 처리
**특징**: 마이크로서비스 아키텍처
**주요 기능**:
- 데이터 조회 및 저장
- 실시간 처리 요청
- 인증 및 권한 관리
- 외부 시스템 연동

### 3. BATCH 처리 (KLID-AI-PF-003)
**용도**: 대용량 데이터 정기 처리
**특징**: 스케줄링 기반 자동 처리
**주요 기능**:
- 비디오 프레임 추출
- 대량 라벨링 작업
- 데이터 정제 및 검증
- 통계 집계

### 4. 저작도구 핵심 모듈 (KLID-AI-PF-004)
**용도**: 핵심 비즈니스 로직 처리
**특징**: 분산 처리 및 확장성
**주요 기능**:
- 머신러닝 모델 관리
- 데이터 전처리
- 특성 추출

### 5. 영상분할 처리 (KLID-AI-PF-005)
**용도**: 비디오 세그먼테이션
**특징**: GPU 기반 고속 처리
**주요 기능**:
- 객체 탐지
- 시맨틱 분할
- 인스턴스 분할
- 트래킹

### 6. 오토라벨링 엔진 (KLID-AI-PF-006)
**용도**: 자동 라벨링 처리
**특징**: 머신러닝 기반 자동화
**주요 기능**:
- 패턴 인식
- 자동 분류
- 신뢰도 점수 계산
- 수동 검수 지원

## 개발 환경 및 기술 스택

### 권장 개발 환경
- **언어**: Python 3.9+, JavaScript/Node.js
- **프레임워크**: FastAPI, React/Vue.js
- **데이터베이스**: MariaDB/MySQL
- **캐시**: Redis
- **메시지 큐**: RabbitMQ / Kafka
- **컨테이너**: Docker & Docker Compose

### 주요 라이브러리
- **ML/DL**: TensorFlow, PyTorch, OpenCV
- **데이터 처리**: Pandas, NumPy
- **API**: FastAPI, Flask
- **프론트엔드**: React, Vue.js

## 코드 관리 정책

### 버전 관리
- **주요 버전**: v1.x (메이저 기능 변경)
- **부 버전**: v1.1, v1.2 (기능 추가)
- **패치**: v1.0.1, v1.0.2 (버그 픽스)

### 브랜치 전략
- **main**: 프로덕션 배포 버전
- **develop**: 개발 통합 브랜치
- **feature/**: 기능 개발 브랜치
- **hotfix/**: 긴급 버그 픽스

### 코드 리뷰
- 모든 변경사항은 Pull Request를 통한 코드 리뷰 필수
- 최소 2명 이상의 승인 후 병합
- 자동 테스트 통과 필수
