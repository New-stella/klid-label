## 1. 개요

본 문서는 **AI CCTV 관제 학습 저작도구 시스템의 관리자 사용법**을 설명합니다.

관리자는 프로젝트 생성, 데이터 배정, 라벨러 권한 관리, 작업 현황 모니터링, 그리고 최종 데이터 검증 및 배포를 담당하는 핵심 역할을 수행합니다.

---

## 2. 권한 관리

### 2.1 관리자 역할 분류

관리자는 **3가지 권한**으로 분류되며, 중복 보유가 가능합니다:

- **슈퍼 관리자**: 전체 시스템 관리 권한
- **프로젝트 담당자**: 특정 프로젝트 관리 권한  
- **업로더**: 영상/이미지 업로드 및 AI 생성 권한

### 2.2 권한별 메뉴 접근 권한

| 메뉴 | 슈퍼 관리자 | 프로젝트 담당자 | 업로더 |
|------|------------|-----------------|--------|
| **대시보드** | O | △ | - |
| **프로젝트 관리** | O | △ | - |
| **영상/이미지 관리** | O | O | - |
| **업로드/생성 데이터 관리** | O | O | - |
| **게시판** | O | O | O |
| **연습장** | O | O | O |
| **업로드/생성** | O | O | - |

**범례**: O = 완전 접근, △ = 제한된 접근 (할당받은 프로젝트만), - = 접근 불가

### 2.3 권한별 접근 상세

**슈퍼 관리자**:
- 대시보드: 전체 프로젝트 통계 조회
- 프로젝트 관리: 전체 프로젝트 생성, 관리, 완료 처리
- 영상/이미지 관리: 전체 영상/이미지 조회 및 배정
- 업로드/생성 데이터 관리: 전체 업로더 생성/업로드 데이터 관리
- 게시판: 공지글 작성 및 관리
- 연습장: 라벨링 연습
- 업로드/생성: AI 동영상/이미지 생성

**프로젝트 담당자**:
- 대시보드: **할당받은 프로젝트만** 통계 조회
- 프로젝트 관리: **할당받은 프로젝트만** 생성 및 관리 (단, 프로젝트 담당자는 자신이 생성한 프로젝트만 수정 가능)
- 영상/이미지 관리: 전체 영상/이미지 조회 및 배정
- 업로드/생성 데이터 관리: 전체 업로더 생성/업로드 데이터 관리
- 게시판: 공지글 작성 및 관리
- 연습장: 라벨링 연습
- 업로드/생성: **"업로더" 권한을 받은 경우에만** AI 동영상/이미지 생성 가능

**업로더**:
- 게시판: 공지글 열람 (작성 불가)
- 연습장: 라벨링 연습
- 업로드/생성: AI 동영상/이미지 생성 및 업로드

### 2.4 권한 조합 사항

**프로젝트 담당자의 다중 권한**:
- 특정 프로젝트에서는 담당자의 권한
- 다른 프로젝트에서는 작업자/검수자의 권한 동시 보유 가능
- **업로드/생성 메뉴 접근 조건**: 업로더 권한 필수

**슈퍼관리자**:
- 권한 부여 없이도 모든 화면에 접근 가능 (아이디 노출 안됨)

| **업로드/생성** | AI로 동영상/이미지 생성 |

## 4. 프로젝트 관리 - 담당 프로젝트

### 4.1 프로젝트 생성

프로젝트 생성은 **학습 데이터셋 구축의 시작 단계**이며, 이 단계에서 프로젝트의 메타데이터와 라벨 체계를 정의합니다.

**경로**: 프로젝트 관리 → 담당 프로젝트 → 프로젝트 생성 버튼

#### 4.1.1 기본 정보 입력

| 필드 | 필수 | 설명 |
|------|------|------|
| **프로젝트명** | O | 사용할 프로젝트명 작성 |
| **프로젝트 아이디** | O | 영문과 숫자만 입력 가능, **중복체크 필수** |
| **프로젝트 설명** | X | 프로젝트 목록에서 노출될 설명 |
| **목표 데이터 수량** | O | 숫자만 입력 가능 |
| **도움말** | X | 라벨러의 라벨링 화면에서 나타날 도움말 |

#### 4.1.2 메타 생성 (Metadata Setup)

메타는 라벨링 작업 시 입력할 이미지/프레임 관련 정보입니다.

**메타 생성 방법**:
1. "메타 추가하기" 버튼 클릭
2. 다음 항목 입력:
   - **메타 아이디**: 영문, 숫자만 입력 가능
   - **질의문**: 라벨러에게 보여줄 질문
   - **선택 항목**: 라벨러가 선택할 수 있는 옵션들

3. **입력 형식 선택**:
   - **텍스트**: 라벨러가 직접 텍스트 입력하도록 함
   - **라디오 버튼**: 미리 정의한 선택 항목 중 하나 선택하도록 함

**생성된 메타의 노출**: 라벨러 화면의 메타 탭에서 확인 가능

#### 4.1.3 라벨 생성 (Label Setup)

라벨은 라벨러가 실제 작업을 수행할 때 사용하는 범주입니다.

**라벨 생성 정보**:

| 필드 | 필수 | 설명 |
|------|------|------|
| **라벨명** | O | 라벨러가 작업 시 사용할 라벨명 |
| **라벨 아이디** | O | 영문, 숫자만 입력 가능 |
| **라벨 형태** | O | 선택: 바운딩박스, 폴리곤, 스켈레톤 중 하나 |
| **라벨 색상** | X | 라벨러 화면에서 표시될 색상 |

**라벨 생성 프로세스**:
1. 위 정보 입력
2. 아이콘 클릭 → 라벨이 하단에 생성

#### 4.1.4 속성 설정 (Attribute Setup)

속성은 하나의 라벨 내에서 추가적으로 분류할 세부 항목입니다.

**예시**: 라벨 "자동차" → 속성 "대형, 중형, 소형"

**속성 정보**:

| 필드 | 필수 | 설명 |
|------|------|------|
| **속성명** | X | 하나의 라벨 안에서 추가 분류할 항목 |
| **속성 선택 UI** | X | 라디오 버튼(선택 항목 정해짐) 또는 텍스트(입력형) |
| **속성 항목/문구** | X | 라디오 버튼 시: 표시할 항목명, 텍스트 시: 입력 가이드 |

**속성 추가 방법**:
1. "속성 추가" 버튼 클릭
2. 위 정보 입력
3. 추가된 속성은 우측 객체 탭에서 선택 가능

#### 4.1.5 스켈레톤 설정 (Skeleton Setup) - 선택사항

라벨 형태에서 "스켈레톤"을 선택했을 경우에만 나타납니다.

**스켈레톤 정보**:

| 필드 | 필수 | 설명 |
|------|------|------|
| **포인트명** | O | 라벨러가 작업할 포인트명 (예: 머리, 왼쪽어깨 등) |
| **포인트 ID** | O | 영문, 숫자만 입력 가능 |
| **포인트 색상** | X | 해당 포인트의 색상 |

**스켈레톤 작성 도구**:

| 아이콘 | 명칭 | 설명 |
|--------|------|------|
| 수정/편집 | 수정/편집 | 포인트 수정/편집 가능 |
| 파일 업로드 | 파일 업로드 | 우측 스켈레톤 영역에 이미지 업로드 (JPG, JPEG, PNG) |
| 포인트 | 포인트 | 우측 스켈레톤 영역에서 포인트 작업 (우클릭으로 포인트명 설정) |
| 이동 | 이동 | 우측 영역에서 포인트 위치 조정 |
| 선 그리기 | 선 그리기 | 포인트 간 연결선 그리기 |
| 삭제 | 삭제 | 우측 영역에서 포인트 삭제 |

#### 4.1.6 프로젝트 단계 설정 (Phase Setup)

데이터 작업 프로세스의 단계를 구성합니다.

**기본 데이터 작업 프로세스**:
```
1단계 가공 → 1차 검수 → 2차 검수 (더 줄이는 것은 불가능)
```

**단계 확장**:
- **"검수 추가"**: 검수 과정 추가 (최대 2단계 검수 가능)
  - 1단계 가공 → 1차 검수
  - 1단계 가공 → 1차 검수 → 2차 검수

- **"단계 추가"**: 가공 단계 추가 (최대 2단계까지 구성)
  - 1단계 가공 → 1차 검수 → 2단계 가공 → 1차 검수 → 2차 검수

**단계 설정 후 처리**:
1. "이전" 버튼: 기본정보/메타/라벨 화면으로 돌아가기
2. "생성" 버튼: 프로젝트 생성 완료 → 사용자 권한 부여 화면으로 이동

#### 4.1.7 사용자 권한 부여 (User Permission)

프로젝트 생성 후 라벨러들의 권한을 단계별로 설정합니다.

**권한 부여 방법**:
1. "사용자 추가" 버튼 클릭 → 팝업 노출
2. 다음 정보 선택:
   - **작업자 아이디**: 권한을 부여할 아이디 (중복 선택 가능)
   - **권한**: 부여할 권한 선택 (단일 선택)

3. "저장" 버튼 → 권한 부여 완료 → 권한 부여 화면에 추가

**권한 부여 화면 기능**:
- **권한 삭제 아이콘**: 부여한 권한 삭제
- **권한 수정 아이콘**: 부여한 권한을 다른 권한으로 수정
- **"비고" 열 더블클릭**: 라벨러의 특이사항 입력
- **"저장" 버튼**: 모든 권한과 비고 내용 저장

**"건너뛰기" 버튼**:
- 권한 부여 단계 건너띄고 프로젝트 목록 화면으로 이동
- 이후 프로젝트에서 "사용자 확인 및 추가" 메뉴로 언제든 추가 가능

**권한 부여 특수 사항**:
- 프로젝트 담당자, 업로더의 경우 1단계 추가 시 자동으로 2단계에도 추가
- 슈퍼관리자는 권한 부여 필요 없음 (모든 화면 접근 가능)

### 4.2 담당 프로젝트 목록 조회

**경로**: 프로젝트 관리 → 담당 프로젝트

관리자/프로젝트 담당자가 관리해야 하는 프로젝트 목록을 확인합니다.

**조회 방법**:

| 필터 | 설명 |
|------|------|
| **데이터 유형** | 전체, 이미지, 동영상 |
| **프로젝트 상태** | 전체, 마감, 진행, 대기 |
| **검색어** | 프로젝트명으로 검색 |

**상세보기**:
- 목록 최우측의 "상세보기" 버튼 클릭 → 프로젝트 상세 화면
- 프로젝트의 기본정보, 메타정보, 라벨정보, 완료 정보 확인 가능

### 4.3 프로젝트 완료 처리 (Project Completion)

프로젝트의 데이터를 현재 기준으로 묶어서 업로드하거나 모든 라벨러의 접근 권한을 제거합니다.

**완료 처리 프로세스**:
1. 완료여부 열에서 "완료" 버튼 클릭
2. 팝업 노출 → **버전 설명 필수 입력**
3. "확인" 버튼 클릭 → 프로젝트 완료 처리

**완료 처리 결과**:
- 작업자들이 해당 프로젝트에 접근 불가
- 완료여부 열: "완료 취소" 버튼으로 변경
- 프로젝트 상태 열: "마감"으로 변경

**완료 취소**:
1. "완료취소" 버튼 클릭
2. 팝업 노출 → **프로젝트 버전을 기존보다 높게 수정 필수**
3. "확인" 버튼 → 완료취소 처리

**완료취소 결과**:
- 작업자들이 해당 프로젝트에 다시 접근 가능
- 완료여부 열: "완료" 버튼으로 변경
- 프로젝트 상태 열: "진행"으로 변경

### 4.4 프로젝트 증강 처리 (Data Augmentation)

완료되지 않은 프로젝트의 **최종완료 라벨링 데이터**에 대해 5가지 증강 처리를 수행합니다.

**증강 종류**:
1. 밝게 (Brightness +)
2. 어둡게 (Brightness -)
3. 좌우반전 (Horizontal Flip)
4. 좌우반전 + 밝게 (Horizontal Flip + Brightness +)
5. 좌우반전 + 어둡게 (Horizontal Flip + Brightness -)

**증강 처리 프로세스**:
1. 증강 열에서 "증강가능" 버튼 클릭
2. 팝업 노출 → "확인" 버튼 클릭 → 데이터 증강 시작
3. 증강열 상태 변경: "증강가능" → "대기" → "진행중" → "완료"

**증강 버튼 상태**:

| 상태 | 설명 |
|------|------|
| **증강가능** | 최종완료된 라벨링 데이터가 있고 프로젝트가 마감상태가 아님 |
| **대기** | 증강 요청 후 대기 중 |
| **진행중** | 증강 진행 중 |
| **완료** | 증강 대상 데이터 전체 완료 |
| **부분성공** | 증강 대상 데이터 중 일부만 성공 |
| **실패** | 증강 대상 데이터 전체 증강 실패 |

**완료되지 않은 프로젝트의 증강 관리**:
1. 증강 열의 "완료" 버튼 클릭
2. 팝업 노출 → 다음 정보 선택:
   - **원시데이터번호**: 라벨링 최종 완료된 원시데이터
   - **원천데이터번호**: 원시데이터의 프레임 분할로 나온 데이터
   - **증강종류**: 5가지 증강 종류 선택

3. 증강 결과 이미지 표시 (클릭 시 원본 이미지 표시)

**증강 관리 옵션**:

| 옵션 | 설명 |
|------|------|
| **밝기** | 밝게, 어둡게, 좌우반전_밝게, 좌우반전_어둡게 증강에서 조정 가능 (기본값: ±60) |
| **수정** | 밝기 옵션 수정 후 클릭 시 선택한 원천데이터-증강옵션 재시작 |
| **삭제** | 해당 원천데이터-증강옵션 증강 데이터 삭제 |

**완료된 프로젝트의 증강 관리**:
- 완료된 프로젝트는 증강 작업 불가능
- 완료취소 후 증강 옵션 수정 가능

### 4.5 담당 프로젝트 데이터 목록 조회

**경로**: 프로젝트 관리 → 담당 프로젝트 → 특정 프로젝트

배정된 데이터 항목들이 노출됩니다.

**조회 방법**:

| 필터 | 설명 |
|------|------|
| **데이터 상태** | 특정 상태의 데이터 검색 |
| **검색어** | 특정 ID의 데이터 검색 |

**리스트 항목**:

| 항목 | 설명 |
|------|------|
| **데이터 상태** | 데이터의 현재 상태 (관리자 확인 요청 데이터는 맨 상단) |
| **작업자 ~ 검수자** | 데이터를 배정받은 작업자, 검수자 |
| **비고** | 라벨러가 작성한 관리자 확인 요청 내용 |

**데이터 배정 방식**:
- 작업자만 배정: 작업자가 직접 배정받아 작업한 데이터
- 작업자 ~ 검수자: 관리자가 한번에 설정하여 배정

### 4.6 데이터 배정 (Data Assignment)

**경로**: 프로젝트 관리 → 담당 프로젝트 → 특정 프로젝트 → "작업배정" 버튼

**배정 프로세스**:
1. "작업배정" 버튼 클릭 → 데이터 배정 화면
2. 다음 필터 설정:
   - **단계**: 1단계, 2단계 중 선택 (1단계 고정 또는 추가 선택)
   - **데이터 상태**: 대기, 가공완료, 1차 검수 완료 중 선택
   - **배정 수량**: 숫자 입력

3. "배정" 버튼 클릭 → 라벨러 설정 팝업
4. 작업자와 검수자 모두 선택 → "저장" 버튼 → 배정 완료

**중요 사항**:
- 관리자가 데이터를 배정할 경우 **작업자 ~ 검수자까지 한번에 설정** 필수
- 작업자만 배정되어 있는 경우: 작업자가 직접 본인 화면에서 배정받은 경우

### 4.7 사용자 확인 및 추가 (User Management)

**경로**: 프로젝트 관리 → 담당 프로젝트 → 특정 프로젝트 → "사용자 확인" 버튼

프로젝트에 추가된 사용자를 확인하고 권한을 관리합니다.

**조회 방법**:

| 필터 | 설명 |
|------|------|
| **단계** | 전체, 1단계, 2단계 |
| **권한** | 전체, 프로젝트 담당자, 업로더, 검수자, 작업자 |

**사용자 관리 기능**:
- **하단 목록**: 이미 추가된 사용자 확인
- **셀렉트 박스**: 사용자의 권한 직접 수정
- **삭제 아이콘**: 선택한 사용자의 권한 삭제
- **"저장" 버튼**: 모든 수정 내용 저장

**사용자 추가**:
1. "사용자 추가" 버튼 클릭 → 팝업 노출
2. 다음 정보 선택:
   - **작업자 아이디**: 아이디 선택 (중복 선택 가능)
   - **단계**: 1단계, 2단계 중 선택 (1단계 고정 또는 추가)
   - **권한**: 권한 선택 (단일 선택)

3. "저장" 버튼 → 사용자 추가 완료

**특수 사항**:
- 프로젝트 담당자, 업로더의 경우 단계가 "전체"로 반영 처리

### 4.8 작업 내용 및 관리자 확인 요청 데이터 확인

**경로**: 프로젝트 관리 → 담당 프로젝트 → 특정 프로젝트 → 특정 데이터 클릭

라벨러 작업 화면으로 이동하여 실제 작업 내용을 확인합니다.

**관리자 확인 요청 데이터 처리**:

라벨러가 "관리자 확인 요청"으로 프레임을 보낸 경우, 상단 버튼이 다음으로 변경됩니다:
- **"확인 및 재배정"**: 문제 없음을 확인하고 라벨러에게 재배정
- **"폐기"**: 프레임에 문제가 있어 삭제 처리

**"확인 및 재배정" 프로세스**:
1. 버튼 클릭 → 확인 사유 입력 팝업 노출
2. 사유 입력 또는 "문제 없음" 선택
3. "확인" 버튼 → 프레임 재배정 및 사유 이슈탭 기재

**"폐기" 프로세스**:
1. "폐기" 버튼 클릭 → 프레임 삭제 처리
2. 삭제된 프레임은 작업 대상에서 제외

**이슈 탭 확인**:
- 라벨러가 "관리자 확인 요청"으로 보낸 사유는 이슈탭에 기재
- 관리자 응답도 이슈탭에 기재되어 라벨러가 확인 가능

### 5.1 작업 프로젝트 목록 조회

**경로**: 프로젝트 관리 → 작업 프로젝트

작업자/검수자 권한을 배정받은 프로젝트 목록이 노출됩니다.

**리스트 항목**:

| 항목 | 설명 |
|------|------|
| **배정** | 배정 상태인 데이터 수 (클립) |
| **작업중** | 현재 작업중인 데이터 수 (프레임) |
| **반려** | 반려된 데이터 수 (프레임) |
| **관리자확인요청** | 관리자 확인 요청으로 보낸 데이터 수 (프레임) |

### 5.2 작업 프로젝트 데이터 목록 조회

상세한 내용은 운영자 매뉴얼의 "3.3 데이터 작업 프로세스"를 참고하세요.

**관리자 추가 기능**: 
- 관리자는 작업 중 "관리자 확인 요청" 기능을 사용할 수 없음
- 직접 판단하여 작업을 진행해야 함

## 6. 영상/이미지 관리

### 6.1 영상/이미지 목록 조회

**경로**: 영상/이미지 관리 메뉴 선택

저작도구에서 보유하고 있는 동영상과 이미지의 목록을 확인하고 관리합니다.

**포함 데이터**:
- "관제지원시스템"에서 전달받은 동영상/이미지
- "업로드/생성 데이터 관리"에서 "등록" 과정을 거친 AI 생성 동영상/이미지
- "업로드/생성 데이터 관리"에서 "등록" 과정을 거친 업로더 업로드 동영상/이미지

**조회 방법**:

| 필터 | 설명 |
|------|------|
| **검색어** | 특정 영상/이미지명으로 검색 |
| **적용 프로젝트** | 이미 데이터로 배정된 영상/이미지 검색 |
| **이벤트 유형** | 특정 이벤트를 갖는 영상/이미지 검색 |
| **이벤트명** | 등록된 이벤트의 구체적 내용으로 검색 |

**상세 검색 (우측 "상세검색" 클릭)**:

| 필터 | 설명 |
|------|------|
| **날씨** | 특정 날씨의 영상/이미지 |
| **시간대** | 주간, 야간, 전체 |
| **계절** | 봄, 여름, 가을, 겨울, 전체 |
| **개인정보 포함여부** | O, X, 전체 |
| **비식별화 포함여부** | O, X, 전체 |
| **AI 생성 여부** | O, X, 전체 |
| **사용자 업로드 여부** | O, X, 전체 |
| **생성일** | 특정 기간 설정 |

**상세정보 팝업**:
- 목록의 영상/이미지명 클릭 → 상세 정보 팝업
- **"기본 정보" 탭**: 파일크기, 영상길이 등 변경 불가능한 정보
- **"메타데이터 수정" 탭**: 메타데이터 확인 및 수정/저장 가능
- 동영상의 경우 재생 가능 (재생 불가능 시 안내 메시지)

### 6.2 영상/이미지 프로젝트 배정

**중요**: 영상/이미지의 미리 많은 배정은 라벨러의 데이터 부족으로 인한 작업 지연을 방지합니다.

**배정 프로세스**:
1. 특정 영상/이미지의 체크박스 선택 (중복 선택 가능)
2. "프로젝트 배정" 버튼 클릭 → 프로젝트 선택 팝업
3. 배정할 프로젝트 선택 (단일 선택) → "선택" 버튼
4. 프레임 분할 기준 팝업 노출 (이미지만 배정할 경우 이 단계 생략)

**프레임 분할 기준 설정**:

상단에 표시되는 정보:
- **영상/이미지명**: 선택한 영상 이름
- **영상의 길이**: 총 영상 길이
- **초당 프레임 기준(FPS)**: 원본 FPS

분할 기준 설정:

| 필드 | 설명 |
|------|------|
| **분할 단위** | 초당, 분당, 시간당, 전체 중 선택 |
| **프레임 수** | 숫자만 입력 가능 |

**분할 기준 규칙**:
- 프레임 분할 시 "초당 프레임 기준(FPS)"보다 작아야 분할 가능
- 분당 분할: 1분 이상의 영상에서만 가능
- 시간당 분할: 1시간 이상의 영상에서만 가능

**배정 완료**:
1. 분할 기준 설정 후 "업로드" 버튼
2. 영상이 프레임 분할 과정을 거쳐 프로젝트에 배정
3. 배정된 데이터는 "프로젝트 관리 → 담당 프로젝트"에서 확인

**데이터 상태**:
- **변환 대기**: 프레임 분할 대기 중
- **변환중**: 프레임 분할 진행 중
- **변환오류**: 프레임 분할 오류 발생
- **배정대기**: 라벨러에게 배정 가능한 상태

**중요**: 라벨러에게 작업을 배정하는 것은 데이터 상태가 "배정대기"일 때만 가능

## 7. 업로드/생성 데이터 관리

### 7.1 업로드/생성 데이터 목록 조회

**경로**: 업로드/생성 데이터 관리 메뉴 선택

업로더가 업로드하거나 AI로 생성한 뒤 **1차 검수 완료**한 동영상/이미지의 목록을 확인합니다.

**중요**: AI로 생성했을 경우 업로더가 1차 검수 필수

**조회 방법**:

| 필터 | 설명 |
|------|------|
| **데이터 상태** | 업로드, 생성 중 선택 |
| **데이터 유형** | 이미지, 동영상 중 선택 |
| **이벤트 유형** | 현재는 침수만 가능 |
| **검색어** | 특정 ID로 검색 |

### 7.2 업로더가 생성/업로드한 AI 동영상/이미지 조회

**경로**: 업로드/생성 데이터 관리 → 동영상/이미지 ID 클릭

상세 정보 팝업이 노출됩니다.

**팝업 기능**:
- **동영상 재생**: 동영상 재생 가능 (재생 불가 시 안내 메시지)
- **"생성 정보" 탭**: 생성/업로드 시 사용한 프롬프트, 참고 이미지 표시
- **"메타데이터 수정" 탭**: 메타데이터 확인 및 수정/저장 가능

**관리자의 2차 검토**:
1. 업로더가 업로드/생성한 동영상/이미지 검토
2. 사용 가능 판정 시 "등록" 버튼 클릭
3. 데이터가 "영상/이미지 관리" 메뉴로 이동
4. "영상/이미지 관리"에서만 프로젝트 배정 가능

**데이터 삭제**: "삭제" 클릭 시 동영상/이미지 삭제 처리

**중요**: "영상/이미지 관리" 메뉴로 이동되어야지만 프로젝트에 배정 가능하므로, "등록" 과정은 필수

## 8. 대시보드 - 담당 프로젝트

### 8.1 담당 프로젝트 대시보드 조회 및 다운로드

**경로**: 대시보드 → 담당 프로젝트

작업자들이 진행한 작업의 통계를 월별/일별로 확인합니다.

**역할**:
- 작업자들의 작업량 및 작업 완성도 파악
- 작업 정확도가 낮은 작업자 개별 관리
- 단계별 작업량 확인으로 병목 현상 방지

**통계 업데이트**: 1시간마다 갱신 (우측에 업데이트 시기 표시)

**통계 조회 방법**:

| 옵션 | 설명 |
|------|------|
| **프로젝트** | 조회를 원하는 프로젝트 선택 |
| **월별/일별** | "월" 버튼: 월별 통계, "일" 버튼: 일별 통계 |
| **기간** | 조회 기간 설정 |

**통계 내용**:

**"전체 작업내역"**:
- 데이터 수량: 배정대기 → 배정 → 가공완료 → 1차 검수완료 순서로 이동
- 특정 열에 수가 많을 경우: 해당 단계에서 로드 발생 의미

**"작업자별 작업내역"**:
- 라벨러가 같은 프로젝트에서도 여러 권한을 가질 수 있으므로 권한별 표시
- "완료", "반려" 수는 클립 수이며 괄호 안은 프레임 수
- "반려"가 "-"로 표시: 최종 라벨러라 반려받을 수 없음

**엑셀 다운로드**: "다운로드" 버튼 클릭 시 통계가 엑셀 파일로 다운로드

본인이 진행한 작업의 통계를 확인합니다 (라벨러와 동일).

## 10. 게시판

### 10.1 게시판 목록 조회

**경로**: 게시판 메뉴 선택

관리자가 발행한 게시글 목록을 확인합니다.

**조회 방법**:

| 필터 | 설명 |
|------|------|
| **제목** | 제목으로 게시글 검색 |
| **내용** | 내용으로 게시글 검색 |

**게시글 삭제**: 특정 게시글의 체크박스 선택 → "삭제" 버튼

### 10.2 게시글 작성

**경로**: 게시판 → "게시글 작성" 버튼

라벨러들을 위한 공지글 및 가이드라인을 작성합니다.

**작성 항목**:

| 항목 | 설명 |
|------|------|
| **게시글 제목** | 필수 |
| **상단 고정 여부** | 체크박스로 고정 처리 여부 선택 |
| **게시글 내용** | 필수 |
| **첨부파일** | 선택사항 (가이드라인 등 첨부 가능) |

**작성 후 처리**:
- **"취소"**: 작성한 게시글 미저장, 목록 화면으로 이동
- **"저장"**: 게시글만 저장 (관리자만 확인 가능)
- **"등록"**: 게시글 발행 (라벨러들도 확인 가능)

### 10.3 게시글 내용 조회 및 수정

**경로**: 게시판 → 특정 게시글 선택

게시글 내용 화면으로 이동합니다.

**기능**:
- **첨부파일 다운로드**: 첨부파일 있을 시 클릭하여 다운로드
- **"발행 취소"**: 게시글을 "저장" 단계로 변경 (라벨러에게 비노출)
- **"목록으로"**: 게시글 목록 화면으로 이동
- **"수정"**: 게시글 수정 화면으로 이동

**게시글 수정**:
1. "수정" 버튼 클릭 → 수정 화면
2. 다음 항목 수정 가능:
   - 게시글 제목
   - 상단 고정 여부
   - 게시글 내용
   - 첨부파일 추가/삭제

3. **"재발행"** 버튼 클릭 → 수정된 게시글 발행 (기존 "저장" 버튼 대신)

## 12. 업로드/생성 (라벨러와 동일)

**경로**: 업로드/생성 메뉴 선택

AI로 동영상이나 이미지를 생성합니다.

**중요 사항**:
- 프로젝트 담당자도 "업로드/생성" 메뉴를 사용하려면 "업로더" 권한 필수

**생성 가능한 모델**:
- TEXT-TO-IMAGE: 텍스트 프롬프트로 이미지 생성
- IMAGE-TO-IMAGE: 기존 이미지 기반 새로운 이미지 생성
- IMAGE-TO-VIDEO: 이미지 기반 동영상 생성

**생성 프로세스**:
1. 동영상/이미지 형태 선택 (필수)
2. 메타 항목 선택 또는 프롬프트 입력 (영어만 가능)
3. 선택사항: 이미지 첨부 (장치 업로드 또는 프로젝트 프레임)
4. "생성" 버튼 → 생성 시작
5. 생성 완료 후 1차 검토
6. "업로드" 버튼 → 최종 업로드

**생성 시 적용 가능한 메타**:
- 이벤트 유형: 침수만 가능
- 시간대: 주간, 야간
- 계절: 봄, 여름, 가을, 겨울
- 날씨: 안개, 비, 눈
- 지형: 고속도로, 골목길, 지하도, 터널, 강변

## 13. 주요 워크플로우 및 체계

### 13.1 프로젝트 전체 생명주기

```
1. 프로젝트 생성 (기본정보, 메타, 라벨, 단계, 권한 설정)
                 ↓
2. 영상/이미지 배정 (프레임 분할 및 프로젝트 배정)
                 ↓
3. 데이터 배정 (작업자/검수자 지정)
                 ↓
4. 라벨링 작업 (작업자 작업 → 검수자 검수)
                 ↓
5. 작업 모니터링 (대시보드로 진행 상황 확인)
                 ↓
6. 관리자 확인 요청 처리 (문제 프레임 검토 및 처리)
                 ↓
7. 프로젝트 완료 (데이터 확정 및 라벨러 접근 차단)
                 ↓
8. 데이터 증강 (선택사항, 데이터 부족 시)
                 ↓
9. 데이터 배포 (최종 데이터셋 활용)
```

### 13.2 일일 관리자 업무

1. **대시보드 확인**
   - 담당 프로젝트의 일일 진행 상황 확인
   - 병목 단계 및 저조한 작업자 파악

2. **데이터 배정**
   - 부족한 데이터 자동 배정
   - 작업자/검수자 균형 조정

3. **관리자 확인 요청 처리**
   - 라벨러가 제출한 문제 프레임 검토
   - "확인 및 재배정" 또는 "폐기" 판단

4. **가이드라인 배포**
   - 필요시 게시판에 새로운 가이드라인 올리기
   - 라벨러 교육 및 품질 개선

5. **영상/이미지 배정**
   - 미리 배정하여 라벨러의 데이터 부족 예방

### 13.3 데이터 품질 관리

**작업 정확도 모니터링**:
- 대시보드의 "작업자별 작업내역"에서 반려 빈도 확인
- 반려율이 높은 작업자 개별 지도

**병목 현상 해결**:
- "전체 작업내역"에서 특정 단계의 데이터 수가 많으면 해당 단계 확인
- 검수자 추가 배정 또는 자동화 도구 활용

**라벨러 피드백**:
- 이슈 탭을 통해 라벨러 문의 사항 파악
- 공지사항으로 피드백 공유

### 13.4 AI 생성/업로드 데이터 관리

**업로더 생성 데이터 흐름**:
```
업로더가 생성/업로드
    ↓
"업로드/생성 데이터 관리"에 노출
    ↓
관리자 2차 검토
    ↓
"등록" 버튼 (필수!)
    ↓
"영상/이미지 관리"로 이동
    ↓
프로젝트에 배정 가능
```

**중요**: "등록" 과정을 거쳐야만 "영상/이미지 관리"에 나타나고 프로젝트 배정 가능

## 14. 단축키 및 효율성 팁

### 14.1 라벨링 단축키 (관리자가 작업 프로젝트에서 사용)

| 단축키 | 기능 |
|--------|------|
| **W/A/S/D** | 프레임 이동 (W: 첫, A: 이전, S: 끝, D: 다음) |
| **Ctrl + S** | 프레임 저장 |
| **Esc** | 도구 닫기/생성 취소 |
| **Ctrl + Z** | 실행 취소 (비식별화 제외) |
| **Delete, R** | 객체 삭제 |
| **Ctrl + C/V** | 객체 복사/붙여넣기 |
| **Ctrl + Shift + C/V** | 전체 객체 복사/붙여넣기 |
| **T** | 라벨 표시/숨김 |
| **F** (폴리곤) | 점 추가 |
| **Q** (폴리곤) | 자동 완료 |

### 14.2 데이터 배정 효율화

- **사전 배정**: 영상/이미지를 미리 충분히 배정하여 라벨러가 데이터 부족 상황 예방
- **자동 배정**: 라벨러가 데이터 10개 이하일 때 자동 배정 기능 활용
- **단계별 배정**: 작업 프로세스의 단계별로 필요한 수량만 배정하여 효율성 극대화

### 14.3 대시보드 활용

- **1시간 단위 갱신**: 통계는 1시간마다 업데이트되므로 정기적 확인 추천
- **엑셀 다운로드**: 통계를 엑셀로 다운로드하여 추가 분석 가능
- **권한별 통계**: 작업자별/단계별 통계로 상세한 진행 상황 파악

## 15. 트러블슈팅 및 주의사항

### 15.1 데이터 배정 시 주의사항

- **필수 설정**: 관리자가 데이터 배정 시 작업자 ~ 검수자까지 한번에 설정
- **단계 선택**: 프로젝트 단계와 일치하는 단계 선택
- **상태 확인**: 영상은 프레임 분할 후 "배정대기" 상태에서만 배정 가능

### 15.2 프로젝트 완료 후 처리

- **완료 후 수정 불가**: 프로젝트 완료 후 라벨러는 접근 불가
- **버전 관리**: 완료취소 시 버전 번호를 기존보다 높게 설정
- **데이터 보존**: 완료된 프로젝트의 데이터는 안전하게 보존되므로 필요시 다시 열 수 있음

### 15.3 AI 생성 데이터 관리

- **순차 처리**: AI 생성은 순차적으로 진행되므로 대량 생성 시 충분한 대기 시간 필요
- **1차 검수 필수**: 업로더의 1차 검수 없이는 시스템에 반영 불가
- **관리자 2차 검토**: "등록" 과정을 통해 최종 검증 필수

### 15.4 프레임 분할 설정

- **FPS 기준**: 분할 프레임 수는 원본 FPS보다 작아야 함
- **분할 단위 선택**: 초당, 분당, 시간당 중 프로젝트 특성에 맞는 단위 선택
- **분할 시간 필요**: 영상은 프레임 분할 과정 시간이 소요되므로 여유있게 배정

### 15.5 라벨러 권한 관리

- **다중 권한 허용**: 동일 라벨러가 다른 프로젝트에서 다른 권한 보유 가능
- **프로젝트 담당자 특수성**: 프로젝트 담당자가 "업로드/생성" 메뉴 접근하려면 업로더 권한 필수
- **권한 변경 용이**: 언제든 사용자 확인 및 추가 메뉴에서 권한 수정 가능

## 16. 특이사항 및 주요 참고사항

### 16.1 시스템 특성

- **프레임 번호**: F (실제 추출), I (분할 시 순차 번호)
- **자동 저장**: 라벨링 작업은 프레임 이동 시 자동 저장
- **1시간 단위 통계**: 대시보드는 1시간마다 갱신

### 16.2 데이터 상태 플로우

```
배정대기 → 배정 → 가공완료 → 1차 검수완료 → (선택) 2차 검수완료 → 최종완료
```

### 16.3 AI 기능 활용

**Auto Labeling 대상**:
- 사람, 자전거, 자동차, 오토바이, 버스, 트럭 등 일부 객체만 자동 라벨링 가능

**프롬프트 입력**:
- 반드시 영어로만 입력
- IMAGE-TO-IMAGE, IMAGE-TO-VIDEO 사용 시 이미지 첨부 가능

### 16.4 증강 기능

- **증강 대상**: 최종완료된 라벨링 데이터만 증강 가능
- **증강 종류**: 5가지 (밝게, 어둡게, 좌우반전, 좌우반전+밝게, 좌우반전+어둡게)
- **비용 절감**: 라벨링된 데이터를 증강하여 데이터 수량 확보
- **완료 프로젝트 제외**: 완료된 프로젝트는 증강 불가 (완료취소 필요)
