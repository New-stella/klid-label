## 1. 개요

본 문서는 **AI CCTV 관제 학습 저작도구 시스템의 라벨러(운영자) 사용법**을 설명합니다.

라벨러는 CCTV 영상에서 추출한 프레임에 대해 다양한 라벨링 작업을 수행하여 학습 데이터셋을 구축합니다. 이 문서는 시스템의 각 메뉴와 기능, 그리고 실제 작업 프로세스를 상세히 기술합니다.

---

## 2. 권한 관리

### 2.1 사용자 역할 구분

라벨러는 **3가지 권한**으로 분류되며, 동일 아이디로 여러 권한을 중복 보유할 수 있습니다:

- **작업자**: 라벨링 작업 수행 권한
- **검수자**: 작업자의 작업 결과 검증 권한  
- **업로더**: 영상/이미지 업로드 및 AI 생성 권한

### 2.2 권한별 메뉴 접근 권한

| 메뉴 | 작업자 | 검수자 | 업로더 |
|------|--------|--------|--------|
| **대시보드** | O | O | - |
| **프로젝트 관리** | O | O | - |
| **게시판** | O | O | O |
| **연습장** | O | O | O |
| **업로드/생성** | O | - | O |

### 2.3 권한 조합에 따른 메뉴 접근

- **작업자/검수자**: 대시보드, 프로젝트 관리, 게시판, 연습장 4개 메뉴 접근
- **업로더**: 게시판, 연습장, 업로드/생성 3개 메뉴 접근
- **작업자 + 업로더**: 5개 메뉴 모두 접근 가능 (대시보드, 프로젝트, 게시판, 연습장, 업로드/생성)

### 2.4 각 메뉴 설명

| 메뉴 | 설명 |
|------|------|
| **대시보드** | 진행한 작업의 통계를 월별/일별로 확인할 수 있는 메뉴 |
| **프로젝트 관리** | 배정받은 프로젝트, 데이터 목록 확인 및 라벨링 작업 수행 메뉴 |
| **게시판** | 관리자가 올린 공지사항, 가이드라인, 파일 다운로드 메뉴 |
| **연습장** | 라벨링 기능 및 도구를 미리 연습하고 테스트하는 메뉴 |
| **업로드/생성** | AI로 영상/이미지를 생성 및 업로드하는 메뉴 |

## 3. 프로젝트 관리

### 3.1 프로젝트 목록 조회

**경로**: 프로젝트 관리 메뉴 선택

작업자/검수자 권한을 배정받은 프로젝트 목록 화면이 노출됩니다.

#### 리스트 항목 설명

| 항목 | 설명 |
|------|------|
| **배정** | 배정 상태인 데이터 수 (클립 단위) |
| **작업중** | 현재 작업 중인 데이터 수 (프레임 단위) |
| **반려** | 검수자가 반려한 데이터 수 (프레임 단위) |
| **관리자확인요청** | 작업자가 관리자 확인 요청으로 보낸 데이터 수 (프레임 단위) |

### 3.2 데이터 목록 조회

**경로**: 프로젝트 관리 → 특정 프로젝트 선택

배정된 데이터 목록이 노출됩니다.

#### 데이터 자동 배정

- 보유한 데이터가 **10개 이하**인 경우: "작업배정" 버튼 클릭 시 최대 **1개까지 자동 배정**

#### 조회 방법

| 검색 옵션 | 설명 |
|----------|------|
| **데이터 상태** | 특정 상태를 갖는 데이터 검색 (배정/작업중/반려 등) |
| **검색어** | 특정 ID를 갖는 데이터 검색 |

#### 리스트 항목 설명

| 항목 | 설명 |
|------|------|
| **단계-작업** | 배정받은 데이터의 단계와 작업 유형 |
| **남은 작업/전체 프레임 수** | 전체 프레임 대비 저장/승인/반려되지 않은 프레임 수 |
| **전체 프레임 수** | "폐기" 상태를 제외한 전체 프레임 수 |
| **남은 작업** | 담당자가 저장/제출하지 않은 프레임 수 |
| **작업자 남은 작업** | 배정완료, 검수반려 상태의 프레임 |
| **검수자 남은 작업** | 검수요청, 검수반려 상태의 프레임 |
| **데이터 상태** | 배정받은 데이터의 현재 상태 |
| **배정일** | 데이터를 배정받은 날짜 |

#### 3.3.3 비식별화 (De-identification)

CCTV 영상에서 찍힌 개인정보(얼굴, 번호판, 전화번호 등)를 보호하는 필수 작업입니다.

**중요**: 비식별화는 **다른 라벨링 작업(바운딩박스, 폴리곤 등)을 진행하기 전에 반드시 먼저 수행**해야 합니다.

**작업 방법**:
1. 라벨링 화면 좌측의 비식별화 아이콘 클릭
2. "브러쉬"와 "지우개", 크기를 설정하는 팝업 노출
3. "브러쉬" 선택 후 비식별화할 영역을 드래그하여 적용
4. 실수한 부분은 "지우개"로 클릭하여 삭제 가능

#### 3.3.4 AI Tool

라벨러가 객체의 일부분만 클릭해도 **자동으로 객체 테두리를 잡아주는 AI 기반 도구**입니다.

**작업 방법**:
1. 라벨링 화면 좌측의 AI Tool 아이콘 클릭
2. 작업할 라벨링 형태와 라벨명 선택
3. 라벨링할 객체의 일부분 클릭
4. 객체가 완전히 포함될 때까지 계속 클릭
5. 우측 객체 탭에서 "생성" 버튼 클릭

**"일반" 버튼 사용**:
- 연속되지 않은 객체 라벨링
- 해당 프레임에만 라벨 생성

**"트랙" 버튼 사용**:
- 연속된 객체를 자동 추적하여 라벨링
- 최초 생성 프레임부터 마지막 프레임까지 동일 위치/크기로 자동 생성
- 마지막 프레임에서 위치/크기 수정 시 '트래킹' 버튼 활성화
- '트래킹' 버튼 클릭 시 중간 프레임들의 라벨이 자동으로 계산되어 변경
- **주의**: 사용자가 직접 수정한 프레임은 자동 계산 제외

#### 3.3.5 Auto Labeling

**사람, 자전거, 자동차, 오토바이, 버스, 트럭 등** 특정 객체를 자동으로 라벨링하는 기능입니다.

**작업 방법**:
1. 라벨링 화면 좌측의 Auto Labeling 아이콘 클릭
2. 라벨링 형태, 객체 종류, 라벨명 선택
3. 자동 라벨링 완료 후 우측 객체 탭에서 속성 정보만 선택

**"일반" 버튼**:
- 해당 프레임에만 라벨 생성

**"트랙" 버튼**:
- 최초 생성 프레임부터 마지막 프레임까지 자동 추적
- 마지막 프레임에서 수정 시 '트래킹' 버튼 활성화
- **주의**: 사용자 수정 프레임은 자동 계산 제외

#### 3.3.6 바운딩 박스 (Bounding Box)

객체를 **사각형 모양으로 라벨링**할 때 사용하는 기본 라벨링 도구입니다.

**작업 방법**:
1. 라벨링 화면 좌측의 바운딩박스 아이콘 클릭
2. 라벨명 선택
3. 객체의 시작점 클릭 → 마우스 이동 → 대각선 끝점 클릭
4. 두 번의 클릭으로 라벨링 완료
5. 우측 객체 탭에서 속성 정보 선택

**"일반" 버튼**:
- 해당 프레임에만 라벨 생성

**"트랙" 버튼**:
- 객체 자동 추적으로 연속 프레임 라벨링
- 마지막 프레임 수정 시 '트래킹' 활성화
- **주의**: 사용자 수정 프레임은 자동 계산 제외

#### 3.3.7 폴리곤 (Polygon)

객체의 **정확한 모양에 맞춰 라벨링**할 때 사용하는 도구입니다.

**작업 방법**:
1. 라벨링 화면 좌측의 폴리곤 아이콘 클릭
2. 라벨명 선택
3. 객체의 시작점 클릭
4. 마우스 이동하며 객체의 테두리를 따라 클릭
5. 시작점 다시 클릭하여 폴리곤 완성
6. 우측 객체 탭에서 속성 정보 선택

**"일반" 버튼**:
- 해당 프레임에만 라벨 생성

**"트랙" 버튼**:
- 객체 자동 추적
- **주의**: 사용자 수정 프레임은 자동 계산 제외

**폴리곤 편집 단축키**:
- **F**: 폴리곤 생성 중 현재 마우스 위치에 점 추가
- **Q**: 폴리곤 자동 완료 (마지막 점과 시작점 자동 연결)
- **Shift + 클릭**: 점 수정 (순서대로 클릭하여 조정)
- **Ctrl + 클릭**: 점 삭제

#### 3.3.8 스켈레톤 (Skeleton)

**사람의 관절을 라벨링**할 때 사용하는 도구입니다.

**작업 방법**:
1. 라벨링 화면 좌측의 스켈레톤 아이콘 클릭
2. 라벨명 선택
3. 사람의 시작점 클릭
4. 마우스 이동하여 대각선 끝점 클릭 → 스켈레톤 자동 생성
5. 작성된 스켈레톤 포인트명에 맞게 각 포인트 위치 조정
6. 모든 포인트 조정 완료 시 라벨링 작업 완료

#### 3.3.9 객체 탭 (Object Tab)

라벨링된 객체들의 정보를 표시하고 관리하는 탭입니다.

**기능**:
- **라벨 변경**: 셀렉트 박스에서 같은 종류 내 다른 라벨로 변경
- **속성 선택**: 라디오 버튼으로 라벨의 속성 선택
- **잠금**: 라벨 수정/이동 불가능하게 처리 (상위 항목 잠금 시 하위도 자동 잠금)
- **뷰어**: 라벨 숨김 처리 (상위 항목 숨김 시 하위도 자동 숨김)
- **삭제**: 라벨 삭제
- **복사**: 라벨 복사 후 이미지 내 특정 영역 클릭하면 동일 형태의 라벨 복사 생성

#### 3.3.10 트랙 연결 (Track Connection)

특정 객체가 **연속된 프레임에 계속 나타날 경우** 자동으로 처리해주는 기능입니다.

**트랙 기능의 동작**:
1. "트랙"으로 라벨 생성하면 최초 프레임부터 마지막 프레임까지 동일 위치/크기의 라벨 자동 생성
2. 마지막 프레임에서 위치/크기 수정 시 '트래킹' 버튼 활성화
3. '트래킹' 클릭 시 첫-마지막 프레임 사이의 프레임들이 자동으로 계산되어 변경
4. **주의**: 사용자가 직접 수정한 프레임은 자동 계산 제외

**트랙 관리 기능**:
- **트랙 고유 번호**: 트랙 생성 시 자동 배정 및 상단 표시
- **삭제 아이콘**: 해당 프레임부터 뒷 프레임의 트랙 라벨 삭제 (객체가 사라졌을 때 사용)
- **변경 버튼**: 트랙 고유 번호 변경 (객체가 가려졌다가 다시 나타났을 때 사용)
  - 예: 사람이 자동차에 가려졌다가 다시 보였을 경우 하나의 트랙으로 연결

#### 3.3.11 메타 탭 (Meta Tab)

이미지와 관련된 **텍스트 정보를 입력하거나 선택**하는 탭입니다.

**기능**:
- 텍스트 입력 또는 라디오 버튼으로 메타데이터 입력
- "다음 프레임에 적용" 버튼 클릭 시 해당 메타 내용이 이후 모든 프레임에 일괄 적용

#### 3.3.12 라벨링 작업 완료 후 제출

**작업자 화면의 제출 프로세스**:

1. **자동 저장**: 프레임 이동 시 자동으로 저장
2. **수동 저장**: 필요시 "저장" 버튼으로 명시적 저장 가능
3. **제출 조건**: 모든 프레임이 "저장" 처리되어야 제출 가능
4. **제출 버튼**: 마지막 프레임에서만 노출
5. **제출 결과**: 해당 데이터가 작업 완료 처리되고 검수자에게 검수 요청으로 전달

**제출 불가 상황**:
- 관리자 확인 요청으로 보낸 프레임이 있을 경우
- 저장되지 않은 프레임이 있을 경우

**검수자 화면의 제출 프로세스**:

1. **승인**: "승인" 버튼으로 프레임 승인 처리
2. **반려**: "반려" 버튼으로 프레임 재작업 요청
3. **제출 조건**: 모든 프레임이 "승인" 또는 "반려" 처리되어야 제출 가능
4. **제출 전 수정**: "제출" 버튼 클릭 전에는 승인/반려 처리 변경 가능
5. **제출 결과**:
   - "승인" 처리 데이터: 승인 완료 처리
   - "반려" 처리 데이터: 작업자에게 전달

**제출 불가 상황**:
- 관리자 확인 요청으로 보낸 프레임이 있을 경우
- 승인/반려되지 않은 프레임이 있을 경우

**프레임 상태별 테두리 색상**:
| 상태 | 표시 방식 |
|------|----------|
| 현재 보고 있는 프레임 | 약간 크게 표시 |
| 반려된/반려한 프레임 | 주황색 테두리 |
| 관리자 확인 요청 프레임 | 붉은색 테두리 |
| 저장된 프레임 | 연두색 테두리 |

#### 3.3.13 라벨링 작업 중 이슈사항/문의사항

**이슈 탭의 역할**:
- 라벨러가 관리자 확인 요청으로 특정 프레임을 보내거나 검수자에게 반려받았을 경우 사유 노출
- 관리자/작업자/검수자가 서로 소통할 수 있는 창구

**관리자 확인 요청**:
- 용도: 작업 진행 중 문의사항이 있거나 프레임 추출에 문제가 있어 폐기를 요청할 경우
- 방법: "관리자 확인 요청" 버튼 클릭 → 사유 입력/선택 → "확인" 버튼
- 결과: 내용이 관리자에게 전달되고 이슈 탭에 기재

**검수자의 반려**:
- 용도: 작업자가 라벨링을 잘못 진행했을 경우
- 방법: "반려" 버튼 클릭 → 반려 사유 입력/선택 → "확인" 버튼
- 결과: 내용이 저장되고 추후 데이터 제출 시 작업자에게 전달, 이슈 탭에 기재

## 4. 대시보드

### 4.1 대시보드 조회 및 다운로드

라벨러가 진행한 작업 통계를 확인하는 메뉴입니다.

**통계 업데이트**: 1시간마다 업데이트 (우측에 업데이트 시기 표시)

**통계 조회 방법**:

| 옵션 | 설명 |
|------|------|
| **프로젝트** | 조회를 원하는 프로젝트 선택 |
| **월별/일별** | "월" 버튼: 월별 통계, "일" 버튼: 일별 통계 |
| **기간** | 조회 기간 설정 (월 선택 시 월 달력, 일 선택 시 일 달력) |

**통계 표시**:
- 라벨러가 같은 프로젝트에서도 여러 권한을 가질 수 있으므로 권한별로 표시
- "완료", "반려" 수는 클립 수이며, 괄호 안의 숫자는 프레임 수

**엑셀 다운로드**: "다운로드" 버튼 클릭 시 조회한 통계가 엑셀 파일로 다운로드

## 7. 업로드/생성

### 7.1 업로드하거나 생성 후 업로드 완료된 동영상/이미지 목록

**경로**: 업로드/생성 메뉴 선택

업로더가 업로드하거나 AI로 생성 후 업로드한 동영상/이미지의 목록입니다.

**표시 조건**:
- AI 생성의 경우: 업로더가 생성 완료된 동영상/이미지를 1차 검토한 후 "업로드"해야만 목록에 노출
- 목록에 노출된 데이터만 관리자, 프로젝트 담당자 측에서 확인 가능

**조회 방법**:

| 검색 옵션 | 설명 |
|----------|------|
| **데이터 상태** | 특정 데이터 상태로 동영상/이미지 검색 (업로드/생성) |
| **데이터 형태** | 특정 데이터 형태로 검색 (이미지/동영상) |
| **이벤트 유형** | 특정 이벤트 유형으로 검색 |

### 7.2 업로드하거나 생성 후 업로드 완료된 동영상/이미지 조회

**경로**: 업로드/생성 메뉴 → 동영상/이미지 클릭

동영상/이미지의 상세 정보를 확인할 수 있는 팝업이 노출됩니다.

**팝업 기능**:
- **동영상 재생**: 동영상을 재생할 수 있으며, 재생 불가능한 경우 안내 메시지 표시
- **탭**: "생성 정보" 탭과 "메타데이터 수정" 탭 제공

**생성 정보 탭**:
- 동영상/이미지 생성 시 사용한 프롬프트 확인
- IMAGE-TO-IMAGE 또는 IMAGE-TO-VIDEO 모델 사용 시 참고 이미지 표시

**메타데이터 수정 탭**:
- 생성된 파일의 메타데이터 확인
- 필요한 경우 메타데이터 수정 및 저장 가능

**추가 기능**:
- **복제 아이콘**: 사용했던 프롬프트, 메타 정보, 이미지를 동일하게 사용하여 AI 동영상/이미지 생성 작업 진행
- **복사 아이콘**: 사용했던 프롬프트를 복사 처리
- **닫기 아이콘**: 팝업 닫기

### 7.3 동영상/이미지 업로드

**경로**: 업로드/생성 메뉴 → 파일 업로드 버튼 클릭

업로드 팝업이 노출됩니다.

**업로드 방법**:
1. 팝업에 1개의 파일을 드래그 앤 드롭 하거나 선택하여 첨부
2. 필수 정보 입력:
   - 계절 (필수)
   - 이벤트 유형 (필수)
   - 시간 (필수)
   - 개인정보 포함여부 (필수)
   - 비식별화 적용여부 (필수)
   - 촬영일자 (필수)
   - CCTV명 (필수)
3. "업로드" 버튼 클릭으로 업로드 완료

**제한 사항**: 한 번에 하나의 파일만 업로드 가능

### 7.4 AI 동영상/이미지 생성

**경로**: 업로드/생성 메뉴 → AI 이미지 생성 버튼 클릭

AI로 동영상이나 이미지를 생성할 수 있는 화면입니다.

**생성 가능한 모델**:
- TEXT-TO-IMAGE: 텍스트 프롬프트로 이미지 생성
- IMAGE-TO-IMAGE: 기존 이미지를 기반으로 새로운 이미지 생성
- IMAGE-TO-VIDEO: 이미지를 기반으로 동영상 생성

**필수 선택**:
- 동영상/이미지 선택 셀렉트 박스에서 생성할 데이터 형태 선택 (이미지 또는 동영상)

**생성 시 적용 가능한 메타**:

| 메타 항목 | 선택 옵션 |
|----------|----------|
| **이벤트 유형** | 침수만 선택 가능 |
| **시간대** | 주간, 야간 |
| **계절** | 봄, 여름, 가을, 겨울 |
| **날씨** | 안개, 비, 눈 |
| **지형** | 고속도로, 골목길, 지하도, 터널, 강변 |

**생성 조건**:
- 위 메타 항목 중 하나 이상을 선택하거나
- 프롬프트 입력 창에 내용 입력 (영어로만 가능)

**이미지 첨부**:
- 이미지 추가 아이콘 클릭으로 "이미지 추가" 세부기능 박스 노출
- **장치에서 업로드**: 파일 선택기 실행하여 이미지 업로드
- **클립 프레임 선택**: 프로젝트와 데이터 선택 후 프레임 선택하여 첨부
- **주의**: 이미지 첨부 시 지형, 프롬프트 적용은 불가능

**생성 프로세스**:
1. 메타 항목 선택 또는 프롬프트 입력
2. "생성" 버튼 클릭 → 목록 상단에 "이미지/동영상 생성대기" 표시
3. 생성 완료 시 목록에 이미지/동영상 노출
4. **순차 처리**: AI 생성은 순차적으로 진행되므로 여러 개를 연속으로 대기열에 추가 가능

### 7.5 생성된 AI 동영상/이미지 업로드

**경로**: AI 이미지 생성 화면 → 생성된 동영상/이미지 선택 후 업로드 버튼 클릭

업로드 전 내용을 확인하고 메타데이터를 수정할 수 있는 팝업이 표시됩니다.

**업로드 프로세스**:
1. 팝업에서 생성된 파일의 정보 확인
2. 필요시 메타데이터 수정
3. "확인" 버튼 클릭 → 정보 저장 및 동영상/이미지 업로드

**업로드 후 처리**:
- "업로드/생성" 메뉴 → "AI 이미지 생성" 화면에서 "업로드/생성" 메뉴 화면으로 이동
- 목록에 노출되는 데이터만 관리자, 프로젝트 담당자가 확인 가능
- 추후 관리자, 프로젝트 담당자의 2차 검토에서 사용 가능 판정을 받을 경우 프로젝트에 배정 가능

**삭제**: "삭제" 클릭 시 해당 동영상/이미지 삭제 처리

### 7.6 생성된 AI 동영상/이미지 조회

**경로**: 업로드/생성 메뉴 → AI 이미지 생성 화면 → 동영상/이미지 클릭

생성된 동영상/이미지의 상세 정보를 확인할 수 있는 팝업이 노출됩니다.

**팝업 기능**:
- **동영상 재생**: 동영상을 재생할 수 있으며, 재생 불가능한 경우 안내 메시지 표시
- **생성 정보 확인**: 생성 시 사용한 프롬프트와 메타 정보, 참고 이미지(IMAGE-TO-IMAGE/IMAGE-TO-VIDEO 사용 시) 노출
- **복제 아이콘**: 동일한 프롬프트, 메타 정보, 이미지를 사용하여 AI 동영상/이미지 생성 재진행
- **복사 아이콘**: 사용했던 프롬프트 복사 처리
- **닫기 아이콘**: 팝업 닫기

**생성 진행 중인 동영상/이미지**: 업로드/생성 메뉴 → AI 이미지 생성 화면에서 확인 가능

**삭제**: "삭제" 클릭 시 해당 동영상/이미지 삭제 처리

## 8. 주요 워크플로우 및 베스트 프랙티스

### 8.1 일일 작업 프로세스

1. **로그인 및 프로젝트 확인**
   - 프로젝트 관리 메뉴에서 배정된 프로젝트 및 데이터 확인

2. **데이터 배정**
   - 보유 데이터가 10개 이하인 경우 자동 배정 활용

3. **라벨링 작업 수행**
   - 비식별화 → 라벨링(바운딩박스/폴리곤/스켈레톤) → 메타데이터 입력 순서 준수
   - 단축키를 적극 활용하여 작업 효율 증대

4. **저장 및 제출**
   - 주기적으로 저장 (Ctrl+S) 또는 자동 저장 활용
   - 모든 프레임 완료 후 제출 버튼 클릭

5. **통계 모니터링**
   - 대시보드에서 일일 작업량 및 반려 현황 확인

### 8.2 라벨링 작업 시 주의사항

1. **비식별화 우선 수행**
   - 다른 라벨링 작업 전에 반드시 먼저 수행
   - 개인정보(얼굴, 번호판, 연락처 등) 철저히 처리

2. **트랙 기능 활용**
   - 연속되는 객체에 트랙 기능 사용으로 작업 시간 단축
   - 트랙 설정 전에는 가급적 수정 작업 미수행 권장

3. **속성 정보 정확히 입력**
   - 라벨 생성 후 우측 객체 탭에서 모든 속성 정보 선택
   - 속성 누락 시 데이터 품질 저하

4. **메타 정보 일괄 적용**
   - 프레임별로 동일한 메타 정보일 경우 "다음 프레임에 적용" 활용

5. **이슈 발생 시 조기 보고**
   - 프레임에 문제가 있거나 불명확한 경우 "관리자 확인 요청" 사용
   - 조기 보고로 문제 해결 시간 단축

### 8.3 에러 처리

1. **작업 취소 (Ctrl+Z)**
   - 마지막 작업 실행취소 가능
   - 비식별화 제외

2. **객체 삭제**
   - Delete 또는 R 키로 선택된 객체 삭제
   - 우측 객체 탭의 "삭제" 버튼으로도 삭제 가능

3. **라벨 복사로 빠른 수정**
   - 비슷한 객체들은 복사 기능(Ctrl+C) 활용

## 9. 특이사항 및 주요 참고사항

### 9.1 시스템 특성

- **프레임 번호**: F (실제 추출된 프레임 번호), I (프레임 분할 시 순차 번호)
- **자동 저장**: 프레임 이동 시 자동 저장되지만, 필요시 수동 저장도 가능
- **1시간 단위 통계 업데이트**: 대시보드 통계는 1시간마다 갱신

### 9.2 권한 관련 중요사항

- **동일 프로젝트 내 다중 권한**: 같은 프로젝트에서 작업자, 검수자, 업로더 권한을 동시에 가질 수 있음
- **권한별 메뉴 접근**: 권한 조합에 따라 접근 가능한 메뉴가 동적으로 변경됨

### 9.3 데이터 품질 관리

- **라벨링 정확도**: 검수자의 반려 빈도를 대시보드에서 모니터링
- **재작업 대응**: 반려된 데이터는 이슈 탭의 반려 사유를 확인하고 신속하게 재작업 수행
- **관리자 소통**: 불명확한 지시사항이 있을 경우 "관리자 확인 요청" 활용

### 9.4 AI 기능 활용

- **Auto Labeling**: 사람, 자동차 등 자동 라벨링 가능한 객체에 우선 적용
- **AI Tool**: 객체 일부분만 클릭하면 자동으로 테두리 감지
- **트래킹**: 동일 객체가 연속 프레임에 나타날 경우 첫-마지막 프레임만 설정하고 자동 계산

### 9.5 업로드/생성 기능

- **프롬프트 입력**: 반드시 영어로만 입력
- **순차 처리**: AI 생성은 순차적으로 진행되므로 대량 생성 시 미리 대기열에 추가
- **1차 검토 후 업로드**: AI 생성 동영상/이미지는 1차 검토 후 업로드해야 시스템에 반영
