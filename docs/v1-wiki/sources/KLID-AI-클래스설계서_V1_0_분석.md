## 개요

이 문서는 AI 기반 지자체 CCTV 관제지원시스템의 클래스 설계를 정의합니다. HWP 형식의 원본 문서에서 추출되었으며, 클래스 다이어그램, 클래스 정의, 속성 및 메서드 등을 포함합니다.

## 주요 내용 구조

### 1. 시퀀스도
- 클립 영상 검색 기능
- 프레임 자동 추출 기능
- 이미지 생성 및 분류 관리 기능
- 수집 이미지 자동조절 기능 (밝기, 대비)
- 이미지 설명 작성 기능
- 학습용 데이터 제작 도구 기능
- 학습용 데이터 검수 관리 기능
- 라벨 및 속성 관리 기능
- 객체 추적 및 복사 기능
- 구축 진행상황 및 이력 기능
- 테스트 제작 기능
- 오토 라벨링 기능
- 생성형 프롬프트 기능

### 2. 설계 클래스도

주요 클래스 범주:
- **공통코드**: CmCodeController
- **사용자 관리**: UserController
- **영상/이미지 데이터**: 데이터 관리 클래스
- **프로젝트**: 프로젝트 관리 클래스
- **프로젝트 데이터**: 프로젝트 데이터 관리
- **프롬프트**: 프롬프트 관리
- **오토라벨링**: 자동 라벨링 기능
- **비디오 분할**: 비디오 처리 기능

### 3. 설계 클래스 정의

각 클래스는 다음 정보를 포함합니다:
- **속성명** (Attributes)
- **타입** (Type)
- **설명** (Description)
- **오퍼레이션** (Operations/Methods)
- **가시성** (Visibility: Public, Private, Protected)

## 주요 클래스 관계

### 상속 구조
- 데이터 관리 클래스들은 공통 기본 클래스에서 상속

### 의존성
- UserController: 사용자 인증 및 권한 관리
- CmCodeController: 공통 코드 관리

### 연관성
- 프로젝트 ↔ 프로젝트 데이터 (One-to-Many)
- 영상/이미지 데이터 ↔ 프롬프트 (Many-to-Many)
- 프로젝트 ↔ 오토라벨링 (One-to-One)

## 패키지/모듈 구조

```
KLID-AI System
├── Common (공통)
│   └── CmCodeController
├── User Management (사용자)
│   └── UserController
├── Data Management (데이터)
│   ├── VideoImageData
│   └── ProjectData
├── Project (프로젝트)
│   └── Project
├── Processing (처리)
│   ├── AutoLabeling
│   ├── Prompt
│   └── VideoSegmentation
```

## 기술 특징

1. **Controller-based Architecture**: 각 도메인별 Controller 패턴 적용
2. **Data-driven Design**: 데이터 중심의 설계 구조
3. **Modular Design**: 기능별 독립 모듈화
4. **Reusability**: 공통코드와 기본 클래스를 통한 재사용성 극대화
