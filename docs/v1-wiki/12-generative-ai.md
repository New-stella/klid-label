화면: `SKKLID-UI-02-05-01 ~ 09`(생성), `SKKLID-UI-03-04-01/03`(데이터 관리). 실데이터 부족 시 생성형 AI로 학습 데이터 보강.

## 12.1 AI 이미지/동영상 생성

| 생성 방식 | 설명 |
|----------|------|
| Text to Image | 프롬프트 입력으로 이미지 생성 |
| Image to Image | 기존 이미지 기반 변형 이미지 생성 |
| Image to Video | 이미지 기반 동영상 생성 |
| 메타데이터 기반 생성 | 계절·날씨·시간대·비식별 등 메타 조건으로 증강 |

**프롬프트**: 입력 후 Enter로 생성 시작(Shift+Enter 줄바꿈), **반드시 영어로만** 입력. 메타데이터 선택 시 자동 프롬프트 생성.

### 생성 파라미터 (요청, UI설계서 §2.1)

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| 적용 프로젝트 | String | 프로젝트 ID |
| 날씨 | String | 맑음/흐림/비/눈 등 |
| 계절 | String | 봄/여름/가을/겨울 |
| 비식별 여부 | Boolean | PII 처리 여부 |
| 생성시작일 | Date | 생성 시작 날짜 |

### 생성 결과 응답

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| 영상/이미지명 | String | 파일명 |
| 이벤트 유형 | String | 이벤트 타입 |
| 생성일 | DateTime | 생성 일시 |
| 시간대 | String | 야간/주간 |
| 개인정보 포함 여부 | Boolean | PII (`DE_IDNTF_YN`) |
| AI 생성 여부 | Boolean | 합성 데이터 식별 (`AI_CRT_YN`) |

### 생성 시 적용 가능한 메타 (매뉴얼 기준)

| 메타 항목 | 선택 옵션 |
|----------|----------|
| 이벤트 유형 | **침수만** 선택 가능 |
| 시간대 | 주간, 야간 |
| 계절 | 봄, 여름, 가을, 겨울 |
| 날씨 | 안개, 비, 눈 |
| 지형 | 고속도로, 골목길, 지하도, 터널, 강변 |

**생성 조건**: 위 메타 중 하나 이상 선택 또는 프롬프트 입력.
**이미지 첨부**: 장치 업로드 또는 클립 프레임 선택. ⚠️ 이미지 첨부 시 지형·프롬프트 적용 불가.
**순차 처리**: AI 생성은 순차 진행 → 연속으로 대기열 추가 가능. 로딩바 + "생성중" 표시.

## 12.2 파일 업로드 (수동)

화면: `SKKLID-UI-02-05-09`. 한 번에 **1개 파일만** 업로드.

- 화면정의서 기준 지원 포맷: JPG/JPEG/PNG (이미지). 업로드 파일은 서버에 저장되지 않고 작업 중 참조 이미지로 사용.
- 운영자매뉴얼 업로드 시 필수 정보: 계절·이벤트 유형·시간·개인정보 포함여부·비식별화 적용여부·촬영일자·CCTV명.

## 12.3 생성 데이터 관리 흐름

```
업로더가 AI 생성 또는 파일 업로드
    ↓ (AI 생성은 업로더 1차 검토 후 "업로드"해야 목록 노출)
"업로드/생성 데이터 관리" 메뉴 노출
    ↓
관리자 2차 검토
    ↓ "등록" 버튼 (필수!)
"영상/이미지 관리"로 이동
    ↓
프로젝트 배정 가능
```

> ⚠️ **"등록" 과정을 거쳐야만** "영상/이미지 관리"에 나타나고 프로젝트 배정 가능.

### 데이터 관리 화면 (`03-04`)
- 조회: 데이터 상태(업로드/생성), 데이터 유형(이미지/동영상), 이벤트 유형(현재 침수만), 검색어
- 상세 팝업: "생성 정보" 탭(프롬프트·참고 이미지) + "메타데이터 수정" 탭, 동영상 재생
- 액션: "등록"(영상/이미지 관리로 이동), "삭제"

### 상세 팝업 부가 기능
- 복제 아이콘: 동일 프롬프트·메타·이미지로 재생성
- 복사 아이콘: 프롬프트 복사

## 12.4 관련 데이터 (DB)

`LS_DATA_SRC`의 `AI_CRT_YN`(AI 생성), `PROMPT_CN`(프롬프트), `DE_IDNTF_YN`/`PRVC_YN`. → [15](15-database.md).

> **v2 참고**: v2에서 **생성형 AI 모델 본체(학습·파인튜닝·프롬프트·생성 UI)는 외부 시스템 책임(범위 외)**. 저작도구는 외부 증강 결과 검수와 생성된 영상 라벨링만 담당하며, 증강 결과는 **새 영상(`RAW_SN`, `PARENT_RAW_SN`로 원본 참조)**으로 수신해 미검수(PENDING)부터 기존 플로우를 탄다. v1의 Text/Image to Image/Video 생성 화면은 v2에 없다.
