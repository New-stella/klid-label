## 12.1 AI 이미지/동영상 생성

| 생성 방식 | 설명 |
|----------|------|
| Text to Image | 프롬프트 입력으로 이미지 생성 |
| Image to Image | 기존 이미지 기반 변형 이미지 생성 |
| Image to Video | 이미지 기반 동영상 생성 |
| 메타데이터 기반 생성 | 메타 항목을 클릭 후 "생성" 클릭 시 해당 메타가 반영된 프롬프트가 **자동 작성**되어 이미지/동영상 생성 진행(증강이 아니라 프롬프트 자동 조립 — 밝기/좌우반전 등 화소 변형인 [11장 증강](11-augmentation-export.md)과는 별개 기능) |

**프롬프트**: 입력 후 Enter로 생성 시작(Shift+Enter 줄바꿈), **반드시 영어로만** 입력이라는 표기는 관리자매뉴얼 §11.4에서 확인(원문: "프롬프트 입력은 영어로만 가능합니다"). 메타데이터 선택 시 자동 프롬프트 생성.

### 생성 시 적용 가능한 메타 (매뉴얼 기준)

| 메타 항목 | 선택 옵션 |
|----------|----------|
| 이벤트 유형 | **침수만** 선택 가능 |
| 시간대 | 주간, 야간 |
| 계절 | 봄, 여름, 가을, 겨울 |
| 날씨 | 안개, 비, 눈 |

**생성 조건**: 위 메타 중 하나 이상 선택 또는 프롬프트 입력.
**이미지 첨부**: 장치 업로드 또는 클립 프레임 선택. ⚠️ 이미지 첨부 시 지형·프롬프트 적용 불가.
**순차 처리**: AI 생성은 순차 진행 → 연속으로 대기열 추가 가능. 로딩바 + "생성중" 표시.

## 12.2 파일 업로드 (수동)

화면: `SKKLID-UI-02-05-09`("업로더 로그인 > 업로드/생성 > 파일 업로드"). 한 번에 **1개 파일만** 업로드.

> ⚠ **정정(2026-08-19 원문 실측)** — 이전 판의 "JPG/JPEG/PNG(이미지)만 지원, 서버 미저장·참조용" 서술은 **다른 화면(SKKLID-UI-03-02-08, 프로젝트 생성 > 라벨/스켈레톤 생성의 파일 업로드 버튼)의 내용이 잘못 전용된 것**이다. 그 화면은 실제로 "이미지만 업로드 가능(JPG, JPEG, PNG)… 해당 파일은 서버에 저장되지 않음"이라고 명시하지만, 이는 스켈레톤 라벨 정의용 참고 이미지이며 이미 [05 프로젝트 관리](05-project-management.md)에 반영돼 있다(`03-02-07` 스켈레톤 작성 도구). SKKLID-UI-02-05-09(본 절)는 별개 화면이다.
>
> **실제 확인된 내용(화면정의서 §2-5-09 원문)**: 파일 형식은 스토리보드 자체가 **"논의 필요"로 미확정** 상태로 남아 있다 — 원문 표기 "파일 형식 논의 필요 (JPEG / JPG / PNG / MP4 / AVI / MOV / WMV)"(이미지+영상 포맷 후보를 모두 나열, 확정 아님). 업로드 시 이벤트 유형·계절·시간(그림상 필수 셀렉트 3종, "추후 지정되는 메타 정보도 셀렉트 박스 선택" 주석 있음)을 입력하고 "업로드" 클릭 시 업로드가 완료된다 — **서버에 저장되지 않는다는 서술은 이 화면에 대한 근거가 없다.** 오히려 관리자매뉴얼 §6.2("생성된 동영상/이미지를 검토한 후 '등록' 버튼 클릭 시 '업로드/생성데이터 관리' → '영상/이미지관리'로 이동")가 업로드된 파일이 이후 관리자 2차 검토·등록 대상으로 남아 있음을 보여준다. 근거: `01-UIUX설계서.txt` 화면 `SKKLID-UI-02-05-09` · `01-UIUX설계서.txt` 화면 `SKKLID-UI-03-02-08`(잘못 전용됐던 원 출처) · `02-관리자매뉴얼.txt` §11.3 동영상/이미지 업로드
>
> 관리자매뉴얼 업로드 시 필수 정보(§11.3, 원문 확인): 계절·이벤트 유형·시간·개인정보 포함여부·비식별화 적용여부·촬영일자·CCTV명 (7항목). ⚠ 이전 판이 이를 "운영자매뉴얼 §7" 출처로 표기했으나, 위 원문은 **관리자매뉴얼 §11.3**에서 확인된 것이다. 운영자(사용자)매뉴얼은 이번 1차 PDF 세트에 포함되지 않아 그 출처 표기 자체는 확인 불가.

## 12.3 생성 데이터 관리 흐름

```
업로더가 AI 생성 또는 파일 업로드
    ↓ (AI 생성은 업로더 1차 검토 후 "업로드"해야 목록 노출)
"업로드/생성 데이터 관리" 메뉴 노출
    ↓
관리자 2차 검토
    ↓ "등록" 버튼 (필수!)
"영상/이미지 관리"로 이동
    ↓
프로젝트 배정 가능
```

> ⚠️ **"등록" 과정을 거쳐야만** "영상/이미지 관리"에 나타나고 프로젝트 배정 가능.

### 데이터 관리 화면 (`03-04`)
- 조회: 데이터 상태(업로드/생성), 데이터 유형(이미지/동영상), 이벤트 유형(현재 침수만), 검색어
- 상세 팝업: "생성 정보" 탭(프롬프트·참고 이미지) + "메타데이터 수정" 탭, 동영상 재생
- 액션: "등록"(영상/이미지 관리로 이동), "삭제"

### 상세 팝업 부가 기능
- 복제 아이콘: 동일 프롬프트·메타·이미지로 재생성
- 복사 아이콘: 프롬프트 복사
