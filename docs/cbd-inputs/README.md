# CBD 산출물 생성 입력값

설계 원장에서 **도출되지 않는** 칸의 값을 둔다. 레시피가 스스로 *"스키마에 축이 없다"* 고 말하는
자리들이며, 그런 칸은 원천 항목을 아무리 채워도 채워지지 않는다.

## 이것은 원장이 아니라 원장의 **재료**다

레시피가 실제로 읽는 이관 원장은 **`convert-service` 레포의 `overlays/`** 에 있다. 여기 있는 것은
그 원장을 만들 때 쓰는 입력이다. **값을 두 곳에 두면 한쪽만 고쳐지므로** 이 구분을 지운 채
「원장」이라 부르지 말 것.

## 왜 레포에 두나

값의 출처인 승인된 제출본(hwpx)은 **레포 밖 사용자 로컬**에 있다. 다른 기계에서 체크아웃하면
그 파일이 없어 값을 다시 뜰 수 없다. 그래서 **뜬 결과를 레포에 둔다.**

## 파일

| 파일 | 담은 것 |
|---|---|
| `D5-아키텍처-원장재료.json` | 제출본에서 셀 단위로 뜬 값 + `_현재형상_갱신`(실측 정정, 근거 병기) |

각 파일의 `_읽는법` 에 **무엇을 · 어디서 떠서 · 안 채우면 무엇이 마커가 되는지**가 있다.

## 쓰기 전에

**제출본 값을 그대로 옮기지 말 것.** 감리를 통과했다는 것이 지금도 맞다는 뜻은 아니다.
어느 칸이 낡았는지는 `_현재형상_갱신` 이 왼쪽(제출본)·오른쪽(실측)으로 갈라 놓았다.

**일부러 비운 칸이 있다** — 두 출처가 어긋나 확인되지 않은 값이다. 마커와 그 이유가 산출물에
나가는 것이 지어낸 값보다 낫다.

절차와 함정은 `docs/rules/cbd-generation.md`.
