# [요청] 저작도구 WAS 설정 1줄 추가 — 포털 연동 키

> ✅ **완료 (2026-09-10 17:13)** — 적용 대상은 `jboss8-3rd.service`(`/opt/jboss-eap-8-3rd`) 였다.
> 경위·현장 형상은 `포털-정리트리거-401-원인과-조치-20260910.md` §7.

**대상** 저작도구 개발망 WAS(포털 향) · **소요** 5분 · **JBoss 재기동 1회**

---

## 요청 내용

`/etc/klid/application.properties` 에 아래 한 줄을 추가하고 **JBoss 를 재기동**해 주십시오.

```
PORTAL_CLEANUP_API_KEY=<안전 채널로 전달드린 값>
```

> ⚠ **`<안전 채널로 전달드린 값>` 자리에는 별도로 전달드린 64자 문자열을 넣어 주십시오.**
> 이 문서는 저장소에 커밋되므로 키 값을 본문에 적지 않습니다.

**사유** — 포털이 저작도구로 보내는 알림이 지금 전부 401 로 실패합니다. 두 시스템이 나눠 갖기로 한
인증 키가 저작도구 쪽에 주입된 적이 없어, 저작도구가 「키 없음 → 거부」로 닫아 둔 상태입니다.
프로그램 결함이 아니라 설정 누락이며 위 한 줄로 해소됩니다.

---

## ⚠ 대상은 아파치가 아니라 JBoss 입니다

같은 장비에 세 개가 떠 있습니다. 아파치(38081)는 **건드리지도, 재기동하지도 않습니다.**

| 포트 | 정체 | 작업 |
|---|---|---|
| 38444 | 포털 웹 | — |
| 38081 | 아파치 | ❌ |
| **49080** | **JBoss EAP — 저작도구** | ✅ 설정 추가 + 재기동 |

---

## 절차

**① 설정 위치 확인** (변경 없음 — 반드시 먼저)
```bash
ps -ef | grep '[j]boss' | tr ' ' '\n' | grep spring.config
```
- `file:/etc/klid/` 가 보이면 → ②
- **안 보이면 ②를 하지 마시고 이 출력을 회신해 주십시오.** 형상이 달라 다른 자리에 넣어야 하며,
  잘못된 파일에 넣으면 **아무 반응 없이 그대로 실패**합니다.

**② 백업 후 추가**
```bash
sudo cp -a /etc/klid/application.properties /etc/klid/application.properties.bak.$(date +%Y%m%d%H%M)
echo 'PORTAL_CLEANUP_API_KEY=<안전 채널로 전달드린 값>' \
  | sudo tee -a /etc/klid/application.properties >/dev/null
```
⚠ 같은 키가 이미 있으면 덧붙이지 말고 **그 줄의 값만** 바꿔 주십시오.

**③ 재기동**
```bash
systemctl list-units --type=service | grep -iE 'jboss|eap'
sudo systemctl restart <유닛명>
```

**④ 검증**
```bash
JH=$(ps -eo args= | tr ' ' '\n' | grep -m1 -- '-Djboss.home.dir=' | cut -d= -f2-)
grep 'PortalSystemApiKey' "$JH/standalone/log/server.log" | tail -3
```

| 출력 | 판정 |
|---|---|
| `…키가 설정됐습니다` | ✅ 완료 |
| `…키가 설정되지 않았습니다` | 값이 안 읽혔다 — 회신 요망 |
| 아무 줄도 없음 | 배포된 애플리케이션이 구판 — 회신 요망 |

---

## 롤백

```bash
sudo cp -a /etc/klid/application.properties.bak.<타임스탬프> /etc/klid/application.properties
sudo systemctl restart <유닛명>
```
되돌리면 현재 상태(포털 알림 401)로 돌아갈 뿐, 다른 기능에는 영향이 없습니다.

---

## 참고

- 이 값은 **포털 알림 수신 창구 하나**에만 쓰입니다. 값이 틀려도 그 창구만 401 일 뿐
  애플리케이션은 정상 동작합니다.
- **재기동 중 저작도구 접속이 잠시 끊깁니다** — 사용이 적은 시간대를 권합니다.
- 설정 파일은 **WAS 실행 계정이 읽을 수 있어야** 합니다. 못 읽으면 WAS 는 뜨는데
  애플리케이션만 설정 없이 기동하는 형태로 드러납니다.
- 개발망 임시 키이며 운영 반영 시 별도 값으로 교체합니다.

**회신** — ④의 출력 한 줄이면 충분합니다. 그 외 막히는 지점이 있으면 해당 명령의 출력을 주십시오.
