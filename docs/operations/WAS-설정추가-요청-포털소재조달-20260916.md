# [요청] 저작도구 WAS 설정 3줄 추가 — 포털 소재 조달(API-132)

**대상** 저작도구 개발망 WAS(포털 향) · **소요** 5분 · **JBoss 재기동 1회**

지금 포털 데이터셋 화면(`/portal/datasets/{번호}`)에 들어가면 **소재 가져오기 단계에서 멈춘다.**
프로그램 결함이 아니라 **설정 누락**이며, 값이 비면 그 창구가 닫히도록(fail-closed) 만들어 둔 결과다.
아래 세 줄로 열린다.

---

## 넣을 값 세 줄

`/etc/klid/application.properties` 에 추가하고 **JBoss 재기동**.

```
PORTAL_MATERIALS_BASE_URL=<아래 ②>
PORTAL_MATERIALS_API_KEY=<안전 채널로 공유된 값 — 이 문서에 적지 않는다>
PORTAL_MATERIALS_REPO_ROOT_ALLOWLIST=<아래 ③>
```

⚠ 같은 키가 이미 있으면 덧붙이지 말고 **그 줄의 값만** 바꾼다.
⚠ 대상은 **JBoss(49080)** 다. 아파치(38081)·포털 웹(38444)은 건드리지 않는다.

---

## 근거 — 포털 WAS 저장소 실측 (2026-09-16)

조사 대상: `infra_dev/klid_portal_was` (`main` = `9d80702`)

| 확인한 것 | 근거 |
|---|---|
| 창구가 **실재한다** | `78b511c`(2026-09-02) `feat(D002): 저작도구 데이터셋 소재경로 조회 내부 API (API-132)` — 컨트롤러·서비스·응답 DTO·시험 3건이 함께 들어왔다 |
| 경로 | `GET /api/internal/v1/datasets/{datasetId}/materials` |
| 인증 | `ApiKeyFilter` 가 **`/api/internal/**` 전 경로**에 걸린다. 헤더 `x-api-key`, 미제시·불일치 401 |
| 검사하는 설정 키 | 포털 쪽 `portal.ingest.api-key` (환경변수 `PORTAL_INGEST_API_KEY`) |
| 우리에게 오는 응답 | `repoRootDir` + `files[]`(`DEPLOYMENT_ZIP` 1건 + `DATASET_VIDEO` 0..N)의 **NAS 절대경로**. 봉투 없는 평문 JSON |
| 망 제한 | 아파치가 `/api/internal/` 을 **파트너망 IP 만** 허용(103·248·245·246·루프백). 그 밖 403 |

### ① 키 — 전달받은 값을 그대로 쓰면 된다

포털 개발 설정의 **기본값이 그 값과 같다**(`portal-ingest/src/main/resources-dev/application.yml`).
즉 지금 개발망에서 그 키로 `/api/internal/**` 이 열린다.

- 같은 파일에서 포털이 **우리에게 보내는** cleanup 통보 키도 같은 값을 쓰고 있고,
  주석이 *"잠정값(관제지원 키 재사용). 저작도구가 전용 키를 회신하면 교체한다"* 로 적혀 있다.
- ⚠ 그래서 **지금은 세 축이 한 값**이다. 우리 쪽 `PORTAL_CLEANUP_API_KEY`(포털 → 저작도구)와
  이번 `PORTAL_MATERIALS_API_KEY`(저작도구 → 포털)는 **자리를 따로 둔다** — 값이 같은 것과
  자리가 하나인 것은 다르다. 나중에 갈릴 때 호출부를 다시 뒤지지 않기 위해서다.
- ⚠ 값 자체는 이 문서에 적지 않는다(저장소에 커밋된다).

### ② 주소 — 포털 **내부 WAS**

아파치 설정(`httpd.conf`)상 `/api/internal/v1/` 은 `balancer://klid-jboss` → **`http://127.0.0.1:39080`** 로 간다.

- 저작도구 WAS 가 **같은 장비**에 있으면 `http://127.0.0.1:39080` 이 가장 짧은 경로다.
- 다른 장비면 포털 장비 주소로 `http://<포털WAS>:39080` 또는 아파치를 경유해 `https://<포털>:38444` 를 쓴다.
  ⚠ 경유하면 **파트너망 IP 목록에 우리 출발지 IP 가 있어야 한다**(없으면 403).
- ⚠ **포털 웹 주소로 외부망에서 부르면 안 된다** — 앞단이 `/api/internal/**` 을 막는다.
- ⚠ 자체 서명 인증서를 쓰는 https 주소면 신뢰 설정이 함께 필요하다. **http 내부 주소가 단순하다.**

**인프라에 확인할 것** — 저작도구 WAS 와 포털 WAS 가 같은 장비인가. 그 답이 위 셋 중 하나를 고른다.

### ③ 허용 루트 — 포털이 주는 경로의 상위 디렉터리

포털은 `repoRootDir`(운영설정 `dataset_repo_root_dir`) 아래의 절대경로를 준다.
저장소 문서·예시에 나오는 값은 **`/nas-storage/data/portal/repo/`** 계열이다
(학습데이터는 `/nas-storage/data/portal/repo/dataset/...`, AI 모델은 별개 `.../repo/ai/`).

⚠ **예시에서 베끼지 말고 실제 값을 확인해서 넣는다.** 운영설정 값이라 배포마다 다를 수 있다.

```sql
SELECT stng_key, stng_value FROM portal.tb_oper_stng WHERE stng_key = 'dataset_repo_root_dir';
```

**왜 이 값을 따로 두나** — 포털 응답이 **함께 준** 저장소 루트만 믿으면, 상대가 루트를 `/` 로,
소재 경로를 아무 시스템 파일로 주었을 때 표기·실경로·정규파일 검사를 **전부 통과한다**(2026-09-15 실측).
그래서 **우리가 아는 값**을 기준점으로 둔다.

## 선행 조건 — NAS 동일 마운트

포털이 주는 것은 **주소가 아니라 파일 경로**다. 저작도구 WAS 가 그 경로를 **같은 자리로 마운트**하고
**읽을 수 있어야** 한다(포털 연동 문서 확정 사항 — 「포털·저작도구가 동일 NAS 를 동일 경로로 마운트」).

```bash
ls -l <repoRootDir>          # 예: /nas-storage/data/portal/repo
```
보이지 않으면 설정을 넣어도 조달이 실패한다. **마운트가 먼저다.**

⛔ 원본 zip 은 **읽기 전용**이다. 우리는 자기 작업영역으로 풀어서 쓴다(구현이 이미 그렇게 한다).

## 절차

**① 설정 위치 확인** (변경 없음 — 반드시 먼저)
```bash
ps -ef | grep '[j]boss' | tr ' ' '\n' | grep spring.config
```
`file:/etc/klid/` 가 보이면 ②로. 안 보이면 **②를 하지 말고 이 출력을 회신**한다(자리가 다르면
아무 반응 없이 그대로 실패한다).

**② 백업 후 추가**
```bash
sudo cp -a /etc/klid/application.properties /etc/klid/application.properties.bak.$(date +%Y%m%d%H%M)
sudo vi /etc/klid/application.properties   # 위 세 줄 추가
```

**③ 재기동**
```bash
systemctl list-units --type=service | grep -iE 'jboss|eap'
sudo systemctl restart <유닛명>
```

**④ 검증 — 기동 로그**
```bash
JH=$(ps -eo args= | tr ' ' '\n' | grep -m1 -- '-Djboss.home.dir=' | cut -d= -f2-)
grep -iE 'PortalMaterials|materials' "$JH/standalone/log/server.log" | tail -5
```

| 출력 | 판정 |
|---|---|
| `허용 루트가 비어 있어 … 닫힌다(fail-closed)` 류 경고 | ③번 값이 안 들어갔다 |
| 그런 경고가 없다 | 설정은 들어갔다 → ⑤로 |

**⑤ 검증 — 화면**
포털에서 학습데이터 하나를 골라 「저작도구로 열기」. 소재 가져오기가 **준비 완료**까지 가면 성공이다.
그다음 영상 목록이 뜨고 라벨링으로 들어갈 수 있다.

**⑥ 실패하면 회신할 것** — 화면에 뜬 실패 사유 문구와 아래 로그.
```bash
grep -iE 'PortalMaterials|PortalDataset' "$JH/standalone/log/server.log" | tail -30
```
