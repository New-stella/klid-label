# [요청] 개발망에 학습데이터 배포본 한 건 등재 — 저작도구 소재 조달 확인용

**보내는 곳** 저작도구 → 포털 · **요청일** 2026-09-16 · **대상** 개발망(103)

---

## 요청

개발망 포털에 **데이터셋 한 건의 배포 압축본(`DEPLOYMENT_ZIP`)을 등재**해 주십시오.
영상이 딸린 데이터셋이면 `DATASET_VIDEO` 도 함께면 더 좋습니다(없어도 진행됩니다).

그 한 건이 있으면 저작도구 쪽 흐름 전체(소재 조달 → 원장 등록 → 영상 목록 → 라벨링 → 저장)를
처음으로 끝까지 확인할 수 있습니다.

---

## 저작도구 쪽 준비는 끝났습니다

| 항목 | 상태 |
|---|---|
| 소재 조달 연동 설정 | ✅ 개발망 WAS 에 주입·재기동 완료 (2026-09-16 11:03) |
| API-132 호출 | ✅ **200 확인** — 주소·인증 키 모두 정상 |
| NAS 마운트 | ✅ `/nas-storage/data/portal/repo/dataset` 접근 가능 |
| 등록·목록·라벨링 창구 | ✅ 구현·시험 완료 (백엔드 회귀 9,676건 통과) |

즉 **받을 것만 없는 상태**입니다.

---

## 확인한 사실

개발망 포털 DB 조회 결과입니다.

```
portal.tb_datst_file   →  0 행
portal.tb_datst        →  7 행
```

데이터셋 카탈로그에는 7건이 있는데 **소재 파일 행이 한 건도 없습니다.**
그래서 어느 번호로 호출해도 아래처럼 빈 목록이 옵니다.

```bash
curl -H "x-api-key: <공유된 키>" \
  "http://127.0.0.1:39080/api/internal/v1/datasets/5034/materials"
```
```json
{"datasetId":5034,"code":null,"version":null,"variant":null,
 "repoRootDir":"/nas-storage/data/portal/repo/dataset/","files":[]}
```

`code`·`version` 이 `null` 인 것으로 보아 수신 원장(`tb_dstrb_rcptn`)도 없는 옛 데이터로 보입니다.

⚠ NAS 에는 `DS-FLOOD-2025-01` 같은 **폴더가 보입니다.** 파일은 있는데 등재가 안 된 것인지,
그 폴더도 시험 잔재인지는 포털 쪽에서 판단해 주십시오.

## 함께 확인 부탁드릴 것 — 압축본 내부 구성

저작도구는 압축본 내부를 **다음 구조로 가정**하고 있습니다. 실제 샘플을 받은 적이 없어
저작도구 산출물 구조를 그대로 가정한 것입니다.

```
{영상 키}/v{n}/deid/0001.jpg
{영상 키}/v{n}/deid/0001.json     ← 같은 이름의 어노테이션 문서
{영상 키}/v{n}/deid/0002.jpg
...
```

- 버전 폴더가 여럿이면 **가장 큰 n** 하나만 씁니다.
- **비식별(`deid`) 이미지만** 읽습니다. 원본(`orgnl`)은 어떤 경로로도 읽지 않습니다.
- 구조가 다르면 **추측으로 채우지 않고 등록 실패로 처리**합니다(잘못 읽는 것보다 낫다는 판단).

**실제 구조가 이와 다르면 알려 주십시오.** 파서만 고치면 되고 나머지는 구조와 무관합니다.
등재해 주시면 저희가 열어 보고 판정할 수도 있습니다.

---

## 등재 뒤 저작도구가 하는 일 (참고)

1. 포털 학습데이터 상세의 **「저작도구로 열기」** 로 진입 (`/portal/datasets/{번호}`)
2. 저작도구 WAS 가 **API-132** 로 소재 경로를 받아 **원본 zip 을 읽기 전용으로** 열고
   자기 작업영역에 **사본을 풀어** 씁니다. ⛔ 원본은 이동·수정·삭제하지 않습니다.
3. 해제본의 영상·프레임·기존 라벨을 저작도구 원장에 등록합니다.
4. 화면에 **데이터셋 영상 목록**이 뜨고, 영상을 골라 라벨링에 들어갑니다.
5. 사용자가 저장한 값은 **포털 전용 저장소에만** 쌓입니다 — 배포본의 원본 라벨은 바뀌지 않습니다.

## 회신 부탁드릴 것

1. 등재한 **데이터셋 번호**(그 번호로 바로 확인하겠습니다)
2. 압축본 내부 구성이 위 가정과 **다른 경우 그 구조**
3. NAS 의 기존 폴더들이 유효한 배포본인지, 시험 잔재인지

문의는 저작도구 쪽으로 주시면 됩니다.
