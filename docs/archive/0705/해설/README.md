## 산출물 관계 한눈에

```
R2 유스케이스 (무엇을)
   └─▶ D1 클래스 · D2 화면 · D3 컴포넌트 (어떻게 설계)
          └─▶ D8 논리 ERD ─▶ D9 물리 DB (데이터 구조)
   D5 아키텍처 (전체 경계·비기능) ── 위 전체를 감싸는 틀
   └─▶ D10 통합시험 (기능이 연결돼 동작하나) · D11 단위시험 (컴포넌트가 맞게 동작하나)
```

- **논리(D8) vs 물리(D9)**: D8=엔티티·관계·논리 FK, D9=실제 컬럼 타입·인덱스·제약·용량.
- **통합(D10) vs 단위(D11)**: D10=외부 경계 간 흐름, D11=클래스/컴포넌트 개별 동작.
- **정직성 원칙**: 각 해설은 원문에 실제 있는 내용만 근거로 하며, 원문에 없는 교차참조는 "원문에 명시되지 않음"으로 표기했습니다.
