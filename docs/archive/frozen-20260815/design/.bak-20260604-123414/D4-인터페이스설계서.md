# D4 인터페이스 설계서

> **ID 표기 규칙(공통)**: 본 산출물의 AT 산출물 ID(KLID-AT-II/IC/IF 등)는 **전체 형식 `KLID-AT-XX-NNN`** 으로 표기한다. 끝부분만(예: `II-001`) 약식 표기 금지. 범위는 시작 ID만 전체형으로(예: `KLID-AT-II-001~004`). ※ LogiCraft 원본 ID(INT/EXTSYS/API)·요구사항(RQ-SFR-NN-NN) 등 타 체계 ID는 각 체계 원형 유지.

## 작성 목적
> 시스템의 내·외부 인터페이스를 식별하고 인터페이스의 명세를 기술한다.
> 본 산출물은 LogiCraft 그래프의 integration_point(INT-001~009)·external_system(EXTSYS-001~006)·도메인×외부시스템 연동 매트릭스를 출처로 한다. R1 요구사항(SFR-06~09)에 매핑된 내·외부 인터페이스만 대상으로 하며, 사용자/권한·게시판 등 R1 무관 인터페이스는 제외한다.

## 작성 방법
> 식별된 인터페이스를 송신측과 수신측으로 구분하여 기술하고 송·수신 간의 인터페이스 방식을 기술하며, 데이터 송신 시스템과 수신 시스템 간의 데이터 저장소와 속성 등의 상세 내역을 기술한다. 송수신 데이터 속성은 실제 코드(`common/client/dto/*`, `webhook/dto/*`, `controlnotify/dto/*`)의 DTO 필드를 기준으로 도출한다.

> - **해상도 변경(RESOLUTION)은 외부 위탁이 아닌 저작도구 내부 기능**으로 분리되었다(INT-008 v2). API-092 `POST /v1/videos/{rawSn}/resolution`(구현됨)이 ffmpeg 리사이즈 + 라벨 좌표 스케일 복사를 직접 수행하므로 외부 인터페이스가 아니며 본 목록에서 제외한다(RQ-SFR-06-03).
> - 비식별 누락 신고용 API-091 `POST /v1/videos/{rawSn}/deident-report`(planned)는 내부 화면→백엔드 호출로 외부 인터페이스가 아니다(본 목록 제외).

## 3. 인터페이스 명세

> 인터페이스별로 송신/수신 시스템의 데이터 저장소·속성·타입·길이를 좌우 대조 형태로 기술한다. 속성·타입은 실제 DTO 필드(JSON 직렬화명 우선)를 기준으로 한다. `List`/중첩 record는 배열 항목 속성을 `└`로 표기한다. 숫자형은 길이를 `—`, 가변·구조형(record/List)은 `N`, 문자열은 설계 권장 최대 길이로 표기한다.

## 항목 설명 (요약)

- **전달 처리형태**: ai-server 추론(KLID-AT-II-001~004)은 Online(동기), VLM·비식별·증강 위탁(005·007·012)은 Online(비동기 요청+콜백), 콜백 수신(006·008·009)은 Online(비동기 콜백), 관제서버 통지(010·011)는 Online(비동기 단방향 outbound), 포털 DB Load(013)는 Online(조회/JDBC)이다. 증강 위탁(012)은 현 단계 외부 미연결 best-effort placeholder다.
- **전달 인터페이스방식**: ai-server·VLM·비식별·증강·관제는 HTTP REST/JSON, 포털은 JDBC(듀얼 데이터소스). 외부 HTTP 연동은 Resilience4j(타임아웃·재시도·서킷브레이커) 적용(NFR-004, 100%). 위탁 요청은 `X-Idempotency-Key` 헤더로 멱등 보장.
- **콜백 수신 보안**: 콜백/통지는 `HmacWebhookFilter`(HMAC 시그니처 + timestamp + idempotencyKey allowlist)로 보호. 양방향 M2M 인증은 deprecated. 페이로드에 PII·토큰·원본(비-비식별) 이미지 포함 금지(NFR-005).
- **관련 요구사항/연동 ID**: LogiCraft integration_point(INT-001~009) ↔ 요구사항(RQ-SFR-NN-NN). INT-001 은 ai-server YOLO/SAM2 4개 호출(KLID-AT-II-001~004)을 묶는다.

## 작성 시 참고사항

> - **출처(LogiCraft)**: integration_point INT-001~009(send/receive·protocol·direction·external_system·used_by_domains), external_system EXTSYS-001~006(6종), 도메인×외부시스템 연동 매트릭스(get_integration_matrix). 송수신 데이터 명세는 실제 DTO 코드 기준(`common/client/dto/`, `webhook/dto/`, `controlnotify/dto/`).
> - **JSON 직렬화명 표기**: ai-server DTO는 `@JsonProperty` 스네이크케이스(image_b64, conf_threshold, track_id 등) 그대로 기재. 그 외 DTO는 record 필드명(camelCase).
> - **ID 체계**: AT 인터페이스 번호 `KLID-AT-II-NNN`(전체형), LogiCraft 연동 `INT-NNN`·외부시스템 `EXTSYS-NNN`·API `API-NNN`(원형), 요구사항 `RQ-SFR-NN-NN`.
> - **길이 표기**: 수치형 `—`, 가변·구조형(record/List) `N`, 문자열은 설계 권장 최대 길이.
> - **범위 분리(RESOLUTION 내부화)**: 해상도 변경은 INT-008 v2에서 외부 위탁 대상에서 제외되어 저작도구 내부 기능(API-092 `POST /v1/videos/{rawSn}/resolution`, 구현됨)으로 수행한다. 따라서 외부 증강 위탁(II-012)·증강 결과 콜백(II-009)의 증강 유형은 WINTER/NIGHT/RAIN 3종이다.
> - **양방향 M2M deprecated**: 관제/포털 양방향 통합 API·M2M 인증 인프라는 미운영. 예외로 저작도구→관제 단방향 outbound 통지(II-010/011)는 인계토큰/IP 화이트리스트로 보호하여 유지한다(RISK-004).
