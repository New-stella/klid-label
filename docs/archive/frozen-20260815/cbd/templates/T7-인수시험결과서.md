## 항목 설명

- **시험 시나리오**: "인수시험 시나리오"의 시험 시나리오를 현행화하고, 인수시험을 수행한다.
- **시험 케이스**: "인수시험 시나리오"의 시험 케이스를 현행화하여 시험을 수행 후, 시험결과를 기록한다.
- (시나리오·케이스 각 필드 정의는 T6 항목 설명과 동일 — 시험결과만 실측 기입)

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_인수시험결과서_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 관련 요구사항 ID: **R1 실존 ID만** — `RQ-SFR-NN-NN`(기능) · `NFR-NNN`(비기능)
>
> - T6와 시나리오·케이스 ID를 동일하게 유지하고 시험결과만 추가한다 (구조 변경 금지).
> - 실패 케이스는 결함 조치 후 재시험(차수 증가)하여 결과를 갱신한다.
> - 인수 판정 기준(부록 C 사용 시): 치명 결함 0건, 주요 결함 수정 완료, 요구사항 충족률 기준 충족.
