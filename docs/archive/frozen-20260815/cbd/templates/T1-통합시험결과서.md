# T1 통합시험 결과서

## 작성 목적
> 총괄시험 계획서와 통합시험 시나리오에 따라서 수행한 시험 결과를 기술한다.

## 작성 방법
> 유스케이스별로 통합 시험 시나리오를 기술하고 시나리오에 대한 시험 케이스를 기술하며 시험 예상결과와 시험결과를 비교한다.

## 항목 설명

### 시험 시나리오
> 설계단계의 "통합시험 시나리오"의 시험 시나리오를 현행화하고, 통합시험을 수행한다.

### 시험 케이스
> 설계단계의 "통합시험 시나리오"의 시험 케이스를 현행화하여 시험을 수행 후, 시험결과를 기록한다.

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_통합시험결과서_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 시험시나리오 ID: `KLID-IT-TS-NNN` (D10 참조)
>   - 시험케이스 ID: `KLID-IT-TC-NNN` (D10 참조)
>   - 관련 유스케이스 ID: `KLID-AT-UC-NNN` (R2 참조)
>   - 화면 ID: `KLID-AT-SC-NNN` (D2 참조)
>
> - D10(통합시험 시나리오)의 양식을 그대로 사용하되, "시험결과" 컬럼을 실제 수행 결과로 채운다.
> - 시험결과는 Pass/Fail로 기록하고, Fail인 경우 결함 내용과 수정 후 재시험 결과를 비고에 기술한다.
> - 차수는 1차(초기 수행), 2차(결함 수정 후 재시험) 등으로 기록한다.
> - 스크린샷이나 API 응답 캡처를 별첨으로 첨부할 수 있다.
