(PDF 원문 그대로)

## 4. 항목 설명 (PDF 원문 전 항목 — 누락 금지)

- **시스템 개요**: 시스템 개요 및 특징, 시스템 구성과 하드웨어, 소프트웨어를 포함한 시스템 운영 환경을 기술한다.
- **시스템 설치 내역**: 서버 주소, 작업내역 및 결과, 상세 작업내역 등을 기술한다.
- **플랫폼 설치 결과**: 개발한 소프트웨어 및 데이터베이스의 설치 내역을 기술한다.
- **데이터 전환 결과**: 기존 데이터베이스의 데이터를 전환 프로그램을 이용하여 개발한 데이터베이스로 전환한 결과를 기술한다.
- **시스템 설치 결과**: 시스템 설치에 대한 상세한 내역을 기술한다.
- **백업 목록표**: 데이터 백업 항목 및 내용을 기술한다.
- **문제점 및 조치사항**: 시스템 설치 과정상의 문제점과 조치내용을 기술한다.
- **기타사항**: 추가적으로 필요한 내용을 기술한다.

## 6. 함정 / 주의

- 설치 *증적* 산출물 — 핵심은 **설치일시·설치시험 성공 여부·설치담당자**가 표마다 기록된다는 점. 추상 설명이 아니라 실측 값으로 채운다.
- "시스템 특성에 따라 항목 차이 큼 → 관련항목 수정 사용" 명시 — 목차 8개 항목은 시스템에 맞게 가감 가능.
- ⚠ **상세 작업내역(§2.3) 사례에 DB 계정/Password 환경설정 키가 그대로 노출됨**(`DBID`/`DBPASS`, 계정 `sondk2782`, SID `db_eok` 등). 본 양식은 민감정보가 들어가기 쉬운 구조다.
- 데이터 전환 결과(§4)는 "기존 DB → 개발 DB" 마이그레이션 전제. 신규 시스템이면 해당 항목 적용 여부 확인 필요(PDF 확인된 사례는 디스크 복제 기반 동일명 전환).

## 7. KLID 프로젝트 적용 메모

- **시스템 개요(§1.1~1.2)**: KLID 학습데이터 저작도구 = FE(React/Vite) + BE(Spring Boot 3.3, Java 17) + ai-server(FastAPI, YOLO/SAM2/VLM) + PostgreSQL(klid_at). 외부 연동(비식별 서버, 관제서버 outbound 통지, 포털 DB). 구성도에 듀얼 데이터소스(Control/Portal)와 배치 파이프라인 포함.
- **시스템 운영 환경(§1.3)**: HW 표에 ai-server **GPU 사양** 명시 필수(YOLO/SAM2 추론). SW 표에 Java 17, Spring Boot 3.3, PostgreSQL, FastAPI/torch, FFmpeg, Quartz(PostgreSQL JobStore). **단일 인스턴스 배포**(BE+Quartz), ai-server만 다중 인스턴스.
- **서버 주소(§2.1)**: local/dev/stg/prd 환경별 BE/ai-server/FE/DB 접속 정보(CLAUDE.md 환경표 기준).
- **상세 작업내역(§2.3)**: 환경변수 키 목록만 기재(`CONTROL_DB_*`, `PORTAL_DB_*`, `JWT_SECRET`, `JWT_ISSUER`, `DEIDENTIFY_API_URL`, `AI_SERVER_URL`, `STORAGE_RAW_PATH`, `STORAGE_DEIDENTIFIED_PATH`, `VITE_API_BASE_URL`). ⚠ **값(시크릿)은 미기재** — security.md: 시스템 설치 결과서 제출본에 DB 계정/비밀번호/JWT 시크릿 평문 금지, 환경변수/Vault 주입 명시.
- **플랫폼 설치 결과(§3)**: BE 빌드(Gradle 8), ai-server 의존(onnxruntime/sam2/transformers), Flyway 마이그레이션(LS_* 자체 / MNG_* validate) 설치 결과 기록.
- **데이터 전환 결과(§4)**: 신규 구축이면 기존→개발 DB 전환 대신 Flyway baseline + MNG_* 공유 스키마 validate 결과로 대체 기재(해당 시). PDF 확인 필요 항목.
- **백업 목록표(§6)**: DB 스냅샷(LS_LABEL_VERSION 라벨 버전), 영상 원본/비식별본 파일 백업, 보존기간·담당자 기록.
- **문제점 및 조치사항(§7)**: 단일 인스턴스 배포의 가용성/백업 전략, GPU 자원 경합, 외부 API 연동 실패 대응(Resilience4j) 등 설치 시 식별된 이슈 기록.
- KLID 산출물 ID 컨벤션: **KLID-AT-T5-NNN** 형식으로 설치 결과 항목 식별.
