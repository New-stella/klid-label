# D7 시스템시험 시나리오 (CBD 표준 산출물 위키)

> 출처: NIA CBD 가이드(2011.12) docs/CBD.pdf 인쇄면 p.79~82

## 1. 작성 목적 / ## 2. 작성 방법 (PDF 원문)

### 1. 작성 목적 (원문)
시스템의 포괄적인 **비기능 요구사항**에 대한 시험을 수행하기 위하여 시험 항목, 시험 절차 및 기준을 설정하기 위한 시나리오를 작성한다.

### 2. 작성 방법 (원문)
성능, 부하, 볼륨, 보안 등 **시험 유형별로** 시스템시험을 수행하기 위해 시나리오에 대한 시험 차를 작성하고 시험 만족기준과 시험결과를 작성한다.

## 4. 항목 설명 (원문 — 전 항목)

- **시험 유형**: 성능, 부하, 볼륨, 보안 시험 등 시험의 측정 형태를 기입한다.
- **관련 요구사항 ID**: 본 산출물이 관련되는 "사용자 요구사항 정의서"의 요구사항 ID를 기술한다.
- **시험 시나리오 ID**: 시스템시험 시나리오에 대한 유일한 ID를 부여하여 기입한다.
- **시험 시나리오**: 시험에 대한 간략한 설명을 기술한다.
- **시험 절차**: 시험 시나리오별 시험을 수행하는 절차를 기술한다.
- **만족기준**: 시험 수행 후 수행결과 측정치에 대한 만족수준 값을 기술한다.
- **시험결과**: 설계단계에서는 기술하지 않으며, 시스템 시험결과서로 활용될 경우 실제 시험을 수행한 결과를 기술한다.
- **비고**: 기타 참조할 만한 사항을 기술한다.

## 5. 작성 사례 요점 (실제 값/패턴 + 산출물코드)

- 블록 헤더 — 시험 유형 `성능` / 관련 요구사항 ID `SS_RQ03002`.
- 시나리오 코드 패턴: `JJ_ST_NNN` (예: `JJ_ST_050`, `JJ_ST_060`).
- 사례 `JJ_ST_050`:
  - 시험시나리오: 입하실적 리포트 조회 기능 실행.
  - 시험절차: 100개의 품목에 대하여 총 3,000건의(30일×100개/1일) 입하를 등록한 후 30일(3,000건 조회), 7일(700건), 1일(100건)에 대한 입하실적 리포트 조회 기능을 실행.
  - 만족기준(측정 지표 `●` + 세부 조건 `◆`로 정량화):
    - ● 응답 시간 — ◆3,000건: 4초 / ◆700건: 1초 / ◆100건: 0.5초
    - ● CPU 사용률 — 3,000건 조회시 최대 40% 이내
    - ● 메모리 사용량 — 3,000건 조회시 최대 50MB 이내
  - 시험결과: (공란 — 설계단계)
  - 비고: 자동화도구 사용(총괄시험계획 참조).
- 사례 `JJ_ST_060`: 출하실적(30,000건 스케일, 7일/1,000건·30,000건 등) 동일 패턴 — 응답시간 ◆30,000건: 40초 / ◆7,000건: 10초 / ◆1,000건: 2초, CPU 40% 이내, 메모리 40MB 이내.

## 6. 함정 / 주의

- **비기능 시험 전용 산출물** — 기능 시나리오는 D10 통합시험 시나리오(유스케이스 기반)가 담당. D7은 성능/부하/볼륨/보안 등 비기능에 한정.
- **시험결과 컬럼은 설계단계 공란** — 실제 측정값은 시스템 시험결과서(T2 등) 단계에서 현행화·기입. 설계 산출물에 추정 결과를 채우지 말 것.
- **만족기준은 반드시 정량화** — 막연한 "빠르게" 금지. 지표(●)별 임계치를 세부 조건(◆)으로 분해해 측정 가능하게 기술.
- 시험 유형별 블록 반복 구조 — 한 표에 여러 유형을 섞지 말고 유형마다 메타 2행 + 본문 표를 별도 블록으로 구성.

## 7. KLID 프로젝트 적용 메모

- **관련 요구사항 매핑**: KLID 기준 비기능 시험은 주로 R1 비기능 표의 `NFR-NNN`을 관련 요구사항 ID로 인용하고, 기능 연계가 필요하면 `RQ-SFR-NN-NN`을 병기.
- **시나리오 ID 체계**: KLID는 `KLID-AT-ST-NNN` 부여(가이드 사례의 `JJ_ST_NNN` 대응).
- **시험결과 공란 유지**: 설계 단계 산출물에서는 시험결과 컬럼을 비우고, 시스템 시험 결과서(T2) 단계에서 현행화·기입.
- 사례 컬럼명 "시험시나리오"는 **명칭(시나리오명) 컬럼**으로 사용.
- KLID 비기능 시험 후보(정량 만족기준 정의 시): 배치 파이프라인 처리량(1건/분), 외부 API 타임아웃/재시도(Resilience4j 정책), 영상 스트리밍 Range 응답, 비식별/오토라벨링 처리 시간, JWT 검증 부하, 대용량 라벨 저장 응답시간 등 — **각 항목은 측정 가능한 임계치로 정의 필요(현재 미확정 항목은 PDF/요구사항 확인 후 기입)**.
