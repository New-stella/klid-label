## 무엇이 왜 여기 있나

### `design-full/` — 2026-08-06 전량 재생성으로 대체된 D1·D3·D8·D9·D11 구판

최종 개정이 2026-07-21 이며, 그 뒤 LogiCraft 그래프에서 `docs/design/` 이 새로 생성되면서 대체됐다.
아래가 구판임을 보여주는 실측 근거다.

- **이미 없어진 테이블을 들고 있다** — `LS_RESOLUTION_EXPORT`·`LS_RESOLUTION_LBL_MAP`(2026-07 폐기)
- **현행 테이블을 모른다** — `LS_DATA_INGEST`·`LS_EVNT_ANNO`·`LS_PORTAL_*` 계열 언급 0회
- **제출본 변환 대상이 아니다** — hwpx 변환 마커가 `docs/design/` 에만 있다
- 테이블 식별자 체계도 다르다(구판 TB-001~041 / 정본 TB-001~063)

### `0705/` — 2026-07-05 시점 해설 문서

같은 이유로 현재 스키마와 어긋난다.

## 왜 고치지 않고 옮겼나

2026-08-13 DB 정리에서 테이블 7종이 없어졌는데, **구판에서 그 7종만 고치면 나머지 10종 넘는
불일치가 남은 채로 최신 문서처럼 보이게 된다.** 부분 정합이 오히려 더 위험하다는 판단이다.

구판을 다시 정본으로 쓸 일이 생기면 **전량 재정합이 선행돼야 한다.**
