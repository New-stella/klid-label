# R2 유스케이스 명세서

> 출처: CBD.pdf §III.1.2 (문서 p10~18)

## 양식 구조

1. **서브시스템 목록** (전체 시스템에 대해 1개 표): | 서브시스템 ID | 서브시스템명 | 서브시스템 설명 |
2. **유스케이스 다이어그램(UCD)** (서브시스템별 작성): 헤더 | UCD ID | UCD 명 | 관련 서브시스템 ID | 관련 서브시스템명 | + 다이어그램
3. **유스케이스 목록** (서브시스템별 작성): | 유스케이스 ID | 유스케이스명 | 유스케이스 설명 | 관련액터 ID | 관련 UCD ID | 관련 요구사항 ID |
4. **액터 목록** (서브시스템별 작성): | 액터 ID | 액터명 | 액터유형(주요/보조/숨은) | 액터설명 |
5. **유스케이스 기술서** (유스케이스별 작성): 헤더(유스케이스ID/유스케이스명) + 본문 8항목:
   1. 주요 액터 / 2. 이해관계자와 관심사항 / 3. 전제조건 / 4. 종료조건 / 5. 기본 시나리오 / 6. 대안 시나리오 / 7. 구현 시 고려 사항 / 8. 발생 빈도

## 작성 목적 (원문)
시스템의 요구사항에 대하여 액터와 시스템 활동 및 상호간의 활동에 대하여 순서화된 시나리오를 상세하게 기술하고, 유스케이스의 이름, 액터, 그들 간의 연관관계를 보여주는 시스템 환경을 다이어그램으로도 표현한다. 또한 주요한 유스케이스에 대하여 대상 시스템과 액터 간의 오퍼레이션을 상세하게 표시하는 **시스템 시퀀스 다이어그램 및 오퍼레이션의 약정**을 나타낼 수 있는데 이 부분은 **필수 산출물에 포함되지 않으며 선택적으로 작성**할 수 있다.

## 작성 방법 (원문)
유스케이스는 시나리오를 구체적인 언어표현으로 기술하고, 유스케이스 다이어그램은 그림으로 작성하며 작성도구를 사용할 수 있다.

## 항목 설명 (원문 요지)

- **서브시스템 목록**: 전체 시스템에 대하여 한 개의 표로 작성. ID/명/간략 설명.
- **UCD**: 서브시스템별로 작성. UCD ID/명, 관련 서브시스템 ID/명.
- **유스케이스 목록**: 서브시스템별 작성. 유스케이스 ID/명/설명(간략), 관련액터 ID, 관련 UCD ID, **관련요구사항 ID**("사용자 요구사항 정의서"의 ID).
- **액터 목록**: 서브시스템별 작성. 액터 유형 — 가) **주요 액터**: 서비스를 사용하여 사용자의 목적을 수행 / 나) **보조 액터**: 서비스를 지원(주로 컴퓨터 시스템, 조직·사람일 수도) / 다) **숨은 액터**: 주요·보조가 아니지만 유스케이스 행위에서 이해관계를 가짐(예: 세무서).
- **유스케이스 기술서** (유스케이스별):
  - 주요 액터: 목적 수행 서비스를 호출하는 주된 액터
  - 이해관계자와 관심사항: 유스케이스 내 사람·조직·컴퓨터 시스템과 이들의 요구사항
  - 전제조건: 시나리오 시작 전 항상 참이어야 하는 조건
  - 종료조건: 주요 성공 시나리오/대안 경로의 성공적 완료 후 참이어야 하는 조건
  - 기본 시나리오: 이해관계자의 관심사항을 충족시키는 일반적인 성공 경로
  - 대안 시나리오: 성공·실패의 모든 시나리오·분기 (기본 시나리오보다 길고 복잡한 경우가 대부분)
  - 구현 시 고려사항: 비기능적 요구사항·품질 속성·설계 제약사항이 유스케이스와 관련되면 기술. 기술적 변화 시 데이터구조 변화 가능성 등도 기재
  - 발생 빈도: 유스케이스 발생 빈도 유형 (사례: "일 1회 이상 지속적으로 발생한다")

## 작성 사례 요점
- 서브시스템: `SS_TOT_010 총액결제관리`. UCD: `SS_UCD_010`(타원에 `SS_UCD_010-01.원화자금이체신청` 식 UC 표기, 액터 좌우 배치).
- UC ID: `SS_UCD_010-01` (목록) / 기술서 헤더는 `SS_UC_010-03`. 액터: `SS_AC_010 주전산기(보조)`.
- 기본 시나리오는 번호 단계("1) 담당자는 …를 선택하고 … 2) 시스템은 입력화면을 출력한다 …"), 대안 시나리오는 "가. 취소 신청" 같은 서브흐름 분기.

## 주의 / KLID 적용
- 시스템 시퀀스 다이어그램·오퍼레이션 약정은 **선택** (필수 아님 — D1 시퀀스도와 별개).
- KLID는 UC ↔ 컴포넌트(D3 CO)·클래스도(D1 DCD) 1:1 도출 기준의 출발점. 관련 요구사항 ID는 R1 실존 ID만.
