# T7 인수시험 결과서

> 출처: CBD.pdf §III.4.7 (문서 p171~174). 단계명=시험.

## 양식 구조

T6 인수시험 시나리오와 **동일 구조** + 시험결과 기입:
1. **시험 시나리오**: 헤더(시험시나리오 ID/명/설명/관련 요구사항 ID) + 케이스 행.
2. **시험케이스**: 헤더(차수/시나리오 ID/케이스 ID) + | 시험 절차{순번, 업무처리내용} | 시험항목 | 사전조건 | 입력자료 | 예상결과 | 화면ID | **시험결과** | 비고 |

## 작성 목적 (원문)
총괄시험 계획서와 인수시험 시나리오에 따라서 수행한 시험 결과를 기술한다.

## 작성 방법 (원문)
**사용자 요구사항의 시스템 반영여부를 시험**하고 시험결과를 작성한다.

## 항목 설명 (원문)
- **시험 시나리오**: "인수시험 시나리오"의 시험 시나리오를 **현행화**하고, 인수시험을 수행한다.
- **시험 케이스**: "인수시험 시나리오"의 시험 케이스를 현행화하여 시험을 수행 후, 시험결과를 기록한다.

## 작성 사례 요점
- T6 시나리오/케이스 재사용. 시험결과 기재 예: "예상결과와 동일(화면1 참조)" / "**오류발생(화면3 참조)**" — 성공·실패 모두 증빙 화면 참조로 기록.

## 주의 / KLID 적용
- 요구사항 반영여부의 최종 검증 — 실패 항목은 조치 후 재시험(차수 증가) 기록. 발주자(고객) 주도 시험이므로 결과 표현은 증빙 중심.
