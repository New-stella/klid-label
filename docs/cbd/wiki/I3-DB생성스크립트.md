# I3 DB 생성 스크립트 (데이터베이스 테이블)

> 출처: CBD.pdf §III.3.3 (문서 p134~137). 단계명=구현. ※ 산출물 목록표 명칭은 "데이터베이스 테이블", 양식 제목은 "DB 생성 스크립트".

## 양식 구조

1. **목록**: | 관련 서브시스템 | 생성 스크립트{ID, 스크립트명} | 데이터베이스{ID, 데이터베이스명} | 테이블{ID, 테이블명} | 인덱스{ID, 인덱스명} | 트리거 | 설치 위치 |
2. **DB생성 스크립트**: (스크립트 파일 제출)
3. **코드 및 초기 데이터 생성 스크립트**: (스크립트 파일 제출)

## 작성 목적 (원문)
설치할 목적의 물리 데이터베이스 테이블의 명세와 테이블, 초기데이터 등을 생성하기 위한 생성 스크립트를 작성한다.

## 작성 방법 (원문)
데이터베이스 테이블 및 생성 스크립트의 목록을 기술하고, 하드웨어 배치도 상의 데이터베이스 설치 위치를 표시하며 **테이블 생성 스크립트를 DDL로** 작성한다.

## 항목 설명 (원문 전 항목)
- **관련 서브시스템**: 본 생성 스크립트에 관련되는 서브시스템명.
- **생성 스크립트 ID/명**: 테이블 생성 스크립트 ID/명칭.
- **데이터베이스 ID/명**: 생성 스크립트에 관련된 DB ID/이름.
- **테이블 ID/명**: 스크립트에 포함된 테이블.
- **인덱스 ID/명**: 스크립트에 포함된 인덱스.
- **트리거**: 테이블별 관련 트리거가 있으면 트리거의 내용.
- **설치 위치**: 테이블이 설치될 **하드웨어 명칭 또는 모델명**.

## 작성 사례 요점
- `POS | JJ_DDL_040 Produt.ddl | JJ_DB_050 상품DB | JJ_TS_040 상점 / JJ_TS_050 카탈로그 / JJ_TS_060 상품명세 | JJ_IDX_040 주소Index | 상품Table DDL | POS.PROD…` — 스크립트 1건이 복수 테이블 포함 가능.
- §2·§3은 스크립트 파일 제출로 갈음.

## 주의 / KLID 적용
- KLID는 Flyway 마이그레이션(`backend/src/main/resources/db/migration/`)이 §2·§3의 실체 — 목록 표에 마이그레이션 파일(V*.sql)을 스크립트 ID로 매핑. PostgreSQL 표준 DDL.
