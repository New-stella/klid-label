# D12 데이터 전환 및 초기데이터 설계서

> 출처: CBD.pdf §III.2.12 (문서 p105~126). ※ **초기데이터 구축·전환데이터가 없는 프로젝트는 생략 가능** (가이드 §I.3).

## 양식 구조 (자유 목차형)

```
1. 개요 (1.1 목적 / 1.2 범위 / 1.3 참조문서)
2. 중점 목표와 구축 전략 (2.1 중점 목표 / 2.2 구축 전략 / 2.3 구축 방법)
3. 전환 조직 및 전환 일정 (3.1 조직 및 역할 / 3.2 전환 작업 수행 타스크 / 3.3 시스템별 전환 상세 일정)
4. 전환 대상 및 범위 (4.1 전환 시스템 및 범위 / 4.2 전환 상세 데이터)
5. 전환 상세 절차
  5.1 데이터 전환 작업순서 / 5.2 절차 및 역할 / 5.3 신구 데이터 매핑 작업
  5.4 현행시스템 데이터 전환 / 5.5 DB LOAD 및 데이터 입력
  5.6 전환결과 검증 및 오류처리 / 5.7 최종 데이터 전환 시 전환 작업 일정
6. 기타 (6.1 신규 데이터 처리 방안 / 6.2 초기 데이터 수집 구축 / 6.3 데이터 전환 시 비상대책 안)
```

## 작성 목적 (원문)
초기 데이터 구축 시 단시일에 대량의 데이터를 이행함에 있어 신속하고 안정적인 데이터 이행을 위하여 체계적인 절차를 수립하여 구축 시 발생할 문제점을 사전에 차단하기 위한 계획을 수립한다.

## 작성 방법 (원문)
업무그룹별 전환계획이 필요한 경우와 전체 미니프로젝트를 통합하여 전환하는 경우를 구분하여 계획을 수립한다. 업무그룹별로 전환하는 경우에는 전체적인 전환 완전성을 검증한다.

## 항목 설명 (원문 요지)
- **개요**: 목적, 범위, 참조문서.
- **중점 목표와 구축전략**: 중점 목표·구축전략·방법.
- **전환조직 및 전환일정**: 조직·역할, 전환 작업 수행 타스크, 시스템별 상세 일정.
- **전환 대상 및 범위**: 전환 시스템·범위, 전환 상세 데이터.
- **전환 상세 절차**: 작업순서 / 절차·역할 / 신·구 데이터 매핑 / 현행시스템 데이터 전환 / DB LOAD·데이터 입력·전환결과 검증·오류처리 / 최종 전환 작업 일정.
- **기타**: 신규데이터 처리 방안, 초기데이터 수집 구축, 비상대책 안.

## 작성 사례 요점
- 참조문서: 현행/신시스템의 분석·설계 산출물 표(환경구성도·DB목록·TABLE 명세서·코드집·테이블/데이터 매핑내역서 등).
- 데이터 매핑 내역서 표: 신시스템{항목명/타입} ↔ 현행{테이블ID/명/항목명/타입} + 전환내용{구분(신규/전환)/전환기준(MOVE, "용국기호+일련번호로 신규생성" 등)}.
- 전환 작업순서 흐름: 전환대상 선정 → 신·구 매핑 → 전환프로그램 설계/구현/시험 → 추출·전환 수행 → 검증·오류처리 → 데이터 Load → 검증·오류처리.
- 검증: 입력 데이터/입력 프로그램/전환 프로그램 오류별 수행주체, 신구 값 일치·코드 Master 존재·테이블 간 일관성 확인. D-3~D 단계별 세부 일정(테이블 Space·PK/FK 생성 → 전환 → Load → Index·Analyze·Cold 백업).

## 주의 / KLID 적용
- 서술형 목차 산출물. KLID 저작도구는 신규 구축(전환 대상 레거시 DB 없음)이면 생략 가능 — 초기데이터(코드성 데이터·시스템 설정)가 있으면 §6.2 중심으로 축소 작성.
