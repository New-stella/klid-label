# I1 프로그램 코드

> 출처: CBD.pdf §III.3.1 (문서 p127~129). 단계명=구현.

## 양식 구조

1. **프로그램 목록**: | 서브시스템명 | 프로그램파일{ID, 파일명} | 비고 |
2. **프로그램 소스코드**: (소스코드 제출)

## 작성 목적 (원문)
설계 명세서에서 기술한 프로그램 코드에 대한 물리적인 형상과 코드 관리를 위한 명세를 기술한다.

## 작성 방법 (원문)
프로그램 코드의 프로그램 목록을 기술한다.

## 항목 설명 (원문 전 항목)
- **서브시스템명**: 본 프로그램파일이 관련되는 서브시스템명.
- **프로그램파일 ID**: 프로그램 파일의 ID.
- **프로그램파일명**: 프로그램 파일 명칭.
- **비고**: 기타 참조할 만한 사항.

## 작성 사례 요점
- `POS | SS_DP_010 | SS_ProSale.jar`, `POS | SS_DP_020 | SS_PreSale.jar` — 배포 단위(jar) 수준 목록 + 소스코드 별도 제출.

## 주의 / KLID 적용
- 목록은 배포/모듈 단위로 간결하게, 실제 소스는 저장소(git) 제출로 갈음 가능. R3 추적표의 "파일 ID"가 본 산출물 ID를 인용.
