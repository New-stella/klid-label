# T3 사용자 지침서 (CBD 표준 산출물 위키)

> 출처: docs/CBD.pdf 인쇄면 p.147~148 (PDF index 약 150~151). §III.4 시험 단계 / 4.3 사용자 지침서. 헤더박스 단계명 = "시험". 매뉴얼형 산출물 — 목차·구성 중심.

## 1. 작성 목적 / 2. 작성 방법 (PDF 원문)

### 작성 목적 (원문 그대로)
> 개발한 시스템을 사용자가 효과적으로 사용할 수 있도록 기능적인 설명과 기타 예외처리에 대한 지침을 기술한다.

### 작성 방법 (원문 그대로)
> 개발 시스템의 기능 및 예외처리 사항을 빠짐없이 기술하며, 이해하기 쉽고 구체적인 언어표현을 사용한다. 사용자지침서의 경우 시스템의 특성에 따라 기술하는 항목이 차이가 많이 발생할 수 있으므로 내용이 빠지지 않도록 관련항목을 수정하여 사용한다.

## 4. 항목 설명 (전 항목 — PDF 원문)

- **개요**: 시스템의 사용자 측면의 전체적인 개요를 기술한다.
- **사용 지침**: 시스템의 설치방법, 시작 및 종료 방법과 공통적인 내용을 **화면 캡처를 이용하여** 사용자가 쉽게 사용할 수 있도록 기술한다.
- **기능별 사용법**: 기능 이름, 기능 설명, 주의 사항, 오류 메시지 및 원인 등을 빠짐없이 완전하고 일관된 언어표현으로 **화면 캡처를 이용하여** 이해하기 쉽게 기술한다.
- **부록**: 오류 메시지 및 처리 절차, 용어 및 색인 등을 제공한다.

## 5. 작성 사례 요점 (실제 값/패턴)

> ※ PDF 4.3 구간(p.147~148)에는 양식·목차·항목설명만 수록되고 별도 채워진 작성 사례 표는 본 구간에 미포함 — 일반 매뉴얼 작성 관례 기준으로 정리(상세 사례 값은 PDF 확인 필요).

- **기능 설명**: 화면 캡처 + ①②③ 번호 마커로 화면 영역별 조작 설명(조회/등록/수정 절차)이 일반 패턴.
- **오류 메시지 표**: `| 오류 메시지 | 원인 | 처리 방법 |` 구조.
- **부록**: 오류 메시지·처리 절차 표 + 용어 표(`| 용어 | 설명 | 별칭 |`) + 색인.
- 핵심: 설치→시작/종료→공통→기능별 순으로, 화면 캡처를 중심으로 단계별 조작을 누락 없이 서술.

## 6. 함정 / 주의

- **표/시나리오 산출물이 아님** — 매뉴얼형. T1/T2(결과 현행화 표)와 달리 자유 목차 + 화면 캡처 중심.
- "관련항목을 수정하여 사용" — 시스템 특성에 따라 목차 항목을 가감하되, **빠짐없이** 기술하는 것이 원칙(특히 예외처리/오류 메시지).
- 화면 캡처 필수 기조 — 텍스트만으로 끝내지 말 것.
- 헤더박스 식별 코드는 **T3**, 단계명 = "시험" (사용자 지침서지만 CBD상 시험단계 산출물로 분류).
- T1/T2와 달리 D-단계 현행화 사슬이 명시되지 않은 독립 매뉴얼 — 다만 실제 구현 화면/기능에 정합해야 한다.

## 7. KLID 프로젝트 적용 메모

> 기존 KLID 적응(화면 캡처 필수·기능=화면/메뉴 단위 반복·역할별 구분) 보존 + 본 단계 추가.

### KLID 적응 보존
- 화면 캡처 필수 기조. 기능 단위 = 화면/메뉴 단위로 3.x 반복.
- **KLID 역할(REVIEWER/WORKER/PORTAL_USER)별 접근 기능 구분 명시 권장.**

### KLID 도메인 적용
- **2. 사용 지침 — 2.1 설치 방법**: 저작도구는 **독립 로그인 UI 없음**. 관제서버(내부)/포털(외부)이 발급한 JWT를 인계받아 진입(동일 도메인 localStorage 공유). "설치"보다 **진입/접속 방법**으로 재해석 — 세션 만료 시 상위 시스템 로그인 페이지 리다이렉트.
- **2.3 공통 사항**: 역할 분기(`@PreAuthorize`), 관리 화면 URL `/manage/*`(REVIEWER 전용), 표준 응답/오류(`ApiResponse`, `errorCode`).
- **3. 기능별 사용법** (역할별):
  - **WORKER**: 마킹(비식별 영상 스트리밍 + 배속 0.25x~4x + 단축키 Space/Del/Enter), 라벨링(바운딩박스/폴리곤/세그멘테이션/SAM2 분할·Track, konva 캔버스, undo/redo), 라벨 저장, 검수 제출, 비식별 누락 신고.
  - **REVIEWER**: 사용자 관리·시스템 설정, 작업 배정/재배정/이력, 검수 승인/반려, VLM 메타 검토(SCR-AUTO-002), 증강 결과 검수(SCR-AUG-002), 해상도 변경(SFR-06-03).
  - **PORTAL_USER**: 데이터마트 영상 선택, 기존 라벨 Load·수정·저장(`LS_PORTAL_USER_LABEL`, 단방향), 본인 데이터 기간 내 다운로드. (오토라벨링·VLM·버전관리·검수·업로드 미제공 — ADR-013).
- **3.x.3 오류 메시지 및 원인 / 부록**: 비식별 미완료 스트리밍 NOT_FOUND, 본인 배정 외 프레임 편집 403, 업스케일 해상도 변경 400 거부, 외부 API 타임아웃(VLM 45s / AI 60s) 등 ErrorCode enum 기반 메시지를 표로 정리. 용어표(WORKER/REVIEWER/마킹/오토라벨링/비식별/VLM 등).
- 반응형 웹·WCAG 2.1 AA(포털) 준수 — 모바일/태블릿 화면 캡처도 포함 권장.
