## 항목 설명

### 프로그램 목록

- **서브시스템명**: 본 프로그램파일이 관련되는 서브시스템명을 기입한다.
- **프로그램파일 ID**: 프로그램 파일의 ID를 부여하여 기입한다.
- **프로그램파일명**: 프로그램 파일 명칭을 기입한다.
- **비고**: 기타 참조할 만한 사항을 기술한다.

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_프로그램코드_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 서브시스템 ID: `KLID-AT-SS-NNN` (R2 참조)
>   - 컴포넌트 ID: `KLID-AT-CO-NNN` (D3 참조)
>   - 프로그램파일 ID: 프로그램별 부여
>
> - `backend/src/main/java/kr/co/cudo/authoring/` 패키지 구조에서 프로그램 목록을 추출한다.
> - 서브시스템별로 Controller, Service, Repository, Entity 등을 프로그램 파일 단위로 목록화한다.
> - `ai-server/app/routers/` 의 Python 파일(yolo.py, sam2.py, vlm.py)도 별도 서브시스템으로 목록화한다.
> - `frontend/src/` 의 주요 페이지/컴포넌트도 프론트엔드 서브시스템으로 목록화한다.
> - 소스코드는 별도 형상관리 시스템(Git)으로 제출하며, 본 문서에는 목록만 기재한다.
