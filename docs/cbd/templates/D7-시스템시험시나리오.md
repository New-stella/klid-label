# D7 시스템시험 시나리오

> 시스템의 포괄적인 비기능 요구사항에 대한 시험을 수행하기 위하여 시험 항목, 시험 절차 및 기준을 설정하기 위한 시나리오를 작성한다.

## 작성 방법
> 성능, 부하, 볼륨, 보안 등 시험 유형별로 시스템시험을 수행하기 위해 시나리오에 대한 시험 차를 작성하고 시험 만족기준과 시험결과를 작성한다.

## 항목 설명

- **시험 유형**: 성능, 부하, 볼륨, 보안 등 시험의 측정 형태를 기입한다.
- **관련 요구사항 ID**: 본 산출물이 관련되는 "사용자 요구사항 정의서"의 요구사항 ID를 기술한다.
- **시험 시나리오 ID**: 시스템시험 시나리오에 대한 유일한 ID를 부여하여 기입한다.
- **시험 시나리오**: 시험에 대한 간략한 설명을 기술한다.
- **시험 절차**: 시험 시나리오별 시험을 수행하는 절차를 기술한다.
- **만족기준**: 시험 수행 후 수행결과 측정치에 대한 만족수준 값을 기술한다.
- **시험결과**: 설계단계에서는 기술하지 않으며, 시스템 시험결과서로 활용될 경우 실제 시험을 수행한 결과를 기술한다.
- **비고**: 기타 참조할 만한 사항을 기술한다.

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_시스템시험시나리오_Rev {버전}`
> - 본 산출물에서 사용하는 ID:
>   - 시스템시험 시나리오 ID: `KLID-ST-NNN` (예: `KLID-ST-001`)
>   - 관련 요구사항 ID: `RQ-AT-NNN` (기능), `RQ-{비기능코드}-NNN` (비기능) — R1 참조
>
> - 시험 유형별 시나리오 예시:
>   - **성능**: 배치 파이프라인 1건/분 처리, YOLO 추론 응답시간, API 응답시간(3초 이내)
>   - **부하**: 동시 사용자 30명 라벨링 작업, 대용량 영상 업로드(TUS)
>   - **볼륨**: 10만장 이미지 라벨 데이터 조회, 5,000건 영상 관리
>   - **보안**: JWT 토큰 만료 처리, 비식별 데이터 접근 통제, SQL Injection 방어
> - 만족기준은 정량적으로 기술한다 (예: "3,000건 조회 시 응답시간 4초 이내", "CPU 사용률 최대 40%")
> - CLAUDE.md의 배치 성능 요구사항과 SFR-16/17 목표치를 참고한다.
