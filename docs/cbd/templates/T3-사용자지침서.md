# T3 사용자 지침서

## 작성 목적
> 개발한 시스템을 사용자가 효과적으로 사용할 수 있도록 기능적인 설명과 기타 예외처리에 대한 지침을 기술한다.

## 작성 방법
> 개발 시스템의 기능 및 예외처리 사항을 빠짐없이 기술하며, 이해하기 쉽고 구체적인 언어표현을 사용한다. 사용자지침서의 경우 시스템의 특성에 따라 기술하는 항목이 차이가 많이 발생할 수 있으므로 내용이 빠지지 않도록 관련항목을 수정하여 사용한다.

## 항목 설명

- **개요**: 시스템의 사용자 측면의 전체적인 개요를 기술한다.
- **사용 지침**: 시스템의 설치방법, 시작 및 종료 방법과 공통적인 내용을 화면 캡처를 이용하여 사용자가 쉽게 사용할 수 있도록 기술한다.
- **기능별 사용법**: 기능 이름, 기능 설명, 주의 사항, 오류 메시지 및 원인 등을 빠짐없이 완전하고 일관된 언어표현으로 화면 캡처를 이용하여 이해하기 쉽게 기술한다.
- **부록**: 오류 메시지 및 처리 절차, 용어 및 색인 등을 제공한다.

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_사용자지침서_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 화면 ID: `KLID-AT-SC-NNN` (D2 참조)
>
> - 본 프로젝트의 사용자 지침서는 역할별로 분리하여 작성한다:
>   - **REVIEWER(검수자)**: 사용자 관리, 시스템 설정, 작업자 배정/재배정, 검수 승인/반려, 마킹 모드 설정
>   - **WORKER(라벨링 작업자)**: 라벨 편집(bbox/polygon/segmentation), 검수 제출, 버전 비교
>   - **PORTAL_USER(포털 회원)**: 영상 선택, 간편 라벨링, 오토라벨링 체험, 데이터 다운로드
> - 화면 캡처는 `frontend/` 실행 화면을 캡처하여 첨부한다.
> - 시작/종료: 관제서버/포털에서 JWT 인계 후 저작도구 진입, 세션 만료 시 리다이렉트
> - 오류 메시지: `common/exception/ErrorCode` enum의 에러 코드와 메시지를 정리한다.
