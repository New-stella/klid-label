# T2 시스템시험 결과서

## 작성 목적
> 총괄시험 계획서와 시스템시험 시나리오에 따라서 수행한 시험 결과를 기술한다.

## 작성 방법
> 성능, 부하, 볼륨, 보안 등 시험 유형별로 시스템시험을 수행하고 시험 예상결과와 시험결과를 비교한다.

## 항목 설명
> 설계단계 산출물인 "시스템시험 시나리오"를 현행화하여 시험을 수행 후, 시험결과를 기록한다.

- 각 항목은 D7(시스템시험 시나리오)의 항목 설명과 동일하다.
- **시험결과**: 실제 시스템시험을 수행한 결과를 기술한다. (측정값 + Pass/Fail 판정)

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_시스템시험결과서_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 시스템시험 시나리오 ID: `KLID-ST-NNN` (D7 참조)
>   - 관련 요구사항 ID: `RQ-AT-NNN` / `RQ-{비기능코드}-NNN` (R1 참조)
>
> - D7(시스템시험 시나리오)의 양식을 그대로 사용하되, "시험결과" 컬럼을 실제 측정값으로 채운다.
> - 성능 시험: 실제 응답시간, 처리량, CPU/메모리 사용률 등 정량적 측정값을 기록한다.
> - 보안 시험: OWASP 점검 결과, 취약점 스캔 결과를 기록한다.
> - 만족기준 대비 실제 결과를 비교하여 Pass/Fail을 판정한다.
> - 시험 도구(JMeter, OWASP ZAP 등)의 리포트를 별첨으로 첨부한다.
