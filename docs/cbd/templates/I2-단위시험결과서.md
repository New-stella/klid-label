# I2 단위시험 결과서

## 작성 목적
> 단위시험 케이스에 따라 수행한 단위시험의 수행 결과를 기술한다.

## 작성 방법
> 작성한 단위시험 케이스에 따라 시험을 수행하고 시험 결과를 기술하며 예상결과와 비교하여 단위시험의 판정 결과를 작성한다.

## 항목 설명
> 설계단계 산출물인 "단위시험 케이스"를 현행화하여 시험을 수행 후, 시험결과를 기록한다.

- 각 항목은 D11(단위시험 케이스)의 항목 설명과 동일하다.
- **시험결과**: 실제 시험을 수행한 결과를 **5요소로 기록**한다 — **수행자 / 수행일 / 결과(Pass·Fail) / 결함내용(별첨 참조 가능) / 결함조치완료여부(조치 완료일)**. (작성 사례 기준 — fail 케이스는 조치 완료 기록까지가 완성 조건)

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_단위시험결과서_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 단위시험 ID: `KLID-AT-UT-NNN` (D11 참조)
>   - 관련 컴포넌트 ID: `KLID-AT-CO-NNN` (D3 참조)
>
> - D11(단위시험 케이스)의 양식을 그대로 사용하되, "시험결과" 컬럼을 채운다.
> - JUnit 5 테스트 실행 결과(Pass/Fail, 실행 시간)를 시험결과에 기입한다.
> - 실패한 케이스는 결함 내용과 수정 후 재시험 결과를 비고에 기술한다.
> - `./gradlew test` 또는 `./gradlew test --tests "패키지명"` 실행 결과 리포트를 첨부한다.
> - ai-server의 경우 `pytest tests/` 실행 결과를 기입한다.
