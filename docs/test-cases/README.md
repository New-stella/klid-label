### ★ 근거는 `파일명(심볼명)` 으로 적는다 — 라인번호 금지 (2026-08-05 사용자 확정, 구속)

근거 칸에는 **판정 주체**를 `PresetService.java(resolveLabels)` 형태로 적습니다. `:105-143` 같은 **라인번호는 적지 않고**, **심볼은 특정 가능하면 반드시 적습니다.**

- **라인번호를 폐지한 이유 — 유지비가 정보 가치를 압도했습니다.** 회차 4 는 정정 ≈699건 중 **기대결과·전제가 실제로 바뀐 건이 24건뿐**이었고 나머지는 전부 라인 드리프트였습니다. 회차 11 은 **76건 전량이 드리프트**(순수 리팩토링, 동작 무변경)였습니다. 즉 회차 노동의 대부분이 "코드를 여는 시간 몇 초"를 위해 소모됐습니다.
- **stale 라인은 없느니만 못합니다.** 회차 4 에서 H-16 의 **17건이 엉뚱한 함수를 가리키고** 있었습니다. 검증자가 그 라인을 열면 잘못된 판정을 합니다 — 틀린 좌표는 좌표가 없는 것보다 위험합니다.
- **★ 심볼은 생략하지 않습니다.** 심볼은 메서드·클래스·테스트명 등 **그 판정을 실제로 수행하는 지점**을 가리키며, 라인과 달리 **리네임 전까지 안정적이면서 검색으로 즉시 도달**합니다. 판정 지점이 여러 곳이면 ` · ` 로 나열합니다(`LabelService.java(bulkUpsert · isNewLabel)`). **심볼 특정이 불가능한 경우**(설정 `application.yml`·마이그레이션 SQL·정책 상수 파일 등)에만 파일명 단독을 허용합니다.
- **적어도 되는 것**: 심볼명(`VlmUrlPolicyTest.java:cgnatRangeRejectedInBothPolicies`) · 짧은 성격 설명(`(신고 게이트 · 락 409)`). **적지 않는 것**: 라인번호, 라인 기반 정정 이력(`구 126-134 드리프트`), 파일 총 줄 수.
- **정정이 필요한 경우**: 파일 **리네임·삭제·이동**, **판정 주체의 클래스 이동**(회차 4 의 `FrameImageController` → `FrameImageService`), **심볼 리네임**. 라인 이동은 더 이상 정정 사유가 아닙니다.
- ⚠ **기존 행은 일괄 백필하지 않습니다 (2026-08-05 사용자 확정).** 회차 12 시점 심볼 보유율은 **13%(287/2,134)** 이고, 나머지 1,847행은 파일명 단독입니다. 코드를 열어 판정 메서드를 찾는 작업이라 기계 치환이 불가능해 전수 보강 비용이 회차 4 급이기 때문입니다. **앞으로 정정·신설로 손대는 행부터 심볼을 채워** 보유율을 점진적으로 올립니다 — 즉 파일명 단독 행이 남아 있는 것은 **결함이 아니라 미보강 상태**이며, 그 자체를 드리프트로 집계하지 않습니다.
