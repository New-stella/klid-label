## I-6. 경로 탐색 — 손으로 적지 않고 골라 넣는다 (2026-08-26 신설)

> **왜 만들었나**: 서버가 허용 저장소 범위를 **판정만 하고 안내는 하지 않는 비대칭**이 있었다. 검수자는 경로를
> 외우거나 다른 곳에서 옮겨 적어야 했고 한 글자만 틀려도 찾을 수 없다는 응답을 받았다. 판정 근거인 허용 루트
> 목록을 서버가 이미 갖고 있으므로, 그것을 내려주면 타이핑이 필수가 아니라 **선택**이 된다.
>
> ⚠ **탐색은 직접 입력을 대신하지 않는다** — 탐색이 죽어도 경로를 적어 검사할 수 있어야 한다(FE 축 `TC-FE-1049`).
>
> ⚠ **허용 범위 판정을 복제하지 않는다** — 탐색은 검사·적재와 **같은 판정기를 호출만** 한다. 목록이 두 벌이 되면
> 한쪽만 넓어져 한 창구에서 막히는 자리가 다른 창구에서 열린다(`ImportSourcePolicy`·`VideoArtifactRootResolver`
> **무변경**을 git diff 0바이트로 실증).
>
> ⚠ **알려진 제약 — 허용 저장소 루트가 심링크면 왕복이 깨진다.** 판정기가 표기 기준 검사를 먼저 하는데 탐색은
> 실경로를 싣기 때문이다(증상: 위로 가기가 항상 비활성 · 고른 폴더가 곧바로 400). 판정기는 공용 소유라
> **코드가 아니라 운영 규약으로** 막았다 — `deploy/onprem/docs/04-configuration.md`. **결함으로 재분류하지 말 것.**
