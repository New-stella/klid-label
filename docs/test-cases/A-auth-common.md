## A-8. AI 정밀도 기본값 읽기 전용 조회 (`GET /v1/ai-defaults`) — 2026-08-08 신설

> 라벨링 화면(SC-005)이 AI 도구 슬라이더 **초기값 두 개**만 받아 가는 경로다. **관리 영역(`/v1/manage/**`) 밖**에 두고 내부 채널 **검수자·작업자 모두 200** 이다.
> **왜 새 경로인가**: 기존 `GET /v1/manage/configs` 의 읽기 권한만 넓히는 안은 채택하지 않았다 — 그 응답은 설정 전량 + **마지막 수정자 계정 식별자**를 담아 작업자에게 운영 파라미터와 검수자 계정 정보가 함께 나간다. 구 처방(호출을 역할로 게이팅)은 403 은 없앴지만 **작업자가 저장된 기본값을 아예 못 받게** 만들어 문제를 옮긴 것이었다.

## A-9. 연동 서버 주소 설정 + 관리자 단기 유효창 (R11) — 2026-08-10 신설

> 외부 연동 4종의 주소를 운영 화면에서 **재기동 없이** 바꾼다. 설정 키는 **애플리케이션 속성명과 같다** — 별도 키명을 만들면 매핑표가 두 번째 진실원이 되어 한쪽만 갱신되는 순간 화면에서 바꾼 주소가 엉뚱한 연동에 반영된다.
> **시드하지 않는다** — 설정 행이 없는 것이 정상이며 그때는 배포 기본값(`@Value`)이 쓰인다.
> 이 4개 키는 REVIEWER 권한 위에 **관리자 단기 유효창**(패스워드 재확인, 기본 10분·상한 30분)을 하나 더 요구한다.
> **비식별 키는 `kpst.deid.base-url` 이다 (2026-08-10 확정)** — 구 설계가 지정한 `authoring.integration.deidentify.base-url` 은 **주입 대상 0건인 빈**을 구동해 바꿔도 위탁 주소가 달라지지 않았다. 실효 0 인 칸을 화면에 남기지 않으므로 구 키는 화이트리스트에서 제거됐다.
>
> ★ **IP 대역 차단은 폐지됐다 (2026-08-10 사용자 확정, 구속)** — 사설·링크로컬·루프백 차단과 **요청 전송 직전 재검증(DNS rebinding 방어)** 이 모두 사라졌다. 근거: 연동 4종은 **실제로 내부망의 별도 서버에 있을 가능성이 높아** 대역으로 막으면 정당한 대상을 막는다. 망 통제는 **인프라 계층** 책임이다. 남는 검증은 **스킴(`http`/`https`) + 형식**뿐이다. ⚠ 아래 대역 케이스들은 **지우지 않고 기대값을 뒤집어** "막지 않는다"를 계약으로 고정한다 — 지우면 다음 사람이 방어가 원래 없었다고 오해하고 되살린다.
>
> ⚠ **기동 시점 정책(TC-PROF-013·014, `ExternalUrlPolicy`)은 override 에 다시 적용되지 않는다** — 그 정책이 판정하는 대상은 **배포 기본값**(`@Value`)이고, 운영 화면에서 넣은 값은 위 스킴·형식 검증만 거쳐 필터가 요청 URL 을 갈아끼운다. 즉 VLM 처럼 기동 시점에 HTTPS·공인망이 강제되는 연동도 **override 로는 평문 http·내부 대역 주소가 나간다**. 두 축은 대상이 달라 모순이 아니며, TC-PROF-013·014 를 근거로 "override 도 막힌다"고 읽지 말 것.
