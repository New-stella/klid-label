## 1. 문서 개요

### 1.1 목적

본 문서는 학습데이터 저작도구의 사용자 인터페이스(UI) 및 사용자 경험(UX)에 대한 설계 기준을 정의한다. 화면 레이아웃, 컴포넌트 구성, 사용자 플로우, 상호작용 규칙을 명세하여 개발 단계에서의 구현 기준으로 활용한다.

### 1.2 범위

| 채널 | 대상 사용자 | 진입 방식 |
|------|-------------|-----------|
| 관제지원시스템 (내부) | 라벨링 작업자, 검수자 | 관제서버 세션 인계 (JWT) |
| AI 영상학습 사용자 포털 (외부) | 데이터 기여자, 외부 AI 연구자 | 포털 서버 세션 인계 (JWT) |

두 채널 모두 저작도구 자체 로그인 화면 없음. 상위 시스템(관제서버 / 포털 서버)에서 발급한 JWT 토큰을 인계받아 진입한다. 세션 만료 시 각 상위 시스템 로그인 페이지로 리다이렉트한다.

### 1.3 관련 SFR

| SFR | 기능명 |
|-----|--------|
| SFR-07 | 데이터 증강 |
| SFR-08 | 저작도구 핵심 기능 (오토라벨링 결과 확인·VLM 객체 검증·외부 메타 검토 UI·증강 연동·배경영상 요청·생성된 영상 라벨링 흡수) |
| SFR-09 | 비식별화 결과 확인 |
| SFR-15 | AI 영상학습 사용자 포털 |
| SFR-16 | 이미지 학습데이터셋 |
| SFR-17 | 영상 학습데이터셋 |
| QUR-03 | 검수 품질관리 |

본체가 외부 시스템인 SFR-03(시계열 메타데이터)·SFR-06(생성형 AI)·SFR-11(영상 합성 모델)은 요구사항정의서에서 제외되며, 저작도구 잔존 책임(VLM 객체 검증·외부 메타 검토·증강 연동·배경영상 요청·생성 영상 라벨링)은 모두 SFR-08에 흡수된다.

### 1.4 화면 ID 체계

```
SCR-[도메인코드]-[3자리 순번]

도메인코드:
  VIDEO  : 영상 목록 / 처리 현황 / 영상 상세 (메인 진입점)
  DASH   : 대시보드
  PRESET : 프리셋 관리
  TASK   : 작업 관리
  LABEL  : 라벨링 도구
  AUTO   : 오토라벨링 결과 확인·메타데이터
  HIST   : 히스토리·버전관리
  REVIEW : 검수 워크플로우
  DEIDENT: 비식별화 결과 확인
  STAT   : 통계
  AUG    : 데이터 증강
  EXPORT : 내보내기
  GEN    : 배경영상 생성
  PORTAL : 포탈 진입
  MANAGE : 관리 (사용자 관리·시스템 설정 — 검수자 전용)
```

### 2.4 공통 인터랙션

- 버튼 Hover: 배경색 10% 어둡게
- 클릭 피드백: 0.1s ease-in transition
- 로딩 상태: 전체 Overlay 스피너 (중앙 정렬, semi-transparent BG)
- 토스트 알림: 우측 상단 고정 (성공/오류/경고 구분)
- 모달 딤처리: `rgba(0,0,0,0.4)` 배경, 클릭 시 닫기 허용 (폼 작성 중 제외)
- 세션 만료 시: 현재 URL 저장 후 상위 시스템(관제서버 또는 포털) 로그인 페이지로 리다이렉트

## 3. 공통 컴포넌트

### 3.1 GNB (Global Navigation Bar)

```
┌────────────────────────────────────────────────────────────────────┐
│  [로고: AI 학습데이터 저작도구]  영상  |  작업관리  |  통계  |  관리          │
│                                                   [🔔] [👤 박찬기 ▼] │
└────────────────────────────────────────────────────────────────────┘
```

- 로고 클릭 시 영상 목록(메인 진입점, `/video/completed`)으로 이동
- 알림 아이콘: 배치 처리 완료, 검수 결과, 작업 배정 알림
- 사용자 드롭다운: 프로필 확인, 로그아웃 (비밀번호 변경은 상위 시스템 담당)
- GNB 라벨은 "영상"으로 통일

### 3.2 LNB (Left Navigation Bar)

"영상" 그룹은 `/video/*` 경로로 영상 목록·처리 현황 메뉴를 제공한다. 배경영상 생성은 영상 목록 행 액션(✨ 배경영상 요청)으로 진입하며 LNB에는 별도 메뉴를 두지 않는다.

```
┌──────────────────┐
│  ▼ 영상           │
│    └ 영상 목록     │  (/video/completed)
│    └ 처리 현황     │  (/video/status)
│  ▼ 작업 관리      │
│    └ 작업 목록    │  (/task)
│    └ 작업 배정    │  ← REVIEWER 전용
│  ▼ 라벨링        │
│    └ 라벨링 도구  │
│  ▼ 검수          │
│    └ 검수 대기    │
│  ▼ 통계          │
│  ▼ 데이터        │
│    └ 데이터 증강  │
│    └ 내보내기     │
│  관리 (검수자 전용)│
└──────────────────┘
```

**메뉴 구조 표**

| 그룹 | 메뉴 | 경로 | 권한 |
|------|------|------|------|
| 영상 | 영상 목록 | `/video/completed` | REVIEWER · WORKER |
| 영상 | 처리 현황 | `/video/status` | REVIEWER · WORKER |
| 작업 관리 | 작업 목록 | `/task` | REVIEWER · WORKER(본인) |
| 작업 관리 | 작업 배정 | `/task/assign` | REVIEWER |
| 라벨링 | 라벨링 도구 | `/label/:id` | REVIEWER · WORKER · PORTAL_USER(제한) |
| 검수 | 검수 대기 | `/review` | REVIEWER |
| 통계 | 전체 구축 현황 | `/stat/overall` | REVIEWER |
| 데이터 | 데이터 증강 | `/augment` | REVIEWER |
| 데이터 | 내보내기 | `/export` | REVIEWER |
| — | 관리 | `/manage/*` | REVIEWER |

## 4. 화면 설계

### 4-1. 세션 인계 · 진입

저작도구는 자체 로그인 화면을 제공하지 않는다. 관제서버 또는 포털 서버가 발급한 JWT 토큰을 URL 파라미터 또는 쿠키로 수신하여 사용자를 식별하고 **영상 목록**(메인 진입점, `/video/completed`)으로 이동시킨다.

| 상황 | 처리 |
|------|------|
| 유효한 토큰 수신 | role 클레임 확인 → 메인 진입점으로 이동 |
| 토큰 없음·만료 | 상위 시스템(관제서버 또는 포털) 로그인 페이지로 리다이렉트 |
| 권한 없는 메뉴 접근 | 403 페이지 표시 + 메인 진입점 링크 안내 |

---

### 4-2. 영상 목록 (메인 진입점)

영상 목록은 메인 진입점이며, 경로는 `/video/completed`이다. 행 액션에 **✨ 배경영상 요청**이 포함되며 모든 영상에 노출된다 (REVIEWER 권한). 클릭 시 `BackgroundGenerateModal`이 열린다.

```
    ↓ 검수 제출
검수대기(REVIEW_PENDING)
    ↓ 검수자 접수
검수중(REVIEWING)
    ↓
  ┌── 승인 ──→ 완료(COMPLETED)
  └── 반려 ──→ 작업중(IN_PROGRESS) (재작업)
```
