## 1. 문서 개요

### 1.1 목적

본 문서는 학습데이터 저작도구의 사용자 인터페이스(UI) 및 사용자 경험(UX)에 대한 설계 기준을 정의한다. 화면 레이아웃, 컴포넌트 구성, 사용자 플로우, 상호작용 규칙을 명세하여 개발 단계에서의 구현 기준으로 활용한다.

### 1.2 범위

| 채널 | 대상 사용자 | 진입 방식 |
|------|-------------|-----------|
| 관제지원시스템 (내부) | 라벨링 작업자, 검수자, 시스템 관리자 | 관제서버 세션 인계 (JWT) |
| AI 영상학습 사용자 포털 (외부) | 데이터 기여자, 외부 AI 연구자 | 포털 서버 세션 인계 (JWT) |

> **V1.1 변경**: 두 채널 모두 저작도구 자체 로그인 화면 없음. 상위 시스템(관제서버 / 포털 서버)에서 발급한 JWT 토큰을 인계받아 진입. 세션 만료 시 각 상위 시스템 로그인 페이지로 리다이렉트.

### 1.3 관련 SFR

| SFR | 기능명 |
|-----|--------|
| SFR-03 | 오토라벨링 결과 확인 |
| SFR-06 | 배경영상 생성 |
| SFR-07 | 데이터 증강 |
| SFR-08 | 저작도구 핵심 기능 |
| SFR-09 | 비식별화 결과 확인 |
| SFR-11 | VLM · 시계열 메타데이터 |
| SFR-13 | 데이터마트 · 검색 · 다운로드 |

## 4. 화면 설계

### 4-1. 세션 인계 · 진입

저작도구는 자체 로그인 화면을 제공하지 않는다. 관제서버 또는 포털 서버가 발급한 JWT 토큰을 URL 파라미터 또는 쿠키로 수신하여 사용자를 식별하고 배치 완료 영상 목록(메인 진입점)으로 이동시킨다.

| 상황 | 처리 |
|------|------|
| 유효한 토큰 수신 | role 클레임 확인 → 메인 진입점으로 이동 |
| 토큰 없음·만료 | 상위 시스템(관제서버 또는 포털) 로그인 페이지로 리다이렉트 |
| 권한 없는 메뉴 접근 | 403 페이지 표시 + 메인 진입점 링크 안내 |

## 5. 사용자 플로우

### 5.1 내부 사용자 — 전체 플로우 (V1.1)

```
[관제서버 세션 인계]
     ↓
[배치 완료 영상 목록 (메인 진입점)]
     │
     ├── 검수자: 영상 선택 → 작업자 배정 (기한·우선순위)
     │
     └── 작업자: 배정된 영상 선택 → 라벨링 도구 진입
                │
                ├── 오토라벨링 결과 확인 (신뢰도별 필터링)
                ├── 수동 라벨 수정·추가·삭제
                ├── 시계열 메타데이터 검토·수정
                ├── 비식별화 결과 확인
                └── 저장 → Gitea 자동 커밋
                          ↓
              [검수 제출]
                ↓
[검수자: 라벨 검수]
  ├── 승인 → 데이터셋 포함 확정
  └── 반려 → 작업자 재작업 → 재제출
                ↓ (승인 후)
[데이터 증강 (선택)] → [내보내기 → NAS + 데이터마트 등록]
```

### 5.2 외부 사용자 — 포탈 플로우 (V1.1)

```
[포털 서버 세션 인계]
     ↓
[포탈 메인 (업로드→라벨링→다운로드)]
     ↓
[이미지/영상 업로드]
     ↓
[간편 라벨링 + 오토라벨링 (YOLO + SAM2)]
     ↓
[본인 업로드 데이터 기간 내 다운로드]
     ※ 데이터마트 접근 불가, 기여도 없음
```

### 5.3 검수 승인/반려 상태 전이

```
배치완료(BATCH_COMPLETED)
    ↓ 검수자 배정
대기(PENDING)
    ↓ 작업자 작업 시작
작업중(IN_PROGRESS)
    ↓ 검수 제출
검수대기(REVIEW_PENDING)
    ↓ 검수자 접수
검수중(REVIEWING)
    ↓
  ┌── 승인 ──→ 완료(COMPLETED)
  └── 반려 ──→ 작업중(IN_PROGRESS) (재작업)
```
