## 2. 변경 배경

V1.x에서는 비식별 처리를 "내보내기 옵션"으로 운영했으나, 발주처 시연 검토 결과 다음 사유로 **자동 파이프라인의 무조건 단계**로 환원하기로 결정.

1. 비식별이 옵션이면 검수자가 옵션을 끄고 내보낼 위험 존재 → 무조건화로 정책 통일
2. 라벨러가 자기 작업 단계에서 개인정보 노출 여부를 직접 확인하고 거부할 수 있어야 함 → 라벨링 대상을 비식별 영상으로 통일
3. 원본 학습 데이터(원본 색채/디테일)와 비식별 학습 데이터 두 형태를 외부 시스템에 모두 제공해야 한다는 요구가 추가됨 → 영상·메타 2벌 상시 보관
4. 데이터 내보내기는 저작도구 사용자가 직접 트리거할 일이 없음(외부 데이터마트·학습 시스템이 API로 가져감) → 저작도구 내 내보내기 화면·메뉴 제거, 외부 API만 유지

## 4. CLAUDE.md (프로젝트 루트) 변경 내역

### 4.1 "주요 도메인" 줄 — 내보내기 범위 표현 조정

**변경 사유**: 내보내기 화면·메뉴 제거. 외부 API만 유지.

**변경 후**: "내보내기" 항목은 "**외부 API 제공**(학습데이터 JSON — 원본·비식별 분리, merge 옵션)"으로 재기술. 사용자 화면/메뉴로서의 내보내기는 제거.

### 4.2 "배치 파이프라인 (인증 불필요)" 단락 — 파이프라인 순서·비식별 정책 갱신

**변경 사유**: V2 정책 #1, #2, #3.

**변경 후**:
- 파이프라인 단계: `VLM → DEIDENTIFY → FRAME_EXTRACT(2벌) → YOLO → SAM2`
- 비식별은 **영상 단위**로 무조건 호출 (PRVC_TYPE_CD 무관 — ANONY 포함). 단, 외부 비식별 서버가 ANONY인 경우 내부적으로 noop 응답을 줄 수 있음 (저작도구 호출은 무조건)
- 원본 영상과 비식별 영상은 **각각 별도 NAS 경로에 영구 보관** (`STORAGE_RAW_PATH` / `STORAGE_DEIDENTIFIED_PATH`)
- FRAME_EXTRACT는 **원본 영상·비식별 영상 둘 다**에서 수행 (프레임도 2벌 보관). FFmpeg 처리 시간이 짧으므로 양쪽 모두 추출
- YOLO/SAM2 오토라벨링은 **원본 프레임**을 입력으로 사용 (좌표 정확도 보장)
- 라벨링 메타 JSON은 원본·비식별 2종 분리 저장 + 라벨링 좌표는 1벌 (원본 기준, 비식별 영상에도 동일 적용 — 객체 위치는 동일)

### 4.3 새 단락 — 라벨러 비식별 누락 신고 워크플로우

**변경 사유**: V2 정책 #5.

**추가 내용**: 라벨러가 비식별 영상에서 개인정보 잔존 발견 시 [비식별 누락 신고] 클릭 → 영상 상태가 `DEIDENTIFY` 단계로 되돌아가고 비식별 재시도 큐에 적재됨. 재시도 완료까지 라벨러 작업은 잠금되며, 재시도 성공 후 라벨러에게 자동 알림 + 작업 재개 가능.

**변경 사유**: V2 정책 #4, #5.

**추가 내용**:
- 라벨러는 **비식별 영상** 기준으로 라벨링·검수
- 비식별 영상에서 개인정보(얼굴·번호판 등) 잔존 발견 시 라벨러는 [비식별 누락 신고] 버튼으로 신고
- 신고 시 동작:
  1. 해당 영상의 자동 처리 단계가 `DEIDENTIFY`로 자동 되돌림
  2. 비식별 재시도 큐에 적재 (외부 비식별 서버 재호출 잡)
  3. 라벨러의 현재 작업은 **잠금**(LOCKED) 상태로 전환되어 편집 차단
  4. 재시도 성공 시 라벨러에게 알림 + 잠금 해제, 라벨러는 갱신된 비식별 영상으로 작업 재개
  5. 재시도 실패 시 검수자에게 알림 + 검수자 화면에서 별도 조치(다른 비식별 도구 적용 또는 영상 폐기)

### 5.5 §4.4.6 학습데이터 내보내기 → "외부 시스템 학습데이터 제공 API"로 변경

**추가 컬럼**:
- `RAW_VIDEO_PATH` — 원본 영상 NAS 경로 (NOT NULL)
- `DEIDENT_VIDEO_PATH` — 비식별 영상 NAS 경로 (DEIDENTIFY 단계 완료 후 채워짐)
- `RAW_META_JSON_PATH` — 원본 메타 JSON 경로
- `DEIDENT_META_JSON_PATH` — 비식별 메타 JSON 경로 (라벨링 좌표 1벌은 별도 또는 두 메타에 동일 참조)
- `DE_IDNTF_YN` — 비식별 완료 여부 (Y/N)
- `DE_IDNTF_DT` — 비식별 최종 완료 일시
- `DE_IDNTF_RETRY_CNT` — 비식별 재시도 횟수 (라벨러 신고로 인한 재시도 포함)
- `DE_IDNTF_LAST_FAIL_REASON` — 직전 비식별 실패 사유
- 기존 V1.x의 `EXPORT_STATUS_CD / LAST_EXPORTED_AT / LAST_EXPORT_FAIL_REASON` 컬럼은 외부 API 호출 로그로 의미 이관 — 영상 메타에서는 제거 검토

### 6.4 §7 mock 필드 ↔ DB 매핑
