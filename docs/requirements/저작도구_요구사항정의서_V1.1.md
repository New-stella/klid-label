## 1. 문서 개요

### 1.1 목적

본 문서는 "AI 기반 지방정부 CCTV 관제지원시스템 구축(2차)" 사업 중 학습데이터 저작도구 모듈의 기능 요구사항, 개발 범위, 일정을 체계적으로 정의한다. 제안요청서(SFR)에 명시된 기능 요구사항과 WBS 상세 태스크를 기반으로 작성되었으며, 설계·개발·테스트 전 단계에서 기준 문서로 활용된다.

**V1.1 주요 변경 배경**: 내부 시나리오 협의 결과, 저작도구는 독립적인 로그인 체계를 갖추지 않고 관제서버의 세션을 인계받아 동작하는 통합 채널로 확정되었다. 영상 유입 및 전처리(프레임 추출 + 오토라벨링)는 관제서버 배치 파이프라인이 담당하며, 저작도구는 배치 처리가 완료된 영상 목록에서 시작하는 구조로 변경된다.

### 1.2 적용 범위

- 관제지원시스템 내 학습데이터 저작도구 기능 고도화
- AI 영상학습 사용자 포털의 저작도구 외부 서비스 연동
- 저작도구와 직·간접으로 연관된 SFR 11개 + QUR-03 전 기능

### 2.2 저작도구 위치 및 역할

저작도구는 추진전략 "다. AI CCTV 관제지원시스템 및 저작도구 기능 고도화"의 핵심 구성요소로, 시계열 메타데이터 생성·관리, 라벨링 정확도 향상, 학습데이터 버전 관리, 데이터마트 연계를 담당한다.

**V1.1 변경**: 저작도구는 관제지원시스템(내부 채널)과 사용자 포털(외부 채널) 두 채널로 제공된다. **두 채널 모두 별도 로그인 화면을 갖지 않으며, 각 채널의 상위 시스템(관제서버 / 포털 서버)으로부터 세션을 인계받아 진입한다.** 내부 채널은 관제서버가 완료한 배치 처리 결과(프레임 추출 + 오토라벨링)를 수신하여 검수·가공 작업을 수행한다.

### 2.3 전체 시스템 구조 (V1.1)

```
[지자체 CCTV]
      ↓ 영상 수신
[관제서버]
  ① 라벨링 필요 여부 판별
  ② 라벨링 대상 영상 목록 → 저작도구에 전달

          ↓ (세션 없이 서버 자동 실행)

[저작도구 — 배치 파이프라인 (백그라운드)]
  ③ 라벨링 대상 영상 배치 처리 (1건/분, 인증 불필요)
      └ FFmpeg 프레임 추출 (1프레임/분)
      └ YOLO + SAM2 오토라벨링 자동 수행
      └ VLM 시계열 메타데이터 자동 생성

          ↓ (사용자 진입 시 세션 인계 — JWT)

[저작도구 — 사용자 화면]
  ④ 배치 완료 영상 목록 진입점 제공
  ⑤ 검수자 → 작업자 배정
  ⑥ 작업자 라벨 정밀 검수·수정
  ⑦ 검수자 최종 승인
  ⑧ 비식별화 처리 → 증강 → 내보내기 → 데이터마트

[포털 서버]
      ↓ 세션 인계 (JWT / SSO)
[저작도구 — 외부 채널 (포털 진입 모드)]
  ① 포털 서버 세션으로 사용자 식별 (회원가입·로그인 없음)
  ② 간편 라벨링 도구 (기능 제한 적용)
  ③ 기여도 기반 다운로드 권한 관리
```

### 2.4 역할 정의 (V1.1)

| 역할 | 코드 | 주요 권한 | V1.1 변경 |
|------|------|-----------|-----------|
| 시스템 관리자 | ADMIN | 전체 관리, 사용자 관리, 시스템 설정 | 작업 배정 권한 제거 |
| 검수자 | REVIEWER | **작업자 배정**, 검수 승인/반려 | **배정 권한 추가** |
| 라벨링 작업자 | WORKER | 라벨 수정·검수 제출 | 변경 없음 |
| 포털 회원 | PORTAL_USER | 이미지/영상 업로드, 간편 라벨링 체험, 본인 데이터 기간 내 다운로드 | 데이터마트 접근 없음, 기여도 점수 없음 |

## 4. 상세 요구사항

### 4.1 SFR-03 | 시계열 메타데이터 생성 및 관리

**정의**: 영상 및 이미지 내 속성 변화를 반영한 시계열 메타데이터 생성·관리

**세부 요구사항**

① 시계열 메타데이터 생성 및 수정 기능 제공
- 연속 프레임 간 객체 상태 변화, 위치 이동, 속성 변화를 분석
- 클립영상 프레임과 연계할 수 있는 시계열 메타데이터 생성·수정 기능 구현

② VLM 기반 영상 메타정보 자동 추출
- VLM 기술로 프레임 단위 자연어 설명, 객체 및 행동 인식 결과, 시간·장소·환경조건 자동 분석
- 정의된 항목에 대해 메타데이터를 자동 생성하는 기능 구현
- 생성된 메타데이터는 JSON 파일 형태로 저장되어 학습데이터로 활용

> **V1.1 변경**: VLM 메타데이터 자동 추출은 관제서버 배치 파이프라인에서 오토라벨링과 함께 자동 수행된다. 저작도구에서는 배치 생성된 메타데이터를 검토·수정하는 기능을 제공한다.

**산출물**: 서비스/기능 아키텍처 구성도, 공정 산출물, 추진계획서, 결과서

### 4.4 SFR-08 | 학습데이터 저작도구 고도화 기능 구현 [핵심 · V1.1 대폭 변경]

**정의**: 학습데이터 제작 편의성 및 효율성 증대를 위한 저작도구 추가기능 개발

#### 4.4.1 인증 및 진입 방식 (V1.1 신규 — 내부·외부 채널 공통)

> **변경 전 (V1.0)**: 내부 채널 — GPKI 로그인, 외부 채널(포털) — 이메일/SMS 자체 회원가입·로그인  
> **변경 후 (V1.1)**: 두 채널 모두 별도 로그인·회원가입 없음 — 단일 세션 체계(공통 JWT 발급 서버)를 통해 관제서버 및 포털 서버가 발급한 토큰을 저작도구가 인계받아 진입

**세션 체계**
- 관제서버(내부)와 포털 서버(외부) 모두 **동일한 JWT 발급 서버** 사용
- 저작도구는 채널 구분 없이 단일 토큰 검증 로직으로 처리
- 토큰 내 역할(role) 클레임으로 내부/외부 채널 및 권한 분기

**DB 연동 체계**
- 내부 채널(관제서버 연동): 저작도구는 **관제서버 DB를 공유** 사용
- 외부 채널(포털 연동): 저작도구는 **포털 DB를 공유** 사용
- 저작도구 전용 독립 DB 인스턴스 없음
- 저작도구 관련 테이블은 각 DB 내 별도 스키마(예: `authoring`)로 구분 관리

**내부 채널 (관제지원시스템)**
- 관제서버 세션 토큰을 수신하여 사용자 인증 처리
- 세션 만료 시 관제서버 로그인 페이지로 리다이렉트

**외부 채널 (포털 진입 모드)**
- 포털 서버 세션 토큰을 수신하여 외부 사용자 식별
- 저작도구 내 회원가입·로그인 UI 미제공
- 세션 만료 시 포털 서버 로그인 페이지로 리다이렉트
- 기여도, 일일 사용량 등 사용자 권한 정보는 포털 서버로부터 수신

#### 4.4.2 영상 유입 및 전처리 (V1.1 대폭 변경)

> **변경 전 (V1.0)**: 저작도구에서 직접 영상 업로드 → 메타데이터 입력 → FFmpeg 프레임 추출 수동 설정  
> **변경 후 (V1.1)**: 관제서버는 라벨링 대상 판별까지 담당, 배치 처리(프레임 추출 + 오토라벨링)는 저작도구가 수행

**관제서버 담당 (저작도구 외부)**
- 지자체 CCTV로부터 영상 수신
- 라벨링 필요 여부 자동 판별
- 라벨링 대상 영상 목록을 저작도구에 전달

**저작도구 담당**

*배치 파이프라인 (백그라운드 서버 프로세스 — 세션·인증 불필요)*
- 관제서버로부터 수신한 라벨링 대상 영상을 자동 처리: **1건/분**
  - FFmpeg 프레임 추출 (1프레임/분)
  - 비식별화 처리 (조건부): 영상 메타정보의 개인정보 유형이 **익명정보가 아닌 경우에만** 비식별 서버 API 호출
    - 원본 이미지와 비식별 처리 이미지를 **동시에 저장** (별도 경로)
    - 익명정보로 분류된 영상은 비식별 서버 호출 없이 원본만 저장
  - YOLO 기반 오토라벨링 자동 수행
  - SAM2 세그멘테이션 자동 수행

### 5.1 내부 채널 (관제지원시스템) — 변경 시나리오

```
[관제서버]
  │  ① CCTV 영상 수신
  │  ② 라벨링 필요 여부 판별
  │  ③ 라벨링 대상 영상 목록 → 저작도구에 전달
  ↓
[저작도구 — 배치 파이프라인] ← 세션 없이 서버 자동 실행
  │  ④ 라벨링 대상 영상 배치 처리 (1건/분, 인증 불필요)
  │      └ FFmpeg 프레임 추출 (1프레임/분)
  │      └ YOLO + SAM2 오토라벨링 자동 수행
  │      └ VLM 시계열 메타데이터 자동 생성
  ↓
  [세션 인계 (JWT/SSO)] ← 사용자가 화면 진입 시
  ↓
[저작도구 — 사용자 화면]
  │  ⑤ 배치 완료 영상 목록 진입점 제공
  │
  ├── 검수자: 영상 선택 → 작업자 배정 (기한·우선순위 설정)
  │
  └── 작업자: 배정된 영상 선택 → 라벨링 도구 진입
                │
                ├── 오토라벨링 결과 검토 (관제서버 배치 결과 확인)
                ├── 라벨 수정·추가·삭제
                ├── 시계열 메타데이터 검토·수정
                ├── 비식별화 처리 확인
                └── 저장 → Gitea 자동 커밋 (버전 생성)
                          ↓
              [검수 제출]
                ↓
[검수자: 라벨 검수]
  ├── 승인 → 데이터셋 포함 확정
  └── 반려 → 작업자 재작업 → 재제출
                ↓ (승인 후)
[데이터 증강 (선택)]
  ↓
[내보내기 → NAS 저장 + 데이터마트 등록]
```

  ↓

  ↓
