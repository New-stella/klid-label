## 1. 화면 구성 원칙

저작도구는 내부 업무 화면과 포털 화면을 분리한다.

| 채널 | 사용자 | 화면 구조 |
|------|--------|-----------|
| 내부 | 검수자, 작업자 | GNB, LNB, 업무 본문 |
| 포털 | 포털 회원 | 포털 전용 상단 메뉴, 간편 화면 |

내부 화면은 영상 처리, 작업 배정, 라벨링, 검수, 통계, 관리 기능을 제공한다. 포털 화면은 업로드와 간편 라벨링만 제공한다.

## 4. 배치 처리 현황 화면

배치 처리 현황은 다음 단계를 순서대로 표시한다.

| 순서 | 단계 | 표시 문구 |
|------|------|-----------|
| 1 | VLM | 메타 처리 |
| 2 | DEIDENTIFY | 비식별 영상 생성 |
| 3 | FRAME_EXTRACT | 프레임 추출 |
| 4 | YOLO | 객체 자동 탐지 |
| 5 | SAM2 | 세그멘테이션 |
| 6 | INTERPOLATE | 트랙 보간 |
| 7 | COMPLETED | 처리 완료 |

비식별 단계는 영상 단위 처리로 표시한다. “비식별 프레임 생성”이라는 표현은 사용하지 않는다.

## 5. 라벨링 화면

### 5.1 작업자 화면

작업자는 비식별 프레임을 기준으로 라벨을 수정한다. 원본 보기 기능은 제공하지 않는다.

주요 요소:

| 요소 | 설명 |
|------|------|
| 캔버스 | 비식별 프레임 표시 |
| 도구바 | 선택, 이동, bbox, polygon, segmentation |
| 객체 목록 | 프레임 내 객체 목록 |
| 클래스/속성 패널 | 라벨 클래스와 속성 수정 |
| 저장 | 라벨 저장 |
| 검수 제출 | 작업 완료 후 제출 |
| 비식별 누락 신고 | 개인정보 잔존 신고 |

비식별 누락 신고 후에는 저장과 검수 제출을 비활성화하고 재비식별 진행 상태를 표시한다.

### 5.2 검수자 화면

검수자는 기본적으로 비식별 프레임을 확인한다. 필요한 경우 원본 보기 토글로 RAW 프레임을 확인할 수 있다.

주요 요소:

| 요소 | 설명 |
|------|------|
| RAW/DEID 전환 | 원본/비식별 프레임 확인 |
| 이슈 목록 | 반려 사유와 검수 의견 |
| 승인 | 검수 승인 처리 |
| 반려 | 사유 입력 후 반려 |
| 이력 | 저장 시점별 라벨 데이터 확인 |
| 롤백 | 선택한 저장 시점으로 라벨 복원 |

---

## 6. 검수 화면

검수 화면은 프레임 목록, 라벨 캔버스, 객체 목록, 이슈 입력, 승인/반려 액션으로 구성한다.

반려 시 검수자는 사유를 입력해야 한다. 반려 사유는 작업자가 재작업할 때 확인할 수 있어야 한다.

---

## 7. 저장 이력과 롤백 화면

저장 이력 화면은 라벨 저장 시점을 목록으로 제공한다.

| 기능 | 설명 |
|------|------|
| 이력 목록 | 저장 시각, 사용자, commit 정보 표시 |
| diff | 저장 시점 간 라벨 변경 확인 |
| 롤백 | 선택한 저장 시점의 라벨 데이터로 현재 라벨 복원 |

롤백 실행 전 확인 모달을 표시한다. 모달에는 현재 라벨 데이터가 선택한 저장 시점의 데이터로 변경된다는 내용을 명확히 안내한다.

---

## 8. 포털 화면

포털 화면은 내부 업무 기능을 제공하지 않는다.

| 화면 | 기능 |
|------|------|
| 포털 홈 | 업로드, 업로드 목록, 오토라벨링 체험 |
| 포털 간편 라벨링 | 본인 업로드 데이터 라벨 확인/수정 |

포털 화면에는 검수, 롤백, 전체 통계, 사용자 관리, 다운로드 기능을 제공하지 않는다.

---

## 9. 제공하지 않는 화면

| 화면 | 처리 |
|------|------|
| 내보내기 화면 | 제공하지 않음 |
| 외부 학습데이터 API 화면 | 제공하지 않음 |
| 데이터마트 화면 | 저작도구 범위 밖 |
| 포털 다운로드 화면 | 포털 자체 책임 |
| 관리자 전용 화면 | 검수자 권한으로 통합 |

---

## 10. 증강 결과 화면

증강 결과 화면은 원본 데이터와 증강 결과를 비교하고, 라벨이 적절하게 유지되었는지 확인할 수 있어야 한다.

| 항목 | 표시 기준 |
|------|-----------|
| 일반 증강 | 원본 라벨 좌표를 동일하게 표시 |
| 해상도 변경 증강 | 낮아진 해상도에 맞춰 재계산된 좌표를 표시 |
| 라벨 무결성 | 증강 전후 라벨 유지 상태와 무결성 점수 표시 |
| 결정 액션 | 채택 또는 반려 |

해상도 변경 증강 결과는 좌표 재계산이 필요한 데이터임을 화면에서 구분해 표시한다.
