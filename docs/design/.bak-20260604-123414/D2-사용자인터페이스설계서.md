# D2 사용자 인터페이스 설계서

> **ID 표기 규칙(공통)**: 본 산출물의 모든 ID(KLID-AT-SC/CO/NAV/UC 등)는 **전체 형식 `KLID-AT-XX-NNN`** 으로 표기한다. 끝부분만(예: `SC-001`) 약식 표기 금지. 범위는 시작 ID만 전체형으로(예: `KLID-AT-CO-001~041`). ※ LogiCraft 원본 ID(SCREEN/UI/NAV/API/UC)와 RQ-SFR-NN-NN(요구사항) 등 타 체계 ID는 각 체계 원형을 유지한다. 본 문서는 LogiCraft 그래프(`screen_spec`·`ui_component`·`navigation_tree`)에서 자동 생성되었으며, KLID-AT 산출물 ID와 LogiCraft 원본 ID를 병기한다.

## 작성 목적
> 시스템이 제공하는 사용자 인터페이스의 전체 구조와 메뉴 형식, 화면 목록과 화면의 상세 설계 내역을 기술한다.
> 본 산출물은 LogiCraft 모델에 등록된 R1 활성 화면(`screen_spec` 26종)·UI 컴포넌트(`ui_component` 96종)·메뉴 트리(`navigation_tree` 2종)를 대상으로 한다. dev/deprecated(비식별 목록·상세, 포털 홈) 화면은 모델에서 retired 처리되어 제외된다.

## 작성 방법
> 전체 시스템에 대한 사용자 인터페이스의 구조를 사용자에게 제공하는 메뉴 형식으로 기술하고, 화면 및 출력으로 구분하여 목록을 작성하며, 화면의 상세 설계의 내용을 화면별로 기술한다. 컴포넌트 명세는 공통/레이아웃/내비게이션/차트·데이터/폼·피드백/화면별 구성으로 분류하여 기술한다.

## 1. 사용자 인터페이스 구조도

> 전체 시스템에 대하여 1개 작성한다. 저작도구는 독립 로그인 UI 없이 관제서버(내부)/포털(외부)이 발급한 JWT를 인계받아 진입한다. INTERNAL 채널은 좌측 LNB(`대시보드 / 영상 / 작업 / 검수 / 데이터 / 통계 / 관리`) 기반이며, PORTAL 채널은 LNB 없는 반응형 레이아웃이다. LNB에 메뉴로 노출되지 않지만 라우트로 도달하는 화면(마킹·영상 상세·라벨링 캔버스·라벨 이력·오토라벨 요약·VLM 메타 검토·증강 결과·검수 상세)은 진입 맥락 노드로 보조 포함한다. (출처: LogiCraft `NAV-001`/`NAV-002`)

## 부록 C. 자동 생성 메모 (빈 셀·후속 보완)

- **realizes_use_cases / covered_by_acceptances**: 전 26개 `screen_spec`에서 비어 있음 → 부록 B로 대체, R2/R3 정본 참조.
- **required_roles(ITEM 필드)**: 전 화면에서 빈 배열 → 본 문서 권한은 `purpose` 문구 및 NAV-001/002 `required_role`(ROLE-001=REVIEWER, ROLE-003=PORTAL_USER) 노드에서 도출.
- **출력물 ITEM 타입 부재**: 모델에 출력물 전용 타입이 없어 §2.2는 화면의 다운로드/통지 동작에서 도출(KLID-AT-OUT-NNN 자체 부여).
- **컴포넌트 props_schema/variants**: 본 문서는 ui_component의 name·category·screen 매핑을 기준으로 카탈로그를 구성했고, 개별 props 스키마는 D3 컴포넌트설계서를 정본으로 한다.
- **retired 화면 제외**: SCREEN-016/017(비식별 목록·상세, 외부 솔루션 이관)·SCREEN-028(포털 홈, ADR-013)은 retired로 제외(번호 결번).
- **포털 시계열 메타 패널 불일치**: KLID-AT-SC-029의 TimeseriesSidePanel은 포털 미노출 의도와 코드(portalMode 분기 없음)가 불일치 — 모델 change_summary에 기록됨, 구현 정합 후속 필요.
- **NAV-002 포털 홈**: 활성 SCREEN 미정(데이터마트 목록 홈 대체 후속 필요).
