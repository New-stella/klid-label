|-----------|---------|------|:------:|-----------|------|---------|------|
| NFR-001 | 배치 파이프라인 처리량 | 성능(performance) | must | 비식별→마킹(비식별 영상)→VLM→FFmpeg(마킹위치 프레임추출)→YOLO/SAM2→트랙보간 배치 파이프라인은 Quartz 단일 인스턴스(PostgreSQL JobStore, 클러스터 미적용)에서 처리한다 (설계 타깃 순서 — 비식별 선두 재배치) | 배치 파이프라인 처리율 ≥ 1건/분 | Micrometer Timer/Counter로 배치 1건 처리 소요시간·처리 건수 수집, Prometheus 집계 | CLAUDE.md 배치 성능(Quartz 1건/분, ai-server만 수평 확장) |

## 항목 설명

- **요구사항 ID**: 요구사항별 유일 ID. 본 문서는 「요구사항정의서.pdf」 원본 ID(`RQ-SFR-NN-NN`)를 그대로 사용한다.
- **RFP ID**: 제안요청서(RFP) 상의 상위 기능 분류 ID(`SFR-06` 등).
- **요구사항명**: 도출된 요구사항을 요약하는 명칭.
- **구분**: 요구사항 분류. 본 표는 기능 요구사항(SFR)만 포함한다.
- **요구사항 설명**: 사용자 요구사항을 구체적·상세하게 기술.
- **요구사항 출처**: 요구사항이 제시된 문서번호·문서명(제안요청서 페이지).
- **제약사항**: 요구사항 수행에 필요한 법적/기술적 조건(예: 외부 솔루션 발주기관 제공, DFEAT 추적 ID).
- **중요도**: 전체 시스템 구현 측면 중요도(상/중/하). 저작도구 핵심(라벨링·버전관리·비식별)은 '상', 외부 시스템 책임(생성형 본체)은 '하'로 분류.
- **해결방안**: 저작도구(AT) 관점의 구체적 해결방안(CLAUDE.md 아키텍처 근거).
- **검수 기준**: 구현 품질을 측정할 수 있는 정량/정성 기준.
- **비고**: 작성자/검토자 등 고려 사항.

## 작성 시 참고사항

> - **ID 체계**: 본 문서는 RFP 원본 ID(`RQ-SFR-NN-NN`)를 유지하며, RFP 분류는 `RFP ID` 컬럼에 병기한다.
> - **범위 정합(CLAUDE.md 기준)**: SFR-06(생성형 AI 본체) 및 SFR-07 증강 본체는 외부 생성 시스템 책임이며, 저작도구는 ① 외부 증강 연동 ② 증강 결과 검수 ③ 외부 VLM 시계열 호출 연동을 보유한다. 단, RQ-SFR-06-03의 해상도 변경은 저작도구가 직접 수행한다. 본체 미구현 항목은 해결방안/비고에 명시.
> - **비기능 요구사항(NFR)**: 「본문 — 비기능 요구사항(NFR)」 표에 LogiCraft NFR-001~007 기준으로 등재했다. PDF 비기능 ID 체계(ECR/PER/SIR/TER/QUR/PSR/DAR/PMR/SER/COR)와의 매핑은 추후 보완 예정이다.
