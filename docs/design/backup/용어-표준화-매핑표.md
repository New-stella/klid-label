# KLID-저작도구 용어 표준화 매핑표

- 생성일: 2026-05-30
- 대상: LogiCraft 사업 용어사전 `KLID-저작도구` (project_id 4ece2c3f-8e99-46f5-9580-71108a76e578, program db8083f7-…)
- 수집 총 용어 수: **661건** (빈 쿼리 200건 스냅샷 + 음절 프로빙 461건 병합·중복제거)
- 분류별 카운트: **KEEP 596 / REPLACE 0 / FIX 6 / CUSTOM 59**

> ⚠ **수집 범위·검증 한계**
> - 빈 쿼리(limit=200)가 정확히 200건을 반환(=cap)하여, 전체 용어를 한 번에 받을 수 없었다. 가장 빈도 높은 접미(영상·사용자·코드·일시·여부·아이디·유형·번호·명·건수·전송·시간·경로·작업·기관·설명·처리·상태·이벤트·CCTV)로 음절 프로빙하여 **661건**을 확보했으나, 프로빙하지 않은 음절의 용어가 추가로 존재할 수 있어 **전수는 아니다**(ID 범위 473~1373 기준 전체는 더 많을 가능성).
> - P1 gov 정확일치 대조는 핵심 의심 행(수정일자·수정일시·우선순위)만 `gov_term_search`로 실시간 확인했다. 나머지 KEEP/CUSTOM 행은 각 용어의 description·source에 이미 기재된 gov 단어ID·합성출처·gov 도메인 매핑을 근거로 판정했고, 실시간 gov 대조가 더 필요한 행은 비고에 ⚠확인필요로 표기했다.
> - 작업 중 LogiCraft MCP 서버가 간헐적 outage 상태였다.

## 우선순위 규칙 요약
- **P1 gov 공통표준용어 정확일치** → 그 term_en_abbr 가 표준 (예: 수정일자=MDFCN_YMD, 수정일시=MDFCN_DT, 우선순위=PRRTY_RNK)
- **P2 gov/사업 단어 조합** → 의미단어를 gov_word(우선)/program_word 약어로 `_` 합성. 형식단어: 코드=CD·일시=DT·일자=YMD·여부=YN·수=CNT·건수=NOCS·명=NM·번호=NO
- **P3 사업 도메인 매핑** → P4 gov 표준 부재 시 사업 자체용어 유지
- 분류: KEEP(현재=표준) / REPLACE(gov·사업 표준이 현재와 다름) / FIX(명백한 오매핑·버그) / CUSTOM(gov 표준 없음·사업용어 유지)
