## FEAT-001 AI 보조 라벨링 (객체 추적·외곽 경계 밀착)

- **사용자 스토리**: 라벨링 작업자로서, 내가 지정한 객체를 AI가 자동으로 추적하고 외곽 경계를 자동으로 맞춰 주기를 원한다. 그래야 수작업 라벨링 시간을 줄이고 경계 정확도를 높일 수 있다.
- **설명**: 사용자가 지정한 객체를 AI가 이어지는 프레임에서 자동 추적하고, 객체 외곽 경계에 자동으로 밀착시켜 라벨링을 보조하는 기능. (사람 개입 없이 배치로 수행하는 오토라벨링과는 구분되는, 작업 과정의 AI 보조)
- **구현 요구사항**: RQ-SFR-08-01(객체 추적), 08-02(외곽 밀착)
- **주요 흐름**
  1. 작업자가 라벨링할 객체를 지정한다.
  2. AI가 이어지는 프레임에서 객체를 자동 추적해 위치·경계를 갱신한다.
  3. AI가 객체 외곽선을 경계에 자동으로 밀착시킨다.
  4. 작업자가 결과를 확인·보정한다.
  5. 라벨을 확정해 저장한다.

## FEAT-002 라벨 버전관리·비교·복구

- **사용자 스토리**: 작업자·검수자로서, 라벨 변경 이력을 남기고 이전 버전과 비교·복구하기를 원한다. 그래야 실수를 되돌리고 변경 내용을 추적할 수 있다.
- **설명**: 라벨을 저장할 때마다 버전을 기록해 변경이력을 추적하고, 버전 간 차이를 비교하며, 필요 시 이전 버전으로 되돌리는 기능.
- **구현 요구사항**: RQ-SFR-08-04(버전관리·이력), 08-05(비교·복구)
- **주요 흐름**
  1. 라벨을 저장한다.
  2. 누가·언제·무엇을 바꿨는지 버전이 자동으로 기록된다.
  3. 버전 목록과 버전 간 차이를 조회한다.
  4. 필요하면 이전 버전으로 복구한다.
- **비즈니스 규칙**: 버전은 DB에 라벨 **전체 스냅샷**으로 보관한다(외부 VCS/Gitea 미사용). 같은 내용 재저장은 페이로드 해시로 동일 버전으로 식별하고, 비교·복구는 저장된 스냅샷 비교로 수행한다.

## FEAT-003 데이터마트 라벨 동기화 통지

- **사용자 스토리**: 시스템(관제 연동)으로서, 검수 완료 후 라벨이 수정되면 외부에 알리기를 원한다. 그래야 데이터마트가 최신 라벨로 유지된다.
- **설명**: 데이터마트 자체는 외부에서 관리한다. 검수가 끝난 영상의 라벨이 수정되면 '수정되었음'을 외부(관제)에 통지해, 외부가 최신 내용으로 다시 맞출 수 있게 한다.
- **구현 요구사항**: RQ-SFR-08-06(데이터마트 동기화)
- **주요 흐름**
  1. 검수 완료된 영상의 라벨 수정이 발생한다.
  2. 수정 내용을 영상 단위로 요약한다.
  3. 외부(관제)에 수정 통지를 발송한다.
  4. 외부가 최신 내용을 다시 조회해 반영한다.

## FEAT-004 영상 증강 연동·검수 + 해상도 변경

- **사용자 스토리**: 검수자로서, 외부에서 증강된 영상을 받아 라벨이 잘 보존됐는지 확인하고 학습데이터로 쓸지 결정하기를 원한다. 그래야 증강 데이터를 안전하게 학습데이터로 편입할 수 있다.
- **설명**: 외부 증강 시스템이 만든 새 영상을 원본과 연결해 수신하고, 원본 라벨을 복사해 무결성을 보존하며, 미검수 상태로 시작해 검수 승인/반려를 거친다. 이미지 해상도 변경은 저작도구가 직접 수행한다.
- **구현 요구사항**: RQ-SFR-06-03(해상도 변경), 07-01(자동 생성 수신), 07-02(라벨 무결성), 07-03(활용 여부 선택)
- **주요 흐름**
  1. 외부 증강 영상을 원본과 연결된 새 영상으로 수신·등록한다.
  2. 원본의 라벨 정보를 새 영상에 복사하고 좌표를 보존한다.
  3. 해상도 변경은 저작도구가 직접 수행한다.
  4. 새 영상은 미검수 상태로 들어온다.
  5. 검수자가 내용을 확인해 학습데이터 활용을 승인/반려한다.
- **비즈니스 규칙**: 증강 결과는 원본과 다른 새 영상으로 등록하며 원본을 참조한다. 프롬프트·생성 본체는 외부 시스템 책임으로 범위 외.

## FEAT-005 개인정보 비식별 처리 (연동·옵션 사용)

- **사용자 스토리**: 시스템·검수자로서, 외부 비식별 솔루션을 연동해 개인정보를 가리고, 솔루션이 제공하는 옵션을 화면에서 직접 설정·사용하기를 원한다. 그래야 개인정보를 안전하게 보호하면서 비식별 강도를 상황에 맞게 조절할 수 있다.
- **설명**: 발주기관이 제공하는 외부 비식별 솔루션을 연동(API·가이드)해 개인정보를 가린다. 단순 연동에 그치지 않고, **솔루션이 제공하는 옵션을 관리 화면에서 선택·설정·사용하는 기능과 화면**을 함께 제공한다. 비식별이 필요한 영상만 처리하며, 원본과 비식별본을 따로 보관한다.
- **구현 요구사항**: RQ-SFR-09-01(비식별 처리), 09-02(API·가이드 연동), 09-04(옵션 설정·사용)
- **주요 흐름**
  1. 비식별 대상 영상을 선별한다.
  2. 외부 비식별 솔루션을 연동 호출한다.
  3. 솔루션이 제공하는 옵션을 관리 화면에서 선택·적용한다.
  4. 비식별 처리를 수행한다.
  5. 원본과 비식별본을 분리해 저장한다.
- **비즈니스 규칙**: 비식별이 필요한 영상만 처리한다. 원본은 어떤 경우에도 삭제하지 않는다. 비식별 옵션은 관리 화면에서 설정한다.

## FEAT-006 비식별 결과 검토·이력 확인

- **사용자 스토리**: 검수자로서, 비식별 처리 결과와 이력을 확인하기를 원한다. 그래야 비식별이 적정하게 됐는지 검토하고 처리 내역을 추적할 수 있다.
- **설명**: 비식별 처리 결과·상태·리포트를 화면에서 확인하고, 영상 단위로 처리 이력을 기록·조회한다. 처리에 실패하면 다시 시도한다.
- **구현 요구사항**: RQ-SFR-09-03(결과 검토·이력), 09-05(결과 연동 확인)
- **주요 흐름**
  1. 비식별 처리가 완료되거나 실패한다.
  2. 처리 결과·상태·리포트를 화면에 표시한다.
  3. 영상 단위로 처리 이력을 기록한다.
  4. 실패한 경우 다시 시도한다.
  5. 검수자가 결과를 확인한다.

## FEAT-007 라벨링 정밀도 조절

- **사용자 스토리**: 라벨링 작업자로서, 라벨의 정밀도(인식 민감도·경계의 세밀함)를 직접 조절하기를 원한다. 그래야 상황에 맞게 라벨 정밀도를 맞춰 품질을 확보할 수 있다.
- **설명**: 라벨링 시 인식 민감도와 경계의 세밀함 등 정밀도를 사용자가 직접 조절할 수 있는 기능.
- **구현 요구사항**: RQ-SFR-08-03(정밀도 조절)
- **주요 흐름**
  1. 작업자가 정밀도 옵션을 연다.
  2. 인식 민감도·경계의 세밀함을 조절한다.
  3. 조절한 값이 라벨에 반영된다.
- **비즈니스 규칙**: 정밀도 옵션은 시스템 설정으로 관리한다.
