## 1. 사용자 인터페이스 구조도

> 전체 메뉴 트리 중 R1 요구사항(SFR-06~09)과 직접 관련된 화면 위주로 작성한다. 인증은 관제/포털 발급 JWT 인계 방식이며 독립 로그인 UI는 없다. 라벨링 캔버스는 LNB/GNB 밖 풀스크린 다크 UI로, 영상 상세·작업 목록·검수 화면에서 진입한다.

> INTERNAL 채널의 실제 좌측 메뉴(LNB)는 `대시보드 / 영상 / 작업 / 데이터 / 통계 / 관리` 그룹으로 구성된다. 아래 표는 그중 R1 요구사항(SFR-06~09)에 직접 매핑되는 진입 경로만 발췌한 것이며, 비식별화·버전관리·시계열메타·라벨링 캔버스는 별도 LNB 항목이 아니라 영상 상세·작업/검수 목록·라벨링 화면에서 컨텍스트로 진입한다(Level 1은 R1 업무 영역 기준 논리 분류).

### 1.1 INTERNAL 채널 (관제 — REVIEWER / WORKER)

| 업무 영역 (Level 1) | Level 2 (LNB/진입점) | Level 3 | Level 4 |
|-------------------|---------|---------|---------|
| 데이터 | 증강 요청 | 증강 결과 확인 | (증강 영상 활용 여부 검수) |
| 작업/라벨링 | (작업 목록·검수 목록 → 라벨링) | 라벨링 캔버스 (AI 추적·외곽 밀착·정밀도) | 버전 이력(인라인 패널) |
| 작업/라벨링 | (영상 상세 → 오토라벨 결과) | 시계열 메타 검토·수정 | — |
| 버전 관리 | (라벨링 → 버전 이력) | 버전 이력·비교·복구 | — |
| 비식별화 | (영상 상세 → 비식별화 결과) | 비식별화 결과 목록 | 비식별화 영상 비교(상세) |
| 관리 | 시스템 설정 | 라벨링 정밀도 / 비식별 옵션 | — |

### 1.2 PORTAL 채널 (포털 회원 — PORTAL_USER)

> 포털 채널은 본 R1 요구사항(SFR-06~09)에 직접 참여하는 유스케이스가 없어 구조도에는 참조용으로만 기재하며, 화면 상세 설계 대상에서는 제외한다.

> 포털은 데이터마트 영상 선택·기존 라벨 확인/수정/저장/다운로드 전용이며 오토라벨링·업로드(TUS)는 ADR-013으로 폐기됨(SCREEN-028 deprecated). 데이터마트 영상 목록 홈은 후속 미구현.

| 업무 영역 (Level 1) | Level 2 | Level 3 | Level 4 |
|-------------------|---------|---------|---------|
| 포털 | 홈(데이터마트 영상 선택 — 목록 홈은 후속 미구현) | 간편 라벨링 | — |
