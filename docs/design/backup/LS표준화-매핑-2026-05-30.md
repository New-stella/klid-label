# LS_* 컬럼 행안부 공통표준 정합 매핑 스펙

> 생성일: 2026-05-30
> 표준 출처: 행정안전부 공통표준용어/단어 **8차(2025-11)** — 도메인 123종 / 용어 13,176건 / 단어 3,284건 (LogiCraft `gov_glossary_stats` 기준)
> 조회 도구: `gov_term_search`(용어 완전/부분일치), `gov_word_search`(단어 단위 합성)
> 본 문서는 **분석·제안 스펙**이다. 코드/마이그레이션/ITEM 변경은 포함하지 않는다.

## 대상 범위

- **소스 1 — Flyway 마이그레이션**: `backend/src/main/resources/db/migration/*.sql` 의 `CREATE TABLE LS_*` (저작도구 소유 테이블만)
- **소스 2 — 배포 스키마 문서**: `docs/dev-db-schema-2026-04-23.md` (klid_system 배포본 — 컬럼 한글 설명의 기준어). 단, 이 배포본의 LS_* 는 **레거시 LS_PJT_* 설계**로 이미 표준약어를 따르며, 실제 저작도구가 V35에서 LS_PJT_* 를 DROP 하고 V36~ 영상단위(RAW_SN) 신규 테이블로 재편했다. 따라서 **현재 소유 테이블의 진실원은 마이그레이션 SQL** 이고, 배포 문서는 의미어 대조용으로만 사용한다.
- **소스 3 — 엔티티**: `backend/src/main/java/**/entity/*.java` 의 `@Column(name=...)` ↔ 필드명 (REPLACE 대상에 엔티티 필드 병기)

## 제외 정책 (절대 변경 대상 아님)

- **QRTZ_\*** (11개 테이블 전체): Quartz 고정 스키마. `SCHED_NAME`, `TRIGGER_NAME`, `JOB_NAME`, `JOB_CLASS_NAME`, `CALENDAR_NAME`, `INSTANCE_NAME`, `LOCK_NAME`, `FIRED_TIME`, `NEXT_FIRE_TIME`, `PREV_FIRE_TIME`, `LAST_CHECKIN_TIME`, `SCHED_TIME`, `REPEAT_COUNT`, `START_TIME`, `END_TIME` 등 — Quartz JDBC JobStore 가 컬럼명을 하드코딩하므로 변경 불가.
- **flyway_schema_history**: Flyway 내부 테이블.
- **MNG_\* / CM_\***: 관제서버 소유 공유 테이블. 저작도구는 `ddl-auto=validate` 로 읽기 참조만. 변경 불가.
- **외부 시스템 고정 식별자 (KEEP)**: `VMS_CLIP_ID`, `VMS_CCTV_ID`, `GITEA_CMT_HASH` 등 — 외부 계약값/외부 시스템 키. 표준약어로 치환하면 외부 연동 깨짐. KEEP (사유: 외부 계약 식별자).

## ⚠ 일관성 결정 필요 항목 (운영 표준 합의 대상)

마이그레이션마다 작성 시점이 달라 동일 의미가 테이블별로 다르게 쓰임. 행안부 표준 기준 권장값 제시.

1. **생성/수정/등록 일시 혼재** — 가장 큰 불일치 (영어식 `*_AT` 다발):
   - 현행: `REG_DT/UPD_DT` (V1~V9 핵심 테이블, 배포본 스타일) vs `CREATED_AT/UPDATED_AT` (V13 LS_LABEL_PRESET, V45 LS_MARKING, V47 LS_PORTAL_USER_LABEL, V39 LS_WEBHOOK_IDEMPOTENCY, V41/V44 폴백큐) vs `REGISTERED_AT` (V5 LS_DATA_ISSUE, V7 LS_DATA_AUG, V8 LS_DATA_SET, V9 LS_PORTAL_USER_VIDEO) vs `OCCURRED_AT`(V36 LS_TASK_EVENT_LOG) vs `DECISION_AT/EXPORTED_AT/APPLIED_AT/PROCESSED_AT`.
   - **권장 표준**: 생성 `CRT_DT` · 수정 `MDFCN_DT` · 등록 `REG_DT` (모두 배포본/공통표준 정합). LS_* 핵심 테이블이 이미 `REG_DT`(+`UPD_DT`)인 점을 고려해 **`REG_DT`+`MDFCN_DT` 로 통일** 권장. `*_AT` 신규 테이블 전부 정정 대상.
   - 영향(전수): LS_LABEL_PRESET, LS_MARKING, LS_PORTAL_USER_VIDEO/LABEL, LS_DATA_ISSUE, LS_DATA_AUG, LS_DATA_SET, LS_DATA_META, LS_WEBHOOK_IDEMPOTENCY, LS_CONTROL_NOTIFY_FALLBACK, LS_TASK_EVENT_LOG.

2. **`UPD_DT` vs `MDFCN_DT`** — LS_* 신규는 `UPD_DT`, 배포본/CM_/MNG_ 은 `MDFCN_DT`. **`MDFCN_DT` 로 통일** 권장(공통표준 수정일시).

3. **정렬순서 `SORT_NO`/`SORT_ORDER` vs `SORT_SEQ`** — V31/V33 은 `SORT_NO`, V13 은 `SORT_ORDER`, 배포본 전 테이블은 `SORT_SEQ`. **`SORT_SEQ` 로 통일** 권장.

4. **설명 `DESCRIPTION` vs `EXPLN`** — V11/V13 은 `DESCRIPTION`, gov 표준단어 `EXPLN`(1345), 배포본은 `*_EXPLN`(CM_CD_EXPLN). **`EXPLN` 통일** 권장.

5. **사유 `*_REASON` vs `*_RSN`/`*_CN`** — LS_DATA_ISSUE/AUG/AUG_RVW/META_REVIEW/AUTH_WORK_LOCK 가 `REASON`/`REJECT_REASON`. 표준단어 `RSN`(사유,1234). **`*_RSN` 통일** 권장(배포본 일부는 `*_CN`(내용) 사용 → 의미상 사유면 RSN 권장).

6. **파일경로 `FILE_PATH` vs `FILE_PATH_NM`** — LS_* 신규는 `FILE_PATH`, 표준용어는 `FILE_PATH_NM`(term:11953), 배포본은 한정어+`_FILE_PATH`(RAW_FILE_PATH, SRC_FILE_PATH). **표준용어 `FILE_PATH_NM` 채택** 또는 배포본 관례(한정어+FILE_PATH) 중 택1 합의 필요.

7. **상태 `STATUS`/`STATE` vs `*_STTS_CD`** — LS_CONTROL_NOTIFY_FALLBACK/LS_MARKING 은 `STATUS`, LS_WEBHOOK_IDEMPOTENCY 는 `STATE`. 표준단어 `STTS`(상태,1291). **`STTS_CD` 통일** 권장.

8. **수정자/수정일시 `UPDATED_BY/UPDATED_AT` vs `MDFR_ID/MDFCN_DT`** — LS_SYSTEM_CONFIG 가 `UPDATED_BY/UPDATED_AT`. 배포본은 `MDFR_ID/MDFCN_DT`. **`MDFR_ID`+`MDFCN_DT` 통일** 권장.

9. **gov 표준 미존재 → 사업(program) 사전 등록 후보** (행안부 8차 조회 결과 완전일치/단어 모두 없음): `IDEMPOTENCY_KEY`(멱등키), `*_HASH`(해시 — VERSION_HASH 등), `CALLBACK`(콜백 — 단어조차 미등재), `INTERVAL`(간격 — '간격' 단어 미등재), `DEAD_LETTER`(사장큐 — 기술용어). → LogiCraft `program_glossary`/`program_word` 에 사업 전용어로 등록 후 사용 권장.
   - 조회로 확정된 gov 단어(전부 8차 실측): 상태 STTS(1291) · 사유 RSN(1234) · 설명 EXPLN(1345) · 값 VL(101) · 내용 CN(584) · 형식 FRM(3192) · 명 NM(813) · 요청 DMND(1833) · 완료 CMPTN(1804) · 발생 OCRN(932) · 처리 PRCS(2657) · 오류 ERR(1794) · 재시도 RTRY(2201) · 횟수 NMTM(3252) · 건수 NOCS(168) · 크기 SZ(2898) · 업로드 ULD(1700) · 배정 ALTMNT(988) · 색상 COLR(1303) · 외부 OTSD(1812) · 적용 APLCN(2248) · 판정 JGMT(2993) · 시작 BGNG(1581) · 프레임 FRME(3048) · 경로 PATH(224) · 파일 FILE(2986).
   - 완전일치 gov **용어**(term): 파일명 FILE_NM(11961) · 파일크기 FILE_SZ(11983) · 파일경로명 FILE_PATH_NM(11953) · 촬영일시 SHT_DT(11003) · 동영상재생시간 VDPLY_HR(3024) · 처리상태명 PRCS_STTS_NM(10704).

## 후속 처리 가이드 (참고, 본 작업 범위 외)

- 실제 컬럼 RENAME 은 ① Flyway `ALTER ... RENAME COLUMN` 마이그레이션 + ② 엔티티 `@Column(name=...)` 동시 수정 + ③ QueryDSL Q타입 재생성 필요 → 별도 Phase 로 진행.
- MNG_*/CM_* 는 변경 금지이므로, LS_* 가 MNG_* 의 컬럼명(예: VMS_CCTV_ID)을 참조/조인하는 경우는 KEEP 유지(외부 계약 정합).
- 본 분석의 표준약어는 모두 gov 8차 실제 조회값. 단 합성어(`AUG_FILE_PATH_NM`, `OTSD_JOB_ID` 등)는 표준'단어' 조합이므로 RENAME 확정 전 사업 ERD 검증(`gov_compare_erd`/`program_glossary`) 권장.
