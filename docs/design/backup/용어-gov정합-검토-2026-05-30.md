## 권고 실행 계획

1. **A그룹**: 적용 제외(동음이의). 현행 유지.
2. **B그룹(10건)**: 저작도구 코드 미변경. `관제팀 표준화 권고 이슈`로 기록(아래 별도 문서/노트).
3. **C그룹(19건)**: 컬럼별 **소유 감사**(LS_* vs 공유) → LS_* 소유분만:
   - Flyway **신규 ALTER 마이그레이션**(기존 마이그레이션 수정 금지 — 체크섬)
   - JPA `@Column` + DTO + QueryDSL/`@Query` + FE 타입 동기 수정
   - LogiCraft 글로서리(term_en_abbr) + ERD ITEM + 설계문서 갱신
   - **빌드/테스트 QA 통과 필수**
   - 날짜·건수 범용 약어(CRT_DT/STRT_DT/CMPT_DT/OCRC_DT/TOT_NOCS 등)는 공유 분포 가능성 높음 → 신중
4. **글로서리 메타 3건**: LogiCraft에서 즉시 정정 가능(코드 무관).

## 소유 감사 결과 (2026-05-30, 확정)

C그룹 18개 약어를 Flyway 마이그레이션 + JPA 엔티티 + 배포 스키마 문서로 전수 감사한 결과:

- **LS_ONLY(저작도구 자체관리, rename 가능) = 0건.** 18개 약어 모두 `db/migration/*.sql`·`@Column` 어디에도 없음.
- 배포 스키마 문서(`dev-db-schema-2026-04-23.md`)에만 등장하는 8건은 전부 MNG_*/CM_*(공유) 또는 코드와 드리프트된 LS_ 문서상 테이블.
- 나머지 10건은 세 소스 어디에도 없음(이 코드베이스 컬럼 아님).

| 소유분류 | 건수 | 처리 |
|---|:---:|---|
| LS_ONLY (코드 rename 대상) | 0 | — |
| SHARED (MNG_/CM_) | 7 | 관제팀 이슈 |
| MIXED | 1 (ACTION_DT) | LS_ 분은 문서상만 존재(코드 없음) |
| NOTFOUND | 10 | 코드 무관 |

> **결론: gov 정합을 위한 저작도구 코드(마이그레이션/엔티티/DTO/FE) 변경은 0건.**
> gov 충돌 31건은 모두 ① 공유/마스터 테이블(관제팀) ② 동음이의(제외) ③ 코드 미사용 사전 항목으로 귀결.
