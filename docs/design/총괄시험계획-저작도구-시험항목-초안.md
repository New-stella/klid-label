# 총괄시험 계획서 — 저작도구시스템 시험 항목 (초안)

> 대상: `총괄시험 계획서`(AI 기반 지방정부 CCTV 관제지원시스템 구축(2차)) `구분=저작도구시스템` 칸.
> 근거: D10(대외 인터페이스 통합시험 TC-001~011) · D11(단위시험 UT 27케이스). **실제 구현 기능만** 수록.
> 형식: 다른 구분(관제지원시스템)과 동일하게 **"대분류 – 세부/세부/세부"**.

## 1. HWP 붙여넣기용 (대분류 – 세부기능)

- **영상 적재** – 관제 공유 DB 학습용 영상 픽업/저작도구 적재/원본·비식별 2벌 저장
- **비식별화** – 외부 비식별 솔루션(KPST) 위탁/진행 폴링/완료 결과 회수/비식별 영상 서빙/비식별 누락 신고·수동 재처리
- **이벤트 마킹** – 비식별 영상 스트리밍(배속·단축키)/자동 마킹(프레임 간격)/수동 마킹/마킹 완료 후속 배치 트리거
- **VLM 시계열 메타** – 외부 VLM 위탁/결과 콜백 수신·진위 검증/시계열 메타 적재/메타 검수(REVIEWER)
- **프레임 추출** – 마킹 위치 기반 원본·비식별 프레임 추출/프레임 매니페스트 생성
- **오토라벨링** – YOLO 객체 탐지/SAM2 분할(클릭·박스 프롬프트)/SAM2 Track(박스→N프레임 추적 전파)/트랙 보간
- **라벨링** – 바운딩박스/폴리곤/세그멘테이션 편집/라벨 속성 입력/작업 임시저장/되돌리기·다시하기
- **검수** – 작업자 배정·재배정·배정 이력 조회/검수 제출/검수 승인·반려
- **버전관리** – 검수 승인 시 라벨 전체 스냅샷(DB)/버전 간 diff/버전 롤백
- **관제 통지** – 검수 완료(TASK_COMPLETED)·수정(TASK_MODIFIED) 단방향 통지/발송 결과 상태 관찰/관제 상세 조회 API 제공
- **데이터 증강** – 외부 증강(겨울·야간·우천) 위탁/결과 콜백·새 영상 등록/원본 라벨 복사/증강 결과 활용 검수(채택·거부)
- **해상도 변경** – 표준 하위 해상도(1080P/720P/480P) 프레임셋 다운스케일
- **사용자·권한** – 검수자(REVIEWER)·작업자(WORKER) 역할 기반 접근 제어/관제·포털 인계 토큰(JWT) 검증
- **데이터마트 연계** – 검수 완료 영상·프레임 페어·라벨·시계열 메타 View 제공

## 3. 작성 시 유의 — 범위 (Critical)

- **범위 외(넣지 말 것)**: 학습데이터셋 Export·데이터마트 구축/검색/다운로드, 생성형 AI·시계열 메타·영상 합성 **모델 본체**, 포털 오토라벨링·업로드 — 모두 외부 시스템 책임이라 저작도구 시험항목 아님.
- **포털 데이터 Load**: 코드 존재하나 R2 활성 요구사항 없음(결번 UC-024). 넣으려면 "요구사항 외 구현"으로 별도 표기.
- **VLM 위탁**: 기본 토글 off(`vlm.client.enabled=false`) — 시험 시 활성 필요.
- **비식별 마스킹 옵션(UT-013)**: `[설계]` 케이스(옵션 키 미등록, 기본값 고정) — 실동작 검증 대상 아님, 승격 시 별도.
