```plantuml
@startuml KLID-AT-SD-001

ORCH -> STATUS : markStage(FRAME_EXTRACT)

note right : 마킹 위치(frameIndex)\n기반 원본+비식별 2벌 추출

note right : 원본 프레임만 실행\n비식별본은 결과 공유
```
