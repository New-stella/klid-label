# 라벨링 정밀도 조절

## goal

폴리곤 단순화 정밀도(epsilon)를 조절하여 밀착/세그멘테이션 결과의 경계 세밀함(점 수)을 제어한다.

## actor

검수자(REVIEWER)

## title

라벨링 정밀도 조절

## status

draft

## priority

should

## main_flow

### [1]

- **step**: 1
- **actor**: 검수자(REVIEWER)
- **action**: PUT /v1/manage/configs/{key}로 POLYGON_SIMPLIFY_TOLERANCE를 조절한다(영속 기본값)

### [2]

- **step**: 2
- **action**: 시스템이 설정값을 저장하고 캐시(TTL 60s)에 반영한다

### [3]

- **step**: 3
- **action**: 이후 SAM2 track/밀착 시 설정 epsilon으로 폴리곤 점 수를 단순화한다

### [4]

- **step**: 4
- **actor**: 라벨링 작업자(WORKER)
- **action**: 라벨링 화면 AI Tool 모달에서 confThreshold/simplifyTolerance를 요청 단위 1회성으로 override한다(비영속)

### [5]

- **step**: 5
- **action**: 설정 조회 실패 시 기본값(1.0px)으로 fail-safe 폴백한다

## brownfield

### notes

2026-07-30: AI Tool 모달의 1회성(비영속) confThreshold/simplifyTolerance 조절 반영 — 영속 시스템 설정(POLYGON_SIMPLIFY_TOLERANCE)과는 별개 메커니즘

### status

new

### change_kind

### diff_summary

폴리곤 단순화 정밀도(epsilon) 설정 기반 제어 신규

## description

REVIEWER가 시스템 설정에서 POLYGON_SIMPLIFY_TOLERANCE(Douglas-Peucker epsilon)를 조절하면 이후 SAM2 track/밀착 시 폴리곤 점 수가 단순화된다(영속 설정, Caffeine 캐시 TTL 60s, 조회 실패 시 기본값 1.0px fail-safe). ★1회성 조절 확장(2026-07-30) — 이와 별개로 라벨링 화면 AI Tool 모달에서 confThreshold(YOLO conf/iou)·simplifyTolerance를 요청마다 1회성(비영속)으로 override할 수 있다(WORKER·REVIEWER 공통, 시스템 설정 변경 없이 해당 요청에만 적용). 두 메커니즘은 별개다 — 시스템 설정은 REVIEWER 전용 영속 기본값, AI Tool 모달 조절은 요청 단위 임시값이다. (R2 UC-006, RQ-SFR-08-03)
