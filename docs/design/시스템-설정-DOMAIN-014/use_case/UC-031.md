## description

REVIEWER가 배치 처리(처리 주기·동시 처리 수)/AI 탐지 추론(Confidence Threshold·IoU 임계값)/라벨링 정밀도(인식 민감도·경계 세밀함) 설정 카드에 더해 비식별 옵션과 연동 서버 주소를 조회·수정하고, 외부 연동(비식별 서버·AI 추론 서버·데이터베이스) 헬스를 5초 주기 폴링으로 읽기 전용 모니터링하며, 되돌릴 수 없는 위험 액션(시스템 초기화·배치 큐 초기화·캐시 삭제)을 확인 절차를 거쳐서만 실행한다. 저장은 카드별 독립 폼이며 일괄 저장 API 가 없어 실제로 바뀐 키에 한해서만 개별 PUT 요청을 보낸다. 화면이 표시하는 범위와 서버가 허용하는 범위가 완전히 일치하지 않는 필드가 있으며 최종 판정은 서버 값이다. 어느 필드가 어떻게 어긋나는지는 기술 고려사항에 적는다.

연동 서버 주소는 비식별 서버(kpst.deid.base-url)·AI 추론 서버(authoring.integration.ai-server.base-url)·외부 시계열 분석 벤더(vlm.client.url)·관제 통지 수신처(authoring.control-notify.url)를 대상으로 하며 데이터베이스 접속 정보는 대상이 아니다. 설정 키는 애플리케이션 속성명을 그대로 쓴다 — 별도 키명을 만들면 그 매핑표가 두 번째 진실원이 된다. 설정에 값이 있으면 그 값을, 없으면 배포 기본값을 쓰며 행이 없는 것이 정상 상태라 저장 전까지는 목록 조회에 그 키가 나타나지 않는다. 반영은 재기동 없이 다음 호출부터이고, 값을 바꾼 노드에서는 즉시 다른 노드에서는 설정 캐시 수명만큼 늦게 반영된다. 이 카드는 기본이 잠금 상태여서 검수자 권한만으로는 저장되지 않고 관리자 공유 패스워드로 단기 유효창을 열어야 하며, 그 유효창은 주소 설정 변경에만 효력이 있고 역할을 승격시키지 않는다. 저장 값에는 빈 값 거부·길이 상한·주소 형식·스킴(http 또는 https)·호스트 존재·자격증명을 담은 표기 거부만 걸리고 주소 대역으로는 막지 않는다 — 망 통제는 인프라 계층이 담당한다.

UC-006(라벨링 정밀도 조절의 1회성 AI Tool 모달 override 메커니즘)·UC-013(비식별 옵션 항목 자체)과 서로 다른 관점에서 같은 화면을 다루며 서로를 대체하지 않는다.

## alternate_flows

### 허용 범위 밖 값 저장 시도

**steps**:

- 서버가 저장을 거부하고 화면은 공통 실패 토스트를 노출한다(필드별 구분 없음)

- **trigger**: 서버 허용 범위를 벗어난 값으로 저장 요청

### 변경 없는 카드 저장 시도

**steps**:

- 저장 버튼이 비활성화되어 요청 자체가 발생하지 않는다

- **trigger**: 카드 내 값이 하나도 바뀌지 않음

### 위험 액션 취소

**steps**:

- 아무 액션도 실행되지 않고 다이얼로그만 닫힌다

- **trigger**: 확인 다이얼로그에서 취소를 선택

### 관리자 유효창 없이 연동 주소 저장 시도

**steps**:

- 저장이 거부되며(403) 없음·만료·위조·타인 발급을 구분해 알리지 않는다
- 화면은 유효창이 닫힌 것으로 보고 주소 카드를 다시 잠근다

- **trigger**: 유효창을 열지 않았거나 만료된 상태에서 연동 서버 주소를 저장

### 연동 주소 값 위반

**steps**:

- 저장이 거부되며(400) 거부 사유에 입력 원문이나 해석 결과를 싣지 않는다
- 화면은 주소 형식 위반과 인증 만료를 갈라 안내한다

- **trigger**: 빈 값·길이 초과·형식 오류·http 와 https 가 아닌 스킴·호스트 없음·자격증명을 담은 표기로 연동 서버 주소를 저장

## tech_considerations

- 화면 슬라이더 표시 범위와 서버 허용 범위가 완전히 일치하지 않는 필드가 있다(예: IoU 임계값 — 화면 25~80 vs 서버 30~80, 25~29 구간은 화면에서 입력 가능하나 서버가 거부한다)
- 연동 주소는 판정 축이 둘이다 — 기동 시점의 배포 기본값을 판정하는 축은 그대로 남아 있어 운영 프로파일에서 위반하면 기동이 막히지만, 운영 화면에서 저장하는 값에는 그 판정이 다시 적용되지 않는다. 같은 주소가 경로에 따라 다르게 판정되는 것은 결함이 아니라 대상이 다른 두 축이다
- 비식별 서버 주소에만 관문이 하나 더 있다 — 운영 배포에서는 알려진 목·시뮬레이터 호스트명으로 저장할 수 없다. 이 관문의 판정 축은 호스트명이지 주소 대역이 아니다
