# dev 로그인/dev 업로드 — prd 빌드 env 토글 허용(기본 OFF, fail-closed)

## context

관제 미기동 폐쇄망 브링업 시나리오에서 관제 로그인 인계 없이 저작도구를 단독 기동/검증할 방법이 필요했다.

## decision

### chosen_option

env 토글로 조건부 허용(채택)

### justification

dev 로그인(/dev/login)·dev 업로드(/dev/autolabel-test)를 prd 빌드에서도 env 토글(VITE_DEV_LOGIN_ENABLED/VITE_DEV_UPLOAD_ENABLED)로 켜질 수 있게 허용한다. 기본 OFF, fail-closed다.

### status

new

### diff_summary

dev 로그인/업로드를 prd 빌드 완전비활성에서 env 토글 기반 조건부 허용(기본 OFF)으로 전환

## consequences

### risks

- 토글이 실수로 켜진 채 prd에 배포되면 dev 로그인/업로드가 노출될 위험 — 배포 파이프라인에서 기본값 검증 필요

### negative

- 운영 예외 경로 추가 — dev 편의기능이 실수로 prd에 노출되지 않도록 기본값 OFF가 전제

### positive

- 관제 미기동 폐쇄망 브링업 시나리오에서 저작도구 단독 기동/검증 가능

## considered_options

### dev 로그인/업로드를 prd 빌드에서 완전 비활성(구, 브링업 불가)

**cons**:

- 관제 미기동 폐쇄망 브링업 시나리오에서 저작도구를 단독 검증할 방법이 없음

**pros**:

- 운영 예외 경로가 전혀 없어 공격면 최소

- **description**: prd 빌드에서 dev 로그인/업로드 경로를 코드 레벨에서 완전 제거

### env 토글로 조건부 허용(채택)

**cons**:

- 운영 예외 경로 추가 — 토글 오설정 시 prd에 dev 편의기능 노출 위험

**pros**:

- 폐쇄망 브링업 시나리오 지원
- 기본 OFF·fail-closed로 실수 노출 방지
