## description

authoring.dev.login.enabled=true(환경변수 DEV_LOGIN_ENABLED) 일 때만 엔드포인트가 노출된다. 미설정이거나 false 면 프로파일과 무관하게 존재하지 않아 404 가 된다(fail-closed). local/dev 프로파일은 기본값이 true 다. stg/prd(운영 계열)는 기본값이 false 이며, 그 값을 뒤집어 켠 채 기동을 시도하면 부팅 자체를 거부한다(fail-closed) — 인증 없이 임의 권한 토큰을 발급하는 경로라 운영에서 켜지면 인증 체계 전체가 우회되기 때문이다.

HS256 서명된 테스트 용 토큰을 즉시 발급한다(인증 불필요 — 토큰을 얻는 진입점이라 같은 설정 조건 아래에서만 열린다). 역할과 채널 조합은 검수자·작업자는 내부 채널, 포털 회원은 포털 채널만 허용한다. 응답에 서명 비밀값은 포함되지 않는다.
