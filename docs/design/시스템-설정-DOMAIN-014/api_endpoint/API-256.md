## description

포털 라벨링 화면이 AI 보조(AI 탐지·AI 분할·AI 자동 추적)에 쓰는 운영 설정을 읽기 전용으로 조회한다. 정밀도 입력의 초기값과 작업 종류별 최대 대기 상한 두 갈래를 담으며 값만 반환한다 — 마지막 수정자·수정일시 같은 운영 메타는 담지 않는다.

★응답은 내부 조회 창구([[API-193]])와 같은 값·같은 형태다. 새 설정을 두지 않고 같은 저장값을 읽는다 — 포털 사용자 요청도 같은 추론 서버와 같은 추론 예산을 쓰므로, 채널마다 값이 갈리면 한쪽 화면이 성공한 추론을 실패로 보게 된다. 최대 대기 상한을 화면이 아니라 서버가 정하는 이유, «고정분 + 프레임당 가산분 x 그 요청이 싣는 프레임 수» 계산식, 절대 상한을 넘기면 한 요청에 싣는 프레임 수를 줄여 나눠 보내는 규칙, 저장값이 없거나 숫자로 해석되지 않으면 그 항목을 생략하고 화면이 자체 기본값으로 대체하는 규칙은 그 창구의 서술이 그대로 적용된다.

내부 조회 창구를 포털 채널에 여는 대신 이 창구를 따로 둔다 — 내부 창구는 내부 채널 전용이라 포털 화면이 쓸 수 없고, 두 채널의 인가 주체를 섞지 않는다([[ADR-012]]). 포털의 AI 보조 제공 결정은 [[ADR-013]] 이 담는다. 이 창구는 포털 회원 역할과 포털 채널 토큰으로만 호출할 수 있다. 소비 화면은 [[SCREEN-029]] 이다.

응답이 내부와 같으므로 포털이 제공하지 않는 작업 종류(선택 객체 추적)의 대기 예산도 함께 담긴다. 포털 화면은 그 항목을 쓰지 않을 뿐 빠진다고 가정하지 않는다 — 채널별로 응답을 잘라내면 두 창구의 계약이 갈라진다. 조회 전용이며 이 경로에는 쓰기 대응물을 두지 않는다 — 설정 변경은 내부 관리 경로가 담당한다.
