## description

한 검증 이벤트 유형의 질문 목록을 통째로 받아 교체한다. 받은 배열의 순서가 곧 정렬순서이며 첫 번째가 그 유형의 기본 질문이다. 검수자 전용이다.

[부분 조작 경로를 두지 않는다] 추가·수정·삭제·순서 변경을 이 하나로 처리한다. 항목 단위 조작 경로를 따로 두면 여러 요청 사이의 중간 상태에서 「첫 번째」가 흔들리고, 그 사이에 조달되는 질문이 운영자가 의도하지 않은 문구가 된다. 쿼리 파라미터로 행위를 분기하지도 않는다.

[빈 배열은 그 유형의 질문을 없앤다] 질문이 하나도 없는 유형은 어노테이션 질문 칸을 비운 채로 둔다 — 값을 지어내지 않는다.

[질문 문구 검증] 질문 문구는 외부 사업자 요청 본문과 로그에 그대로 실리는 값이다. 그래서 개행·제어문자를 허용하지 않고, 저장 컬럼 폭 안에서 길이를 제한하며, 빈 문자열이거나 공백만으로 이루어진 질문은 거부한다. 이 제한이 없으면 로그 한 줄에 여러 줄이 섞여 들어가 기록을 위조할 수 있고 사업자 쪽 해석도 깨진다. 하나라도 어긋나면 요청 전체를 거부한다 — 일부만 반영되면 남은 목록의 순서가 운영자가 보낸 것과 달라진다.

[교체 후 마킹 선택값] 교체 전 질문을 가리키던 마킹의 선택값은 교체 후 그 유형의 질문을 더 이상 가리키지 않을 수 있다. 그때는 확정된 폴백대로 그 유형의 첫 번째 질문을 쓴다 — 선택값이 그 유형에 속하는지 조달 시점마다 확인하고 화면 입력을 신뢰하지 않는다.

[유형은 이 경로로 만들지 않는다] 등록되지 않은 검증 이벤트 유형 코드로 호출하면 거부한다. 이 경로가 다루는 것은 질문 목록뿐이며 유형 자체의 이름·설명·순서는 바꾸지 않는다.
