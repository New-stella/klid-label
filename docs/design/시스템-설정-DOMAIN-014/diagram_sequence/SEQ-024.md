## description

검수자가 시스템 설정 화면에서 운영 파라미터를 조회·수정하고, 외부 연동 상태를 읽기 전용으로 지켜보는 흐름을 그린다. 연동 서버 주소를 바꾸는 흐름은 참여자와 분기가 크게 달라 별도 시퀀스로 분리했으며, 두 흐름은 설정 저장 지점 하나에서만 만난다.

저장은 카드 단위가 아니라 키 단위다 — 일괄 저장 계약이 없으므로 화면은 카드 안에서 실제로 값이 바뀐 키마다 개별 요청을 보낸다. 서버는 요청마다 검수자 권한을 다시 확인하고, 허용 목록에 없는 키와 유형별 허용 값·허용 범위를 벗어난 값을 거부한다. 거부 메시지에는 요청한 키를 되비추지 않는다.

저장이 끝나면 설정 캐시를 통째로 비운다. 이 캐시는 프로세스 로컬이라 무효화가 다른 노드로 전파되지 않으며, 값을 바꾼 노드에서는 즉시, 다른 노드에서는 캐시 수명만큼 늦게 반영된다.

헬스 모니터링은 화면이 열려 있는 동안 주기적으로 도는 읽기 전용 조회다. 점검 대상은 비식별 서버·AI 추론 서버·데이터베이스이며, 하나라도 정상이 아니면 전체 상태를 저하로 내린다.
