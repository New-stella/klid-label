## description

저작도구 개인정보 위탁 처리 기준:
- 개인정보 처리에 관하여 표준 개인정보처리 위탁계약서 내용을 준수한다.
- 계약상의 권리와 의무는 전부 또는 일부를 재위탁하지 않는다.
- 개인정보의 안전성 확보조치 기준에 따라 필요한 기술적·관리적 조치를 취한다 — 외부에 전달하는 자료는 위탁 목적에 필요한 최소 범위로 한정하고, 비식별 처리가 끝난 자료를 우선 전달하며, 전달 경로와 저장 위치를 지정된 범위로 제한한다.
- 위탁업무 수행 목적 범위를 넘어 개인정보를 이용하거나 제3자에게 제공·누설하지 않는다.
- 수탁자에 대한 개인정보 처리현황, 접속현황, 접속대상자, 목적 외 이용·제공 및 재위탁 금지 준수 여부 관리·감독에 응한다. 이를 위해 위탁 요청·응답 이력과 처리 결과를 조회 가능한 형태로 보존한다.
