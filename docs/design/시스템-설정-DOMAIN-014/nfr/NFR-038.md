## description

저작도구 상호운용성 기준:
- 인터페이스 요구사항과 애플리케이션·정보 간 상호작용 기능은 기능 구현의 정확성뿐 아니라 데이터 정합성과 정보의 무결성까지 검증한다.
- 통지 페이로드는 수신측 계약과 필드 단위로 일치하는지 검증하고, 필수 항목은 값이 비어도 키를 유지해 수신측 검증 실패를 막는다.
- 조회용 뷰는 출력 항목의 이름·순서·건수 불변식을 시험으로 고정한다.
- 외부 위탁의 요청·콜백은 상관 식별자로 짝을 맞추고, 응답을 받지 못한 건은 회수 경로로 종결해 미결 상태가 남지 않게 한다.
- 산출물이 재생성되면 그 버전이 통지와 대응되도록 하여 수신측이 옛 산출물에 고착되지 않게 한다.
