## description

시스템 설정 컴포넌트. 비식별 옵션 값도 같은 설정 키-값 경로에 담기지만 이 컴포넌트는 저장과 제공만 담당한다. REVIEWER 가 /v1/manage/configs 에서 화이트리스트 키(ConfigKeys.ALLOWED)만 조회/수정한다. SystemConfigController(@PreAuthorize REVIEWER) → SystemConfigService(Caffeine 'sysconfig' 캐시 TTL 60s, getInt/getDouble/getString 핫패스 가속, update 시 allEntries 무효화) → LsSystemConfigRepository(@ControlRepo). 타입별 검증(NUMBER 범위/DECIMAL 범위/BOOLEAN true|false) + 키별 범위(ConfigKeys.NUMBER_RANGE/DECIMAL_RANGE) + Service 단 REVIEWER 이중 검증. CWE-117 방어로 허용 안된 키는 원본 메시지 미노출. 설정값은 비식별 처리(DeidentifyClient 호출 시) 등 소비측이 읽어간다.
