## description

관리 기능에 들어가기 전 관리자 패스워드를 확인하는 게이트 화면의 고충실 시안. 이 화면은 확인만 맡고 관리 기능을 담지 않으므로, 화면을 가득 채우는 관리 표면이 아니라 넓은 여백 가운데 세운 좁은 카드 하나로 그 성격을 시각으로 말한다. 카드는 안내·입력·유효창 세 단으로 나뉜다. 머리에는 자물쇠 표식과 제목, 검수자 전용·관리자 확인 필요 두 배지를 두어 지금 잠겨 있다는 사실을 색이 아니라 아이콘과 글자로 알린다. 확인으로 열리는 것이 잠깐 열리는 유효창일 뿐 역할이 바뀌는 것이 아니며 검수자 권한은 그대로 필요하다는 설명을 회색 안내 상자로 붙여, 권한이 모자란다는 지적이 아니라 절차 안내로 읽히게 했다. 어디로 가려다 막혔는지 알 수 있도록 돌아갈 화면을 이름표로 밝히고, 그것을 알 수 없을 때만 기본 화면으로 간다는 예외도 함께 적었다. 입력단은 가려진 패스워드 칸 하나와 확인·취소 두 버튼을 세로로 쌓아 확인이 주 행동임을 위계로 드러낸다. 결과단은 유효창 스트립이며 첫 진입 상태에서는 아직 열려 있지 않음을 중립 색과 함께 남은 유효 시간 자리를 비워 보여준다. 확인 실패·시도 제한·유효창 열림·유효 시간 만료 네 상태는 카드 아래 참고 패널에 실물로 그려 두었다. 실패는 사유를 구분하지 않는 단일 문구 하나뿐이며, 시도가 잦을 때만 제한된다는 사실을 덧붙이고 남은 횟수나 해제 시각은 그리지 않는다. 색·간격·타이포·컴포넌트는 DS-001 토큰만 쓰고 자물쇠 배너와 남은 유효 시간 표시는 시스템 설정 시안의 패턴을 그대로 옮겨왔다. 무 JS 정적 렌더이며 본문 17px 이상, 대화형 요소는 44px 이상 타격 영역과 3px 포커스 링을 지킨다.
