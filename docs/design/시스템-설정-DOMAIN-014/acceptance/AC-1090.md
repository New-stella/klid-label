# 장비 관리 쓰기는 관리자와 유효창을 함께 요구한다

## priority

high

## scenario

### then

- 검수자의 조회는 성공한다
- 검수자의 쓰기는 거부된다
- 유효창 없는 관리자의 쓰기도 거부되고, 두 거부는 사유를 구분해 알리지 않는다

### when

- 검수자가 목록을 조회한다
- 검수자가 장비를 등록하려 한다
- 관리자가 유효창 없이 장비를 등록하려 한다

### given

- 관리자 권한과 유효한 관리자 단기 유효창을 가진 사람이 관리 화면에 들어와 있다

## statement

장비 목록 조회는 검수자 권한만으로 된다 — 막으면 장비 상태를 확인할 길이 없어진다. 반면 등록·수정·상태 전이·삭제는 운영·관리 성격의 쓰기라 관리자 권한에 더해 유효한 관리자 단기 유효창을 함께 요구한다. 유효창은 권한을 대체하지 않고 가산되며 역할을 승격시키지도 않는다. 검수자는 이 쓰기 창구를 열 수 없다 — 계층은 관리자가 검수자 자리를 통과하게 할 뿐 그 반대는 성립하지 않는다. 거부 응답은 권한이 모자란 것인지 유효창이 없는 것인지 구분해 알리지 않는다.
