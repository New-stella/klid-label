# 연동 서버 주소는 주소 대역으로 막지 않는다

## notes

연동 대상이 내부망의 별도 서버에 있을 가능성이 높아 대역으로 막으면 정당한 연동이 막힌다. 실제로 기본값으로 들어 있던 추론 서버 주소가 그 이유로 저장되지 않은 적이 있다. 망 통제는 인프라 계층이 담당한다. 자격증명을 담은 표기를 거부하는 것과 빈 값·길이 상한을 거는 것은 이 기준이 말하는 대역 판정과 다른 축이라 그대로 유효하다.

## priority

critical

## scenario

### then

- 저장이 받아들여진다
- 대역을 이유로 거부되지 않는다
- 스킴이 허용된 둘 중 하나가 아니거나 주소 형식이 아니면 그때는 잘못된 입력으로 거부된다

### when

- 내부망 주소를 값으로 저장한다

### given

- 관리자 유효창이 열린 상태에서 연동 서버 주소를 수정하려 한다

## statement

연동 서버 주소 저장은 스킴과 주소 형식과 호스트 존재만 판정하며, 사설망이나 루프백처럼 특정 대역에 속한다는 이유로 거부하지 않는다.
