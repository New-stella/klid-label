# 장비 주소는 저장될 때도 검증을 받는다

## priority

high

## scenario

### then

- 평문·사설 주소는 등록된다
- 예약 대역·비허용 스킴·형식 위반은 잘못된 요청으로 거부된다
- 거부 문구에 입력한 주소나 해석 결과가 드러나지 않는다

### when

- 평문 http 와 사설 대역 주소로 장비를 등록한다
- 클라우드 메타데이터 주소나 링크로컬 주소로 등록한다
- 허용하지 않는 스킴이나 형식이 깨진 주소로 등록한다

### given

- 관리자 권한과 유효한 관리자 단기 유효창을 가진 사람이 관리 화면에 들어와 있다

## statement

장비 주소를 저장할 때 스킴은 http 또는 https 여야 하고 주소 형식과 호스트가 있어야 한다. 평문 http 와 사설 대역 주소는 통과가 정상이다 — 연동 대상이 내부망의 별도 장비에 있는 것이 통상이고, 대역으로 막으면 공격자가 아니라 정당한 대상을 막는다. 반면 클라우드 메타데이터 주소와 링크로컬 같은 예약 대역, 허용하지 않는 스킴, 형식 위반은 거부한다. 거부 사유에는 입력 원문·호스트·주소 해석 결과를 싣지 않는다 — 실으면 그 응답 자체가 내부망을 훑는 수단이 된다.
