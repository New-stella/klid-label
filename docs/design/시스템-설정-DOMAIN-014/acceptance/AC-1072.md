## statement

관리자가 시스템 설정 화면(/manage/settings)에서 설정 키-값 목록을 조회하고(API-068) 배치 처리/AI 탐지 추론/라벨링 정밀도/비식별 옵션 카드 중 값을 수정한다(카드별 독립 폼, 실제로 바뀐 카드만 저장 버튼 활성). 저장 시 카드 안에서 실제로 바뀐 키에 한해 개별 PUT(API-069)을 보내고(일괄 저장 없음) 서버가 타입·범위를 검증한다. 연동 서버 주소 변경·관리자 패스워드 교체는 관리자 페이지 진입 시 공유 패스워드를 제출해 단기 유효창을 열고(API-194, 관리 기능 공통 진입·남은 시간 표시·만료 시 재확인), 유효창이 사는 동안 비식별·AI·시계열 벤더·관제 통지 주소를 재입력 없이 수정 저장하며(PUT API-069, X-Admin-Session 헤더). 설정 화면 카드는 유효창 없이 검수자 권한만으로 저장되고, 우측 패널이 5초 폴링으로 외부 연동 상태를 읽기 전용 확인하며(API-090), 위험 액션은 확인 다이얼로그를 눌러야 실행되고, 패스워드 교체 시 현재 패스워드 재확인 후 제출하면 그 전 발급 유효창은 본인 것까지 모두 무효가 된다.
