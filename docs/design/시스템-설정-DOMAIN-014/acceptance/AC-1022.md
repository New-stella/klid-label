## scenario

### then

- 비식별이 선두로 실행되고 성공 시 마킹 대기로 전이된다

## statement

적재 사건을 받아 비식별을 선두로 시작하고(적재만으로는 마킹 진입 불가), 성공하면 마킹 대기로 전이해 마킹 완료 신호를 기다린다. 신호를 받으면 잔여 단계를 시계열 위탁→프레임 추출→오토라벨링→트랙 보간 순으로 시작하되, 시계열 위탁은 논블로킹으로 제출해 결과를 콜백으로 따로 받고 파이프라인 스레드를 붙잡지 않는다. 마킹이 가리킨 위치에서 원본·비식별본 두 벌의 프레임과 목록 파일을 만들고, 실효 프리셋이 정한 대상에 원본 프레임으로 탐지·분할·보간을 수행하며, 단계마다 이력을 남기고 완료 시 작업 상태를 배정 상태로 되돌린다(검수 종결은 검수 승인 시점).
