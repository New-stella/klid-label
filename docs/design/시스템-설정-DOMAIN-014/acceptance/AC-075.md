# 설정 값의 허용 범위는 서버가 최종 판정한다

## notes

화면의 입력 제한은 편의이고 판정이 아니다. 판정을 화면에만 두면 화면을 거치지 않은 요청이 범위를 벗어난 값을 그대로 저장한다.

## priority

high

## scenario

### then

- 저장이 거부된다
- 기존 값이 그대로 남는다

### when

- 그 값으로 설정을 저장한다

### given

- 화면이 허용하는 것처럼 보이지만 서버 범위를 벗어나는 값이 있다

## statement

설정 값의 타입과 범위는 서버가 판정하며, 화면이 표시하는 범위와 서버가 허용하는 범위가 일치하지 않는 값이 들어와도 서버 판정이 최종이다.
