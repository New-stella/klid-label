## 1. 개요

### 1.1 목적
본 문서는 학습데이터 저작도구의 시스템시험 시나리오를 정의한다. 시험 대상은 R1 사용자 요구사항(SFR) 16개에 매핑된 R2 유스케이스(증강·AI 보조 라벨링·버전관리·검수·비식별·시계열 메타·볼륨)와 관련된 비기능 품질(성능·부하·볼륨·보안)에 한정한다.

### 1.2 시험 범위
- 성능 시험 — AI 추론 응답시간, 비식별 처리, 증강 수신 처리, API 응답시간, 배치 처리율
- 부하 시험 — 동시 검수/라벨링 사용자 처리
- 볼륨 시험 — 라벨 버전·비식별 이력·시계열 메타 대량 적재 시 조회/비교 성능(SFR-16 이미지 10만장 / SFR-17 영상 5,000건 기준)
- 보안 시험 — JWT 인증·인가, 비식별 원본 비노출, 통지 페이로드 PII 미포함, SQL Injection 방어, 개인정보 유형별 공개대상 통제, 영상 암호화 저장·로그 PII 마스킹·비정상 로그인 차단
- 기능·연동 시험 — 영상 스트리밍(Range)·배속·마킹(자동/수동) 단축키, 마킹 완료→BATCH_QUEUED 자동 기동, 검수 승인→COMPLETED→TASK_COMPLETED 발행, 검수 완료 후 수정→TASK_MODIFIED 통지(디바운스·idempotency·dead-letter), 해상도 변경 증강(새 RAW_SN)

### 1.3 시험 환경
| 구분 | 내용 |
|------|------|
| 시험 서버 | Spring Boot 단일 인스턴스(Java 17), ai-server(Python FastAPI, GPU Worker) |
| DB | PostgreSQL (klid_at 스키마) |
| 네트워크 | 내부망 (관제서버·포털·비식별 서버·VLM 서버 연동) |
| 시험 도구 | nGrinder / JMeter(부하·성능), 대량 데이터 시드 스크립트(볼륨), OWASP ZAP·sqlmap(보안) |
