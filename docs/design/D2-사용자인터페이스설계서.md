# D2 사용자 인터페이스 설계서

> **ID 표기 규칙(공통)**: 본 산출물의 모든 ID(KLID-AT-UC/CO/DC/DCD/SD/SC/AC/EN/ERD/TB/II/IC/IF/UCD/ACT 등)는 **전체 형식 `KLID-AT-XX-NNN`** 으로 표기한다. 끝부분만(예: `UC-001`) 약식 표기 금지. 범위는 시작 ID만 전체형으로(예: `KLID-AT-UC-001~013`). ※ 요구사항(RQ-SFR-NN-NN)·시스템시험(KLID-ST-NNN) 등 타 체계 ID는 각 체계 원형 유지.

## 작성 목적
> 시스템이 제공하는 사용자 인터페이스의 전체 구조와 메뉴 형식, 화면 목록과 화면의 상세 설계 내역을 기술한다.

## 작성 방법
> 전체 시스템에 대한 사용자 인터페이스의 구조를 사용자에게 제공하는 메뉴 형식으로 기술하고, 화면 및 출력으로 구분하여 목록을 작성하며, 화면의 상세 설계의 내용을 화면별로 기술한다.

### 1. 사용자 인터페이스 구조도

> **▣ 전체 시스템에 대하여 1개 작성한다.** 저작도구는 동일 도메인 SSO로 진입하는 **내부 채널(INTERNAL)** 과 외부 **포털 채널(PORTAL)** 두 채널로 구성된다. 아래는 실제 LNB(`Lnb.tsx`)·라우트(`router/index.tsx`) 구조를 반영한 메뉴 트리이며, 본 산출물의 화면 범위(활성 유스케이스 실현 화면)에 해당하는 노드를 굵게 표기한다. 메뉴로 노출되지 않고 진입 맥락(목록 행 클릭·풀스크린 진입)으로 도달하는 화면은 `(맥락 진입)` 으로 표기한다.

- **화면시작**
. 진입 시 현재 프레임의 라벨과 영상 이미지를 조회해 캔버스에 표시한다. 라벨은 좌표·색상·출처(수동/자동(YOLO·SAM2))로 구분해 정리한다.
- **수동 라벨링**
. 좌측 도구바에서 선택(S)/바운딩박스(B)/폴리곤(P) 도구로 객체를 그리고, 우측 속성 패널에서 라벨과 좌표(X/Y/W/H)를 편집한다(이미지 경계 안으로 보정). 삭제(Del)·실행취소(Ctrl+Z)는 화면에서 즉시 처리한다.
- **SAM2 자동 추적(KLID-AT-SD-004)**
. 시드 박스와 클래스를 지정해 자동 추적을 실행하면 다음 N개 프레임에 폴리곤이 전파·보간되어 캔버스에 반영된다.
- **객체 외곽 밀착(KLID-AT-SD-005)**
. 클릭 또는 박스 시드로 객체 외곽 경계 자동 밀착을 요청해 폴리곤을 생성한다. (임시 응답인 경우 자동 적용은 차단된다.)
- **정밀도 적용(KLID-AT-SD-006)**
