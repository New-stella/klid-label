## description

시스템 자원(CPU·메모리)의 평균 사용률 80% 이하 (본격 사용시기 모의추정 기준).
- 배치 파이프라인(FFmpeg 프레임 추출·오토라벨링 호출)·Quartz 워커의 자원 관리
- 데이터소스 HikariCP 커넥션 풀 최적화 ⚠ 구 항목 「듀얼 데이터소스(관제/포털) 풀 분리」는 **폐기** — 2026-08-31 「저작도구와 포털은 서로의 DB 에 접근하지 않는다」 확정으로 듀얼 구도가 철거돼 분리할 대상이 없다(정본 INT-009)
- 메모리 누수 등 자원 효율 문제 방지 (장시간 배치·스트리밍 구간 점검)
- 로그아웃/토큰 만료 시 세션 자원 정리
- 단위·통합·성능·부하 테스트를 단계별로 실시하고, 구축 초기부터 완료까지 모니터링·시험 결과를 지속 반영해 보완한다
