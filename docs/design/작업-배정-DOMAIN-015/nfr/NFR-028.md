## description

저작도구 사이트 구성·디자인 설계 기준:
- 사이트 구조와 디자인 방향은 콘텐츠 접근성과 이용 편리성을 기준으로 정한다.
- 특정 브라우저에 종속되지 않는 플랫폼 독립적 사용자 환경을 지원한다.
- 레이아웃: 고정 영역과 팝업을 사용자 편의 관점에서 구성하고, 열린 창은 사용자가 선택하여 닫을 수 있도록 설계한다.
- 색상: 장시간 라벨링·검수 작업의 피로도를 낮추고 가독성을 확보하는 색상 계열로 구성한다.
- 아이콘·버튼: 기능과 용도를 직관적으로 파악할 수 있게 사용한다.
※ 지원 단말은 채널에 따라 다르다 — 포털 채널 화면은 PC·태블릿·모바일을 지원하고, 관제 채널의 라벨링·검수 화면은 정밀 편집 작업 특성상 PC 환경을 기준으로 한다.
