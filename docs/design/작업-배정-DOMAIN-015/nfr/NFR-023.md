## description

저작도구가 반입하는 시스템 소프트웨어의 라이선스·버전 기준:
- 시스템 소프트웨어(WEB·WAS·DB)는 공개 소프트웨어 활용을 원칙으로 하되, 발주기관이 지정한 상용 제품을 도입하는 경우 정품 라이선스와 관리적·기술적·법적 하자 없음을 확인한다.
- 응용 의존 라이브러리는 permissive 라이선스(MIT·Apache-2.0)를 채택하고, 배포 시 소스 공개 의무가 발생하는 라이선스(AGPL 계열)는 배제한다. 객체 탐지·분할 모델도 permissive 백엔드로 구성한다.
- 도입 소프트웨어의 버전은 발주기관과 협의하여 확정하며, 확정 버전은 반입 산출물 명세에 기재한다.
- 의존성 목록과 라이선스는 반입 시점에 고정하여 재현 가능한 형상으로 관리한다.
