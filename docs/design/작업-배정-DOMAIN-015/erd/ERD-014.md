## description

작업 배정 고도화 ERD. 작업 단위 = 영상 1건(LS_DATA_RAW.RAW_SN, 본 ERD 에서는 RAW_DATA_ID 로 참조). 검수자가 작업자에게 라벨링 작업을 영상 단위로 배정하고, 재배정을 포함한 작업 라이프사이클 이벤트(배정·재배정·검수 시작·검수 제출·승인·반려)를 누적한다. 검수자에게는 배정하지 않는다 — 검수는 배정 없이 전체 대기열에서 집어가므로 배정을 인가 축으로 쓰지 않으며, 지금 누가 그 영상을 검수 중인지는 작업 이벤트 로그의 검수 시작 이벤트로 표현한다. (V36 신설, V9 개명) + JPA 엔티티 LsTaskAssignment/LsTaskEventLog. 재배정 전용 이력 테이블은 두지 않는다 — 재배정은 작업 이벤트 로그에 이전·신규 담당자와 수행자를 담아 같은 사실을 이미 남기고, 배정 이력 조회도 영상 식별자로 그 로그를 읽는다. 두 곳에 같은 사실을 쓰면 한쪽만 갱신될 때 서로 어긋난다.
