## description

기존 배정을 재배정한다(작업 이벤트 로그에 재배정 이력 기록). REVIEWER 전용.

[배정의 대상은 작업자뿐] 재배정의 대상도 작업자다 — 검수자를 영상에 배정하는 절차를 두지 않으므로 응답 항목에 검수자 축이 없다(ADR-067). 요청 본문은 원래 작업자만 받았으므로 바뀌지 않는다.

[재배정과 배정 해제는 다르다] 재배정은 담당을 바꾸고, 배정 해제(API-259)는 배정을 없앤다. 담당을 없애려면 재배정이 아니라 해제를 쓴다 — 지금까지는 해제 창구가 없어 재배정이 배정을 되돌리는 유일한 수단이었고, 그래서 담당을 없애는 대신 다른 사람에게 넘기는 것만 가능했다. 그 한계가 영상 제외(ADR-069)에서 드러나 같은 라운드에 해제 창구가 생겼다. 해제에는 이 창구와 다른 축의 거부 조건이 따로 있다 — 검수 대기·검수 중·승인 상태의 배정은 해제되지 않는다(배정이 그 워크플로의 전제다). 이 창구의 거부 조건(완료된 배정은 재배정할 수 없다)과 섞어 적지 않는다. ⚠ 낱말 주의 — 검수 축의 「점유 해제」는 또 다른 개념이다. 그것은 지금 누가 그 영상을 검수 중인지의 표시가 유예 시간이 지나 저절로 풀리는 것이고, 배정 해제는 작업자 배정을 푸는 것이다.
