# 역할에 따라 볼 수 있는 작업 범위가 서버에서 갈린다

## notes

범위를 화면에서 거르면 서버가 보낸 응답 자체에는 남의 작업이 담겨 있어, 화면을 거치지 않는 요청에 그대로 드러난다. 집계도 같은 이유로 서버가 전체를 기준으로 세며, 지금 보고 있는 쪽만 세면 값이 틀린다.

## priority

critical

## scenario

### then

- 자신에게 배정되지 않은 작업은 응답에 담기지 않는다
- 화면이 받은 결과를 다시 거르지 않아도 범위가 맞다

### when

- 작업자가 작업 목록을 조회한다

### given

- 여러 작업자에게 나뉘어 배정된 작업이 있다

## statement

작업자는 자신에게 배정된 작업만, 검수자는 배치가 끝난 작업 전체를 조회하며, 거르기와 정렬과 집계는 서버가 전체를 기준으로 수행한다.
