# 이벤트 유형으로 거르면 같은 표시명 그룹이 모두 걸린다

## notes

선택지만 접고 조회 조건을 코드 하나로 두면 접힌 선택지를 고른 순간 그룹의 나머지 작업이 목록에서 통째로 사라진다. 선택지를 접는 것과 조회 조건을 넓히는 것은 함께 가야 한다. 이 기준은 인가 범위를 넓히지 않는다 — 작업자가 보는 범위는 여전히 자신에게 배정된 것뿐이다.

## priority

critical

## scenario

### then

- 같은 그룹에 속한 다른 코드의 작업도 결과에 담긴다
- 집계도 같은 범위를 센다

### when

- 그 그룹의 코드 하나로 목록을 거른다

### given

- 표시명이 같지만 코드가 다른 이벤트 유형의 작업들이 있다

## statement

이벤트 유형으로 목록을 거를 때 그룹의 어느 코드로 요청하든 표시명이 같은 그룹 전체의 작업이 결과에 담긴다.
