# 이벤트 유형 옵션은 표시명이 같은 유형을 하나로 접는다

## notes

접기 전에 자르면 잘린 구간에만 있던 그룹이 통째로 사라지고, 접은 결과가 상한보다 훨씬 적은데도 일부만 보여준다는 잘못된 안내가 나간다. 그래서 접기와 절단의 순서 자체가 계약이다. 등록되지 않았거나 규격을 벗어난 코드는 선택지에서 빼지 않는다 — 빼면 그 코드를 가진 작업에 필터로 도달할 수 없게 된다.

## priority

high

## scenario

### then

- 같은 표시명이 선택지에 여러 번 나타나지 않는다
- 접은 결과가 상한 이하이면 일부만 표시한다고 알리지 않는다

### when

- 작업 목록의 이벤트 유형 선택지를 조회한다

### given

- 표시명이 같은 이벤트 유형이 여럿 있는 데이터가 있다

## statement

이벤트 유형 선택지는 표시명이 같은 유형들을 하나로 접어 보여주며, 개수 상한은 접은 뒤에 적용한다.
