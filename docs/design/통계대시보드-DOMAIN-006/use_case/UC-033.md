# 전체 구축 현황 조회 — 검수완료 기준과 전체 기준 병기

## goal

검수완료(APPROVED) 영상만 집계한 확정 기준 수치를 전체(진행중 포함) 수치와 함께, 관제 이벤트 유형의 표시명 그룹 기준으로 확인해 학습데이터 산출물 목표 대비 진척과 병목을 파악한다.

## actor

검수자(REVIEWER)

## title

전체 구축 현황 조회 — 검수완료 기준과 전체 기준 병기

## status

draft

## priority

must

## frequency

상시

## main_flow

### [1]

- **step**: 1
- **actor**: 검수자(REVIEWER)
- **action**: 전체 구축 현황 화면에 진입한다

### [2]

- **step**: 2
- **action**: 시스템이 검수완료 기준 누적 건수(이미지·영상)와 전체 누적 건수를 함께 조회한다

### [3]

- **step**: 3
- **action**: 시스템이 관제 이벤트 유형 분포를 표시명이 같은 상세 유형코드끼리 대표코드 한 칸으로 합산하여 검수완료 기준·전체 기준 두 축으로 조회한다

### [4]

- **step**: 4
- **action**: 시스템이 처리 현황 5종 카운트(대기/승인/반려/진행중/검수대기)와 작업자별 표를 조회한다

### [5]

- **step**: 5
- **actor**: 검수자(REVIEWER)
- **action**: 검수완료 기준 수치를 주 수치로, 전체 수치를 보조로 읽어 산출물 목표 대비 진도와 병목을 판단한다

## description

검수자가 전체 구축 현황 화면에서 검수완료(APPROVED) 영상만 집계한 확정 기준 수치와, 검수 여부와 무관한 전체 누적 수치를 함께 확인한다. 이벤트 유형 분포는 관제 상세 유형코드 중 표시명이 같은 것끼리 대표코드 한 칸으로 합산되어 표시되며, 데이터가 없는 카테고리도 0건으로 노출된다. 검수완료 기준 수치가 주 수치이고 전체 수치는 보조로 병기된다 — 둘을 섞어 하나로 읽으면 산출물 달성률이 부풀려진다. 확정 기준 이미지 건수와 프레임 단위 분포는 폐기된 프레임을 세지 않는다 — 폐기된 프레임은 산출물과 데이터마트 노출에서 빠지므로 확정 분량에도 들어가지 않는다. 전체 누적 수치는 수집한 전체 분량이라는 다른 축이라 걸러내지 않는다.
