## description

검수자가 전체 구축 현황 화면에서 확정 기준 수치와 전체 누적 수치를 함께 확인하고, 화면이 보여준 다섯 축을 한 파일로 내려받는 흐름을 그린다.

두 수치는 축이 다르다. 확정 기준은 검수완료된 영상만 세고 전체 기준은 진행중을 포함한다. 둘을 섞어 하나로 읽으면 산출물 달성률이 부풀려지므로 확정 기준을 주 수치로 두고 전체를 보조로 병기하며, 확정 기준 수치는 항상 대응하는 전체 수치 이하다.

이벤트 유형 분포는 상세 유형코드 그대로가 아니라 표시명이 같은 것끼리 대표코드 한 칸으로 접어 보인다. 대표코드는 그룹 안의 가장 작은 유형코드이며 실행마다 흔들리면 저장된 프리셋 매칭이 흔들린다. 집계는 대표코드 하나가 아니라 그룹에 속한 유형코드 전부로 하며, 데이터가 없는 카테고리도 0건으로 채운다.

확정 기준 이미지 건수와 프레임 단위 분포에서는 폐기된 프레임을 빼고, 전체 누적 수치에서는 걸러내지 않는다. 폐기된 프레임은 산출물과 데이터마트 노출에서 빠지므로 확정 분량에도 들어가지 않지만, 전체 누적은 수집한 전체 분량이라는 다른 축이기 때문이다.

내려받기는 조회와 갈라 세우지 않고 같은 흐름 안에 둔다. 둘이 한 사람의 이어진 동선이고 화면 값과 파일 값이 일치해야 한다는 요구가 같은 흐름 안에서만 검증되기 때문이다. 권한이 없거나 허용 목록 밖 집계 기간으로 요청하면 파일을 내보내지 않고 거부하며, 거부 응답이 요청한 값을 그대로 되비추지 않는다.
