## description

개발된 소스코드 전체에 대해 보안약점 진단·모의해킹 등 취약점 점검을 1회 이상 실시하고 지적사항을 보완 완료한다. 웹 취약점 표준 항목(공통 웹 취약점·국가 권고 항목) 기준으로 수행한다. 점검은 외부 기관을 통해서도 실시하며, 소스코드 보안약점 진단항목은 소프트웨어 개발보안 가이드를, 모의해킹 점검항목은 공개 웹 취약점 목록·국가 권고 항목·전자정부 웹 취약점 표준 점검 항목을 따른다. 점검 결과에 따른 후속 보완조치를 수행하고 완료를 확인한다.
