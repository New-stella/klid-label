# 짝이 없거나 개수가 다른 산출물은 경고만 하고 실제 파일 기준으로 적재한다

## priority

high

## scenario

### then

- 검사 응답에 두 경고가 모두 담긴다.
- 적재는 거부되지 않는다.
- 짝 문서가 없는 이미지도 라벨이 없는 프레임으로 적재된다.
- 적재된 프레임 수는 문서가 선언한 수가 아니라 실제 파일 수와 같다.

### when

- 그 폴더를 검사하고 적재한다.

### given

- 산출물 폴더에 짝 문서가 없는 이미지가 섞여 있다.
- 문서가 선언한 프레임 수가 실제 파일 수보다 많다.

## statement

짝 문서가 없는 이미지가 있거나 문서가 선언한 건수와 실제 파일 수가 달라도 적재를 막지 않고, 실제 파일을 기준으로 적재하며 그 사실을 경고로 알린다.
