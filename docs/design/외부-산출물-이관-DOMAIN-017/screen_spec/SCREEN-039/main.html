① 가져오기 입력

설명

산출물 폴더 경로와 원본 영상 경로를 받고, 이 산출물의 비식별 여부를 고르는 자리다. 영상 경로는 선택이며 비우면 프레임과 라벨만 가져온다. 비식별 여부는 기본이 원본이다.

Components

  • Input — 산출물 폴더 경로
  • Input — 원본 영상 경로 (선택)
  • RadioGroup — 원본 / 비식별 완료
  • Alert — 비식별 완료 선택 시 주의
  • Button — 검사

API

② 미리보기

설명

검사 결과를 보여준다. 경고는 적재를 막는 것과 알리기만 하는 것이 구분된다. 선언된 프레임 수와 실제 파일 수가 다르면 둘 다 보여주고 실제 파일을 기준으로 가져온다.

Components

  • KeyValue — 영상 정보
  • Stat — 프레임 수 / 라벨 수
  • Alert — 적재를 막는 문제
  • Alert — 알리기만 하는 문제

API

  • API-205

③ 분류 대응 확정

설명

처음 보는 분류만 모아 저작도구 라벨과 이벤트 유형에 연결하게 한다. 이름이 비슷한 후보를 미리 골라 두지만 사람이 확인해야 확정된다. 한 번 확정한 대응은 다음 산출물부터 자동으로 적용되어 이 표에 다시 나오지 않는다.

Components

  • Table — 미등록 분류 목록
  • Select — 연결할 대상
  • Button — 대응 확정

④ 적재 실행

설명

미리보기와 대응을 확인한 뒤 실제로 가져오는 자리다. 적재를 막는 문제가 남아 있으면 버튼이 비활성이다. 끝나면 결과 요약과 함께 검수 목록으로 가는 길을 제공한다.

Components

  • Checkbox — 경고 확인
  • Button — 가져오기
