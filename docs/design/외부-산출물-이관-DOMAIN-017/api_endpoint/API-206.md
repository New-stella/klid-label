## description

검사를 통과한 산출물 폴더를 실제로 적재한다. 영상 한 건과 그에 딸린 프레임·라벨이 만들어지고, 이관 이력이 함께 남는다.

적재된 영상은 곧바로 검수 대기 상태가 된다. 작업자 배정은 필요하지 않으며, 검수자가 바로 검수를 시작하거나 고칠 것이 있으면 그때 배정한다.

비식별 상태는 요청에서 지정한다. 이미 비식별이 끝난 산출물이라고 지정하면 그대로 받아들이고, 원본이라고 지정하면 적재는 하되 비식별이 끝나기 전까지 검수 승인을 막는다. 기본값은 원본 쪽이다. 잘못 고르면 비식별되지 않은 화면이 학습데이터로 나가기 때문이다.

적재는 비식별 처리를 불러오지 않는다. 외부 산출물은 그 처리가 이미 끝난 상태로 오거나, 원본이라면 외부에서 다시 처리해 가져오는 것이 정상 동선이기 때문이다.

같은 산출물을 두 번 적재할 수 없다. 이미 가져온 것이면 기존 영상을 알려주며 거부한다.

검수자만 호출할 수 있다.
