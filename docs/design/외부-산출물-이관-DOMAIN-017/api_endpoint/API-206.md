## description

검사를 통과한 산출물 폴더를 실제로 적재한다. 영상 한 건과 그에 딸린 프레임·라벨이 만들어지고, 이관 이력이 함께 남는다.

적재된 영상은 곧바로 검수 대기 상태가 된다. 작업자 배정은 필요하지 않으며, 검수자가 바로 검수를 시작하거나 고칠 것이 있으면 그때 배정한다.

비식별 상태는 요청에서 지정한다. 이미 비식별이 끝난 산출물이라고 지정하면 함께 받은 영상을 곧 비식별 영상으로 보고, 비식별 단계를 다시 밟지 않으며 검수 승인도 보류하지 않는다. 원본이라고 지정하면 적재는 하되 검수 승인을 보류한다. 기본값은 원본 쪽이다. 잘못 고르면 비식별되지 않은 화면이 학습데이터로 나가기 때문이다.

원본으로 지정한 경우 보류가 풀리는 길은 영상 파일을 함께 주었는지에 따라 갈린다. 영상 파일을 함께 준 경우에는 저작도구가 그 영상에 비식별 단계를 태우고, 그 비식별이 성공으로 기록되면 보류가 풀린다. 영상 파일 없이 프레임만 가져온 경우에는 비식별할 대상 영상이 없어 저작도구가 비식별 단계를 태우지 않는다. 이때는 외부에서 비식별한 산출물을 받아 기록하는 별도 행위가 보류를 푼다. 그 별도 행위 자체는 이 계약의 범위 밖이다.

같은 산출물을 두 번 적재할 수 없다. 이미 가져온 것이면 기존 영상을 알려주며 거부한다.

검수자만 호출할 수 있다.
