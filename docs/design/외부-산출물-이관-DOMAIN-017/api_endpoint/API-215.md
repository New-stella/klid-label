## description

영상 파일 없이 프레임만 가져온 산출물의 검수 승인 보류를 푼다. 외부에서 이미 비식별한 산출물을 받아 그 사실을 기록하는 행위이며, 이 계약이 비식별을 수행하지는 않는다.

이 기록은 비식별 산출물이 실제로 존재하는지 확인한 뒤에만 성립한다. 요청이 알려준 위치를 허용된 저장소 범위 안에서 확인하고, 그 산출물이 실재하지 않으면 아무것도 기록하지 않고 거부한다. 확인 없이 기록만 바꿀 수 있으면 처리되지 않은 산출물이 검수 승인을 통과하기 때문이다.

확인을 통과하면 그 영상의 비식별 처리 이력에 행을 남기고 거기에 비식별 산출물의 위치를 적재한다. 이어서 검수 워크플로 상태의 비식별화완료여부를 완료로 바꾼다. 그 값이 완료가 되면 승인 보류가 풀려 검수 승인이 정상으로 진행된다.

이 계약은 승인 보류를 푸는 두 갈래 가운데 프레임만 가져온 쪽을 맡는다. 영상 파일을 함께 준 산출물은 저작도구가 그 영상에 비식별 단계를 태우고 그 성공 기록으로 보류가 풀리므로 이 계약을 쓰지 않는다.

대상 영상이 외부 산출물 이관 경로로 들어온 것이 아니면 거부한다. 이 계약은 그 경로로 원본이라고 지정해 들어온 영상의 보류를 푸는 수단이며, 다른 경로로 들어온 영상의 비식별 사실을 대신 적는 자리가 아니다. 어느 경로로 들어왔는지는 뒤에 달라지지 않으므로 다시 시도해도 결과가 같다.

이미 비식별 완료로 기록된 영상에는 다시 기록하지 않는다. 보류가 이미 풀려 있어 풀 것이 없고, 두 번 기록하면 어느 산출물이 그 영상의 비식별 결과인지 이력에서 갈린다. 비식별이 끝난 것으로 지정해 가져와 애초에 보류가 서지 않은 영상도 같이 다룬다.
