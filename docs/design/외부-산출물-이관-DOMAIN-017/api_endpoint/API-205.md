## description

지정한 폴더를 훑어 가져올 수 있는 내용과 경고를 돌려준다. 이 요청은 아무것도 저장하지 않는다.

검사하는 것은 네 가지다. 첫째 폴더가 허용된 위치 안에 있는가, 둘째 산출물 문서를 읽을 수 있는가, 셋째 이미 가져온 산출물인가, 넷째 아직 대응이 정해지지 않은 분류가 남아 있는가이다.

경고에는 적재를 막지 않는 사항만 담는다. 짝이 없는 이미지가 있거나 문서가 선언한 건수와 실제 파일 수가 다른 것이 여기에 해당하며, 알리되 진행할 수 있다. 적재를 막는 사유는 경고가 아니라 별도로 돌려준다. 대응이 정해지지 않은 분류 목록과 이미 가져온 산출물 정보를 각각 따로 담고, 지금 상태로 적재할 수 있는지는 별도의 적재 가능 여부로 알린다.

경로를 주소줄이 아니라 본문으로 받는다. 경로에 구분자와 공백이 섞여 주소줄에 넣으면 기록과 중간 경유지에 그대로 남기 때문이다. 저장하는 일이 없으므로 여러 번 보내도 결과가 같다.

검수자만 호출할 수 있다.
