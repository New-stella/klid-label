## description

지정한 폴더를 훑어 가져올 수 있는 내용과 경고를 돌려준다. 이 요청은 아무것도 저장하지 않는다.

검사하는 것은 네 가지다. 첫째 폴더가 허용된 위치 안에 있는가, 둘째 산출물 문서를 읽을 수 있는가, 셋째 이미 가져온 산출물인가, 넷째 아직 대응이 정해지지 않은 분류가 남아 있는가이다.

허용 저장소 범위 판정은 폴더 탐색과 완전히 같은 규칙을 따른다. 이 창구가 자기 허용 목록을 따로 갖지 않는다 — 목록이 두 벌이 되면 한쪽만 넓어져 한 창구에서 막히는 위치가 다른 창구에서 열린다. 판정은 허용 저장소 루트의 표기와 루트가 실제로 가리키는 자리를 둘 다 허용 범위의 시작점으로 인정한다. 그래서 폴더 탐색이 돌려준 위치를 그대로 이 창구에 보내도 통과한다 — 허용 저장소 루트 자체가 바로가기라서 그 값이 설정에 적힌 표기와 달라지는 경우에도 마찬가지다. 넓어지는 것은 시작점의 표기뿐이다 — 위로 거슬러 올라가는 표기는 여전히 거부하고, 허용 범위 밖을 가리키는 위치도 여전히 거부하며, 허용 범위 안의 이름이라도 실제로는 범위 밖을 가리키는 바로가기면 여전히 거부한다. 바로가기가 없는 저장소에서는 판정 결과가 종전과 완전히 같다. 이 축은 허용 범위의 시작점을 읽는 방식에 관한 것이며, 아래의 폴더 안 항목을 세는 규칙과는 다른 자리다.

경고는 알려야 하는 사항이며 그중 일부는 적재를 막는다. 막지 않는 예로는 짝이 없는 이미지, 문서가 선언한 건수와 실제 파일 수의 차이, 폴더 안의 바로가기를 건너뛴 사실이 있다. 막는 예로는 훑기 상한을 넘은 경우, 식별자를 만들 수 없는 경우, 프레임이 한 건도 없는 경우가 있다. 이 열거는 예시이며 전수 목록이 아니다. 적재할 수 있는지는 응답의 적재 가능 여부 필드 하나로만 판정하고, 그와 별도의 차단 표시를 두지 않는다. 판정 지점을 둘로 두면 두 값이 어긋날 때 어느 쪽이 진실인지 알 수 없기 때문이다. 대응이 정해지지 않은 분류 목록과 이미 가져온 산출물 정보는 각각 따로 담는다.

폴더 안에 다른 자리를 가리키는 바로가기가 있으면 따라가지 않고 건너뛰며, 건너뛴 사실을 반드시 경고로 알린다. 조용히 빠뜨리지 않는다. 산출물은 외부에서 만들어진 것이라 그대로 믿을 수 없고, 폴더 경로를 한 번 검사하는 것만으로는 폴더 안의 항목이 허용 범위 밖을 가리키는 것을 막지 못하기 때문이다. 이 경고는 적재를 막지 않는다.

경로를 주소줄이 아니라 본문으로 받는다. 경로에 구분자와 공백이 섞여 주소줄에 넣으면 기록과 중간 경유지에 그대로 남기 때문이다. 저장하는 일이 없으므로 여러 번 보내도 결과가 같다.
