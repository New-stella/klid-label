## description

마킹 완료 후 영상이 배치 대기로 전이하고 배치 오케스트레이션이 잔여 배치를 실행한다. 잔여 배치 파이프라인: VLM 시계열 → 마킹위치 프레임추출 → YOLO → SAM2 → 트랙보간. 단계 순서는 선언적 파이프라인 설정 한 곳에서 재배치한다.

[상태 전이] 두 테이블의 책임이 다르다.
· LsDataRaw.dataSttsCd (배치 단계 축): PENDING → MARKING_READY → COMPLETED.
· LsRawDataStatus.dataSttsCd (작업·검수 워크플로우 축): 배치 시작 시 PROCESSING, 배치 완료 시 ASSIGNED 복귀, 실패 시 FAILED.
작업 상태를 배치 완료로 COMPLETED 로 올리면 검수 제출(ASSIGNED→PENDING)이 상태머신에서 차단되므로 그렇게 두지 않는다. 이 축의 검수 종결값은 APPROVED 이며 검수 승인에서만 전이한다 — COMPLETED 를 두지 않는다.

[비식별 단계 위치] 비식별은 이 배치 안이 아니라 적재 직후 VideoIngested(EVT-005)가 돌리는 pre-marking 단계다. post-marking 배치에는 두지 않는다.

## side_effects

- 배치 파이프라인 실행
- LsRawDataStatus.dataSttsCd → PROCESSING (시작) / ASSIGNED (완료 복귀) / FAILED (실패)
- LsDataRaw.dataSttsCd → COMPLETED (배치 단계 마감)
