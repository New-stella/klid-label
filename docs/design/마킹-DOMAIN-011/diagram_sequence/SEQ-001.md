## description

영상 1차 적재부터 오토라벨링까지의 파이프라인. 적재는 관제서버가 저작도구 소유 인입 테이블 LS_DATA_INGEST 에 학습용 영상 메타를 직접 INSERT(PRCS_STTS_CD='PENDING')하고, 저작도구 주기 배치(ControlTrainingVideoScanJob, 60초 간격 폴링)가 미처리 행을 픽업해 TrainingVideoIngestService 가 LS_DATA_RAW(PENDING)로 적재하는 방식이며, inbound 연동 API·M2M 인증은 쓰지 않는다(관리 화면 TUS 업로드는 1차 적재 경로가 아니다). 단계 순서는 선언적 파이프라인(BatchPipelineConfig)이 소유한다 — pre-marking=[DEIDENTIFY], post-marking=[MARKING, VLM, FRAME_EXTRACT, YOLO, SAM2, INTERPOLATE]. ①비식별이 선두 단계로 적재 직후 자동 트리거되며(VideoIngestedEvent→IngestDeidentifyBridge(AFTER_COMMIT)→AsyncDeidentifyRunner→DeidentifyStep) PRVC_TYPE_CD 게이팅 없이 전체 영상이 대상이다. 성공 시 dataSttsCd=MARKING_READY 로 전이해 마킹 진입을 허용한다. ②마킹은 비식별 영상 대상이며 마킹 완료(MarkingCompleted → MarkingBatchBridge AFTER_COMMIT)가 잔여 배치를 비동기로 기동한다. ③VLM 시계열 위탁은 파이프라인 스레드를 붙잡지 않는 논블로킹 제출(subscribe)이고 결과는 POST /v1/vlm/callback 으로 별도 수신하며, 신호가 오지 않으면 ACK 창(기본 30분)·콜백 창(기본 360분) 2단 미결 스위퍼가 회수한다. ④프레임 추출은 마킹 위치 기반 원본+비식별 2벌, YOLO/SAM2 는 원본에만 실행하고 좌표를 비식별본과 공유한다. 완료 시 LS_DATA_RAW.dataSttsCd=COMPLETED 로 마감하고 LS_RAW_DATA_STATUS 는 ASSIGNED 로 복귀시킨다(작업 상태의 검수 종결값은 APPROVED 이며 검수 승인 시점에만 전이한다 — 배치 완료가 작업 상태를 점프시키면 검수 제출 ASSIGNED→PENDING 이 상태 머신에서 차단된다). 마킹 중 비식별 누락 신고는 배치 단계가 MARKING_READY 일 때만 접수되고 자동 재비식별 큐는 없다 — 외부 솔루션 수동 비식별 후 resolve 하면 MARKING_READY 로 되감아 재마킹한다. 시계열 위탁에는 그 앞에 전체 건너뛰기 스위치 판정이 있다 — 켜져 있으면 위탁하지 않고 건너뜀 표식만 남기며 외부 호출이 한 번도 일어나지 않는다. 사유는 설정값이 그대로 표식에 실리고, 그 영상·묶음에 사람이 남긴 표식이 이미 있으면 자동 표식이 덮지 않는다.
