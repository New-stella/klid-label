## scenario

### then

- 마킹 단계 신고는 412로 거부되고 단계를 구분하지 않는 단일 문구로 안내된다(CWE-209)
- 화면은 MARKING_READY가 아니면 진입 자체를 막는다
- 비식별 미완료 영상 스트리밍은 404로 원본 노출을 차단한다

### when

- 비-MARKING_READY 상태에서 마킹 단계 신고를 직접 호출하거나, 비식별 미완료 영상의 스트리밍을 요청한다

### given

- 영상이 MARKING_READY가 아니거나 비식별본이 유효하지 않다

## statement

배치 단계가 MARKING_READY가 아닌 상태의 마킹 단계 신고는 412 PRECONDITION_FAILED로 거부하되 PROCESSING/COMPLETED/FAILED/PENDING을 구분하지 않는 단일 문구로 안내하고(응답이 처리 단계 오라클이 되지 않게 — CWE-209), 화면은 MARKING_READY가 아니면 마킹 화면 진입 자체를 막는다(편집기도 신고 버튼도 열리지 않는다). 비식별본이 유효하지 않은 영상의 스트리밍 요청은 404로 원본 노출을 차단한다 — 스트리밍은 항상 비식별 영상만 서빙한다. 화면 선차단과 서버 거부는 서로를 대체하지 않는다.
