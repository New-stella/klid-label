## description

자동/수동 이벤트 시점 마킹 생성과 마킹 완료 시 잔여 배치 트리거(조회·수정·삭제 엔드포인트는 폐기되어 현재는 생성 1건만 활성이다). MarkingController(/v1/videos/{rawSn}/markings) → MarkingService → LsMarkingRepository. 완료 시 MarkingService 가 MarkingCompletedEvent(EVT-001)를 발행하면 MarkingBatchBridge(AFTER_COMMIT)가 잔여 배치를 비동기로 시작한다.

[★전제 — 비식별 선행] 마킹은 선두 비식별이 성공해 MARKING_READY 가 된 뒤에만 열리며, 작업자는 원본이 아닌 비식별 영상을 보며 마킹한다. 잔여 배치 진입은 부모의 deIdntfYn='Y' 가드를 통과해야 한다. 영상 스트리밍은 항상 비식별본만 서빙하고 비식별 미완료면 404 로 원본 노출을 막는다.

[신고] 마킹 중 개인정보 노출을 발견하면 rawSn 기준 비식별 누락 신고를 접수한다(POST /v1/videos/{rawSn}/deident-report).
