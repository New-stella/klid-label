- **description**: 영상별 자동/수동 이벤트 식별 마킹 정보. 영상 1건(RAW_SN)에 대해 N건의 마킹이 생성될 수 있으며, 마킹 완료 시 VLM 시계열 위탁 요청에는 frame_policy(프레임 선택 정책)만 반영된다 — 이벤트명·영상 경로·마킹 원문 배열은 위탁 규격 밖이라 싣지 않는다. 상태 전이: RESERVED → PENDING → VLM_REQUESTED → {VLM_COMPLETED | VLM_FAILED}, PENDING/VLM_REQUESTED → SKIPPED(배치 skip 종결. 비식별 신고 해소 후 재마킹 시 활성 마킹을 종결시켜 부분 유니크 제약 UK_LS_MARKING_RAW_ACTVTN(RAW_SN, WHERE STTS_CD IN ('PENDING','VLM_REQUESTED'))을 해제하는 경로 포함), RESERVED → SKIPPED(적용하지 못한 예약을 마감하는 경로). RESERVED 는 외부에서 받은 마킹을 영상 적재 시점에 담아 두는 시작 상태이며 그 부분 유니크 제약이 보는 값이 아니다.

## description

영상 마킹(LS_MARKING) 물리 ERD. 선두 비식별이 끝난 영상을 대상으로 진행하는 자동/수동 이벤트 식별 마킹 정보를 보관한다. 자동(AUTO) 모드는 프레임간격수(FRME_INTV_NOCS) 기반으로 marks(프레임 인덱스/타임스탬프)를 생성하고, 수동(MANUAL) 모드는 작업자가 키보드 단축키로 선택한 marks 배열을 저장한다. 마킹 완료 이벤트를 트랜잭션 커밋 이후에 받아 잔여 배치(VLM 시계열 위탁 → 프레임 추출 → 오토라벨링 → 트랙 보간)를 트리거한다. 행안부 공통표준 약어 정합 적용(EVENT_NAME→EVNT_NM, MARKS→MARK_CN, STATUS→STTS_CD 등). (V45 신설) + JPA 엔티티 LsMarking.
