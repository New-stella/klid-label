## description

학습데이터 구축 관련 품질 관리 기준 수립 — 수집부터 제작, 검수까지 각 단계별 수행기준 수립 및 품질 관리 방안 제시 (RFP p46, QUR-03).

**해결방안(확정)**: 학습데이터 수집(업로드 검증)·제작(비식별→마킹→오토라벨링)·검수(검수자 승인/반려) 단계별 수행기준을 수립하고, 승인 시점 라벨 스냅샷 버전관리(LS_LABEL_VERSION, SHA-256 해시)와 단계별 품질지표(반려율 등)로 품질을 관리한다.

**제약사항**: 검수 승인(APPROVED) 데이터만 학습데이터 확정.
