## description

저작도구가 외부 VLM 서비스에 영상 시계열 메타(설명) 생성을 위탁하는 outbound 호출. 결과 상세는 콜백(INT-003)으로 비동기 수신한다.

## 실측 계약 (2026-08-15 확인)
- `POST {vlm.client.url}/v1/videovlm/verify`
- 요청 `VlmTimeseriesRequest`: `request_id` · `event_type` · `media{type, source_type, path, frame_policy{mode, framerate, selected_frames}}` · `callback_url`
- 동기 응답 `VlmTimeseriesResponse`: `request_id` · `status` (정상값은 `accepted` 만 인정) → 즉시 파이프라인 다음 단계로 진행하고 결과 상세는 콜백으로 받는다
- 호출 주체: 배치 파이프라인의 시계열 위탁 단계
- 인증: `vlm.client.token` 설정 시에만 `Authorization: Bearer` 부착(조건부)
- 파일 본문 미전송 — `media.path` 로 경로만 전달
- 신고 구간(`DE_IDNTF_YN='F'`) 위탁은 스텝 내부에서 **보류(SKIPPED)** — 실패가 아니라 보류이며, 해소 시 자동으로 재위탁한다(멱등 조건: 시계열 메타 0건)

## 신뢰성 정책 (실측값)
- HTTP 클라이언트 타임아웃 `vlm.client.timeout-seconds` 기본 **10s**, 배치측 block **45s**
- Retry `vlmClient`: 3회, 1s, ×2 backoff — **4xx 는 재시도·서킷 집계 제외**(비재시도 오류로 분류)
- CircuitBreaker `vlmClient`: 50% / window 10 / min-calls 5 / open 30s

## ★★ 활성화 상태 — 설정 토글은 폐지됐다 (ADR-049)
연동 여부를 설정으로 켜고 끄던 토글은 폐지됐다. 연동 주소가 주입되어 있지 않으면 위탁은 **실패**하며 조용히 건너뛰지 않는다. 구 동작은 토글이 꺼져 있으면 외부 호출 없이 즉시 건너뛴 것으로 처리하고 아무 기록도 남기지 않았는데, 그 기본값이 비활성이라 시계열이 꺼진 채로 납품될 수 있었다.

벤더 미연동 구간의 운영은 **검수자가 사유를 남기고 누르는 시계열 묶음 스킵**으로 처리한다(단건·일괄 모두 제공). 설정으로 끄는 것과 달리 누가 언제 왜 건너뛰었는지가 배치 이력에 남고, 벤더 연동 시점에 해제·재수행으로 되돌릴 수 있다.

⚠ **미연동 구간에는 먼저 스킵한다** — 스킵 없이 돌려 실패시키면 마킹이 위탁 실패 상태로 종결되고, 마킹 상태 전이는 위탁 대기 상태에서만 일어나므로 이후 재수행해도 마킹 표시가 실패로 남는다(시계열 적재·검수 진입·산출물 재생성은 정상 동작한다).

| 환경 | 연동 대상 |
|---|---|
| local | 목업 벤더 서버 |
| dev | 목업 벤더 서버 |
| stg | 실제 연동 주소 주입 필요 |
| prd | 실제 연동 주소 주입 필요 — 콜백 허용 출처 설정이 선행돼야 한다 |
