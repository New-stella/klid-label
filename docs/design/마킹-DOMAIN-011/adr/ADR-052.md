# 외부 제공 이벤트 마킹은 업로드 시 예약하고 비식별 완료 후 적용한다

## context

외부에서 이벤트 마킹이 끝난 영상을 받는다. 마킹은 비식별된 영상을 대상으로 하도록 정해져 있고 비식별은 적재 뒤 비동기로 수행되므로, 영상을 올리는 시점에는 마킹을 곧바로 활성화할 수 없다. 한편 외부가 함께 주는 프레임 이미지는 비식별 이전의 원본 화면이다.

## decision

### chosen_option

업로드 시 마킹을 예약 상태(RESERVED)로 만들어 두고, 비식별이 끝나 영상이 마킹 가능 상태가 되면 활성 상태로 전이시켜 이후 처리를 시작한다. 외부가 준 프레임 이미지는 적재하지 않고 시점 위치 정보로만 쓰며, 마킹 방식 코드는 수동(MANUAL)을 쓴다. 외부 마킹을 받아들이는 것은 사람이 영상을 직접 적재하는 경로 전용이다.

### justification

업로드 시 마킹을 예약 상태(RESERVED)로 만든다. 이 상태는 활성 마킹으로 세지 않으므로 영상당 활성 마킹 1건 제약을 점유하지 않고, 이후 처리도 이 마킹을 가져가지 않는다.

비식별이 끝나 영상이 마킹 가능 상태가 되면 예약된 마킹을 활성 상태로 전이시키고 이후 처리를 시작한다.

외부가 준 프레임 이미지는 적재하지 않는다. 그 이미지는 비식별 이전 원본이고, 프레임 추출 단계가 같은 시점 위치에서 원본과 비식별본 두 벌을 다시 만든다. 외부 파일은 시점 위치 정보로만 쓴다.

마킹 방식 코드는 수동(MANUAL)을 쓴다. 외부가 준 시점 배열의 구조가 수동 마킹과 같기 때문이다.

외부 마킹을 받아들이는 것은 사람이 영상을 직접 적재하는 경로 전용이다. 관제 인입을 재현하는 경로는 관제가 마킹을 보내지 않으므로 대상이 아니다. 그 경로로 무엇을 어떻게 받아들이는지는 별도 결정이 정하며, 이 결정은 받아들인 마킹을 언제 활성화하는지만 정한다.

## consequences

### risks

- 비식별이 끝내 실패하면 예약된 마킹이 남으므로 회수 장치가 함께 있어야 한다

### neutral

- 예약 상태는 기존 마킹 원장에 담기므로 저장 위치와 필수 항목은 기존 규칙을 그대로 따른다

### negative

- 사람이 찍은 마킹과 외부가 준 마킹이 마킹 방식 코드로는 구분되지 않는다
- 관제 인입 재현 경로에서는 이 기능을 쓸 수 없다

### positive

## considered_options

### 업로드 시 예약하고 비식별 완료 후 적용한다

**cons**:

- 비식별이 끝내 실패하면 예약된 마킹이 남으므로 회수 장치가 함께 있어야 한다
- 사람이 찍은 마킹과 외부가 준 마킹이 마킹 방식 코드로는 구분되지 않는다

**pros**:

- 새 테이블과 이행 스크립트가 필요 없다
- 예약 상태는 활성 마킹으로 세지 않으므로 영상당 활성 마킹 1건 제약을 점유하지 않는다. 비식별이 실패해도 그 영상을 다시 마킹할 수 있다
- 마킹 생성의 사전 조건을 그대로 둔 채 외부 마킹을 받아들인다

- **description**: 업로드 시 마킹을 예약 상태로 만들어 두고, 비식별이 끝나 영상이 마킹 가능 상태가 되면 활성 상태로 전이시켜 이후 처리를 시작한다.

### 업로드 시점에 마킹을 곧바로 활성화한다

**cons**:

- 활성 마킹 1건 제약을 점유해, 비식별이 실패하면 다시 마킹할 수 없게 된다

**pros**:

- 예약 상태를 따로 두지 않는다

- **description**: 영상을 올리는 그 자리에서 마킹을 활성 상태로 만든다.

### 마킹 생성의 사전 조건을 이 경로에만 완화한다

**cons**:

- 그 조건은 평가 순서까지 고정된 계약이라, 한 곳을 열면 비식별되지 않은 영상에 마킹하는 길이 열린다

**pros**:

- 예약 상태를 새로 두지 않고 기존 흐름을 그대로 쓴다

- **description**: 외부 마킹을 받는 경로에 한해 마킹 생성의 사전 조건을 풀어 준다.

### 예약을 담을 별도 원장을 새로 만든다

**cons**:

- 사람이 직접 올리는 경로에서는 영상 식별자가 즉시 생겨 기존 마킹 원장의 필수 항목을 모두 채울 수 있으므로 불필요하다

**pros**:

- 예약을 기존 마킹 원장과 섞지 않는다

- **description**: 예약된 마킹을 기존 마킹 원장과 분리해 별도 원장에 담는다.

### 비식별 뒤 사람이 다시 마킹한다

**cons**:

- 외부가 프레임 단위로 찍어 둔 위치를 사람이 재현할 수 없어 인계의 의미가 사라진다

**pros**:

- 새로 만들 것이 없다

- **description**: 외부 마킹을 쓰지 않고 비식별이 끝난 뒤 사람이 마킹을 다시 찍는다.
