## description

라벨링 화면의 AI 탐지 팝업용 조회다. 활성 라벨 마스터 목록과 각 라벨의 COCO 검출 매핑(DTCT_TYPE_CD) 여부(mapped)를 반환한다.

AI 탐지 후보는 라벨 마스터 기준으로 노출하되 검출 매핑이 있는 라벨만 실제 검출할 수 있다 — 매핑된 라벨만 선택 가능하게 하고 미매핑은 표시하되 비활성화한다. 목록에서 아예 숨기지 않는 것은 운영자가 '왜 이 라벨로는 탐지가 안 되는지' 를 알 수 있게 하기 위함이다.

이 응답은 표시·선택 후보일 뿐이다. 실제 검출 대상은 서버가 신뢰 경계에서 마스터 매핑과 교집합을 다시 계산하므로 화면이 보낸 목록을 그대로 신뢰하지 않는다.

[소비처] 내부 라벨링 화면의 AI 탐지 팝업과 포털 라벨링 화면의 AI 탐지 팝업이 이 조회를 쓴다. 포털 화면에서 고른 대상 라벨로 실제 탐지를 실행하는 창구는 포털 AI 탐지 창구 [[API-255]] 다.
