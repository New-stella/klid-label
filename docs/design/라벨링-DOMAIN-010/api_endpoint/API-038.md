## description

라벨링 프리셋을 생성한다. REVIEWER 전용.

등록이 성공하면 그 이벤트유형에 대해 보류돼 있던 오토라벨의 재개가 촉발된다(ADR-054). 재개는 보류 이력이 있고 지금 그 프리셋이 실효할 때만 일어나며, 뒤 조건이 멱등을 담당한다 — 이미 재개된 영상을 다시 촉발해도 중복 적재되지 않는다. 재개는 응답을 지연시키지 않는다(등록 응답은 재개 완료를 기다리지 않는다). 재개가 실패해도 프리셋 등록은 되돌아가지 않는다. 보류 골격과 보류 사유 구분은 ADR-054 가 정하며 여기서 다시 정의하지 않는다.

담긴 라벨 중 검출 클래스에 매핑된 것이 하나도 없는 프리셋도 저장은 성공한다 — 거부하지 않고, 그 프리셋이 오토라벨링에 적용되지 않는다는 것만 경고한다. 운영자가 나중에 라벨 마스터에 매핑을 지정하면 그때 실효해지므로 그 동선을 닫지 않는다. 라벨을 하나도 담지 않은 프리셋은 그 이벤트 유형을 오토라벨 대상에서 빼겠다는 선언이다. 그 유형의 영상은 보류되지 않고 배치가 완료로 마감되며 오토라벨 묶음만 건너뛴다. 라벨을 골랐으나 전부 AI 검출 클래스 매핑이 없는 경우와는 다르다 — 그쪽은 보류된다.
