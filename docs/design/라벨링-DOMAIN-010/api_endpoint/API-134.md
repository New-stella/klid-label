## description

영상 단위(RAW_SN) 이벤트 어노테이션을 upsert 한다(LS_EVNT_ANNO, RAW_SN UK 기준 1건). 라벨링 화면의 수동입력 경로다. 필드별 조달 출처는 2026-08-25 확정 축을 따른다 — 자동으로 채우는 것은 질문(저작도구가 보관하는 검증 이벤트 유형별 질문 문구 목록에서 마킹 선택값, 없으면 그 유형의 첫 번째)과 caption(추가 질문 응답 서술), cot 의 1단계(묘사 전문의 「상황」 라벨 줄)이고, 답변과 evidence 및 cot 의 2단계 이후는 자동으로 채우지 않는 사람 확정 공란이다. 이 경로는 그 공란을 사람이 채우고 자동으로 채워진 값을 수정하는 창구다. 이 축은 2026-08-24 에 "추가 질문 결과를 답변 초안으로 넣는다"로 확정했던 것을 2026-08-25 회신이 되돌린 것이다 — 같은 축이 이틀 만에 두 번 뒤집혔으므로 세 번째 반전을 막기 위해 경위를 남긴다. evidence 는 캔버스 선택 객체를 자동 연결하며 MAX_ID 힌트를 제공한다. 저장 시 검토 상태는 PENDING 으로 전이(AUTO_GENERATED 에서 수정 시). 권한 REVIEWER/WORKER, 본인 배정 영상 IDOR 검증, 포털 채널 격리. 검수 승인된 영상을 이 경로로 수정하면 그 영상은 재검수 대상이 되며, 검수자가 다시 승인한 시점에 TASK_MODIFIED 통지 대상이 된다.
