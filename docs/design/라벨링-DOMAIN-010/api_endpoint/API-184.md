## description

영상 단위 개인정보 판정을 저장한다.

[전체 교체 계약] 익명·가명·개인정보포함여부 3필드를 항상 함께 전송한다. 생략(null)한 필드는 수동값이 삭제되어 조회 시 기본상수로 폴백한다. 허용값은 Y 또는 N 뿐이다.

[사용자가 고르지 않은 필드는 null 로 보낸다] 조회 응답의 출처가 DERIVED 인 필드를 그대로 되돌려 보내면 시스템 기본상수가 사람의 판정으로 승격된다. 서버는 그 값이 화면에서 온 것인지 프리필을 되돌려받은 것인지 구분할 수 없어 이를 막지 못한다.

[산출물과의 연결] 저장값은 학습데이터 산출물 JSON 의 video 블록 개인정보 3필드로 나간다.

[산출·통지의 트리거는 재검수 승인이다] 검수 완료된 영상의 이 값을 고치면 그 영상은 다시 검수 대상이 되고, 검수자가 그 수정을 다시 승인한 시점에 산출 폴더가 새 버전으로 전량 재생성된 뒤 관제 수정 통지가 발행된다.

[동시성] 이 저장은 같은 영상의 검수 승인과 직렬화된다. 직렬화하지 않으면 승인 직전에 저장된 판정이 그 승인의 산출물에 반영되지 않고 다음 승인까지 밀려 과소 신고가 된다.

[감사] 변경은 행위 단위로 감사 기록되며 누가 언제 왜 바꿨는지만 남기고 판단값 자체는 남기지 않는다. 작업자는 본인 배정 영상만 저장할 수 있다.
