## description

라벨링 프리셋을 수정한다. REVIEWER 전용.

수정이 성공하면 그 이벤트 유형에 대해 보류돼 있던 오토라벨 묶음의 재개가 촉발된다. 재개는 보류 이력이 있고 지금은 프리셋이 실효한다는 두 조건을 모두 만족할 때만 일어나며, 뒤 조건이 멱등을 담당한다 — 이미 재개된 영상을 다시 촉발해도 중복 적재되지 않는다. 재개는 응답을 지연시키지 않으며, 재개가 실패해도 프리셋 수정이 되돌아가지 않는다. 수정은 매핑된 라벨이 없던 무효 프리셋에 매핑된 라벨을 넣는 동선이라 재개가 실제로 일어나는 주요 경로다.

프리셋에 담긴 라벨 중 AI 검출 클래스에 매핑된 것이 하나도 없어도 저장은 성공한다. 그런 프리셋은 오토라벨링에 적용되지 않으므로, 거부하지 않고 그 사실만 알린다.

삭제는 재개를 촉발하지 않는다 — 프리셋이 사라지면 오히려 보류 조건이 성립한다.

보류 판정과 사유 구분의 골격은 ADR-054 가 정한다. 라벨을 하나도 담지 않은 프리셋은 그 이벤트 유형을 오토라벨 대상에서 빼겠다는 선언이다. 그 유형의 영상은 보류되지 않고 배치가 완료로 마감되며 오토라벨 묶음만 건너뛴다. 라벨을 골랐으나 전부 AI 검출 클래스 매핑이 없는 경우와는 다르다 — 그쪽은 보류된다.
