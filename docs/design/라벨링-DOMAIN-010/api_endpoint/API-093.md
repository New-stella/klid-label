## description

사용자가 캔버스에서 클릭(포인트) 또는 드래그(박스)로 객체를 지목하면 추론 서버의 분할 경로로 프록시해 폴리곤과 신뢰도를 받는다.

points 와 box 는 정확히 하나만 제공해야 하며 둘 다 보내거나 둘 다 없으면 400 이다.

분할은 정책상 원본 프레임 이미지에만 실행하고 비식별본은 좌표를 공유한다. 응답 폴리곤은 이미지 실측 해상도 상한까지 좌표를 검증한 뒤(CWE-20) 단순화한다. 목업 응답은 화면이 자동 적용하지 않는다.

서버는 상태 없는 프록시라 DB 에 저장하지 않는다 — 저장은 라벨 임시저장 흐름이 담당한다. 보안: 작업자는 본인 배정 프레임만(CWE-639), 경로순회 차단(CWE-22), 이미지 크기 상한 20MB(초과 시 413).

화면에서는 AI 분할 도구(단축키 G)로 쓴다.
