## description

이슈 스레드에 댓글 작성. WORKER 는 해당 영상 현재 배정자 또는 이슈 작성자 본인만 가능. 검수자 이상(관리자 포함)이 INQUIRY(OPEN)에 댓글 작성 시 상태가 ANSWERED 로 자동 전이 — 관리자는 검수자 권한을 계층으로 물려받으므로 같은 전이를 일으킨다. RESOLVED INQUIRY 에는 댓글 차단(409) — 단 REJECTION 은 RESOLVED 여도 댓글 허용(반려 후 후속 질문). 낙관적 잠금으로 resolve 와의 동시 충돌 시 409.
