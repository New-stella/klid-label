## description

KRDS Public(DS-001) 토큰 기반 고충실 디자인. 페이지 헤더(제목·동적 부제 '전체 N개'·프리셋 추가) + 반응형 3열 카드 그리드(프리셋명·이벤트 배지·설명·라벨 코드 칩·수정/삭제/복제 액션) + 클라이언트 페이지네이션(9건/페이지) 본문과, 프리셋 편집 모달(이벤트유형 select/라벨 마스터 체크박스 멀티셀렉트/미연결 경고 배너)·삭제 확인·라벨 없이 저장 확인 다이얼로그 오버레이 3종의 정적 미리보기를 포함한다. 편집 모달은 진입 모드별로 두 벌 병기한다 — 신규 모드는 이벤트유형과 라벨 두 축 모두 미선택이고 이벤트유형 자리에 안내 문구 「이벤트유형을 선택하세요」가 놓인 빈 상태이며, 수정 모드는 저장돼 있는 이벤트유형과 라벨이 두 축 모두 선택돼 필수 입력 오류 안내 없이 저장 수단이 곧바로 활성인 상태다. 로딩 스켈레톤·빈 상태·조회 실패 3종 상태 변형도 참고용으로 병기.
