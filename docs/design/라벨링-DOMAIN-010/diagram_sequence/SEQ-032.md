## description

라벨링 화면에서 사람이 눌러 실행하는 탐지를 그린다. 배치가 자동으로 도는 탐지와 달리 사람이 그 자리에서 부르며, 결과를 저장하지 않고 좌표만 돌려주어 작업본 편집에 쓰인다. 저장은 라벨 편집 흐름이 소유한다.

무엇을 탐지할지는 서버가 정한다. 화면이 보낸 대상 분류를 그대로 믿지 않고 라벨 마스터에 매핑된 분류와의 교집합으로 정하며, 매핑되지 않은 분류만 요청되면 외부를 부르지 않고 빈 결과와 안내를 돌려준다.

좌표는 경계로 좁히되 형식 위반은 전부 거른다. 음수와 이미지 초과는 경계로 좁혀 돌려주고, 이미지 밖 퇴화 상자는 그 검출만 빼며, 수가 아닌 좌표가 섞이면 그 응답의 검출을 하나도 돌려주지 않는다. 좁히는 것과 거르는 것은 다른 판정이다.

잠긴 영상이면 외부 추론을 부르기 전에 막고, 외부 호출이 끝난 사이에 잠겼으면 좌표를 돌려주지 않고 충돌로 막되 진행 표식을 풀어 다시 요청할 수 있게 한다. 같은 프레임의 동시 탐지는 하나만 통과시켜 라벨이 겹쳐 만들어지지 않게 하고, 동시 요청이 상한을 넘으면 거부해 추론 자원 경합을 막는다.

클릭으로 외곽을 따는 것과 객체를 따라가는 것은 각각 별도 흐름이 소유하므로 여기서 그리지 않는다.
