    autonumber
    actor RV as 검수자(REVIEWER)
    participant RC as ReviewController
    participant RS as ReviewService
    participant VS as VersionService
    participant DB as PostgreSQL (LS_RAW_DATA_STATUS / LS_LABEL_VERSION)
    participant EP as ApplicationEventPublisher

    RV->>RC: POST /v1/reviews/{videoId}/approve
    RC->>RS: approve(videoId, actor)
    RS->>DB: loadByVideoId
    RS->>RS: 승인 게이트 — 검수 워크플로 상태의 비식별화 완료 여부 판정 (상태 전이보다 먼저)
    alt 비식별화 미완료 — 외부 산출물을 원본으로 지정해 들여온 영상
        RS-->>RC: 412 PRECONDITION_FAILED (행위 중립 메시지)
        RC-->>RV: 412 — 승인 거부. 상태 전이·아래 스냅샷 생성·학습데이터 산출물 재생성·관제 통지가 하나도 일어나지 않음
    else 비식별화 완료 (기본값)
        Note over RS: 이 게이트는 승인만 막는다 — 라벨 조회·프레임 이미지·영상 스트리밍·산출물 생성까지 함께 닫는 비식별 누락 신고와는 다른 축이다
    end
    RS->>RS: 상태머신 verify(→APPROVED) — 승인 게이트를 통과한 뒤에 평가한다. 게이트에서 막히면 이 검증에 닿지 않아 400 이 아니라 412 로 응답한다
    RS->>DB: transitionTo(APPROVED) + TaskEventLog.approve save
    RS->>DB: flush()
    alt OptimisticLock 충돌
        RS-->>RC: 409 CONFLICT
        RC-->>RV: 409
    else 승인 확정
        RS->>VS: commitApproved(rawSn, actor)
        loop 영상 프레임별
            VS->>DB: findBySrcSn (라벨)
            opt 라벨 있음
                VS->>VS: LabelResponse JSON 직렬화 + SHA-256(VERSION_HASH)
                VS->>DB: findActiveForUpdate (비관적 잠금)
                alt 동일 해시(멱등)
                    VS->>VS: 스킵
                else 변경됨
                    VS->>DB: 새 active 버전 save (SAVE_REASON_CD=APPROVED)
                end
            end
        end
        RS->>EP: publish ReviewApprovedEvent(rawSn)
        RS-->>RC: ReviewResponse(APPROVED)
        RC-->>RV: 200 OK
    end

## description

ReviewController.approve(POST /v1/reviews/{videoId}/approve, REVIEWER) → ReviewService.approve: IN_REVIEW→APPROVED 전이 + 낙관적 잠금 flush(충돌 시 409) → 같은 트랜잭션에서 VersionService.commitApproved: 영상 프레임 순회, 프레임별 현재 라벨을 LabelResponse JSON 으로 직렬화 → SHA-256 VERSION_HASH → ACTIVE 행 비관적 잠금 후 동일 해시면 멱등 스킵, 아니면 SAVE_REASON_CD=APPROVED 새 active 저장. 끝으로 ReviewApprovedEvent 발행. 전제조건 — 승인 요청이 들어오면 상태 전이보다 먼저 승인 게이트가 검수 워크플로 상태의 비식별화 완료 여부를 판정한다. 외부 산출물을 원본으로 지정해 들여온 영상은 비식별이 끝나기 전까지 미완료이고 그 밖에는 완료가 기본값이며, 미완료면 412 로 승인이 거부되어 이 흐름 자체가 시작하지 않는다. 상태 전이 유효성 검증도 이 게이트 뒤에 오므로, 게이트에서 막힌 요청은 전이가 잘못됐는지와 무관하게 412 로 응답한다 — 상태 전이·버전 스냅샷·학습데이터 산출물 재생성·관제 통지가 하나도 생기지 않는다. 이 게이트는 승인만 막는다는 점에서, 라벨 조회·프레임 이미지·영상 스트리밍·산출물 생성까지 함께 닫는 비식별 누락 신고 축과 구분된다.
