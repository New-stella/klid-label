# 라벨 버전 스냅샷 저장·해시 식별

## priority

critical

## scenario

### then

- 영상 단위 라벨 전체 JSON 스냅샷이 LS_LABEL_VERSION.LABEL_PAYLOAD에 SAVE_REASON_CD='APPROVED'로 적재된다
- payload SHA-256(VERSION_HASH)로 버전이 식별되며 동일 payload 재승인은 새 버전을 생성하지 않는다(멱등)
- 라벨 임시저장(작업본 저장) 시점에는 스냅샷을 생성하지 않는다
- 비식별화완료여부가 미완료이면 검수 승인 요청이 거부된다
- 거부된 승인에서는 라벨 버전 스냅샷이 만들어지지 않는다 — 승인 가부 판정이 상태 전이보다 먼저 이뤄지기 때문이다
- 거부된 승인에서는 학습데이터 산출물 재생성과 관제 통지도 일어나지 않는다
- 비식별화완료여부가 완료로 바뀐 뒤 다시 승인하면 승인이 정상 진행되어 라벨 버전 스냅샷이 만들어진다
- 비식별화완료여부가 완료를 기본값으로 갖는 기존 영상은 이 조건 때문에 승인이 막히지 않는다

### when

- REVIEWER가 검수를 승인(APPROVED)한다
- 비식별화완료여부가 미완료인 상태에서 REVIEWER가 검수 승인을 요청한다

### given

- 대상 영상의 라벨이 존재하고 REVIEWER로 인증되어 있다
- 외부에서 라벨링이 끝난 산출물을 원본으로 지정해 가져온 영상은 비식별이 끝나기 전까지 검수 워크플로 상태의 비식별화완료여부가 미완료로 유지된다
- 이 경로를 거치지 않은 기존 영상은 비식별화완료여부가 완료를 기본값으로 갖는다

## statement

REVIEWER가 검수를 승인(APPROVED)하면 영상 단위 라벨 전체 스냅샷(JSON)을 LS_LABEL_VERSION에 적재하고 payload SHA-256(VERSION_HASH)으로 버전을 식별한다(동일 payload 멱등)
