# 매핑된 라벨이 없는 프리셋은 경고와 함께 저장에 성공한다

## priority

high

## scenario

### then

- 라벨별 매핑 여부가 화면에 보인다
- 오토라벨링에 적용되지 않는다는 경고가 뜬다
- 저장이 거부되지 않고 성공한다
