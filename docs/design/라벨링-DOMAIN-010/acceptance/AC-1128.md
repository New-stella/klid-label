# 프리셋 편집에서 라벨을 상한보다 많이 고르면 저장할 수 없고 막힌 사유가 저장 수단 곁에서 보인다 (negative)

## priority

high

## scenario

### then

- 저장할 수 없다
- 저장이 막힌 사유가 저장 수단 바로 곁에서 보인다
- 현재 선택 개수가 그 사유와 함께 보인다
- 라벨 목록 쪽 먼 자리의 작은 표시만 있는 상태는 충족으로 보지 않는다
- 상한을 넘겨서도 라벨 선택 자체는 막히지 않는다
- 상한 이하로 줄이면 사유 안내가 사라지고 다시 저장할 수 있다
- 상한 이하에서는 종전과 똑같이 저장된다

### when

- 라벨을 상한보다 많이 고른 상태에서 저장을 시도한다

### given

- 검수자가 프리셋 편집 모달에서 라벨을 고르고 있다
- 라벨 선택 개수 상한은 라벨 선택 칸에 표시된 값이 정한다

## statement

검수자가 [[SCREEN-026]] 프리셋 편집 모달에서 라벨을 상한보다 많이 고른 상태로는 저장할 수 없다. 상한 값의 단일 원천은 라벨 선택 칸에 이미 표시돼 있는 값이며 이 기준은 그 값을 따로 적지 않는다. 저장이 막힌 사유와 현재 선택 개수는 저장 수단 바로 곁에서 보인다 — 라벨 목록 쪽 먼 자리의 작은 표시만으로는 충족되지 않는다. 상한을 넘겨서도 선택 자체는 막지 않는다 — 무엇을 뺄지 고르려면 넘긴 상태가 화면에 남아 있어야 한다. 상한 이하로 줄이면 그 사유 안내가 사라지고 다시 저장할 수 있어 막힘이 영구 상태로 남지 않는다. 상한 이하에서는 종전과 똑같이 저장된다.
