# 이벤트 유형 목록이 프리셋 연결 상태를 구분해 보이고 미연결만 거를 수 있다

## priority

high

## scenario

### then

- 세 상태가 구분되어 표시된다
- 미연결만 거르는 조작이 전체 기준으로 동작한다
- 그룹의 비대표 코드도 대표코드의 프리셋을 반영해 표시된다

### when

- 검수자가 이벤트 유형 관리 화면을 연다

### given

- 프리셋이 있고 실효한 유형, 프리셋은 있으나 매핑된 라벨이 없는 유형, 프리셋이 없는 유형이 각각 있다
- 표시명이 같아 하나로 접힌 그룹이 있다

## statement

이벤트 유형 관리 화면에서 유형별 프리셋 연결 상태가 연결됨·연결됨(무효)·미연결로 구분되어 보이고 미연결만 거를 수 있으며, 같은 표시명 그룹의 비대표 코드도 대표코드에 걸린 프리셋을 반영해 표시된다.
