# 프리셋은 라벨 식별자만 담고 이름과 형태를 스스로 갖지 않는다

## notes

이 기준은 저장되는 것이 무엇인지를 다루고, 마스터 변경이 프리셋에 반영되는지는 라벨 마스터 쪽 기준이 맡는다. 두 기준이 같은 구조를 서로 다른 방향에서 고정한다.

## priority

critical

## scenario

### then

- 고른 라벨의 식별자만 저장된다
- 이름과 형태는 프리셋에 저장되지 않는다
- 화면에서 형태를 프리셋별로 바꿀 수 없다

### when

- 프리셋을 저장한다

### given

- 검수자가 프리셋에 담을 라벨을 고른다

## statement

프리셋을 저장할 때 담기는 것은 고른 라벨의 식별자뿐이며, 이름과 형태는 저장 대상이 아니고 화면에서도 마스터 값을 읽기 전용으로 보여준다.
