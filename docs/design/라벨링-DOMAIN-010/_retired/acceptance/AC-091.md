# 라벨 이름과 검출 클래스 매핑은 사용 중인 라벨끼리 겹칠 수 없다

## notes

이름이 눈으로 같아 보이는데 다른 라벨이면 작업자가 매번 어느 것을 골라야 할지 알 수 없다. 검출 클래스가 둘 이상에 매핑되면 자동 검출 결과를 어느 라벨로 귀속시킬지 정해지지 않는다. 사용 중지된 라벨까지 막지 않는 것은 그것이 이미 후보에서 빠져 혼동을 만들지 않기 때문이다.

## priority

high

## scenario

### then

- 충돌로 거부된다
- 기존 라벨은 그대로 남는다
- 사용 중지된 라벨과는 겹쳐도 거부되지 않는다

### when

- 대소문자나 앞뒤 공백만 다른 이름으로, 또는 이미 매핑된 검출 클래스로 라벨을 만들거나 고친다

### given

- 사용 중인 라벨이 이미 있다

## statement

사용 중인 라벨 안에서 이름이 겹치거나 같은 검출 클래스에 둘 이상이 매핑되면 저장이 거부되며, 이름 비교는 대소문자와 앞뒤 공백 차이를 같은 것으로 본다.
