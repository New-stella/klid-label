## description

프레임별 라벨 CRUD, 라벨 속성·마스터 코드 관리, SAM2 분할·트랙 대화형 세그멘테이션, 키포인트(COCO-17), 트랙 편집(병합·분할·삭제), 프레임 설명을 다룬다. LabelController(/v1/frames)가 LabelService·Sam2TrackService 를 조합하고 LabelAccessGuard 로 본인 배정 프레임만 편집을 허용한다.

[저장 시맨틱] 저장은 현재 작업본을 LS_DATA_LBL 에 full-replace 로 영속하는 작업 임시저장이며, 학습데이터 버전 스냅샷은 검수 승인 시점에만 따로 만들어진다.

[★신고 게이트] 비식별 누락 신고(DE_IDNTF_YN='F') 구간에는 라벨 조회·이력이 412 로 차단된다(역할 무관) — 라벨 좌표 자체가 PII 위치 특정 정보라 스트리밍만 막는 것으로는 부족하기 때문이다. 라벨은 삭제하지 않고 보존한다.

[★프레임 이미지 서빙 규약] 캔버스가 쓰는 /v1/frames/{srcSn}/image 는 기본이 비식별본이고 원본은 REVIEWER 가 명시적으로 요청할 때만 나간다. 비식별 프레임을 여는 4경로는 단일 판정기로 검증하고 그 실경로를 NOFOLLOW 로 열어야 하며(심링크 교체 방지), 조회·인가·게이트는 트랜잭션 안에서 값만 받고 파일 I/O 는 트랜잭션 밖에서 한다(커넥션 기아 방지). 게이트 대상 미디어 응답은 Cache-Control: no-store 다.

컴포넌트·관계는 실제 생성자 의존성에서 도출.
