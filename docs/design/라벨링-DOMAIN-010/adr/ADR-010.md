# DBMS MariaDB에서 PostgreSQL로 전환

## context

1차는 MariaDB(klid_system) 기반이었으나, 관제서버가 PostgreSQL로 전환됨에 따라 저작도구도 PostgreSQL로 정합한다. 저작도구 소유 LS_* 테이블만 PostgreSQL용으로 구성하고, 공유 MNG_*/QRTZ_* 스키마는 인프라가 제공하며 ddl-auto=validate로 연동만 한다. Quartz는 PostgreSQLDelegate(BYTEA) JobStore로 운영하고, MariaDB 고유 문법(AUTO_INCREMENT, ENGINE, LONGTEXT, ON UPDATE CURRENT_TIMESTAMP, utf8mb4)은 PostgreSQL 표준으로 전환했다. 단일 인스턴스 서비스 배포(Quartz 클러스터 미적용).

## deciders

- 박찬기
- 김현욱

## decision

### chosen_option

PostgreSQL 전환(채택)

### justification

관제 인프라 PostgreSQL 전환과 정합하고, LS_*는 자체 PostgreSQL 구성, 공유 MNG_*/QRTZ_*는 validate/연동만 한다. MariaDB 고유 문법은 표준 PostgreSQL로 전환한다.
