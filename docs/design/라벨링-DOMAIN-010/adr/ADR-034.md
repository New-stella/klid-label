# 라벨 프리셋 = 라벨 마스터 단일 진실원(LBL_ID FK)

## context

프리셋 코드(LS_LABEL_PRESET_CODE)가 라벨명·형태를 스냅샷 저장해 마스터 변경이 기존 프리셋에 반영 안 되던 구조였다.

## decision

### chosen_option

LBL_ID FK로 마스터 실시간 join(채택)

### justification

프리셋 코드는 LBL_ID(FK→LS_LABEL.LBL_ID, nullable)로 마스터를 실시간 join한다. 형태는 마스터 LBL_TYPE_CD가 강제 파생하며(프리셋에서 개별 토글 불가, 구 BBOX_ENABLED/POLYGON_ENABLED 컬럼 제거), 라벨명 유일성은 활성행 LOWER(TRIM(LBL_NM)) 부분 유니크로 강제한다. 매칭 안 되는 기존 코드(labelId null/비활성)는 오류 없이 '미연결'로 표시한다(자동 생성/삭제 없음).

## consequences

### negative

- 매칭 안 되는 기존 코드는 '미연결' 상태로 남아 별도 정리 작업 필요

- 형태(BBOX/POLYGON)가 마스터와 항상 일치

## considered_options

### 프리셋에 라벨명·형태 스냅샷 저장(구 구조)

**cons**:

- 마스터 변경이 기존 프리셋에 반영되지 않아 드리프트 발생
- 형태 개별 토글 컬럼(BBOX_ENABLED/POLYGON_ENABLED)이 마스터와 불일치 가능

**pros**:

- 조회 시 join 불필요

- **description**: 프리셋 코드가 라벨명·형태를 자체 컬럼에 스냅샷 저장

### LBL_ID FK로 마스터 실시간 join(채택)

**cons**:

- 매칭 안 되는 기존 코드(labelId null/비활성)는 '미연결' 표시 필요

**pros**:

- 마스터 변경이 모든 프리셋에 즉시 반영
- 형태 불일치 원천 차단

- **description**: 프리셋 코드는 LBL_ID(FK→LS_LABEL.LBL_ID, nullable)로 마스터를 실시간 join. 형태는 마스터 LBL_TYPE_CD가 강제 파생(프리셋 개별 토글 불가, 구 컬럼 제거). 라벨명 유일성은 활성행 LOWER(TRIM(LBL_NM)) 부분 유니크로 강제
