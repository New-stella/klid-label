# 검수 워크플로우 단일화 — 2차 검수 폐기

## context

1차는 1차 검수 통과 데이터를 2차 검수자가 최종 검토하는 2단계 검수 워크플로우를 가졌다. 고도화는 REVIEWER 1인이 승인(APPROVED)까지 반복 검수하는 단일 검수 모델로, 검수 완료=작업 완료(LsRawDataStatus.dataSttsCd=APPROVED)이며 이 시점에 outbound TASK_COMPLETED 통지를 발행한다.

## deciders

- 박찬기
- 김현욱

## decision

### chosen_option

단일 검수 채택

### justification

고도화 역할 모델(REVIEWER 단일)·완료 통지 단위와 정합한다. 2차 검수는 단일 검수(DFEAT-021)로 통합 폐기한다.

⚠ **이 문장이 근거로 든 역할 모델은 뒤집혔다 — `ADR-055` 가 관리자 역할(ADMIN)을 신설해 역할은 4종(ADMIN·REVIEWER·WORKER·PORTAL_USER)이고 계층은 관리자 → 검수자 한 단계다.** 「REVIEWER 단일」은 그 시점의 판단으로 남겨 두되 현재 사양이 아니다.

⚠ 그러나 **이 결정의 결론은 그대로 유효하다** — 검수 단계를 하나로 두고 승인 시점을 작업 완료로 삼는다는 결론은 바뀌지 않았다. 관리자가 검수자 권한을 계층으로 물려받아 검수·승인을 그대로 수행하므로 검수 단계가 늘지 않기 때문이다. 이 표기를 근거로 2차 검수를 되살리지 말 것.
