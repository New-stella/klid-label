## description

저작도구 상호운용성 기준:
- 인터페이스 요구사항과 애플리케이션·정보 간 상호작용 기능은 기능 구현의 정확성뿐 아니라 데이터 정합성과 정보의 무결성까지 검증한다.
- 통지 페이로드는 수신측 계약과 필드 단위로 일치하는지 검증하고, 필수 항목은 값이 비어도 키를 유지해 수신측 검증 실패를 막는다.
- 조회용 뷰는 출력 항목의 이름·순서·건수 불변식을 시험으로 고정한다.
- 외부 위탁의 요청·콜백은 상관 식별자로 짝을 맞추고, 응답을 받지 못한 건은 회수 경로로 종결해 미결 상태가 남지 않게 한다.
- 산출물이 재생성되면 그 버전이 통지와 대응되도록 하여 수신측이 옛 산출물에 고착되지 않게 한다.
- 외부 시스템 호출은 호출마다 연동 이름·대상 주소·결과 코드·소요 시간을 서버 로그에 남긴다. 외부가 오류로 응답하면 그 응답이 담은 사유를 길이 제한·제어문자 치환·자격증명 마스킹 후 함께 남겨, 연계 장애의 원인을 저작도구 로그만으로 판별할 수 있게 한다. 세션 자격증명이 오갈 수 있는 창구는 응답 본문을 기록하지 않고, 요청·응답 헤더의 자격증명 값과 주소의 쿼리 문자열은 어떤 경우에도 기록하지 않는다. 호출이 취소되거나 대기 시간을 넘겨 끊긴 경우도 그 사실을 결과로 남기고, 상태 점검처럼 주기적으로 반복되는 호출은 성공했을 때 상세 수준으로만 남겨 실제 호출 기록을 덮지 않게 하되 실패는 항상 남긴다.
