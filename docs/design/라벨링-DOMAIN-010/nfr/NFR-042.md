## description

저작도구 데이터 구조 설계 기준:
- 데이터 구조 설계(모델링) 기준을 제시하고 이를 준수하여 구조를 설계·구현한다.
- 데이터 주제영역을 정의하고 개념·논리·물리 데이터 모델을 설계한다.
- 데이터 활용과 업무요건 변화, 시스템 변경으로 인한 구조적 변화가 최소화되도록 유연한 구조로 설계한다.
- 데이터 설계 표준(분류체계·명명 규칙·데이터베이스 객체 사용기준)을 정의하고 적용한다.
- 업무규칙 처리를 위한 구조를 모델에 반영한다.
※ 저작도구가 소유하는 데이터 객체가 설계 대상이며, 다른 시스템이 소유한 공유 객체는 참조 대상으로 구분한다.
