포털 데이터셋 소재 조달 화면

포털 데이터셋 상세의 「저작도구로 열기」가 보낸 사용자가 떨어지는 자리다. 주소의 ★경로 변수에 실린 데이터셋 숫자 식별자를 화면이 직접 읽어 조달 창구에 넘기고, 배포 압축본이 작업영역에 풀릴 때까지의 진행을 보여 준다. 포털이 주입하는 것이 아니라 우리가 주소에서 읽으며, 질의 문자열이 아니라 경로 변수다. 진입하면 먼저 상태를 묻고(조회 창구), 아직 조달한 적이 없으면 ★데이터셋마다 한 번만 스스로 착수한다 — 이 주소로 들어온 것이 곧 그 의사이므로 버튼을 한 번 더 누를 이유가 없다. 착수는 멱등이라 이미 준비됐거나 진행 중이면 서버가 새로 시작하지 않는다. 실패한 뒤의 재시도는 사람이 누른다(자동으로 되풀이하면 확정 실패 사유에서 같은 요청이 끝없이 나간다). 되묻기는 ★진행 중일 때만 하고 … · route /portal/datasets/:datasetId

⑥ 데이터셋 영상

설명

소재가 준비 완료일 때만 나타난다. 데이터셋에 든 영상을 한 줄씩 보여 주고, 사용자가 영상을 골라 라벨링 화면으로 들어간다. 구역 머리는 제목 「데이터셋 영상」과 전체 건수, 그리고 「라벨을 저장해야 내 작업에 남습니다」라는 한 줄 설명을 갖는다. 영상·프레임 등록이 아직 끝나지 않았으면 목록 대신 등록 중이라는 안내를 두고 주기적으로 다시 부르며, 등록이 실패하면 실패 안내와 다시 시도를 둔다. 등록이 끝났는데 영상이 없으면 빈 상태를 보인다. 한 페이지를 넘으면 페이지 이동을 둔다. 정렬은 영상 이름 오름차순이다.

  • Alert(영상 목록을 불러오지 못함 · 등록 실패)

    조회 실패와 등록 실패를 빈 상태와 반드시 가른다 — 오류를 영상이 없는 것으로 보이면 사용자가 데이터셋이 비었다고 오해한다. 다시 시도를 함께 둔다.

    등록이 끝났는데 영상이 하나도 없을 때만 보인다.
