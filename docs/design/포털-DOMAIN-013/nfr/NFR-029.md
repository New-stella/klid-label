## description

저작도구 화면 사이즈 기준:
- 저해상도(1024x768)부터 1920x1080(권장 24인치)까지 지원하는 레이아웃을 적용한다.
- 화면과 구성요소의 크기는 CSS로 지정하고 특정 해상도에 최적화된 고정 디자인을 지양한다.
- 각 페이지의 접근과 메뉴 이동이 편리하도록 내비게이션을 구성한다.
- 수평 스크롤은 사용하지 않는다. 다만 넓은 표·타임라인·라벨링 캔버스처럼 조회·편집 목적상 불가피한 영역은 해당 영역 안에서만 스크롤하고 페이지 전체가 수평으로 밀리지 않게 한다.
- 스크린 사이즈별로 제공 범위를 달리해야 하는 콘텐츠가 있으면 대상을 선정해 발주기관과 협의 후 확정한다.
