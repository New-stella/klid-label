## description

포털 사용자가 영상의 이벤트 어노테이션을 Load 한다. 대상은 자산 출처를 가리지 않는다 — 데이터마트에서 불러온 영상과 본인이 올린 영상 둘 다이며, 포털의 라벨링 화면이 하나로 합쳐져 두 출처를 같은 화면에서 다루기 때문이다. 데이터마트 자산은 원본(LS_EVNT_ANNO)과 본인 오버레이(LS_PORTAL_USER_EVNT_ANNO)를 병합해 내려주며 본인 작업분이 우선하고, 본인이 올린 자산은 오버레이를 거치지 않고 그 자산의 어노테이션을 그대로 내려준다 — 가려야 할 남의 원본이 없어 병합할 것이 없고, 그래서 원본을 가렸다는 표시도 서지 않는다. 어느 쪽인지는 화면이 알려 주지 않고 서버가 자산 출처로 판정한다. 영상 단위라 프레임 참조가 없다. 본문은 내부 원장과 같은 구조체를 그대로 담는다 — 키별로 펴지 않는 이유는 산출 JSON 과 모양이 갈리면 내보낼 때마다 재조립이 필요하고 중첩 구조가 무너지기 때문이다.
