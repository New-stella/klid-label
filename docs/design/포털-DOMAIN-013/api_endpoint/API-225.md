## description

PORTAL_USER 본인이 데이터마트 자산에 대해 저장해 둔 저작 작업을 영상 단위로 묶어 페이징 조회한다. 포털 채널 진입 화면의 「내 저장 작업 목록」이 이 창구를 소비하며, 각 행에서 이어서 작업하기와 작업 데이터 내려받기로 이어진다.

★ 이 창구가 필요한 이유 — 데이터마트 영상 목록의 소유가 Host(포털)로 이전되면서 저작도구가 그리는 목록은 「내가 저장한 작업」으로 바뀌었다. 기존 본인 라벨 조회 창구는 영상 식별자가 필수라 한 영상 안의 라벨만 돌려주므로 여러 영상에 걸친 이 목록을 채우지 못한다. 같은 URL 에 파라미터로 행위를 분기하지 않는다는 규약에 따라 확장이 아니라 별도 창구로 둔다.

★ 만료 예정 시각을 이 응답이 싣는다 — 포털 작업 데이터에는 보존기간 만료 자동 삭제가 걸려 있고, 데이터마트 채널의 고지 창구가 폐기된 영상 목록 조회에서 이 창구로 이관된다. 고지가 빠지면 사용자가 예고 없이 작업물을 잃는다. 값은 저장 시각과 보존기간 설정에서 파생하며 캐시하지 않는다.

정렬 기본값은 마지막 저장 시각 내림차순이다. 본인 데이터만 반환하며 토큰 주체가 격리 키다.
