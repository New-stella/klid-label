## description

TUS 1.0 재개 가능 영상 업로드 세션을 생성한다. 요청/응답 모두 헤더 기반(Upload-Length, Upload-Metadata). Upload-Length 가 포털 영상 상한(5GB, portal.upload.max-file-size-bytes) 초과 시 413. Upload-Metadata 의 filename 을 base64 디코딩해 확장자(mp4/mov/avi)를 allowlist 검증한다(그 외 400). 사용자별 동시 진행 세션 3건 초과 시 429. 저장 파일명은 UUID(uldId) 강제 — filename 은 표시용만(경로순회 차단). 성공 시 201 + Location 헤더로 세션 식별자(uldId, UUID)를 반환한다.
