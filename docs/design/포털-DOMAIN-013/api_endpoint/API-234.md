## description

포털 사용자가 프레임의 메타를 Load 한다 — 촬영환경·프레임 설명·개인정보 판정·시계열 메타 네 축이다. 대상은 자산 출처를 가리지 않는다 — 데이터마트에서 불러온 영상과 본인이 올린 영상 둘 다이며, 포털의 라벨링 화면이 하나로 합쳐져 두 출처를 같은 화면에서 다루기 때문이다. 데이터마트 자산은 원본(LS_DATA_META)과 본인 오버레이(LS_PORTAL_USER_META)를 병합해 내려주며 본인 작업분이 우선하고, 본인이 올린 자산은 오버레이를 거치지 않고 그 자산의 메타를 그대로 내려준다 — 가려야 할 남의 원본이 없어 병합할 것이 없고, 그래서 원본을 가렸다는 표시도 서지 않는다. 어느 쪽인지는 화면이 알려 주지 않고 서버가 자산 출처로 판정한다. 영상 축 메타와 프레임 축 메타를 함께 담으므로 원소마다 어느 축인지 표시한다 — 저장할 때 그 축으로 되돌려 보내야 영상 축 값이 프레임에 매달리지 않는다. 본인이 고친 값은 표시를 달아 화면이 원본과 구분해 보일 수 있게 한다. ★시계열 메타를 미제공으로 다루지 않는다 — 미제공의 축은 외부 시계열 분석 서버로 나가는 위탁 연동(호출·콜백)이며, 그 결과물을 화면에 표시하고 사람이 고치는 것은 그 축이 아니다.
