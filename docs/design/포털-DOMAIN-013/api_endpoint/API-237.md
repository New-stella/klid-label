## description

포털 사용자가 확인·수정·추가한 이벤트 어노테이션을 적재한다. 대상은 자산 출처를 가리지 않는다 — 데이터마트에서 불러온 영상과 본인이 올린 영상 둘 다이며, 포털의 라벨링 화면이 하나로 합쳐져 두 출처를 같은 화면에서 다루기 때문이다. 저장처는 화면이 가르지 않고 서버가 자산 출처로 판정한다 — 화면은 어느 쪽인지 알 필요가 없고 어느 출처든 같은 저장 요청을 보낸다. 데이터마트 자산은 본인 오버레이(LS_PORTAL_USER_EVNT_ANNO)에 적재한다. ★원본(LS_EVNT_ANNO)과 승인 시점 동결본을 수정하지 않는다 — 단방향이라 데이터마트로 되돌아가지 않으며 관제 통지·산출물 재생성을 일으키지 않는다. 그 오버레이의 적재 키는 (포털사용자, 영상)이라 영상당 한 벌이고 다시 저장하면 덮어쓴다. 본인이 올린 자산은 오버레이를 거치지 않고 그 자산의 어노테이션에 그대로 적재한다 — 원본이 본인 것이라 가려 둘 원본이 없다.
