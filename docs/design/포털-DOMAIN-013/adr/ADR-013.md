# 포털 범위 확정 — 데이터마트 영상 선택 + 본인 자산 업로드(예외) + 메타·이벤트 어노테이션 표시·수정·추가 + 업로드 영상 한정 이벤트구간 마킹·AI 증강 연동 제공, 오토라벨링·SAM2 인터랙티브·키포인트·트랙관리·검수·버전관리 미제공

## context

포털(외부 채널)의 기능 범위와 데이터 흐름을 확정해야 한다. 관제서버가 데이터마트를 포털에 제공하면 포털이 등록하고, 포털 사용자는 제공된 영상을 선택해 기존 라벨을 확인·수정·저장·다운로드한다. 포털 작업이 데이터마트를 오염하면 안 되며, 내부 저작도구와 기능 차이를 명확히 해야 한다. 기존 방침은 포털에 오토라벨링 체험·업로드를 포함했으나 2026-06-01 이를 정정한다. 이후 ADR-013 예외로 포털 사용자 본인 자산(이미지 20MB/장·50장, 영상 5GB TUS 재개업로드) 업로드가 신설되었다(2026-07-17, SC-034/035, LS_PORTAL_* 전용 테이블 V107~V111 — 내부 파이프라인·데이터마트와 완전 분리). 포털 트랙 rename/merge 전용 인프라는 포털 데이터모델에 트랙 개념 자체가 없어 투기적 판단으로 확인되었고 미제공이 확정되었다(2026-07-15, R1-b 축소).

SAM2 인터랙티브 분할·자동추적·키포인트는 한 번 노출됐다가 되돌려졌다 — 이 이력을 지우지 말 것. ①2026-07-15 에 좌표만 반환하고 내부에 저장하지 않는다는 근거로 포털에 부분 노출했고(ADR-013 부분 override), ②2026-07-30 이 ADR v2 가 그 노출을 "제공한다"로 기록했으며, ③2026-08-03 보안 2차 전수검증에서 신규 HIGH 로 판정되어 서버에서 완전 제거되었다(포털 SAM2 전용 엔드포인트 삭제 + 포털 라벨 저장 allowlist 를 BBOX/POLYGON 으로 fail-closed). 즉 v2 기록은 틀린 기록이 아니라 그 뒤 보안 사유로 반전된 결정의 정확한 기록이며, 본 v3 는 반전 결과를 반영한 것이다.

현재 상태(실측): 포털 채널에는 sam2 엔드포인트가 없고 sam2 는 내부 채널의 POST /v1/frames/{srcSn}/sam2-segment·sam2-track 2건으로만 제공된다. 회귀 가드가 포털 경로 sam2 엔드포인트 404·포털 경로 sam2 핸들러 매핑 0건을 고정하고, 동시에 내부 채널 SAM2 는 영향받지 않으며 포털 토큰에는 403 임을 함께 고정한다. 키포인트도 포털 라벨 저장 경로(데이터마트 영상·본인 업로드 자산 양쪽)의 BBOX|POLYGON allowlist 로 400 차단된다. 따라서 포털에 SAM2·키포인트를 다시 만들지 말 것 — 되살리려면 2026-08-03 보안 판정부터 뒤집어야 한다.

## decision

### chosen_option

데이터마트 영상 선택 + 본인 자산 업로드(예외) + 데이터마트 로드분의 메타·이벤트 어노테이션 표시·수정·추가(포털 전용 저장소 적재, 데이터마트·원본 미수정 단방향) + 업로드 영상 한정 이벤트구간 마킹·AI 증강 연동 제공, 오토라벨링·SAM2 인터랙티브·키포인트·트랙관리·검수·버전관리 미제공

### justification

포털은 ①관제가 제공한 데이터마트 영상 선택 + 기존 라벨 확인·수정·저장·다운로드, ②ADR-013 예외로 신설된 본인 자산 업로드(이미지/영상, SC-034/035, LS_PORTAL_* 전용 테이블, 내부 파이프라인·데이터마트와 완전 분리)를 제공한다. 라벨 도형은 BBOX·POLYGON 수동 라벨링만 허용한다(allowlist fail-closed). 데이터마트에서 불러온 영상의 메타(촬영환경·프레임 설명·개인정보 판정·시계열 메타 등)와 이벤트 어노테이션은 포털 작업 화면에 표시하며, 포털 사용자가 직접 수정·추가할 수 있다 — 제공한다. 미제공인 것은 외부 시계열 분석 서버로 나가는 위탁 연동(호출·콜백)이지 그 결과물을 사람이 보고 고치는 일이 아니다. 포털에서 고친 메타·이벤트 어노테이션은 포털 전용 저장소에만 적재하며 데이터마트와 원본(영상 메타 동결 스냅샷·이벤트 어노테이션 동결본)을 수정하지 않는다 — 포털 라벨 저장과 같은 단방향 축이다. 포털 사용자가 업로드한 본인 영상에 한해서는 이벤트구간 마킹과 AI 증강 연동을 제공한다(2026-07-17 본인 자산 업로드 예외의 연장). 오토라벨링(YOLO)·SAM2 인터랙티브 분할·자동추적·키포인트·트랙 rename/merge·검수·버전관리는 미제공한다. 이 중 SAM2·키포인트는 2026-07-15 부분 노출됐다가 2026-08-03 2차 전수검증 HIGH 로 서버에서 완전 제거되어 미제공으로 되돌아온 항목이며, 나머지는 데이터모델·파이프라인 불일치로 처음부터 계속 미제공이다. 미제공인 SAM2 인터랙티브 분할·자동추적·키포인트와 제공하는 AI 증강 연동은 성질이 다른 축이라 함께 묶지 않는다. 전자는 포털 사용자가 외부 채널에서 직접 호출하는 추론 엔드포인트라 그 자체가 공격면이 되어 2026-08-03 보안 2차 전수검증에서 HIGH 로 판정됐고 그 판정은 그대로 유효하다. 후자는 서버가 서버로 보내는 비동기 위탁이라 포털 사용자가 외부 추론 엔드포인트를 직접 호출하는 구조가 아니다. 사용자 저장 데이터는 여전히 LS_PORTAL_USER_LABEL/LS_PORTAL_ULD_LBL에 사용자별로만 적재되고 데이터마트에 정합되지 않는다(단방향).

- **description**: 데이터마트 영상 선택 전용 원칙은 유지하되, ADR-013 예외로 본인 자산 업로드(SC-034/035)를 추가 제공한다. 라벨 도형은 BBOX/POLYGON 수동 라벨링만 허용한다. 2026-07-15 시점에는 여기에 SAM2 인터랙티브 분할·자동추적·키포인트(좌표만 반환·내부 미저장)를 얹은 안을 실제로 채택했으나, 2026-08-03 2차 전수검증 HIGH 판정으로 그 확장분만 철회하고 서버에서 완전 제거했다. 오토라벨링·트랙관리·검수·버전관리는 처음부터 계속 미제공.
