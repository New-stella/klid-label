## brownfield

### notes

### 2026-08-26 — ADR-013 v9 cascade
- 미제공의 축을 외부 시계열 분석 서버로 나가는 위탁 연동(호출·콜백)으로 좁혔다. 그 결과물인 시계열 메타를 화면에 표시하고 사람이 수정·추가하는 것은 미제공 대상이 아니다.
- 데이터마트 로드분의 메타와 이벤트 어노테이션을 포털 작업 화면에 표시하고 포털 사용자가 직접 수정·추가하는 것을 제공 범위로 명시했다. 적재는 포털 전용 저장소이며 데이터마트와 원본 동결본은 수정하지 않는다(경로 A 라벨 저장과 같은 단방향 축).
- 경로 B(본인 자산 업로드)에 한해 이벤트구간 마킹과 AI 증강 연동을 제공하는 예외를 반영했다. 경로 A 에는 해당하지 않는다.
- 오토라벨링(YOLO)·SAM2 인터랙티브 분할·자동추적·키포인트·트랙 rename/merge·검수·버전관리 미제공은 그대로 유지한다. 사용자가 직접 호출하는 추론 엔드포인트와 서버간 비동기 위탁이 다른 축임을 본문에 적어 2026-08-03 보안 판정이 되돌려지지 않게 했다.
- 구 서술 '오토라벨링(YOLO/SAM2)·SAM2 분할·SAM2 추적·키포인트(SKELETON)·VLM 시계열·버전관리·검수는 두 경로 모두 제공하지 않는다'는 폐기 3 으로 본문에 남겼다.

### 2026-08-27 — INT-013 v8 cascade
- 포털 회신 수용으로 임베딩 협의가 전부 해소돼, 확정 사양으로 서술할 단계가 아니라던 직전 판단의 전제가 소멸했다. 그래서 비워 뒀던 도메인 본문에 임베딩 진입 경로를 넣었다.
- 진입 경로는 경로 A·B 와 다른 축이라 새 분류 체계를 만들지 않고 공통 절에 두었다. 경로 A·B 는 작업 대상을 가르고 진입 경로는 유입 지점을 가른다.
- 진입 경로가 정하는 것은 화면 축뿐임을 함께 적었다. 서버 인가 판정의 진실원은 토큰 클레임(채널·역할)이며 진입 경로는 클라이언트가 주장하는 값이라 위조할 수 있다.
- 상세 규약(진입점 이름·마운트 경로·번들 서빙·인계 창구)은 INT-013 이 소유하므로 복제하지 않고 가리키기만 했다.

## description

외부 채널(포털 회원) 도메인. ★서로 다른 두 경로를 갖으며 기능 경계가 다르다 — 혼동하지 말 것.

[경로 A — 데이터마트 영상 라벨 작업] 관제가 구축해 포털 DB 에 적재한 데이터마트 영상을 고른다(적재는 관제서버 책임). 이때 Load 하는 기존 라벨·메타는 포털 DB 가 아니라 저작도구 DB 의 검수 승인(APPROVED) 자산(LS_DATA_RAW·LS_DATA_SRC·LS_DATA_LBL)이다 — 저작도구는 포털 DB 를 읽지 않는다. 저장해도 원본·데이터마트는 수정되지 않고 사용자별 작업 데이터(LS_PORTAL_USER_LABEL)로 별도 적재된다(단방향, 마트로 반영 안 됨). 다운로드는 본인 작업 데이터 기준이고 기여도 점수는 없다. 경로 A 가 내보내는 프레임 이미지·라벨은 내부 파이프라인 자산이라, 비식별 누락 신고가 열린 영상이면 412 로 거부되고 그 응답은 Cache-Control: no-store 로 캐시되지 않는다 — 경로 B 의 본인 업로드 자산은 이 게이트의 대상이 아니다.

[경로 B — 본인 자산 업로드 (ADR-013 예외, 2026-07-17)] 포털 사용자가 본인 이미지(jpg/jpeg/png, 20MB/장, 50장/요청)·영상(mp4/mov/avi, 5GB, TUS 재개 업로드)을 직접 올려 수동 라벨링(BBOX/POLYGON 만) 후 본인 데이터를 내려받는다. 업로드 자산은 LS_PORTAL_* 전용 테이블로 내부 파이프라인(비식별→마킹→배치→검수)·데이터마트 View 와 완전 분리된다. 영상은 본인 데이터라 비식별을 적용하지 않으며 고정 간격 프레임 추출(기본 5초, 상한 2000장)만 한다. 상태는 UPLOADED→PROCESSING→READY|FAILED. 포털 사용자가 업로드한 본인 영상에 한해 이벤트구간 마킹과 AI 증강 연동을 제공한다(2026-07-17 본인 자산 업로드 예외의 연장) — 이 둘은 경로 B 전용이라 경로 A 의 데이터마트 영상에는 해당하지 않는다.

[★제공 범위 — 라벨 편집 도구] 두 경로 모두 수동 라벨링(BBOX/POLYGON)만 제공한다. 도형 종류는 서버 allowlist 로 강제되며(두 경로가 각각 자기 allowlist 를 갖는다) 그 외 값은 400 으로 거부된다. 좌표 개수도 타입별로 강제된다(BBOX 정확히 2점, POLYGON 3~200점).

[★제공 범위 — 메타·이벤트 어노테이션] 경로 A 로 불러온 데이터마트 영상의 메타(촬영환경·프레임 설명·개인정보 판정·시계열 메타 등 — 예시이며 전수 목록이 아니다)와 이벤트 어노테이션을 포털 작업 화면에 표시하며, 포털 사용자가 직접 수정·추가할 수 있다. 포털에서 고친 값은 포털 전용 저장소에만 적재하며 데이터마트와 원본(영상 메타 동결 스냅샷·이벤트 어노테이션 동결본)은 수정하지 않는다 — 경로 A 의 라벨 저장과 같은 단방향 축이다.

[★미제공 기능 — 폐기된 구 서술 포함] 오토라벨링(YOLO)·SAM2 인터랙티브 분할·SAM2 자동추적·키포인트(SKELETON)·트랙 rename/merge·검수·버전관리는 두 경로 모두 제공하지 않는다(ADR-013). 외부 시계열 분석 서버로 나가는 위탁 연동(호출·콜백)도 제공하지 않는다.
· 폐기 1 — 구 본문의 '오토라벨링 체험(YOLO+SAM2)'은 오류였다.
· 폐기 2 — 그 뒤 남아 있던 'SAM2 분할·추적과 키포인트는 경로 A 에만 부분 노출된다(ADR-013 부분 override)'도 폐기한다. 부분 override 는 존재하지 않는다.
· 폐기 3 — 그 문장이 함께 적고 있던 'VLM 시계열은 두 경로 모두 제공하지 않는다'도 폐기한다. 미제공의 축은 외부 시계열 분석 서버로 나가는 위탁 연동(호출·콜백)이며, 그 결과물인 시계열 메타를 화면에 표시하고 사람이 수정·추가하는 것은 미제공 대상이 아니다(위 제공 범위 참조).
근거는 두 축이 서로 다르다. ①SAM2 — 구 포털 전용 SAM2 핸들러 기반 노출은 ADR-013 위반으로 폐지됐다 — 포털 경로에는 SAM2 핸들러를 두지 않는다(API-130·API-131 도 같은 근거로 폐기). ②키포인트 — 위 두 allowlist 가 BBOX|POLYGON 만 허용해 fail-closed 로 막으며, 구 '포털 키포인트(SKELETON) 허용'은 폐기됐다(레거시로 적재된 SKELETON 행은 로드 시 조용히 스킵).
⚠ 미제공인 SAM2 인터랙티브 분할·자동추적·키포인트와 경로 B 에 제공하는 AI 증강 연동은 성질이 다른 축이라 함께 묶지 않는다. 전자는 포털 사용자가 외부 채널에서 직접 호출하는 추론 엔드포인트라 그 자체가 공격면이 되어 2026-08-03 보안 2차 전수검증에서 HIGH 로 판정됐고 그 판정은 그대로 유효하다. 후자는 서버가 서버로 보내는 비동기 위탁이라 포털 사용자가 외부 추론 엔드포인트를 직접 호출하는 구조가 아니다.
⚠ 내부(INTERNAL) 채널의 SAM2 분할·추적은 SFR-08-01(VOS) 핵심 기능이라 그대로 살아 있다 — 포털 미제공을 저작도구 전체 미제공으로 오독하지 말 것.

[공통] 반응형 웹(PC/태블릿/모바일), WCAG 2.1 AA 준수. 인증은 포털 서버 발급 JWT 인계(channel 클레임으로 분기).
포털 채널에는 포털 화면 안의 지정된 자리에 저작도구 화면이 마운트되는 임베딩 진입 경로가 있다 — 포털이 Host, 저작도구가 Remote 다. 이것은 위 경로 A·B 와 다른 축이다: 경로 A·B 는 무엇을 대상으로 작업하는지를 가르고, 이 진입 경로는 사용자가 어디를 통해 들어오는지를 가른다. 진입점 이름·마운트 경로·번들 서빙·인계 창구 같은 상세 규약은 INT-013 이 갖는다.
임베딩으로 진입한 사용자는 포털 권한 사용자로 본다 — 화면 축 한정이다. 포털 채널 산출물은 그 권한 기준으로 화면·메뉴·기능을 게이팅한다. ⚠ 서버 인가 판정의 진실원은 토큰 클레임(채널·역할)이며 진입 경로가 권한을 올리지 않는다. 진입 경로는 클라이언트가 주장하는 값이라 위조할 수 있다.
