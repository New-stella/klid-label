# 실패한 업로드 자산은 더 짧은 보존기간으로 삭제된다

## notes

FAILED 전이 시각은 그 자산의 최종 변경 일시(MDFCN_DT)다. 방치 판정으로 UPLOADED·PROCESSING 에서 전이된 자산도 같은 기준점을 쓰므로 두 축이 자연스럽게 이어진다 — 방치 전이가 곧 FAILED 축 보존기간의 시작이며, 그것이 처리 시작 전·처리 중 자산의 영구 잔류를 막는 유일한 경로다(AC-036). 파일 삭제는 자산 삭제와 같은 실경로 판정기를 거친 뒤에만 수행하며, 판정이 실패하면 그 자산의 삭제만 건너뛴다(배치 전체 중단 아님).
