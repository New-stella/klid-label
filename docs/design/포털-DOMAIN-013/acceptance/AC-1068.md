## statement

포털 사용자가 Host 데이터마트 목록에서 대상 영상을 인계받아 진입하거나(새로쓰기) 저작도구 「내 저장 작업 목록」에서 이어쓰기로 진입하면 기존 저장 라벨과 촬영환경·프레임 설명·개인정보 판정·시계열 메타, 이벤트 어노테이션을 Load해 포털 라벨링 화면(SCREEN-029)에 표시한다 — 데이터마트 영상 목록은 Host(포털)가 자기 화면에서 그리므로 저작도구는 그 목록을 두지 않고, 저작도구 진입 화면(SCREEN-028)은 본인 저장 작업 목록을 그리는 자리라 Load 표시 대상이 아니다. 라벨을 확인·수정해 저장하면 LS_PORTAL_USER_LABEL에 사용자별로 적재하고(원본·마트 미수정), 표시된 메타·이벤트 어노테이션을 확인·수정·추가한 결과도 포털 전용 저장소에 사용자별로 적재한다(데이터마트·원본 동결본 미수정, 단방향·마트 반영 안 됨). 본인 작업 데이터는 마지막 저장일로부터 보존기간(기본 7일) 이내에만 다운로드할 수 있고 화면이 만료 예정 시각을 미리 표시하며, 기간 경과 시 자동 삭제되고 이후 재작업 시 새 보존기간이 적용된다.
