## description

포털 사용자가 본인 영상을 업로드해 LS_PORTAL_ULD 가 완료될 때 발행된다. 프레임 추출 트리거 전용이다.

[★VideoIngested 와 완전 분리] 본 이벤트는 portal 패키지에만 존재하며 관제 비식별·마킹·오토라벨링 파이프라인에 절대 연결되지 않는다. 포털 자산은 본인 데이터라 비식별을 적용하지 않고, 데이터마트 View 와도 분리된 LS_PORTAL_* 전용 경로다(ADR-013 예외).

[발행] 포털 영상 업로드 완료 트랜잭션에서 발행한다.
[소비] 포털 전용 프레임 추출 — 고정 간격(portal.upload.frame-interval-sec 기본 5초, 상한 maxFrames 2000).

[상태] UPLOADED → PROCESSING → READY | FAILED.
