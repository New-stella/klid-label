## description

포털(외부 채널) ERD. 포털은 관제 제공 데이터마트 영상을 선택해 기존 라벨을 확인·수정하며, 원본(LS_DATA_LBL)을 수정하지 않고 사용자 작업분을 별도 적재(LS_PORTAL_USER_LABEL)한다. PORTAL_USER_NO(포털 발급 토큰 sub 클레임)를 IDOR 차단 키로 본인 데이터만 조회/라벨링한다. 저장 데이터는 데이터마트에 정합되지 않는다(단방향). 오토라벨링은 ADR-013 으로 미제공이다(LS_PORTAL_USER_VIDEO·V9 폐기). 업로드(TUS)는 ADR-013 예외(2026-07-17)로 허용되며, 포털 사용자 본인 자산은 내부 파이프라인·데이터마트와 분리된 전용 테이블 LS_PORTAL_ULD·LS_PORTAL_ULD_FRME·LS_PORTAL_ULD_LBL·LS_PORTAL_TUS_ULD 로 관리된다.
