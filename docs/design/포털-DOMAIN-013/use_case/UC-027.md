# 포털 자산 업로드·수동 라벨링

## goal

본인 이미지/영상을 직접 업로드해 BBOX/POLYGON 수동 라벨링을 수행하고 본인 데이터를 다운로드한다

## actor

포털 회원(PORTAL_USER)

## title

포털 자산 업로드·수동 라벨링

## status

approved

## priority

should

## main_flow

### [1]

- **step**: 1
- **actor**: 포털 회원(PORTAL_USER)
- **action**: 이미지(jpg/jpeg/png, 20MB/장, 50장/요청) 또는 영상(mp4/mov/avi, 5GB, TUS 재개가능 업로드)을 업로드한다

### [2]

- **step**: 2
- **actor**: 시스템
- **action**: LS_PORTAL_ULD에 자산을 등록한다 — 이미지는 추출 단계 없이 등록 시점에 READY 로 적재되고 그 이미지 파일 자신을 가리키는 프레임 행 1건(FRME_NO=0)이 함께 생성된다. 영상만 UPLOADED 로 등록한 뒤 고정 간격 프레임 추출을 거친다(UPLOADED→PROCESSING→READY|FAILED)

### [3]

- **step**: 3
- **actor**: 포털 회원(PORTAL_USER)
- **action**: 업로드한 영상 자산에 한해 이벤트구간 마킹을 수행한다(이미지 자산은 대상이 아니다). 업로드 자산 경로는 내부 파이프라인·데이터마트와 분리된 채로 유지된다

### [4]

- **step**: 4
- **actor**: 포털 회원(PORTAL_USER)
- **action**: 업로드 라벨링 화면(/portal/uploads/:uldSn/label)에서 BBOX/POLYGON만 수동 라벨링한다(오토라벨링/SAM2 인터랙티브 분할/자동추적/키포인트/검수/버전관리 미제공 — 라벨 도형은 BBOX·POLYGON allowlist 로 fail-closed 차단한다)

### [5]

- **step**: 5
- **actor**: 시스템
- **action**: PUT /v1/portal/uploads/frames/{uldFrmeSn}/labels로 라벨을 전체교체(멱등, 빈배열=전체삭제) 저장한다

### [6]

- **step**: 6
- **actor**: 포털 회원(PORTAL_USER)
- **action**: 업로드한 영상 자산에 한해 AI 증강 연동을 요청한다 — 요청은 서버가 외부로 보내는 비동기 위탁이며 포털 사용자가 외부 추론 엔드포인트를 직접 호출하지 않는다

### [7]

- **step**: 7
- **actor**: 시스템
- **action**: 증강 결과를 수신해 요청한 포털 회원 본인에게만 제공한다 — 데이터마트와 원본은 수정하지 않는다(단방향)

### [8]

- **step**: 8
- **actor**: 포털 회원(PORTAL_USER)
- **action**: 본인 자산(JSON export/원본 파일)을 다운로드한다

## description

포털 사용자가 본인 이미지(jpg/jpeg/png, 20MB/장, 50장/요청, all-or-nothing)·영상(mp4/mov/avi, 5GB, TUS 1.0 재개 가능 업로드)을 직접 업로드해 수동 라벨링(BBOX/POLYGON만)한 뒤 본인 데이터(JSON export/원본)를 다운로드한다(ADR-013 예외, 2026-07-17). 업로드 자산은 신규 LS_PORTAL_* 테이블(LS_PORTAL_ULD·LS_PORTAL_ULD_FRME·LS_PORTAL_ULD_LBL·LS_PORTAL_TUS_ULD, V107/V108)로 내부 파이프라인(비식별→마킹→배치→검수)·데이터마트 View와 완전히 분리된다. 영상은 비식별 미적용(본인 데이터)이며 고정 간격 프레임 추출(portal.upload.frame-interval-sec 기본 5초, 상한 maxFrames 2000). 상태 전이는 두 경로가 갈린다 — 영상은 UPLOADED→PROCESSING→READY|FAILED 를 거치고, 이미지는 프레임 추출이 없어 등록 시점에 READY 로 적재된다. 업로드 영상에 한해 이벤트구간 마킹과 AI 증강 연동을 제공한다(본인 자산 업로드 예외의 연장). 미제공은 오토라벨링(YOLO)·SAM2 인터랙티브 분할·자동추적·키포인트·검수·버전관리이며, 시계열 축의 미제공은 외부 시계열 분석 서버로 나가는 위탁 연동(호출·콜백)이다. 제공하는 AI 증강 연동은 서버가 외부로 보내는 비동기 위탁이라, 포털 사용자가 외부 추론 엔드포인트를 직접 호출해 공격면이 되는 SAM2 인터랙티브 분할·자동추적·키포인트와는 축이 다르다 — 후자의 미제공은 그대로 유지된다. 화면: 포털 업로드(/portal/uploads, SCREEN-033)·포털 업로드 라벨링(/portal/uploads/:uldSn/label, SCREEN-034).
