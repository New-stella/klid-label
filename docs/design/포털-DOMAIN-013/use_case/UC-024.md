## description

포털은 데이터마트 영상 선택 전용 채널(ADR-013 — 오토라벨링(YOLO/SAM2)·VLM·버전관리·검수 미제공). 관제서버→데이터마트→포털 DB 적재(관제 책임). 이 화면이 Load 하는 영상 목록·프레임·라벨은 저작도구 DB 의 검수 승인(APPROVED) 자산(LS_DATA_RAW·LS_DATA_SRC·LS_DATA_LBL)이며 포털 DB 를 읽지 않는다 — 포털 DB 는 반대 방향으로, 저작도구가 동결 영상 메타를 아웃박스 기반 단방향 복제로 써 넣는 대상이다. 저장 시 원본·데이터마트를 수정하지 않고 사용자별 작업 데이터로 LS_PORTAL_USER_LABEL 에 별도 적재한다(단방향, 마트 반영 안됨). 다운로드는 사용자 작업 데이터 기준·본인 데이터 기간 내. 반응형 웹(PC/태블릿/모바일), WCAG 2.1 AA. JWT 는 포털 서버 발급이며 동일 검증 로직(channel 클레임 분기)을 쓴다.

[폐기] SAM2 분할·추적(sam2-segment·sam2-track)을 포털에 예외적으로 노출한다 — 포털 전용 SAM2 경로는 두지 않는다. FE 도 채널 분기를 두지 않는다. ADR-013 의 예외는 포털 자산 업로드(UC-027) 한 건이며 SAM2 예외는 없다.

⚠ 본 UC 는 R1 기능 요구사항 대응이 없어 R2 유스케이스명세서 문서 범위에서는 제외되나, ITEM 자체는 유효한 활성 유스케이스다(SCREEN-028·SCREEN-029 가 이를 실현한다).
