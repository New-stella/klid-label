## description

KRDS Public(DS-001) 토큰 기반 고충실 디자인. 세션 확인 (로딩) + 인증 실패 안내. 로딩 상태는 인가 역할 확보가 끝나기 전까지 유지되는 상태로 그리며, 화면을 다시 불러올 때도 같은 확보를 수행함을 함께 표시한다. 실패는 두 가지를 한 표현으로 뭉개지 않는다 — 인증이 유효하지 않은 경우는 로그인 화면 이동(이동할 주소가 없을 때만 배너)으로, 역할을 다시 확보하는 조회 장애는 오류 배너로 구분해 그린다.
