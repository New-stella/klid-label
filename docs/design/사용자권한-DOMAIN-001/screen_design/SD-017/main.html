/ingress 공개 · 상단 메뉴와 좌측 메뉴가 없는 진입 화면

세션 인계 진입 화면

저작도구에는 자체 로그인 화면이 없습니다. 관제서버(내부) 또는 포털(외부)이 발급한 인증 토큰을 인계받아 진입하며, 이 화면은 그 인계를 처리하는 동안만 보입니다.

1세션 확인 — 진입 직후 기본 상태

세션을 확인하는 중

관제서버 또는 포털에서 전달한 인증 정보를 확인하고 있습니다. 확인이 끝나면 자동으로 이동합니다.

확보 완료 전 인가 역할을 확보하기 전에는 도착지를 판정하지 않고 이 상태를 유지합니다. 화면을 다시 불러올 때도 같은 확보를 수행하며, 확보는 채널을 가리지 않습니다.

2인증 실패 안내 — 이동할 로그인 화면이 없거나 권한 정보를 확인하지 못했을 때 표시

로그인 서버에 연결할 수 없습니다

관제서버 또는 포털에서 다시 접근해주세요.

인증 정보가 없거나 만료된 경우에는 원래 접근하려던 위치를 기억한 채 로그인 화면으로 자동 이동합니다. 이 안내는 이동할 로그인 화면 주소가 설정돼 있지 않은 경우에 보입니다.

인증 실패 토큰이 없거나 만료·검증 실패인 경우입니다. 로그인 화면으로 이동하며, 이동할 주소가 없을 때만 위 배너가 보입니다.

역할 재확보 실패 화면을 다시 불러오며 역할을 다시 확보하는 조회가 실패한 경우입니다. 그 밖의 조회 장애이므로 위 배너로 알리며, 역할 없음으로 다루지 않고 도착지 판정도 내리지 않습니다.

참고 인증 실패 안내에 들어가는 문구는 실패 사유에 따라 세 가지입니다 — 실제 화면에서는 이 중 하나만 위 자리에 표시됩니다.

② 세션이 만료된 경우

세션이 만료되었습니다

관제서버 또는 포털에서 다시 접근해주세요.

③ 권한 정보를 확인하지 못한 경우

권한 정보를 확인하지 못했습니다

잠시 후 다시 시도해주세요.

이 실패를 역할 없음으로 다루지 않습니다 — 최초 관리자 등록 안내로도, 역할 부여를 요청하라는 안내로도 바꾸어 표시하지 않습니다.

참고 이 화면이 진입할 때마다, 그리고 다시 불러올 때마다 수행하는 처리 순서입니다. 화면에 보이는 요소는 아니며, 어느 단계에서 멈추면 위 2번 상태가 되는지를 나타냅니다.
  1. 브라우저 저장소 또는 쿠키에서 인증 토큰을 인계받습니다. 주소창 질의 문자열로는 토큰을 받지 않습니다. 개발 환경에 한해, 두 경로에 토큰이 없으면 미리 설정해 둔 개발용 대체 토큰을 사용합니다.
  2. 받은 토큰의 내용을 화면에서 해석해 만료 여부를 확인합니다. 서명 검증은 이 화면에서 하지 않고 이후 서버 요청에서 처리합니다.
  3. 인가 역할을 저작도구에 다시 물어 확보합니다. 확보가 끝나기 전에는 도착지를 판정하지 않고 1번 상태를 유지합니다. 화면을 다시 불러올 때마다 확보하며 채널을 가리지 않습니다. 알아낸 역할은 인계 토큰을 두는 자리에 함께 보관하지 않습니다.
  4. 확인에 성공하면 채널에 따라 이동합니다 — 포털이면 포털 홈, 그 외에는 대시보드. 뒤로가기로 이 화면에 다시 남지 않도록 현재 화면을 교체하며 이동합니다.
  5. 실패하면 로그인 화면으로 이동합니다 — 개발 환경이면 개발용 로그인 화면, 운영이면 채널별 로그인 화면. 원래 접근하려던 위치를 함께 넘겨 로그인 후 그 자리로 돌아오게 하며, 허용된 주소로만 이동합니다. 이동할 주소가 없을 때만 2번 상태를 표시합니다.
  6. 역할을 확보하는 조회가 실패하면 원인에 따라 갈라집니다 — 인증이 유효하지 않으면 위와 같이 로그인 화면으로 이동하고, 그 밖의 조회 장애는 2번 상태로 알립니다. 확인하지 못한 상태를 역할 없음으로 읽으면 잘못된 안내로 보내지므로, 확보되지 않은 동안에는 도착지 판정을 내리지 않은 채로 둡니다.
