## description

라벨링·검수·마킹·목록 등 저작도구 전 화면의 페이지 응답속도 3초 이하 (초과 불가피 시 발주기관 협의). 페이지별 용량과 HTTP 요청 횟수를 최소화해 응답시간 기준을 만족한다.

[전제 — 조회 시점에 파생하는 표시 항목] 목록에 실리는 항목 가운데 검수 점유처럼 저장해 둔 값을 읽는 것이 아니라 조회 시점에 이력에서 파생하는 판정이 있다. 그런 항목은 영상별 최신 이벤트를 한 번의 조회로 합쳐 가져와야 한다 — 목록의 행마다 이력을 따로 되짚으면 조회가 행 수에 비례해 늘어 이 응답시간 기준을 지킬 수 없다. 이 전제는 위 기준값을 바꾸지 않으며, 그 기준이 성립하기 위한 조건이다.
