# 역할 판정 진실원을 관제 공유 MNG_ACCT_*에서 저작도구 자체 LS_USER_ROLE로 재전환 (ADR-017 supersede)

## context

ADR-017(2026-06-19)은 사용자·권한 판정의 진실원을 저작도구 전용 LS_USER_*/LS_AUTHRT_MPNG에서 관제 공유 MNG_ACCT_* 테이블로 통합하기로 결정했다. 그러나 관제 역할 마스터(MNG_ACCT_USER_AUTHRT 등)에는 REVIEWER/WORKER 같은 저작도구 고유 역할이 존재하지 않아, 관제 공유 스키마만으로는 저작도구 역할 개념을 표현할 수 없는 정합성 결함이 발생했다. 이를 해소하기 위해 저작도구 라벨링 역할 판정을 관제 계정 테이블에서 분리해 저작도구가 자체 소유하는 LS_USER_ROLE(V75)로 되돌린다.

## decision

### chosen_option

저작도구 자체 LS_USER_ROLE(V75)로 재전환(채택)

### justification

역할 판정(REVIEWER/WORKER) 진실원을 관제 공유 MNG_ACCT_*에서 저작도구 자체 소유 LS_USER_ROLE(V75)로 전환한다(2026-06-30). 화면 라우트 가드는 동일 role 값을 그대로 사용하므로 화면단 영향은 없으나, 역할 데이터의 소유권·조회 경로가 근본적으로 바뀐다. 이로써 ADR-017(관제 공유 MNG_ACCT_* 통합)을 supersede한다.

## brownfield

## considered_options

### 관제 공유 MNG_ACCT_* 유지(ADR-017 원안)

**cons**:

- 관제 역할 마스터에 REVIEWER/WORKER 부재 — 저작도구 고유 역할을 표현할 수 없는 정합성 결함 지속

**pros**:

- 사용자/권한 단일 진실원(관제 기준)
- 중복 스키마 없음

- **description**: 사용자·권한 진실원을 관제 공유 MNG_ACCT_*로 유지하고 저작도구는 validate/참조만.

### 저작도구 자체 LS_USER_ROLE(V75)로 재전환(채택)

**cons**:

- 사용자/권한이 관제 공유와 다시 이원화됨
- 향후 관제와 동기화 요구 시 재작업 가능성

**pros**:

- 저작도구 고유 역할(REVIEWER/WORKER) 완전 표현 가능
- 정합성 결함 해소
- 화면 라우트 가드는 동일 role 값을 사용해 화면단 영향 없음

- **description**: 저작도구 라벨링 역할 판정을 관제 계정 테이블에서 분리해 자체 소유 LS_USER_ROLE(V75)로 되돌린다.
