## description

저작도구가 소유하는 사용자 마스터와 인가 역할 매핑, 그리고 역할 자가부여 시도 제한 집계. 저작도구에는 독립 로그인 화면이 없고 관제(내부)·포털(외부)이 발급한 토큰을 인계받으므로 비밀번호 같은 자격증명을 보관하지 않는다. 사용자 표시 정보는 역할을 청구하는 시점에 인계값으로 자동 등록·갱신되고, 인가 판정의 단일 진실원은 역할 매핑(LS_USER_ROLE)이다. 두 테이블은 사용자 번호로만 연결하고 외래키를 두지 않는다(집합체 사이는 식별자 참조). 역할은 원래 관제가 소유한 공유 권한 매핑 테이블에 있었고, 저작도구 전용으로 분리·이관한 뒤 그 공유 테이블은 삭제됐다. (V75·V132·V169 신설) + LsAcntUser · LsUserRole 엔티티.
