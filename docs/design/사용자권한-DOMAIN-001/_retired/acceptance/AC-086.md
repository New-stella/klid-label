# 인가에 쓰는 역할은 저작도구가 보관한 값이다

## notes

역할 체계가 서로 다른 두 시스템이라 상대의 역할 이름을 그대로 인가에 쓰면 뜻이 어긋난다. 더 중요한 것은 토큰에 담긴 값은 발급한 쪽이 정한다는 점이다 — 그 값을 그대로 믿으면 저작도구의 권한 구성을 저작도구 밖에서 정하게 된다.

## priority

critical

## scenario

### then

- 저작도구가 보관한 역할로 접근이 판정된다
- 토큰에 담긴 역할 값은 판정에 쓰이지 않는다
- 저작도구에 그 사용자의 역할 기록이 없으면 어떤 역할도 주어지지 않는다

### when

- 그 토큰으로 저작도구 기능을 호출한다

### given

- 외부 시스템이 발급한 내부 채널 토큰에 그 시스템의 역할 값이 담겨 있다

## statement

기능 접근을 판정하는 역할은 저작도구가 보관한 역할 기록에서 읽으며, 인계받은 토큰에 담긴 역할 값은 판정에 쓰지 않는다.
