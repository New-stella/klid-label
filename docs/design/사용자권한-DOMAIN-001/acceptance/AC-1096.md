# 정적 토큰 override 가 설정되면 동적 발급보다 우선한다

## notes

근거: ADR-063 v4 결정 ⑥, CO-20260905 §3. 관제팀이 별도 토큰을 주는 경우의 하위호환 경로. QA override 실단언.

## priority

medium

## scenario

### then

- x-access-token 헤더에 설정된 정적 토큰 값이 그대로 실린다
- 발송 시점 동적 발급기(ControlNotifyTokenProvider)는 호출되지 않는다

### when

- 저작도구가 관제 통지를 발송한다

### given

- 정적 토큰 override(authoring.control-notify.token / env CONTROL_NOTIFY_TOKEN)에 값이 설정돼 있다
- 관제 통지가 활성화되어 있다

## statement

authoring.control-notify.token(env CONTROL_NOTIFY_TOKEN) 설정값이 있으면 그 값이 그대로 x-access-token 헤더에 실리고 발송 시점 동적 발급기(ControlNotifyTokenProvider)는 호출되지 않는다.
