# 이미 가진 역할을 다시 저장하면 아무것도 바뀌지 않는다

## notes

역할 기록이 아직 없는 사용자에게 처음 역할을 부여하는 것은 같은 값을 다시 적용하는 것이 아니므로 이 기준의 대상이 아니며 그때는 저장이 일어난다.

## priority

medium

## scenario

### then

- 요청은 성공하고 응답은 작업자를 돌려준다
- 역할 기록의 수정 시각이 갱신되지 않는다
- 인가 역할 캐시가 비워지지 않는다

### when

- 검수자가 그 사용자의 역할을 작업자로 다시 저장한다

### given

- 어떤 사용자가 작업자 역할을 갖고 있다

## statement

사용자가 이미 가진 역할과 같은 값으로 역할 변경을 요청하면 저장도 인가 역할 캐시 무효화도 일어나지 않고 요청은 성공으로 끝난다.
