## statement

관리자(ADMIN)가 /admin/users(SCREEN-024)에서 사용자 목록을 조회하고(GET /v1/users=API-001, 서버 페이징 20건/페이지, 등록 순서 고정) 이름·이메일 부분일치 검색과 역할 필터(전체/관리자/검수자/작업자/포털)를 확정하면 서버가 재조회해 1페이지로 리셋한다. 행의 계정 활성 배지는 외부(관제) 소유 읽기 전용이다. '수정' 모달에서 역할을 골라 저장하면 역할 값만 PATCH /v1/users/{userNo}(API-004)로 보내며, 이 쓰기는 유효한 관리자 단기 유효창을 함께 요구한다(역할을 대체하지 않고 가산, 승격 아님). 서버가 허용 역할 화이트리스트로 재검증하고 성공 시 즉시 반영·목록 최신화하며 바꾼 사람을 개인 단위로 기록한다.
