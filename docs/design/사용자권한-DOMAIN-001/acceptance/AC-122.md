# 자격 저장 위치가 비어 있으면 배포 설정값으로 판정하고, 둘 다 없으면 아무 패스워드도 통과하지 않는다

## notes

되돌아가는 갈래가 없으면 자격이 저장 위치로 옮겨간 직후의 최초 상태에서 관리 기능이 통째로 잠긴다 — 들어갈 수 없으니 패스워드를 넣을 수도 없는 잠금이다.

반대로 둘 다 없을 때 통과시키는 갈래를 두면 자격이 없는 상태가 곧 무제한 접근이 된다. 그래서 그 경우는 막는 쪽으로 어긋나게 한다 — 이 방향은 저장 위치를 읽지 못하는 장애 상황에도 같다.

## priority

high

## scenario

### then

- 값이 있으면 그 값으로 판정한다
- 저장 위치가 비어 있으면 배포 설정값으로 판정해, 한 번도 교체하지 않은 상태에서도 관리 기능에 들어갈 수 있다
- 둘 다 없으면 어떤 패스워드를 넣어도 통과하지 않는다
- 교체가 한 번이라도 성공한 뒤에는 저장 위치의 값이 판정을 맡고 배포 설정값으로 되돌아가지 않는다

### when

- 자격 저장 위치에 값이 있다
- 자격 저장 위치가 비어 있고 배포 설정값만 있다
- 자격 저장 위치도 배포 설정값도 없다

### given

- 관리자 유효창을 열려고 패스워드를 제출한다

## statement

관리자 패스워드 판정은 자격 전용 저장 위치의 값을 먼저 쓰고, 그 위치가 비어 있으면 배포 설정값으로 되돌아가며, 둘 다 없으면 어떤 패스워드도 통과시키지 않는다.
