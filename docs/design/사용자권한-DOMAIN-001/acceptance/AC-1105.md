# 관제 채널 세션 만료 연장 팝업 — 임계 도달 시 표시(감시 주기 되풀이 없음)·「로그아웃」·「로그인 연장」 두 버튼만(ESC·배경 클릭 무반응)·만료 시 로그아웃·셸 밖 전체 화면 적용·미저장 편집 경고와 만료 시 확인 없이 이동

## notes

팝업의 치수·색·문구 전체는 [[SHELL-001]] 이 소유한다. 이 수용기준은 표시 횟수·닫힘 수단·버튼 구성·결말·적용 범위만 단언하며 시각 값을 복제하지 않는다.

## priority

high

## scenario

### then

- 팝업이 뜨고 제목에 「N분 N초 후 자동 로그아웃 됩니다.」가 남은 시간과 함께 매초 갱신되어 표시된다 — 임계에 닿으면 띄우되 매 감시 주기마다 되풀이하지 않는다
- 팝업의 버튼은 「로그아웃」과 「로그인 연장」 둘뿐이며 닫기 버튼과 닫기 아이콘(X)은 없다
- 「로그아웃」이나 「로그인 연장」 중 하나를 누르면 팝업이 닫힌다 — 같은 토큰 수명 동안 팝업이 다시 뜨지 않는 것은 「로그인 연장」이 성공했을 때와 「로그아웃」으로 실제 이탈했을 때뿐이고, 「로그아웃」을 눌렀다가 미저장 확인에서 취소해 화면에 남으면 그 억제가 풀린다
- ESC 를 누르거나 배경을 눌러도 팝업이 닫히지 않는다
- 「로그인 연장」을 누르면 저작도구 갱신 창구 [[API-247]] 가 refresh 토큰을 요청 본문에 실어 호출되고, 성공하면 저장소의 klid-jwt-token · tokenInfo(13개 필드 — expiresAt·issuedAt 은 밀리초, 접근 불가 메뉴 클레임이 없으면 inAccessibleMenus 는 빈 배열) · userNm 이 관제지원 웹과 같은 모양으로 저장된다
- 갱신이 성공하면 이 탭이든 다른 탭이든 떠 있는 팝업이 닫히고 만료 기준이 새 토큰의 만료 시각으로 바뀌며 표시 이력도 초기화되어 새 토큰 수명에서는 임계 도달 시 팝업이 다시 한 번 뜬다 — 표시 이력이 풀리는 것은 갱신 성공만이 아니라 「로그아웃」을 눌렀다가 미저장 확인에서 취소해 화면에 남았을 때도 같다
- 남은 시간이 0 이 되면 팝업을 닫고 세션을 비운 뒤 관제지원 웹 로그인 화면으로 이동한다 — 연장이 일시 장애로 실패해 현재 토큰으로 계속 쓰던 경우도 같다
- 라벨링 캔버스 전체 화면에서도 셸 안의 화면과 같은 시점에 같은 팝업이 뜨고 같은 결말을 따른다
- 로그인 전 화면(진입·오류·개발용 로그인)에는 팝업이 뜨지 않는다
- 저장하지 않은 편집이 있는 화면에서 연장 팝업이 뜨면 본문에 「저장하지 않은 작업이 있습니다」 취지의 경고가 함께 표시되고, 저장하지 않은 편집이 없으면 그 경고는 표시되지 않는다
- 저장하지 않은 편집이 남은 채 남은 시간이 0 이 되면 미저장 확인 절차(공통 확인 창·브라우저 이탈 경고)를 거치지 않고 — 확인 창에서 멈추지 않고 — 세션을 비운 뒤 관제지원 웹 로그인 화면으로 이동하며, 그 편집을 자동으로 저장하지 않는다
- 「로그아웃」을 누르면 저작도구 로그아웃 창구 [[API-246]] 가 호출되고(access 토큰을 Authorization 으로), 응답(항상 204)과 무관하게 저장소 토큰 키(klid-jwt-token · tokenInfo)가 지워진 뒤 관제지원 웹 로그인 화면으로 이동한다 — 저장소를 공유하는 같은 출처의 관제지원 웹 탭도 함께 로그아웃된다
- 「로그인 연장」의 갱신을 관제가 거절하면(관제 응답의 error 가 0 이 아니어서 [[API-247]] 이 401 로 답함) 즉시 세션을 비우고 관제지원 웹 로그인 화면으로 이동하며 거절된 refresh 토큰으로 다시 갱신하지 않는다. 일시 장애(네트워크 오류, 또는 관제에 닿지 못해 [[API-247]] 이 503 으로 답함)로 실패하면 아무것도 저장하지 않고 현재 토큰으로 계속 쓰며, 남은 시간이 0 이 되면 로그아웃한다
- 「로그아웃」을 눌렀을 때 저장하지 않은 편집이 있으면 화면 이탈 시의 공통 미저장 확인 절차(공통 확인 창·브라우저 이탈 경고)가 뜨고, 취소하면 로그아웃하지 않고 그 화면에 남는다. 계속을 고르면 저작도구 로그아웃 창구 [[API-246]] 가 호출되고(access 토큰을 Authorization 으로), 응답(항상 204)과 무관하게 저장소 토큰 키(klid-jwt-token · tokenInfo)가 지워진 뒤 관제지원 웹 로그인 화면으로 이동한다
- 저장하지 않은 편집이 없으면 「로그아웃」을 눌렀을 때 확인 절차 없이 바로 로그아웃된다
- 미저장 확인 절차는 사용자가 누른 「로그아웃」에만 붙는다 — 강제 로그아웃(갱신 거절 · 401 뒤 갱신 실패 · 남은 시간 0)은 확인 절차 없이 세션을 비우고 관제지원 웹 로그인 화면으로 이동한다
- 「로그아웃」을 눌렀을 때 뜬 미저장 확인 절차에서 취소하면 로그아웃하지 않고 그 화면에 남으며, 같은 토큰 수명 동안 다시 띄우지 않는다는 표시가 풀려 다음 감시 주기에 남은 시간이 여전히 임계 이하이면 팝업이 다시 뜬다 — 「로그인 연장」이 성공했거나 확인 절차 없이 로그아웃한 경우에는 종전대로 다시 뜨지 않는다
- 「로그인 연장」과 「로그아웃」 어느 쪽에서도 브라우저는 관제지원 계정 서비스의 창구를 직접 호출하지 않는다 — 브라우저가 부르는 것은 저작도구 갱신 창구 [[API-247]] 와 로그아웃 창구 [[API-246]] 뿐이며, 관제 계정 서비스 호출은 저작도구 서버가 한다([[INT-015]])

### when

- 남은 시간이 임계 이하가 된다
- 사용자가 「로그아웃」을 누른다
- 사용자가 ESC 를 누르거나 팝업 바깥 배경을 누른다
- 사용자가 「로그인 연장」을 누른다
- 다른 탭(관제 탭 포함)이 토큰을 갱신한다
- 남은 시간이 0 이 된다
- 저장하지 않은 편집이 남은 화면에서 남은 시간이 임계 이하가 되거나 0 이 된다
- 「로그인 연장」의 갱신을 관제가 거절하거나(error 가 0 이 아님) 일시 장애(네트워크 오류·5xx)로 갱신이 실패한다

### given

- 관제 채널로 로그인된 상태이고 저장소에 access 토큰과 토큰 정보(tokenInfo)가 있다
- 알림 임계는 토큰 정보가 실어 온 분 값이며, 없으면 같은 이름의 access 토큰 클레임, 그것도 없으면 30분이다
- 사용자는 셸이 감싸는 화면 또는 셸이 감싸지 않는 라벨링 캔버스 전체 화면에 머물러 있다
- 화면에는 저장하지 않은 편집(라벨링 캔버스 등의 미저장 변경)이 남아 있을 수도 있고 없을 수도 있다

## statement

관제 채널의 로그인된 모든 화면은 세션 만료가 다가오면 연장을 권하는 팝업을 띄운다 — 임계에 닿으면 띄우되 매 감시 주기마다 되풀이하지 않는다. 팝업의 모양·문구·임계 조달 순서의 정본은 [[SHELL-001]], 호출 창구의 정본은 갱신 [[API-247]] · 로그아웃 [[API-246]], 관제 연동(외부 엔드포인트·헤더·응답·실패 코드)의 정본은 [[INT-015]], 인계 창구 동작과 저장 형식의 정본은 [[INT-013]] 이며 이 수용기준은 그 사양이 지켜지는지를 검증한다. 브라우저는 관제 계정 창구를 직접 호출하지 않는다 — 갱신과 로그아웃 모두 저작도구 서버의 창구만 부르고, 관제 계정 서비스 호출은 저작도구 서버가 중계한다.

팝업은 관제지원 웹의 세션 팝업과 같게 동작한다 — 감시 주기마다 되풀이해 띄우지 않고, 버튼은 「로그아웃」과 「로그인 연장」 둘뿐이며 닫기 버튼·닫기 아이콘을 두지 않고 ESC·배경 클릭으로도 닫히지 않는다. 두 버튼 중 하나를 누르면 팝업이 닫힌다 — 같은 토큰 수명 동안 다시 띄우지 않는 것은 「로그인 연장」이 성공했을 때와 「로그아웃」으로 실제 이탈했을 때뿐이다. 「로그아웃」은 관제지원 웹의 로그아웃과 같은 결말(저작도구 로그아웃 창구 [[API-246]] 호출 후 저장소 토큰 삭제·관제 로그인 화면 이동 — 관제 서버 세션 종료는 저작도구 서버가 중계한다)을 따른다. 저장하지 않은 편집이 남아 있으면 그 전에 화면 이탈 공통 확인 절차를 거치며, 취소하면 로그아웃하지 않고 그 화면에 남는다. 취소로 남은 경우에는 한 번 띄웠다는 표시도 함께 풀려, 남은 시간이 여전히 임계 이하이면 다음 감시에서 팝업이 다시 뜬다. 한 화면에 가장 오래 머무는 라벨링 캔버스가 셸이 감싸지 않는 전체 화면이므로, 팝업은 셸 안에서만이 아니라 그 화면에서도 같게 동작해야 한다.

저장하지 않은 편집이 남은 화면에서는 팝업이 그 사실을 함께 경고한다. 만료 결말은 미저장 편집이 있어도 멈추지 않는다 — 미저장 확인 절차를 거치지 않고 로그인 화면으로 보내며, 편집을 대신 저장하지 않는다. 확인 절차는 사용자가 스스로 누른 「로그아웃」에만 붙고, 강제 로그아웃에는 붙지 않는다.
