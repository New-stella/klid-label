## scenario

### then

- 발급처 허용 목록 검증을 통과한다(목록 밖이면 인증 실패 거부)
- 채널 표식으로 내부/포털이 갈린다(표식 없으면 내부)
- 내부 채널은 저작도구 보관 역할로 인가가 해석된다(주체 식별자 비숫자면 거부)
- 역할 없는 내부 진입자는 작업자로 자동 등록되고 배정 대상 목록에 나타난다(기존 역할 미덮음)
- 관리자는 검수자 자리를 계층으로 물려받되 작업자 전용 자리는 열리지 않는다
- 세션 만료 시 각 상위 시스템 로그인 화면으로 되돌아간다

### when

- 상위 시스템이 발급한 유효한 토큰을 채널 수단으로 인계받아 진입한다

### given

- 상위 시스템이 저작도구와 같은 발급처로 토큰을 발급한다
- 저작도구는 세션 토큰을 스스로 발급하지 않는다

## statement

상위 시스템(관제서버/포털)이 발급한 토큰을 저작도구 프론트가 채널별 수단으로 인계받으면, 시스템이 발급처 허용 목록을 검증하고(목록 밖이면 인증 실패로 거부) 채널 표식으로 내부/포털을 가른 뒤(표식 없으면 내부), 내부 채널이면 저작도구가 보관한 역할로 인가를 해석하고(주체 식별자가 숫자가 아니면 닫힌 채로 거부), 역할이 없는 내부 진입자는 그 시점에 작업자로 자동 등록한다(이미 부여된 역할은 덮지 않음). 채널과 역할로 각 창구 접근을 판정하며 관리자는 검수자 자리를 계층으로 물려받되 작업자 전용 자리는 열리지 않는다.
