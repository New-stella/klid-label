## description

외부 비식별 솔루션 옵션을 관리(/v1/manage/*) 화면에서 REVIEWER 가 설정. SystemConfigController.update(PUT /v1/manage/configs/{key}, REVIEWER 전용, WORKER 403, 범위 초과 400) → SystemConfigService.update 가 비식별 옵션 설정값을 LS 설정 테이블에 저장 + Caffeine 캐시 전체 무효화로 이후 비식별 요청에 새 값 적용. 비식별 옵션 전용 별도 엔드포인트는 없으며 일반 시스템 설정 키-값 관리 경로를 공유한다.
