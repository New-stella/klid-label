# 재비식별 강제 재생성 + resolve fail-closed 게이트

## context

재비식별 시 기존 비식별 프레임이 멱등 skip되어 APPROVED 영상은 재비식별해도 프레임이 갱신되지 않던 결함이 있었다. 또한 신고 해제(resolve) 시 신고 이전 stale 산출물로 우회 복원되던 위험(CWE-359)이 있었다.

## decision

### chosen_option

강제 재생성 + resolve fail-closed 게이트(채택)

### justification

①재비식별 경로는 refreshExisting=true로 비식별 프레임을 강제 재생성한다. ②resolve는 fail-closed 게이트: procLog 경로 파일 실존 + '신고 이후 시점' 재비식별 판정(완료시각/mtime 비교) 통과해야 DE_IDNTF_YN='F'→'Y' 복원, 미충족 시 409로 거부한다.

## considered_options

### 멱등 skip 유지 + resolve 무조건 허용(구, 결함)

**cons**:

- APPROVED 영상 재비식별 시 프레임이 갱신되지 않음
- 신고 이전 stale 산출물로 우회 복원 가능(CWE-359)

**pros**:

- 구현 단순

- **description**: 재비식별 시 기존 비식별 프레임이 있으면 skip, resolve는 별도 검증 없이 F→Y 전환

### 강제 재생성 + resolve fail-closed 게이트(채택)

**cons**:

- 재비식별마다 프레임 전체 재생성으로 처리 비용 증가

**pros**:

- 재비식별 시 프레임이 항상 최신으로 갱신됨
- stale 산출물로의 우회 복원 차단

- **description**: 재비식별 경로는 refreshExisting=true로 비식별 프레임을 강제 재생성. resolve는 procLog 경로 파일 실존 + 신고 이후 시점 재비식별 판정(완료시각/mtime 비교) 통과해야 F→Y 복원, 미충족 시 409
