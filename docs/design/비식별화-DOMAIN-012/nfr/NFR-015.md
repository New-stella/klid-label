## description

저작도구 프론트엔드(React 18 + TypeScript) 웹표준 기준:
- 액티브X 등 비표준 기술(플러그인) 없이 HTML5 기반으로 전 기능 동작 (라벨링 캔버스는 konva.js 웹표준 Canvas)

- 표준 (X)HTML·CSS 문법 준수 — W3C Markup/CSS Validation 통과
- 포털 화면은 PC/태블릿/모바일 반응형 — 웹 접근성(WCAG 2.1 AA)과는 별개의 웹표준 관점이다
- 이용자가 쉽고 편리하게 이용할 수 있는 UI/UX를 설계·구현하고 공개된 정보에 대한 접근 개방성을 확보한다
- 웹사이트 품질진단 기준에 따른 진단을 실시하고 그 결과를 제출한다
