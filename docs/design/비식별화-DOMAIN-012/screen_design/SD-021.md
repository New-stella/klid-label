## description

KRDS Public(DS-001) 토큰 기반 고충실 디자인. 페이지 헤더 + 신고 상태 필터 탭 + 신고 목록 테이블 + 비식별 산출물 선택 다이얼로그에 더해, 이관으로 들어와 승인 보류가 선 영상 목록과 그 보류를 푸는 비식별 완료 기록 창구를 담는다. 보류 목록은 탭 안이 아니라 목록 아래에 따로 세웠다 — 신고는 작업자가 올린 것이고 보류는 이관이 만든 것이라 축이 다르며, 탭 안에 넣으면 두 축이 한 목록으로 읽힌다. 보류 사유는 배지 하나로 그치지 않고 아래 줄에 무엇을 하면 풀리는지를 함께 적고, 목록 위에는 보류가 검수 승인만 막고 착수·라벨 조회·프레임 열람은 막지 않는다는 사실을 먼저 밝혀 처음 오는 사람이 보류를 아무것도 못 하는 상태로 읽지 않게 했다. 기록 창구는 산출물 가져오기 화면의 같은 행위와 표현을 맞췄고, 이름이 맞는 파일이 없는 프레임은 비워 둔 채 산출물에 나간다는 경고를 누르기 전에 띄운다.
