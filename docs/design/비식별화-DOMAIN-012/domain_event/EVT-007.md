## description

비식별 누락 신고가 해소되어 그 영상의 신고 게이트가 다시 열렸음을 알리는 이벤트. 신고 구간에 보류됐던 파이프라인 작업을 재개시킨다.

[★DeidentReportResolved 와의 차이 — 둘을 합치지 말 것]
· DeidentReportResolved 는 검수 승인(APPROVED) 영상에만 발행된다. 소비자가 재검토 표시와 재승인 시점 재산출이라 미승인 영상에는 발행할 이유가 없다(불필요한 v1 생성 방지).
· 본 이벤트는 게이트가 열린 모든 노드에 발행된다. VLM 시계열 위탁은 파이프라인 진행 중(=대개 미승인) 영상에서 보류되므로, 승인 전용 이벤트만 있으면 재개 신호가 영원히 도달하지 않아 시계열 메타가 영구 결손된다.

[발행 범위 = 차단 범위와 대칭] 해제된 영상 하나뿐이다. 차단 게이트가 자기 rawSn 행만 보므로 신고가 막던 영상도 그 하나이며, 파생영상은 원본 신고에 영향받지 않으므로 발행 대상도 아니다(2026-07-29 확정). 조상/자손 전파는 4라운드 시도 후 철회됐다 — 되살리지 말 것.

[발행] 비식별 누락 신고의 해소 처리에서 발행한다.
[소비] 해소 커밋 이후(AFTER_COMMIT) 보류 재개가 SKIPPED 기록(LS_BATCH_PROC_LOG)을 근거로 재위탁(멱등 조건: 시계열 메타 0건).
소비자는 AFTER_COMMIT 이어야 한다 — DE_IDNTF_YN 'F'→'Y' 복원이 커밋되기 전에 실행하면 재개된 작업이 진입부 게이트에서 스스로 다시 보류된다.
