## statement

외부 호출이 실패하면 DE_IDNTF_YN='F'로 마킹하고 원본을 보존하며(원본 절대 삭제 금지) LS_DEIDENT_PROC_LOG에 실패 상태·오류를 기록한다 — 자동 재비식별 큐는 없고 작업자/검수자가 외부 솔루션으로 수동 재비식별한 뒤 resolve로 해소한다(UC-016). 수락 응답도 결과 회신도 관측되지 않은 건은 미결 회수 스위퍼가 주기적으로 다시 집어 재위탁하며(in-memory subscription은 노드가 죽으면 사라져 실패 행조차 없으므로 스위퍼가 유일 회수 경로), 수락 대기 창(ACK)과 결과 대기 창(콜백)을 구분해 정상 위탁을 잘못 회수하지 않고 2노드 Active-Active에서 조건부 UPDATE로 원자 클레임해 두 번 재위탁하지 않는다. 대상 영상이 비식별 재처리 대기(DE_IDNTF_YN='F')면 외부 위탁을 개시하지 않고 보류한다.
