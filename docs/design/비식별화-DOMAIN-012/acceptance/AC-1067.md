## scenario

### then

- 이미 잠금 재신고는 409, OPEN 아닌 resolve 재호출은 409(영향행수 0)
- 비-MARKING_READY 마킹 신고는 412(단일 문구·CWE-209)
- 파생 신고는 412·사유만(원본 미유도·신고 행 미생성·WARN 감사), 타인 배정은 403(IDOR)
- 비식별 결과 미성공은 DE_IDNTF_YN='F'·이력 FAILED·오류 코드 기록

## statement

이미 재비식별 진행 중(LOCKED_FOR_REDEIDENT)인 영상에 재신고하면 작업락 UNIQUE 제약 최후 방어로 409를 반환한다. OPEN이 아닌(RESOLVED/DISMISSED) 신고를 resolve 재호출하면 409(OPEN→RESOLVED 조건부 UPDATE 영향행수 0으로 판정). 배치 단계가 MARKING_READY가 아닌 상태의 마킹 단계 신고는 412(상태를 구분 않는 단일 문구 — CWE-209, 화면은 마킹 대기 아니면 진입 자체를 막고 그 상태 신고는 라벨링 화면 담당). 파생영상(ORGNL_RAW_SN non-null) 신고는 412로 거부하고 사유만 안내한다(원본 미유도·부모 rawSn 미제공, 신고 행 미생성·REVIEWER 알림 없음·정제 후 WARN 감사). WORKER가 본인 배정 아닌 영상을 신고/해소하면 403(IDOR). 외부 비식별 결과가 성공(SUCCEEDED)이 아니면 DE_IDNTF_YN을 F로 마킹하고 이력에 FAILED·오류 코드를 기록한다.
