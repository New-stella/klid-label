## description

작업 안내를 게시하고 읽는 흐름이다. 쓰기는 검수자 이상이 하고 관리자는 역할 계층으로 같은 일을 하며, 작업자는 발행된 글만 읽는다.

[초안은 존재 자체가 드러나지 않는다] 발행하지 않은 글은 작업자의 목록에 담기지 않고 식별자를 직접 지정해 상세를 요청해도 찾을 수 없다는 응답으로 돌아온다 — 권한이 없다는 응답으로 구분되지 않는다.

[발행 일시는 현재 상태의 전이 시점이다] 발행을 취소하면 비워지고 다시 발행하면 새로 기록되며 최초 발행 이력은 보존하지 않는다.

[첨부는 이름을 새로 만들어 보관한다] 사용자가 준 이름을 그대로 쓰지 않고 새로 만든 이름으로 정해진 폴더 안에만 저장하며, 원본 이름은 저장소에만 보관하고 기록에는 남기지 않는다.

[포털 채널은 이 흐름에 닿지 않는다] 채널이 다르기 때문이며 발행 여부와 무관하다.

## alternate_flows

### 작업자가 초안에 접근

**steps**:

- 목록에서 초안이 제외된다
- 상세를 직접 요청해도 찾을 수 없음으로 거부된다
- 권한 없음으로 구분되지 않아 존재 여부가 드러나지 않는다

- **trigger**: 작업자나 포털 회원이 발행되지 않은 글을 요청한다

### 허용하지 않은 첨부

**steps**:

- 업로드가 거부되고 파일이 저장되지 않는다
- 그 공지에 첨부 기록이 남지 않는다

- **trigger**: 허용 목록 밖 확장자이거나 크기 상한을 넘는 파일을 올린다

### 작업자가 쓰기 주소로 직접 진입

**steps**:

- 권한 없음 화면으로 막힌다
- 목록과 상세 열람은 그대로 가능하다

- **trigger**: 작업자가 작성이나 수정 주소로 직접 들어온다
