# 공지 목록은 고정한 것을 앞에 두고 최신 순으로 돌아온다

## notes

정렬 기준이 고정 여부와 시각뿐이면 시각이 같은 공지들의 순서가 조회할 때마다 달라져, 쪽을 넘길 때 같은 공지가 두 번 보이거나 빠진다. 마지막에 유일한 값을 기준으로 하나 더 두어 순서를 확정한다.

## priority

medium

## scenario

### then

- 고정한 공지가 앞에 온다
- 같은 시각의 공지들도 조회할 때마다 같은 순서로 돌아온다

### when

- 공지 목록을 여러 번 조회한다

### given

- 고정한 공지와 고정하지 않은 공지가 섞여 있고 등록 시각이 같은 공지가 있다

## statement

공지 목록은 고정한 공지를 앞에 두고 그 안에서 최신 순으로 정렬해 쪽 단위로 돌아오며, 등록 시각이 같아도 순서가 흔들리지 않는다.
