## description

공지·가이드라인 게시판 물리 ERD. v1 원형(LS_NTC_BBS/LS_ATCH_FILE, ERD-006)을 재사용하지 않고 v2 신규 테이블로 구성. DRAFT→PUBLISHED 발행 상태 관리, 첨부파일은 UUID 저장 파일명 + 원본 파일명 DB 보관.
