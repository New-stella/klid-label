# 첨부는 저장 이름을 새로 만들고 정해진 폴더 밖으로 나가지 않는다

## notes

저장할 때만 확인하고 내려받을 때 확인하지 않으면, 기록된 경로가 나중에 바뀌었을 때 폴더 밖의 파일이 그대로 나간다. 원본 이름은 화면에 보여줄 때만 복원해 쓴다.

## priority

critical

## scenario

### then

- 보관 폴더 밖에 파일이 만들어지지 않는다
- 보관 폴더 밖의 파일을 내려받을 수 없다
- 저장된 이름은 원본 이름과 다르다

### when

- 그 파일을 첨부로 올리고 다시 내려받는다

### given

- 원본 이름에 상위 폴더로 거슬러 올라가는 표기가 담긴 파일이 있다

## statement

첨부는 원본 이름을 그대로 쓰지 않고 새로 만든 이름으로 저장하며, 저장할 때와 내려받을 때 모두 실제 경로가 정해진 보관 폴더 안에 있는지 확인한다.
