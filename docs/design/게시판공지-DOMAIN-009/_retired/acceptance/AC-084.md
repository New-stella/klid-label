# 첨부의 원본 이름은 로그에 남기지 않는다

## notes

원본 이름은 사용자가 정한 문자열이라 개행이나 제어문자가 섞이면 기록이 여러 줄로 갈라져 다른 기록을 지어낸 것처럼 보이게 만들 수 있고, 이름 자체가 개인을 식별하는 내용을 담기도 한다.

## priority

medium

## scenario

### then

- 식별자와 확장자와 크기가 남아 있다
- 원본 파일 이름은 남아 있지 않다

### when

- 그 처리 기록을 확인한다

### given

- 검수자가 첨부를 올린다

## statement

첨부 처리 기록에는 식별자와 확장자와 크기만 남기고 사용자가 올린 원본 파일 이름은 남기지 않는다.
