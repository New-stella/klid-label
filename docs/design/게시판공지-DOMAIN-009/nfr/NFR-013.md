### diff_summary

2차 RFP 보안 요구 중 저작도구 책임분(세션 종료·역할별 접근 통제) 수용 — 로그인 정책은 상위 시스템 책임

## description

인증·세션 통제 기준:
- 로그아웃·토큰 만료 시 세션 종료 — 만료 JWT 거부 및 상위 시스템(관제/포털) 로그인 페이지 리다이렉트
- 인증정보·시크릿은 소스코드에 하드코딩하지 않고 환경변수로 주입, 민감정보 암호화
- 관리 화면(/manage/*) 등 권한 페이지는 비인가자에게 노출되지 않도록 함
※ 로그인 실패 5회 제한·동시 로그인 차단은 인증 발급 주체(관제/포털) 책임 — 저작도구는 JWT 검증만 담당
※ 예외 — 시스템 설정 화면의 관리자 단기 유효창(연동 서버 주소 변경용)은 저작도구가 스스로 발급·검증·만료시키는 유일한 자체 세션이다. 관리자 공유 패스워드를 대조해 발급하며 기본 10분·상한 30분이고, 주소 설정 변경에만 효력이 있어 역할을 승격시키지 않는다.
