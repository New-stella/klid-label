## description

작업 안내를 게시하고 읽는 흐름을 그린다. 쓰기는 검수자 이상이 하고 관리자는 역할 계층으로 같은 일을 하며, 작업자는 발행된 글만 읽는다.

발행하지 않은 글은 작업자의 목록에 담기지 않고 식별자를 직접 지정해 상세를 요청해도 찾을 수 없다는 응답으로 돌아온다. 권한이 없다는 응답으로 구분되지 않아 존재 자체가 드러나지 않는다.

발행 일시는 현재 상태의 전이 시점이다. 발행을 취소하면 비워지고 다시 발행하면 새로 기록되며 최초 발행 이력은 보존하지 않는다.

첨부는 사용자가 준 이름을 그대로 쓰지 않고 새로 만든 이름으로 정해진 폴더 안에만 저장한다. 원본 이름은 저장소에만 보관하고 기록에는 남기지 않는다 — 사용자가 정한 문자열이 기록으로 흘러들면 기록이 오염되고 개인정보가 샐 수 있기 때문이다. 첨부 내려받기에는 일반 요청과 다른 전용 제한 시간을 건다.

작성 화면에는 첨부 영역이 없고 첨부는 수정 화면에서 다룬다. 목록에는 저장소 기본 키가 드러나는 번호 열을 두지 않는다. 포털 채널은 채널이 달라 이 흐름에 닿지 않으며 그것은 발행 여부와 무관하다.
