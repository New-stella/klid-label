# 도메인 모델 (Domain Model / Context Map)

## 작성 목적
> 학습데이터 저작도구의 bounded context(도메인)를 식별하고 도메인 간 협력 관계를 정의한다.
> 본 문서는 **전체 기능(기존 1차 + 2차 고도화)** 을 다루는 Track B의 기초 산출물이다.

## brownfield 2단계 방침
> - **Pass 1 (본 버전)**: 1차 시스템(타 업체 개발·상용 운영)을 **있는 그대로(preserved) baseline**으로 식별한다. "원래 무엇이 있었나".
> - **Pass 2 (✅ 완료, v2.0)**: 2차 고도화 변경을 얹었다 — 수정(modified)/신규(new: 마킹·외부 비식별)/폐기(deprecated: 생성형 AI 본체·데이터마트/Export). 역할 6→3 통합, '프로젝트→영상 단위' 전환 등. 상세 변경명세는 `brownfield-변경명세-2026-05-29.md` 참조.
>
> **소스 정정**: 1차 화면 수는 분석 MD가 "66개"로 표기했으나 원본 PDF 기준 **70개**가 정확하다(분석 MD 누락분 5종: 사용자 관리 03-05-01 + 게시판 관리 03-06-01~04. `03-04-02`는 결번). LogiCraft 레거시 카탈로그(LEGACY-060~129)는 70개 기준으로 등록됨.

## 도메인 목록 (1차 baseline 10종 → 2차 활성 7 · 폐기 3)

> 1차 baseline은 10종(모두 preserved). 2차 스코프 확정으로 **3종 폐기**. 상세 brownfield 분류는 `brownfield-변경명세-2026-05-29.md` 참조.

| 도메인 | 유형 | 핵심 책임(1차) | 2차 상태 |
|--------|:---:|----------|------|
| 사용자·권한 | supporting | 사용자 인증·역할/권한 관리 | 유지 (역할 6→3) |
| 프로젝트 관리 | core | 프로젝트 생성·설정·배정·완료 | ❌ **폐기** (영상 단위 전환, 배정→검수·영상관리→수집 이관) |
| 영상·프레임 수집 | core | 클립 수신·프레임 추출·전처리 | 유지 (+영상관리·마킹 신규) |

## 1. 사용자·권한 (supporting)

- **책임**: 사용자 인증(GPKI 연동), 역할 기반 접근 제어(RBAC), 메뉴별 접근 권한, 프로젝트별 권한 배정.
- **도메인 용어**: 작업자, 검수자(1차), 검수자(2차), 업로더, 슈퍼 관리자, 프로젝트 담당자.
- **협력 도메인**: 프로젝트 관리(권한 배정), 검수(검수자 역할).

## 2. 프로젝트 관리 (core) — ❌ 2차 폐기 (프로젝트 개념 폐기, 영상 단위 전환)

- **책임**: 프로젝트 5단계 생성(기본정보 → 메타 → 라벨 → 단계 → 권한), 라벨·메타·검수단계 설정, 영상/이미지 데이터 배정, 완료/완료취소 처리.
- **도메인 용어**: 프로젝트, 메타(질의문), 라벨 설정, 단계(가공/검수), 배정, 마감(완료).
- **협력 도메인**: 사용자·권한, 영상·프레임 수집, 라벨링, 검수.

## 3. 영상·프레임 수집 (core)

- **책임**: 지자체 클립영상 수신(Ingest), 룰셋 필터링, FFmpeg 기반 프레임 자동 추출(배치 1회/분), 이미지 전처리(리사이징·밝기/대비 보정), 메타데이터 기반 자동 분류.
- **도메인 용어**: 클립영상, 원천(원시)데이터, 프레임, FFmpeg 배치, 자동 분류.
- **협력 도메인**: 프로젝트 관리, 라벨링.

## 4. 라벨링 (core)

- **책임**: 바운딩박스·폴리곤·스켈레톤 라벨, 블러(비식별) 처리, 캔버스 도구(이동·회전·확대·그리드), 객체·메타·이슈 탭, 단축키, 전체 복사/붙여넣기.
- **도메인 용어**: 바운딩박스, 폴리곤, 스켈레톤, 블러, 객체 탭, 메타 탭, 이슈 탭, 트랙.
- **협력 도메인**: 프로젝트 관리, AI 보조 라벨링, 검수, 영상·프레임 수집.

## 5. AI 보조 라벨링 (core)

- **책임**: AI Tool(SAM 방식 클릭 세그멘테이션), Auto Labeling(YOLO 방식 객체 탐지), 트랙 모드(선형보간 기반 연속 프레임 자동 추적).
- **도메인 용어**: AI Tool, Auto Labeling, 트랙, 선형보간(Linear Interpolation), 트랙 고유번호.
- **협력 도메인**: 라벨링.

## 6. 검수 (core) — ⚠️ 2차 수정 (1·2차 → 단일 검수자 반복, 작업 배정 이관)

- **책임**: 1차/2차 검수 워크플로우, 프레임 상태 색상(연두/주황/빨강), 승인·반려, 관리자 확인 요청, 검수 이력.
- **도메인 용어**: 1차 검수, 2차 검수, 반려, 관리자 확인 요청, 제출.
- **협력 도메인**: 라벨링, 사용자·권한, 통계·대시보드.

## 7. 통계·대시보드 (supporting)

- **책임**: 작업자 월별/일별 작업 통계, 관리자 프로젝트 통계(전체/권한별/상태별/일일 진행률).
- **도메인 용어**: 진행률, 작업 건수, 배정 수, 완료 수, 반려 수.
- **협력 도메인**: 프로젝트 관리, 검수.

## 8. 데이터 증강·내보내기 (core) — ⚠️ 2차 수정 (내보내기·데이터마트 폐기, 증강만 잔존)

- **책임**: 5종 증강(밝게/어둡게/좌우반전/반전+밝게/반전+어둡게), 증강 상태 흐름(가능→대기→진행→완료/부분성공/실패) 및 자동 재처리, 학습 데이터 내보내기·데이터마트 등록.
- **도메인 용어**: 증강, 데이터마트, 데이터셋, 원천/학습 유형, 부분성공.
- **협력 도메인**: 라벨링, 검수.

## 9. 생성형 AI 연동 (supporting) — ❌ 2차 폐기 (생성 본체 외부)

- **책임**: Text2Image / Image2Image / Image2Video 생성, 메타데이터(계절·날씨·시간) 기반 생성, 업로더의 생성·업로드 데이터 검토·등록.
- **도메인 용어**: Text2Image, Image2Image, Image2Video, 프롬프트, AI 생성 여부.
- **협력 도메인**: 데이터 증강·내보내기, 사용자·권한.

## 10. 게시판·공지 (generic) — ❌ 2차 폐기 (미제공)

- **책임**: 공지사항 작성·관리, 게시글 목록·상세 조회.
- **도메인 용어**: 공지, 게시글.
- **협력 도메인**: 사용자·권한.
