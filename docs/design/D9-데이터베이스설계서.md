## 6. 데이터마트 적재용 View (V52)

관제서버 데이터마트가 검수 완료(`LS_RAW_DATA_STATUS.DATA_STTS_CD='APPROVED'`) 영상의 원본·비식별 프레임, 라벨, 시계열 메타를 영상 1건(`RAW_SN`) 단위로 일관되게 조회하도록 평면화된 View 5개 제공.

| View ID | View 명 | 책임 | 필터링 |
|---|---|---|---|
| KLID-AT-VW-001 | V_COMPLETED_VIDEO | 영상 메타 + 원본 영상 경로 + 검수 완료 일시 | `LS_RAW_DATA_STATUS.DATA_STTS_CD='APPROVED'` |
| KLID-AT-VW-002 | V_COMPLETED_FRAME | 프레임 페어 (`FILE_PATH`=원본, `SRC_BKUP_FILE_PATH`=비식별) | 검수 완료 영상의 프레임 |
| KLID-AT-VW-003 | V_COMPLETED_LABEL | 라벨 좌표 + 마스터 코드(NAME/COLOR/TYPE) 평면 | 검수 완료 영상의 라벨 |
| KLID-AT-VW-004 | V_COMPLETED_LABEL_ATTR | 라벨 속성값 + 속성 정의(NAME/INPUT_TYPE/VALUES_JSON) | 검수 완료 영상의 라벨 속성값 |
| KLID-AT-VW-005 | V_COMPLETED_META | 시계열 메타 (`META_KEY`/`META_VAL`) 승인본 | `LS_DATA_META_REVIEW.RVW_STTS_CD='APPROVED'` |

### 운영 컨벤션
- 비식별 영상 파일 경로는 `LS_DATA_RAW` 에 별도 컬럼이 없음 → 애플리케이션 레이어에서 `STORAGE_RAW_PATH` → `STORAGE_DEIDENTIFIED_PATH` 컨벤션 치환으로 도출.
- 모든 View 는 `CREATE OR REPLACE VIEW` 라 멱등 — Flyway 재실행 안전.
- 데이터마트 사용 패턴: `TASK_COMPLETED`/`TASK_MODIFIED` 통지 수신 후 `RAW_SN` 으로 5 View 단순 SELECT → 영상 1건=1 row UPSERT.
- 권한: 데이터마트 ETL 계정에 `GRANT SELECT ON klid_at.V_COMPLETED_* TO datamart_user`.
