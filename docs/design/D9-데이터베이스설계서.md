## 작성 범위 / 진실원

- **DBMS = PostgreSQL** (CLAUDE.md · R1 v1.2 확정). 템플릿 작성참고의 MariaDB 10.11 / MaxScale / utf8mb4 / InnoDB 전제는 본 프로젝트에 적용하지 않는다. 인코딩은 UTF-8, 스키마는 `klid_at`.
- **대상 테이블** = R1 16개 요구사항에 매핑된 R2 유스케이스(증강 / 라벨링 / 버전관리 / 검수 / 비식별 / 시계열 메타 / 영상 기반 작업)와 직접 관련된 저작도구 전용 `LS_*` 테이블만. (구 RQ-SFR-09-06/07은 2026-06-02 범위 외 삭제 — LS_SYSTEM_CONFIG 기반으로 본 명세 본래 제외 대상, 테이블 불변)
- **범위 외**(본 명세 제외): 사용자/권한(`MNG_ACCT_*`), 작업배정/상태(`LS_TASK_ASSIGNMENT`·`LS_RAW_DATA_STATUS`), 마킹(`LS_MARKING`), 포털(`LS_PORTAL_USER_*`), 통계/게시판, 배치로그(`LS_BATCH_PROC_LOG`·`LS_TASK_EVENT_LOG`), 웹훅 멱등(`LS_WEBHOOK_IDEMPOTENCY`), 관제통지 fallback(`LS_CONTROL_NOTIFY_FALLBACK`), Quartz(`QRTZ_*`), 관제서버 재사용 공유(`MNG_*` — `ddl-auto=validate` 참조 전용).
- **컬럼 진실원** = `backend/src/main/java/.../entity/*.java` 의 `@Column` 매핑 + `backend/src/main/resources/db/migration/V1~V53` Flyway 최종 상태(V3 행안부 표준 rename 반영). 본 문서의 모든 컬럼명·타입·길이·제약은 코드와 1:1 정합한다.

> **행안부 표준 적용 현황(샘플)**: 본 프로젝트의 `LS_*` 컬럼은 이미 행안부 공통표준용어 약어로 명명되어 있다 — `RAW_FILE_PATH_NM`(파일경로명), `DE_IDNTF_YN`(비식별여부), `PRVC_TYPE_CD`(개인정보유형코드), `EVNT_TYPE_CD`(이벤트유형코드), `LCLGV_CD`(지자체코드), `MDFCN_DT`(수정일시), `REG_DT`(등록일시), `LBL_TYPE_CD`(라벨유형코드), `RVW_STTS_CD`(검수상태코드), `LBL_INTGRT_PCT`(라벨정합률). 컬럼명은 코드 기준 그대로 표기하며 추측·임의 rename 하지 않았다.

## 3. 테이블 명세

> 컬럼 ID는 `KLID-AT-CL-{테이블 일련 2자리}-{컬럼 일련 2자리}`. 모든 컬럼명/타입/길이/제약은 엔티티 `@Column` + Flyway 최종 상태와 1:1 정합. PK는 `BIGINT GENERATED BY DEFAULT AS IDENTITY`(`@GeneratedValue(IDENTITY)`). FK는 운영 정책상 물리 FK 미설정(공유 DB 안정성 우선)이며 ID 참조이므로 아래 FK 열은 "논리 FK"를 표기한다. `REG_DT`/`MDFCN_DT` 등 일시 컬럼은 PostgreSQL `TIMESTAMP`(엔티티 `LocalDateTime`).

## 4. 작성 참고

- **DBMS**: PostgreSQL, 스키마 `klid_at`, 인코딩 UTF-8. (템플릿 예시의 MariaDB/InnoDB/MaxScale/utf8mb4 전제 미적용.)
- **마이그레이션 진실원**: Flyway 10.13 + `flyway-database-postgresql`, `backend/src/main/resources/db/migration/V1~V53`. V3에서 행안부 공통표준용어 약어 정합(예: `RAW_FILE_PATH_NM`, `DE_IDNTF_YN`, `PRVC_TYPE_CD`, `MDFCN_DT`).
- **JPA 정합**: `ddl-auto=validate` 고정. 본 명세 컬럼명은 엔티티 `@Column(name=...)` 와 1:1 일치.
- **키 생성**: PK는 `BIGINT GENERATED BY DEFAULT AS IDENTITY`(`@GeneratedValue(IDENTITY)`).
- **물리 FK 원칙적 미설정**: 공유 DB 운영 안정성 우선 정책으로 LS_* 간 물리 FK는 원칙적으로 정의하지 않고 ID 참조(논리 FK)로 관리한다. **예외**: `LS_LABEL_PRESET_CODE → LS_LABEL_PRESET`은 물리 FK `FK_LS_LABEL_PRESET_CODE_PRESET (PRESET_ID) REFERENCES LS_LABEL_PRESET(PRESET_ID) ON DELETE CASCADE`(V13)를 보유 — 프리셋 삭제 시 하위 코드 일괄 정리.
- **TEXT/대용량 컬럼**: `POINT_CN`, `LABEL_PAYLOAD`는 PostgreSQL `TEXT`. (JSONB 미사용 — 현 코드는 TEXT 직렬화. 검색 최적화 필요 시 JSONB+GIN 전환 검토.)
- **트리거**: 전 테이블 트리거 미사용. 일시 컬럼 갱신은 엔티티 비즈니스 메서드 / `@PrePersist`/`@PreUpdate`로 처리.
- **데이터마트 적재 View**(V52): `V_COMPLETED_VIDEO`/`V_COMPLETED_FRAME`/`V_COMPLETED_LABEL`(+ATTR)/`V_COMPLETED_META` — 검수 완료 영상만 노출하는 읽기 전용 `CREATE OR REPLACE VIEW`(멱등). 테이블 명세 대상 아님.
