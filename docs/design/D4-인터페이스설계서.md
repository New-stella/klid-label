# D4 인터페이스 설계서

> **ID 표기 규칙(공통)**: 본 산출물의 모든 ID(KLID-AT-UC/CO/DC/DCD/SD/SC/AC/EN/ERD/TB/II/IC/IF/UCD/ACT 등)는 **전체 형식 `KLID-AT-XX-NNN`** 으로 표기한다. 끝부분만(예: `UC-001`) 약식 표기 금지. 범위는 시작 ID만 전체형으로(예: `KLID-AT-UC-001~013`). ※ 요구사항(RQ-SFR-NN-NN)·시스템시험(KLID-ST-NNN) 등 타 체계 ID는 각 체계 원형 유지.

## 작성 목적
> 시스템의 내.외부 인터페이스를 식별하고 인터페이스의 명세를 기술한다.

## 작성 방법
> 식별된 인터페이스를 송신측과 수신측으로 구분하여 기술하고 송.수신간의 인터페이스 방식을 기술하며, 데이터 송신 시스템과 수신 시스템간의 데이터 저장소와 속성 등의 상세 내역을 기술한다.

- **송신 일련번호**: 한 개 송신단위에서 여러 개의 서브시스템으로 동시에 전송되는 경우에는 순차적으로 기술한다.

- **송신 프로그램 ID**: 송신에 해당하는 프로그램 ID를 기입한다.
- **전달 처리형태**: 인터페이스를 처리하는 형태를 기술한다. Batch / Online 등
- **전달 인터페이스방식**: 통신 프로토콜 및 통신 기술 방식을 기술한다.

## 부록 — 작성 보충

### 가. 관련 요구사항 ID 매핑 사유

인터페이스 목록의 '관련 요구사항 ID'는 R1 사용자요구사항정의서에 실존하는 ID만 기재한다. 본 산출물의 인터페이스는 외부 시스템 연동을 통해 다음 기능 요구사항을 실현하며, 매핑은 아래 근거에 따른다.

| 인터페이스 | 실현 요구사항 | 근거 |
|------------|-------------|------|
| KLID-AT-II-001 | RQ-SFR-08-04 | 오토라벨링(객체 탐지) 보조 |
| KLID-AT-II-002~004 | RQ-SFR-08-01 | 라벨링 정확도 향상(추적·분할) |
| KLID-AT-II-005~006 | RQ-SFR-08-03 | 시계열 메타 연동·검토 |
| KLID-AT-II-007~008 | RQ-SFR-05-01 | 영상 비식별화 |
| KLID-AT-II-009·KLID-AT-II-012 | RQ-SFR-07-01 | 외부 생성형 증강(겨울·야간·우천) |
| KLID-AT-II-010~011 | RQ-SFR-08-05 | 검수 완료·수정 통지 |
| KLID-AT-II-013 | RQ-SFR-09-01 | 포털 데이터 연동 |

> R1에 직접 대응 ID가 확정되지 않은 인터페이스는 목록에 `-` 로 표기하고 본 부록에 사유를 명시한다. 현재 전체 인터페이스가 위 기능 요구사항에 매핑되어 `-` 항목은 없다.

### 나. 길이 `-` 표기 사유

이진(이미지·영상·마스크)·좌표 배열·요약 객체 등 가변 길이 속성은 고정 길이를 부여하지 않으므로 '길이' 셀을 `-` 로 표기한다. 식별번호·구분 코드·경로·명칭 등 고정 자릿수 속성만 길이를 기재한다.

### 다. 비식별 연동 방식

비식별 연동은 결과 콜백 수신이 아닌 **위탁 → 진행 폴링 → 결과 회수** 단일 경로로 확정되었다(KLID-AT-II-007 위탁, KLID-AT-II-008 폴링). 외부 비식별 솔루션으로의 전송은 내부망 평문 전송과 자체 인증서 기반 보안 전송을 모두 지원하며, 운영 환경에서는 자체 인증서 신뢰 기반 보안 전송을 사용한다. 비식별 결과 콜백 수신 인터페이스는 운영하지 않는다.

### 라. 수신 상대 담당자 미정 항목

외부 시스템(AI 추론 서버·외부 VLM·외부 비식별 솔루션·외부 증강 시스템·관제서버·포털 DB) 측 인터페이스 담당자는 연동 협의 시점에 확정한다. 콜백 수신 인터페이스(KLID-AT-II-006·KLID-AT-II-009)의 수신 담당자는 저작도구 연동 담당자다.
