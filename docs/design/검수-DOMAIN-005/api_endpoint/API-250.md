[별도 자원이다] 단건 승인 주소에 질의 항목을 붙여 행위를 가르지 않는다. 같은 주소가 대상 수에 따라 다르게 동작하면 권한·감사·오류 처리가 한 자리에 섞인다.

[자격 — 두 조건이다] ① 유효 점유의 주인이 요청자 본인이고 ② 단건 승인이 허용하는 상태인 건만 승인된다. ①은 그 영상의 최신 검수 시작 기록이 요청자의 것이고, 그보다 뒤에 승인·반려 같은 종결 기록이 없으며, 유예가 지나지 않았다는 뜻이다. 유예는 배포 설정값이고 기본값은 30분이다 — 배포마다 바꿀 수 있으므로 고정된 계약 값으로 다루지 않는다. ②의 상태 축은 검수 진행으로 좁히지 않는다 — 단건 승인이 받아들이는 상태를 그대로 받아들이며, 수정 뒤 재검수를 기다리는 승인 영상도 여기에 든다. 남이 점유 중인 건과 아무도 점유하지 않은 건은 승인되지 않고 실패로 담긴다. ★이 제약이 이 창구의 안전장치다 — 한 번도 열어 보지 않은 영상을 무더기로 승인하는 길이 열리지 않는다. 단건 승인은 점유를 자격으로 삼지 않으며 그 비대칭은 의도된 것이다(ADR-067).

[부분 실패를 허용한다 — 되는 것만 처리한다] 건마다 독립해 처리하고 안 된 건은 식별자와 사유를 응답에 담아 돌려준다. ★한 건의 실패가 다른 건을 되돌리면 안 된다 — 처리 경계는 건별이다. 영상끼리 서로 영향을 주지 않으므로 한 건의 거부가 다른 건의 정합성을 해치지 않는다. 한 건도 승인되지 못해도 200 이며 판정은 결과 목록으로 한다. 대상 영상이 없거나, 상태가 맞지 않거나, 다른 사람이 먼저 처리했거나, 비식별 누락 신고가 열려 있거나, 비식별이 끝나지 않았거나, 라벨이 한 건도 없는 경우는 모두 그 건의 실패 사유이며 요청 전체를 거부하는 코드로 올리지 않는다.

[라벨 0건 확인 항목을 두지 않는다] 라벨이 한 건도 없는 영상의 승인은 그 영상 하나를 보고 내리는 판단이라 단건 승인 창구에서만 확인할 수 있다. 이 창구에서는 그 영상이 실패로 담기며 승인하려면 단건 승인으로 처리한다.

[★결과는 단건 승인과 완전히 같다] 각 건에 단건 승인과 동일한 처리를 적용한다 — 라벨 전체 스냅샷 동결·메타 동결·학습데이터 산출 폴더 재생성·관제 완료 통지·재검토 필요 표시 해제 가운데 하나도 빠지지 않는다. 승인 이력에는 건마다 행위자와 행위 시점 역할이 함께 남으므로 관리자가 승인한 건은 관리자로 남는다. 점유는 승인 기록으로 저절로 풀리며 해제 동작은 없다.
