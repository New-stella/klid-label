# 학습데이터셋 자동·수동 검수

## priority

critical

## scenario

### then

- 승인 시 LS_RAW_DATA_STATUS APPROVED 전이 + 라벨 버전 스냅샷 + export 새 버전 전량 재생성 + 그 산출이 성공한 뒤 TASK_COMPLETED 통지가 발행되고, 반려 시 사유 기록·재작업된다
- 비식별화완료여부가 N 인 영상의 승인은 거부된다
- 그 거부는 상태 전이보다 먼저 판정되므로, 거부될 때 검수 상태 전이도 라벨 버전 스냅샷도 학습데이터 산출물 새 버전 재생성도 관제 통지도 하나도 생기지 않는다
- 비식별화완료여부가 Y 로 바뀐 뒤의 승인은 주 흐름 그대로 진행되어 학습데이터 산출물이 만들어지고 통지가 발행된다
- 기본값이 Y 인 기존 영상은 이 조건 때문에 승인이 막히지 않는다
- 비식별화완료여부가 막는 것은 검수 승인뿐이다. 라벨 조회·프레임 이미지·영상 스트리밍·학습데이터 산출물 생성은 이 값으로 닫히지 않으며, 그 통로들까지 함께 닫는 것은 비식별 누락 신고 상태로서 이 값과는 별개의 축이다

### when

- REVIEWER가 영상 단위로 라벨·메타를 검토하여 승인 또는 반려한다
- REVIEWER가 비식별화완료여부가 N 인 영상을 승인하려 한다
- 비식별화완료여부가 Y 로 바뀐 뒤 같은 영상을 다시 승인한다

### given

- 작업자가 라벨링을 완료하고 검수 제출했다
- 외부에서 이미 라벨링이 끝난 산출물을 가져오는 경로로 원본이라고 지정해 들어온 영상은 검수 워크플로 상태와 같은 자리에 보관되는 비식별화완료여부가 N 으로 시작한다
- 그 경로와 무관한 기존 영상의 비식별화완료여부는 기본값 Y 다
