# UC-023 검수 일괄 승인 — 부분 실패 허용·성공분은 단건 승인과 같은 결과 (edge)

## priority

critical

## scenario

### then

- 요청자가 점유한 세 건이 승인되고 나머지 두 건은 각각의 사유와 함께 실패로 담긴다
- 한 건의 실패가 다른 건을 되돌리지 않는다 — 처리 경계는 건별이다
- 성공한 건의 결과는 단건 승인과 같다 — 라벨 스냅샷 동결·메타 동결·산출 폴더 새 버전 재생성·관제 완료 통지·재검토 필요 표시 해제 가운데 하나도 빠지지 않는다
- 승인 이력에는 건마다 행위자와 행위 시점 역할이 남는다
- 반려는 이 경로에 담기지 않는다

### when

- 다섯 건을 한 번에 승인한다(API-250)

### given

- 요청자가 세 영상의 검수를 시작해 그 세 건을 점유하고 있다
- 다른 사람이 점유한 영상 한 건과 비식별이 끝나지 않은 영상 한 건이 함께 목록에 담겼다

## statement

검수 목록에서 여러 영상을 골라 한 번에 승인하면 건마다 독립해 처리하고 부분 실패를 허용한다. 자격은 두 조건이다 — 유효 점유의 주인이 요청자 본인이고, 단건 승인이 허용하는 상태인 건만 승인된다. 요청자가 점유한 세 건과 다른 사람이 점유한 한 건과 비식별이 끝나지 않은 한 건을 함께 보내면 세 건이 승인되고 두 건이 각각의 사유와 함께 실패로 담긴다. 한 건도 승인되지 못해도 요청 자체는 받아들여진 것이므로 판정은 결과 목록으로 한다. 한 건의 실패가 다른 건을 되돌리지 않는다 — 처리 경계는 건별이다. 성공한 건의 결과는 단건 승인과 완전히 같다 — 라벨 스냅샷 동결·메타 동결·산출 폴더 새 버전 재생성·관제 완료 통지·재검토 필요 표시 해제 가운데 하나도 빠지지 않으며, 승인 이력에는 건마다 행위자와 행위 시점 역할이 남는다. 반려는 건마다 사유가 달라 이 경로에 두지 않는다.
