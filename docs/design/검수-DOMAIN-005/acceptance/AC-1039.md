## statement

이미 채택/폐기 판단이 끝난 결과에 다시 요청하면 409(리뷰 행 '재결정 금지' 불변식 LsDataAugRvw.ensurePending — 판정 기준은 AUG_PROC_STTS_CD가 아니다). 반려 사유가 비면 400. 유예기간 내 폐기 철회는 restore로 폐기 표식 해제+리뷰 PENDING 재오픈해 다시 채택/반려를 고르게 하고(표식만 지우면 REJECTED로 남는 반쪽 복구) 되돌린 이력을 반드시 남기며 유예 경과 후 실삭제 건은 409. 해상도 파생(AUG_TYPE_CD=RESL_*)은 내부 생성물이라 accept/reject를 차단하고 리뷰 행이 없으므로 등재 게이트에 통과 예외를 명시적으로 박는다. 게이트 도입 이전 그랜드퍼더링 파생(NEW_RAW_SN·리뷰 행 없음)은 신규 파생부터 게이트를 적용하고 NEW_RAW_SN NULL 건은 실삭제 대상에서 완전 제외해 감사 로그에 '수동 정리 필요'만 남긴다. 삭제 대상은 파생 영상·반려·유예 경과를 모두 충족해야 하며, 검수 승인 이력이 있으면 대상에서 제외한다(관제 접근 보장 정책) — 이미 검수 완료·통지된 건을 지우는 것은 되돌릴 수 없다. 조건은 서비스뿐 아니라 최종 DELETE SQL 자체에 리터럴로 박아 검사~삭제 사이 창을 단일 문장으로 폐쇄한다.
