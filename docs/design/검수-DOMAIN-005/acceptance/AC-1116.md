# UC-023 검수 목록 전체 열람 — 배정과 무관하게 전체가 보이고 점유는 표시이지 필터가 아니다 (happy)

## priority

high

## scenario

### then

- 배정 여부와 무관하게 검수 대기 전체가 보인다
- 남이 점유 중인 영상도 목록에서 사라지지 않고 점유자가 표시로 보인다
- 점유는 표시이지 필터가 아니다

### when

- 검수 목록을 조회한다

### given

- 검수 권한을 가진 사람이 검수 목록을 연다
- 목록에 배정된 영상과 배정되지 않은 영상, 남이 점유 중인 영상이 섞여 있다

## statement

검수 목록은 검수 권한을 가진 누구에게나 검수 대기 전체를 보여준다. 그 영상에 검수자가 배정되어 있을 것을 전제로 삼지 않으며, 검수자를 영상에 배정하는 절차 자체를 두지 않는다 — 배정의 대상은 작업자뿐이다. 남이 점유 중인 영상도 목록에서 사라지지 않는다. 점유는 지금 누가 그 영상을 보고 있는지 알리는 표시이며 목록을 거르는 조건이 아니다.
