## description

저작도구 가용성 기준:
- 정상상태에서 24시간 365일 무중단 운영을 목표로 한다.
- 애플리케이션은 다중 노드 Active-Active로 배포하며, 노드가 상태를 보유하지 않도록 설계해 일부 노드가 빠져도 서비스가 지속되게 한다.
- 주기 작업은 클러스터 구성으로 트리거 중복 발화를 막고, 작업 단위의 중복 처리는 원자적 선점으로 별도 차단한다. 두 장치는 서로를 대체하지 않는다.
- 배치·외부 위탁 실패는 재처리와 회수 경로를 두어 노드 장애가 작업 유실로 이어지지 않게 한다.
- 백업 절차와 상황별 장애복구 대응방안, 지원체계를 수립한다. 저장소·데이터베이스 백업은 인프라 운영 주체와 협력하여 구성한다.
※ '모든 채널에 동일한 자료·결과'는 같은 자산을 다루는 화면과 인터페이스 사이의 일관성으로 이행한다 — 관제 채널과 포털 채널은 각각 별도로 배포되고 저장소가 분리되어 있으며, 자산은 정해진 전달 경로를 거쳐 옮겨진다.
