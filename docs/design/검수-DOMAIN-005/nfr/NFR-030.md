## description

저작도구 도움말·메시지 기준:
- 별도 교육 없이도 사용할 수 있도록 온라인 도움말과 절차 안내를 체계적으로 구성하고, 기능 변경 시 도움말을 현행화하는 방안을 함께 둔다.
- 전체 기능을 한눈에 파악할 수 있는 사이트맵을 구성하고, 항목을 선택하면 해당 기능으로 바로 이동한다.
- 오류 메시지는 구체적인 오류 내용과 대처방안을 함께 안내하고, 표준 응답 규격을 근거로 일관된 형식을 유지한다.
- 오류 메시지에 개인정보·인증정보·내부 경로를 노출하지 않는다.
- 등록·수정·저장·삭제 등 사용자 활동에는 확인 메시지를 제공하고, 메시지는 공통 컴포넌트로 통일해 일관성을 유지한다. 되돌릴 수 없는 작업은 실행 전 확인을 받는다.
