## description

영상 분석 설명(저장 축은 시계열 메타)을 편집하거나 읽기 전용으로 보여 주는 패널. 영상 전체에 해당하는 값이라 프레임을 넘겨도 내용이 같다.

배치: 우측 메타 탭의 접이식 패널로 두지 않고 「영상 분석 설명 · 이벤트 어노테이션」 비모달 창(FloatingWindow)의 왼쪽 칸에 둔다(오른쪽 칸은 EventAnnotationPanel). 칸 머리에 제목 「영상 분석 설명」·범위 표시 「영상 전체」·한 줄 설명을 두고, 바뀐 값이 있으면 「저장 안 됨」을 표시한다. 칸 설명은 라벨링 「외부 분석이 영상을 보고 장소·날씨·상황 등을 적은 설명입니다. 틀린 내용은 고칠 수 있습니다.」, 검수 「외부 분석이 영상을 보고 장소·날씨·상황 등을 적은 설명입니다.」다. 우측 메타 탭의 패널 자리는 요약 카드(TimeseriesAnnotationSummaryCard)가 대신한다.

표기: 이 창 안에서는 「영상 분석 설명」이라고 쓰며 「시계열」「시계열 메타」「시계열 서술」이라고 쓰지 않는다(다른 화면의 「시계열」 표기는 이 부품의 범위가 아니다). 슬롯의 내부 저장 키 이름은 라벨로 노출하지 않는다. 편집 칸 아래에 글자 수를 「{n} / 2000자」로 보인다.

편집 규칙(라벨링 — 유지): 편집 대상은 화이트리스트로 판정한 슬롯(위탁 서술 전문과 신규 등록용 수동 시계열 1건)만이며, 슬롯이 하나도 없으면 신규 등록 슬롯을 자동으로 하나 제공한다. [폐기] 이전 방식 구간 키 값(시작~종료 구간 키)에는 대응하지 않는다 — 나열·읽기 전용 병기·접기·대체 규칙을 두지 않는다. 그 값은 분석 결과가 아니라 모의 응답 서버가 만든 값으로 판명됐다. 영상 기술 정보는 편집 대상이 아니며 저장 요청에 싣지 않는다. 값은 텍스트로만 렌더링해 자동으로 이스케이프된다.

저장: 패널 자체 저장 버튼을 두지 않는다 — 창 아래 공통 「저장」 하나로 이벤트 어노테이션과 함께 저장하며, 그 버튼은 두 칸 중 하나라도 바뀌었을 때만 활성화된다. 저장은 슬롯별로 원본과 달라진 항목만 전송하며(공백만 남긴 편집은 제외), 이 칸에서 달라진 슬롯이 없으면 이 칸은 저장하지 않는다. 손대지 않은 슬롯을 보내지 않는 것은 그사이 다른 사람이 고친 값을 조용히 덮어쓰지 않기 위해서다. 한쪽만 실패하면 실패한 칸 머리에 표시하고, 성공한 칸의 「저장 안 됨」은 해제한다. 저장 처리 중에는 입력을 비활성화해 같은 요청이 겹치지 않게 한다.

프레임 전환: 조회 요청은 프레임 식별자로 하므로 프레임을 넘기면 다시 조회되지만 값은 영상 단위다. 프레임 전환 시 조회 결과로 편집 값을 다시 채우는 동작은 두지 않는다 — 창 내용이 흔들리거나 편집 중인 값이 덮이지 않게 한다.

검수(읽기 전용): 입력 칸·글자 수·저장을 그리지 않고 값만 보인다. 검토 상태 배지를 두지 않는다. 검토(승인/반려) 표면은 이 패널에 두지 않는다 — 검토 상태 확정은 영상 검수 승인 시 자동 처리된다.

## accessibility_notes

각 편집 슬롯 textarea 에 라벨을 연결한 aria-label 을 지정한다(신규 등록 슬롯은 스크린리더 전용 라벨). 읽기 전용 참고 정보 묶음에는 aria-label(영상 분석 설명 참고 정보)을 지정해 편집 슬롯과 구분해 안내한다. [폐기] 이전 구간별 정보 묶음의 aria-label(이전 구간별 영상 분석 설명)은 두지 않는다 — 그 묶음을 그리지 않는다. [폐기] 접이식 섹션 헤더(button + aria-expanded)는 두지 않는다 — 이 패널은 창의 칸으로 항상 펼쳐져 있다. 각 편집 슬롯 하단에는 글자수 카운터(「{n} / 2000자」)를 병기한다. 읽기 전용 모드는 입력 칸을 그리지 않아 편집 슬롯 라벨이 없다. 창 안 입력에 포커스가 있는 동안에는 뒤 화면의 캔버스 단축키가 동작하지 않는다.
