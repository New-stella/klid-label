## scenario

### then

- PENDING·재시도 도래 행이 RCPTN_DT·RCPTN_SN 순으로 원자 클레임된다
- 영상 파일 NAS 실재가 검증된다(행 존재 ≠ 파일 존재)
- LS_DATA_RAW에 1건 등록·작업 상태 PENDING 초기화(이벤트유형 인입값 우선)
- 인입 행 PRCS_STTS_CD 종결·RAW_SN 기록
- VideoIngested AFTER_COMMIT로 비식별 선두 단계가 자동 시작된다

### when

- 폴링 배치가 미처리 인입 행을 클레임해 적재한다

### given

- 관제서버가 LS_DATA_INGEST에 학습용 영상 메타 1행을 INSERT했다
- 해당 영상 파일이 NAS에 실재한다

## statement

관제서버가 학습용 영상 메타를 LS_DATA_INGEST에 평면 1행으로 직접 INSERT하면(VMS_CLIP_ID 유니크로 중복 방어, 처리상태 미기재 시 DEFAULT 'PENDING'), 저작도구 폴링 배치가 PENDING이면서 재시도 시각이 도래한 행(NXTM_RTRY_DT IS NULL OR <= 현재)을 RCPTN_DT·RCPTN_SN 순서로 조회해 원자 클레임하고, NAS의 영상 파일 실재를 검증한 뒤 LS_DATA_RAW에 1건을 등록한다(작업 상태 행은 이 시점에 만들지 않는다 — 배정 시점에 생성되며 그전까지 조회는 PENDING으로 표시된다)(이벤트유형은 인입 EVNT_TYPE_CD 우선, 인입 PRCS_STTS_CD 종결·RAW_SN 기록). 커밋 후 VideoIngested(AFTER_COMMIT)로 비식별 선두 단계가 자동 진행된다.
