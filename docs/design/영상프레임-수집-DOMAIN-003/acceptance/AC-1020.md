### then

- PENDING·재시도 도래 행이 RCPTN_DT·RCPTN_SN 순으로 원자 클레임된다
- 영상 파일 NAS 실재가 검증된다(행 존재 ≠ 파일 존재)
- LS_DATA_RAW에 1건 등록·작업 상태 PENDING 초기화(이벤트유형 인입값 우선)
- 인입 행 PRCS_STTS_CD 종결·RAW_SN 기록
- VideoIngested AFTER_COMMIT로 비식별 선두 단계가 자동 시작된다
- 출처유형이 비식별 제외 목록에 없는 영상은 선두 비식별 단계가 외부 비식별화 솔루션에 위탁한다 — 제외 목록 설정이 비어 있거나 출처유형이 비어 있는 영상도 같다
- 출처유형이 비식별 제외 목록에 든 영상(기본값이면 GENERATED)은 외부 비식별화 솔루션 호출이 0회이고, 비식별 영상 자리에 원본과 바이트가 같은 복사본이 원본 파일명 그대로 일반 파일로 놓인다
- 그 영상의 비식별 처리 이력(LS_DEIDENT_PROC_LOG)에 PROC_STTS_CD=SUCCEEDED·REQ_KND_CD=EXCLUDED·DE_IDNTF_FILE_PATH_NM=복사본 경로 행이 남고, 비식별여부 'Y'·배치 단계 마킹 대기(MARKING_READY)로 전이한다
- 비식별 제외 여부는 적재를 바꾸지 않는다 — 인입 행 클레임·파일 실재 검증·영상 원장 등록·인입 행 종결은 출처유형과 무관하게 같다

## statement

관제서버가 학습용 영상 메타를 LS_DATA_INGEST에 평면 1행으로 직접 INSERT하면(VMS_CLIP_ID 유니크로 중복 방어, 처리상태 미기재 시 DEFAULT 'PENDING'), 저작도구 폴링 배치가 PENDING이면서 재시도 시각이 도래한 행(NXTM_RTRY_DT IS NULL OR <= 현재)을 RCPTN_DT·RCPTN_SN 순서로 조회해 원자 클레임하고, NAS의 영상 파일 실재를 검증한 뒤 LS_DATA_RAW에 1건을 등록한다(작업 상태 행은 이 시점에 만들지 않는다 — 배정 시점에 생성되며 그전까지 조회는 PENDING으로 표시된다)(이벤트유형은 인입 EVNT_TYPE_CD 우선, 인입 PRCS_STTS_CD 종결·RAW_SN 기록). 커밋 후 VideoIngested(AFTER_COMMIT)로 비식별 선두 단계가 자동 진행된다. 다만 출처유형(LS_DATA_RAW.SRC_TYPE)이 배포 설정 비식별 제외 목록(authoring.deidentify.excluded-src-types, 기본값 GENERATED)에 든 영상은 적재가 같게 진행되되, 선두 비식별 단계가 외부 비식별화 솔루션을 호출하지 않고(호출 0회) 원본과 바이트가 같은 복사본을 비식별 영상 자리에 원본 파일명 그대로 두며, 비식별 처리 이력(LS_DEIDENT_PROC_LOG)에 PROC_STTS_CD=SUCCEEDED·REQ_KND_CD=EXCLUDED 행을 남기고 비식별여부 'Y'·배치 단계 마킹 대기(MARKING_READY)가 된다(ADR-066). 제외 목록 설정이 비어 있거나, 출처유형이 목록에 없거나 비어 있는 영상은 종전대로 외부 비식별화 솔루션에 위탁한다.
