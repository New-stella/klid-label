## description

REVIEWER 가 POST /v1/videos/{rawSn}/resolution (VideoController, @PreAuthorize REVIEWER, 201) 으로 표준 해상도 3종(RESL_1080P/RESL_720P/RESL_480P)을 요청하면, 프리셋마다 <새 파생영상(RAW_SN)>을 만들어 ORGNL_RAW_SN 으로 원본을 참조한다 — 증강과 동일한 파생영상 취급이다. 비디오 파일은 부모의 비식별본을 그대로 복사하고(재인코딩 없음) <프레임 이미지셋만> 리스케일한다. 프리셋의 두 수치는 산출 프레임의 고정 크기가 아니라 상한이다 — 배율은 원본의 짧은 변을 프리셋의 짧은 값(1080/720/480)에 맞추어 구하고, 그 배율로 계산한 긴 변이 프리셋의 긴 값(1920/1280/854)을 넘을 때만 긴 변이 상한에 맞도록 배율을 낮춘다. 가로·세로에 같은 배율을 적용해 종횡비를 보존하고 남는 영역을 채우는 패딩을 두지 않으므로, 산출 프레임 크기는 그 배율로 계산된 실제 크기이며 원본 종횡비에 따라 달라진다. 라벨 좌표는 그 균일 배율의 곱셈만으로 재계산해 적재한다(BBOX·POLYGON·세그멘테이션·키포인트 전 종류, 오프셋 가산이 없다). 업스케일(확대)도 허용하며 산출 크기가 원본과 같아지는 프리셋만 스킵한다. 저장모델은 증강과 완전 통합된다 — 판별자는 LS_DATA_AUG.AUG_TYPE_CD 값 RESL_1080P/RESL_720P/RESL_480P 이고, 라벨 배율은 기존 LS_DATA_AUG_LBL_MAP.COORD_RECALC_YN='Y'/SCALE_X/SCALE_Y 를 재사용하며(균일 배율이라 두 값은 항상 같고 오프셋이 없어 이 두 값만으로 좌표 변환이 완전히 역산된다), 중복 방지는 부분 유니크 인덱스 UK_LS_DATA_AUG_RESL(SRC_SN, AUG_TYPE_CD WHERE AUG_TYPE_CD LIKE 'RESL_%', V125)가 담당한다(구 전용 테이블 LS_RESOLUTION_EXPORT·LS_RESOLUTION_LBL_MAP 은 V126 백필 후 fail-closed DROP — 해상도 전용 EXPORT 행은 더 이상 만들지 않는다). 검증 순서는 파생본 400(깊이 1 고정) → 미검수 409 → 부모 비식별 산출물 실재 404 이며, 게이트는 LsDataRaw.hasDeidentArtifact()('Y'|'F') 로 판정해 DE_IDNTF_YN='N'·null 만 차단하고 'F'(비식별 누락 신고)는 통과시킨다 — 해상도 파생은 외부 위탁이 전혀 없는 내부 ffmpeg 리스케일뿐이라 신고 구간에 생성해도 외부 유출 경로가 열리지 않는다(증강 경로와 동일 헬퍼 사용). 확정은 3-Phase 비동기다 — Phase A(짧은 REQUIRES_NEW + 부모 잠금, 검증·경로 스냅샷) → Phase B(잠금·트랜잭션 밖 순수 파일 I/O) → Phase C(재잠금 + stale 창 게이트 후 영속). Phase C 의 stale 게이트 판정축은 신고가 아니라 <복사 원자성>이다 — 스냅샷 이후 부모 비식별본 경로가 바뀌었거나 mtime 이 스냅샷 이후면 abort 한다(프레임별로 다른 버전이 섞인 산출물 방지). aug 라이프사이클은 예약 시 PENDING(생성 중) → finalize 성공 시 ACCEPTED(생성 완료), 실패 시 예약행 삭제다. 응답 계약은 {derivatives:[{rawSn, goalResCd, targetW, targetH, status}]} 이고 1건 이상 생성 성공=201 / 전부 실패=500 / 대상 프리셋 전부 스킵=400 이며, 201 은 “예약 성공”만 의미하므로 확정 결과는 GET /v1/videos/{rawSn}/resolution 으로 조회한다. 이 배율 규칙은 신규 생성부터 적용하며 기존에 생성된 파생본은 재생성하지 않는다. 해상도 파생은 증강 이력·집계·통계에는 포함되나 accept/reject(검수 승인·반려)는 차단된다(내부 생성물이라 라벨 검수 대상 아님) — 그래서 등재 게이트에도 RESL_ 예외가 명시적으로 박혀 있다.
