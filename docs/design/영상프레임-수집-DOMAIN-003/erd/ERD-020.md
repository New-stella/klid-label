#### notes

V2 생성 시 MNG_CLIP_SCHEDULE_QUE 로 명명됐으나 소유자는 저작도구였고, V162 에서 LS_CLIP_SCHEDULE_QUE 로 개명해 소유권 표기를 바로잡았다. 관제 데이터 참조 전면 제거(ADR-042)에서 삭제 대상 9종과 달리 이 테이블만은 존치된다 — 우리가 쓰는 테이블이기 때문이다.

#### status

modified

- **description**: 라벨링 배치 작업 큐(V2 생성, V162 개명). 원래 MNG_CLIP_SCHEDULE_QUE 라는 이름으로 관제 소유처럼 보였으나, 실제로는 저작도구가 직접 INSERT 하는 우리 테이블이고 관제 공유 9종 중 유일하게 @Immutable 이 아니었다. 따라서 V162 에서 소유권 표기를 LS_ 로 정정했다(테이블·인덱스·제약·시퀀스 일괄 개명, 멱등). 컬럼 물리명은 한동안 원형 그대로였다 — 공유 스키마로 오인돼 협의가 필요하다는 이유로 표준용어 정합 범위 밖에 있었고, 소유권이 저작도구로 정리되면서 그 제약이 사라져 정합했다. 물리 컬럼명은 행정안전부 공통표준단어 조합을 따른다 — 작업(JOB)·유형(TYPE)·코드(CD)·상태(STTS)·재시도(RTRY)·횟수(NMTM)·등록(REG)·시작(BGNG)·완료(CMPTN)·최종(LAST)·오류(ERR)·메시지(MSG)·내용(CN)·일시(DT). 코드값은 표준도메인에 따라 16자로 둔다.
