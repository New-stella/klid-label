고도화(2차) 영상·프레임 수집 물리 ERD. 진실원: 마이그레이션 이력 (V2 LS_DATA_RAW, V4 LS_DATA_SRC/HSTRY, V82 ORGNL_RAW_SN — 구 V46 PARENT_RAW_SN 에서 개명, V103 FRM_EXPLN, V130 프레임 개인정보 3필드, V147 LS_DATA_INGEST 신설, V148 SRC_TYPE/AUG_TYPE_CD, V149 백필, V163 영상 개인정보 3필드, V166 인입 수신 4컬럼) + JPA 엔티티(LsDataRaw/LsDataSrc/LsDataSrcHstry/LsDataIngest @Column). 작업 단위=영상 1건(RAW_SN), VMS_CLIP_ID 유니크로 upsert. 1차 LS_DATA_RAW/SRC 대비 컬럼을 대폭 슬림화·표준화(예: FILE_PATH→RAW_FILE_PATH_NM, VDO_LEN→VDO_LEN_SEC). 이력 테이블은 전체 미러링이 아닌 변경사유(CHG_TYPE_CD)+상태전이(PREV/NEW_STTS_CD)만 기록하는 슬림 구조로 재설계. ★ 적재 경로 반전(ADR-042) — 관제가 공유 DB(MNG_*)를 설정하면 저작도구가 스캔해 적재하던 구조가 폐기되고, 관제가 LS_DATA_INGEST 에 직접 INSERT 한 평면 1행을 저작도구 폴링 배치가 집어 적재한다. 이름·포맷·좌표는 LS_DATA_RAW 에 복사하지 않고 조회 시 LEFT JOIN LS_DATA_INGEST i ON i.RAW_SN = COALESCE(r.ORGNL_RAW_SN, r.RAW_SN) 로 얻는다(파생 깊이 1 고정이라 1단계 폴백으로 충분). 단 개인정보 3필드는 파생에서 인입 조인을 제외한다(파생의 판정은 비식별 축이며 자기 행에 계승돼 있음). 구 LS_RESOLUTION_EXPORT 관계는 V126 DROP·ADR-018(증강 모델 통합)로 제거됐다. 1차 원형은 ERD-007(deprecated) 참조. 영상 변경 이력 테이블은 두지 않는다 — 상태 전이는 영상 상태 테이블이 현재값으로, 사람의 조작은 작업 이벤트 로그가 각각 담당해 이 이력을 읽는 경로가 설계에 없다.
