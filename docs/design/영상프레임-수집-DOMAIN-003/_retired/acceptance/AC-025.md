# 관제 인입 → 폴링 적재 정상 흐름 수용

## notes

근거: UC-018(적재 주체 반전, ADR-042). 판정 지점: 인입 행 적재 · 주기 폴링의 원자 클레임 · 적재 완료 후 선두 비식별 개시.

## priority

high

## scenario

### then

- LS_DATA_RAW 에 영상 1건이 등록되고 LS_RAW_DATA_STATUS.DATA_STTS_CD='PENDING' 이다
- LS_DATA_INGEST.PRCS_STTS_CD 가 종결 처리되고 RAW_SN 이 기록되어 인입 행으로 역추적 가능하다
- VideoIngested 이벤트가 트랜잭션 커밋 후(AFTER_COMMIT) 비식별(선두) 단계를 비동기로 개시한다

### when

- 폴링 배치가 PENDING 이면서 재시도 시각이 도래한 행(NXTM_RTRY_DT IS NULL OR <= 현재)을 RCPTN_DT·RCPTN_SN 순서로 조회해 조건부 UPDATE 로 원자 클레임한다

### given

- 관제서버가 LS_DATA_INGEST 에 VMS_CLIP_ID 유니크인 행을 INSERT 했다(PRCS_STTS_CD 는 값을 넣지 않아도 DEFAULT 'PENDING' 이 부여된다)
- RAW_FILE_PATH_NM 경로에 영상 파일이 공유 NAS 에 이미 존재한다

### and_examples

#### [1]

- **case**: 관제가 EVNT_TYPE_CD 를 함께 보냈을 때
- **result**: 그 값이 LS_DATA_RAW.EVNT_TYPE_CD 로 우선 사용된다

#### [2]

- **case**: 인입 행의 보존
- **result**: 감사 추적을 위해 영구 보존되며 삭제되지 않는다(중복 INSERT 감지 근거)

## statement

관제서버가 LS_DATA_INGEST 에 학습용 영상 메타 1행을 INSERT 하면 폴링 배치가 이를 원자 클레임해 NAS 파일 실재를 검증한 뒤 LS_DATA_RAW 에 영상 1건을 PENDING 으로 등록하고, 선두 비식별 단계부터 배치 파이프라인이 자동 진행된다.
