# ADMIN 역할 폐기 — 관리 권한 REVIEWER 통합

## context

1차는 관리자(ADMIN)·담당자 등 다중 관리 역할을 가졌다. 고도화는 별도 ADMIN 역할 없이 모든 관리 권한(사용자 관리·시스템 설정·작업 배정/재배정·검수 승인)을 REVIEWER에 통합하고, UI 호칭을 '검수자'로 통일하며 관리 화면 URL을 /manage/* 로 둔다. 토큰 role/channel 클레임으로 권한을 분기한다.

## deciders

- 박찬기
- 김현욱

## decision

### chosen_option

REVIEWER 통합 채택

### justification

역할을 REVIEWER/WORKER/PORTAL_USER 3종으로 단순화하고 관리 권한을 REVIEWER에 통합한다. '관리자' 호칭은 '검수자'로 정정한다.
