## rationale

관제지원시스템 요구사항정의서(KLID_AN V1.0, 비기능)에서 담당=타시스템/저작도구로 위임된 요구. 출처: RFP(제안요청서) p57 DAR-06, 중요도 상. 관제지원은 수신 데이터 적재·연동만 담당. 담당=공통인 RQ-DAR-06-01(입력 데이터 값 검증·오류 입력 방지 방안 및 업무규칙 정의)도 같은 요구사항명이라 이 항목이 함께 담는다.

## brownfield

### status

new

### diff_summary

2차 RFP 비기능(DAR-06-02)에서 저작도구로 위임된 신규 데이터 품질 요구

## description

시스템에서 생성되는 데이터 외 제공되는 학습데이터에 대한 진단 수행 및 검증 — 원본 데이터와 정합성 검증, 공공데이터 범정부 품질진단 기준 및 업무규칙(BR)에 따른 값 검증, 오류데이터 개선·영향도·유형별 조치 관리 (RFP p57, DAR-06).

**해결방안(확정)**: 라벨 저장·검수 시 좌표 범위·필수 속성·코드 정합 등 업무규칙(BR) 기반 값 검증으로 오류 입력을 차단하고, 원본 정합성 검증과 오류데이터 반려·재작업 및 오류유형별 조치 이력을 관리한다.

**제약사항**: 공공데이터 품질진단 기준 준수 (공공데이터 품질관리 매뉴얼 참고).

**입력 데이터 값 검증 (RQ-DAR-06-01)**: 시스템 구축 후 입력되는 데이터 전반에 대해 값 검증과 오류 데이터 입력 방지 방안을 적용한다. 저작도구의 구축·운영 근거(법령·규정·규칙·매뉴얼)에 맞는 업무규칙(BR)을 정의하고, 화면 입력과 인터페이스 수신 양쪽에서 그 규칙으로 검증한다 — 화면에서만 막으면 인터페이스 경로로 우회된다.
