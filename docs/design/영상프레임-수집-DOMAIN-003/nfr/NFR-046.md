## description

저작도구 메타데이터 현행화 기준:
- 저작도구의 메타데이터 표준 관리 항목이 발주기관의 메타데이터 관리시스템과 중앙메타시스템에 등록·현행화되도록 지원한다.
- 발주기관이 운영 중인 메타데이터 관리시스템이 없는 경우 문서·파일 형태로 메타데이터 항목을 작성하여 제출한다.
- 데이터 구조가 변경되면 등록된 메타데이터도 함께 갱신하여 실제 구조와 어긋나지 않게 한다.
