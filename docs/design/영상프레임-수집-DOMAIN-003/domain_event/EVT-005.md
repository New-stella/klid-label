## description

관제 인입 영상이 LS_DATA_RAW 에 영속된 직후 발행되어 파이프라인 선두의 비식별화를 트리거한다. 적재된 모든 영상이 (ANONY 포함) 무조건 비식별 대상이며 게이팅은 폐지됐다.

[발행] 영상 적재 트랜잭션 안에서 발행한다.
[소비] 적재 트랜잭션 커밋 이후(AFTER_COMMIT) 두 소비자가 각각 비동기로 받는다 — 선두 비식별 위탁, 그리고 영상 기술메타 추출.
소비가 AFTER_COMMIT 이어야 하는 이유: 적재 트랜잭션이 커밋되기 전에 비식별이 시작하면 대상 행을 읽지 못한다.

[상태 흐름] 적재 PENDING → (선두 비식별 성공) MARKING_READY → (마킹 완료 → 잔여 배치) COMPLETED.

[★ADR-042 이후 적재 주체 반전] 관제서버가 LS_DATA_INGEST 에 직접 INSERT 하고 저작도구 폴링 배치가 원자 클레임해 적재한다(구 관제 공유 마스터 스캔 방식 폐기). 발행 지점(LS_DATA_RAW 영속 직후)은 불변이다.

[한계 — 의도된 것] 증강·해상도 파생 적재 경로는 본 이벤트를 발행하지 않는다 — 파생은 부모의 비식별본을 복사해 만들어져 재비식별 대상이 아니다.
