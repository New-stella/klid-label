## description

마킹 완료(비식별 영상) 시 발행된다. 마킹 저장이 커밋된 뒤(AFTER_COMMIT) 잔여 배치(VLM 시계열 위탁 → 마킹위치 프레임추출 → YOLO → SAM2 → 트랙보간)를 비동기로 시작하는 트리거 이벤트다.

[발행 가드] 부모 영상의 비식별 완료 여부(deIdntfYn)가 'Y' 일 때만 잔여 배치로 넘어간다 — 마킹은 비식별 영상을 대상으로 하므로 비식별이 유효하지 않은 영상은 진행하지 않는다.

구 서술(비식별 선두를 설계 타깃으로 적고 마킹이 전체 배치를 트리거하는 것을 구 순서로 적었던 것)은 폐기됐다 — 비식별이 적재 직후 선두로 자동 실행되고, 본 이벤트는 그 이후 잔여 배치(post-marking = MARKING, VLM, FRAME_EXTRACT, YOLO, SAM2, INTERPOLATE)만 트리거한다.

- 잔여 배치 파이프라인 비동기 시작 (post-marking 단계군)
