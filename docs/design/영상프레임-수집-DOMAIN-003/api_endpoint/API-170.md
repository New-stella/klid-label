## description

영상 단위 촬영환경을 저장한다.

[전체 교체 계약] weather/timeOfDay/season 3필드를 항상 함께 전송한다. 생략(null)한 필드는 수동값이 삭제되어 조회 시 파생값으로 폴백한다. 허용값은 weather=맑음/흐림/비/눈/안개, timeOfDay=DAY/NGT, season=SPRING/SUMMER/FALL/WINTER 이며 그 밖이거나 길이 상한을 넘으면 400 이다.

[파생 상태로 두려면 null 로 보낸다] 조회 응답의 프리필값(출처 DERIVED)을 그대로 되돌려보내면 수동값으로 승격되어, 이후 촬영일시가 정정돼도 옛 값이 스냅샷과 산출물에 고정된다.

[산출·통지의 트리거는 재검수 승인이다] 검수 완료된 영상의 촬영환경을 고치면 그 영상은 다시 검수 대상이 되고, 검수자가 그 수정을 다시 승인한 시점에 산출 폴더가 새 버전으로 전량 재생성된 뒤 관제 수정 통지가 발행된다. 저장 자체는 트리거가 아니다.

작업자는 본인 배정 영상만 저장할 수 있다.
