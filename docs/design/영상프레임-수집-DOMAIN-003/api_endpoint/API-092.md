## description

검수 완료된 원본 영상을 표준 해상도 프리셋(RESL_1080P/RESL_720P/RESL_480P)마다 새 파생영상(RAW_SN, ORGNL_RAW_SN 으로 원본 참조)으로 생성한다. 해상도 변경은 증강 파생영상 모델로 통합돼 있다.

비디오 파일은 원본(비식별) 복사이며 재인코딩하지 않는다. 프레임 이미지셋만 리스케일한다.

프리셋의 두 수치는 산출 프레임의 고정 크기가 아니라 상한이다. 원본의 짧은 변을 프리셋의 짧은 값(1080/720/480)에 맞추는 배율을 구하고, 그 배율로 계산한 긴 변이 프리셋의 긴 값(1920/1280/854)을 넘을 때만 긴 변이 상한에 맞도록 배율을 낮춘다. 산출 프레임 크기는 그 배율로 계산된 실제 크기이며, 남는 영역을 채우는 패딩이 없다. 가로·세로에 같은 배율을 적용해 종횡비를 보존하며, 축을 따로 늘려 왜곡시키지 않는다.

라벨 좌표 변환은 그 균일 배율의 곱셈만이고 오프셋 가산이 없다(BBOX/POLYGON/세그멘테이션/키포인트 전 종류 동일, 업스케일 허용).

720p 프리셋 기준 산출 크기 예 — 원본 1920x1080 → 1280x720 / 1440x1080 → 960x720(짧은 변 기준) / 640x480 → 960x720(업스케일) / 1080x1920 → 720x1280(세로 영상) / 2560x1080 → 1280x540(긴 변 상한에 걸려 배율이 낮아진 경우).

요청 바디의 presets[] 미지정 시 표준 프리셋 전체를 생성하고, 산출 크기가 원본과 같아지는 프리셋만 건너뛴다. 파생 라이프사이클은 예약 시 PENDING → 확정 성공 시 ACCEPTED 이며 실패하면 예약행을 지운다. 기존에 생성된 파생본은 재생성하지 않으며, 신규 생성부터 이 규칙이 적용된다.

상태코드: 1건 이상 생성 201 / 전부 실패 500 / 대상 프리셋이 전부 건너뛰어지면 400.
