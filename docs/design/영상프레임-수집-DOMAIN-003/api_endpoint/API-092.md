## description

검수 완료된 원본 영상을 표준 해상도 3종 프리셋(RESL_1080P/RESL_720P/RESL_480P)마다 새 파생영상(RAW_SN, ORGNL_RAW_SN 으로 원본 참조)으로 생성한다. 해상도 변경은 증강 파생영상 모델로 통합돼 있다.

비디오 파일은 원본(비식별) 복사이며 재인코딩하지 않는다. 프레임 이미지셋만 목표 해상도로 리스케일(축소·확대)하고, 라벨 좌표는 해상도 배율(scaleX/scaleY)로 재계산해 적재한다(BBOX/POLYGON/세그멘테이션/키포인트 전 종류, 업스케일 허용).

요청 바디의 presets[] 미지정 시 3종 전체를 생성하고, 원본과 동일 해상도인 프리셋은 스킵한다. 파생 라이프사이클은 예약 시 PENDING → 확정 성공 시 ACCEPTED 이며 실패하면 예약행을 지운다.

상태코드: 1건 이상 생성 201 / 전부 실패 500 / 대상 프리셋이 전부 스킵되면 400.
