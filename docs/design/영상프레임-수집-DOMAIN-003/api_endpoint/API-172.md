## description

프레임의 익명·가명·개인정보 포함여부를 조회한다. 수동 저장값이 있으면 그 값을, 없으면 기본상수를 프리필해 유효값으로 반환한다.

[출처 필드가 계약의 핵심이다] 각 필드의 출처는 그 값이 사람이 저장한 판정(MANUAL)인지 시스템 기본상수(DERIVED)인지를 구분한다. 화면은 DERIVED 로 받은 필드를 사용자가 직접 고르지 않았다면 저장 요청에서 null 로 보내야 한다.

[세 필드 모두 산출물을 결정한다] 수동값은 학습데이터 산출물 JSON 의 image 블록 개인정보 3필드로 나간다. 익명값만 표시·기록용이라는 구 서술은 폐기됐다 — 그렇게 적어 두면 화면에서 고친 값과 파일의 값이 어긋나게 된다.

[영상 단위와는 별개 축이다] 산출물의 video 블록은 영상 단위 값을 읽는다. 두 블록의 값이 달라도 모순이 아니다 — 입도가 다른 서로 다른 사실이기 때문이다.

작업자는 본인 배정 프레임만 조회할 수 있다(CWE-639 IDOR 방어).
