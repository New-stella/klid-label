## description

영상(원시데이터) 목록을 페이징 조회한다. 인증된 사용자이며 검수자와 라벨링 작업자만 접근한다. 검수자는 전체 영상을, 라벨링 작업자는 본인에게 배정된 영상만 조회한다. 범위 제한은 거부가 아니라 결과 축소이며, 배정이 하나도 없으면 빈 목록을 반환한다. 요청 파라미터로 이 범위를 넓히거나 다른 사용자를 지정할 수 없다. 정렬은 시간축 단일 기준이고 정렬 키는 허용목록으로만 해석하며, 목록에 없는 키는 오류가 아니라 버려지고 유효한 정렬이 하나도 남지 않으면 등록일 내림차순으로 폴백한다. 모든 필터 파라미터는 선택이며 지정하지 않으면 그 축으로 좁히지 않는다. 필터를 새로 더할 때도 기본값을 바꾸지 않아, 파라미터를 보내지 않던 기존 호출의 결과가 달라지지 않는다. 목록에는 개인정보 유무를 표시하지 않는다. 이 목록의 기본은 제외 표시가 붙지 않은 영상만 보는 것이다 — 제외된 영상은 목록에서 빠지고 전체 건수도 함께 줄어든다. 목록과 건수는 언제나 같은 조건에서 나온다. 제외된 영상을 보려면 제외분만 보기 파라미터를 보낸다. 이 파라미터는 선택이며 보내지 않으면 종전과 같은 응답이라 기본값이 바뀌지 않는다. 값역은 표시분만과 제외분만 두 갈래뿐이고 둘을 섞어 보는 갈래는 두지 않는다 — 섞이면 어느 것이 제외분인지 행마다 구분해야 한다. 응답에는 제외됨 건수가 키 하나로 더해지며, 목록 내용과 전체 건수를 비롯한 기존 키의 이름과 타입과 뜻은 그대로다. 그 건수는 현재 페이지가 아니라 전체 기준이고 행이 하나도 없는 페이지에서도 실린다 — 제외분만 남은 상태에서 화면이 건수를 모르면 되돌아갈 길을 안내하지 못한다. 화면이 제외 동작을 그리는 데 필요한 값은 이미 이 목록에 실려 있다 — 배정 식별자와 작업자와 배정 상태로 배정된 영상의 제외 버튼을 미리 비활성해, 거부를 받고 나서야 아는 동선을 만들지 않는다. 그 목적으로 항목을 새로 더하지 않는다.
