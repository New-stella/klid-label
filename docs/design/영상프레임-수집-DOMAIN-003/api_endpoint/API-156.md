## description

TUS 1.0 재개 가능 업로드 프로토콜 사전 협상(tus-js-client). Tus-Resumable/Tus-Version/Tus-Extension(creation,termination)/Tus-Max-Size(524288000=500MB) 헤더를 반환하고 본문은 없다(204). 응답은 표준 ApiResponse 래퍼를 사용하지 않고 TUS 프로토콜 규약(헤더 기반)을 따른다. ⚠ 1차 영상 적재 경로가 아니다 — 1차 적재는 관제가 인입 원장(LS_DATA_INGEST)에 직접 등록한 행을 저작도구 주기 배치가 폴링해 수행한다. 이 업로드 통로는 내부 관리 화면의 대용량 영상 적재에 쓴다.

관리자 단기 유효창은 이 창구에서 요구하지 않는다. 프로토콜이 지원하는 능력을 알리는 조회이며 특정 전송에 속하지 않는다. 유효창은 운영과 관리 성격의 쓰기에만 요구된다.
