## description

종결된 인입 행을 오래된 수신일시 순으로 최대 limit 건 되살린다.

[요청이 정하는 것은 건수뿐이다] 대상 상태는 서버가 종결 행으로 고정한다. 상태를 요청으로 받으면 이미 처리 완료된 행까지 되살려 중복 적재를 유발할 수 있다.

[남은 건수를 응답으로 돌려준다] remainingFailed 가 0 이 될 때까지 반복 호출하는 것이 회수 동선이다. 한 번에 무제한 되살리지 않는 이유는 되살린 행이 곧바로 다음 스캔의 부하가 되기 때문이다.

[화면 동선을 두지 않는다] 이 엔드포인트는 운영자가 직접 호출하는 경로다. 되살릴 대상은 아직 영상으로 적재되기 전 단계의 인입 행이라 영상 목록 화면에 나타나지 않으며, 이 호출은 개별 대상을 고르는 조작이 아니라 남은 건수가 0 이 될 때까지 반복하는 회수 작업이다.

단건 재큐와 같이 대기 예산도 함께 리셋된다.
