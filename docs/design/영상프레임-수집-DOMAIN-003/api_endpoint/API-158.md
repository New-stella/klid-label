## description

TUS 1.0 재개 가능 업로드 세션을 생성한다. 응답은 201 + Location: /v1/uploads/{uploadId} 헤더(본문 없음). Upload-Metadata 는 TUS 규약(key b64value,key2 b64value2)이며 원문 1KB 상한. ⚠ 1차 영상 적재 경로가 아니다 — 1차 적재는 관제가 인입 원장(LS_DATA_INGEST)에 직접 등록한 행을 저작도구 주기 배치가 폴링해 수행한다. 이 세션은 내부 관리 화면의 대용량 영상 적재 통로다.
