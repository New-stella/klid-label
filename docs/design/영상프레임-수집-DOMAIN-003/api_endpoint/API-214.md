## description

건너뛴 적이 있는 시계열 묶음을 여러 영상에 대해 한 번에 다시 수행한다. 수락 조건은 그 영상에서 건너뛴 적이 있는 묶음인가 하나이며 단건 재수행과 같은 판정을 쓴다 — 건너뛴 상태와 해제된 상태를 모두 수락하고, 건너뛴 상태로 들어온 건은 재수행이 해제 표식을 함께 남긴다 — 임의 묶음을 받으면 요청이 앞 작업을 건너뛰도록 강제할 수 있어 전제 없는 산출물이 만들어진다. 재수행은 지목한 묶음의 구성원만 켜고 나머지 단계는 끄므로 프레임과 라벨을 다시 만들지 않는다. ★검수 승인 이력이 있는 영상도 이 경로에서는 대상이 된다. 시계열 재수행은 확정된 라벨을 되돌리지 않고 메타만 더하며, 들어온 서술은 승인 완료 영상의 서술이 갱신되면 재검수를 강제하는 규칙이 받아 검토 대기로 되돌리고 산출물 재생성과 관제 재통지를 건다. 같은 값이면 아무 일도 일어나지 않는다. 오토라벨 묶음에는 이 예외가 없다 — 라벨을 다시 만들어 승인 시점 스냅샷과 어긋나기 때문이다. ★재수행이 실패해도 영상 상태를 훼손하지 않는다. 스킵의 존재 이유가 기다려도 성공하지 않는 작업이라 해제해 재수행하면 실패가 기대값이며, 그 실패가 완주한 영상을 실패 상태로 강등시키면 자동 재시도가 범위를 모른 채 앞 단계를 돌려 사람이 손댄 보간 라벨을 지운다. ★대상은 시계열 묶음만 받는다. 한 번에 받는 상한과 중복 식별자를 한 건으로 취급하는 규칙, 요청 순서 보존, 되는 것만 처리하고 거부분은 건별 사유로 돌려주는 부분 성공은 배치 일괄 재처리와 같은 계약을 따른다. 한 건도 처리되지 못해도 200 이며 판정은 결과 목록으로 한다 — 건별 거부 사유를 상태 코드로 올리면 요청이 응답 코드로 영상의 상태를 알려주는 통로가 된다.
