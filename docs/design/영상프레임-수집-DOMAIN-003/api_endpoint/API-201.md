## description

건너뛰기를 되돌린 작업 묶음을 다시 수행한다. 「문제가 생긴 곳부터 재시도한다」는 원칙에 따라 전체 재기동과 분리된 요청이다.
★단위는 개별 단계가 아니라 작업 묶음이다 — 시계열(VLM)과 오토라벨(AI 탐지 · AI 분할 · 트랙 보간)이며, 오토라벨은 쪼개서 부분 수행하지 않는다. 뒤 단계가 앞 결과를 입력으로 받고 보간이 그 산출물을 재계산하므로 일부만 수행하면 산출물끼리 어긋나기 때문이다. 보간을 묶음 밖에 두면 어떤 재수행에서도 보간이 무조건 돌아 사람이 손댄 보간 라벨을 지운다 — 묶음이 그 사고를 구조적으로 없앤다.
★범위를 고르지 않는다 — 묶음이 곧 범위다. 되돌린 그 묶음만 수행하고 다른 묶음은 건드리지 않는다. 오토라벨을 재수행하면 트랙 보간도 함께 다시 만들어지므로 그 묶음에 사람이 손댄 보간 라벨이 있으면 새로 계산된 것으로 바뀐다 — 오토라벨을 통째로 다시 만드는 선택이므로 예상되는 결과이며, 화면은 고르는 시점에 이 사실을 알린다.
★★대상 묶음을 요청이 자유롭게 지정하지는 못한다 — 서버는 그 영상에서 실제로 되돌린 묶음만 수락하고 그 외에는 거부한다. 임의 지정을 허용하면 앞 작업을 건너뛴 산출물이 전제 없이 만들어진다.
★재수행이 실패해도 영상 상태를 훼손하지 않는다 — 선점 직전 상태로 되돌리고 자동 재시도 큐에도 넣지 않는다. 한 묶음의 재수행 실패가 완주한 영상 전체를 실패로 만들면, 그 영상이 자동 재시도로 파이프라인 전체를 다시 돌아 사람의 작업을 지운다.
실행은 비동기 접수다. 한 번이라도 검수가 완료된 영상은 받지 않는다.
