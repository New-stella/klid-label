## description

REVIEWER가 WORKER에게 영상 단위 작업을 배정한다. REVIEWER 전용.

[배정의 대상은 작업자뿐] 검수자를 영상에 배정하는 절차를 두지 않는다 — 검수는 배정 없이 전체 대기열에서 집어간다(ADR-067). 요청 본문과 응답 항목 어디에도 검수자 축을 두지 않는다. ★ 옛 호출자가 검수자 항목을 그대로 보내도 거부하지 않고 무시한다(400 아님) — 옵션 항목이었으므로 거부는 과한 대응이고 기존 호출을 깨뜨린다.

[배정 해제와의 관계] 배정을 푸는 창구는 따로 있다(API-259). ★ 해제를 되돌리는 방법은 이 창구로 다시 배정하는 것이며, 해제를 취소하는 창구는 따로 두지 않는다. 해제는 배정만 푼다 — 그때 작업 결과(라벨·이력)는 지워지지 않으므로, 다시 배정하면 그 작업 위에서 이어서 한다. ⚠ 제외된 영상에는 배정할 수 없다(ADR-069) — 제외된 영상은 목록에서 보이지 않고, 제외분 보기에서도 배정 동작을 노출하지 않는다.
