# 검수 워크플로우 단일화 — 2차 검수 폐기

## context

1차는 1차 검수 통과 데이터를 2차 검수자가 최종 검토하는 2단계 검수 워크플로우를 가졌다. 고도화는 REVIEWER 1인이 승인(APPROVED)까지 반복 검수하는 단일 검수 모델로, 검수 완료=작업 완료(LsRawDataStatus.dataSttsCd=APPROVED)이며 이 시점에 outbound TASK_COMPLETED 통지를 발행한다.

## deciders

- 박찬기
- 김현욱

## decision

### chosen_option

단일 검수 채택

### justification

고도화 역할 모델(REVIEWER 단일)·완료 통지 단위와 정합한다. 2차 검수는 단일 검수(DFEAT-021)로 통합 폐기한다.
