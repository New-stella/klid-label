## description

내부 채널(관제서버와 같은 도메인으로 진입하는 채널) 화면의 접근성 기준이다.

적용 범위는 관리 영역 화면 — 사용자 관리·연동 서버 주소·패스워드 교체·위험 액션이다. 나머지 내부 화면으로 넓히는 것은 별도 결정으로 남긴다. 지금 전 화면에 한 번에 걸면 기준만 서고 지켜지지 않는 상태가 되기 때문이다.

판정은 자동 감사로 한다. 다만 자동 감사가 사람의 확인을 대체하지 않는다 — 자동으로 잡히는 것은 규칙으로 판정 가능한 부분뿐이고, 초점 순서가 화면의 논리와 맞는지나 안내 문구가 실제로 뜻이 통하는지는 그 밖에 있다. 위반 0 은 최소선이지 접근성이 확보됐다는 뜻이 아니다.

이 기준은 웹표준·크로스브라우징과 다른 축이다. 그쪽은 브라우저가 같게 그리는가를 보고 이쪽은 보조기술로 조작할 수 있는가를 본다. 한쪽을 지켰다고 다른 쪽이 따라오지 않는다.

색상만으로 의미를 전달하지 않는다는 것은 이 기준 안에 있다 — 상태나 역할을 색으로만 가르면 그 구분이 보이지 않는 사용자에게는 존재하지 않는 정보가 된다. 그런 자리에는 글자나 아이콘을 함께 둔다.
