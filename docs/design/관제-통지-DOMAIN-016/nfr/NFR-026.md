## description

저작도구 화면의 UX/UI 표준:
- 화면 스타일(레이아웃·색상·타이포그래피·대화상자)·화면 사양·실행 방식(메뉴·아이콘)·화면 구성·화면 연계·오류 처리 방안을 포괄하는 표준 체계를 정의하고, 디자인 시스템을 단일 진실원으로 전 화면에 일관 적용한다.
- 최적 해상도·브라우저 버전·적응형 웹 적용 방안을 정의한다.
- 한국형 웹 콘텐츠 접근성 지침과 전자정부 웹사이트 품질관리 지침을 준수한다.
- 액티브X 등 비표준 기술 없이 HTML5 웹표준으로 구현하고 크로스브라우징을 지원한다.
- 동일 기능은 매체(PC·모바일)에 따라 중복 개발하지 않고 단일 코드베이스를 재사용한다.
- 확장성을 고려해 UI를 구조화하고, 대내외 인터페이스 표준화 방안을 함께 제시한다.
