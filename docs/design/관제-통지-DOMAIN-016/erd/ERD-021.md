### diff_summary

2차 신규 두 테이블 — 관제 통지 재시도·사장 큐, 외부 위탁 멱등 원장. 1차에 대응 테이블이 없다.

## description

저작도구 → 관제서버 단방향 outbound 통지(TASK_COMPLETED/TASK_MODIFIED)의 영속 fallback 큐 + 외부 위탁 webhook 멱등 원장. 인메모리 구현을 영속화하여 재시작·멀티 인스턴스 환경에서 dead-letter·중복 적재를 방어한다. 진실원: 베이스라인 마이그레이션의 CREATE TABLE + JPA 엔티티(@Column). 신설 세대는 control_notify_fallback V44 · webhook_idempotency V39 이며 그 원문은 마이그레이션 아카이브에 보존된다.
