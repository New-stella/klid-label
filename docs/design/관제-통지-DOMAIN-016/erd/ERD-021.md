## description

저작도구 → 관제서버 단방향 outbound 통지(TASK_COMPLETED/TASK_MODIFIED)의 영속 fallback 큐 + 외부 위탁 webhook 멱등 원장. 인메모리 구현을 영속화하여 재시작·멀티 인스턴스 환경에서 dead-letter·중복 적재를 방어한다. 진실원: 베이스라인 마이그레이션의 CREATE TABLE + JPA 엔티티(@Column). 신설 세대는 control_notify_fallback V44 · webhook_idempotency V39 이며 그 원문은 마이그레이션 아카이브에 보존된다. 이 ERD 는 방향이 다른 두 축을 함께 담는다 — 위 서술은 우리가 밖으로 내보내는 나가는 쪽이고, 여기에 외부에서 우리 쪽으로 도착하는 웹훅 요청을 막고 걸러 내는 들어오는 쪽 원장 둘이 함께 있다. 두 축을 「멱등」 한 낱말로 뭉뚱그리지 말 것 — 나가는 쪽의 위탁 멱등은 우리가 발급한 키로 우리 요청이 두 번 처리되는 것을 막고, 들어오는 쪽의 서명 재사용 차단은 남이 보낸 서명을 기억해 같은 서명이 다시 오는 것을 막는다. 방향도 대상도 다르다.
