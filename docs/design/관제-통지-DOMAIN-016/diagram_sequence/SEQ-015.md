## description

검수자(REVIEWER)가 제출된 영상을 승인/반려하는 흐름의 시퀀스 다이어그램. 제출(submit)·검수 시작(start)·승인(approve)·반려(reject) 4개 API 호출과, 승인 트랜잭션 내부에서 일어나는 비식별 신고 게이트 · 라벨 전체 스냅샷 생성 · event_annotation·시계열 메타 자동 승인 · 통합 메타 동결(materialize)을 그린다. 승인 트랜잭션 커밋 이후(AFTER_COMMIT)에 비동기로 이어지는 학습데이터 산출(export)과, 그 산출이 성공한 뒤에만 나가는 관제 완료 통지(TASK_COMPLETED)까지 포함한다. 최초 승인과 재승인(검수완료 후 수정 → 재검수 → 재승인)은 이벤트 발행 여부가 갈리며, 재승인의 경우 산출·수정 통지(TASK_MODIFIED)는 이 API 호출 안에서 나가지 않고 재검토 표시(REVLT_YN) 해제로 풀리는 디바운스 윈도우가 별도 스케줄 tick 에서 처리한다.
