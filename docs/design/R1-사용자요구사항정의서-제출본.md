# R1 사용자 요구사항 정의서 (제출본)

> 본 문서는 「R1-사용자요구사항정의서.md」(저작도구 상세판)의 저작도구(AT) 항목을, 발주처 제출 엑셀(「KLID_AN_요구사항정의서」)과 동일한 톤으로 재작성한 **간결 제출본**이다.
> 제약·해결방안·검수기준은 한두 문장의 업무 서술로 기술하며, 내부 구현 식별자(클래스명·메서드명·DTO명)와 DB 테이블/컬럼·API 경로·연동 필드 계약은 노출하지 않는다. 시스템·솔루션·라이브러리 이름과 역할(REVIEWER 등)만 유지한다.
> 연동 계약·DB 스키마·API 경로 등 상세 설계 근거가 필요하면 상세판(「R1-사용자요구사항정의서.md」)을 참조한다.

## 작성 목적
> 시스템의 요구사항을 도출하여 발주자와 내용을 합의하고 하나의 업무 단위로서 가치를 가지고 수행될 수 있는 단위로서의 업무를 도출하여 업무 내용을 기술한다.

> **SFR-11(산불 학습데이터) 보완 반영 범위(2026-06-09)**: 발주처 보완요청으로 추가된 SFR-11 하위 항목 중 저작도구가 실제 수행하는 부분(`RQ-SFR-11-04/05/06/08/09/10`)만 위 표에 등재했다. 이들은 라벨링·증강 연동·비식별 연동·검수 등 기존 SFR-07/08/09 기능과 결합되며 신규 기능이 아니다. `RQ-SFR-11-01`(생성형 AI 모델 개발)·`RQ-SFR-11-02`(탐지 알고리즘 파라미터 조정)는 생성형 AI 본체로 외부 책임이고, 산불 실영상의 현장 수집·이미지 10만장·영상 5,000건 등 데이터 구축 규모와 외부 시험기관 품질검사는 데이터 구축 사업 영역이라 저작도구 R1에서 제외한다.

## 항목 설명

- **요구사항 ID**: 요구사항별 유일 ID. 「요구사항정의서.pdf」 원본 ID(`RQ-SFR-NN-NN`)를 사용한다.
- **RFP ID**: 제안요청서(RFP) 상의 상위 기능 분류 ID(`SFR-06` 등).
- **요구사항명 / 요구사항 설명**: 요구사항의 명칭과 상세 내용.
- **요구사항 출처**: 요구사항이 제시된 문서·페이지(제안요청서).
- **제약사항**: 수행에 필요한 조건·역할 경계(외부 책임 범위 등)를 한두 문장으로 기술.
- **중요도**: 전체 시스템 구현 측면 중요도(상/중/하).
- **해결방안**: 저작도구가 수행하는 업무를 한두 문장으로 기술(내부 구현 식별자·DB/API 계약은 제외).
- **검수 기준**: "~를 확인한다." 형식의 검증 기준.
- **비고**: 작성자/검토자.

## 작성 시 참고사항

> - **문서 성격**: 본 제출본은 발주처 제출 엑셀과 동일한 간결 업무 서술 톤을 따른다. 클래스명·메서드명·DTO명 등 내부 구현 식별자와 DB 테이블/컬럼·API 경로·연동 필드 계약은 노출하지 않는다.
> - **상세판 연계**: 연동 계약(요청/수신 항목)·DB 스키마·API 경로 등 상세 설계 근거는 「R1-사용자요구사항정의서.md」(상세판)를 참조한다. 두 문서는 동일한 요구사항 집합을 서술 수준만 달리하여 다룬다.
> - **범위 정합**: 저작도구(AT)는 ① 외부 증강 연동 ② 증강 결과 검수 ③ 외부 VLM 시계열 호출 연동 ④ 해상도 변경(직접 수행) ⑤ 라벨링·검수·버전관리 ⑥ 비식별 연동을 담당한다. **AI 추론 서버(ai-server)는 외부 시스템이 아니라 저작도구의 구성요소**(YOLO/SAM2 추론 등을 담당하는 내부 서버)이다. 생성형 AI 본체·VLM 본체·영상 합성 본체·비식별 솔루션·데이터마트 구축·내보내기가 외부 시스템 책임이다.
