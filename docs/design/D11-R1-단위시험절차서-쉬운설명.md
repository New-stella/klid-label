# D11-R1 단위시험 절차서 — 쉬운 설명본 (R1 기능요구사항 한정)

## 작성 목적
> 본 문서는 `D11-R1-단위시험절차서.md`(원본)의 내용을 **개발 용어(클래스명·테이블/컬럼명·상태코드)를 모두 일상어로 풀어** 옮긴 것이다. 시험 항목·범위는 원본과 동일하며, 처음 보는 사람도 "무엇을 확인하는 시험인지"를 바로 이해할 수 있도록 문장을 다시 썼다. 추적을 위해 케이스ID·요구사항ID·유스케이스(UC)·컴포넌트(CO) 식별자는 그대로 유지한다.
> 대상은 R1 기능요구사항에 **직접 대응하는 기능만**이며, 기능당 핵심 1~3건(정상 1건 + 핵심 경계/예외 1~2건)으로 압축했다. 작업 배정·로그인/인증·보안 필터·배치 진행 관리·프레임 추출·통계 같은 공통/기반 기능은 제외한다.

### 이 문서 읽는 법
- **표 컬럼**: 케이스ID · 무엇을 확인하나(케이스명) · 누가(작업권한) · 준비 데이터 · 어떻게(처리절차) · 기대 결과 · 결과(공란 — 실제 시험 후 기입).
- **블록 제목**: `요구사항ID · 기능명 · UC · CO · 처리 기능(쉬운 설명)` 순으로 표기. 원본의 "프로그램: 클래스명…" 부분은 일반 독자가 알기 쉬운 기능 설명으로 대체했다.
- **상태/판정 용어 풀이** (원본의 숫자 코드 → 본 문서의 표현):
  - 성공 처리됨 = 요청이 정상 수행됨(원본 200/201)
  - 잘못된 입력으로 거부됨 = 형식·범위·허용목록 위반(원본 400)
  - 로그인 안 한 사용자 차단됨 = 인증 없음(원본 401)
  - 권한 없는 사용자 차단됨 = 역할 권한 부족(원본 403)
  - 대상이 없어 "없음" 처리됨 = 존재하지 않는 자원(원본 404)
  - 이미 있어 충돌로 거부됨 = 중복·동시처리 충돌(원본 409)
- **역할**: 검수자 = 검수·관리 권한자(원본 REVIEWER), 작업자 = 라벨링 작업자(원본 WORKER).
