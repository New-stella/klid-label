# SFR-08-01 해석 확정 = VOS(추적+분할)

## context

R1 SFR-08-01(라벨링 정확도 향상) 해석을 두고 구 '자석 올가미'(magnetic lasso) 방식이 폐기된 뒤 최종 해석이 미확정 상태였다.

## decision

### chosen_option

VOS(추적+분할) 해석(채택)

### justification

SFR-08-01(라벨링 정확도 향상)은 VOS(추적+분할)로 확정한다 — SAM2 Track(박스→N프레임 추적 전파) + SAM2 분할(클릭/박스→폴리곤+신뢰도) + 폴리곤 트랙 보간(CVAT polyshape 정점대응 포팅)이 담당한다. POLYLINE은 라벨 타입 부재로 보간을 배선하지 않는다.

### 자석 올가미(magnetic lasso) 해석(구 해석·구현물, 폐기)

**cons**:

- 구현물 제거 완료 — 재도입 금지

**pros**:

### VOS(추적+분할) 해석(채택)

**cons**:

- POLYLINE은 라벨 타입 부재로 보간 미배선

**pros**:

- 추적·분할 자동화로 라벨링 정확도·생산성 동시 향상
- CVAT 포팅 자산 재사용 가능

- **description**: SAM2 Track(박스→N프레임 추적 전파) + SAM2 분할(클릭/박스→폴리곤+신뢰도) + 폴리곤 트랙 보간(CVAT polyshape 정점대응 포팅)이 담당
