# ai-server 탐지 백엔드 = YOLOX 단일화(RT-DETRv2 제거)

## context

RT-DETRv2(transformers) 백엔드가 병행 운영되던 중 라이선스 정책(ultralytics AGPL-3.0 회피, permissive 백엔드 통일) 및 유지보수 단순화 목적으로 정리되었다.

## decision

### chosen_option

YOLOX 단일화(채택)

### justification

ai-server 탐지 백엔드를 YOLOX(onnxruntime, Apache-2.0) 단일화하고 RT-DETRv2를 제거한다.

F1.

## consequences

### negative

- RT-DETRv2가 제공하던 대안 탐지 성능 특성 상실

### positive

- 라이선스 정책(ultralytics AGPL-3.0 회피, permissive 백엔드 통일) 준수 단순화
- 유지보수 대상 단일화

## decision_drivers

- 기술스택 정의에 이미 YOLOX가 현재 스택으로 명시돼 있어 실질적으로는 문서-코드 정합 확인 성격에 가까움

## considered_options

### YOLOX + RT-DETRv2 병행 운영(구, 폐기)

**cons**:

- 라이선스 정책(permissive 백엔드 통일) 목적상 병행 유지 불필요
- 유지보수 대상 배가

**pros**:

- 두 백엔드 성능 비교 가능

- **description**: 탐지 백엔드로 YOLOX와 RT-DETRv2(transformers)를 병행 운영

### YOLOX 단일화(채택)

**cons**:

- RT-DETRv2가 제공하던 대안 성능 특성 상실

**pros**:

- permissive(Apache-2.0) 백엔드로 라이선스 정책 준수 단순화
- 유지보수 대상 단일화

- **description**: ai-server 탐지 백엔드를 YOLOX(onnxruntime, Apache-2.0) 단일화, RT-DETRv2 제거
