# 마킹 도메인 신규 도입 — 자동/수동 이벤트 식별

## context

고도화는 영상 배치 파이프라인에 이벤트 식별 단계인 '마킹'을 신규 도입했다. 파이프라인은 적재 직후 자동 실행되는 선두 비식별로 시작하고, 마킹은 비식별이 끝난 영상을 대상으로 수행하며, 마킹 완료가 잔여 배치(VLM 시계열 위탁 → 프레임 추출 → 오토라벨링 → 트랙 보간)를 기동한다. 마킹은 자동(프레임 간격 기반)과 수동(작업자가 이벤트 시점을 직접 지정)의 두 모드를 가진다. 마킹 결과는 VLM 시계열 위탁 요청에 프레임 선택 정책으로만 반영한다 — 이벤트명·영상 경로·마킹 원문 배열은 위탁 규격 밖이라 싣지 않는다. 마킹 완료 이벤트는 마킹 트랜잭션 커밋 이후에만 소비해 배치 대기 상태로 전이시키고 잔여 배치를 비동기로 시작한다. 구 순서(마킹 → VLM 시계열 → 비식별 → 프레임 추출)와 구 위탁 내용(이벤트명·영상 경로·마킹 배열 전달)은 지금은 그렇게 하지 않는다 — 비식별을 선두로 옮겨 마킹 이후 모든 단계가 비식별 영상만 다루게 하고, 위탁에는 프레임 선택 정책만 싣는다.
