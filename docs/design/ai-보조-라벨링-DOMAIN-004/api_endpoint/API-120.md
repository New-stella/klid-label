## description

base64 이미지와 클릭 포인트 또는 박스 프롬프트를 받아 폴리곤 마스크(폐곡선 좌표)와 신뢰도를 반환한다. points/box 둘 다 없으면 이미지 중앙점을 기본 프롬프트로 사용한다. mock 모드/모델 미로드/마스크 없음 시 사각 폴리곤 mock으로 fallback하며 mock/source/mock_reason으로 표시한다. Meta 공식 SAM2ImagePredictor 사용. 저작도구 내부 stateless 추론, 인증 없음. BE는 POST /v1/frames/{srcSn}/sam2-segment(API-093)로 프록시한다. 배치와 저작도구 화면 요청은 서로 다른 실행 슬롯에서 처리되며, 어느 슬롯으로 갈지는 선택 요청 헤더 X-Workload 가 정한다. 헤더가 없으면 저작도구 화면 요청으로 처리한다.
