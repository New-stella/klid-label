AI 추론·외부 시계열 분석 장비의 노드 원장을 다루는 관리 창구다. 이 원장이 장비 주소의 진실원이며, 배포 설정값은 원장이 비어 있을 때 최초 1회 씨앗으로만 쓰인다.

주소 검증은 진실원이 옮겨갔다고 사라지지 않는다 — 저장되는 주소에도 스킴(http 또는 https)·형식·예약 대역 거부가 그대로 걸린다. **평문 http 와 사설 대역은 통과가 정상이다**(대역 차단은 폐기됐다). 거부되는 것은 클라우드 메타데이터·링크로컬 같은 예약 대역과 비허용 스킴·형식 위반이며, 거부 사유에 입력 원문·호스트·해석 결과를 싣지 않는다 — 실으면 그 응답이 내부망을 훑는 수단이 된다.

장비 유형은 추론(탐지·분할·추적)과 외부 시계열 분석 둘이며 유형마다 여러 대를 둘 수 있다. 부하를 세는 축이 유형마다 다르다 — 추론은 동기 호출이라 큐 길이가 곧 부하지만, 시계열은 위탁 후 콜백이라 큐를 볼 수 없어 우리 원장의 미결 위탁 수를 센다.

이 창구는 운영·관리 성격의 쓰기라 관리자 권한에 더해 유효한 관리자 단기 유효창을 함께 요구한다. 유효창은 권한을 대체하지 않고 가산되며 역할을 승격시키지도 않는다 — 관리자 권한은 그대로 필요하다. ⚠ 검수자는 이 창구를 열 수 없다. 계층(ROLE_ADMIN > ROLE_REVIEWER)은 관리자가 검수자 자리를 통과하게 할 뿐 그 반대는 성립하지 않는다.

상태는 가용·이용불가·정비중·비활성 넷이며 아무 상태로나 갈 수 있는 것이 아니다. 정비중은 신규 배정만 막고 진행 중인 배정은 끝까지 간다 — 그것이 무중단의 정의다. 이용불가는 상태점검 연속 실패로 자동 배제된 상태이고 복귀는 연속 성공으로 한다.
