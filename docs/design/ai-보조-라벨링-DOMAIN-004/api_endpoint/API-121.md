## description

이전 프레임 폴리곤을 다음 프레임으로 전파하고 동일 track_id를 유지한다. 이전 폴리곤의 bbox를 프롬프트로 다음 프레임을 세그멘테이션하며, 마스크 없음/추론 실패 시 이전 폴리곤을 그대로 반환하는 mock 으로 fallback한다. prev_image_b64/next_image_b64는 mock 모드에서는 미사용이라 기본값 빈 문자열이다. 저작도구 내부 stateless 추론, 인증 없음. (SFR-08-01 VOS 이어붙이기) 배치와 저작도구 화면 요청은 서로 다른 실행 슬롯에서 처리되며, 어느 슬롯으로 갈지는 선택 요청 헤더 X-Workload 가 정한다. 헤더가 없으면 저작도구 화면 요청으로 처리한다.
