## description

저작도구 사용자 편의 기능:
- 사용자 기능에 대한 온라인 도움말을 제공하고, 입력 서식이 있는 화면은 서식과 관련 정보를 함께 안내한다.
- 콘텐츠의 모양과 배치를 이해하기 쉽게 구성하고, 사용자가 원하는 기능을 쉽게 찾을 수 있는 탐색 체계를 제공한다.
- 모든 페이지에 현재 위치 정보를 명확히 표시한다.
- 자주 쓰는 기능은 바로가기 퀵메뉴로 제공한다.
※ 포털 채널 화면은 상위 시스템이 머리 영역과 주 메뉴를 소유하므로, 위치 표시와 바로가기는 본문 영역이 제공하는 범위에서 충족한다.
