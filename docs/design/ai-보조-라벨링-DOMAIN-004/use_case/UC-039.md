## description

라벨링 화면에서 사람이 눌러 실행하는 탐지다. 배치가 자동으로 도는 탐지와 달리 사람이 그 자리에서 부르며, 결과를 저장하지 않고 좌표만 돌려주어 작업본 편집에 쓰인다 — 저장은 라벨 편집 흐름이 소유한다.

[무엇을 탐지할지는 서버가 정한다] 화면이 보낸 대상 분류를 그대로 믿지 않고 라벨 마스터에 매핑된 분류와의 교집합으로 정한다. 매핑되지 않은 분류만 요청되면 외부를 부르지 않고 빈 결과와 안내를 돌려준다.

[좌표는 경계로 좁히되 형식 위반은 전부 거른다] 음수와 이미지 초과는 경계로 좁혀 돌려주고, 이미지 밖 퇴화 상자는 그 검출만 빼며, 수가 아닌 좌표가 섞이면 그 응답의 검출을 하나도 돌려주지 않는다.

[외곽 밀착·추적과는 다른 흐름이다] 클릭으로 외곽을 따는 것과 객체를 따라가는 것은 각각 별도 흐름이 소유한다.

## alternate_flows

### 매핑된 대상이 없음

**steps**:

- 외부 추론을 부르지 않는다
- 빈 결과와 안내 문구를 돌려준다

- **trigger**: 요청한 분류가 전부 미매핑이거나 매핑된 라벨이 하나도 없다

### 외부 추론 실패 또는 목 응답

**steps**:

- 실패는 외부 오류로 알리고 진행 표식을 푼다
- 목 응답은 자동 적용하지 않고 빈 결과와 안내만 돌려준다

- **trigger**: 외부 추론이 실패했거나 목 응답을 돌려줬다

### 추론 뒤에 작업락이 걸림

**steps**:

- 좌표를 돌려주지 않고 충돌로 막는다
- 진행 표식을 풀어 다시 요청할 수 있게 한다

- **trigger**: 외부 호출이 끝난 사이에 그 영상이 잠겼다
