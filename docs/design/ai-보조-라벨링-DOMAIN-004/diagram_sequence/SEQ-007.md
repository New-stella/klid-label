## description

SystemConfigController.update(PUT /v1/manage/configs/{key}, REVIEWER 전용, WORKER 호출 시 403) → SystemConfigService.update 가 POLYGON_SIMPLIFY_TOLERANCE 값을 LS 설정 테이블에 저장 + Caffeine 캐시(TTL 60s) 전체 무효화. 이후 Sam2TrackService.readSimplifyTolerance 가 해당 epsilon 을 조회해 폴리곤 단순화에 적용하며, 조회 실패 시 기본값(1.0px)으로 fail-safe 폴백.
