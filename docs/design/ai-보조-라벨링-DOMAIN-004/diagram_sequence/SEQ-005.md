## description

작업자가 시작 프레임의 객체를 지정하면 SAM2 기반 비디오 객체 추적·분할(VOS)로 후속 프레임의 위치를 추론해 전파한다(LabelController.sam2Track → Sam2TrackService.track). 요청 검증은 path/body srcSn 불일치 400(CWE-345), nextSrcSns <최대 50>(CWE-770), prevPolygon 정점 3~1000 · 음수/형식 차단(400)이다. IDOR(CWE-639)은 시작 프레임과 <모든 후속 프레임>에 대해 AI 호출 전에 검증하고, 프레임 이미지 인코딩은 FrameImageEncoder 단일 진입점을 거치므로 비식별 누락 신고 게이트가 <프레임마다> 평가된다 — 추적 도중 신고가 들어와도 그 이후 프레임 픽셀은 나가지 않는다(412). ★결과를 DB 에 저장하지 않는다 — 구 구현은 프레임마다 createAutoPolygon(AUTO_LBL_YN='Y')로 즉시 저장했으나, AI 탐지(AutolabelOnlineService)와 동일하게 <좌표(draft)만 반환>하도록 통일됐고 클라이언트가 작업본에 병합한 뒤 PUT /v1/frames/{srcSn}/labels 로 확정한다. DB write 가 없어 @Transactional 도 제거되어 AI 블로킹 호출 구간이 control HikariCP 커넥션을 점유하지 않는다(F-1 커넥션풀 고갈 방지). 트랙 병합(TrackMergeService)·보간(TrackInterpolator)은 이미 저장된 라벨을 대상으로 하므로 본 미저장 전환과 무관하다(회귀 없음). 출력 형태(R12)는 선택 객체의 형태를 따른다 — shape=POLYGON(기본)이면 폴리곤을 그대로, shape=BBOX 면 폴리곤의 외접 bbox([[minX,minY],[maxX,maxY]])를 산출하며 퇴화 폴리곤(폭/높이 1px 미만)은 해당 프레임만 스킵하고 전체 추적은 중단하지 않는다. 단순화 epsilon 은 시스템 설정 POLYGON_SIMPLIFY_TOLERANCE 를 조회해 쓰고 실패 시 1.0px 로 fail-safe 폴백한다(UC-006). 데이터 진정성(CWE-345) — ai-server mock 응답 프레임은 결과에서 <제외>한다. mock track 은 시드 폴리곤 복사본을 score=0.9 로 돌려주므로 걸러내지 않으면 "N 프레임 추적"이 "시드 N개 복제"로 둔갑해 학습데이터가 오염된다. 판정은 긍정 증명 기반(mock 메타 생략 응답도 신뢰하지 않음)이고, 제외 사실은 Sam2TrackOutcome 으로 컨트롤러에 전달돼 안내 메시지(FE 자동적용 차단 신호)가 된다 — SAM2 세그·YOLO 오토라벨과 동일 규약이다. 응답 폴리곤의 최소 정점 수 위반은 502(외부 시스템이 잘못 준 것)이며 요청 축의 400 과 섞지 않는다. 그 안내 자리는 제외된 프레임을 알리는 용도 전용이며 상한 절단 안내는 싣지 않는다 — 같은 자리에 다른 안내를 얹으면 두 사실이 섞인다.
