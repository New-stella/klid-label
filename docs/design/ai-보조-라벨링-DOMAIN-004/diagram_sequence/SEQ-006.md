## description

대략 친 시드(클릭 또는 박스)를 ai-server SAM2 segment 로 프록시해 외곽선 기반 폴리곤 + 신뢰도를 산출하고 경계에 밀착시킨다. 구현은 <POST /v1/frames/{srcSn}/sam2-segment>(LabelController.sam2Segment → Sam2SegmentService.segment)이며, 구 서술이 가리키던 sam2-track(Sam2TrackService)은 객체 자동 추적(UC-004)의 별도 엔드포인트다 — 두 경로를 혼동하지 말 것. 입력 검증은 ①points/box 정확히 1개(@AssertTrue 배타, 위반 400) ②path srcSn ≠ body srcSn → 400(CWE-345) ③본인 배정 아니면 403(CWE-639) ④비식별 누락 신고 구간이면 412 ⑤이미지 상한 초과 413 이다. 응답 폴리곤은 정점 3개 이상·[x,y] 쌍·이미지 실측 경계 내임을 검증한 뒤(CWE-20) Douglas-Peucker 로 단순화하고, 단순화 결과가 3점 미만으로 줄면 원본 응답 폴리곤을 그대로 쓴다(형태 보존). ★BE 는 DB 저장을 하지 않는 stateless 프록시다 — 결과는 FE 가 캔버스 폴리곤으로 적용하고 저장은 라벨 임시저장 흐름(PUT /v1/frames/{srcSn}/labels)이 담당한다(구 서술 'createAutoPolygon(AUTO_LBL_YN=Y) save' 는 sam2-track 의 동작이라 폐기). 내부 mock(모델 미로드) 응답은 좌표를 신뢰할 수 없으므로 빈 폴리곤 + 안내 message 로 내려 FE 자동적용을 차단하며(YOLO 오토라벨·SAM2 Track 과 동일 규약), ai-server 연동 실패는 502 다. SAM2 는 <원본 프레임 이미지에만> 실행하고 좌표는 동일 해상도라 비식별본과 공유한다. FE 는 SAM_SEGMENT 캔버스 도구(단축키 G)이고 MASK↔RLE↔Polygon 변환(CVAT 포팅)을 사용한다. 본 흐름은 SFR-08-01(라벨링 정확도 향상) = VOS(추적+분할) 해석의 <분할> 축이다 — 구 '자석 올가미' 해석은 2026-06-04 재정정으로 폐기됐다.
