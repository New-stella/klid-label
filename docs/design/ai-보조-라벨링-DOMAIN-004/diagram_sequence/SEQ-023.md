## description

외부 VLM 시계열 메타가 저작도구에 도착해서 사람이 검토·수정하고 승인으로 확정되기까지를 그린다. 결과는 폴링이 아니라 벤더가 보내는 콜백으로 도착하며, 그 경로는 인증 없이 열려 있고 호출 IP 허용목록·본문 크기 상한·상관키 발급 게이트가 대신 방어한다. 콜백 본문의 results 는 배열이 아니라 일치도와 서술을 담은 객체 한 벌이다.

적재는 시계열 메타 테이블(LS_DATA_META)에 키-값으로 이뤄지고, 검수큐(LS_DATA_META_REVIEW)에 들어가는 것은 서술(vlm.description) 하나다. 일치도(vlm.accuracy)는 화면 전용이라 검토행을 만들지 않으며, 그 귀결로 승인된 메타만 노출하는 데이터마트 뷰와 학습데이터 산출물에도 나가지 않는다 — 마트에 없는 것은 결함이 아니라 의도다.

사람은 별도 전용 화면이 아니라 라벨링 캔버스 화면(SCREEN-005)의 시계열 메타 패널에서 검토·수정한다. 조회 응답은 편집 가능 목록·읽기 전용 목록·영상 기술 정보 목록으로 나뉘고, 읽기 전용 키와 영상 기술 정보를 수정하려 하면 400 이다.

승인된 영상의 서술이 벤더 콜백으로 다시 갱신되면 그 검토행을 검토 대기로 되돌리고 산출 재생성을 동반하는 수정 통지를 발행한다. 되돌림은 값이 실제로 달라졌을 때만 일어나며 같은 값 재수신은 멱등 처리다. 반려된 검토행도 함께 되돌린다 — 반려 판단은 바뀌기 전 본문에 대한 것이라 새 본문에 적용되지 않기 때문이다.

검토 상태의 최종 확정은 영상 검수 승인이 담당한다. 승인 트랜잭션 안에서 검토 대기 행이 승인으로 전이되며, 반려 행은 반려를 존중해 건너뛴다.
