## description

AI 추론 장비를 여러 대 등록해 놓고 부하로 골라 쓰기 위한 원장. 세 표가 서로 다른 축을 맡는다. LS_AI_SRVR 가 장비 등록부로 장비의 주소·유형·상태와 점검 성공·실패 누계를 갖는다. LS_AI_SRVR_USG 는 같은 장비의 부하를 용도(배치·인터랙티브)로 갈라 세며, 그래서 기본키가 장비와 용도의 복합이다 — 배치가 장비를 포화시켜도 인터랙티브 요청이 막히지 않게 축을 가른 것이다. LS_AI_SRVR_ALTMNT 는 영상 한 건이 어느 장비에 배정됐는지를 고정하며, 원시일련번호에 유일 제약이 걸려 영상당 장비 한 대로 묶인다(같은 영상의 연속 처리가 장비를 오가지 않게 하는 고정 배정). 장비 유형은 추론과 시계열로 갈린다. 물리 컬럼명은 표준단어 조합을 따른다 — 서버(SRVR)·아이디(ID)·명(NM)·주소(ADDR)·유형(TYPE)·코드(CD)·상태(STTS)·점검(CHCK)·실패(FAIL)·성공(SCS)·건수(NOCS)·일시(DT)·등록(REG)·수정자(MDFR)·수정(MDFCN)·배정(ALTMNT)·일련번호(SN)·원시(RAW)·사유(RSN)·용도(USG)·대기(WTNG)·처리(PRCS).
