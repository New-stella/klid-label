## description

저작도구가 준수하는 표준 지침·가이드:
- 행정기관 및 공공기관 정보시스템 구축·운영 지침(행정안전부)
- 전자정부 웹사이트 품질관리 지침(행정안전부)
- 한국형 웹 콘텐츠 접근성 지침 2.1(국립전파연구원)
- 모바일 애플리케이션 콘텐츠 접근성 지침 2.0(국립전파연구원)
- 행정기관의 코드표준화 추진지침(행정안전부)
- 행정정보데이터베이스 표준화 지침(행정안전부)
- 행정·공공기관 웹사이트 구축·운영 가이드(행정안전부)
- 공공 웹사이트 플러그인 제거 가이드라인(행정안전부)
- 디지털 정부서비스 UIUX 가이드라인(행정안전부)
- 정보시스템 성능관리 지침(한국정보통신기술협회)

적용 방식:
- 코드성 데이터는 코드표준화 추진지침, 데이터베이스 객체는 행정정보데이터베이스 표준화 지침을 준거로 설계한다.
- 화면은 접근성 지침과 UIUX 가이드라인을 디자인 시스템에 반영하고, 비표준 플러그인 없이 구현한다.
- 성능관리 지침을 근거로 응답시간과 자원 사용률의 관리 기준을 설정한다.
※ 저작도구는 별도의 모바일 네이티브 애플리케이션을 두지 않으므로, 모바일 애플리케이션 콘텐츠 접근성 지침은 반응형 웹 화면의 접근성 준수로 이행한다.
