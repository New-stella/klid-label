### diff_summary

2차 RFP 비기능(담당=공통) 요구를 저작도구 기준으로 신규 수용

## description

저작도구 연계 제공 기준:
- 다른 주체에 데이터를 온라인으로 제공할 때는 개방형 연계 기술을 활용한 인터페이스를 제공한다.
- 발주기관이 지정한 표준 연계모듈이 있으면 그것을 이용해 타 시스템 연계체계를 설계한다.
- 연계로 인해 본 시스템 성능에 영향을 주지 않도록 설계한다 — 외부 위탁 호출은 비동기로 제출하고, 통지는 축적·병합하여 발송 횟수를 제한하며, 대량 조회는 페이징을 강제한다.
- 외부 연계 시스템은 해당 시스템 담당과 협의하여 규격을 확정한 뒤 구축한다.
