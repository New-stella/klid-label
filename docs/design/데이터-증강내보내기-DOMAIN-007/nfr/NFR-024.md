## description

국가정보자원관리원 도입 HW·SW 사양을 참고하여 저작도구의 프로그램 개발과 아키텍처를 설계한다.
- 웹·WAS·DB·AI 추론 서버의 배치와 자원 배분을 도입 사양에 맞춰 설계한다.
- AI 추론(오토라벨링·분할·추적)의 GPU 자원은 동시 처리 한도를 결정하는 제약이므로, 도입 사양에 맞춰 동시 처리 상한과 부하 분산 기준을 정한다.
- HW·SW 규격과 수량은 실제 도입 시점에 변경될 수 있으므로, 특정 사양에 종속되지 않는 구성을 택하고 변경 시 재설계 범위를 최소화한다.
- 도입 이전 기간에도 개발·시험이 가능하도록 별도 개발환경을 선확보한다.
