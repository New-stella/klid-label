## description

저작도구 데이터 표준 관리 기준:
- 구축기간 동안 데이터 표준의 변경이력을 관리하는 방안을 수립하고 적용한다.
- 표준사전과 실제 데이터 항목의 일치 여부를 주기적으로 점검한다.
- 신규 데이터베이스 객체를 만들 때 물리명(표준단어 조합)과 자료형·길이(표준도메인)를 표준사전과 대조해 확정하고, 대조 결과를 변경 단위로 남긴다.
- 표준에 없는 개념이 필요하면 임의 약어를 만들지 않고 소유 주체의 등록 절차를 거쳐 사용한다.
