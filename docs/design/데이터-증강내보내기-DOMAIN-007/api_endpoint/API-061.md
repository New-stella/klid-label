## description

원본 영상 1건에 딸린 증강·해상도 파생 결과를 비교 이미지와 함께 조회한다. 검수자 전용이다.

[경로 변수는 원본 영상 식별자다] 요청한 값을 그대로 돌려주며, 한 영상의 파생들이 이 값으로 묶인다. 채택·반려·복구 요청의 경로 변수는 이것이 아니라 결과 항목 식별자다.

[페이징 축이 둘이다] 결과 항목(파생 1건) 축과 그 안의 비교 이미지 쌍 축이 각각 따로 잘린다. 한 영상에 파생이 여러 건 공존할 수 있고 파생마다 프레임 쌍이 수백 건일 수 있어 한 축으로는 자를 수 없다.

[비교 이미지가 비어 있는 이유를 항상 말한다] 결과물 상태 축이 값 없이 비는 경우가 없어, 화면이 '생성 중'·'비교 이미지 반입 중'·'비식별 신고로 보류'·'생성 실패'·'취소됨'·'유예 경과로 실삭제'·'파생 매핑 없음'을 빈 화면 대신 사실대로 안내한다.

[결정 축과 생성 축을 섞지 않는다] 활용 결정 상태는 사람의 검수 결정이고, 해상도 파생은 검수 대상이 아니라 채택·반려를 시도할 수 없다는 것이 응답에 함께 실린다.

[이미지 경로는 API 경로만 내려준다] 스토리지 파일 경로는 싣지 않으며, 실제 서빙 시점에 인가·비식별 신고 게이트·경로 검증을 다시 수행한다.
