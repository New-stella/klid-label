# 해상도 변경 수행

## goal

표준 해상도 프리셋(1080P/720P/480P)을 산출 프레임의 크기 상한으로 삼아 프리셋마다 새 파생영상(RAW_SN)을 생성해 비디오 복사 + 프레임 리스케일(종횡비 보존 균일 배율, 업/다운스케일 모두 허용) + 좌표 재계산 적재를 수행한다.

### [5]

- **action**: finalize 성공 시 파생영상이 ACCEPTED로 확정된다(실패 시 예약행 삭제)

## description

해상도 변경은 표준 해상도 프리셋(1080P/720P/480P)마다 새 파생영상(RAW_SN, ORGNL_RAW_SN으로 원본 참조)을 생성하는 증강형 파생영상이다. 비디오 파일은 원본(비식별) 복사(재인코딩 없음), 프레임 이미지셋만 리스케일한다(축소·확대 모두 허용). 프리셋의 두 수치는 산출 프레임의 고정 크기가 아니라 상한이다 — 원본의 짧은 변을 프리셋의 짧은 값(1080/720/480)에 맞추는 배율을 구하고, 그 배율로 계산한 긴 변이 프리셋의 긴 값(1920/1280/854)을 넘을 때만 긴 변이 상한에 맞도록 배율을 낮춘다. 가로·세로에 같은 배율을 적용해 종횡비를 보존하며(축을 따로 늘려 왜곡시키지 않는다), 산출 프레임 크기는 그 배율로 계산된 실제 크기라 원본 종횡비에 따라 달라지고 남는 영역을 채우는 패딩이 없다. **업스케일(원본보다 높은 해상도)도 허용**한다 — 산출 크기가 원본과 같아지는 프리셋만 스킵하고 나머지 프리셋은 모두 생성한다. 라벨/이미지 좌표는 그 균일 배율의 곱셈만으로 재계산해 **적재한다** — 오프셋 가산이 없다(BBOX/POLYGON/세그먼테이션/키포인트 전 종류). 저장모델은 증강과 완전 통합돼 있다 — 전용 테이블(LS_RESOLUTION_EXPORT/LS_RESOLUTION_LBL_MAP) 없이 LS_DATA_AUG(AUG_TYPE_CD=RESL_1080P/720P/480P)+LS_DATA_AUG_LBL_MAP(COORD_RECALC_YN/SCALE_X/SCALE_Y 재사용 — 균일 배율이라 두 값은 항상 같다)에 적재한다. 해상도 파생은 증강 이력(GET /v1/augments)에 노출·집계에 포함되나 accept/reject(검수 승인·반려)는 차단된다(UC-010 참조). 기존에 생성된 파생본은 재생성하지 않으며 신규 생성부터 이 규칙이 적용된다. (R2 UC-003, RQ-SFR-06-03)

## alternate_flows

### 대상 프리셋 전부 스킵

**steps**:

- 대상 프리셋이 전부 스킵 대상(산출 크기가 원본과 동일)이면 400으로 거부한다

- **trigger**: 대상 프리셋 모두에서 산출 크기가 원본과 같아지는 경우

### 일부 프리셋 생성 실패

**steps**:

- 1건 이상 성공 시 201, 전부 실패 시 500

- **trigger**: ffmpeg 리스케일 또는 좌표 재계산 실패

### 파생본 대상 요청

**steps**:

- 해상도 변경 요청을 400으로 거부한다 — 파생 깊이 1 고정(ADR-023)에 따른 영구 조건이라 재시도 여지가 없다

- **trigger**: 대상 영상이 이미 파생영상(ORGNL_RAW_SN non-null)인 경우

### 비식별 누락 신고 구간

**steps**:

- 해상도 파생 생성은 차단하지 않는다 — 외부 위탁이 없는 내부 ffmpeg 리스케일이라 유출 경로가 열리지 않는다
- 부모 게이트는 DE_IDNTF_YN='N'(비식별 미수행)만 차단하고 'F'(신고)는 통과시킨다

- **trigger**: 대상 영상이 비식별 재처리 대기(DE_IDNTF_YN='F') 상태인 경우
