## description

`POST /v1/genai/callback` 이 외부 증강 결과(WINTER/NIGHT/RAIN)를 웹훅으로 수신 → 새 영상(RAW_SN, **`ORGNL_RAW_SN`** 으로 원본 참조 — V82/V95 표준용어) 등록·원본 라벨 verbatim 복사·PENDING 시작.

## ★★ 경로·인증·페이로드 전면 교체 완료 (구 /v1/aug/callback+HMAC 폐기)
구 경로 `POST /v1/aug/callback`(HMAC 서명 필수, secret `webhook.hmac.secret.augment`) + 내부 자체 채움(self-fill) 콜백 시뮬레이터는 **폐기**되었다. 신 경로 `POST /v1/genai/callback` — 「생성형 AI API 연동명세서 v1.1」§4.2/§4.3 그대로 준수, **무서명**(명세서상 웹훅에 서명·인증 헤더 자체가 없음).

## 페이로드 (GenAiCallbackRequest, snake_case)
`request_id`(≤128, `^[A-Za-z0-9_-]+$`, 우리가 발급한 job 단위 멱등키 = `LS_DATA_AUG_JOB.IDMP_KEY` 의 echo) · `job_id`(≤200, 외부가 202 응답으로 발급) · `status`(RUNNING|SUCCEEDED|FAILED) · `progress`(0~100) · `current_step`(≤20) · `updated_at`(≤64) · `results[]`(SUCCEEDED 시, 최대 100건: `generated_data_id`·`media_type`(IMAGE|VIDEO)·`output_file_path`(≤500)·`checksum`) · `error_code`(≤50, FAILED 시)·`error_message`(≤1000, FAILED 시).
- 상태 전이마다(RUNNING progress 10/50/90 → SUCCEEDED|FAILED) 발사되며 CANCELED 는 발사되지 않음(명세서 계약 사실).
- 전송 실패 시 벤더가 재시도하므로 동일 페이로드 중복 도착이 정상 — 수신부는 멱등해야 함.
- 미지 필드는 무시한다(외부 필드 추가에 강건).

## 응답·멱등
`applied`(실제 반영 여부) 필드로 회신 — 멱등 흡수(DUPLICATE)·롤업 보류(DEFERRED)는 `applied:false`(구 구현은 이 경우도 true 를 반환해 외부가 정상 인계로 오해하던 결함 수정). **정책 보류(WITHHELD_*)는 2026-07-29 폐기** — 부모가 비식별 신고('F') 구간이어도 파생 생성은 진행하며, 부모를 물리적으로 쓸 수 없는 경우(비식별 미완료·부모/프레임 부재)는 보류가 아니라 REJECTED 로 즉시 실패 확정한다.

## 상태 전이
SUCCEEDED→ACCEPTED, FAILED→REJECTED(PENDING 가드 — 종결 상태에서는 되돌리지 않음).
