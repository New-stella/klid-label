## description

외부 생성형 AI(SFR-07) 가 증강 결과를 webhook 으로 보내면 AugmentResultService 가 멱등 원장(발급 allowlist · 중복 replay 스킵) · resultFilePath SSRF/CWE-22 검증 · augType 일치 검증을 거친 뒤 부모 게이트를 <상태 전이 앞>에서 판정한다(구 순서처럼 전이 후 게이트에 걸리면 aug 는 ACCEPTED 로 종결되고 신규 영상은 0건인데 재콜백도 막힌다). 부모 게이트는 LsDataRaw.hasDeidentArtifact() 단일 헬퍼로 판정하며 DE_IDNTF_YN='N'(비식별 미수행 — 복사할 비식별본이 물리적으로 없음)만 차단하고 'F'(비식별 누락 신고 구간)는 통과시킨다 — 신고가 막는 것은 외부 위탁(요청·전송)뿐이고 파생 생성은 신고와 무관하다. AUG_PROC_STTS_CD 는 <생성 결과 전용>(성공 ACCEPTED / 실패 REJECTED / 취소 CANCELED)이며 웹훅이 소유한다 — REVIEWER 의 사용·폐기 결정은 LS_DATA_AUG_RVW.RVW_STTS_CD 가 단독으로 소유하고 작업목록 등재 게이트도 리뷰 축을 본다(두 축을 한 컬럼에 합치지 말 것). 성공 시 동기 트랜잭션은 <새 영상 RAW + 매핑까지만> 한다 — LsDataRaw.createFromAugment 로 ORGNL_RAW_SN(구 PARENT_RAW_SN, V82 rename)=부모 · SRC_TYPE=AUGMENTED · PENDING · deIdntfYn='N' 으로 생성하고, VMS_CLIP_ID 는 시각이 아니라 증강 행 PK(DATA_AUG_SN)로 유일화하며(중복 요청 허용 이후 동시 콜백이 같은 밀리초에 UK_LS_DATA_RAW_VMS_CLIP 을 위반하면 결과물이 유실된다), 촬영환경·개인정보 영상축 판정을 부모로부터 1회 계승하고(copyShootingEnvironmentFrom/copyPrivacyMetaFrom), NEW_RAW_SN 매핑(V155)을 같은 트랜잭션에서 확정해 등재 게이트 그랜드퍼더링 창을 닫는다. 파생의 RAW_FILE_PATH_NM 은 <파생 자신의 비식별 사본 경로>이며 부모 원본(비-비식별) 경로 폴백은 금지된다(CWE-359). 프레임 재추출·라벨/메타 복사·비식별 불변식 확정은 커밋 이후 AsyncAugmentFrameRunner 의 3-Phase 로 미룬다 — Phase A(짧은 REQUIRES_NEW, 멱등 가드·경로 스냅샷) → Phase B(트랜잭션 밖 순수 파일 I/O — 부모 비식별 영상 실제 복사 + ffmpeg 프레임 재추출) → Phase C(짧은 REQUIRES_NEW, 라벨 좌표를 그대로 복사해 LS_DATA_AUG_LBL_MAP(COORD_RECALC_YN='N')·메타 영속 + COMPLETED 전이) → ffprobe 기술메타. 부모 비식별 영상 경로는 문자열로 조합하지 않고 LS_DEIDENT_PROC_LOG.DE_IDNTF_FILE_PATH_NM 값을 읽는다(mock=deidentified.mp4 / KPST={원본stem}-mask{ext} 로 영상마다 다르다). ffprobe 를 Phase C 성공 이후에만 돌리는 이유는 측정 대상이 부모가 아니라 파생의 비식별 사본이기 때문이다(나란히 기동하면 사본 생성 전 probe 레이스).
