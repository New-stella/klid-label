# 해상도 변경(SFR-06-03)을 증강 파생영상 모델(LS_DATA_AUG/RESL_*)로 통합

## context

구 설계는 해상도 변경(SFR-06-03)을 '프레임 이미지셋 다운스케일만·라벨 좌표 미제공·전용 테이블 LS_RESOLUTION_EXPORT/LS_RESOLUTION_LBL_MAP로 1행 추적·업스케일(targetH>=srcH) 400 거부'로 모델링했다(INT-008/CDIAG-010/API-092에 기록). 그러나 이는 증강 파생영상과 저장·라이프사이클·라벨매핑 로직이 사실상 동일한데도 별도 테이블·별도 코드 경로로 이원화되어 유지비와 드리프트 위험이 컸고, 라벨 좌표 미제공은 파생영상을 학습데이터로 쓸 수 없게 만들었다. 2026-07-21 설계 반전 → 2026-07-22 저장모델 통합으로 재정리한다.

## deciders

- 박찬기

## decision

### chosen_option

증강 파생영상 모델로 통합(채택)

### justification

표준 해상도 3종 프리셋마다 새 파생영상(RAW_SN)을 생성하고 ORGNL_RAW_SN으로 원본을 참조해 증강과 동일한 파생영상으로 취급한다. 저장모델은 증강과 완전 통합: 전용 테이블 없이 LS_DATA_AUG + LS_DATA_AUG_LBL_MAP에 적재하고, 판별자는 AUG_TYPE_CD 값 RESL_1080P/RESL_720P/RESL_480P(표준용어 RESL=해상도), 라벨 배율은 기존 LS_DATA_AUG_LBL_MAP.COORD_RECALC_YN/SCALE_X/SCALE_Y를 재사용하며, 중복 방지는 부분 유니크 인덱스 UK_LS_DATA_AUG_RESL (SRC_SN, AUG_TYPE_CD) WHERE AUG_TYPE_CD LIKE 'RESL_%'(V125)로 건다. 비디오 파일은 원본(비식별) 복사(재인코딩 없음), 프레임 이미지셋만 목표 해상도로 리스케일하고, 라벨/이미지 좌표를 배율(scaleX=targetW/srcW, scaleY=targetH/srcH)로 재계산해 적재한다(BBOX/POLYGON/세그멘테이션/키포인트 전 종류). 원본과 동일 해상도인 프리셋만 스킵하고 업스케일(확대)도 허용한다. 구 전용 테이블 LS_RESOLUTION_EXPORT/LS_RESOLUTION_LBL_MAP은 V126에서 백필 후 fail-closed DROP한다. 해상도 파생은 증강 이력(GET /v1/augments, resolutionTypes 필드)에 노출·집계에 포함되나 내부 생성물이므로 accept/reject(검수 승인·반려)는 차단한다. aug 라이프사이클은 예약 시 PENDING(생성 중) → finalize 성공 시 ACCEPTED(생성 완료), 실패 시 예약행 삭제다.

## consequences

### risks

- V126 fail-closed DROP 전 백필 누락 시 데이터 손실 — 백필 검증 게이트 필요
- finalize 락-I/O 분리(재비식별 stale PII 게이트, 증강 ffmpeg 트랜잭션 밖) 미준수 시 stale PII 노출 창

### neutral

- API POST /v1/videos/{rawSn}/resolution 응답이 생성된 파생영상 목록(derivatives[])으로, 요청 바디는 선택적 presets[](미지정=3종 전체)
- 결과 코드: 1건 이상 생성 성공=201 / 전부 실패=500 / 대상 프리셋 전부 스킵(모두 원본과 동일 해상도)=400

### negative

- 구 전용 테이블 LS_RESOLUTION_EXPORT/LS_RESOLUTION_LBL_MAP 폐기·백필 마이그레이션(V125/V126) 필요
- INT-008·CDIAG-010·API-092·API-059·ERD-011 산출물 갱신 필요

### positive

- 증강과 단일 저장모델·단일 코드 경로로 유지비·드리프트 감소
- 라벨 좌표 배율 재계산으로 해상도 파생영상을 학습데이터로 활용 가능
- 업스케일 허용으로 표준 3종 프리셋 완전 커버
- 신규 컬럼 없이 AUG_TYPE_CD·기존 배율 컬럼 재사용
- 증강 이력·집계에 자연 노출, 기존 RAW_SN 파이프라인·데이터마트 뷰 재사용(뷰 스키마 변경 불필요)

- 기존 구현 재작업 불필요

- **description**: LS_RESOLUTION_EXPORT/LS_RESOLUTION_LBL_MAP 전용 테이블로 1행 추적, 프레임 다운스케일만·라벨 좌표 미제공·업스케일 거부

- 증강과 단일 코드 경로·단일 저장모델
- 라벨 좌표 배율 재계산으로 학습데이터 활용 가능
- 업스케일 허용
