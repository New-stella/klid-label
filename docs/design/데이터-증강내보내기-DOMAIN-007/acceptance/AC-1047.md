## statement

원본 참조 부재 또는 페이로드 무효면 등록을 거부하고 실패를 기록한다. 부모 DE_IDNTF_YN='N'이면 비식별 영상 파일이 없어 파생 비디오 복사가 물리적으로 불가하므로 등록하지 않는다. 같은 request_id 재전송은 중복 방지 식별자로 200 no-op(멱등) 또는 409(상태 충돌)로 구분한다. 중복 요청 허용(ADR-044) 이후 동시 콜백은 같은 영상·같은 종류 파생이 여러 건 공존할 수 있으므로 파생 식별자(VMS_CLIP_ID)를 증강 행 PK(DATA_AUG_SN)로 요청 건별 유일 부여한다.
