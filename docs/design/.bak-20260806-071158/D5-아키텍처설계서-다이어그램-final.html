1 소프트웨어 아키텍처 (레이어드)

표현·업무·데이터 계층을 분리한 레이어드(Layered) 아키텍처의 모듈형 단일 애플리케이션이다. 표현 계층은 업무 계층의 REST 인터페이스만 호출하고, 업무 계층은 컨트롤러 → 서비스 → 리포지토리의 단방향 의존으로 구성한다. AI 추론 연산은 내부 추론 서버(별도 프로세스, 무상태)로 분리해 GPU 자원을 격리한다.

동기 호출 (REST/JSON · ORM·동적질의 · 파일 I/O)
공통 기능 사용 (횡단 관심사)
프로세스 경계 호출 (내부 추론 서버 · 60초 타임아웃 · 장애 차단)

2 시스템 아키텍처

개발 대상시스템(학습데이터 저작도구)은 단일 인스턴스 애플리케이션 서버를 중심으로 내부 추론 서버(GPU 워커, 수평 확장)·관계형 DB·파일 스토리지로 구성한다. 애플리케이션 서버와 내부 추론 서버는 같은 내부 운영 영역이며, 외부 연동 시스템 5종(비식별 서버·외부 VLM·외부 증강 AI·관제서버·포털 DB)과는 시스템·인터페이스 경계를 두고 연동한다(모두 온프레미스 내부망의 별도 서버/시스템 — 인터넷·보안 경계가 아님).

연동 대상방향프로토콜 / 조건내용
사용자 단말 → 웹 프론트엔드→HTTPS관제/포털 발급 JWT를 브라우저 공유 스토리지로 인계 → 요청 헤더로 전달
웹 프론트엔드 → 애플리케이션→REST/JSON표준 응답 래퍼 기반 API 호출
애플리케이션 → 내부 추론 서버→내부망 · 60초 타임아웃객체탐지·세그멘테이션 추론 (장애 차단 적용)
애플리케이션 ↔ DB / 스토리지→ORM · 파일 I/O전용 스키마 영속 + 원본·비식별 2벌 저장
애플리케이션 → 비식별 서버outHTTP비식별 요청
애플리케이션 → 외부 VLMoutHTTP · 45초시계열 요청 + 결과 콜백 수신
애플리케이션 → 외부 증강 AIoutHTTP증강 요청 + 결과 콜백 수신 (WINTER/NIGHT/RAIN/해상도)
애플리케이션 → 관제서버out단방향 outbound완료/수정 통지 (메타·요약만, 본문·토큰 미포함)
