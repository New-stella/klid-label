# D11-R1 단위시험 절차서 (R1 기능요구사항 한정 최소 단위시험)

## 작성 목적
> 본 절차서는 R1 기능요구사항에 **직접 대응하는 컴포넌트만** 대상으로, 기능당 핵심 1~3건(정상 1건 + 핵심 경계/예외 1~2건)으로 압축한 **최소 단위시험 절차서**다. 인프라/공통(작업 배정·인증·세션·보안필터·배치 오케스트레이터·프레임추출·통계·관찰가능성 등) 컴포넌트는 제외한다.
> 대부분의 시험 케이스는 `docs/design/D11-단위시험케이스.md`(백엔드 단위테스트 코드 기반, 32개 컴포넌트 블록·329케이스)에서 R1 기능 직접대응 블록만 추출하고, 각 블록에서 대표 케이스만 선별한 것이다. **D11 원문 케이스는 문구를 변형 없이 그대로** 사용했고, 시험결과 칸은 설계 단계 규칙에 따라 공란으로 둔다(I2 단위시험 결과서에서 기입). **예외(유스케이스 누락 방지 보강분, 각 블록 출처에 명시)**: 블록 12(RQ-SFR-09-04 비식별 옵션 설정)는 D11 미수록·`[설계]` 케이스, 블록 13의 `TC-ING-*`(관제 학습용 적재, UC-018)는 D11 미수록이나 백엔드 실테스트(TrainingVideoIngestServiceTest 등)에서 도출했다. 활성 R1 기능 유스케이스 18종은 모두 실제 케이스를 보유한다(누락 0).
