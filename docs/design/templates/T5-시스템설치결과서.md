# T5 시스템 설치 결과서

## 작성 목적
> 개발한 시스템을 운영 환경에 설치한 결과를 기술하고, 설치 과정에서 발생한 이슈 및 해결 방안을 기록한다.

## 작성 방법
> 시스템 설치 절차에 따라 설치를 수행하고, 각 단계별 설치 결과와 검증 내역을 기술한다. 설치 환경, 설치 항목, 설치 결과, 설치 후 확인 사항 등을 체계적으로 작성한다.

## 항목 설명

- **설치 개요**: 설치 목적, 범위, 일정 등 전체적인 개요를 기술한다.
- **설치 환경**: 설치 대상 하드웨어, 소프트웨어, 네트워크 환경을 기술한다.
- **설치 항목 및 결과**: 서버, 데이터베이스, 애플리케이션 등 각 설치 항목별 설치 과정과 결과를 기술한다.
- **설치 후 검증**: 시스템 기동, 주요 기능 동작, 외부 시스템 연동 등을 확인한 결과를 기술한다.
- **이슈 및 조치사항**: 설치 과정에서 발생한 이슈와 해결 방안을 기록한다.
- **설치 확인서**: 설치 완료를 확인하는 서명란을 제공한다.

## 작성 시 참고사항

> **ID 체계 (프로젝트 공식)**
> - 프로젝트 ID: `KLID`
> - 서브시스템 ID (저작도구): `AT`
> - 산출물 파일명: `KLID_AT_시스템설치결과서_Rev {버전}`
> - 본 산출물에서 참조하는 ID:
>   - 데이터베이스 ID: `KLID-AT-DB-NNN` (D9 참조)
>   - 컴포넌트 ID: `KLID-AT-CO-NNN` (D3 참조)
>
> - HW 환경: CLAUDE.md의 환경별 접속 정보 참조 (dev/stg/prd 서버)
> - SW 환경: Java 17, Spring Boot 3.3, Python 3.11, FastAPI, Node.js, MariaDB 10.11, MaxScale 24.02.5
> - DB 설치: Flyway 마이그레이션 자동 실행 결과 확인 (`flyway_schema_history` 테이블)
> - 애플리케이션 설치: backend JAR 배포, ai-server uvicorn 기동, frontend static 배포
> - 연동 확인: ai-server `/health`, Gitea API 연결, 비식별서버 연결, 관제서버 통지 테스트
> - 설치 확인서: 발주자/수주자 양측 서명
