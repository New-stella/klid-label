**문제**: `build.gradle`에 `spring-boot-starter-websocket` 의존성이 있으나, 코드에서 WebSocket/STOMP/SockJS 사용처가 없음. D5 아키텍처에도 WebSocket 컴포넌트 없음.

**판단 필요**: 향후 실시간 알림에 사용할 예정인지, 아니면 제거할지

## 6. 개발 우선순위 권장

### Phase A — 관제서버 통지 인프라 (CRITICAL, 예상 3~5일)

```
#1~#8: ControlNotify 컴포넌트 전체 (Client + Debouncer + FallbackQueue + EventListener + Flyway)
#15~#18: 통지 테스트 스위트
```

- 의존: ReviewService.approve(), LabelService.upsert(), MetaService.update()에 이벤트 발행 추가
- 핵심 리스크: 디바운서 동시성, 폴백 큐 → 재시도 루프, 멱등성

### Phase B — 관제서버 조회 API (HIGH, 예상 2~3일)

```
#9~#14: TaskQueryController + 조회 API 3~4종 + 인증
```
